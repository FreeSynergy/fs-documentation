# Templates

Copy, rename `_program` → product name (lowercase, `-`), `_version` → vendor version (`1.11`, `2024`).
Rules: ADR 0012 (file set), ADR 0013 (no copying, notable ideas, store research), ADR 0014 (standards).
Placeholders are `<…>`. Optional files ("if needed") may be deleted if empty.
Mark claims ✅ (checked at a primary source, listed in Sources) or ⚠️ (unchecked).
