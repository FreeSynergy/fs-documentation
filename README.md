## 🌍 Multi-language support

All documentation is maintained in multiple languages to ensure global accessibility:

- 🇬🇧 **English**: [en/](docs/en/) — the only language written by hand
- 🇩🇪 **German / Deutsch**: [de/](docs/de/) — machine-translated from English
- 🌍 More languages are added the same way: translated from `en/`

## 📁 Project structure

| Path | Purpose | Published |
|------|---------|-----------|
| `docs/en/` | documentation (source) | yes |
| `docs/de/` | translation of `docs/en/` | yes |
| `conventions/` | rules and decisions (ADRs), templates | no |
| `todo/` | task lists per AI / role | no |
| `temp/` | inbox, drafts, research notes | no |
| `scripts/` | generators, checkers, fixers | no |
