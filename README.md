## 🌐 Multi-language support

All documentation is maintained in multiple languages to ensure global accessibility:

- 🇩🇪 **German / Deutsch**: see [`de/`](de/) directory
- 🇬🇧 **English**: see [`en/`](en/) directory
- 🌍 More languages can be added easily by creating new top-level directories (e.g., `fr/`, `es/`, etc.)
