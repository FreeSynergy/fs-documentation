    App Embed - Aussehen¶

    Grundlayout¶

    Ein App Embed ist die Einbettung ganzer Apps.

    Layout¶

    ┌─────────────────────────────────────────┐
│  ┌─────────────────────────────┐        │
│  │   App                       │        │
│  │   [Menü]                    │        │
│  │   [Content]                 │        │
│  └─────────────────────────────┘        │
└─────────────────────────────────────────┘

    Größe-Varianten¶

    Größe Breite/Höhe Verwendung
    Small 400x300px Inline
    Medium 600x400px Standard
    Large 800x600px Featured
    Full 100% Volle Breite

    Farb-Varianten¶

    Status Farbe Beschreibung
    Background Weiß Hintergrund
    Border Grau Rand

    Responsive¶

    Breakpoint Verhalten
    Desktop (>768px) Volle Größe
    Tablet (480-768px) Skaliert
    Mobile (<480px) Fullscreen

    Hover-Effekte¶

    Effekt Beschreibung
    border Rand leuchtet auf
