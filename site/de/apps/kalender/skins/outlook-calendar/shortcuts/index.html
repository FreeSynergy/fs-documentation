    Outlook Kalender - Tastatur-Shortcuts¶

    Übersicht¶

    Outlook Kalender hat je nach Client sehr unterschiedliche Tastaturbelegung. Für das klassische Outlook auf Windows veröffentlicht Microsoft eine umfangreiche Kurzreferenz (Module, Terminanlage, Navigation). Für Outlook im Web und das neue Outlook für Windows ist der dokumentierte Kalender-Umfang deutlich kleiner: es gelten überwiegend Browser-Standards plus wenige App-Tasten. Die Outlook-Mobile-Apps haben keine eigenen Shortcuts.

    Stand: Outlook im Web / neues Outlook, Outlook Classic (Windows), Outlook für Mac, Outlook Mobile. Microsoft ändert die Listen versionsweise; die Übersicht in der App (Einstellungen → Barrierefreiheit → Tastatur-Shortcuts) ist maßgeblich. Unsichere Kombinationen sind hier ausdrücklich als „nicht dokumentiert" markiert.

    Allgemein (Browser-Standard, alle Web-Clients)¶

    Shortcut Funktion
    Tab / Shift+Tab Nächstes/vorheriges Bedienelement (Befehlsleiste, Kalenderliste, Termine)
    Enter Fokussierten Termin öffnen, Schaltfläche auslösen
    Space Kalenderauswahl in der Liste umschalten, Schalter bedienen
    Esc Overlay-Formular, Menü oder Suchvorschläge schließen
    F5 / Ctrl+R Seite neu laden, Kalenderblatt neu abrufen
    Alt+← / Alt+→ Browser zurück/vor
    Ctrl+P Drucken (Druckdialog des Kalenders bzw. des Browsers)
    Ctrl+F Text auf der Seite suchen (Browser-Funktion, nicht Kalendersuche)
    Ctrl+++ / Ctrl+- / Ctrl+0 Vergrößern, Verkleinern, Zoom zurücksetzen

    Outlook Classic (Windows-Desktop, dokumentierte Tasten)¶

    Shortcut Funktion
    Strg+1 Zum Postfach wechseln
    Strg+2 Zum Kalender wechseln
    Strg+3 Zu den Kontakten wechseln
    Strg+4 Zu den Aufgaben wechseln
    Strg+6 Zum heutigen Datum springen
    Strg+N Neues Element in der aktuellen Ansicht (im Kalender: Termin)
    Strg+Umschalt+Q Neuen Termin anlegen
    Strg+E Suchfeld fokussieren
    F3 Suche über alle Outlook-Elemente
    Esc Dialog abbrechen, Bearbeitung verlassen
    Tab / Shift+Tab Felder im Terminformular durchlaufen
    Alt + Buchstabe Zugriff auf Menübandfunktionen (KeyTips)

    Navigation im Kalenderblatt¶

    Shortcut Funktion
    Tab Termine in Lesereihenfolge ansteuern
    Enter Angezeigten Termin öffnen
    Pfeiltasten Zwischen Terminen bzw. Tagen innerhalb des Rasters wandern (Web-Client: nur in Teilen dokumentiert, sonst (nicht dokumentiert))
    Esc Terminübersicht/Overlay verlassen
    Strg+6 (nur Classic) Heute

    Nicht dokumentiert bzw. nicht vorhanden:

    Erwarteter Shortcut Status
    T für „Heute" ❌ Nicht dokumentiert — „Heute"-Schaltfläche nutzen (Classic: Strg+6)
    D / W / M für Tag/Woche/Monat ❌ Nicht dokumentiert — Ansicht nur über die Schaltfläche Ansicht
    G dann C (zu Kalender) ❌ Für Outlook Kalender nicht dokumentiert — Web-Client: Modul links anklicken, Classic: Strg+2
    Q für Schnellerfassung ❌ Nicht vorhanden — keine Quick-Add-Zeile
    1–9 für Kalenderauswahl ❌ Nicht vorhanden

    Erstellung und Bearbeitung¶

    Shortcut Funktion
    Strg+N (Classic, im Kalender) Neuen Termin anlegen
    Strg+Umschalt+Q (Classic) Neuen Termin anlegen
    Enter (im Formular) Standardaktion auslösen (in Outlook „Senden" bei Besprechungen)
    Tab / Shift+Tab Eingabefelder des Terminformulars erreichen
    Esc Formular ohne Speichern schließen
    Backspace / Entf Text in Feldern löschen; markierten Termin löschen (nur mit aktiver Auswahl, sonst Rückmeldung des Clients)
    Ziffern in Datums-/Zeitfeldern Werte direkt eingeben (Feldstandard, kein App-Shortcut)

    Nicht dokumentiert bzw. nicht vorhanden:

    Erwarteter Shortcut Status
    N für neues Ereignis im Web-Client ⚠️ In der offiziellen Referenz für den Kalender nicht eindeutig dokumentiert — sicherer Weg: Neues Ereignis-Schaltfläche
    Entf zum Löschen eines Termins im Web ⚠️ Nicht dokumentiert — Kontextmenü oder Formular nutzen
    Strg+Z für Rückgängig beim Verschieben ❌ Nicht vorhanden — Änderungen werden sofort gespeichert
    Pfeiltasten zum Verschieben eines Termins ❌ Nicht vorhanden — Drag & Drop mit Maus oder Touch
    Strg+S zum Speichern ❌ Nicht vorhanden — Overlay-Formulare speichern automatisch, Besprechungen werden gesendet

    Dialoge und Formulare (alle Clients)¶

    Shortcut Funktion
    Tab / Shift+Tab Felder durchlaufen
    Enter Aktive Standardschaltfläche auslösen
    Esc Abbrechen, Overlay schließen
    Space Auswahl öffnen, Checkbox/Schalter umschalten
    ↑ / ↓ Werte in Zahlen-/Datumsfeldern und Auswahllisten ändern
    Shift+Enter Zeilenumbruch im Beschreibungsfeld

    Suchen und Filtern¶

    Shortcut Funktion
    Suchfeld anklicken + Text Termine durchsuchen
    Enter Suche ausführen bzw. hervorgehobenen Treffer öffnen
    Esc Sucheingabe verlassen
    Strg+E (Classic) / F3 (Classic) Suche fokussieren bzw. allgemeine Suche
    / als Suchtaste ❌ Nicht dokumentiert — Suchfeld muss fokussiert werden

    Mac-Varianten¶

    Unter macOS ersetzen Cmd die Strg-Tastenkombinationen der Desktop-Version; im Browser gelten die macOS-Browser-Tasten.

    Shortcut Funktion
    Cmd+1 / Cmd+2 / Cmd+3 Modul wechseln (Mail / Kalender / Kontakte) — klassische Mac-Version, für das neue Outlook für Mac nicht separat dokumentiert
    Cmd+N Neues Element im aktuellen Modul (im Kalender: Termin)
    Cmd+F Suchfeld fokussieren bzw. Seitentext suchen (clientabhängig)
    Cmd+R Neu laden (Browser)
    Cmd+P Drucken
    Cmd+K Adressleiste fokussieren (Browser)
    Cmd+++ / Cmd+- / Cmd+0 Zoom
    Cmd+↑ / Cmd+↓ Seitenanfang/-ende (Browser)
    Esc Dialog schließen

    Nicht dokumentiert: Cmd+D (Tag-Ansicht), Cmd+T (Heute), Cmd+Shift+C (Termin) — für Outlook Kalender nicht belegt; Bezeichnungen und Tasten können je nach Version abweichen.

    Outlook Mobile (iOS, Android)¶

    • Keine eigenen Shortcuts. Bedienung über Touch: Tippen, langes Drücken (Kontext), Ziehen (Termin verschieben), Wischen (Datum/Ansicht).
    • Angeschlossenem Bluetooth-Keyboard folgen den System-Standards von iOS/Android; eine von Microsoft dokumentierte Outlook-Kalender-Tastenliste existiert dafür nicht.

    Barrierefreie Bedienung¶

    Shortcut Funktion
    Tab Befehlsleiste, Kalenderliste, Terminblöcke und Formulare erreichen
    Shift+Tab Rückwärts navigieren
    Enter / Space Termin öffnen, Aktion auslösen
    Esc Overlays, Menüs und Vorschlagslisten verlassen
    ↑ / ↓ / ← / → Auswahlen, Teilnehmerlisten und Listenansichten bedienen
    Alt (Classic) Menüband-KeyTips anzeigen

    Zusammenfassung¶

    • Outlook Classic (Windows) ist der Client mit den meisten dokumentierten Tasten: Strg+2 (Kalender), Strg+6 (Heute), Strg+N / Strg+Umschalt+Q (Termin), Strg+E (Suche).
    • Outlook im Web und neues Outlook verlassen sich weitgehend auf Browser-Tasten und Maus/Touch; Einzelbuchstaben für Ansichten existieren nicht als dokumentierte Funktion.
    • Outlook Mobile hat keine Tastatur-Shortcuts.
    • Wer im Web schnell arbeiten will, nutzt die Schnellzugriff-Elemente (Heute, Ansicht, Neues Ereignis in der Befehlsleiste) und die Kalenderliste statt erwarteter Einzeltasten.
