    VSCodium - Tastatur-Shortcuts¶

    Übersicht¶

    VSCodium bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten mit dem Code-Editor, integrierten Git, Terminal und Debugger.

    Allgemeine Shortcuts¶

    Shortcut Funktion
    Ctrl+Shift+P / Cmd+Shift+P Befehlspalette öffnen
    Ctrl+, / Cmd+, Einstellungen öffnen
    F1 Befehlspalette öffnen
    Ctrl+K Ctrl+S / Cmd+K Cmd+S Tastatur-Shortcuts anzeigen
    Ctrl+Shift+F / Cmd+Shift+F Global Suche
    Ctrl+H / Cmd+H Ersetzen
    Ctrl+Shift+J / Cmd+Shift+J Suchfenster öffnen

    Navigation Shortcuts¶

    Datei-Navigation¶

    Shortcut Funktion
    Ctrl+P / Cmd+P Schnellsuche (Dateien)
    Ctrl+Shift+E / Cmd+Shift+E Explorer öffnen
    Ctrl+Shift+F / Cmd+Shift+F Globale Suche
    Ctrl+Shift+G / Cmd+Shift+G Git öffnen
    Ctrl+Shift+X / Cmd+Shift+X Erweiterungen öffnen
    Ctrl+Shift+D / Cmd+Shift+D Debugging öffnen
    Ctrl+Shift+E / Cmd+Shift+E Explorer öffnen
    Ctrl+Shift+H / Cmd+Shift+H Ersetzen
    Ctrl+Shift+J / Cmd+Shift+J Suchfenster ein/ausblenden

    Editor-Navigation¶

    Shortcut Funktion
    Ctrl+G / Cmd+G Zeile springen
    Ctrl+Shift+O / Cmd+Shift+O Symbol in Datei suchen
    Ctrl+T / Cmd+T Alle Symbole suchen
    Ctrl+Shift+M / Cmd+Shift+M Probleme (Problems) öffnen
    F8 / Cmd+F8 Nächster Fehler
    Shift+F8 / Shift+Cmd+F8 Vorheriger Fehler
    Ctrl+Shift+Tab / Cmd+Shift+Tab Vorheriger Tab
    Ctrl+Tab / Cmd+Tab Nächster Tab

    Zeilennavigation¶

    Shortcut Funktion
    Ctrl+↑ / Cmd+↑ Editor-Anfang
    Ctrl+↓ / Cmd+↓ Editor-Ende
    Ctrl+Home / Cmd+Home Dokument-Anfang
    Ctrl+End / Cmd+End Dokument-Ende
    Ctrl+Left / Cmd+Left Wortanfang (links)
    Ctrl+Right / Cmd+Right Wortanfang (rechts)

    Editor Shortcuts (Code-Bearbeitung)¶

    Textauswahl¶

    Shortcut Funktion
    Ctrl+A / Cmd+A Alles auswählen
    Ctrl+L / Cmd+L Ganze Zeile auswählen
    Ctrl+D / Cmd+D Nächstes Wort auswählen
    Ctrl+Shift+L / Cmd+Shift+L Alle Vorkommen auswählen
    Ctrl+U / Cmd+U Cursor zurücksetzen
    Alt+Click Mehrere Cursor setzen
    Shift+Alt+I Cursor an Zeilenende

    Kopieren/Einfügen¶

    Shortcut Funktion
    Ctrl+C / Cmd+C Kopieren
    Ctrl+X / Cmd+X Ausschneiden
    Ctrl+V / Cmd+V Einfügen
    Ctrl+Shift+D / Cmd+Shift+D Zeile duplizieren
    Ctrl+Shift+K / Cmd+Shift+K Zeile löschen
    Ctrl+Shift+↑ / Cmd+Shift+↑ Zeile nach oben verschieben
    Ctrl+Shift+↓ / Cmd+Shift+↓ Zeile nach unten verschieben
    Alt+Shift+↑ Zeile nach oben verschieben
    Alt+Shift+↓ Zeile nach unten verschieben

    Formatierung¶

    Shortcut Funktion
    Alt+Shift+F / Option+Shift+F Dokument formatieren
    Ctrl+K Ctrl+F / Cmd+K Cmd+F Ausgewählten Code formatieren
    Ctrl+] / Cmd+] Einrücken
    Ctrl+[ / Cmd+[ Einzug entfernen
    Tab Einrücken
    Shift+Tab Einzug entfernen

    Kommentare¶

    Shortcut Funktion
    Ctrl+/ / Cmd+/ Zeile auskommentieren
    Ctrl+K Ctrl+C / Cmd+K Cmd+C Block auskommentieren
    Ctrl+Shift+A / Cmd+Shift+A Block auskommentieren (Alternative)

    Git Shortcuts¶

    Shortcut Funktion
    Ctrl+Shift+G / Cmd+Shift+G Git öffnen
    Ctrl+Shift+C / Cmd+Shift+C Repository kopieren
    Ctrl+Shift+K / Cmd+Shift+K Repository entfernen
    Ctrl+Shift+B / Cmd+Shift+B Branch wechseln
    Ctrl+Shift+P → Git: Sync Pull/Push

    Debugging Shortcuts¶

    Shortcut Funktion
    F5 / Fn+F5 Debugger starten
    Shift+F5 / Shift+Fn+F5 Debugger stoppen
    F9 / Fn+F9 Haltepunkt umschalten
    F10 / Fn+F10 Step over
    F11 / Fn+F11 Step into
    Shift+F11 / Shift+Fn+F11 Step out
    Ctrl+Shift+F5 / Cmd+Shift+Fn+F5 Neustart

    Terminal Shortcuts¶

    Shortcut Funktion
    Ctrl+` / Cmd+` Terminal öffnen/schließen
    Ctrl+Shift+ ` / Cmd+Shift+ ` Neues Terminal
    Ctrl+C / Cmd+C Prozess unterbrechen
    Ctrl+Z / Cmd+Z Prozess in Hintergrund
    Ctrl+L / Cmd+L Terminal leeren

    View Shortcuts¶

    Shortcut Funktion
    Ctrl+B / Cmd+B Sidebar ein/ausblenden
    Ctrl+Shift+E / Cmd+Shift+E Explorer öffnen
    Ctrl+Shift+F / Cmd+Shift+F Suche öffnen
    Ctrl+Shift+G / Cmd+Shift+G Git öffnen
    Ctrl+Shift+D / Cmd+Shift+D Debugging öffnen
    Ctrl+Shift+X / Cmd+Shift+X Erweiterungen öffnen
    Ctrl+Shift+M / Cmd+Shift+M Probleme öffnen
    Ctrl+Shift+H / Cmd+Shift+H Ersetzen
    F11 Vollbildmodus
    Ctrl+Shift+I / Cmd+Shift+I Entwicklerwerkzeuge
    Ctrl+Q / Cmd+Q Menü ausblenden
    Ctrl+Shift+V / Cmd+Shift+V Markdown-Vorschau

    Schnelle Aktionen¶

    Shortcut Funktion
    Ctrl+. / Cmd+. Schnelle Korrektur
    Ctrl+Shift+. / Cmd+Shift+. Refactoring
    F2 / Cmd+F2 Umbenennen
    Ctrl+Shift+R / Cmd+Shift+R Symbol in Datei umbenennen
    Ctrl+Shift+F10 / Cmd+Shift+F10 Code ausführen

    Mac Shortcuts¶

    Shortcut Funktion
    Cmd+Shift+P Befehlspalette
    Cmd+, Einstellungen
    Cmd+P Schnellsuche
    Cmd+Shift+F Globale Suche
    Cmd+Shift+E Explorer öffnen
    Cmd+Shift+G Git öffnen

    Tastatur-Navigation¶

    Shortcut Funktion
    Tab Nächster Fokus
    Shift+Tab Vorheriger Fokus
    Enter Aktivieren
    Escape Fokus verlassen
    Space Checkbox auswählen

    Zusammenfassung¶

    VSCodium bietet umfangreiche Shortcuts für: - Navigation: Datei, Editor, Git, Debugging - Code-Bearbeitung: Textauswahl, Kopieren/Einfügen, Formatierung - Git: Repository-Verwaltung, Branches, Sync - Debugging: Haltepunkte, Step-by-Step - Terminal: Integrierter Terminal-Zugriff - Ansicht: Sidebar, Menüs, Vorschauen

    Mac-Nutzer profitieren von den gleichen Shortcuts mit Cmd anstelle von Ctrl.
