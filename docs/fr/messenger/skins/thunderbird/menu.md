# Thunderbird - Menus

## Vue d'ensemble

Thunderbird est un client de courrier électronique et de messagerie open source développé par la Mozilla Foundation. Il fait partie de l'écosystème Mozilla et a été spécifiquement conçu pour la communication par courrier électronique, avec des fonctions de calendrier et de carnet d'adresses optionnelles via des extensions.

## Éléments du menu principal

### 1. Fichier
- **Fonction**: Gestion des fichiers et des comptes
- **Détails**:
  - Ajouter/supprimer un compte
  - Paramètres du compte
  - Importer/exporter (CSV, vCard, EML)
  - Imprimer
  - Enregistrer sous
  - Quitter

### 2. Édition
- **Fonction**: Éditer des objets
- **Détails**:
  - Annuler/Rétablir
  - Couper/Copier/Coller
  - Rechercher/Remplacer
  - Sélectionner
  - Tout sélectionner
  - Rechercher dans les messages

### 3. Actions
- **Fonction**: Actions contextuelles
- **Détails**:
  - Envoyer/recevoir des courriels
  - Filtrer le message
  - Marquer le message
  - Déplacer/copier le message
  - Récupérer les messages envoyés

### 4. Affichage
- **Fonction**: Disposition et affichage
- **Détails**:
  - Actualiser
  - Changer le mode d'affichage (Liste, Tuiles)
  - Trier (par date, objet, etc.)
  - Grouper
  - Afficher/masquer les colonnes
  - Afficher/masquer les barres d'outils
  - Afficher/masquer le volet de navigation
  - Afficher/masquer le volet d'aperçu

### 5. Courrier électronique
- **Fonction**: Gestion du courrier électronique (dans la fenêtre de courrier électronique)
- **Détails**:
  - Nouveau courriel
  - Répondre/Transférer
  - Déplacer/copier le courriel
  - Marquer le courriel
  - Catégoriser le courriel
  - Supprimer le courriel
  - Imprimer
  - Propriétés
  - Ajouter/vérifier la signature GPG

### 6. Calendrier (Lightning)
- **Fonction**: Gestion des rendez-vous (dans la fenêtre de calendrier)
- **Détails**:
  - Nouveau rendez-vous
  - Nouveau rendez-vous récurrent
  - Ouvrir/modifier le rendez-vous
  - Copier/supprimer le rendez-vous
  - Déplacer le rendez-vous
  - Partage de calendrier
  - Importer/exporter le calendrier

### 7. Carnet d'adresses (Lightning)
- **Fonction**: Gestion des adresses
- **Détails**:
  - Nouveau contact
  - Nouveau dossier de contacts
  - Ouvrir/modifier le contact
  - Copier/supprimer le contact
  - Importer/exporter les contacts
  - Créer une liste de diffusion

### 8. Extras
- **Fonction**: Extensions et extras
- **Détails**:
  - Gérer les extensions
  - Exécuter des scripts
  - Importer (Outlook, Outlook Express, Eudora)
  - Exporter
  - Paramètres
  - Outils de développement

### 9. Outils
- **Fonction**: Outils et utilitaires
- **Détails**:
  - Paramètres du compte
  - Modifier les filtres
  - Reconstruire les index de recherche
  - Statut hors ligne
  - Gérer le stockage

### 10. Aide
- **Fonction**: Fonctions d'aide
- **Détails**:
  - Documentation d'aide
  - À propos de Thunderbird
  - À propos de Mozilla
  - Informations de licence
  - Dépannage
