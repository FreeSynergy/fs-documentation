# Kontact - Menus

## Vue d'ensemble

Kontact est une application intégrée de gestion des informations personnelles (PIM) pour l'environnement de bureau KDE. Il combine plusieurs applications KDE bien connues en une seule application consolidée.

## Éléments du menu principal

### 1. Fichier (vue backstage)
- **Fonction**: Gestion des fichiers et des comptes
- **Détails**:
  - Ajouter/supprimer un compte (courrier électronique, nouvelles, calendrier)
  - Paramètres du compte
  - Importer/exporter (vCard, CSV, ICS)
  - Paramètres
  - Quitter

### 2. Édition
- **Fonction**: Éditer des objets
- **Détails**:
  - Annuler/Rétablir
  - Couper/Copier/Coller
  - Rechercher/Remplacer
  - Sélectionner
  - Tout sélectionner

### 3. Actions
- **Fonction**: Actions contextuelles
- **Détails**:
  - Envoyer/recevoir des courriels
  - Mettre à jour le calendrier
  - Synchroniser les contacts
  - Mettre à jour les tâches
  - Lancer la recherche plein texte

### 4. Affichage
- **Fonction**: Disposition et affichage
- **Détails**:
  - Actualiser
  - Changer le mode d'affichage (Liste, Tuiles)
  Trier (par date, objet, etc.)
  - Grouper
  - Afficher/masquer les colonnes
  - Afficher/masquer les barres d'outils
  - Afficher/masquer le volet de navigation

### 5. Courrier électronique
- **Fonction**: Gestion du courrier électronique (dans la fenêtre de courrier électronique)
- **Détails**:
  - Nouveau courriel
  - Répondre/Transférer
  - Déplacer/copier le courriel
  - Marquer le courriel
  - Catégoriser le courriel
  - Supprimer le courriel
  - Imprimer
  - Propriétés

### 6. Calendrier
- **Fonction**: Gestion des rendez-vous (dans la fenêtre de calendrier)
- **Détails**:
  - Nouveau rendez-vous
  - Nouveau rendez-vous récurrent
  - Ouvrir/modifier le rendez-vous
  - Copier/supprimer le rendez-vous
  - Déplacer le rendez-vous
  - Partage de calendrier
  - Importer/exporter le calendrier

### 7. Contacts
- **Fonction**: Gestion des adresses (dans la fenêtre de contacts)
- **Détails**:
  - Nouveau contact
  - Nouveau dossier de contacts
  - Ouvrir/modifier le contact
  - Copier/supprimer le contact
  - Importer/exporter les contacts
  - Créer une liste de diffusion

### 8. Tâches
- **Fonction**: Gestion des tâches (dans la fenêtre de tâches)
- **Détails**:
  - Nouvelle tâche
  - Ouvrir/modifier la tâche
  - Copier/supprimer la tâche
  - Changer le statut de la tâche
  - Rappels

### 9. Notes
- **Fonction**: Gérer les notes (dans la fenêtre de notes)
- **Détails**:
  - Nouvelle note
  - Modifier la note
  - Supprimer la note
  - Copier la note

### 10. Extras
- **Fonction**: Extensions et extras
- **Détails**:
  - Gérer les plugins
  - Exécuter des scripts
  - Importer (Outlook, Thunderbird)
  - Exporter
  - Paramètres

### 11. Aide
- **Fonction**: Fonctions d'aide
- **Détails**:
  - Documentation d'aide
  - À propos de Kontact
  - À propos de KDE
  - Informations de licence
