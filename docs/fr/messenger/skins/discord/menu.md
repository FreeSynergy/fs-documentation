# Discord - Éléments de menu

## Vue d'ensemble

Discord est une plateforme de communication propriétaire et un client de chat initialement développé pour les communautés de jeu, mais aujourd'hui utilisé pour toutes sortes de communautés.

## Éléments de menu principaux

### 1. Menu serveur (Gauche)
- **Fonction**: Gestion serveur
- **Détails**:
  - Créer/rejoindre serveur
  - Paramètres serveur
  - Changer l'icône/nom du serveur
  - Gérer les rôles serveur

### 2. Menu canal (Gauche)
- **Fonction**: Gestion canal
- **Détails**:
  - Rejoindre canal texte
  - Rejoindre canal voix
  - Paramètres canal
  - Permissions canal

### 3. Menu chat (Centre)
- **Fonction**: Communication chat
- **Détails**:
  - Envoyer messages
  - Modifier/supprimer messages
  - Marquer messages
  - Citer messages
  - Insérer emojis
  - Insérer GIFs

### 4. Menu voix (Droite)
- **Fonction**: Appels voix et vidéo
- **Détails**:
  - Démarrer appel audio
  - Démarrer appel vidéo
  - Partage d'écran
  - Contrôler microphone
  - Contrôler volume

### 5. Menu membres (Droite)
- **Fonction**: Gestion membres
- **Détails**:
  - Afficher liste des membres
  - Inviter membres
  - Expulser membres
  - Bannir membres
  - Changer rôles membres

### 6. Paramètres
- **Fonction**: Gérer paramètres
- **Détails**:
  - Paramètres généraux
  - Paramètres médias
  - Paramètres de sécurité
  - Paramètres de thème
  - Paramètres de langue

### 7. Fonctions d'aide
- **Fonction**: Fonctions d'aide
- **Détails**:
  - Documentation d'aide
  - À propos de Discord
  - Dépannage
