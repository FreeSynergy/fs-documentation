# Discord - Description

## Vue d'ensemble

Discord est une plateforme de communication propriétaire et un client de chat initialement développé pour les communautés de jeu, mais aujourd'hui utilisé pour toutes sortes de communautés. Discord propose la voix sur IP, la vidéo, le chat texte et le partage d'écran.

## Ce que fait Discord

Discord est une plateforme de communication spécialement conçue pour créer et gérer des communautés. Il permet le chat de groupe dans des serveurs avec plusieurs canaux, des appels vocaux et vidéo, ainsi que le partage d'écran pour le streaming et le jeu.

## Avantages

- **Appels voix et vidéo**: Appels voix et vidéo natifs de haute qualité
- **Structure serveur**: Organisation des communautés en serveurs avec canaux
- **Partage d'écran**: Partage d'écran natif pour le streaming
- **Focus jeu**: Optimisé pour les communautés de jeu
- **Multiplateforme**: Fonctionne sur Windows, macOS, Linux, iOS, Android, Web
- **Intégrations**: Nombreuses intégrations avec des services externes
- **Bots**: Système de bots étendu pour l'automatisation
- **Modération**: Outils de modération étendus
- **Gratuit**: Gratuit pour toutes les fonctionnalités (avec options premium)

## Distinction par rapport aux autres systèmes

### Discord vs. Element
- **Discord** est propriétaire et centralisé, **Element** est open source et décentralisé
- **Discord** a la voix/vidéo native, **Element** l'a via le protocole VoIP
- **Element** a le chiffrement de bout en bout par défaut, **Discord** seulement dans les messages privés
- **Discord** a plus de fonctionnalités de jeu, **Element** a plus de confidentialité

### Discord vs. Telegram
- **Discord** a la voix/vidéo native, **Telegram** l'a via VoIP
- **Discord** a une structure de serveur, **Telegram** a des canaux/groupes
- **Telegram** a des chats secrets avec chiffrement de bout en bout, **Discord** seulement dans les messages privés
- **Discord** a plus d'outils de modération

### Discord vs. Mastodon
- **Discord** est pour le chat et les groupes, **Mastodon** est pour le microblogging
- **Discord** a la voix/vidéo, **Mastodon** n'a pas de voix/vidéo
- **Discord** est centralisé, **Mastodon** est décentralisé via des instances

## Détails techniques

- **Plateforme**: Windows, macOS, Linux, iOS, Android, Web
- **Protocole**: Protocole propriétaire Discord
- **Backend**: Backend personnalisé Discord
- **Voix/vidéo**: WebRTC pour les appels voix/vidéo
- **Chiffrement**: TLS pour la transmission des données, pas de chiffrement de bout en bout
- **Authentification**: OAuth2, Email/Mot de passe
- **Bots**: Bots Discord via API
- **Langage de programmation**: TypeScript, React (Web), Kotlin (Android), Swift (iOS)

## À qui convient Discord ?

- **Communautés de jeu**: Pour ceux qui veulent gérer des communautés de jeu
- **Communautés de loisirs**: Pour ceux qui veulent gérer des communautés de loisirs
- **Entreprises**: Pour ceux qui veulent gérer la communication d'équipe
- **Streamers**: Pour ceux qui veulent gérer des communautés de streaming
- **Grandes communautés**: Pour ceux qui veulent gérer de grandes communautés
