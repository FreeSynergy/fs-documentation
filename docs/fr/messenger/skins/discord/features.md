# Discord - Fonctionnalités

## Vue d'ensemble

Discord est une plateforme de communication propriétaire et un client de chat initialement développé pour les communautés de jeu, mais aujourd'hui utilisé pour toutes sortes de communautés.

## Fonctionnalités principales

### 1. Gestion de serveur
- **Créer serveur**: Créer vos propres serveurs
- **Rejoindre serveur**: Rejoindre des serveurs existants
- **Paramètres serveur**: Configurer les paramètres serveur
- **Rôles serveur**: Gérer les rôles pour les membres
- **Permissions serveur**: Configurer les permissions pour les rôles

### 2. Gestion de canal
- **Canaux texte**: Canaux basés sur le texte pour le chat
- **Canaux voix**: Canaux voix pour les chats audio
- **Catégories**: Organiser les canaux en catégories
- **Paramètres canal**: Configurer les paramètres canal
- **Permissions canal**: Configurer les permissions pour les canaux

### 3. Communication chat
- **Chat texte**: Communication basée sur le texte dans les canaux
- **Messages directs**: Messages directs à des utilisateurs individuels
- **Messages de groupe**: Messages de groupe à plusieurs utilisateurs
- **Chiffrement de bout en bout**: Pas de chiffrement de bout en bout (seulement TLS)
- **Statut**: En ligne/Abusé/Occupé/Hors ligne
- **Accusés de lecture**: Afficher les accusés de lecture

### 4. Appels voix et vidéo
- **Chats voix**: Chats audio dans les canaux voix
- **Chats vidéo**: Chats vidéo avec caméra
- **Partage d'écran**: Partage d'écran pour le streaming
- **Outils d'appel**: Muet, contrôle du volume
- **Historique d'appel**: Afficher l'historique d'appel

### 5. Transfert de fichiers
- **Pièces jointes**: Envoi de fichiers de toute taille
- **Drag & Drop**: Drag & drop pour le transfert de fichiers
- **Aperçu fichier**: Aperçu des images, vidéos, documents
- **GIFs**: Intégrer des GIFs dans les messages

### 6. Bots et intégrations
- **Bots**: Système de bots étendu pour l'automatisation
- **Webhooks**: Webhooks pour les intégrations externes
- **OAuth2**: Intégration OAuth2 pour les services externes
- **Fonctions aléatoires**: Fonctions aléatoires pour le divertissement
- **Gestionnaire d'intégrations**: Gestionnaire pour les intégrations externes

### 7. Modération
- **Gérer membres**: Expulser, bannir des membres
- **Gérer rôles**: Créer et gérer des rôles
- **Journal d'audit**: Journal d'audit pour les modifications serveur
- **Système d'avertissements**: Système d'avertissements pour les membres
- **Modération automatique**: Modération automatique

### 8. Profil
- **Profil personnel**: Gérer votre propre profil
- **Notifications**: Gérer les notifications
- **Paramètres de confidentialité**: Configurer les paramètres de confidentialité
- **Authentification**: Authentification à deux facteurs

## Ce que Discord ne peut pas faire

- Aucune prise en charge native pour email (doit être combiné avec le client email)
- Aucune prise en charge native pour IRC
- Aucune prise en charge native pour Signal/WhatsApp
- Aucune intégration native Mastodon (seulement via webhooks)
- Aucun chiffrement de bout en bout natif (seulement TLS)

## Bots Discord

- **MEE6**: Bot de modération et bot de musique
- **Dyno**: Bot de modération et automation
- **Bot de musique**: Jouer de la musique dans les canaux voix
- **Carl-bot**: Bot de modération et auto-modération
- **Bots utilitaires**: Divers bots utilitaires

## Discord Nitro (Premium)

### Fonctionnalités de Discord Nitro
- **Taille de fichier plus grande**: Envoyer des fichiers jusqu'à 100Mo
- **Vidéos HD**: Envoyer des vidéos HD
- **GIFs**: Utiliser des GIFs personnalisés comme emojis
- **Logo serveur**: Logo serveur personnalisé
- **Avatar animé**: Avatar animé
- **Streaming**: Qualité de streaming plus élevée
- **Serveur plus grand**: Serveurs plus grands (jusqu'à 1 million de membres)

## Raccourcis

| Raccourci | Fonction |
|----------|----------|
| `Entrée` | Envoyer message |
| `Maj+Entrée` | Nouvelle ligne |
| `Ctrl+K` | Rechercher canal |
| `Ctrl+Maj+K` | Rechercher serveur |
| `Ctrl+E` | Paramètres |
| `Ctrl+M` | Appel audio |
| `Ctrl+V` | Appel vidéo |
| `Ctrl+Maj+D` | Partage d'écran |
