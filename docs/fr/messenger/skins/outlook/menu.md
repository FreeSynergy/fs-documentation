# Outlook - Menus

## Vue d'ensemble

Outlook est le client de messagerie le plus populaire de Microsoft, intégré à Microsoft 365. Il combine courrier électronique, agenda, tâches et contacts dans une seule application.

## Menus principaux

### 1. Fichier (Vue backstaging)
- **Fonction** : Gestion des fichiers et des comptes
- **Détails** :
  - Ajouter/supprimer un compte
  - Paramètres du compte
  - Options d'impression
  - Exporter/Importer (PST, OST)
  - Options (Paramètres)

### 2. Accueil
- **Fonction** : Vue principale des courriels
- **Détails** :
  - Nouveau courriel
  - Répondre/Transférer
  - Navigation dans les dossiers
  - Recherche
  - Filtrer et trier

### 3. Envoyer/Réception
- **Fonction** : Transmission des courriels
- **Détails** :
  - Envoyer/réceptionner tous les dossiers
  - Actualiser
  - Paramètres d'envoi/réception

### 4. Affichage
- **Fonction** : Mise en page et affichage
- **Détails** :
  - Actualiser
  - Changer la mise en page actuelle
  - Trier
  - Groupes
  - Options d'affichage

### 5. Envoyer/Réception
- **Fonction** : Transmission des courriels
- **Détails** :
  - Envoyer/réceptionner tous les dossiers
  - Actualiser
  - Paramètres d'envoi/réception

### 6. Message
- **Fonction** : Gestion des messages (dans la fenêtre de message)
- **Détails** :
  - Répondre/Transférer
  - Déplacer le message
  - Marquer
  - Catégoriser
  - Actions (Imprimer, Transférer)

### 7. Agenda
- **Fonction** : Gestion des rendez-vous
- **Détails** :
  - Nouveau rendez-vous
  - Nouveau rendez-vous récurrent
  - Ouvrir/modifier le rendez-vous
  - Partage d'agenda

### 8. Contacts
- **Fonction** : Gestion des contacts
- **Détails** :
  - Nouveau contact
  - Nouveau dossier de contacts
  - Modifier le contact
  - Importer/exporter les contacts

### 9. Tâches
- **Fonction** : Gestion des tâches
- **Détails** :
  - Nouvelle tâche
  - Modifier la tâche
  - Changer le statut de la tâche
  - Rappels

### 10. Notes
- **Fonction** : Gérer les notes
- **Détails** :
  - Nouvelle note
  - Modifier la note
  - Supprimer la note

### 11. Partager
- **Fonction** : Partager des dossiers
- **Détails** :
  - Partager l'agenda
  - Partager les contacts
  - Partager les courriels
