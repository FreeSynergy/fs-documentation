# Outlook - Fonctionnalités

## Vue d'ensemble

Outlook est le client de messagerie le plus populaire de Microsoft, intégré à Microsoft 365. Il combine courrier électronique, agenda, tâches et contacts dans une seule application.

## Fonctionnalités principales

### 1. Gestion des courriels
- **Réception** : POP3, IMAP, Exchange, Office 365
- **Envoi** : Support SMTP
- **Chiffrement** : S/MIME pour les courriels sécurisés
- **Signatures** : Signatures automatiques
- **Règles** : Filtre automatique des courriels
- **Recherche** : Recherche puissante dans tous les dossiers
- **Clutter** : Filtre intelligent des courriels indésirables

### 2. Agenda
- **Rendez-vous** : Rendez-vous simples et multijours
- **Réunions** : Rendez-vous avec participants
- **Ressources** : Réservation de salles
- **Répétitions** : Répétitions quotidiennes, hebdomadaires, mensuelles
- **Partage** : Partager l'agenda avec d'autres
- **Abonnements** : Support CalDAV et iCalendar
- **Statut** : Afficher la disponibilité (Occupé, Libre, etc.)

### 3. Contacts
- **Répertoire** : Répertoires personnels et partagés
- **Groupes de contacts** : Listes de diffusion
- **Import/Export** : CSV, vCard
- **Liens** : Liens entre contacts et courriels
- **Photos** : Photos de contacts

### 4. Tâches
- **Listes de tâches** : Listes de tâches personnelles et partagées
- **Rappels** : Rappels par date et heure
- **Priorités** : Haute, Moyenne, Basse
- **Statut** : Non commencé, En cours, Terminé
- **Répétitions** : Tâches récurrentes
- **Partage** : Partager les tâches avec d'autres

### 5. Notes
- **Notes simples** : Notes textuelles
- **Partage** : Partager les notes avec d'autres
- **Synchronisation** : Avec OneNote

### 6. Intégrations
- **Microsoft 365** : Word, Excel, PowerPoint
- **Teams** : Chat et réunions
- **OneDrive** : Pièces jointes
- **SharePoint** : Partage de documents
- **Power Automate** : Automatisation

## Ce qu'Outlook ne peut pas faire

- Aucun support natif pour IRC
- Aucun support natif pour Signal/WhatsApp
- Aucune intégration native Mastodon/médias sociaux
- Aucun chiffrement de bout en bout natif (seulement S/MIME)
- Aucun support natif multi-compte sur toutes les fonctionnalités (limité)

| `Ctrl+Shift+A` | Créer un rendez-vous |
| `Ctrl+Shift+K` | Créer des contacts |
| `Ctrl+Shift+L` | Créer une liste de diffusion |
| `Ctrl+Shift+T` | Nouvelle note |
| `Ctrl+R` | Répondre |
| `Ctrl+Shift+R` | Transférer |
| `Ctrl+Shift+D` | Recherche rapide |
| `Ctrl+1` | Vue courriel |
| `Ctrl+2` | Vue agenda |
| `Ctrl+3` | Vue contacts |
| `Ctrl+4` | Vue tâches |
