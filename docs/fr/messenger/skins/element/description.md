# Element - Description

## Vue d'ensemble

Element est un messager open source pour la communauté du protocole Matrix. C'est une implémentation client complète du protocole Matrix, conçue pour une communication sécurisée et décentralisée. Element est l'implémentation de référence officielle du protocole Matrix.

## Ce que fait Element

Element est un client de chat et de communication complet basé sur le protocole Matrix. Il permet une communication sécurisée et chiffrée dans les groupes et les conversations individuelles, tant sur les serveurs publics que privés. Element prend en charge le texte, les fichiers, les appels voix et vidéo.

## Avantages

- **Open Source**: Gratuit et open source sous licence Apache-2.0
- **Protocole Matrix**: Protocole ouvert et décentralisé
- **Chiffrement de bout en bout**: Chiffrement E2E pour une communication sécurisée
- **Décentralisation**: Fonctionne avec n'importe quels serveurs Matrix
- **Multiplateforme**: Fonctionne sur Web, Windows, macOS, Linux, iOS, Android
- **Fédération**: Les serveurs peuvent communiquer entre eux
- **Intégrations**:Nombreuses intégrations avec des services externes
- **Projet de recherche**: Développement ultérieur par la fondation Matrix.org
- **Certifié**: Chiffrement E2E certifié par un expert en sécurité externe

## Distinction par rapport aux autres systèmes

### Element vs. Discord
- **Element** est décentralisé et open source, **Discord** est centralisé et propriétaire
- **Element** a le chiffrement de bout en bout par défaut, **Discord** seulement dans les messages privés
- **Discord** a la voix/vidéo native, **Element** l'a via le protocole VoIP
- **Element** est pour les utilisateurs privés et les communautés, **Discord** pour les serveurs communautaires

### Element vs. Telegram
- **Element** est open source et décentralisé, **Telegram** est propriétaire et centralisé
- **Element** a le chiffrement de bout en bout par défaut, **Telegram** seulement dans les chats secrets
- **Element** utilise le protocole Matrix, **Telegram** utilise le protocole propriétaire
- **Telegram** a plus de fonctionnalités (bots, canaux), **Element** a plus de confidentialité

### Element vs. Mastodon
- **Element** est pour le chat et les groupes, **Mastodon** est pour le microblogging
- **Element** a le chiffrement de bout en bout, **Mastodon** n'a pas de chiffrement de bout en bout
- **Element** est décentralisé sur les serveurs, **Mastodon** est décentralisé sur les instances

## Détails techniques

- **Plateforme**: Web, Windows, macOS, Linux, iOS, Android
- **Protocole**: Matrix
- **Backend**: Protocole Matrix personnalisé
- **Chiffrement**: Olm/Ratchet pour le chiffrement E2E
- **Authentification**: OAuth2, OpenID Connect
- **Fédération**: Protocole de fédération Matrix
- **Langage de programmation**: TypeScript, React (Web), Kotlin (Android), Swift (iOS)
- **Hébergement**: Serveur Matrix propre ou serveurs publics

## À qui convient Element ?

- **Utilisateurs privés**: Pour ceux qui valorisent la confidentialité
- **Communautés**: Pour ceux qui veulent gérer leurs propres groupes de chat
- **Entreprises**: Pour ceux qui veulent une communication auto-hébergée
- **Utilisateurs open source**: Pour ceux qui préfèrent les logiciels open source
- **Utilisateurs Matrix**: Pour ceux qui veulent utiliser le protocole Matrix
