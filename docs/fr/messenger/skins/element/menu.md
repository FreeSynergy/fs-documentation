# Element - Éléments de menu

## Vue d'ensemble

Element est un messager open source pour la communauté du protocole Matrix. C'est une implémentation client complète du protocole Matrix, conçue pour une communication sécurisée et décentralisée.

## Éléments de menu principaux

### 1. Paramètres
- **Fonction**: Gérer paramètres
- **Détails**:
  - Ouvrir paramètres
  - Paramètres généraux
  - Paramètres médias
  - Paramètres de sécurité
  - Paramètres de thème
  - Paramètres de langue

### 2. Salle
- **Fonction**: Actions liées à la salle
- **Détails**:
  - Rejoindre/quitter salle
  - Paramètres salle
  - Notifications salle
  - Abonnements salle
  - Effacer l'historique de la salle

### 3. Membres
- **Fonction**: Gestion des membres de la salle
- **Détails**:
  - Afficher membres
  - Inviter membres
  - Expulser membres
  - Bannir membres
  - Changer droits membres

### 4. Recherche
- **Fonction**: Rechercher des messages et des salles
- **Détails**:
  - Recherche globale
  - Recherche salle
  - Recherche message
  - Appliquer filtres

### 5. Fichier
- **Fonction**: Opérations fichier
- **Détails**:
  - Envoyer fichiers
  - Télécharger fichiers
  - Ouvrir fichiers
  - Sauvegarder fichiers

### 6. Fonctions d'aide
- **Fonction**: Fonctions d'aide
- **Détails**:
  - Documentation d'aide
  - À propos d'Element
  - À propos de Matrix
  - Dépannage
