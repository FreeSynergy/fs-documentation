# Element - Fonctionnalités

## Vue d'ensemble

Element est un messager open source pour la communauté du protocole Matrix. C'est une implémentation client complète du protocole Matrix, conçue pour une communication sécurisée et décentralisée.

## Fonctionnalités principales

### 1. Communication chat
- **Conversations individuelles**: Messages directs à des utilisateurs individuels
- **Salles de groupe**: Salles de chat avec plusieurs participants
- **Chiffrement E2E**: Chiffrement de bout en bout pour une communication sécurisée
- **Statut**: En ligne/Absent/Inactif
- **Accusés de lecture**: Afficher les accusés de lecture
- **Synchronisation**: Synchronisation sur tous les appareils

### 2. Appels audio et vidéo
- **Appels individuels**: Appels audio et vidéo avec un participant
- **Appels de groupe**: Appels audio et vidéo avec plusieurs participants
- **Partage d'écran**: Partage d'écran pendant les appels
- **Historique d'appel**: Afficher l'historique d'appel
- **Muet**: Contrôler le microphone et la caméra

### 3. Transfert de fichiers
- **Pièces jointes**: Envoi de fichiers de toute taille
- **Drag & Drop**: Drag & drop pour le transfert de fichiers
- **Aperçu fichier**: Aperçu des images, vidéos, documents
- **Hébergement de fichiers**: Hébergement de fichiers propre optionnel

### 4. Fonctionnalités de salle
- **Description salle**: Description et sujet pour les salles
- **Image salle**: Image de salle personnalisée
- **Abonnements salle**: S'abonner/épingler des salles
- **Notifications salle**: Notifications pour les salles
- **Invitations salle**: Envoyer des invitations aux utilisateurs
- **Permissions salle**: Configurer les permissions pour les salles

### 5. Intégrations
- **Giphy**: Intégrer des GIFs dans les messages
- **Webhooks**: Webhooks pour les intégrations externes
- **Bots**: Support de bots pour l'automatisation
- **Fonctions aléatoires**: Fonctions aléatoires pour le divertissement
- **Gestionnaire d'intégrations**: Gestionnaire pour les intégrations externes

### 6. Sécurité
- **Chiffrement E2E**: Activé par défaut
- **Gestion des appareils**: Gérer tous les appareils
- **Conseils de sécurité**: Afficher les conseils de sécurité
- **Authentification**: Authentification à deux facteurs
- **Protection par mot de passe**: Protection par mot de passe pour les comptes

### 7. Navigation
- **Historique salle**: Rechercher dans l'historique des salles
- **Recherche**: Rechercher dans les salles et globalement
- **Sélection rapide**: Sélection rapide des salles
- **Marquage**: Marquer les messages
- **Réponses**: Répondre aux messages

## Ce que Element ne peut pas faire

- Aucune prise en charge native pour email (doit être combiné avec le client email)
- Aucune prise en charge native pour IRC
- Aucune prise en charge native pour Signal/WhatsApp
- Aucune intégration native Mastodon (seulement via webhooks)
- Aucune intégration native Office (comme Word/Excel)

## Extensions et fonctions bot

### Bots populaires
- **Giffy**: Intégrer des GIFs dans les messages
- **Sondages**: Créer des sondages dans les salles
- **Bots musicaux**: Jouer de la musique dans les salles
- **Bots de modération**: Modération de salle
- **Bots d'intégration**: Intégration avec des services externes

### Extensions populaires
- **Thème**: Thèmes personnalisés
- **Emoji**: Support étendu des emojis
- **Markdown**: Support Markdown pour le formatage
- **Bloc de code**: Support de bloc de code

## Raccourcis

| Raccourci | Fonction |
|----------|----------|
| `Entrée` | Envoyer message |
| `Maj+Entrée` | Nouvelle ligne |
| `Ctrl+K` | Rechercher salle |
| `Ctrl+Maj+F` | Recherche globale |
| `Ctrl+P` | Préférences salle |
| `Ctrl+E` | Paramètres |
| `Ctrl+M` | Appel audio |
| `Ctrl+V` | Appel vidéo |
