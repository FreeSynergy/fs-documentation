# Mastodon - Fonctionnalités

## Vue d'ensemble

Mastodon est un réseau de microblogging open source basé sur le protocole ActivityPub. Il est décentralisé et se compose de nombreux serveurs indépendants (instances) qui peuvent communiquer entre eux.

## Fonctionnalités principales

### 1. Communication toot
- **Publier toots**: Publier des messages courts (toots)
- **Modifier toots**: Modifier toots (dans une fenêtre de temps)
- **Supprimer toots**: Supprimer toots
- **Citer toots**: Citer et commenter toots
- **Marquer toots**: Marquer toots (marque-pages)
- **Partager toots**: Partager toots (boost)

### 2. Gestion de la ligne de temps
- **Ligne de temps maison**: Ligne de temps avec messages des utilisateurs suivis
- **Ligne de temps locale**: Ligne de temps avec messages de votre propre instance
- **Ligne de temps fédérée**: Ligne de temps avec messages de l'ensemble du réseau
- **Ligne de temps hashtag**: Ligne de temps pour des hashtags spécifiques
- **Filtres de ligne de temps**: Filtres de ligne de temps par hashtags, sensibilité, etc.

### 3. Gestion des utilisateurs
- **Suivre utilisateurs**: Suivre utilisateurs
- **Ne plus suivre utilisateurs**: Ne plus suivre utilisateurs
- **Bloquer utilisateurs**: Bloquer utilisateurs
- **Ignorer utilisateurs**: Ignorer utilisateurs
- **Ouvrir profil utilisateur**: Ouvrir profil utilisateur
- **Liste de contacts**: Gérer contacts

### 4. Messages directs
- **Envoyer messages directs**: Envoyer messages directs à des utilisateurs individuels
- **Recevoir messages directs**: Recevoir messages directs
- **Modifier/supprimer messages directs**: Modifier/supprimer messages directs
- **Marquer messages directs**: Marquer messages directs
- **Pas de chiffrement de bout en bout**: Les messages directs ne sont pas chiffrés de bout en bout

### 5. Gestion des médias
- **Télécharger images**: Télécharger images dans toots
- **Télécharger vidéos**: Télécharger vidéos dans toots
- **Modifier médias**: Modifier médias (description, sensibilité)
- **Aperçu médias**: Aperçu médias dans toots
- **Texte alternatif**: Texte alternatif pour images

### 6. Sensibilité et filtres
- **Marquer comme sensible**: Marquer toots comme sensibles (NSFW)
- **Cacher médias**: Cacher médias dans toots
- **Filtrer mots**: Filtrer mots
- **Filtrer utilisateurs**: Filtrer utilisateurs
- **Filtrer hashtags**: Filtrer hashtags

### 7. Gestion de profil
- **Profil personnel**: Gérer votre propre profil
- **Bio**: Modifier bio
- **Image profil**: Changer image profil
- **Image d'en-tête**: Changer image d'en-tête
- **Paramètres de confidentialité**: Configurer paramètres de confidentialité

### 8. Modération
- **Signaler utilisateurs**: Signaler utilisateurs
- **Signaler toots**: Signaler toots
- **Modérateurs instance**: Gérer modérateurs instance
- **Journal d'audit**: Journal d'audit pour actions de modération

## Ce que Mastodon ne peut pas faire

- Aucune prise en charge native pour email (doit être combiné avec le client email)
- Aucune prise en charge native pour IRC
- Aucune prise en charge native pour Signal/WhatsApp
- Aucune intégration native Discord (pas de chat)
- Aucun chiffrement de bout en bout natif (seulement TLS)
- Aucune communication voix/vidéo native

## Instances Mastodon

### Instances populaires
- **mastodon.social**: Instance la plus grande, générale
- **tech.io**: Pour les communautés technologiques
- **queer.party**: Pour les communautés LGBTQ+
- **freie.social**: Pour les communautés de logiciels libres
- **Instance spécifique**: Chaque instance a ses propres règles et sujets

## Raccourcis

| Raccourci | Fonction |
|----------|----------|
| `Entrée` | Envoyer toot |
| `Maj+Entrée` | Nouvelle ligne |
| `Ctrl+K` | Rechercher toot |
| `Ctrl+Maj+F` | Rechercher profil |
| `Ctrl+E` | Paramètres |
| `Ctrl+Maj+M` | Nouveau message direct |
