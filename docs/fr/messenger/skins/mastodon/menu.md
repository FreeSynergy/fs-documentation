# Mastodon - Éléments de menu

## Vue d'ensemble

Mastodon est un réseau de microblogging open source basé sur le protocole ActivityPub. Il est décentralisé et se compose de nombreux serveurs indépendants (instances) qui peuvent communiquer entre eux.

## Éléments de menu principaux

### 1. Menu (Gauche)
- **Fonction**: Navigation et fonctions principales
- **Détails**:
  - Ouvrir ligne de temps maison
  - Ouvrir ligne de temps locale
  - Ouvrir ligne de temps fédérée
  - Ouvrir messages directs
  - Ouvrir notifications

### 2. Menu toot (Centre)
- **Fonction**: Communication toot
- **Détails**:
  - Nouveau toot
  - Modifier/supprimer toot
  - Citer toot
  - Marquer toot
  - Partager toot (boost)
  Télécharger médias

### 3. Menu ligne de temps (Centre)
- **Fonction**: Gestion de la ligne de temps
- **Détails**:
  - Ligne de temps maison
  - Ligne de temps locale
  - Ligne de temps fédérée
  - Ligne de temps hashtag
  - Appliquer filtres ligne de temps

### 4. Menu utilisateur (Droite)
- **Fonction**: Gestion des utilisateurs
- **Détails**:
  - Ouvrir profil utilisateur
  - Suivre/ne plus suivre utilisateur
  - Bloquer/ignorer utilisateur
  - Signaler utilisateur

### 5. Menu notifications (Droite)
- **Fonction**: Gestion des notifications
- **Détails**:
  - Notifications suivis
  - Notifications toots
  - Notifications mentions
  - Notifications messages directs

### 6. Paramètres
- **Fonction**: Gérer paramètres
- **Détails**:
  - Paramètres généraux
  - Paramètres médias
  - Paramètres de sécurité
  - Paramètres de thème
  - Paramètres de langue

### 7. Fonctions d'aide
- **Fonction**: Fonctions d'aide
- **Détails**:
  - Documentation d'aide
  - À propos de Mastodon
  - Dépannage
