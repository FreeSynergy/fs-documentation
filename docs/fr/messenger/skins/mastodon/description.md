# Mastodon - Description

## Vue d'ensemble

Mastodon est un réseau de microblogging open source basé sur le protocole ActivityPub. Il est décentralisé et se compose de nombreux serveurs indépendants (instances) qui peuvent communiquer entre eux.

## Ce que fait Mastodon

Mastodon est un service de microblogging qui fonctionne comme une alternative à Twitter/X. Il permet de publier des messages courts (toots), de suivre des utilisateurs, de partager du contenu et de participer à des discussions dans les hashtags. Mastodon n'est pas un seul service mais organisé comme un réseau décentralisé.

## Avantages

- **Open Source**: Gratuit et open source sous licence AGPL
- **Décentralisation**: De nombreux serveurs indépendants qui communiquent entre eux
- **Confidentialité**: Pas de contrôle central, pas de publicité
- **ActivityPub**: Protocole ouvert pour le web social
- **Orienté communauté**: Orienté communauté, pas d'algorithmes pour la ligne de temps
- **Résistant à la censure**: Résistant à la censure grâce à la décentralisation
- **Interopérabilité**: Communication avec d'autres réseaux ActivityPub
- **Transparence**: Développement ouvert, revue de code publique
- **Personnalisabilité**: Chaque instance peut avoir ses propres règles et fonctionnalités

## Distinction par rapport aux autres systèmes

### Mastodon vs. Twitter/X
- **Mastodon** est décentralisé et open source, **Twitter/X** est centralisé et propriétaire
- **Mastodon** n'a pas de publicité, **Twitter/X** a de la publicité
- **Mastodon** n'a pas d'algorithmes pour la ligne de temps, **Twitter/X** a des algorithmes
- **Mastodon** est orienté communauté, **Twitter/X** est orienté entreprise

### Mastodon vs. Discord
- **Mastodon** est pour le microblogging, **Discord** est pour le chat et les groupes
- **Mastodon** n'a pas de voix/vidéo, **Discord** a la voix/vidéo native
- **Discord** est pour les serveurs communautaires, **Mastodon** est pour le microblogging

### Mastodon vs. Element
- **Mastodon** est pour le microblogging, **Element** est pour le chat et les groupes
- **Mastodon** n'a pas de chiffrement de bout en bout, **Element** a le chiffrement de bout en bout
- **Element** est pour les messages directs, **Mastodon** est pour les toots publics

## Détails techniques

- **Plateforme**: Web, iOS, Android (tierce partie)
- **Protocole**: ActivityPub, OStatus
- **Backend**: Ruby on Rails
- **Chiffrement**: TLS pour la transmission des données, pas de chiffrement de bout en bout
- **Authentification**: OAuth2, Email/Mot de passe
- **Hébergement**: Serveur Mastodon propre ou instances publiques
- **Langage de programmation**: Ruby on Rails (backend), TypeScript (frontend)

## À qui convient Mastodon ?

- **Confidentiel**: Pour ceux qui valorisent la confidentialité
- **Utilisateurs communautaires**: Pour ceux qui veulent des réseaux orientés communauté
- **Utilisateurs open source**: Pour ceux qui préfèrent les logiciels open source
- **Utilisateurs alternatifs**: Pour ceux qui cherchent une alternative à Twitter/X
- **Utilisateurs de décentralisation**: Pour ceux qui veulent des réseaux décentralisés
