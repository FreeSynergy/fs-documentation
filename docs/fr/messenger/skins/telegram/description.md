# Telegram - Description

## Vue d'ensemble

Telegram est un messager basé sur le cloud avec un focus sur la rapidité et la sécurité. Il est disponible sur de nombreuses plateformes et propose des chats chiffrés, de grands groupes et des canaux pour la diffusion.

## Ce que fait Telegram

Telegram est un service de messagerie basé sur le cloud spécialement conçu pour une communication rapide et sécurisée. Il permet des chats individuels et de groupe, de grands canaux pour la diffusion, des "Chats Secrets" chiffrés et le transfert de gros fichiers.

## Avantages

- **Rapidité**: Transmission de messages très rapide
- **Basé sur le cloud**: Les messages sont stockés dans le cloud
- **Chiffrement**: "Chats Secrets" chiffrés avec chiffrement de bout en bout
- **Grands groupes**: Groupes jusqu'à 200 000 membres
- **Grands canaux**: Canaux avec abonnés illimités
- **Taille de fichier**: Envoyer des fichiers jusqu'à 2 Go
- **Multiplateforme**: Fonctionne sur Windows, macOS, Linux, iOS, Android, Web
- **Bots**: Système de bots étendu pour l'automatisation
- **API ouverte**: API ouverte pour les développeurs
- **Gratuit**: Gratuit pour toutes les fonctionnalités

## Distinction par rapport aux autres systèmes

### Telegram vs. Discord
- **Telegram** est pour le messaging et la diffusion, **Discord** est pour le chat et les serveurs communautaires
- **Discord** a la voix/vidéo native, **Telegram** a la voix/vidéo via VoIP
- **Telegram** a de grands groupes/canaux, **Discord** a des serveurs avec limites
- **Discord** a plus de fonctionnalités de jeu, **Telegram** a plus de fonctionnalités de diffusion

### Telegram vs. Element
- **Telegram** est propriétaire, **Element** est open source
- **Telegram** a des chats basés sur le cloud, **Element** a des chats décentralisés
- **Element** a le chiffrement de bout en bout par défaut, **Telegram** seulement dans les "Chats Secrets"
- **Element** est pour la communication décentralisée, **Telegram** est pour la communication centralisée

### Telegram vs. Mastodon
- **Telegram** est pour le messaging et les groupes, **Mastodon** est pour le microblogging
- **Telegram** n'a pas de chiffrement de bout en bout (sauf Chats Secrets), **Mastodon** n'a pas de chiffrement de bout en bout
- **Mastodon** est décentralisé, **Telegram** est centralisé

## Détails techniques

- **Plateforme**: Windows, macOS, Linux, iOS, Android, Web
- **Protocole**: MTProto (protocole propriétaire)
- **Backend**: Backend Telegram basé sur le cloud
- **Chiffrement**: MTProto pour les chats cloud, AES-256 + RSA pour les Chats Secrets
- **Authentification**: OAuth2, Numéro de téléphone
- **Bots**: Bots Telegram via Bot API
- **Langage de programmation**: C++ (noyau), JavaScript (web), Kotlin (Android), Swift (iOS)

## À qui convient Telegram ?

- **Chercheurs de rapidité**: Pour ceux qui veulent une communication rapide
- **Grandes communautés**: Pour ceux qui veulent gérer de grands groupes/canaux
- **Transfert de fichiers**: Pour ceux qui veulent transférer de gros fichiers
- **Utilisateurs de bots**: Pour ceux qui veulent des intégrations de bots
- **Utilisateurs multiplateforme**: Pour ceux qui communiquent sur plusieurs plateformes
