# Telegram - Éléments de menu

## Vue d'ensemble

Telegram est un messager basé sur le cloud avec un focus sur la rapidité et la sécurité. Il est disponible sur de nombreuses plateformes et propose des chats chiffrés, de grands groupes et des canaux pour la diffusion.

## Éléments de menu principaux

### 1. Menu chat (Gauche)
- **Fonction**: Gestion chat
- **Détails**:
  - Démarrer nouveau chat
  - Créer groupes
  - Créer canal
  - Démarrer chats secrets
  - Champ de recherche chat

### 2. Liste chat (Gauche)
- **Fonction**: Vue d'ensemble chat
- **Détails**:
  - Afficher chats actifs
  - Afficher groupes
  - Afficher canaux
  - Afficher chats secrets
  - Tri chat

### 3. Menu messages (Centre)
- **Fonction**: Gestion messages
- **Détails**:
  - Envoyer messages
  - Modifier/supprimer messages
  - Marquer messages
  - Citer messages
  - Transférer messages
  - Envoyer médias

### 4. Menu médias (Centre)
- **Fonction**: Gestion médias
- **Détails**:
  - Télécharger photos
  - Télécharger vidéos
  - Télécharger documents
  - Aperçu médias
  - Télécharger médias

### 5. Menu membres (Droite)
- **Fonction**: Gestion membres
- **Détails**:
  - Afficher liste des membres
  - Inviter membres
  - Expulser membres
  - Modifier membres
  - Gérer rôles

### 6. Paramètres
- **Fonction**: Gérer paramètres
- **Détails**:
  - Paramètres généraux
  - Paramètres médias
  - Paramètres de sécurité
  - Paramètres de thème
  - Paramètres de langue

### 7. Fonctions d'aide
- **Fonction**: Fonctions d'aide
- **Détails**:
  - Documentation d'aide
  - À propos de Telegram
  - Dépannage
