# Telegram - Fonctionnalités

## Vue d'ensemble

Telegram est un messager basé sur le cloud avec un focus sur la rapidité et la sécurité. Il est disponible sur de nombreuses plateformes et propose des chats chiffrés, de grands groupes et des canaux pour la diffusion.

## Fonctionnalités principales

### 1. Communication chat
- **Conversations individuelles**: Messages directs à des utilisateurs individuels
- **Groupes**: Groupes jusqu'à 200 000 membres
- **Canaux**: Canaux avec abonnés illimités pour la diffusion
- **Chats Secrets**: Chats chiffrés avec chiffrement de bout en bout
- **Auto-destruction**: Messages avec minuteur d'auto-destruction
- **Statut**: En ligne/Absent/Vu dernièrement
- **Accusés de lecture**: Afficher les accusés de lecture

### 2. Appels voix et vidéo
- **Appels individuels**: Appels audio et vidéo avec un participant
- **Appels de groupe**: Appels de groupe avec plusieurs participants
- **Partage d'écran**: Partage d'écran pendant les appels
- **Outils d'appel**: Muet, contrôle du volume
- **Historique d'appel**: Afficher l'historique d'appel

### 3. Transfert de fichiers
- **Pièces jointes**: Envoi de fichiers jusqu'à 2 Go
- **Drag & Drop**: Drag & drop pour le transfert de fichiers
- **Aperçu fichier**: Aperçu des images, vidéos, documents
- **Téléchargement médias**: Télécharger photos, vidéos, documents
- **Stockage cloud**: Les fichiers sont stockés dans le cloud

### 4. Gestion de groupe
- **Créer groupes**: Groupes jusqu'à 200 000 membres
- **Paramètres groupe**: Configurer paramètres groupe
- **Rôles groupe**: Gérer rôles pour les membres
- **Permissions groupe**: Configurer permissions pour les rôles
- **Historique groupe**: Rechercher dans l'historique des groupes

### 5. Gestion de canal
- **Créer canaux**: Canaux avec abonnés illimités
- **Paramètres canal**: Configurer paramètres canal
- **Notifications canal**: Notifications pour les canaux
- **Historique canal**: Rechercher dans l'historique des canaux
- **Opérateurs canal**: Outils opérateur pour les canaux

### 6. Bots et intégrations
- **Bots**: Système de bots étendu pour l'automatisation
- **Webhooks**: Webhooks pour les intégrations externes
- **OAuth2**: Intégration OAuth2 pour les services externes
- **Fonctions aléatoires**: Fonctions aléatoires pour le divertissement
- **Gestionnaire d'intégrations**: Gestionnaire pour les intégrations externes

### 7. Sécurité
- **Chiffrement E2E**: Dans les "Chats Secrets" avec auto-destruction
- **Protection par mot de passe**: Protection par mot de passe pour les comptes
- **Authentification à deux facteurs**: Authentification à deux facteurs
- **Gestion des appareils**: Gérer tous les appareils
- **Conseils de sécurité**: Afficher les conseils de sécurité

### 8. Profil
- **Profil personnel**: Gérer votre propre profil
- **Notifications**: Gérer les notifications
- **Paramètres de confidentialité**: Configurer paramètres de confidentialité
- **Photo de profil**: Changer photo de profil

## Ce que Telegram ne peut pas faire

- Aucune prise en charge native pour email (doit être combiné avec le client email)
- Aucune prise en charge native pour IRC
- Aucune prise en charge native pour Signal/WhatsApp
- Aucune intégration native Mastodon (seulement via webhooks)
- Aucune prise en charge native pour open source (propriétaire)

## Telegram Premium (Premium)

### Fonctionnalités de Telegram Premium
- **Deux fois plus**: Membres de groupe (200 000 au lieu de 200 000)
- **Fichiers plus gros**: Envoyer des fichiers jusqu'à 4 Go
- **Vitesse de téléchargement plus élevée**: Vitesse de téléchargement plus élevée
- **Deux comptes**: Deux comptes sur un appareil
- **Bots avancés**: Fonctionnalités de bots avancées
- **Canaux**: Abonnés canal illimités

| `Ctrl+M` | Appel audio |
| `Ctrl+V` | Appel vidéo |
