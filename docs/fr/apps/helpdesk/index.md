# Service d'aide et systèmes de support

## Vue d'ensemble

Cette section contient la documentation pour divers systèmes d'aide et de tickets.

## Systèmes disponibles

- **osTicket** - Système d'aide open source
- **rt** - Request Tracker pour la gestion de tickets
- **zammad** - Service d'aide open source
- **freshdesk** - Logiciel de support client
- **zendesk** - Plateforme de service client
- **helpscout** - Outil de support client
- **civicrm** - Gestion des relations avec les composants
- **GLPI** - Gestion des actifs IT
- **sysaid** - Gestion des services IT
- **servertime** - Logiciel d'aide
- **kayako** - Plateforme de support client

## Qu'est-ce qu'un Service d'aide?

Un service d'aide est un système pour gérer les demandes des clients et les tickets de support. Les systèmes d'aide incluent :

- Création et gestion de tickets
- Catégorisation et priorisation des tickets
- Gestion des SLA et temps de réponse
- Base de connaissances pour les questions fréquentes
- Portail client pour l'auto-service
- Rapports et analyses

## Domaines d'application

- **Support client** : Gérer le service client
- **Service d'aide IT** : Support IT interne
- **Support technique** : Support technique pour les produits
- **Support commercial** : Support pour l'équipe commerciale
- **Support interne** : Support pour les employés

## Avantages des systèmes d'aide

- **Vue d'ensemble** : Toutes les demandes en un seul endroit
- **Priorisation** : Prioriser les demandes importantes
- **Gestion des SLA** : Maintenir les temps de réponse
- **Base de connaissances** : Documenter les questions fréquentes
- **Rapports** : Contrôle de réussite et analyse
- **Intégration** : Connexion avec d'autres outils

## Critères de sélection

Lors du choix d'un système d'aide, considérez les critères suivants :

- **Fonctionnalités** : Quelles fonctionnalités sont requises ?
- **Évolutivité** : Combien de tickets par jour ?
- **Facilité d'utilisation** : Quelle est la facilité d'utilisation ?
- **Intégration** : Dans quelle mesure le système s'intègre-t-il à l'infrastructure existante?
- **Coûts** : Gratuit ou payant?
- **Auto-hébergement ou Cloud** : Options d'hébergement
