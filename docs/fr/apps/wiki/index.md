# Systèmes wiki

## Vue d'ensemble

Cette section contient la documentation pour divers systèmes wiki et plateformes de connaissances.

## Systèmes disponibles

- **wikijs** - Wiki moderne et léger avec prise en charge de Markdown
- **xwiki** - Wiki d'entreprise avec extensions et macros
- **mediawiki** - Moteur wiki de Wikipedia
- **tango.io** - Base de connaissances moderne pour équipes
- **notion** - Espace de travail tout-en-un avec fonctionnalités wiki
- **confluence** - Collaboration d'équipe Atlassian
- **vscodium** - VS Code sans télémétrie (pour l'hébergement local de wiki)
- **dokuwiki** - Wiki simple basé sur des fichiers
- **mediagoblin** - Plateforme d'hébergement de médias fédérée

## Qu'est-ce qu'un Wiki?

Un wiki est un système web collaboratif pour créer, modifier et organiser des bases de connaissances, de la documentation ou des textes communautaires. Les systèmes wiki se caractérisent par :

- Édition facile via interface web
- Suivi des révisions et gestion de version
- Catégorisation et liens de contenu
- Rôles d'utilisateur et systèmes d'autorisation
- Fonctions de recherche et d'indexation

## Domaines d'application

- **Documentation technique** : Documentation de projet, documentation API
- **Gestion des connaissances** : Wikis d'entreprise, bases de connaissances
- **Éducation** : Matériel d'enseignement, documentation de cours
- **Projets communautaires** : Documentation open-source, wikis communautaires

## Critères de sélection

Lors du choix d'un système wiki, considérez les critères suivants :

- **Fonctionnalités** : Quelles fonctionnalités sont requises ?
- **Évolutivité** : Combien d'utilisateurs et de pages ?
- **Intégration** : Dans quelle mesure le système s'intègre-t-il à l'infrastructure existante ?
- **Facilité d'utilisation** : Quelle est la facilité d'utilisation ?
- **Coûts** : Auto-hébergement ou service cloud ?
- **Open Source** : Les conditions de licence sont-elles adaptées ?
