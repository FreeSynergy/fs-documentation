# Wiki Skin Documentation

## Overview

This directory contains documentation for menu items and editors of various wiki software systems and developer tools.

## Included Documentation

- [Wiki.js](/de/apps/wiki/skins/wikijs/index.md) - Modern, lightweight wiki software
- [XWiki](/de/apps/wiki/skins/xwiki/index.md) - Enterprise wiki platform
- [MediaWiki](/de/apps/wiki/skins/mediawiki/index.md) - The most popular wiki software (Wikipedia)
- [Tango.io](/de/apps/wiki/skins/tango.io/index.md) - Knowledge management platform
- [Notion](/de/apps/wiki/skins/notion/index.md) - All-in-one collaboration platform
- [Confluence](/de/apps/wiki/skins/confluence/index.md) - Enterprise wiki by Atlassian
- [VSCodium](/de/apps/wiki/skins/vscodium/index.md) - Open-source code editor (VS Code fork)

## Content of Each Documentation

Each project directory contains four files:

### menu.md
- All main menu items
- Context menus
- User rights-dependent menus

### features.md
- Editor features
- What the editor can do
- What the editor CANNOT do
- Extensions and plugins
- Shortcuts

### description.md
- What the program does
- Advantages
- Differentiation from other systems
- Technical details
- Who the program is suitable for

### structure.md
- Window structure
- UI/UX design
- Editor structure
- Responsive design
- Accessibility

## Notes

- All documentation is written in English
- Content is suitable for users and administrators
- Editor descriptions include syntax highlighting, snippets, Git integration, and extensions
- VSCodium is an open-source VS Code fork with identical features but without Microsoft telemetry
