# Documents – description

**What this domain is:** all longer texts — wiki pages, help texts, guides, notes, books — and how
they are grouped (books, libraries) and explained (own explanations beside the original).

**What it covers:**

- Text files edited in the **code editor** workbench (Markdown, source code, configuration)
- Structured documents edited in the **block editor** workbench (ADR 0023)
- Books and chapters (like BookStack), libraries and shelves
- The **shared library** every program uses: each tool has a help point that opens the matching
  entry in a window/workbench, without opening the wiki app (ADR 0031)
- **Own explanations and screenshots** beside existing text; the original is muted, not deleted

**Differentiation:**

| Topic | Where | Why |
|-------|-------|-----|
| chat, mail, comments on a resource | [messages/](../messages/index.md) | transient utterances, not works |
| tags/comments on a text fragment | here (Web Annotation) | same mechanism as own explanations |
| files in general (binary, media) | `files/` (proposed) | documents are text works |
