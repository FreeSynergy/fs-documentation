# Maps help

Maps keeps your places: a name, a position and a few words about each. Today the window is a list of places with a page for each one. There is no drawn map yet.

## The views

- [Places](places.md): the list of places and the search.
- [Place](place.md): the page of one place.
- [Edit place](edit-place.md): the form to change a place or make a new one.
- [Delete place](delete-place.md): the two steps to remove a place.

## How to start

Start `fs-maps` without arguments. The window opens. If no maps server answers, the window starts one for you in the background. You can also start the server yourself with `fs-maps serve`.
