# Sources

Sources are the Git places the Store reads its list of programs from. You open this page with **Store**, then **Sources**.

## What you see

- At the top, a field with the hint "Git address of a source, for example https://example.org/packages" and a button **Add**.
- One row for each source: its name, its address, and the buttons **Switch off** (or **Switch on**) and **Remove**.
- The built-in FreeSynergy source carries the mark "built in". A source that is switched off carries the mark "off".
- If there are none, you see "There are no sources."
- Below the sources you see the same choices as on [Settings](settings.md). The Sources entry only puts the list of sources first.
- A button **Back to the programs** leads back to the cards.

## What you can do

1. Add a source: type its Git address into the field and press **Add**. If the field is empty, the Store says "Type the Git address of a source first."
2. Switch a source off: press **Switch off** on its row. Press **Switch on** to bring it back.
3. Remove a source: press **Remove** on its row. The built-in source has no **Remove** button. You can switch it off, but not remove it.
4. Go back: press **Back to the programs**.

Only sources that are switched on offer programs. If a source cannot be read, the Store says so at the top of the page and names the source.

## Keyboard

- **Ctrl+Q** quits the Store.

## Not there yet

- There is no way to edit a source's address. Remove it and add it again.
