# Installing and updating

When you install or update a program, a bar appears at the top of the window. It shows what the Store is doing right now.

## What you see

- One sentence about the job. When nothing runs it says "Nothing is being installed."
- A row of steps: **Waiting**, **Checked**, **Installing**, and then **Installed**. The step the job is in stands out.
- The sentences you can see are: "(name): waiting to start.", "(name): signature and checksum are good.", "(name): installing.", and "(name) (version) is installed."
- If something goes wrong the last step reads **Rolled back**, with "(name): the previous state is back." If even that fails, it reads **Failed**.
- On the program's card, the buttons are replaced by the name of the current step.

## What you can do

1. Start a job with **Install** or **Update** on a card in [Programs](programs.md).
2. Watch the steps. Only one job runs at a time. If you start a second one, the Store says the first is still being installed and asks you to wait.
3. If a message appears in red, read it. The Store names the reason, for example that a signature could not be verified, that the download is not the one that was announced, that the source offers an older version than yours, or that the program is running.
4. Try again after you have fixed the cause.

## Keyboard

- **Ctrl+Q** does not quit while a job runs.

## Not there yet

- You cannot cancel a running job.
- There is no list of past jobs. The bar shows the latest one only.
