# About

A small page that says which Store you have. You open it with **Help**, then **About**.

## What you see

- The name and version, for example "FreeSynergy.Store 0.0.N".
- "Licence: MIT OR Apache-2.0".
- "Project: https://github.com/FreeSynergy/fs-store".
- A button **Back to the programs**.

## What you can do

1. Read the version when you report a problem.
2. Press **Back to the programs** to leave.

On the command line, `fs-store version` prints the version too.

## Keyboard

- **Ctrl+Q** quits the Store.
