# Event

## What you see

The event you clicked. It shows its title and marks, then sections with the details: Title, Start, End, All day, Time zone, Location, Description, and Status when set. For a repeating event you also see "Repeats", the rule, and a note. Participants are shown, and things the window does not show are named under "Kept on the event". A task shows its Due time and Progress, and a note that it belongs to the Tasks program.

The bar has **Edit**, **Delete** and, in a narrow window, **Back**.

## What you can do

Edit the event:

1. Press **Edit**. See [Edit event](edit-event.md).

Delete the event:

1. Press **Delete**. The window asks and says it cannot be taken back here. For a repeating event it says all occurrences go.
2. Press **Really delete** to go on, or **Keep** to stop.

Go back:

1. Press **Back** to return to the calendar.

## Keyboard

The window code defines no shortcuts for this view.
