# Edit event

## What you see

A form with **Title**, **Start**, **End**, **All day** (a Yes or No choice), **Time zone**, **Location** and **Description**. A new event starts at 09:00 and ends at 10:00 on the day you were looking at, in the time zone the window uses. At the bottom are **Save** and **Cancel**.

## What you can do

Add an event:

1. Press **New**, or choose **Event**, then **New**.
2. Type a title. An event needs one.
3. Set the start and end. Write them like 2026-11-30 09:00.
4. Press **Save**. The window says "Created."

Change an event:

1. Open it and press **Edit**.
2. Change the fields.
3. Press **Save**. The window says "Saved." Only what you changed is written.

Problems you may meet: "enter a title", "the end is before the start", and a start that does not exist because the clocks jump forward then. Enter a time before or after it.

Stop:

1. Press **Cancel**. If you changed something, the window asks. Press **Discard changes** to throw it away, or **Keep editing** to go on.

If someone else changed the times of the event meanwhile, your times are not written. Put them back as they were to save the rest, or press **Cancel** and start again. Other fields are merged, and **Save** again writes over them.

## Keyboard

The window code defines no shortcuts for this view.
