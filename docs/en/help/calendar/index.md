# Calendar help

FreeSynergy Calendar keeps your events and shows them by month, week, day or as an agenda. An event in a time zone stays at the right wall-clock time when the clocks change. Your tasks appear beside your events, but they belong to the Tasks program. Events follow an open standard (JSCalendar) and can be imported and exported as iCalendar.

## Views

- [Month](month.md)
- [Week](week.md)
- [Day](day.md)
- [Agenda](agenda.md): events and tasks as a list.
- [Event](event.md): one event, to read, edit or delete.
- [Edit event](edit-event.md): the form for a new event or an existing one.

## How to start

1. Open the program with `fs-calendar`. The window opens on the month around today.
2. Press **New** to write your first event.
3. Type a title and press **Save**.

By default the program keeps events in memory only, and they are gone when you close it. To keep them, start it with `--store` and a file name.
