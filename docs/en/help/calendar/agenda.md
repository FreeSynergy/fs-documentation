# Agenda

## What you see

Your events and tasks as a list in time order. The toolbar is the same as in the other views: **Today**, **<**, **>**, **Month**, **Week**, **Day**, **Agenda** and **New**. Tasks stand at the time they are due, marked as a task. If one event is damaged, a line above the calendar names it, and you can click it to read or delete it.

## What you can do

1. Press **>**, **<** or **Today** to move in time.
2. Click an event to read it. See [Event](event.md).
3. Press **New** to add an event. See [Edit event](edit-event.md).
4. Press **Month**, **Week** or **Day** to see the same time in another form.

## Keyboard

The window code defines no shortcuts for this view.
