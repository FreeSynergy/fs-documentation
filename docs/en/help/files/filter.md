# Filter

## What you see

Pressing "Filter" in the toolbar opens the side area "Filter this folder by size and date". It has four fields: "At least (size)", "At most (size)", "Changed on or after (date)" and "Changed before (date)", and the buttons "Clear" and "Apply". While a filter is active the toolbar button reads "Filter is on".

## What you can do

1. Press "Filter".
2. Type a size, for example 500, 20 KB, 3 MB or 1 GB, into "At least (size)" or "At most (size)".
3. Press "Apply". The list shows only matching files.
4. If a value is not understood, the window says "Not a size" or "Not a date. Write it as 2026-11-30."
5. Press "Clear" to remove the filter.
