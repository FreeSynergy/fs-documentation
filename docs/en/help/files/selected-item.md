# Selected item

## What you see

The side area to the right of the list (on a narrow window it takes the place of the list, with a "Back to the list" button). Before you pick anything it says "Nothing is selected." After you pick a file or folder, you see buttons for it. A marked file would be held back until you press "Show preview".

## What you can do

For a folder:

1. Press "Open folder" to go in.
2. Press "Rename". The window asks for the new name at the bottom (see [Questions](questions.md)).
3. Press "Move". The window then says "Moving ...: open the folder it should go to." Open the target folder and press "Move here". Press "Cancel" to stop.
4. Press "Delete folder". Only an empty folder can be deleted, and there is no way back. A question at the bottom asks you to confirm.

For a file:

1. Press "Rename", "Move" or "Copy". Copy works like Move and ends with "Copy here".
2. Press "Delete" to put it in the [trash](trash.md). A question at the bottom asks "Put ... in the trash?". After you press "Delete", the button turns into "Keep it".

While you are typing a name, buttons that would throw it away are not offered.

## Keyboard

None of its own.

## Not there yet

- No preview of file content: the window says previews are not shown yet.
- No "Download" and no "Upload". The window takes no uploads and writes no downloads yet.
- No sharing, no versions, no replacing a file. A name clash lets you refuse or keep both.
