# What the rescan found

## What you see

After you press "Rescan", the side area shows "What the rescan found". It starts with a note: "Changes from outside only come in by Rescan; nothing watches the folder. Rescan and uploads hold the window until they are done." Then come groups of names, each with a count:

- "Taken over": new files and folders now known to Files.
- "Changed": files that changed outside.
- "Missing: the record stays, nothing was deleted".
- "Not taken over".

Long groups are cut and end with "and N more".

## What you can do

1. Press "Rescan" in the toolbar (not available in the trash).
2. Wait. The window is held until it is done and says "Rescan done. See the report."
3. Read the groups. Click any file in the list to leave the report.

## Keyboard

None of its own.

## Not there yet

- Rescan never deletes anything. A vanished file keeps its record.
- There is no automatic watching of the folder.
