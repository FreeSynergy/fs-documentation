# Grid

## What you see

The same files and folders as in the [List](list.md), but as tiles. Each tile shows the name, the type and the size. A sensitive file carries the mark "Sensitive". An empty folder says "This folder is empty."

## What you can do

1. Press "Grid" in the toolbar to switch to tiles. Press "List" to go back.
2. Click a tile to select it. The [side area](selected-item.md) shows it.
3. Click the selected tile again to open it, if it is a folder.
4. Search, order and filter work as in the list.

## Keyboard

Left, Right, Up and Down move between tiles. Page Up and Page Down move by pages of tiles. Home goes to the first tile and End to the last. At the edge a key does nothing and opens no folder.

## Not there yet
