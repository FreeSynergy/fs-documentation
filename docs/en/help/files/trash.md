# Trash

## What you see

The "Trash" button in the toolbar opens the trash. The path shows Files, then Trash. The list shows the deleted files. If there are none it says "The trash is empty." A file in the trash cannot be read: "A file in the trash cannot be read. Restore it first."

In the trash the toolbar offers "Back to files", the order buttons and "Empty trash".

## What you can do

1. Press "Trash" to open it. Press "Back to files" to leave.
2. To bring a file back, click it, then press "Restore". If the name is taken, the window asks what to do (see [Questions](questions.md)).
3. To bring it back somewhere else, press "Restore to", open the folder you want and press "Restore here".
4. To remove one file for good, click it and press "Delete forever". A question at the bottom asks "Delete ... forever? There is no way back." Answer "Yes, delete forever" or "Keep it".
5. To remove everything, press "Empty trash". The window tells you how many files it will delete. Answer "Yes, delete all forever" or "Keep it". If the trash changed meanwhile, nothing is deleted and you are told to look at the number again.
