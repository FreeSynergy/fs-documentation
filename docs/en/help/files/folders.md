# Folders

## What you see

On a wide window you see the folder tree on the left. It starts at "Files", the top. Above the list there is a path (a breadcrumb) that shows where you are, for example Files, then the folder you opened. On a window narrower than the tree needs, the tree is hidden and only the path is shown. On a wide window the path line also tells you: "Changes made outside appear after Rescan."

If the tree cannot be read, a line says "Could not read the folders" and why. A line "More folders: open the parent" means a folder has more subfolders than the tree shows.

## What you can do

1. To go into a folder, click it in the tree.
2. To go up or back to the top, click a name in the path, or click "Files".
3. To open a folder from the list, click it once to select it, then click it again. You can also click it once and press "Open folder" in the [side area](selected-item.md).
4. To make a folder, press "New folder" in the toolbar (see [Questions](questions.md)).
5. To pick up changes that were made outside the program, press "Rescan". See [What the rescan found](what-the-rescan-found.md).

## Keyboard

In the tree, Enter and Space choose the folder under the cursor.
