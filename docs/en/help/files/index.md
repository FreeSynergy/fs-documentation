# Files help

Files looks after your files and folders. Your files lie in an ordinary folder on your disk, under the names you gave them. Deleting goes through a trash first, and a name clash never overwrites anything silently.

## The views

- [Folders](folders.md): the folder tree and the path on top.
- [List](list.md): what is in a folder, as rows.
- [Grid](grid.md): the same, as tiles.
- [Selected item](selected-item.md): the side area for the file or folder you picked.
- [Filter](filter.md): narrow a folder by size.
- [Trash](trash.md): deleted files, and how to bring them back.
- [Questions](questions.md): the bar at the bottom where the window asks you to type a name or confirm.
- [What the rescan found](what-the-rescan-found.md): the report after Rescan.

## How to start

Start `fs-files` without arguments. The window opens. If no files server answers, the window starts one for you in the background. You can also start the server yourself with `fs-files serve`.
