# List

## What you see

The middle of the window shows the content of the open folder as rows. The columns are Name, Type and Size. In a narrow window only Name and Size are shown. Folders show no size. A file marked sensitive carries the mark "Sensitive". If the folder is empty it says "This folder is empty." After a search with no hits it says "Nothing found for" your words.

Above the list the toolbar has a search field ("Search all folders") and the buttons "Filter", "List", "Grid" and "Trash". The tools are: "Name", "Modified", "Size", "Type" for the order, a button to switch between "Ascending" and "Descending", "New folder", "Rescan". On a narrow window the tools hide behind the "Tools" button.

If the list is long, a "Show more" button under it loads the next rows. If reading failed, a line says "Could not read the list" and a "Try again" button appears.

## What you can do

1. To search, type into "Search all folders". The list shows what matches. Clear the field to come back.
2. To change the order, press "Name", "Modified", "Size" or "Type". Press "Ascending" or "Descending" to turn the direction.
3. To see only some files, press "Filter" (see [Filter](filter.md)).
4. To pick something, click its row. The [side area](selected-item.md) shows it.
5. To open a folder, click its row again.
6. To switch to tiles, press "Grid" (see [Grid](grid.md)). "List" brings you back.
7. To load more, press "Show more".

## Keyboard

After you click into the list: Up and Down move one row, Page Up and Page Down move a page, Home goes to the first row, End to the last. Moving to a row selects it.
