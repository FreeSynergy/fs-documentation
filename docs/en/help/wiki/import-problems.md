# Import problems

## What you see

A page called "Import problems", listed as "(import problems)" in the [Page tree](page-tree.md). It exists only if the import found something that needs a person. It can have these parts:

- "Not imported": files that could not be imported, each with the reason.
- "Changed in the file and in the wiki": the wiki keeps its text, nothing is overwritten, and the version from the file is shown so nothing is lost.
- "Files that are gone": files imported once; their texts are kept.
- "Missing on the server": files imported once whose text the server no longer has. They are not imported again.
- "Not looked at": entries of the folder that were left out.

An unsaved draft of a page that moved or was deleted is listed here too.

## What you can do

1. Open "(import problems)" in the tree.
2. Read the parts. For a conflict, copy what you need from the shown text.
3. To get a missing file back, import it by hand.
