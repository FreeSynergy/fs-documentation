# Export

## What you see

The button "Export" in the bar above the page. It only appears if the app was started with `--export FOLDER`.

## What you can do

1. Open the page you want.
2. Press "Export". The page is written as Markdown to the folder you gave at start, under its own path.
3. If a file is already there, the window says so and "Press Export again to replace it."
4. Press "Export" again to replace it.
5. If it did not work, you see "Not exported" and why.

The documentation folder you imported is only read. Nothing is written back unless you press Export.

## Keyboard

None of its own.
