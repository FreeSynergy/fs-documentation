# Group

## What you see

The page of the group you chose. At the top is its name. Below that:

- "Details": the "Kind".
- "Part of": the groups it belongs to, each as "Group" and a name. Only shown if there are any.
- "Members": each member with the role, or "Member" if there is no role. Only shown if there are any.

Above the page are the buttons "Edit" and "Delete". If nothing is chosen the page says "Nobody selected." If the group was removed meanwhile it says "This group no longer exists."

## What you can do

1. Press "Edit" to change the group. See [Edit group](edit-group.md).
2. Press "Delete" to remove it. See [Delete group](delete-group.md).
3. Choose another group in the [list](groups.md) to read it.

## Keyboard

None of its own.
