# Groups help

Groups keeps track of who belongs together: a family, a team, a club. Today the window lists your groups and shows each one with what it is part of and its members. You can make, rename, re-kind and delete groups.

## The views

- [Groups](groups.md): the list of groups and the search.
- [Group](group.md): the page of one group.
- [Edit group](edit-group.md): the form to change a group or make a new one.
- [Delete group](delete-group.md): the two steps to remove a group.

## How to start

Start `fs-groups` without arguments. The window opens. If no groups server answers, the window starts one for you in the background. You can also start the server yourself with `fs-groups serve`.
