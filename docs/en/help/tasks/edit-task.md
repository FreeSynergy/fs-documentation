# Edit task

## What you see

A form in the area beside the list. It has these fields: **Title**, **Description**, **Due**, **Priority**, **Status** and **Labels**. Status is a row of buttons, one for each status; the chosen one is highlighted. At the bottom are **Save** and **Cancel**. For a task that repeats, the form has no Due and no Status, and a note says you are editing all occurrences.

## What you can do

Make a new task:

1. Press **New**, or choose **Task**, then **New** in the menu bar.
2. Type a title. A task needs one.
3. Fill in what you want. Write the due date with a time, like 2026-11-30 17:00.
4. Press **Save**. The window says "Created."

Change a task:

1. Pick the task, then press **Edit**.
2. Change the fields.
3. Press **Save**. The window says "Saved." Only what you changed is written.

Write labels:

1. Separate labels with commas, like `home, urgent`.
2. A label with a comma in it goes in quotes, like `"a, b"`.

Stop:

1. Press **Cancel**. If you changed something, the window asks. Press **Discard changes** to throw it away, or **Keep editing** to go on.

If someone else changed the task while you were editing, the window says so and keeps your text. Press **Save** again to write it anyway.

Problems you may meet: "enter a title", "enter the due date with a time", and "the priority is a number from 0 to 9, or empty".
