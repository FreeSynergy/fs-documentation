# Tasks help

FreeSynergy Tasks keeps what you have to do. Each task has a title, a due date, a status and labels. You can look at the same tasks as a list or by status. Tasks follow an open standard, so other programs, like the calendar, can show them too.

## Views

- [List](list.md): all your tasks in rows, with search.
- [Status](status.md): the same tasks in one column for each status.
- [Task](task.md): one task, read, moved or deleted.
- [Edit task](edit-task.md): the form for a new task or an existing one.

## How to start

1. Open the program with `fs-tasks`. The window opens on the list.
2. Press **New** to write your first task.
3. Type a title and press **Save**.

Your tasks are kept in your data folder, so they are there the next time you open the window.
