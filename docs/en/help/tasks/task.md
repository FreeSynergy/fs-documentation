# Task

## What you see

The task you picked, beside the list or the columns. At the top is its title, and a mark such as "Sensitive" if the task has one. Below are the details that the task has: Status, Due, Time zone, Priority, Percent done, Extended status, Labels and Description. Empty details are left out. If the task repeats, you see "Repeats: Yes" and a note. If it has participants or related tasks, you see how many. In the status view you also see the "Move to" buttons.

If no task is picked, the area says "No task selected."

## What you can do

Edit the task:

1. Press **Edit**. See [Edit task](edit-task.md).

Delete the task:

1. Press **Delete**. The window asks whether to delete the task and says it cannot be taken back here.
2. Press **Really delete** to go on, or **Keep** to stop.

Change its status:

1. Under "Move to", press a status. See [Status](status.md).

## Keyboard

The window code defines no shortcuts for this page.
