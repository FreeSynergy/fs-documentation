# 🌍 FreeSynergy.Documentation

Welcome to the official documentation of **FreeSynergy** — a project aimed at providing open-source tools and knowledge for better collaboration, knowledge sharing, and accessibility.

## 📁 Documentation in multiple languages

This documentation is available in several languages:

- 🇬🇧 **English**: [To the English version](/en/)
- 🇩🇪 **Deutsch**: [Zur deutschen Version](/de/)
- 🌍 more languages coming soon — contributions welcome!

## 🚀 What you'll find here

- 🔧 Guides for setup & usage of our tools
- 📚 Architectures, concepts & background information
- 💡 Best practices & tips from the community
- 🧩 Extensions, plugins & integrations

## 🗂️ Areas

| Area | Contents |
|------|----------|
| [Programs](programs/) | Programs by category (apps/suites/platform), with frontend documentation (menu, features, structure, shortcuts, API) |
| [Components](components/) | UI elements in three bands (primitives, widgets, workbenches): description, appearance, attributes (84 elements) |
| [Gestures](interactions/gestures/) | Touch interactions in 4 families: single (Tap, Swipe, Drag …), multi (Pinch, Rotate …), device (Shake, Tilt …), combined (Drag and Drop …) |
| [Animations](interactions/animations/) | Transitions and effects: Fade, Slide, Zoom, Bounce, Flip, Pulse, Skeleton and others |
| [Standardised data](data/) | Formats, models, fields, conventions and the uniform API pattern |

## 💬 Contribute

Want to help? It's easy:

1. **Fork** this repository  
2. Edit or add documentation (in `docs/de/` or `docs/en/`)  
3. **Commit & push**  
4. Create a **Pull Request**  

All contributions are welcome — from tiny fixes to complete tutorials! 🙌
