# Telegram - Description

## Overview

Telegram is a cloud-based messenger with a focus on speed and security. It is available on many platforms and offers encrypted chats, large groups, and channels for broadcasting.

## What Telegram Does

Telegram is a cloud-based messaging service specifically designed for fast and secure communication. It enables one-on-one and group chats, large channels for broadcasting, encrypted "Secret Chats", and the transfer of large files.

## Advantages

- **Speed**: Very fast message transmission
- **Cloud-based**: Messages are stored in the cloud
- **Encryption**: Encrypted "Secret Chats" with E2E encryption
- **Large Groups**: Groups up to 200,000 members
- **Large Channels**: Channels with unlimited subscribers
- **File Size**: Send files up to 2 GB
- **Cross-Platform**: Works on Windows, macOS, Linux, iOS, Android, Web
- **Bots**: Extensive bot system for automation
- **Open API**: Open API for developers
- **Free**: Free for all features

## Distinction from Other Systems

### Telegram vs. Discord
- **Telegram** is for messaging and broadcasting, **Discord** is for chat and community servers
- **Discord** has native voice/video, **Telegram** has voice/video via VoIP
- **Telegram** has large groups/channels, **Discord** has servers with limits
- **Discord** has more gaming features, **Telegram** has more broadcasting features

### Telegram vs. Element
- **Telegram** is proprietary, **Element** is open source
- **Telegram** has cloud-based chats, **Element** has decentralized chats
- **Element** has E2E encryption by default, **Telegram** only in "Secret Chats"
- **Element** is for decentralized communication, **Telegram** is for centralized communication

### Telegram vs. Mastodon
- **Telegram** is for messaging and groups, **Mastodon** is for microblogging
- **Telegram** has no E2E encryption (except Secret Chats), **Mastodon** has no E2E encryption
- **Mastodon** is decentralized, **Telegram** is centralized

## Technical Details

- **Platform**: Windows, macOS, Linux, iOS, Android, Web
- **Protocol**: MTProto (proprietary protocol)
- **Backend**: Cloud-based Telegram backend
- **Encryption**: MTProto for cloud chats, AES-256 + RSA for Secret Chats
- **Authentication**: OAuth2, Phone Number
- **Bots**: Telegram bots via Bot API
- **Programming Language**: C++ (core), JavaScript (web), Kotlin (Android), Swift (iOS)

## Who is Telegram Suitable For?

- **Speed seekers**: For those who want fast communication
- **Large communities**: For those who want to run large groups/channels
- **File transfer**: For those who want to transfer large files
- **Bot users**: For those who want bot integrations
- **Cross-platform users**: For those who communicate on multiple platforms
