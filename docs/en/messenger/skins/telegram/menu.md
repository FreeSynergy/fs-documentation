# Telegram - Menu Items

## Overview

Telegram is a cloud-based messenger with a focus on speed and security. It is available on many platforms and offers encrypted chats, large groups, and channels for broadcasting.

## Main Menu Items

### 1. Chat Menu (Left)
- **Function**: Chat management
- **Details**:
  - Start new chat
  - Create groups
  - Create channel
  - Start secret chats
  - Chat search field

### 2. Chat List (Left)
- **Function**: Chat overview
- **Details**:
  - Show active chats
  - Show groups
  - Show channels
  - Show secret chats
  - Chat sorting

### 3. Messages Menu (Center)
- **Function**: Message management
- **Details**:
  - Send messages
  - Edit/delete messages
  - Mark messages
  - Quote messages
  - Forward messages
  - Send media

### 4. Media Menu (Center)
- **Function**: Media management
- **Details**:
  - Upload photos
  - Upload videos
  - Upload documents
  - Preview media
  - Download media

### 5. Members Menu (Right)
- **Function**: Member management
- **Details**:
  - Show member list
  - Invite members
  - Kick members
  - Edit members
  - Manage roles

### 6. Settings
- **Function**: Manage settings
- **Details**:
  - General settings
  - Media settings
  - Security settings
  - Theme settings
  - Language settings

### 7. Help Functions
- **Function**: Help functions
- **Details**:
  - Help documentation
  - About Telegram
  - Troubleshooting
