# Discord - Features

## Overview

Discord is a proprietary communication platform and chat client originally developed for gaming communities but now used for all kinds of communities.

## Main Features

### 1. Server Management
- **Create Server**: Create your own servers
- **Join Server**: Join existing servers
- **Server Settings**: Configure server settings
- **Server Roles**: Manage roles for members
- **Server Permissions**: Configure permissions for roles

### 2. Channel Management
- **Text Channels**: Text-based channels for chat
- **Voice Channels**: Voice channels for audio chats
- **Categories**: Organize channels into categories
- **Channel Settings**: Configure channel settings
- **Channel Permissions**: Configure permissions for channels

### 3. Chat Communication
- **Text Chat**: Text-based communication in channels
- **Direct Messages**: Direct messages to individual users
- **Group Messages**: Group messages to multiple users
- **E2E Encryption**: No E2E encryption (only TLS)
- **Status**: Online/Away/Busy/Offline
- **Read Receipts**: Display read receipts

### 4. Voice and Video Calls
- **Voice Chats**: Audio chats in voice channels
- **Video Chats**: Video chats with camera
- **Screen Sharing**: Screen sharing for streaming
- **Call Tools**: Mute, volume control
- **Call History**: Display call history

### 5. File Transfer
- **File Attachments**: Sending files of any size
- **Drag & Drop**: Drag & drop for file transfer
- **File Preview**: Preview images, videos, documents
- **GIFs**: Embed GIFs in messages

### 6. Bots and Integrations
- **Bots**: Extensive bot system for automation
- **Webhooks**: Webhooks for external integrations
- **OAuth2**: OAuth2 integration for external services
- **Random Functions**: Random functions for entertainment
- **Integration Manager**: Manager for external integrations

### 7. Moderation
- **Manage Members**: Kick, ban members
- **Manage Roles**: Create and manage roles
- **Audit Log**: Audit log for server changes
- **Warning System**: Warning system for members
- **AutoMod**: Automatic moderation

### 8. Profile
- **Own Profile**: Manage your own profile
- **Notifications**: Manage notifications
- **Privacy Settings**: Configure privacy settings
- **Authentication**: Two-factor authentication

## What Discord Cannot Do

- No native support for email (must be combined with email client)
- No native support for IRC
- No native support for Signal/WhatsApp
- No native Mastodon integration (only via webhooks)
- No native end-to-end encryption (only TLS)

## Discord Bots

### Popular Bots
- **MEE6**: Moderation bot and music bot
- **Dyno**: Moderation bot and automation
- **Music Bot**: Play music in voice channels
- **Carl-bot**: Moderation bot and auto-moderation
- **Utility Bots**: Various utility bots

## Discord Nitro (Premium)

### Discord Nitro Features
- **Larger File Size**: Send files up to 100MB
- **HD Videos**: Send HD videos
- **GIFs**: Use custom GIFs as emojis
- **Server Logo**: Custom server logo
- **Animated Avatar**: Animated avatar
- **Streaming**: Higher streaming quality
- **Larger Server**: Larger servers (up to 1 million members)

## Shortcuts

| Shortcut | Function |
|----------|----------|
| `Enter` | Send message |
| `Shift+Enter` | New line |
| `Ctrl+K` | Search channel |
| `Ctrl+Shift+K` | Search server |
| `Ctrl+E` | Settings |
| `Ctrl+M` | Audio call |
| `Ctrl+V` | Video call |
| `Ctrl+Shift+D` | Screen sharing |
