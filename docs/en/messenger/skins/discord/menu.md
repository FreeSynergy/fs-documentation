# Discord - Menu Items

## Overview

Discord is a proprietary communication platform and chat client originally developed for gaming communities but now used for all kinds of communities.

## Main Menu Items

### 1. Server Menu (Left)
- **Function**: Server management
- **Details**:
  - Create/join server
  - Server settings
  - Change server icon/name
  - Manage server roles

### 2. Channel Menu (Left)
- **Function**: Channel management
- **Details**:
  - Join text channel
  - Join voice channel
  - Channel settings
  - Channel permissions

### 3. Chat Menu (Center)
- **Function**: Chat communication
- **Details**:
  - Send messages
  - Edit/delete messages
  - Mark messages
  - Quote messages
  - Insert emojis
  - Insert GIFs

### 4. Voice Menu (Right)
- **Function**: Voice and video calls
- **Details**:
  - Start audio call
  - Start video call
  - Screen sharing
  - Control microphone
  - Control volume

### 5. Members Menu (Right)
- **Function**: Member management
- **Details**:
  - Show member list
  - Invite members
  - Kick members
  - Ban members
  - Change member roles

### 6. Settings
- **Function**: Manage settings
- **Details**:
  - General settings
  - Media settings
  - Security settings
  - Theme settings
  - Language settings

### 7. Help Functions
- **Function**: Help functions
- **Details**:
  - Help documentation
  - About Discord
  - Troubleshooting
