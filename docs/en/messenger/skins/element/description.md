# Element - Description

## Overview

Element is an open-source messenger for the Matrix protocol community. It is a complete client implementation of the Matrix protocol, designed for secure, decentralized communication. Element is the official reference implementation of the Matrix protocol.

## What Element Does

Element is a full-featured chat and communication client based on the Matrix protocol. It enables secure, encrypted communication in groups and one-on-one conversations, both over public and private servers. Element supports text, files, voice, and video calls.

## Advantages

- **Open Source**: Free and open source under Apache-2.0 license
- **Matrix Protocol**: Open, decentralized protocol
- **End-to-End Encryption**: E2E encryption for secure communication
- **Decentralization**: Works with any Matrix servers
- **Cross-Platform**: Works on Web, Windows, macOS, Linux, iOS, Android
- **Federation**: Servers can communicate with each other
- **Integrations**: Many integrations with external services
- **Research project**: Further development by Matrix.org Foundation
- **Certified**: E2E encryption certified by external security expert

## Distinction from Other Systems

### Element vs. Discord
- **Element** is decentralized and open source, **Discord** is centralized and proprietary
- **Element** has E2E encryption by default, **Discord** only in private messages
- **Discord** has native voice/video, **Element** has it via VoIP protocol
- **Element** is for private users and communities, **Discord** for community servers

### Element vs. Telegram
- **Element** is open source and decentralized, **Telegram** is proprietary and centralized
- **Element** has E2E encryption by default, **Telegram** only in secret chats
- **Element** uses Matrix protocol, **Telegram** uses proprietary protocol
- **Telegram** has more features (bots, channels), **Element** has more privacy

### Element vs. Mastodon
- **Element** is for chat and groups, **Mastodon** is for microblogging
- **Element** has E2E encryption, **Mastodon** has no E2E encryption
- **Element** is decentralized over servers, **Mastodon** is decentralized over instances

## Technical Details

- **Platform**: Web, Windows, macOS, Linux, iOS, Android
- **Protocol**: Matrix
- **Backend**: Custom Matrix protocol
- **Encryption**: Olm/Ratchet for E2E encryption
- **Authentication**: OAuth2, OpenID Connect
- **Federation**: Matrix federation protocol
- **Programming Language**: TypeScript, React (Web), Kotlin (Android), Swift (iOS)
- **Hosting**: Own Matrix server or public servers

## Who is Element Suitable For?

- **Private users**: For those who value privacy
- **Communities**: For those who want to run their own chat groups
- **Companies**: For those who want self-hosted communication
- **Open Source users**: For those who prefer open source software
- **Matrix users**: For those who want to use the Matrix protocol
