# Element - Menu Items

## Overview

Element is an open-source messenger for the Matrix protocol community. It is a complete client implementation of the Matrix protocol, designed for secure, decentralized communication.

## Main Menu Items

### 1. Settings
- **Function**: Manage settings
- **Details**:
  - Open settings
  - General settings
  - Media settings
  - Security settings
  - Theme settings
  - Language settings

### 2. Room
- **Function**: Room-related actions
- **Details**:
  - Join/leave room
  - Room settings
  - Room notifications
  - Room subscriptions
  - Clear room history

### 3. Members
- **Function**: Room members management
- **Details**:
  - Show members
  - Invite members
  - Kick members
  - Ban members
  - Change member rights

### 4. Search
- **Function**: Search for messages and rooms
- **Details**:
  - Global search
  - Room search
  - Message search
  - Apply filters

### 5. File
- **Function**: File operations
- **Details**:
  - Send files
  - Download files
  - Open files
  - Save files

### 6. Help Functions
- **Function**: Help functions
- **Details**:
  - Help documentation
  - About Element
  - About Matrix
  - Troubleshooting
