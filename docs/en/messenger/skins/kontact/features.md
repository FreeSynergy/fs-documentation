# Kontact - Features

## Overview

Kontact is an integrated Personal Information Manager (PIM) application for the KDE desktop environment. It combines several well-known KDE applications into a single, consolidated application.

## Main Features

### 1. Email Management (KMail)
- **Receiving**: IMAP, POP3, Maildir
- **Sending**: SMTP support
- **Encryption**: GnuPG (GPG), S/MIME for secure emails
- **Signatures**: Automatic signatures (GPG-signed emails)
- **Rules**: Automatic email filtering with comprehensive filter rules
- **SEARCH**: Powerful search across all folders (including text content)
- **Folders**: Unlimited folders with subfolders
- **Filters**: Color coding, custom filters
- **Full-text Search**: Kontact search (Baloo)
- **Offline Mode**: Work without internet connection

### 2. Calendar (KOrganizer)
- **Events**: Single events and multi-day events
- **Meetings**: Appointments with participants and resources
- **Recurrences**: Daily, weekly, monthly, yearly recurrences
- **Sharing**: Share calendar with others (CardDAV, CalDAV, WebDAV)
- **Subscriptions**: CalDAV and iCalendar support (ICS)
- **Status**: Show availability (Busy, Free, Appointments, etc.)
- **Calendar Colors**: Custom colors per calendar
- **Working Hours**: Configurable working hours and holidays
- **Tasks**: Tasks and to-dos with deadlines and priorities

### 3. Contacts (KAddressBook)
- **Address Book**: Personal and shared address books
- **Contact Groups**: Mailing lists
- **Import/Export**: CSV, vCard (3.0, 4.0), LDIF
- **Linking**: Link contacts with emails and appointments
- **Photos**: Contact photos (JPEG, PNG)
- **Custom Fields**: Adjustable fields for each contact
- **Synchronization**: CardDAV, vCard sync
- **QR Codes**: Generate QR code for contacts

### 4. Tasks (To-do Lists)
- **Task Lists**: Personal and shared task lists
- **Reminders**: Date and time reminders
- **Priorities**: High, Medium, Low, None
- **Status**: Not Started, In Progress, Waiting, Completed
- **Recurrences**: Recurring tasks
- **Deadlines**: Due date and time
- **Progress**: Percentage progress display
- **Sharing**: Share tasks with others

### 5. Notes (KNotes)
- **Simple Notes**: Text-based notes
- **Multi-notes**: Multiple notes at once
- **Sharing**: Share notes with others (via calendar)
- **Formatting**: Basic formatting (Bold, Italic, Underline)
- **Note Manager**: Organize and manage notes

### 6. News Reader (KNode)
- **Newsgroups**: NNTP support for Usenet
- **News Servers**: Configurable news servers
- **RSS/Atom**: Read RSS and Atom feeds
- **Filters**: Message filters and rules
- **Offline Mode**: Read news offline

### 7. Integrations
- **KDE Integration**: Seamless integration with KDE Plasma
- **Plasmoids**: KDE plasmoids for widget support
- **KDE Connect**: Synchronization with Android devices
- **KMail Integration**: Email in all KDE applications
- **System Integration**: System notifications, keyring

## What Kontact CANNOT do

- No native support for IRC
- No native support for Signal/WhatsApp
- No native Mastodon/social media integration
- No native end-to-end encryption (only GPG/S/MIME)
- No native chat function (must be combined with Konversation/Kopete)
