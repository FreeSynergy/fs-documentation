# Thunderbird - Features

## Overview

Thunderbird is an open-source email and messaging client developed by the Mozilla Foundation. It is part of the Mozilla ecosystem and was specifically designed for email communication, with optional calendar and address book functions via extensions.

## Main Features

### 1. Email Management
- **Receiving**: IMAP, POP3, Maildir
- **Sending**: SMTP support with authentication
- **Encryption**: GnuPG (GPG), S/MIME for secure emails
- **Signatures**: Automatic signatures (GPG-signed emails)
- **Rules**: Comprehensive filter rules for automatic email management
- **SEARCH**: Powerful search across all folders (including text content)
- **Clutter**: Intelligent filtering of unwanted emails (spam filter)
- **Folders**: Unlimited folders with subfolders
- **Filters**: Color coding, custom filters
- **Offline Mode**: Work without internet connection

### 2. Calendar (via Lightning Add-on)
- **Events**: Single events and multi-day events
- **Meetings**: Appointments with participants and resources
- **Recurrences**: Daily, weekly, monthly, yearly recurrences
- **Sharing**: Share calendar with others (CalDAV, WebDAV)
- **Subscriptions**: iCalendar support (ICS)
- **Status**: Show availability (Busy, Free, Appointments, etc.)
- **Calendar Colors**: Custom colors per calendar
- **Tasks**: Tasks and to-dos with deadlines and priorities

### 3. Address Book (via Lightning Add-on)
- **Address Books**: Personal and shared address books
- **Contact Groups**: Mailing lists
- **Import/Export**: CSV, vCard (3.0, 4.0)
- **Linking**: Link contacts with emails
- **Photos**: Contact photos (JPEG, PNG)
- **Synchronization**: CardDAV support (via add-ons)

### 4. Messages and News Reader (Upcoming)
- **Newsgroups**: NNTP support for Usenet
- **News Servers**: Configurable news servers
- **RSS/Atom**: Read RSS and Atom feeds (via add-ons)

### 5. Integrations
- **Mozilla Ecosystem**: Integration with Firefox (bookmarks, passwords)
- **Certificates**: Manage S/MIME certificates
- **Add-ons**: Comprehensive add-on system
- **System Integration**: System notifications, keyring

### 6. Security
- **Phishing Protection**: Detection of phishing emails
- **Tracking Protection**: Protection from tracking in emails
- **Encryption**: GPG/S/MIME for secure communication
- **Certificate Management**: Manage certificates

## What Thunderbird CANNOT do

- No native support for IRC
- No native support for Signal/WhatsApp
- No native Mastodon/social media integration
- No native chat function (must be combined with Konversation/Kopete)
- No native Office integration (like Word/Excel)
- Calendar and address book functions require Lightning add-on

## Add-ons and Extensions

### Popular Add-ons
- **Lightning**: Calendar and tasks (standard extension)
- **Enigmail**: GPG support for email encryption
- **Address Book Synchronization**: CardDAV sync
- **QuickFolders**: Quick access to folders
- **ImportExportTools**: Import/export of emails and contacts
- **Super Productivity**: Productivity tools

| `Ctrl+Shift+N` | New message (News) |
| `Ctrl+R` | Reply |
| `Ctrl+Shift+R` | Forward |
| `Ctrl+Shift+D` | Quick search |
| `Ctrl+1` | Email view |
| `Ctrl+2` | Calendar view (Lightning) |
