# Mastodon - Features

## Overview

Mastodon is an open-source microblogging network based on the ActivityPub protocol. It is decentralized and consists of many independent servers (instances) that can communicate with each other.

## Main Features

### 1. Toot Communication
- **Post toots**: Publish short messages (toots)
- **Edit toots**: Edit toots (within a time window)
- **Delete toots**: Delete toots
- **Quote toots**: Quote and comment on toots
- **Bookmark toots**: Bookmark toots
- **Share toots**: Share toots (boost)

### 2. Timeline Management
- **Home timeline**: Timeline with posts from followed users
- **Local timeline**: Timeline with posts from your own instance
- **Federated timeline**: Timeline with posts from the entire network
- **Hashtag timeline**: Timeline for specific hashtags
- **Timeline filters**: Timeline filters by hashtags, sensitivity, etc.

### 3. User Management
- **Follow users**: Follow users
- **Unfollow users**: Unfollow users
- **Block users**: Block users
- **Ignore users**: Ignore users
- **Open user profile**: Open user profile
- **Contact list**: Manage contacts

### 4. Direct Messages
- **Send direct messages**: Send direct messages to individual users
- **Receive direct messages**: Receive direct messages
- **Edit/delete direct messages**: Edit/delete direct messages
- **Bookmark direct messages**: Bookmark direct messages
- **No E2E encryption**: Direct messages are not end-to-end encrypted

### 5. Media Management
- **Upload images**: Upload images in toots
- **Upload videos**: Upload videos in toots
- **Media editing**: Edit media (description, sensitivity)
- **Media preview**: Media preview in toots
- **Alt text**: Alt text for images

### 6. Sensitivity and Filters
- **Mark as sensitive**: Mark toots as sensitive (NSFW)
- **Hide media**: Hide media in toots
- **Filter words**: Filter words
- **Filter users**: Filter users
- **Filter hashtags**: Filter hashtags

### 7. Profile Management
- **Own profile**: Manage your own profile
- **Bio**: Edit bio
- **Profile image**: Change profile image
- **Header image**: Change header image
- **Privacy settings**: Configure privacy settings

### 8. Moderation
- **Report users**: Report users
- **Report toots**: Report toots
- **Instance moderators**: Manage instance moderators
- **Audit log**: Audit log for moderation actions

## What Mastodon Cannot Do

- No native support for email (must be combined with email client)
- No native support for IRC
- No native support for Signal/WhatsApp
- No native Discord integration (no chat)
- No native end-to-end encryption (only TLS)
- No native voice/video communication

## Mastodon Instances

### Popular Instances
- **mastodon.social**: Largest instance, general
- **tech.io**: For technology communities
- **queer.party**: For LGBTQ+ communities
- **freie.social**: For free software communities
- **Instance-specific**: Each instance has its own rules and topics
