# Outlook - Features

## Overview

Outlook is Microsoft's most popular email client, part of Microsoft 365. It combines email, calendar, tasks, and contacts in a single application.

## Main Features

### 1. Email Management
- **Receiving**: POP3, IMAP, Exchange, Office 365
- **Sending**: SMTP support
- **Encryption**: S/MIME for secure emails
- **Signatures**: Automatic signatures
- **Rules**: Automatic email filtering
- **Search**: Powerful search across all folders
- **Clutter**: Intelligent filtering of unwanted emails

### 2. Calendar
- **Appointments**: Single and multi-day appointments
- **Meetings**: Appointments with participants
- **Resources**: Room bookings
- **Repetitions**: Daily, weekly, monthly repetitions
- **Sharing**: Share calendar with others
- **Subscriptions**: CalDAV and iCalendar support
- **Status**: Display availability (Busy, Free, etc.)

### 3. Contacts
- **Address Book**: Personal and shared address books
- **Contact Groups**: Distribution lists
- **Import/Export**: CSV, vCard
- **Linking**: Link contacts with emails
- **Photos**: Contact photos

### 4. Tasks
- **Task Lists**: Personal and shared task lists
- **Reminders**: Date and time reminders
- **Priorities**: High, Medium, Low
- **Status**: Not Started, In Progress, Completed
- **Repetitions**: Recurring tasks
- **Sharing**: Share tasks with others

### 5. Notes
- **Simple Notes**: Text-based notes
- **Sharing**: Share notes with others
- **Synchronization**: With OneNote

### 6. Integrations
- **Microsoft 365**: Word, Excel, PowerPoint
- **Teams**: Chat and meetings
- **OneDrive**: File attachments
- **SharePoint**: Document sharing
- **Power Automate**: Automation

## What Outlook Cannot Do

- No native support for IRC
- No native support for Signal/WhatsApp
- No native Mastodon/social media integration
- No native end-to-end encryption (only S/MIME)
- No native multi-account support across all features (limited)
