# Pinch

## Description

Pinch is pulling the fingers together on the screen - at least two, any number
more.

The number plays no role: with three, four, or five fingers it is the same
gesture; what is evaluated is the decreasing distance between the pointers.

## Usage

- Zoom out
- Shrinking content

## Direction

- Two or more fingers move towards each other

## Distance

- Typical: > 20px movement
