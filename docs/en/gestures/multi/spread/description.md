# Spread

## Description

Spread (stretching) is pulling the fingers apart on the screen - at least two,
any number more.

The number plays no role: with three, four, or five fingers it is the same
gesture; what is evaluated is the increasing distance between the pointers.

## Usage

- Zoom in
- Enlarging content

## Direction

- Two or more fingers move away from each other

## Distance

- Typical: > 20px movement
