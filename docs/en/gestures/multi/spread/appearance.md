# Spread - Appearance

## Basic Layout

Spread (stretching) is pulling the fingers apart - at least two, any number
more.

## Visual Feedback

```
┌─────────────────────────────────────────┐
│   (        )                            │
│    (      )                             │
│     (    )                              │
│      (  )                               │
└─────────────────────────────────────────┘
```

## Feedback Options

| Option | Description |
|--------|-------------|
| **Zoom** | Show zoom factor |
| **Scale** | Element scales itself |
| **None** | No feedback |

## Direction

- Two or more fingers move away from each other

## Distance

- Typical: > 20px movement

## Zoom Factor

- Typical: 2.0x (doubling)
