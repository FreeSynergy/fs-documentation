# Long Press - Appearance

## Basic Layout

A long press is a sustained touch on the screen.

## Visual Feedback

```
┌─────────────────────────────────────────┐
│                                         │
│     [──────]                            │
│                                         │
└─────────────────────────────────────────┘
```

## Feedback Options

| Option | Description |
|--------|-------------|
| **Ripple** | Ripple wave on touch |
| **Scale** | Slight enlargement |
| **Color** | Color changes |
| **Haptic** | Haptic feedback (vibration) |

## Duration

- Typical: > 500ms

## Difference from Tap

- Tap: short (< 250ms)
- Long Press: long (> 500ms)
