# Tap - Attributes

## Main Attributes

| Attribute | Type | Default | Description |
|-----------|------|---------|-------------|
| `onTap` | function | - | Executed on Tap |

## Feedback Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `rippleEffect` | boolean | `true` | Show ripple effect? |
| `scaleEffect` | boolean | `false` | Show scale effect? |
| `colorEffect` | boolean | `false` | Change color? |

## Threshold Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `tapThreshold` | number | `250` | Time limit for Tap in ms |
| `moveThreshold` | number | `10` | Max. movement in px |

## Accessibility

| Attribute | Type | Description |
|-----------|------|-------------|
| `aria-label` | string | Descriptive text |
| `role` | string | ARIA role: `button` |
