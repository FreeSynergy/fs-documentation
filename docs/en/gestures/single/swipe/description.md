# Swipe

## Description

A swipe is a glide in one direction.

## Usage

- Navigation (e.g. changing a page)
- Switching between views
- Delete by swiping

## Directions

| Direction | Description |
|-----------|-------------|
| Left | Swiping to the left |
| Right | Swiping to the right |
| Up | Swiping upwards |
| Down | Swiping downwards |

## Distance

- Typical: > 50px
