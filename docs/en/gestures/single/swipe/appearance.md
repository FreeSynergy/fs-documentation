# Swipe - Appearance

## Basic Layout

A swipe is a glide in one direction.

## Visual Feedback

```
┌─────────────────────────────────────────┐
│  ←─────                                 │
│    ←─────                               │
│      ←─────                             │
│        ←─────                           │
└─────────────────────────────────────────┘
```

## Feedback Options

| Option | Description |
|--------|-------------|
| **Velocity** | Show velocity |
| **Direction** | Arrow in the swipe direction |
| **None** | No feedback |

## Directions

| Direction | Arrow | Description |
|-----------|-------|-------------|
| Left | ← | Swiping to the left |
| Right | → | Swiping to the right |
| Up | ↑ | Swiping upwards |
| Down | ↓ | Swiping downwards |

## Distance

- Typical: > 50px
