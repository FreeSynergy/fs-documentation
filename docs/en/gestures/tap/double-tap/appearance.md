# Double Tap - Appearance

## Basic Layout

A double tap is two quick touches in rapid succession.

## Visual Feedback

```
┌─────────────────────────────────────────┐
│                                         │
│     [Click] [Click]                     │
│                                         │
└─────────────────────────────────────────┘
```

## Feedback Options

| Option | Description |
|--------|-------------|
| **Ripple** | Ripple wave on each touch |
| **Scale** | Slight enlargement |
| **Color** | Color changes |
| **None** | No feedback |

## Duration

- Between the taps: < 300ms

## Difference from Tap

- Tap: a single touch
- Double Tap: two quick touches
