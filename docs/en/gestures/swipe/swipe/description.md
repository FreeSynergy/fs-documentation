# Swipe

## Description

A swipe is a glide in one direction.

## Finger Count

1 up to the device limit (typically 5–10 fingers). Several simultaneous
fingers are recognised as one gesture at the centre of all pointers.

## Usage

- Navigation (e.g. changing a page)
- Switching between views
- Delete by swiping

## Directions

| Direction | Description |
|-----------|-------------|
| Left | Swiping to the left |
| Right | Swiping to the right |
| Up | Swiping upwards |
| Down | Swiping downwards |

## Distance

- Typical: > 50px
