# Wave - Appearance

## Basic Layout

The device shows a preparatory countdown; the hand appears in the sensor cone
above the display.

```
┌───────────────────────────────┐
│          ✋ (hand above device)│
│          ┆ Sensor cone        │
│  ┌─────────────────────┐      │
│  │ Call from Anna      │      │
│  │ ⏱ 3…2…1 to answer   │      │
│  └─────────────────────┘      │
└───────────────────────────────┘
```

## Feedback Options

| Option | Description |
|--------|-------------|
| **Countdown** | The window for waving visibly runs down |
| **Hand Cursor** | A pointer follows the hand over the UI |
| **Haptic + Sound** | Acknowledgement after detection |
| **Privacy Dot** | Permanently: sensor active |

## Countdown Lengths

| Length | Usage |
|--------|-------|
| 3s | Answering a call |
| 5s | Assistant/media commands |

## Duration

- Gesture recognition: < 500ms after the pattern ends
- Preparation countdown: 3–5s

## Difference from Shake

- Wave: the sensor points outwards, the user moves a hand
- Shake: the sensor is in the device, the user moves the device
