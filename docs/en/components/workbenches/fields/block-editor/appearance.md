# Block Editor - Appearance

## Base layout

```
┌─────────────────────────────────────────┐
│ ⋮⋮ # Heading                            │
│ ⋮⋮ Paragraph of text …                  │
│ ⋮⋮ ☐ Task block                         │
│ ⋮⋮ [ Contact block ]                    │
│ + Add block                             │
└─────────────────────────────────────────┘
```

## Variants

| Variant | Appearance |
|---|---|
| **edit** | drag handle left of each block, insert line between |
| **read** | no handles |
| **template** | placeholders highlighted |

## Sizes

| Size | Height | Use |
|---|---|---|
| `medium` | 400 px | standard |
| `large` | 600 px | page |
| `full` | 100% | full area |

## Colours and states

| State | Appearance |
|---|---|
| Default | theme surface |
| Selected block | accent outline |
| Mark layer | underline or tint by type |
| Placeholder | dashed outline |

## Hover and focus effects

| Effect | Description |
|---|---|
| `handle` | drag handle appears |
| `background` | block highlight |

## Responsive

- Handles become a block menu button on narrow screens.
- Blocks stack at full width.
