# basics

Band [primitives](../) – cannot be broken down further.

The fundamentals all other components start from: the base class with its
inherited attributes, states and tokens, plus the smallest building blocks.

## Elements

- [**kbd**](./kbd/) – kbd shows a single key or a key combination visually – like a key cap.
- [**label**](./label/) – a label is the caption of a control or a field.
- [**link**](./link/) – a link changes the address – it leads to another page, another object, or a place inside the current view.
- [**separator**](./separator/) – a separator separates content from each other: horizontally between blocks, vertically between columns or tool groups.
