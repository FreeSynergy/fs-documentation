# media

Band [primitives](../) – cannot be broken down further.

Elements that play or show media. `media-player` is the parent class of `audio`
and `video`.

## Elements

- [**icon**](./icon/) – an icon is a symbolic graphic element that visually represents a function or an object.
- [**image**](./image/) – an image element shows graphics, photos or other visual content.

## Profiles

| Component | Inherits from | Variants | Role | Status |
|-----------|---------------|----------|------|--------|
| [icon](./icon/) | `base` | `outline`, `gefüllt`, `animiert` | - | documented |
| [image](./image/) | `base` | `einfach`, `vignette`, `hintergrund` | - | documented |
