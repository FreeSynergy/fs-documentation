# actions

Band [primitives](../) – cannot be broken down further.

Action elements trigger a single action or bundle actions that belong together.
They change data or states, but not the address.

## Elements

- [**button**](./button/) – a button triggers a single action.
- [**button-group**](./button-group/) – a button group brings related buttons together into one visual and logical unit.
- [**floating-action-button**](./floating-action-button/) – a floating action button (FAB) is a round main-action button, usually placed bottom right.

## Profiles

| Component | Inherits from | Variants | Role | Status |
|-----------|---------------|----------|------|--------|
| [button](./button/) | `base` | `primary`, `secondary`, `outline`, `ghost`, `danger`, `link` | - | documented |

| [floating-action-button](./floating-action-button/) | `base` | `standard FAB`, `mini FAB`, `extended FAB` | - | documented |
