# Link Preview - Appearance

## Base layout

```
┌────────────────────────────────────┐
│ ▢ image   Title of the page        │
│           Short description …      │
│           example.org              │
└────────────────────────────────────┘
```

## Variants

| Variant | Appearance |
|---|---|
| **card** | image left or on top, up to three text lines |
| **compact** | one line with a favicon-sized image ⚠️ |

## Sizes

| Size | Height | Use |
|---|---|---|
| `small` | 64 px | compact |
| `medium` | 120 px | standard |
| `large` | 200 px | image on top |

## Colours and states

| State | Appearance |
|---|---|
| Default | card surface |
| Hover | lighter surface |
| Unavailable | muted, shows only the URL |

## Hover and focus effects

| Effect | Description |
|---|---|
| `background` | surface changes |
| `underline` | title underlined |

## Responsive

- Image moves above the text on narrow screens.
- Description is cut after two lines.
