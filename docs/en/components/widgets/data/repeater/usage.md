# Repeater - Usage

!!! note
    The examples are kept syntax-neutral. As soon as the implementation moves to
    Rust and Blinc, the `usage.md` examples will be replaced in a separate pass.

## Application

A repeater is a repeating layout for lists.

- Products
- Contacts
- Articles
- Lists

## Examples

### Products

```jsx
<Repeater items={entries} />
```

### Contacts

```jsx
<Repeater items={entries} interactive={false} />
```

### Articles

```jsx
<Repeater items={entries} interactive={false} />
```
