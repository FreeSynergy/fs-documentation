# data

Band [widgets](../) – knows its contents when it is built.

Elements that present data: lists, tables, grids, trees, timelines and charts. They do not edit values but show them — the fields are what changes them.

## Elements

- [**avatar**](./avatar/) – An avatar is a visual representation element for a user.
- [**calendar-view**](./calendar-view/) – A calendar view shows appointments in a calendar.
- [**chart**](./chart/) – A chart is a data visualisation (diagrams).
- [**description-list**](./description-list/) – A description list shows pairs of a label and a value — the detail view of a data record.
- [**grid-view**](./grid-view/) – A grid view is a card/grid display of elements.
- [**link-preview**](./link-preview/) – A link preview is a preview card for a link, generated by the **sender** and attached to the message.
- [**list-view**](./list-view/) – A list view is a simple list display of elements.
- [**mail-view**](./mail-view/) – A mail view shows one e-mail: header (From, To, Cc, Subject, Date), body as text or HTML, attachments, and signature and encryption state.
- [**message-bubble**](./message-bubble/) – A message bubble shows one chat message with sender, content, reply reference, reactions, delivery state and encryption.
- [**message-list**](./message-list/) – A message list shows the messages of one conversation in time order, anchored at the bottom, loading older ones on demand, with day and unread separators.
- [**reaction-bar**](./reaction-bar/) – A reaction bar shows reactions to a message as emoji with a count and lets the person toggle their own reaction.
- [**repeater**](./repeater/) – A repeater is a repeating layout for lists.
- [**table**](./table/) – A table is a tabular display with rows and columns.
- [**table-of-contents**](./table-of-contents/) – A table of contents is an overview of chapters/sections.
- [**timeline**](./timeline/) – A timeline is a chronological display of events.
- [**tree-view**](./tree-view/) – A tree view is a hierarchical directory structure with collapse/expand.
