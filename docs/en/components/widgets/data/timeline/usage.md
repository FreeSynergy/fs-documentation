# Timeline - Usage

!!! note
    The examples are kept syntax-neutral. As soon as the implementation moves to
    Rust and Blinc, the `usage.md` examples will be replaced in a separate pass.

## Application

A timeline is a chronological display of events.

- Showing a history
- Activities
- History
- Project phases

## Examples

### Showing a history

```jsx
<Timeline events={entries} />
```

### Activities

```jsx
<Timeline events={entries} interactive={false} />
```

### History

