# Reaction Bar - Appearance

## Base layout

```
 [👍 2] [❤ 1] [😂 3]  [+]
```

## Variants

| Variant | Appearance |
|---|---|
| **inline** | chips with 1 px border; own reaction with accent fill |
| **compact** | single chip "3 reactions" |

## Sizes

| Size | Height | Use |
|---|---|---|
| `small` | 20 px | inside dense bubbles |
| `medium` | 28 px | standard |

## Colours and states

| State | Appearance |
|---|---|
| Default | neutral outline |
| Own reaction | accent fill |
| Hover | lighter surface |
| Disabled | grey (no write permission) |

## Hover and focus effects

| Effect | Description |
|---|---|
| `background` | chip highlights |
| `tooltip` | names of the reacting people |

## Responsive

- Chips wrap into several rows.
- Touch target at least 44 px high, even if the chip is smaller.
