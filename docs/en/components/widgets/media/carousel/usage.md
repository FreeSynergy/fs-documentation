# Carousel - Usage

!!! note
    The examples are kept syntax-neutral. As soon as the implementation moves to
    Rust and Blinc, the `usage.md` examples will be replaced in a separate pass.

## Application

A slideshow is a loop of images or content.

- Image galleries
- Product presentations
- Advertising
- Carousels

## Examples

### Image galleries

```jsx
<Carousel images={entries} autoplay={false} interval={5000} />
```

### Product presentations

```jsx
<Carousel images={entries} autoplay={false} loop={true} />
```

### Advertising

```jsx
<Carousel images={entries} autoplay={false} loop={true} />
```
