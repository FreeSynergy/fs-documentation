# Call Controls - Appearance

## Base layout

```
 [🎤] [📷] [🖥 share] [⚙]      [ 📞 hang up ]
```

## Variants

| Variant | Appearance |
|---|---|
| **bar** | centred row of round buttons, hang-up in error colour |
| **compact** | two buttons |

## Sizes

| Size | Height | Use |
|---|---|---|
| `small` | 32 px | mini-bar |
| `medium` | 44 px | standard |
| `large` | 56 px | touch |

## Colours and states

| State | Appearance |
|---|---|
| Default | neutral buttons |
| Active toggle | accent fill |
| Muted/off | crossed glyph |
| Hang up | error colour |

## Hover and focus effects

| Effect | Description |
|---|---|
| `background` | button hover |
| `tooltip` | action name |

## Responsive

- Secondary controls move into an overflow menu on narrow screens.
- The hang-up button stays visible.
