# Drag - Appearance

## Basic Layout

Drag is pulling an element across the screen.

## Visual Feedback

```
┌─────────────────────────────────────────┐
│  [Element]                              │
│     ↓                                   │
│     ↓                                   │
│     ↓                                   │
│        [Element]                        │
└─────────────────────────────────────────┘
```

## Feedback Options

| Option | Description |
|--------|-------------|
| **Ghost** | Semi-transparent element |
| **Scale** | Enlargement while dragging |
| **Shadow** | Shadow below the element |

## Distance

- Typical: > 10px

## Phases

| Phase | Description |
|-------|-------------|
| **Start** | Drag start |
| **Move** | The element follows |
| **End** | Drop at the new position |
