# Drag

## Description

Drag is pulling an element across the screen.

## Finger Count

1 up to the device limit (typically 5–10 fingers). Several simultaneous
fingers are recognised as one gesture at the centre of all pointers.

## Usage

- Reordering elements
- Scrolling
- Reorder in lists

## Phases

1. Start the touch
2. The element follows
3. Drop at the new position

## Distance

- Typical: > 10px
