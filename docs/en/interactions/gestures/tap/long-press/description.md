# Long Press

## Description

A long press is a sustained touch on the screen.

## Finger Count

1 up to the device limit (typically 5–10 fingers). Several simultaneous
fingers are recognised as one gesture at the centre of all pointers.

## Usage

- Opening a context menu
- Marking
- Drag start

## Duration

- Typical: > 500ms

## Difference from Tap

- Tap: short (< 250ms)
- Long Press: long (> 500ms)
