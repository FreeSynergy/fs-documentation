# Tap

## Description

A tap is a brief touch on the screen.

## Finger Count

1 up to the device limit (typically 5–10 fingers). Several simultaneous
fingers are recognised as one gesture at the centre of all pointers.

## Usage

- Button clicks
- Item selection
- Navigation

## Duration

- Typical: < 250ms

## Difference from Long Press

- Tap: short (< 250ms)
- Long Press: long (> 500ms)
