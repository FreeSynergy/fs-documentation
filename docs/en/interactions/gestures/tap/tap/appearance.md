# Tap - Appearance

## Basic Layout

A tap is a brief touch on the screen.

## Visual Feedback

```
┌─────────────────────────────────────────┐
│                                         │
│     [Click]                             │
│                                         │
└─────────────────────────────────────────┘
```

## Feedback Options

| Option | Description |
|--------|-------------|
| **Ripple** | Ripple wave on touch |
| **Scale** | Slight enlargement |
| **Color** | Color changes |
| **None** | No feedback |

## Duration

- Typical: < 250ms

## Difference from Long Press

- Tap: short (< 250ms)
- Long Press: long (> 500ms)
