# Double Tap

## Description

A double tap is two quick touches in rapid succession.

## Finger Count

1 up to the device limit (typically 5–10 fingers). Several simultaneous
fingers are recognised as one gesture at the centre of all pointers.

## Usage

- Zoom in/out
- Opening elements
- Marking

## Duration

- Between the taps: < 300ms

## Difference from Tap

- Tap: a single touch
- Double Tap: two quick touches
