# Rotate

## Description

Rotate is turning the fingers around a center point - at least two, any number
more.

The number plays no role: with three or five fingers it is the same gesture;
what is evaluated is the change of angle of the pointers to the center.

## Finger Count

From 2 up to the device limit (usually exactly 2); `pointerCount` sets
the minimum.

## Usage

- Rotating images
- Rotating objects

## Direction

- Two or more fingers turn clockwise or counter-clockwise

## Angle

- Typical: > 10° rotation
