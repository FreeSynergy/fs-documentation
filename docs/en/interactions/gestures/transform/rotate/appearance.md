# Rotate - Appearance

## Basic Layout

Rotate is turning the fingers around a center point - at least two, any number
more.

## Visual Feedback

```
┌─────────────────────────────────────────┐
│      ↻                                  │
│    ↻                                    │
│  ↻                                      │
│↻                                          │
└─────────────────────────────────────────┘
```

## Feedback Options

| Option | Description |
|--------|-------------|
| **Angle** | Show angle |
| **Rotate** | Element rotates |
| **None** | No feedback |

## Direction

- Two or more fingers turn clockwise or counter-clockwise

## Angle

- Typical: > 10° rotation

## Direction of Rotation

| Direction | Symbol | Description |
|-----------|--------|-------------|
| Clockwise | ↻ | Clockwise |
| Counter-Clockwise | ↺ | Counter-clockwise |
