# Pinch - Appearance

## Basic Layout

Pinch is pulling the fingers together - at least two, any number more.

## Visual Feedback

```
┌─────────────────────────────────────────┐
│      (  )                               │
│     (    )                              │
│    (      )                             │
│   (        )                            │
└─────────────────────────────────────────┘
```

## Feedback Options

| Option | Description |
|--------|-------------|
| **Zoom** | Show zoom factor |
| **Scale** | Element scales itself |
| **None** | No feedback |

## Direction

- Two or more fingers move towards each other

## Distance

- Typical: > 20px movement

## Zoom Factor

- Typical: 0.5x (halving)
