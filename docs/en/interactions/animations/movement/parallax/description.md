# Parallax

## Description

Parallax moves layers of the same content at different speeds: the background
runs behind the foreground. That creates a spatial impression of depth: flat
content appears staged in layers. The triggers are scrolling, pointer movement
or the tilt of the device.

## Use

- hero header: the image stays behind the text that moves along
- cards that react to pointer movement with a slight displacement
- 2D games and maps with ground, midground and sky
- storytelling: backdrops travel at different speeds while scrolling
- split layouts: the image column slower than the text column
- dialogs: shadow and content react differently to the pointer

## Duration

- Follows the scroll or pointer movement (no fixed duration); transitions
  100–300 ms

## Difference from Stagger and Slide In

- Stagger: several elements make the same movement, only offset in time; Parallax
  gives each layer its own speed.
- Slide In: a single layer moves on entrance; Parallax is always the interaction of
  at least two layers.
