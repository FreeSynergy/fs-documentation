# Bounce Out

## Description

Bounce Out takes an element farewell with a springy motion: it briefly pulls
back in the opposite direction (anticipation/compression), then overshoots and
disappears from the surface. The exit therefore feels markedly more playful
than a plain fade out.

## Use

- remove toasts and badges playfully
- let deleted entries "spring away" out of lists
- gamification: let stars, points and hearts hop away
- close modals with a playful character
- push completed tasks out of checklists
- tidying and clearing actions in learning and children's apps

## Duration

- Typical: 300–500ms (anticipation plus floating away)
- Default value: 400ms
- Keep the anticipation short and subtle, so the disappearance does not feel
  like it blocks

## Difference from Bounce In

- Bounce Out: the element anticipates at the starting position, then leaves it
  and disappears
- Bounce In: the element comes from outside, shoots past the target and settles
  in
