# Zoom Out

## Description

Zoom Out shrinks an element from its full size to a scale close to zero while
fading it out – the counterpart of Zoom In. The element visibly pulls "back"
and disappears.

## Use

- shrink modal dialogs and lightboxes when closing
- let deleted list items shrink together
- close context menus and popovers softly
- let disabled icons disappear while tidying up
- page exit in assistants: the old page shrinks out
- "suck" a minimised window into a dock position

## Duration

- Typical: 150–300ms
- Exits shorter than entrances, so users do not have to wait
- Minimising into a dock/icon position: up to 350ms, since the distance
  travelled is visible

## Difference from Zoom In

- Zoom Out: the scale falls from 1 to close to 0, the element disappears
- Zoom In: the scale rises from below 1 to 1, the element appears
