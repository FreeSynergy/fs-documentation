# Rotate

## Description

Rotate turns an element through a defined angle around its own axis – for
instance a chevron from 0° to 180° – and stays in the new orientation afterwards.
It is a one-time change of state, not a continuous movement.

## Use

- turn the chevron/arrow in an accordion from ▾ to ▴ (180°)
- turn a hamburger menu icon into an X by rotating it
- show the sort direction (ascending ↔ descending, 180°)
- rotate a plus icon into a close icon (45°)
- acknowledge an active/inactive status by rotating an icon
- turn compass and alignment elements further in steps

## Duration

- Typical: 200–500ms per turn
- Icon turns: 180–300ms
- A full 360° turn as an acknowledgement: 400–500ms

## Difference from Spin

- Rotate: a one-time turn to a defined end angle; afterwards the element stands
  still
- Spin: an endless turn without an end angle as an activity or loading indicator
