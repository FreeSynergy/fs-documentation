# Typing

## Description

Typing is the typing indicator: three dots (or bars) move in a wave shape and
show that a chat partner is writing right now. The indicator usually appears in a
small speech bubble above the input field. It disappears as soon as the message
is sent or the typing ends.

## Use

- chats: the responding partner is typing right now
- assistant and AI answers ("thinking")
- comment columns and forums
- group chats with several people writing (several indicators)
- a waiting display in dialogs when the answer is delayed

## Duration

- Typical: 1000–1400 ms per cycle (a loop, for as long as typing continues)

## Difference from Pulse and Glow

- Pulse: a single element swells and shrinks as a whole; Typing is a travelling
  wave of several small dots.
- Glow: a status signal as a glow around a contour; Typing announces a concrete
  next action (an incoming message).
