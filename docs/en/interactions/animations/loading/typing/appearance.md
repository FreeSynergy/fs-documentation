# Typing - Appearance

## Base layout

Three small dots in a speech bubble; the raised dot travels as a wave from left
to right.

## Visual progress

```
┌──────────────────────────────────────────────────────┐
│frame 1         frame 2         frame 3        frame 4│
│                                                      │
│· · ·          • · ·          · • ·          · · •    │
│                                                      │
│the high dot travels left → right (a wave)            │
└──────────────────────────────────────────────────────┘
```

## Variants

| Variant | Description |
|---------|-------------|
| **Wave** | the dots rise one after another (standard) |
| **Blinking** | the dots change their opacity cyclically |
| **Hopping** | the dots briefly skip over their position of rest |
| **Bars** | three bars instead of dots (the "editing" status) |
| **Adapted** | colour and size follow the chat theme |

## Duration

- Typical: 1000–1400 ms per cycle
