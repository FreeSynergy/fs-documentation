# Progress

## Description

Progress makes a measurable advance visible: bars, rings or segments fill up
according to a value between a start and a target. If the target is unknown, the
display runs as an indeterminate loop.

## Use

- uploads and downloads with a percentage
- installations, exports and batch processing
- synchronisation between devices
- how far forms and onboarding steps are filled in
- the progress of a task in lists and tickets
- loading screen when the application starts

## Duration

- Typical: 200–500 ms per change of value, indeterminate loop 1000–1500 ms

## Difference from Skeleton and Spin

- Skeleton: placeholders in the shape of the coming content without a dependable
  numeric value; Progress shows a concrete, quantifiable advance.
- Spin: a pure activity symbol with no statement about amount or pace; Progress
  is only worthwhile when the progress is measurable.
