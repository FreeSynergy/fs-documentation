# Skeleton - Appearance

## Base layout

Grey placeholder shapes (bars, circles, blocks) in the measurements of the later
content, with a light shimmer travelling over them in a loop.

## Visual progress

```
┌──────────────────────────────────────────────────────┐
│cycle 1           cycle 2           cycle 3           │
│                                                      │
│(●) ▓▓▒▒▒▒▒▒     (●) ▒▓▓▓▒▒▒▒     (●) ▒▒▒▒▒▓▓▓        │
│    ▓▓▓▒▒▒▒         ▒▒▓▓▒▒▒▒         ▒▒▓▓▓▒▒▒         │
│                                                      │
│▓ = shimmer   ▒ = base surface   ● = avatar           │
└──────────────────────────────────────────────────────┘
```

## Variants

| Variant | Description |
|---------|-------------|
| **Rows** | text lines of differing width |
| **List** | an avatar circle plus two text bars per row |
| **Card** | an image block, a title line and two text lines |
| **Table** | a header row plus even data rows |
| **Static** | without shimmer, only grey shapes (reduced motion) |

## Duration

- Typical: 1200–1800 ms per cycle
