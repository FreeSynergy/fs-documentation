# Highlight

## Description

Highlight briefly makes the background of an element light up and then fade
away again. The surface stays at its position meanwhile; only the colour
changes in order to direct the eye to a particular place.

## Use

- the found passage after a search in the text
- a jump marker or anchor link in long documents
- a newly inserted entry in a list
- a corrected input field after validation
- the target area in onboarding ("this is where you find the settings")
- a marked area after saving

## Duration

- Typical: 600–1200 ms
- Default value: 900 ms

## Difference from Ripple

- Ripple: a wave with a recognisable origin at the click point, spreading across
  the element
- Highlight: a flat glowing of the entire background without an origin point
- Glow: an endless glow around the contour as a lasting status; Highlight is
  limited in time
