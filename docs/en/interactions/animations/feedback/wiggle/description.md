# Wiggle

## Description

Wiggle makes an element rock back and forth through a small angle (a rotation of
about 1 to 3 degrees). As a rule it signals "editable" or "not yet placed" – unlike Shake it does not
signal "error".

## Use

- edit mode on the home screen (icons rock back and forth)
- selected objects in editors that can be moved
- a hint that a card has not been placed yet
- a provisional or unsaved state
- playful feedback in game-like surfaces
- several objects before moving them together

## Duration

- Typical: 400–800 ms per cycle, usually as an endless loop
- Default value: 600 ms per cycle

## Difference from Shake

- Shake: a horizontal displacement with a large amplitude, once, as an error
  message
- Elastic: a single overshoot past the final position and a spring back, no
  repeated rocking
- Pulse: a change of size or opacity in a cycle, no rotation
