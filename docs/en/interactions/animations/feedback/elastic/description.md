# Elastic

## Description

Elastic performs a movement with overshoot: the element shoots past its target
position and then springs back into it. The movement looks springy and
physical. The target position and the moment of arrival are fixed from the
start.

## Use

- let an element snap into a drop area
- a switch knob that shoots past its final position
- open menu or FAB elements with a springy character
- a slider that snaps into a grid
- let list rows settle softly when reordering
- a button grows springily into its new size

## Duration

- Typical: 400–800 ms (including the decay of the oscillation)

## Difference from Bounce In and Rubber Band

- Bounce In: an entrance with several ground contacts while the element
  appears; Elastic moves an already visible element into a fixed final
  position.
- Rubber Band: the content follows the finger past the edge and only springs
  back after release; Elastic overshoots on its own without any gesture.
