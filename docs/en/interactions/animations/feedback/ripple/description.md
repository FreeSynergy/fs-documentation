# Ripple

## Description

Ripple sends a circular wave out from the point of contact: the circle grows
past the element and dissolves as it does. The animation confirms exactly
where the user triggered something.

## Use

- tap and click feedback on buttons and icons
- confirmation in navigation bars and tabs
- rows in lists and cards on tap
- making the exact touch point visible on large surfaces
- Material-like surfaces as the standard feedback
- confirming a menu entry on a tablet

## Duration

- Typical: 350–600 ms per wave
- Default value: 450 ms per wave

## Difference from Highlight

- Highlight: the background of the entire element lights up evenly, without a
  recognisable origin point
- Pulse: the whole element swells and shrinks periodically; Ripple happens once
  per interaction and is tied to a place
- Elastic: the element itself springs; Ripple only overlays the element with a
  colour
