# Expand

## Description

Expand grows the height (optionally the width) of an element from 0 to its
natural content height. The content keeps its original size and is revealed
step by step.

## Use

- open an accordion entry
- "show more" / collapsible sections
- dropdown and submenu panels
- detail area in lists and tables
- inline help below an input field
- answer area below a question in FAQ lists

## Duration

- Typical: 200–400 ms
- Default value: 300 ms

## Difference from Collapse

- Collapse: opposite direction – the content height is reduced to 0
- Unfold: opens the content out of the plane with 3D perspective; Expand only
  changes the height without rotation
- Slide In: the element glides in from outside into an already existing slot;
  Expand enlarges the slot itself
