# Unfold

## Description

Unfold opens an element like a sheet of paper: the top edge stays anchored, the
rest swings out of the plane into the viewer plane with perspective
(`rotateX`). The result is a spatial folding effect, not a mere change of size.

## Use

- collapsible menu "sheets" and card stacks
- note or postcard aesthetics in onboarding
- collapsible image and quote areas
- paper-like envelopes (invitation, report)
- striking opening sequences in marketing areas
- the envelope of a digital invitation

## Duration

- Typical: 300–600 ms
- Default value: 450 ms

## Difference from Expand

- Expand: a pure height change from 0 to the content height, without rotation
  and without perspective
- Flip: turns the entire element through 180° and shows a different back side
  meanwhile; Unfold only opens part of it and shows the same content
- Slide In: the element only moves; by rotating, Unfold also changes the visible
  height
