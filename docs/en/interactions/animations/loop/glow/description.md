# Glow

## Description

Glow lays a soft, coloured glow around the contour of an element. The shine can
stand constant or slowly swell and shrink. The element itself stays unmoved –
only its surroundings glow.

## Use

- selection in an editor: the marked element glows persistently
- live status: recording, streaming or a connection is active
- presence display: a contact or cursor is active right now
- onboarding: a control is gently emphasised
- dashboards: the active data source stays visibly marked
- selection lists: the active card stands out without a hard frame

## Duration

- Typical: 1000–2000 ms per cycle (endless loop), entry/exit 200–400 ms

## Difference from Pulse and Highlight

- Pulse: the whole body of the element swells and shrinks; Glow moves nothing, it
  changes only the glow around the contour.
- Highlight: a one-time, brief lighting up of the background (e.g. for a found
  passage); Glow lasts for as long as the status (selection, live) persists.
