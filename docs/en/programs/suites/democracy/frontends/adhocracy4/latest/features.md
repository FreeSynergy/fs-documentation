# Adhocracy4 - Features

## Main features

### Phase modules
- Brainstorming (collect ideas), review (editorial check), evaluation/discussion, surveys, **Kiezkasse** (citizens propose investments and vote on a share of the budget)
- Automatic phase changes (by date), project roadmap visible

### Depth of participation
- Comments and ratings with counter, geo-location of ideas (city map), image attachments
- Moderation flow: "under review" and "being implemented" markers — transparency about handover to administration

### Operations
- Multiple organisations (tenant instance), newsletter, import/export (CSV), multilingual support (German first)
- **API** for evaluation dashboards; statistics widgets

## What Adhocracy4 does NOT do

- **no decisions or voting in the sense of elections** (rating ≠ vote; a Kiezkasse "vote" is an opinion poll with contractual binding in real life)
- no delegated votes (liquid model: ❌)
- no pol.is clustering
- setup is Django project work (not a click-together SaaS)
