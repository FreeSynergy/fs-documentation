# Adhocracy4 - Menus

## Participant navigation

| Element | Content |
|---------|---------|
| Projects | Ongoing and completed initiatives (tiles with phase) |
| Project home page | Description, phase overview, map (geo reference!) |
| Module views | Brainstorming (idea list), idea review, evaluations, surveys, Kiezkasse (budget modules) |
| Contribution | Detail with comments, rating (▲/▼), moderation note |
| My area | Own contributions, notifications |

## Moderation and administration

| Area | Content |
|---------|---------|
| Moderation area | Review contributions, marking as "forwarded" (organisation note), delete/block |
| Project administration (operating organisation) | Create projects, phases/timing, module selection, map and Kiezkasse budgets |
| Platform admin | Users, home page, moderator roles |

## Menus by role

Guest (read, per project) → participant (contribute/evaluate) → moderator → project coordinator → admin.
