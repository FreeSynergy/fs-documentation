# Adhocracy4 - Keyboard shortcuts

## Overview

Adhocracy4 has **no documented keyboard shortcuts**.

> Status: A4 4.x/5.x.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Contribution and comment forms |
| `Esc` | Close dialogs |
| `Ctrl/Cmd+F` | Lists (browser) |

## Explicitly not available

- Rating via keyboard shortcut (buttons only)

## Mac

`Cmd` follows browser standards.
