# LiquidFeedback Documentation

## Overview

LiquidFeedback ("LiQu", PHP, free software) implements **delegative voting (liquid democracy)**: initiatives in topic rooms, delegation chains for votes, arguments for and against, votes with quorums. A classic for grassroots organisations and parties.

## File structure

- [menu.md](latest/menus.md) - Rooms, initiatives, delegates, vote tables
- [features.md](latest/features.md) - Delegation logic, initiative phases, what Liquid does NOT do
- [description.md](latest/description.md) - Differentiation from Decidim and Consul (direct vs. delegative)
- [structure.md](latest/layout.md) - Initiative as a three-part layout (proposal / arguments / decision)
- [shortcuts.md](latest/shortcuts.md) - none
- [api.md](latest/api.md) - No public API; database and export routes
