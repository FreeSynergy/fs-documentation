# LiquidFeedback - Description

## What the program does

LiquidFeedback is delegative democracy in practice: members submit motions, discuss them on the basis of arguments and decide — while passing their vote on a topic-by-topic basis to people they trust. It addresses the representation problem of small and medium-sized organisations.

## Advantages

- Delegation chains and counter-initiatives make **interests visible instead of party whipping**
- Tested in parties and associations (the Pirate Party's conventions shaped it)
- Self-hosted, open licence

## Differentiation

| System | Difference |
|--------|-------------|
| **Decidim/Consul** | Public participation (motion catalogue); Liquid is a decision by a governing body |
| **pol.is** | Mass deliberation without motions |
| **Ademeco/other e-voting** | Pure election systems |

## Technical details

- **Stack**: PHP (classic), MySQL; template-based web UI
- **Auth**: Accounts with verification; password hygiene is the organisation's responsibility
- **Licence**: free (Apache); maintenance irregular — check current status

## For whom it is suitable

- Associations and initiatives with statute-bound decision processes
- FreeSynergy skins: the delegation model as an example of voting relations ([models.md](../../../../../../data/models.md))
