# LiquidFeedback - Keyboard shortcuts

## Overview

LiquidFeedback has **no keyboard shortcuts**.

> Status: LiQu 1.x (last maintained version).

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Forms |
| `Ctrl/Cmd+F` | Text pages (browser) |

## Explicitly not available

- Everything else

## Mac

`Cmd` follows browser standards.
