# Pol.is

> Category: [democracy](../../index.md)

## What it is

Pol.is (commercial, with non-profit roots) is the **deliberation scaling platform**: all participants write comments and rate those of others ("agree/disagree/pass") — an algorithm clusters the opinions into groups with border topics. Known from large citizen dialogues.
