# Pol.is - Features

## Main features

- **Mass deliberation**: thousands of participants, comments plus pairwise rating; PCA clustering shows opinion groups (A/B/C…) and **consensus statements** (agreement across groups)
- **Trivia questions** (multiple choice) colour the clusters (e.g. by district)
- Live opinion map and a "what's new" card stack
- Moderation: merge, flag, block; featured comments
- Results exportable; multiplier reports for administration

## What Pol.is does NOT do

- **no motions or decisions** (an opinion picture is not a decision)
- no delegated votes
- **Data API is read-only**; writing only through participant actions (embed)
- moderation needs supervision (trolling remains possible despite clustering)
- operated only by the provider (pol.is) — no self-hosting of hosted conversations (the open-source code exists, but self-operation requires development work)

## Extensions and integrations

| Integration | Route |
|-------------|-----|
| Embed (iframe/JS) in own pages | official |
| Data API (`developers.pol.is`, JSON) | evaluation and dashboards |
