# Pol.is - Menu items

## Participant view (conversation)

| Element | Content |
|---------|---------|
| Input field | Own comment (after a trivia question) |
| Comment cards | Rate: 👍 agree / 👎 disagree / pass — with "important" flag |
| Group chips ("A/B/C…") | Opinion poles with representative statements |
| Opinion map | Scatter of participants (consensus and borders) |

## Organiser and moderation area

| Area | Content |
|---------|---------|
| Create conversation | Questions, trivia (multi-party questions for cluster colouring) |
| Moderation | Merge comments, block, feature |
| Results | Group reports, consensus statements, exports (CSV) |
| Embedding | iFrame/JS embed, domain allowlist |

## Menus by role

Anyone can take part anonymously (with protection against abuse); moderation and organisation require protected accounts.
