# Pol.is - Keyboard shortcuts

## Overview

Pol.is has **no documented keyboard shortcuts** (card buttons replace key commands).

> Status: 2026.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Submit comment |
| `Esc` | Close dialog |
| `Ctrl/Cmd+F` | Browser search |

## Explicitly not available

- Rating via single-letter key (buttons only)

## Mac

`Cmd` follows browser standards.
