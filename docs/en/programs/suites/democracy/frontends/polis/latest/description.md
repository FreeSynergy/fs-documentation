# Pol.is - Description

## What the program does

Pol.is turns participation around: instead of voting, people rate statements made by others — from which opinion groups and surprising consensus emerge automatically. It is the tool for **dialogue formats** ("What moves you?") rather than motion-filing.

## Advantages

- Scales deliberation (hundreds up to 100k participants)
- Shows where camps touch (consensus maps)
- **Low barrier**: one comment is enough to get started

## Differentiation

| System | Difference |
|--------|-------------|
| **Decidim/Consul** | Motion and budget formats; pol.is is an opinion map |
| **Liquid** | Internal decision-making (delegative) |
| **Survey tools** | Predefined questions; pol.is generates them from participants' texts |

## Technical details

- **Model**: SaaS (pol.is); codebase open (historically the polis project)
- **Authentication**: participant identifiers (cookie/IP heuristic), optional login
- **Languages**: multilingual; moderation can be used across languages

## For whom it is suitable

- Large dialogue formats (urban development, consultation procedures) with evaluation resources
- FreeSynergy skins: Data API evaluation as a result widget ([models.md](../../../../../../data/models.md) → cluster and consensus model)
