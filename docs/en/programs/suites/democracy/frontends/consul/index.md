# Consul Documentation

## Overview

Consul ("Decide Madrid" software, Apache-2.0, Ruby on Rails) is the participation platform for municipalities: proposals, participation processes, **citizen budgets**, polls and votes, debates, legislative participation (plus mailing and verification). Operated by many cities worldwide.

## File structure

- [menu.md](latest/menus.md) - Citizen menus, administration and moderation areas
- [features.md](latest/features.md) - Budgets, polls with voting, what Consul does NOT do
- [description.md](latest/description.md) - Differentiation from Decidim and pol.is
- [structure.md](latest/layout.md) - Participation types as tiles, proposal lists
- [shortcuts.md](latest/shortcuts.md) - none
- [api.md](latest/api.md) - REST API (public JSON), OAuth2, webhooks (newer versions)
