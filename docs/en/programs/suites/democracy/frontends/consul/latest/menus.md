# Consul - Menu items

## Citizen area

| Menu | Content |
|------|---------|
| Participation (Participación) | Proposals, processes, campaigns |
| Citizen budget (Presupuestos participativos) | Budget groups → investments with support and voting |
| Consultations and votes | Questions with yes/no/majority, results |
| Debates | Comments with supports |
| Law/Reglamento processes | Draft laws with article comments |
| My account | Verification, notifications, own content |

## Administration (admin console)

| Area | Content |
|---------|---------|
| Participation manager | Create proposals and processes, phases, publish results |
| User manager | Users, verification resources, permission levels (person/verification…) |
| Moderation | Reports, hiding, blocking |
| Settings | Login methods (account and verification levels), voting options, e-mails |

## Menus by role

Administrator · moderator · manager · viewer · user (with verification levels).
