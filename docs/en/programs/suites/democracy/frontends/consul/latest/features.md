# Consul - Features

## Main features

- **Proposals and supports** (thematic, geo-located), linked to processes
- **Citizen budgets**: budget sections, projects with support and a voting phase (count from the top, per section)
- **Consultations and polls**: yes/no and multiple choice, campaigns with timelines
- **Legislative processes**: article numbering with margin comments
- **Participatory panels** (randomly selected groups; check version), debate features
- Verification levels (e.g. age, place of residence), multilingual support (Spanish first, German translation available)

## What Consul does NOT do

- **no delegated voting** (liquid model: ❌)
- no certified e-voting cryptography (polls are opinion and participation surveys; legally binding elections need another tool)
- process-phase model weaker than Decidim (more free-form, less formal)
- admin interface is functional, with a plain Rails look
