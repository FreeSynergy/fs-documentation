# Consul - Keyboard shortcuts

## Overview

Consul has **no documented keyboard shortcuts**.

> Status: Consul 1.3+.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Forms |
| `Esc` | Close dialogs |
| `Ctrl/Cmd+F` | Lists (browser) |

## Explicitly not available

- Command palette / quick jump search

## Mac

`Cmd` follows browser standards.
