# Decidim Documentation

## Overview

Decidim (AGPL, Ruby on Rails) is the platform for **participatory democracy**: processes (citizen budgets, participation, planning), proposals with comments and supports, debates, meetings and events, votes, budgets (participatory budgets), moderation — modular and multilingual. Used by hundreds of cities.
