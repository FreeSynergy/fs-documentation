# Decidim - Description

## What the program does

Decidim structures participation processes the way administrations need them: clearly delimited processes, traceable phases, proposals with supports, and results published as accountability reports. The platform provides the formal framework of participation.

## Advantages

- **Institution-safe** (traceability, moderation, statistics)
- Exemplary open GraphQL API
- Large community, widespread German-language installations

## Differentiation

| System | Difference |
|--------|-------------|
| **Consul** (Consulado) | Similar purpose, different technical setup; Decidim is more process-strict |
| **Liquid Feedback** | Delegative decision-making within groups; Decidim is the process stage |
| **pol.is** | Mass deliberation (spectrum of opinions); Decidim is a structured catalogue |

## Technical details

- **Stack**: Ruby on Rails, PostgreSQL; modules as engines
- **Auth**: Own accounts plus verification workflows (configurable per organisation)
- **Licence**: AGPL; deployment: Docker or Decidim Zoom hosting offers

## For whom it is suitable

- Municipalities and associations with formal participation procedures
- FreeSynergy skins: the process/component model as a template for participatory workflows ([models.md](../../../../../../data/models.md) → proposal/support/phase)
