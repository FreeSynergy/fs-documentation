# Decidim - Keyboard shortcuts

## Overview

Decidim has **no documented keyboard shortcuts** (accessible forms instead of key combinations).

> Status: Decidim 0.27+.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Forms (proposal/comment) |
| `Esc` | Close dialogs |
| `Ctrl/Cmd+F` | Process pages (browser) |

## Explicitly not available

- Command palette / quick jump search

## Mac

`Cmd` follows browser standards.
