# Decidim - Menu items

## Participant view

| Element | Content |
|---------|---------|
| Processes | Participation processes (with phases: discussion → prioritisation → result) |
| My profile | Own proposals, supports, notifications, verification (accounts optional) |
| Components (within a process) | Proposals · debates · meetings · budgets · surveys · blogs · pages · votes |

## Admin console (organisation administrator)

| Area | Content |
|---------|---------|
| Organisation | Users and roles, verification rules (e.g. proof of age), language, topics and categories |
| Processes | Create, plan phases, add components |
| Moderation | Reports, hiding, user blocks (moderator role) |
| Reports | Activities, proposal statistics |

## Menus by role

Participants · moderator (content) · administrator (structure) · developer/technical (instance).
