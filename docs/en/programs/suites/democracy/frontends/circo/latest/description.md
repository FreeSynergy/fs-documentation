# Circo - Description

## What the program does

Circo moderates participation under professional direction: organisers set guiding questions, invited groups discuss and rate, and moderation turns the results into reports. It is the **moderation back end** for consultations where result quality takes priority over open participation.

## Advantages

- Tested in the DACH region, German-speaking service
- Clear phases and reports (usable in committees)
- Protected spaces (by invitation) for sensitive formats

## Differentiation

| System | Difference |
|--------|-------------|
| **pol.is** | Open crowd plus automatic clustering; Circo uses moderated circles |
| **Decidim** | Public procedures; Circo is an accompanying process |
| **Mural/workshop tools** | Visualisation; Circo contribution funnel and reports |

## Technical details

- **Model**: SaaS/operated by the provider; details (server location, licence) are project-specific
- **Authentication**: invitation accounts or SSO per project (ask the provider)
- Documentation deliberately kept sparse (no invented API knowledge)

## For whom it is suitable

- Associations and municipalities with facilitated consultations
- FreeSynergy scenarios: importing result exports into wiki reports
