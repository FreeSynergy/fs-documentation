# Circo - Keyboard shortcuts

## Overview

For Circo, **no keyboard shortcuts are documented**.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Contribution and question forms |
| `Esc` | Close dialogs |
| `Ctrl/Cmd+F` | Lists (browser) |

## Mac

`Cmd` follows browser standards.
