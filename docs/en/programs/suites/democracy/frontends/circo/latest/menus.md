# Circo - Menus

## Participation interface (participants)

| Element | Content |
|---------|---------|
| Project page | Guiding question, phases, join/start |
| Contribution flows | Write statements/ideas; others rate and comment |
| Surveys | Question sheets (scale/selection) |
| Result pages | Published reports per phase |

## Project control (organisers)

| Area | Content |
|---------|---------|
| Create project | Phases (question → collection → evaluation → result), time periods |
| Participants | Invitation lists, access rules (invitation only or open) |
| Moderation | Review and approve contributions, summarise |
| Evaluation | Charts, export (CSV/PDF reports) |

## Menus by role

Organiser · moderation · participants (often invited circles — Circo frequently works **by invitation**, not publicly).
