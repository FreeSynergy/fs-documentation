# Circo - Features

## Main features

- **Structured consultations**: guiding questions → contributions → mutual evaluation → moderated results
- Workshop support (on-site and online combined), invitation circles for committees and associations
- Result reports as PDF or charts (for use in meetings)
- German-speaking support and operation (DACH focus)

## What Circo does NOT do

- **no documented open self-hosting licence** (SaaS/operated by the provider)
- no delegated votes, no elections
- low public visibility of the API: clarify integration as a **project matter** with the provider
- mass dialogue (10k+) as in pol.is is not its strength (invited groups instead)
