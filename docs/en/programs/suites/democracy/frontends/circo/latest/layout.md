# Circo - Structure and UI/UX

## Project funnel

```
Project page (guiding question)
  → Phase 1: write contributions (list or card view)
  → Phase 2: evaluate (symbols per contribution, filter)
  → Phase 3: moderation summaries
  → Result: report page (PDF/download)
```

- Phase banner with progress; contributions in card lists
- Moderation view as a separate layout (organisers only)

## UI/UX

- Sober and functional, German interface texts
- Role permissions hide phases that are not currently relevant

## Interactions

- Create a contribution (short version + detail), ratings with comments
- Drag ordering only by moderators (no free sorting by participants)

## Responsive design

- Responsive; mobile participation intended

## Accessibility

- Standard web; no special shortcuts

## Performance

- Scales with project size (hundreds of contributions are not a problem)
