# EspoCRM - Menu items

## Global menu (left)

| Menu | Content |
|------|--------|
| Dashboard | Portlets (My Pipeline, Due, Activities) |
| Streams | activity-related feed (like a timeline) |
| Calls / Meetings / Tasks / Emails | Activities |
| Leads → convert | convert a lead into account/contact/opportunity |
| Opportunities | Pipeline view + table |
| Accounts / Contacts | main entities |
| (custom) | own entities from the entity manager |

## Record actions (detail page)

Edit · Delete · Follow (subscribe) · Print/Templates (PDF) · Mass Actions (dropdown over lists) · Create related tabs

## Admin menu (⚙)

| Area | Content |
|------|--------|
| User Management | Users, Roles, Teams, Portal Users |
| Entity Management | **Entity Manager** (new entities/fields/relations), layout editor, Formula |
| Customization | Menus, portlets, templates (Handlebars), Maps configuration |
| Workflow | Workflows (triggers/conditions/actions), scheduled jobs, recipes |
| Email | SMTP/IMAP accounts, group mailboxes, mass mail (campaign) |
| System | selection lists, preferences, extension installation, API access |

## Menus by role

Roles define rights per entity and field (portal users: only their own records via the portal).
