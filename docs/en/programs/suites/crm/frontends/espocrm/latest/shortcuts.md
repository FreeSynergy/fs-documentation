# EspoCRM - Keyboard shortcuts

## Overview

EspoCRM documents few shortcuts; quick search and form standards dominate.

> Status: EspoCRM 7.x/8.x.

## Available

| Shortcut | Function |
|----------|----------|
| `Esc` | Close panel/detail, cancel editing — see note |
| `Tab`/`Enter` | Fields/forms |
| `Ctrl/Cmd+F` (detail page) | Browser search on the page |
| `+` button | Create record (keyboard shortcut not documented) |
| List filter by click (no keyboard shortcut) | — |

> Note: No fixed app shortcuts are confirmed in the official forums; some builds offer `Ctrl+K` quick-search-like behavior, status "(not documented)".

## Explicitly not available

- Vim keys, command palette (confirmed)
- Shortcuts for mass actions

## Mac

`Cmd` for browser standards.
