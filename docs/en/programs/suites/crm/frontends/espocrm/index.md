# EspoCRM Documentation

## Overview

EspoCRM is a lean, fast open-source CRM (PHP + Backbone/JS, SPA): leads, opportunities, accounts, contacts and activities — with a graphical entity manager, workflows and a clean REST API. Self-hosting without the bloat.

## File structure

- [menu.md](latest/menus.md) - Global menu, admin menu, record actions
- [features.md](latest/features.md) - Pipelines, portal, workflows, What EspoCRM CANNOT do
- [description.md](latest/description.md) - Differentiation from SuiteCRM, CiviCRM and HubSpot
- [structure.md](latest/layout.md) - SPA with tab navigation, detail page with left/right panels
- [shortcuts.md](latest/shortcuts.md) - Quick search and standard keys
- [api.md](latest/api.md) - REST /api/v1, API token/HMAC, webhooks, metadata capability
