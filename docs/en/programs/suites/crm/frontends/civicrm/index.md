# CiviCRM Documentation

## Overview

CiviCRM is the open CRM for associations, NGOs and clubs ("Constituent Relationship Management"): contacts, donations, memberships, events, campaigns and cases — embedded in a CMS (Drupal, Joomla or WordPress) instead of running as a separate web app.

## File structure

- [menu.md](latest/menus.md) - Civi menu bar in the CMS, contact actions, admin menu
- [features.md](latest/features.md) - Contributions, events, memberships, cases, What CiviCRM CANNOT do
- [description.md](latest/description.md) - Description and differentiation from SuiteCRM, EspoCRM and Salesforce
- [structure.md](latest/layout.md) - CMS embedding, contact page with tabs, search forms
- [shortcuts.md](latest/shortcuts.md) - Keyboard shortcuts (CMS-dependent, none of its own)
- [api.md](latest/api.md) - REST API v3/v4 (`/ajax/api`), keys, entities, webhooks via extensions
