# CiviCRM - Menu items

## Civi menu bar (in the CMS, top)

| Menu | Entries |
|------|----------|
| **Contacts** | New Contact (Individual/Organization/House), Import, Export, Find Contacts, Groups, Search Builder, Advanced Search |
| **Contributions** | New Contribution, Import, Contribution Pages, PCP (Personal Campaign Pages) |
| **Events** | New Event, Event Registration (Backend), Import, Event Templates |
| **Memberships** | New Membership, Membership Types, Status Types, Import |
| **Campaigns** | Campaigns, Petitions, Surveys |
| **Cases** (activatable) | New Case, Case Types, Manager |
| **Grants** (activatable) | Grant Application, Grant Status |
| **Administer** | Customize Data and Screens (Custom Fields), Communications (Mailings, Templates), CiviContribute/CiviEvent/CiviMember settings, Locations, API Explorer, Extensions, Scheduler Jobs |

## Contact page (tabs)

Activities · Mailings · Contributions · Events · Memberships · Relationships · Cases · Grants · Notes · Tags · Custom Fields

Actions menu ("Actions"): Email (Bulk), Print/Email Labels, Add Activity, Add Relationship, Tag, Add to Group, Merge Contacts, Delete, Export

## Menus by role

| Role (CMS permission) | View |
|------------------------|-------|
| authenticated (member portal) | own contributions/registrations (Contribution/Membership Pages) |
| CiviCRM user (basic) | Contacts/Find + own activities |
| Administrator roles | Administer menu (fine-grained via "Access CiviCRM" permissions) |
