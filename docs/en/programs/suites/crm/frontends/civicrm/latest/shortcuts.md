# CiviCRM - Keyboard shortcuts

## Overview

CiviCRM ships **no keyboard shortcuts of its own**; the CMS's and the browser's standards apply.

> Status: CiviCRM 5.x.

## Available

| Shortcut | Function |
|----------|----------|
| `Ctrl+F` | Search on page |
| `Tab`/`Enter` | Forms |
| `Alt+Shift+…` | CMS administration shortcuts (Drupal only, do not affect Civi itself) |
| Autocomplete: 2+ characters | contact/group selection opens suggestions |

## Explicitly not available

- no command palette, no single-key actions ("N" for a new contact does not exist)
- no keyboard handling for tabs (Tab only)

## Mac

`Cmd` with browser standards.
