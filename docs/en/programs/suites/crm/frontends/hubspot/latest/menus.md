# HubSpot - Menu items

## Main navigation (hub switcher at top)

| Hub | Menus (selection) |
|-----|-----------------|
| **CRM** | Contacts, Companies, Deals, Tickets, Tasks, Meetings (meetings tool), Pipelines, Reports |
| **Marketing** | Emails, Campaigns, Forms, Landing Pages, Blog/Content, Automation (workflows), Social, Ads |
| **Sales** | Sequences, Playbooks, Prospects, Quotes, Call logging |
| **Service** | Tickets, Conversations (inbox), Knowledge Base, SLA, Bots |
| **Website** | Pages, Menus, Domain, A/B tests |
| **Operations** | Objects editor, routing, workflows (platform-wide) |

## Record page (e.g. contact)

- Actions: Email, Call, Task, Meeting, edit property, associate (company/deal)
- Tabs: activity timeline, emails, meetings, associated objects, buying signals (plan-dependent)

## Settings (⚙)

| Area | Content |
|------|--------|
| Properties | own fields per object |
| Objects (Pro) | own object types |
| Pipelines & Deals | stages, deal properties |
| Integrations | install apps, **private apps + token**, webhooks |
| Users & Teams | seats, permissions (teams, views) |
| Tracking & Analytics | tracking code, sources, cookies (consent banner) |

## Menus by role

Seats (Marketing/Sales/Service seat) + team rights; contact read/write rights per team view.
