# HubSpot - Features

## Main features

### Free CRM
- Contacts, companies, deals, tasks, tickets — unlimited and free (seat/tool limits apply)
- Email tracking (opens/clicks), calendar scheduling links, inbox for conversations
- List segments, custom properties, associations between objects

### Marketing hub
- Email campaigns, automation workflows (lead routing/enrichment), forms/landing pages, blog CMS, social timing, ads sync
- Lifecycle stages + attribution reports (plan-dependent)

### Sales/service hub
- Pipeline kanban, sequences (multi-touch), quotes
- Tickets, SLA, knowledge base, bots/chatflows

### Platform
- Marketplace apps, **embeddable applications** (own UI inside HubSpot), client-side library for website context

## What HubSpot CANNOT do

- **No self-hosting / unrestricted data export**: data sovereignty only via API/export, SaaS
- **CRM logic without hubs is thin** (workflows from Pro)
- **No deep process modeling** like Salesforce (objects/operations are more expensive)
- **Email sending quotas tied to list/plan** (contact-tier pricing model)
- **ERP functions**: ❌
