# HubSpot - Keyboard shortcuts

## Overview

HubSpot does not document a comprehensive shortcut list; quick search works in many views.

> Status: 2026. Individual bindings depend on the hub.

## Available

| Shortcut | Function |
|----------|----------|
| `Cmd/Ctrl+K` | Global search / "Quick find" (in most hubs) |
| `Esc` | Close dialogs/overlays |
| `Tab`/`Enter` | Forms |
| `Ctrl/Cmd+Enter` | Send email in the editor (status: widespread, not officially listed everywhere) |

## Explicitly not available

- No single-letter actions (create/task via key)
- No macro shortcuts

## Mac

`Cmd` variant dominant; Windows `Ctrl`.
