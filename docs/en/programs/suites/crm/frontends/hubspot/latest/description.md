# HubSpot - Description

## What the program does

HubSpot starts with a free CRM and earns from the hubs: website + forms + emails create contacts that turn into deals in the CRM. Everything runs on one platform — tracking code, consent, forms, inbox, reports.

## Advantages

- **Free entry** with a real CRM (not a demo version)
- **Complete inbound package**: content → lead → deal from one source
- **Simple API v3** (JSON, private app token) for synchronization

## Differentiation

| System | Difference |
|--------|-------------|
| **Salesforce** | process/enterprise platform; HubSpot is marketing-driven and easier to use |
| **Mailchimp** | only campaigns/audiences; HubSpot complements CRM and website |
| **EspoCRM** | own infrastructure/GPL; HubSpot is SaaS with a modular kit |

## Technical details

- **Model**: SaaS; portal ("account") per company, seats per hub
- **Tracking**: JS tag on your own website (cookie/consent management included)
- **Authentication**: email/password, SSO; API: private app token (OAuth2 internally), webhooks signed
- **Pricing**: free → Starter → Professional → Enterprise per hub; contact tiers

## Suitable for

- SMB/B2B teams that combine marketing and CRM without a large admin team
- FreeSynergy skins for contact-deal-pipeline models and consent/tracking fields
