# Twenty - Description

## What the program does
It stores people, companies and deals and lets a team shape its own data model: add objects and fields, build views, automate with workflows.

## Advantages
- Data model changes without leaving the product; same permissions for custom and built-in objects.
- Open source and self-hostable.
- Stack: TypeScript monorepo, NestJS, PostgreSQL, Redis, React (README ✅).

## Differentiation
| System | Difference |
|--------|------------|
| EspoCRM | Entity manager in an admin area; Twenty defines objects also in code. |
| Attio | Commercial, with enrichment; Twenty is open source. |
