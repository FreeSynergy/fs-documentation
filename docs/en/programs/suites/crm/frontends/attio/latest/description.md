# Attio - Description

## What the program does
A team keeps contacts, companies and deals in objects it can reshape, with records enriched automatically and e-mail and calendar history attached.

## Advantages
- Auto-enrichment of records.
- Configurable data model; reports and forecasts; workflows.

## Differentiation
| System | Difference |
|--------|------------|
| Twenty | Open source and self-hostable; Attio is a hosted commercial product. |
| HubSpot | Marketing-first suite; Attio focuses on the data model. |

## Technical details
Hosted only. Open: data sources of enrichment, API limits, privacy terms.
