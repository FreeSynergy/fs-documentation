# Pipedrive Documentation

## Overview

Pipedrive is a cloud-based sales CRM organized around the sales pipeline: deals move through columns (stages) from qualification to closing, supplemented by leads, contacts, organizations, activities and simple automations. Operation and configuration run entirely in the browser; data lives in the Pipedrive cloud.
