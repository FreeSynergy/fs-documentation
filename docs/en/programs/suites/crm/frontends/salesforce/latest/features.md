# Salesforce - Features

## Main features

### Data model and sales
- Standard objects (Account, Contact, Lead, Opportunity, Case, Campaign…) + unlimited custom objects
- Lead conversion, stage paths, products/pricebooks, quotes, forecasts
- Duplicate rules, matching, role hierarchy for data visibility

### Automation
- **Flow Builder** (visual), legacy process builder/workflows, approval processes
- Apex (programming language) + triggers, formula fields, validation rules

### Channels and suites
- Service Cloud (cases, knowledge, omnichannel router), Marketing Cloud Journey (separate), Pardot/Account Engagement, Experience Cloud portals
- AppExchange marketplace (thousands of integrations)

### Analytics
- Reports, dashboards, Einstein (AI forecasts/answers, plan-dependent), CRM Analytics (Tableau stack, extra)

## What Salesforce CANNOT do

- **No self-hosting** — tenant in Salesforce clouds (data regions selectable)
- **No cheap entry-level CRM** (license/add-on costs are structurally high)
- **No customization without a learning curve**: objects/flows need admin know-how
- **Fixed API quotas** (API calls per 24 h per edition) — integrations must cache
- **No real ERP functionality** (invoices/inventory only via add-ons/Commerce Cloud)

## Extensions and integrations

| Integration | Way |
