# Salesforce - Menu items

## Navigation (Lightning)

| Element | Content |
|---------|----------|
| App launcher (waffle) | Apps: Sales, Service, Marketing, own custom apps |
| Tab bar per app | Standard tabs: Accounts, Contacts, Leads, Opportunities, Cases, Reports, Campaigns, Dashboards, Quotes (plan-dependent) |
| Global search + **Action button** | "New…" for all visible objects |
| Chatter feed | collaboration stream |
| Setup (gear) | administration |

## Object detail page

- Header: name, actions (edit, follow, call center, quick actions)
- Path bar (stage track), detail fields, **related lists** (activities, contacts, opportunities…)
- Related lists at the bottom; left/right sidebar (knowledge articles, activities, apps) configurable depending on the page layout

## Setup menu (selection)

| Area | Content |
|------|--------|
| Users / Profiles / Permission Sets | rights model |
| Object Manager | standard/custom objects, fields, page layouts, record types |
| Flow Builder | automation (visual), approval processes |
| Reports & Dashboards | report types, analytics cloud (extra) |
| Data Management | import/export (Data Loader), duplicate rules |
| Platform | Apex classes, Process Builder (legacy), Connect/REST setup, API usage |
| Integration | connected apps (OAuth), identity, single sign-on |

## Menus by license/role

Licenses (Sales/Service/Platform/…) + profiles/permission sets + the role hierarchy determine tabs and data visibility.
