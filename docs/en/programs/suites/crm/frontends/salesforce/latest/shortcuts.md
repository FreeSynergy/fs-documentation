# Salesforce - Keyboard shortcuts

## Overview

Salesforce Lightning documents a small, official shortcut list (help: `Ctrl+/` or `Ctrl+Shift+?` depending on version).

> Status: Lightning Experience (2026).

## Global

| Shortcut | Function |
|----------|----------|
| `Ctrl/Cmd+K` | Focus global search |
| `Ctrl/Cmd+J` | "Action" button (New/Quick Actions) |
| `Esc` | Close modals/dropdowns |
| `Ctrl+/` (or `?`) | Shortcuts overlay |
| `Alt+Shift+←/→` | To previous/next tab |

## On lists

| Shortcut | Function |
|----------|----------|
| `N` | New record (in lists with key support; otherwise the Action button) — depends on status |
| `Click on column header` | Sort (no key) |

## Record detail

| Shortcut | Function |
|----------|----------|
| `Tab` | To actions/fields |
| `Enter` in edit mode | Save |

## Explicitly not available

- Freely assignable Vim maps (only retrofittable via a browser extension)

## Mac

All `Ctrl` keys become `Cmd`.
