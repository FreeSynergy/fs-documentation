# Salesforce Documentation

## Overview

Salesforce is the leading commercial CRM platform (SaaS): leads, accounts, contacts, opportunities and dozens of clouds (Service, Marketing, Commerce, Analytics) on a modelable data core (standard + custom objects). Skin-relevant: REST/Tooling API, Metadata API, Apex ecosystem.

## File structure

- [menu.md](latest/menus.md) - App launcher, tabs, object lists, setup menu
- [features.md](latest/features.md) - Objects, flows, reports, What Salesforce CANNOT do
- [description.md](latest/description.md) - Differentiation from HubSpot, EspoCRM, Odoo
- [structure.md](latest/layout.md) - Lightning layout, sidebar, related lists
- [shortcuts.md](latest/shortcuts.md) - Documented Lightning shortcuts
- [api.md](latest/api.md) - REST/SOAP/Bulk/Metadata, OAuth2, limits
