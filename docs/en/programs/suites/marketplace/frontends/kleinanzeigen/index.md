# Kleinanzeigen Documentation

## Overview

Kleinanzeigen (formerly eBay Kleinanzeigen, Nowint/AVENUE A) is the largest **regional classifieds marketplace** in Germany: private and commercial providers post ads with a local reference, communicate via messages, and handover is usually local ("pickup"). An important reference for local offer skins, **without a public API**.
