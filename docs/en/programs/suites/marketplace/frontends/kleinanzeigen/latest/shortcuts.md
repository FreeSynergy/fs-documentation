# Kleinanzeigen - Keyboard shortcuts

## Overview

Kleinanzeigen has **no keyboard shortcuts** (app-oriented).

> As of: 2026.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Ad/chat forms |
| `Esc` | Close overlays |
| `Ctrl/Cmd+F` | Web views (browser) |

## Mac

`Cmd` for browser standards.
