# Kleinanzeigen - Menu items

## End-user app/web

| Element | Content |
|---------|--------|
| Category tree | household appliances, furniture, jobs, apartments, leisure… |
| Search/radius | keyword + radius/radius map |
| "+ Create ad" | category, title, description, photos, price, location, pickup/shipping |
| Messages | chat per inquiry (with sharing of payment/handover links) |
| My area | active ads, search alerts, favorites, safety notices |

## Commercial areas

| Area | Content |
|---------|--------|
| Business account | brand/dealer profiles, volume packages |
| Partner import | for large dealers: **cooperation feeds** (only under a contractual relationship) |

## Menus by role

Private users · commercial users (verified accounts) · moderation (internal to the platform).
