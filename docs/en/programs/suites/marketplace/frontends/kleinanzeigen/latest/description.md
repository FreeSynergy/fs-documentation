# Kleinanzeigen - Description

## What the program does

Kleinanzeigen is the digital village market: ads with location, chat, handover around the corner. As a marketplace reference, it stands for **local C2C brokerage without payment and logistics complexity** and for the boundary of "a platform without an API".

## Advantages

- largest local reach in Germany
- no barriers for private users
- map/radius logic as a blueprint for Standpunkte skins

## Distinction

| System | Difference |
|--------|-------------|
| **eBay** | shipping/auction/payment layer + APIs |
| **Etsy** | curated maker world |
| **Sharetribe/Arcemall** | own marketplace with an API instead of a third-party platform |

## Technical details

- **Model**: SaaS app (Nowint/AVENUE A), web + iOS/Android
- **Authentication**: account (phone/email verification)
- **Interface situation**: no open API → automation only via partner programs

## Suitable for

- community projects that maintain local offers **on** the platform (manually) — do not automate
- FreeSynergy skins: rebuild the category/radius model ([standpunkte.md](../../../../../apps/maps/standpunkte.md))
