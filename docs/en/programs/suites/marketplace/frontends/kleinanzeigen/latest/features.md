# Kleinanzeigen - Features

## Main features

- **Local reach**: location/radius, map view, pickup logic (shipping optional with "Safe payment" escrow)
- Straightforward ad creation (photos from a phone), search alerts, favorites
- Trust layer: verifications, message chats, reporting/moderation system, fraud warnings
- Categories mixing used goods and services (including apartments/jobs)

## What Kleinanzeigen cannot do

- **no public API** for automation (scraping contradicts the terms of service; not recommended)
- no auctions/price proposals; payment processing only as an optional platform feature
- no shop/inventory management for providers (ads only)
- data export for normal users is limited (GDPR access channels)

## Extensions and integrations

| Integration | Path |
|-------------|-----|
| Commercial partner feeds | contractual relationship (marketer) |
| "Safe payment" | internal escrow integration |
| App notifications (push) | standard |
