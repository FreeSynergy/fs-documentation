# Arcemall - Features

## Main features

- Modelable marketplace types (products, services, rentals, appointments)
- Map/region search, booking calendar, reviews, provider profiles
- Payment flows with split (provider/platform) via Stripe
- API/webhook access for own frontends and integrations; templates speed up the start

## What Arcemall cannot do

- **no huge feature register** like eBay (auctions/buyer protection empire); it is a platform for **building**, not a super-marketplace
- less mature ecosystem/community than Sharetribe (younger project)
- deep warehouse/shipping logistics: limited (focus on brokerage)
- documentation and details change; verify the API status before project start

## Extensions and integrations

| Integration | Path |
|-------------|-----|
