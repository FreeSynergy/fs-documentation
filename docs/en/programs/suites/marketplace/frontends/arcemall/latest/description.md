# Arcemall - Description

## What the program does

Arcemall wants to be a marketplace kit: instead of starting from scratch, you model listings, bookings, payments and search in a low-code environment and get API and UI building blocks for them. It is aimed at initiatives that want their **own** marketplace (regional, thematic).

## Advantages

- own-your-data approach (open-source core, self-hostable; check deployment models)
- modelability beats the rigid configuration corset of Sharetribe
- map/geo search built in (FreeSynergy connection)

## Distinction

| System | Difference |
|--------|-------------|
| **Sharetribe** | mature SaaS convenience; Arcemall offers more flexible modelling |
| **CS-Cart MV** | shop world (products/shipping); Arcemall brokerage logic |
| **eBay/Etsy** | existing marketplaces (external rules) |

## Technical details

- **Model**: platform + self-hosted instances depending on licensing path (verify current status)
- **Payments**: Stripe Connect pattern
- **Documentation situation**: deliberately kept brief; verify detailed APIs in the project

## Suitable for

- FreeSynergy-adjacent projects with a wish for their own marketplace and IT resources
- Skins: model editor pattern for own listing models ([models.md](../../../../../../data/models.md))
