# Arcemall - Menu items

## End-user page (example marketplace)

| Element | Content |
|---------|--------|
| Search/map view | listings in region/category |
| Listing details | description, price/booking, provider profile, reviews |
| Account | my listings, bookings, chat |

## Operator editor (low-code)

| Area | Content |
|---------|--------|
| Model editor | entity types (Listing, Booking, User), fields, relations |
| UI editor | page components (lists, cards, forms) |
| Payment/process editor | payment flows (Stripe), transaction steps |
| Integrations | API keys, webhooks, importers |

## Menus by role

Operator (editor) · Provider (listings) · Customer (search/booking). Roles can be defined in the model editor.
