# Arcemall Documentation

## Overview

Arcemall is a **low-code platform for your own marketplaces** (open-source approach): marketplace models (products/services, bookings, payments, search/map) are built with own-code components and templates. A younger project with an API focus.

> Documentation situation is thin: API details are only described as officially published; everything else is marked "verify current status".
