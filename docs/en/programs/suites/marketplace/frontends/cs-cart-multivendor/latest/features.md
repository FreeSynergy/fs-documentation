# CS-Cart Multi-Vendor - Features

## Main features

- **Real shop engine** with multivendor: product management per merchant, approval workflows, commission/fee models, payout reports
- Shipping/payment add-ons (PayPal, Stripe, DHL shipping labels), stock logic, B2B modules
- Multiple frontends (multi-storefront), SEO equipment, theme system
- **REST API** (products, orders, categories…) for ERP/CRM sync

## What CS-Cart Multi-Vendor cannot do

- **no rental/appointment logic** (booking processes à la Sharetribe only via add-ons)
- license costs plus add-on costs (not a free product)
- auction mechanics missing
- self-hosting requires operation (PHP/MySQL stack)

|-------------|-----|
