# CS-Cart Multi-Vendor - Description

## What the program does

CS-Cart Multi-Vendor turns a fully fledged shop into a marketplace: many merchants sell through a shared storefront with their own product management; the operator collects commissions and keeps control over the catalog and legal compliance.

## Advantages

- **shop maturity** (stock, shipping, checkout) that pure brokerage platforms lack
- API available for ERP integration
- DE add-ons (legal, shipping) available

## Distinction

| System | Difference |
|--------|-------------|
| **Sharetribe** | focus on services/rentals |
| **WooCommerce + WC Vendors** | WP tinkering, can be started for free |
| **eBay** | rent a marketplace instead of owning one |

## Technical details

- **Stack**: PHP/MySQL, self-hosted or CS-Cart Cloud
- **Authentication**: backend logins; API: API keys (admin per scope)
- **License**: commercial (annual/permanent)

## Suitable for

- merchant alliances/traders who want to sell **goods** online together
- FreeSynergy scenarios: product/order sync with ERP skins (Odoo/ERPNext adapter)
