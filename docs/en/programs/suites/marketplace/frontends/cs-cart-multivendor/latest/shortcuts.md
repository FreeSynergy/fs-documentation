# CS-Cart Multi-Vendor - Keyboard shortcuts

## Overview

No keyboard shortcuts are documented for CS-Cart.

> As of: CS-Cart 4.18+.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Product/order forms |
| `Esc` | Close popups |
| `Ctrl/Cmd+F` | Lists (browser) |

## Explicitly not available

- Command palette/jump search

## Mac

`Cmd` for browser standards.
