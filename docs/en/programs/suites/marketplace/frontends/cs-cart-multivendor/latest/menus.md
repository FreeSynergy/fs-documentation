# CS-Cart Multi-Vendor - Menu items

## Admin center (marketplace operator)

| Area | Content |
|---------|--------|
| Sellers | create/activate merchants, contracts/commission schemes |
| Catalog | categories, attributes, product approval workflows |
| Orders | central order management, split per merchant |
| Finances | payouts to merchants, fees, taxes |
| Add-ons | Add-on marketplace (shipping/payment extensions) |

## Merchant dashboard

| Menu | Content |
|------|--------|
| Products | create (variants/stock), import (CSV) |
| Orders | own orders, shipping status |
| Finances | revenue, payout report |
| Shop design | own merchant storefront page (vendor design tools) |

## Customer frontend

Categories/search, product pages with "Sold by" display, cart (multi-vendor split), checkout with payment gateways.

## Menus by role

Admin · Merchant (with rights) · Customer · Guest.
