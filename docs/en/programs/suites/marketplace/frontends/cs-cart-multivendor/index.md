# CS-Cart Multi-Vendor Documentation

## Overview

CS-Cart Multi-Vendor (commercial software, PHP) turns a shop into a **marketplace with many vendors**: products, stock, shipping, payment gateways, vendor commissions, admin consoles. Classic e-commerce approach (vs. brokerage marketplaces such as Sharetribe).

## File structure

- [menu.md](latest/menus.md) - Admin, merchant and customer menus
- [features.md](latest/features.md) - Multivendor logic, add-ons, what CS-Cart MV cannot do
- [description.md](latest/description.md) - Distinction from Sharetribe/Arcemall/WooCommerce MV
- [structure.md](latest/layout.md) - Shop frontend, vendor dashboard, admin center
- [shortcuts.md](latest/shortcuts.md) - none
- [api.md](latest/api.md) - REST API (products/orders etc.), API keys
