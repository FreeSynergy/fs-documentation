# CS-Cart Multi-Vendor

> Category: [marketplace](../../index.md)

## What it is

CS-Cart Multi-Vendor (commercial software, PHP) turns a shop into a **marketplace with many vendors**: products, stock, shipping, payment gateways, vendor commissions, admin consoles. Classic e-commerce approach (vs. brokerage marketplaces such as Sharetribe).
