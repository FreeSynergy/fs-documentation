# eBay - Menu items

## Buyer side

- Search bar + filters (price/condition/location/shipping)
- Product detail: price format, shipping, ratings, "Buy It Now"/price proposal
- My eBay: purchases, messages, ratings

## Seller side (Seller Hub)

| Area | Content |
|---------|--------|
| Create listings | form or **File Exchange/CSV**, templates |
| Active sales | price/actions (end, revise) |
| Outgoing orders | payment/shipping status, shipment tracking |
| Finances | fees, payouts (managed payments) |
| Marketing | promotions, shipping discounts |
| Settings | business information, payment policies, API keys (Developer Portal separately) |

## Developer Portal (developer.ebay.com)

- Create apps (OAuth2), API catalog (Sell, Browse, Inventory, Fulfillment, Marketing), test OAuth keys

## Menus by role

Guest · Buyer · Seller (business/private) · PowerSeller; API rights depend on app approval.
