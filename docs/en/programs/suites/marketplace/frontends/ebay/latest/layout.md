# eBay - Structure and UI/UX

## Layouts

```
Search: result list (tiles: price format, shipping, distance to location)
Listing: image gallery · price/auction timer · seller card ·
         shipping/return blocks · ratings
Seller Hub: side menu · dashboards (revenue/open orders) ·
         tables with bulk actions
```

## UI/UX

- functional, information-dense (price formats/timers dominate the listing)
- Mobile app with bottom-bar navigation (search/sell/messages)

## Interactions

- watch/best offer as buttons; sellers: accept/decline price proposals
- Seller Hub: checkbox bulk actions (end/extend/price change)

## Responsive design

- Web is responsive; apps are fully functional (in-app purchase/listing basis)

## Accessibility

- standard web; timer as a live element (screen reader hints provided by the vendor)

## Performance

- search results fast; Seller Hub tables use large-account cursors
