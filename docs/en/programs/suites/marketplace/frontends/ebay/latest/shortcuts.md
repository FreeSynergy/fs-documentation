# eBay - Keyboard shortcuts

## Overview

eBay does not document **keyboard shortcuts** for web/app.

> As of: 2026.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Search/listing forms |
| `Esc` | Close overlays |
| `Ctrl/Cmd+F` | Browser search |

## Explicitly not available

- Speed keys for buying/bidding (deliberately, to prevent accidental input)

## Mac

`Cmd` for browser standards.
