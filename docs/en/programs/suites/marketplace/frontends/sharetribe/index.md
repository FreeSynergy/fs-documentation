# Sharetribe Documentation

## Overview

Sharetribe is the leading **marketplace software**: open source (a marketplace you build yourself, Ruby on Rails; "Sharetribe Flex": API-first with web app/Marketplace Console) as well as SaaS versions (Sharetribe One/Go for beginners). With it, you run your own C2C/service marketplaces: listings, browsing/map, bookings/orders, payments (Stripe), reviews.
