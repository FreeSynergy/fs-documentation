# Sharetribe - Keyboard shortcuts

## Overview

Sharetribe has **no documented keyboard shortcuts**.

> As of: 2026.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Search/listing forms |
| `Esc` | Close modals (calendar) |
| `Ctrl/Cmd+F` | Browser search |

## Explicitly not available

- Command palette/jump search

## Mac

`Cmd` for browser standards.
