# Sharetribe - Menu items

## Marketplace UI (end users)

| Element | Content |
|---------|--------|
| Search | keyword, categories, **map** (radius), price/date filters |
| Listing detail | description, prices/variants, reviews, "Inquire/Book" button |
| Profile | offers ("My listings"), inquiries, reviews, payouts |
| Messages | chat between provider and customer (per transaction) |
| Account | payments (Stripe account), verification, notifications |

## Operator console (Console)

| Area | Content |
|---------|--------|
| Branding/design | colors, logo, landing page |
| Marketplace content | categories, search texts, email texts |
| Transactions | process type (pre-booking/purchase/inquiry), pricing rules |
| Analytics | traffic, transactions (newer versions) |
| Developers | **create API client**, webhooks, marketplace API |

## Menus by role

Unregistered (search) · user (inquire) · provider (list + chat) · admin (Console).
