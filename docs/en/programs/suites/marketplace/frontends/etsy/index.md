# Etsy Documentation

## Overview

Etsy (publicly listed) is the curated marketplace for **handmade goods, vintage and design**, including digital products. Automation via **Open API v3** (OAuth2, REST): listings, orders, shops, reviews, subject to an approval process.

## File structure

- [menu.md](latest/menus.md) - Buyer/seller interfaces, API registration
- [features.md](latest/features.md) - Curation, digital products, shop extras, what Etsy cannot do
- [description.md](latest/description.md) - Distinction from eBay/Kleinanzeigen
- [structure.md](latest/layout.md) - Shop page, listing editor, stats
- [shortcuts.md](latest/shortcuts.md) - none
- [api.md](latest/api.md) - Open API v3 (OAuth2 PKCE), endpoints, limits
