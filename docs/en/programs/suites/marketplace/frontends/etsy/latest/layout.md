# Etsy - Structure and UI/UX

## Layout

```
Listing: gallery (left) · purchase block (right: variants, quantity,
         note field, shipping) · shop info + reviews below
Search:  filter bar left (material, occasion, price, location)
Shop manager: side menu · listings table (preview+status) ·
         orders with detail drawer (messages/addresses)
```

## UI/UX

- light, image-centered marketplace look; personalization hints prominent
- mobile app for shopping + "Sell Manager" (manage orders on mobile)

## Interactions

- variant picker, note field for unique items; cart coupons
- Sellers: bulk status changes (active/vacation mode), variant templates

## Responsive design

- responsive; app is strong (Etsy focuses on mobile shopping)

## Accessibility

- standard web; alt text required for listing images (seller obligation)

## Performance

- image CDN; search filters tightly integrated client- and server-side
