# Etsy - Features

## Main features

- **Curated marketplace**: handmade/vintage/design plus digital download items, material/occasion taxonomy for discovery
- Shop management with variants, personalizable listings (note field at checkout), coupon/sale promotions
- Reviews, favorite lists, gift guides
- **Open API v3**: listings (r/w), receipts (orders), shop statistics, reviews; app approval process (non-commercial vs. commercial)

## What Etsy cannot do

- **no auctions/price proposals**
- app write access only with an approved app/scopes; no marketplace community features via API
- no complex inventory management (batches/production only rudimentary)
- fee and policy regime is fixed; account suspensions are strict

## Extensions and integrations

| Integration | Path |
|-------------|-----|
| Open API v3 (OAuth2) | official (app acceptance) |
| Printful/print-on-demand apps | official partners |
| Accounting exports (CSV) | standard |
