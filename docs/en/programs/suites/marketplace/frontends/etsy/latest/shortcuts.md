# Etsy - Keyboard shortcuts

## Overview

Etsy does not document **keyboard shortcuts**.

> As of: 2026.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Purchase/listing forms |
| `Esc` | Close overlay (search suggestions) |
| `Ctrl/Cmd+F` | Pages (browser) |

## Explicitly not available

- Speed keys

## Mac

`Cmd` for browser standards.
