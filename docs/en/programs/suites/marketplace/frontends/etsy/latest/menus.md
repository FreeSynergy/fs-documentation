# Etsy - Menu items

## Buyer side

- Search/filter (category, material, occasion, price, location)
- Listing page: images/videos, variants, shipping, shop card, reviews
- "Favorite lists", messages, purchases/downloads (digital)

## Seller side (Shop Manager)

| Area | Content |
|---------|--------|
| Listings | create (variants, tags, materials), templates |
| Orders | orders, labels (shipping), messages |
| Finances | fees, payouts |
| Shop statistics | visits, conversion, SEO hints |
| Shop settings | banner/about, vacation mode, payment methods |
| Apps/API | connected third-party apps (API use runs via registered apps) |

## Developer (developers.etsy.com)

- Register app (API key + OAuth2 PKCE), scopes (`email_r`, `listings_r`, `listings_w`, …), approval rules

## Menus by role

Guest · Buyer · Seller · API app (scope-based).
