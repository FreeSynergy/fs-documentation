# Marketplaces

## Overview

Marketplaces are platforms on which **different people and organizations** offer things to each other, like eBay or Etsy, **not** like a shop of your own. The category covers both marketplace software (with which you can run a marketplace yourself) and existing marketplaces that you connect to via API.

## Available systems

- **sharetribe** - open-source marketplace software (local/service marketplaces)
- **arcemall** - marketplace kit
- **cs-cart-multivendor** - multivendor extension for e-commerce
- **ebay** - global C2C/B2C marketplace
- **etsy** - marketplace for handmade and design goods
- **kleinanzeigen** - regional classifieds marketplace (DE)
