# ERPNext - Keyboard shortcuts

## Overview

Frappe/ERPNext documents only a few, but important, shortcuts.

> As of: ERPNext 15 (Frappe 15).

## Available

| Shortcut | Function |
|----------|----------|
| `Ctrl/Cmd+G` | "Go to" palette (doctypes/menu) |
| `Ctrl/Cmd+S` | Save document |
| `Esc` | Close dialog/dialog box |
| `Tab`/`Enter` | Field navigation |
| `↑↓` (list) | Record navigation — check current state |

## Explicitly not available

- single-letter module jumps; no `?` overview everywhere

## Mac

`Cmd` instead of `Ctrl`.
