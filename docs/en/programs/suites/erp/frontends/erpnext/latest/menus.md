# ERPNext - Menu items

## Desk navigation

| Element | Content |
|---------|--------|
| Search palette (`Ctrl+G`/search field) | "Go to": doctypes, lists, reports, settings |
| Workspaces (left) | Modules as cards: Accounting, Selling, Buying, Stock, Manufacturing, HR, Projects, Quality |
| List view | Filters, tags, bulk "Actions", report links |
| Form collection | Cycle status path (e.g. Quotation→Sales Order→Delivery→Invoice), links at bottom |

## Setup menus

| Menu | Content |
|------|--------|
| Settings (per module) | Company structure, chart of accounts, serial number rules |
| Users & Permissions | Roles ("Sales Manager"…), user rules |
| Developer tools (enable once) | Doctype designer, webhooks, print formats, server scripts, scheduler tasks |

## Menu by role

Standard roles (Website Visitor → Guest → Employee → Module Manager); API access via the roles of the API user.
