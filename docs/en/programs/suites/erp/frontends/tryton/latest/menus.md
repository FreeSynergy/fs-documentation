# Tryton - Menu items

## Module trees (client, left)

| Module | Content |
|-------|--------|
| Accounting | Parties (customer/supplier), journals, accounts, invoices, payments |
| Sale | Quotations, sales, sale configuration |
| Purchase | Purchase orders |
| Stock | Warehouses, moves, inventory, production (module) |
| Project/Time | Projects, timesheets, working times |
| CRM | Leads, activities (module) |
| Analytics | Timesheet analyses, reports |

## Settings (⚙)

| Area | Content |
|---------|---------|
| Configuration (per module) | Charts of accounts, series/sequences, tax rules, shipment/invoice approvals |
|administration | Users, groups (record rules), read models/fields |

## Clients

| Client | Character |
|--------|-----------|
| Tryton desktop (GTK) | full feature set, offline buffering |
| Web client (trytond-web) | lighter, integrated in the server |

## Menus by role

Record rules + field rights; group-based (e.g. `account.group_account_invoice`).
