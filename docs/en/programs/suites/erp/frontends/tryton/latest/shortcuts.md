# Tryton - Keyboard shortcuts

## Overview

The desktop client uses GTK standard keys plus Tryton's own (visible in menus).

> As of: Tryton 7.x.

## Available (desktop)

| Shortcut | Function |
|----------|----------|
| `Ctrl+S` | Save record |
| `Ctrl+N` | New record (list/form) |
| `F5` | Refresh list |
| `F2` (list) | Open form / edit field |
| `Esc` | Cancel editing |
| `Tab`/`Shift+Tab` | Fields |
| `Ctrl+Shift+C` | Client settings — check current state |

## Web client

Reduced to standard form behaviour.

## Mac

Linux-first; GTK keys without `Cmd` equivalents.
