# Tryton Documentation

## Overview

Tryton (GPL, Python) is the calm, modular ERP for technical users: modules for accounting, sales, purchasing, warehouse, projects, time tracking — with strong data integrity, a desktop client (GTK) and a web client. RPC interface lean and stable.

## File structure

- [menu.md](latest/menus.md) - Module trees, settings, Tryton client vs. web UI
- [features.md](latest/features.md) - Module landscape, workflow field logic, what Tryton cannot do
- [description.md](latest/description.md) - Differentiation from Odoo, ERPNext, GnuCash

- [shortcuts.md](latest/shortcuts.md) - GTK standard keys
