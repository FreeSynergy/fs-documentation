# Axelor - Keyboard shortcuts

## Overview

Axelor does **not document any shortcuts**; navigation is via menus/search.

> As of: Axelor Open Suite 8.x.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Form fields |
| `Esc` | Close popups/pickers |
| `Ctrl/Cmd+F` | Browser search in grids |

## Explicitly not available

- no command palette, no save key

## Mac

`Cmd` for browser standards.
