# Axelor - Features

## Main features

### ERP modules
- Standard chain CRM→quote→order→invoice, stock (multi-warehouse), MRP manufacturing, account (multiple journals), HR (expense/leave/timesheet), projects

### Low-code/BPM (core differentiator)
- **App Builder**: models + views + menus without deployment; **BPM designer** (BPEs, tasks, mail actions) with responsibilities
- Action runner/dashboards via configuration

### Technology
- Automatic REST per model (`/ws/rest/partner`, `/ws/rest/saleOrder`…), JSON batch, workflow triggers via API
- Reports (Jasper Reports), DMS/document modules

## What Axelor cannot do

- **Community smaller** than Odoo — add-on market limited
- **UX takes getting used to** (builder mindset, French-influenced history)
- **GoBD/German localisation** only partly (check community modules)
- No large-scale SaaS operation like Odoo Online; Axelor Cloud is smaller

## Extensions and integrations

| Integration | Route |
|-------------|-----|
| REST per model + BPM actions | official |
| Java modules extensible in the core | developer route |
| Axelor Store | commercial add-on modules |
