# Axelor Documentation

## Overview

Axelor Open Suite (AGPL, Java) combines ERP (CRM, Sales, Purchasing, Stock, Manufacturing, Account, HR, Project) with **low-code/BPM**: forms, models and workflows are modelled in the "App Builder"; REST endpoints are generated automatically.

## File structure

- [menu.md](latest/menus.md) - App menus, App Builder, BPM designer
- [features.md](latest/features.md) - App builder, BPM/workflow, what Axelor cannot do
- [description.md](latest/description.md) - Differentiation from Odoo, ERPNext, Bonita
- [structure.md](latest/layout.md) - Grid/form/kanban, dashboards, workflows
- [shortcuts.md](latest/shortcuts.md) - Keyboard shortcuts (barely documented)
- [api.md](latest/api.md) - REST `/ws/rest/<model>` (Basic/JWT), batch, workflow actions
