# Sage Documentation

## Overview

"Sage" is a commercial suite group (Sage Group) for accounting/ERP: **Sage Business Cloud** (SaaS accounting, successor to Sage One, for example), **Sage 100** (mid-market ERP, on-premise), **Sage X3** (large mid-market), and in Germany additionally **Sage 50** (finance/payroll). API access varies strongly per product — documented here as a collective skin with clear references.
