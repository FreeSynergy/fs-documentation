# Sage - Menu items

## Product landscape (important for menus)

| Product | Character |
|---------|-----------|
| Sage Business Cloud (accounting/CRM) | SaaS web menus: sales, purchases, bank, reporting |
| Sage 50 (DE) | Windows application: financial posting, fixed assets, finance, fixed assets, payroll as Windows modules |
| Sage 100 | Module ERP: inventory/merchandise management/accounting/production as window applications with a navigation tree |
| Sage X3 | Web-based modules (FIN, PUR, SAL, INV) with start pages/KPI tiles |

## Typical menu structure (all products)

- **Master data**: customers, suppliers, items, chart of accounts
- **Transactions**: quotes/orders/invoices, posting batches
- **Evaluations**: reports, journals, "My reports"
- **Administration**: users/rights, print/e-mail profiles, import interfaces

## Menus by role

Roles model-based (Sage 100: "groups/functions"; Cloud: plan tiers); German versions with tax/GoBD menu items.
