# Sage - Features

## Main features (per product)

### Sage Business Cloud
- Online accounting: invoices, quotes, payments, bank feeds, VAT returns (country-dependent), light CRM (product variants change!)
- REST API + webhooks for the Cloud products (developer.sage.global)

### Sage 50 / Sage 100 / Sage X3 (relevant for DE)
- Financial accounting with GoBD exports, fixed assets, dunning; 100/X3 with inventory/merchandise management, manufacturing, multi-site
- Interfaces: file/DB interfaces, Sage 100 "connectors", X3 REST APIs (version-specific!)

## What Sage cannot do

- **No uniform product** — "the Sage API" does not exist; each line has its own interface/licence
- **Open source/self-hosting: no** (commercial, licence required)
- **Modern UI throughout**: Windows legacy in 50/100
- FreeSynergy-side skin tinkering is limited (vendor-dependent SDKs)
