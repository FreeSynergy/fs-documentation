# Sage - Description

## What the program does

Sage is the classic of commercial business software: accounting and ERP products for self-employed people up to the mid-market, in the market for decades, with a strong channel (tax advisers/IT partners). FreeSynergy documents Sage as a **reference suite with a heterogeneous API landscape** — planning before integration is mandatory.

## Advantages

- **German legal certainty** (GoBD, procedural documentation, DATEV bridges)
- Product ladder 50→100→X3 for growth
- Large support/partner structure

## Differentiation

| System | Difference |
|--------|-------------|
| **DATEV** | tax adviser platform; Sage = company accounting with input-tax operation |
| **Lexware** | SME comfort SaaS; Sage broader (100/X3) |
| **Odoo/ERPNext** | open customisation; Sage vendor specifications |

## Technical details

- **Models**: SaaS (Business Cloud), on-premise (50/100/X3 incl. databases SQL/Progress depending on product)
- **Authentication**: Sage account (Cloud), Windows/DB user (on-premise); API: OAuth2 (Cloud), product-specific otherwise
- **Pricing**: subscription (Cloud) / licence + maintenance (on-premise)

## For whom it is suitable

- Companies with tax adviser connection and compliance obligations
- FreeSynergy scenarios: Sage as accounting backend behind open CRM/project skins (export chains instead of live API where necessary)
