# Sage - Keyboard shortcuts

## Overview

Shortcuts are **product-specific**; Windows products have classic function/navigation keys.

> As of: 2026, check per version.

## Sage 50/100 (Windows) — typical

| Shortcut | Function |
|----------|----------|
| `F2`/`F4` | Field help/search (depending on document) |
| `Esc` | Cancel entry |
| `Tab`/`Shift+Tab` | Fields |
| `Ctrl+D` | Print dialog (mask) — check current state |
| Function tree | via Alt+letter (menu letters visible) |

## Business Cloud (web)

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Document forms |
| `Ctrl/Cmd+F` | Lists (browser) |

## Explicitly not available

- a uniform Sage palette across products

## Mac

Cloud products: `Cmd`; Windows products: Windows keys.
