# Odoo - Menu items

## App switcher (top left)

| Area | Content |
|---------|---------|
| Apps | installable modules (Community/Enterprise), store |
| App tiles | CRM · Sales · Warehouse · Accounting · Projects · HR · Website · POS … |

## Within an app

| Element | Content |
|---------|---------|
| Favourite star / views | Kanban, list, calendar, Gantt (Ent), pivot/graph (Ent) |
| "New" / import / export | CSV/XLSX, field mapping |
| Actions (list) | Labels, e-mails, delete, "Export selection" |
| Settings (app) | Configuration, user rights per app |

## Developer mode (⚙ → Activate developer mode)

- Field tooltips, "View edit"/"Fields" in the form header, custom actions
- Menu **Technical → Users & Companies / Database structure / Automated actions (ir.ql) / Webhooks (Enterprise)**

## Global ⚙ menu

- My settings, users, companies, templates, automations, "Approvals"

## Menus by role

Group rights (e.g. "Sales / User / Manager") determine the menu tree; portal/website users see their own customer portal.
