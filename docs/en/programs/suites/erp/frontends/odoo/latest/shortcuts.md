# Odoo - Keyboard shortcuts

## Overview

Odoo documents shortcuts sparingly; the `c` command palette (Odoo 16+) is the official navigation route.

> As of: Odoo 17/18.

## Available

| Shortcut | Function |
|----------|----------|
| `c` | Command palette (apps/menus "jump to") |
| `?` | Shortcut overlay (in masked versions directly the list) |
| `Enter` | Confirm field / save row |
| `Esc` | Cancel editing / close dialog |
| `↑↓` | Field/row navigation in lists |
| `Tab`/`Shift+Tab` | Fields forward/back |
| `Alt+F5` or browser reload | Reload page (not an official one) |

## Explicitly unconfirmed

| Assumed | Status |
|------------|--------|
| `Shift+C` new record | ❌ not documented |
| `n` new record | ❌ (button "New") |

## Mac

`Cmd` variant only for browser standards; `c`/`?` identical.
