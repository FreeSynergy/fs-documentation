# Odoo Documentation

## Overview

Odoo is the open business suite (LGPL core + commercial Enterprise apps): CRM, sales, purchasing, warehouse, manufacturing, accounting, projects, HR — as integrated modules with a shared ORM layer. Python-based, Community Edition self-hosted, Odoo.sh/Cloud optional.

## File structure

- [menu.md](latest/menus.md) - App switcher, dashboard, settings, developer mode
- [features.md](latest/features.md) - Module system, Studio/automations, what Odoo cannot do
- [description.md](latest/description.md) - Differentiation from ERPNext, SAP, Dolibarr
- [structure.md](latest/layout.md) - Kanban/list/form views, menu tree
- [shortcuts.md](latest/shortcuts.md) - Navigation shortcuts (`c` palette)
- [api.md](latest/api.md) - XML-RPC/JSON-RPC, REST module (new), webhooks, OAuth2
