# Dolibarr - Menu items

## Main menu (left, modular)

| Menu | Content |
|------|--------|
| Accueil (Start) | Dashlets, follow-ups, search |
| Tiers | Customers/suppliers (third-party sheet), contacts, categories |
| Commercial | Proforma (quotes), orders, invoices, credits, "Evennements" |
| Produits/Services | Products, stock, prices, manufacturing (module) |
| Comptabilité | Customer/supplier posting, journal, account statement (from the "Accounting" standard version) |
| Projets | Tasks, time tracking (module-dependent) |
| Adhérents (Vereine) | Membership fees (NPO scenario!) |
| Outils | Utilities (mass printing, import/export) |

## Administration (⚙ Setup)

| Area | Content |
|---------|---------|
| Enable/disable modules | feature switches + **API REST**, webhooks |
| Users/groups/rights | Profiles (VRAC…), perimeters |
| Model selection | Number sequences, PDF templates, tax rates |
| Technical parameters | SMTP, e-mails, generate API keys |

## Menus by role

Rights profiles per module (read/create/manage/delete); "Super-Admin" for setup.
