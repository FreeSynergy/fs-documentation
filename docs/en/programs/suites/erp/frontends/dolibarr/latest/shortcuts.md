# Dolibarr - Keyboard shortcuts

## Overview

Dolibarr does **not document any shortcuts**; operation is via menus/forms.

> As of: Dolibarr 20.x.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Form fields |
| `Esc` | Close popups (calendar/pickers) |
| `Ctrl/Cmd+F` | List search (browser) |

## Explicitly not available

- command palette/jump search; no save key

## Mac

`Cmd` for browser standards.
