# Taiga - Keyboard shortcuts

## Overview

Taiga has **no documented shortcuts** in the web UI; operation is by click and form standards.

> State: Taiga 6.x/7.x (Taigo).

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | forms, quick-add rows |
| `Esc` | close the details panel/dialog |
| `Ctrl/Cmd+F` | browser search |

## Explicitly not available

- no `c` for a new story, no palette
- no shortcuts for status changes (chips/panel)

## Mac

`Cmd` with the browser standards.
