# Taiga - Menu items

## Head navigation per project (modules)

| Module | Content |
|--------|---------|
| Backlog | user stories, points, filters, sprint assignment (scrum projects) |
| Kanban | board with columns, WIP limits (kanban projects) |
| Issues | classic bug/task list (all project types) |
| Sprints | active sprint, burndown, closure check |
| Epics | epics + subtasks (with the epics module) |
| Customer CRM | customer contacts + CRM notes (optional module) |
| Wiki | pages in the project |
| Stats | statistics/burndown charts |
| Timeline | milestone/sprint timeline |

## Epic tracker (across projects)

Epics over several projects, progress bars, status fields.

## Admin centre (⚙)

| Area | Content |
|------|---------|
| Projects | create, roles (epics manager/backlog admin…), activate modules |
| Users | members, invitations, teams (Taiga Cloud) |
| Custom fields | status/priorities/field choices, own fields |
| Notifications/templates | mail templates, Slack/Telegram/GitHub integrations |
| Import/export | JSON backup, import from Asana/Jira/Trello (check the version) |

## Menus by role

Roles (backlog admin, user story admin, EPIC admin, page admin…) unlock module access; anonymous projects = publicly readable.
