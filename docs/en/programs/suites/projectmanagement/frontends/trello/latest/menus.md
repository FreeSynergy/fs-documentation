# Trello - Menu items

## Workspace level

| Menu | Content |
|------|---------|
| Workspaces | Board collections per team/company, members |
| Template centre | Board and card templates |
| Power-Ups | Manage add-ons (Jira, Calendar, Custom Fields …) |

## Board menu (☰ top right)

- **Menu**: invite members, restrictions, legend (labels), Power-Ups, activity, settings (background, views: table/calendar/list/timeline (premium), map (Power-Up))
- **Filters**: labels, members, due dates
- **Share/privacy**: workspace, board members, read/write rights

## Card menu (click a card)

| Area | Content |
|---------|--------|
| Title/description | editable inline |
| Checklists, attachments, labels, members, due date, location | as buttons |
| Actions | archive, copy, move, watch, card template |
| Automation ("wand") | card rules (Butler) |

## Menus by role

| Role | Rights |
|-------|--------|
| Admin (board) | everything, members |
| Member | edit cards |
| Observer | read/comment only |
| Guest (restricted) | assigned cards |
