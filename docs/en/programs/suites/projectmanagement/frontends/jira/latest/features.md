# Jira - Features

## Main features

### Issues and workflows
- Issue types (story, task, bug, epic, subtask) with their own workflows (statuses + transitions + conditions/validators)
- Custom fields (text, selection, date, user…), screens/screen schemes, issue types per project (company-managed)
- Links (blocks/is blocked by/relates), epics and (new) initiatives, fix versions, components

### Agile work
- Scrum boards with backlog, sprints, story points, velocity; kanban boards with WIP limits
- Advanced roadmaps/plans (premium), Automation for Jira (rules "when… then…")

### Queries and reports
- **JQL**: `project = WEB AND status changed to Done AFTER -7d ORDER BY Rank`
- Filters/subscriptions, dashboards (gadgets), control chart/cycle time, burn-up

### Integrations
- Confluence (issue ↔ page), Bitbucket/git commits (#KEY), branch development, marketplace (thousands of apps: ScriptRunner, Tempo…)

## What Jira does NOT do

- **not a lightweight tool** — the admin overhead (schemes, permission schemes) is notorious
- **no offline use** (cloud/data center need a connection)
- **Chargeable** from 10 users (cloud subscription)
- **Reports deeper than Trello, flatter than dedicated BI tools**
- **No native Gantt cannon** (plans only in premium; otherwise add-ons like BigPicture)
