# Wekan - Keyboard shortcuts

## Overview

Wekan documents **no dependable shortcut list**. Trello-like shortcuts (e.g. `C`) are not
guaranteed — here only what works consistently in current builds.

> State: Wekan 7.x.

## Available

| Shortcut | Function |
|----------|----------|
| `Esc` | close the card modal/dropdowns |
| `Tab`/`Enter` | forms, new card in a list (end of the list) |
| `Space` on a focused card (in some builds) | open the details — check the state |
| `Ctrl/Cmd+F` | browser search |

## Explicitly not available / unconfirmed

| Assumed | Status |
|---------|--------|
| `C` new card | ❌ not documented (use the "+" button) |
| `]`/`[` move list | ❌ |
| `?` shortcuts overlay | ❌ |

## Mac

`Cmd` with the browser standards.
