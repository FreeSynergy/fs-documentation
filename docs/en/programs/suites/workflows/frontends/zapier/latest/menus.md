# Zapier - Menu items

## Zap editor

| Element | Content |
|---------|--------|
| Trigger step | App + trigger event (instant/polling), fetch test data |
| Action steps (+) | Apps/actions in sequence, "Format" (text/code/data conversion) |
| Paths | Branches ("If condition A…" / "otherwise…") |
| Test/Publish | Step tests, name, auto-reload |

## Workspace menus

| Menu | Content |
|------|---------|
| Zaps | List, folders, shared zaps |
| Explorer | Templates (thousands), app combinations |
| Tables | Tables (records, automations) |
| Interfaces | Forms/mini websites built from zap logic |
| Forms | Forms as zap triggers |
| Analytics/Catalog | Run history, metrics; Enterprise: app control |
| Settings | Connections, invitations, plans/API keys for your own integrations |

## Developer area (platform.zapier.com)

- Zapier platform: own app definitions (UI builder/CLI `zapier`), prefill webhooks, OAuth setups

## Menus by role

Admin · member · limited (view zaps) · zap owner; Enterprise workspaces with governance.
