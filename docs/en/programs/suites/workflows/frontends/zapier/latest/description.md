# Zapier - Description

## What the program does

Zapier connects apps without infrastructure: a trigger in one app starts actions in others. The value lies in the selection (8,000 apps) and zero maintenance; the price is tasks, polling latency and cloud dependency.

## Advantages

- **Largest app library**, ready to use immediately
- **Interfaces/tables** replace small in-house builds
- Platform API: publish your own customer app as a Zap connector

## Differentiation

| System | Difference |
|--------|-------------|
| **Make** | Cheaper operations, visually deeper; Zapier has more apps |
| **n8n** | Self-hosted/cost-controlled; Zapier fully managed |
| **Power Automate** | M365 focus; Zapier neutral |

## Technical details

- **Model**: SaaS (US), EU data handling via sub-processor setups (GDPR chapter in the Trust Center)
- **Auth**: OAuth2/keys per app; API: session/secret token, OAuth2 for partners
- **Pricing**: Free (100 tasks) → Professional/Team/Enterprise

## Who it is for

- Business teams that need broad app coverage immediately
- FreeSynergy skins: the zap metaphor (trigger→steps) as the lowest-friction entry point for automation templates
