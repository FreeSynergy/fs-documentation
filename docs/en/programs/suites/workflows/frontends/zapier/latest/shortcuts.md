# Zapier - Keyboard shortcuts

## Overview

Zapier documents **no editor keyboard shortcuts**; guided step forms dominate.

> As of: 2026.

## Available

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Step forms |
| `Esc` | Close dropdowns/dialogs |
| `Ctrl/Cmd+F` | Search lists (browser) |

## Explicitly not available

- Palette/snippets; no `?` overlay

## Mac

`Cmd` for browser standards.
