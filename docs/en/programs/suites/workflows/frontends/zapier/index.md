# Zapier Documentation

## Overview

Zapier is the largest SaaS automation library (8,000+ apps): "Zaps" link triggers → actions, multi-step zaps and paths for branching, interfaces/tables/forms as mini apps. No self-hosting; API for custom integrations and platform partners.

## File structure

- [menu.md](latest/menus.md) - Zap editor, workspace menus, Explore
- [features.md](latest/features.md) - Zaps, paths, interfaces/tables, what Zapier CANNOT do
- [description.md](latest/description.md) - Differentiation from Make, n8n, Power Automate
- [structure.md](latest/layout.md) - Zap structure, multi-step, run log
- [shortcuts.md](latest/shortcuts.md) - Keyboard shortcuts (no official ones)
- [api.md](latest/api.md) - REST (zaps, objects), OAuth2 platform, prefill webhooks
