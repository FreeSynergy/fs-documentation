# Apple Shortcuts - Description

## What the program does

The user assembles a shortcut from actions in an editor and runs it by tapping, by voice or from a trigger. Personal automations start shortcuts on their own, on conditions set by the user (details Open).

## Differentiation

| System | Difference |
|--------|------------|
| Power Automate | Business-wide, with connectors and admin policy; Shortcuts is on-device and personal. |
| n8n, Huginn | Server-side and always on; Shortcuts runs on the user's device. |

## Open

- Platforms beyond iPhone and iPad; limits of background automations.
