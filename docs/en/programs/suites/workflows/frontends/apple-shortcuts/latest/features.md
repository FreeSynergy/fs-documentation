# Apple Shortcuts - Features

- Shortcuts built from actions combining on-device apps, content and internet services.
- Gallery of curated shortcuts to add and edit.
- Personal automations (intro and adding are documented; trigger list Open).
- Run from: Shortcuts app, Siri, Control Center, Action button, widget, search, other apps, Apple Watch, back tap.
- App shortcuts supplied by installed apps.
- Sharing and syncing; import questions for shared shortcuts.
- Run, create or open a shortcut from a URL; x-callback-url; calling other apps' URL schemes.
