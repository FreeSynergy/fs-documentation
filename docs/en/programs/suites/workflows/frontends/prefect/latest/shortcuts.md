# Prefect - Keyboard shortcuts

## Overview

Prefect documents only a global search/jump palette; otherwise no shortcuts.

> As of: Prefect 3.x.

## Available

| Shortcut | Function |
|----------|----------|
| `Ctrl/Cmd+K` (or `⌘K`) | Search/command palette (UI) — check version |
| `Esc` | Close dialogs/drawers |
| `Tab`/`Enter` | Form navigation |

## Explicitly not available

- No run/pause keys in the style of Airflow table actions

## Central commands = CLI

| Command | Effect |
|--------|--------|
| `prefect deployment run <name>` | Start run |
| `prefect deployment pause/resume` | Schedule |
| `prefect worker start --pool …` | Start infrastructure |

## Mac

`Cmd` variant.
