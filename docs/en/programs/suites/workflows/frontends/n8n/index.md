# n8n Documentation

## Overview

n8n is the open-source workflow automation tool (Node.js, "fair-code"): wire nodes into workflows graphically, hundreds of integrations, custom JS/Python code nodes, webhooks as triggers, self-hosting or cloud.

## File structure

- [menu.md](latest/menus.md) - Workflow editor menus, node menus, admin area
- [features.md](latest/features.md) - Triggers, nodes, code nodes, what n8n CANNOT do
- [description.md](latest/description.md) - Differentiation from Make, Zapier, Node-RED
- [structure.md](latest/layout.md) - Canvas editor, right-hand panel, executions log
- [shortcuts.md](latest/shortcuts.md) - Documented editor keyboard shortcuts
- [api.md](latest/api.md) - Public REST API (workflows, executions), webhooks, OAuth2
