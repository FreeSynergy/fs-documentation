# n8n - Keyboard shortcuts

## Overview

n8n documents editor keyboard shortcuts (overview: `?` icon in the editor).

> As of: n8n 1.x.

## Editor

| Shortcut | Function |
|----------|----------|
| `Tab` | Open node palette |
| `Ctrl/Cmd+S` | Save workflow |
| `Ctrl/Cmd+Z` / `+Shift+Z` | Undo / redo |
| `Ctrl/Cmd+C` / `+V` / `+D` | Copy / paste / duplicate node |
| `Ctrl/Cmd+A` | Select all nodes |
| `Del`/`Backspace` | Delete selection |
| `Esc` | Clear selection/dropdown |
| `Ctrl/Cmd+=` / `+-` | Zoom |
| `Ctrl+Mouse wheel` | Zoom |
| `Space` + drag / middle mouse button | Pan canvas |

## Explicitly not available

- Shortcuts for executing (buttons); no command palette equivalent besides `Tab`

## Mac

`Cmd` variant.
