# Node-RED

> Category: [workflows](../../index.md)

## What it is

Node-RED is the flow-based programming environment (Node.js, Apache-2.0) from IBM's IoT labs: you wire nodes together with wires (messages flow along them), with a dashboard, MQTT/OPC-UA support and thousands of community packages. The standard for self-built automation and embedded connectivity.
