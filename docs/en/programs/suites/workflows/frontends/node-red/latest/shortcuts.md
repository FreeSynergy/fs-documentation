# Node-RED - Keyboard shortcuts

## Overview

Node-RED documents editor keyboard shortcuts (list in the official documentation).

> As of: Node-RED 4.x.

## Available

| Shortcut | Function |
|----------|----------|
| `Ctrl/Cmd+Space` | Node search (palette) |
| `Ctrl/Cmd+Z` / `+Y` | Undo / redo |
| `Ctrl/Cmd+C` / `+X` / `+V` | Copy / cut / paste |
| `Ctrl/Cmd+A` | Select all nodes of the tab |
| `Del` | Delete selection |
| `Esc` | Clear selection / close node config |
| `Ctrl+Mouse wheel` | Zoom |
| Middle mouse button / `Space`+drag | Pan canvas |
| `Tab` | Nodes in selection order (common, verify current state) |

## Explicitly not available

- No guaranteed "Deploy" shortcut (button); the shortcut list in the documentation is authoritative

## Mac

`Cmd` instead of `Ctrl`.
