# Huginn - Description

## What the program does

The user creates agents in a web interface, sets their options and connects them. An agent might read an RSS feed or scrape a page; another might send a message to a chat service when an event matches. Data stays on the user's own server.

## Differentiation

| System | Difference |
|--------|------------|
| n8n | Visual canvas with nodes; Huginn is agent-list oriented with an event-flow diagram. |
| Zapier | Hosted; Huginn is self-hosted. |

## Technical details

Ruby on Rails; MySQL or PostgreSQL; Docker, Compose and other deploy options. Licence MIT.
