# Huginn - Features

- Agents for web scraping, RSS, IMAP mailboxes, webhooks, MQTT; outputs to services such as Slack, Telegram, Twilio.
- Events passed along a directed graph between agents.
- Logic in JavaScript, Liquid or jq; complex agents can be added as external gems.
- Web interface: agent list, event-flow diagram, event browsing.
- Deployment: Docker image, Compose, Dokku, hosting platforms, manual install.
