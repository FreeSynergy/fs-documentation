# Windmill - Description

## What the program does

Developers write scripts; Windmill derives the input form from the function signature, runs it on a worker and keeps the results. Scripts are then linked into flows, or given a user interface as an app.

## Differentiation

| System | Difference |
|--------|------------|
| n8n | Node canvas with integrations first; Windmill starts from code. |
| Airflow, Prefect | Python-centred orchestration; Windmill is multi-language and includes a UI builder. |
