# Windmill - Features

- Languages: TypeScript (Bun), Python, Go, PHP, Bash, PowerShell, C#, SQL, Rust, Ruby, R, Java, Ansible, or any Docker image (some only in the full image).
- Triggers: schedules, webhooks, HTTP routes, Kafka, WebSockets, email.
- Flows: visual editor, YAML, workflows as code.
- Apps: full-code React/Svelte, plus a legacy low-code editor.
- Data tables, DuckDB; pipelines (alpha).
- AI sessions in a workspace fork, with preview and diff review.
- Workspace roles, protection rulesets, dev workspaces, SSO/OAuth.
- CLI, VS Code extension, Git sync, MCP server.
- Deploy: Docker Compose or Helm.
