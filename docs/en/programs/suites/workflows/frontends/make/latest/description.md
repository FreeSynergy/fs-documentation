# Make - Description

## What the program does

Make builds automations as scenarios: a trigger creates data records, modules process them visibly (routers, iterators), and actions write them into apps. Everything runs in Make cloud data centers, billed by operations consumed.

## Advantages

- **Most visual data paths** on the market (records as bubbles), strong for nested logic
- Free plan that is good enough for learning
- Custom apps via OpenAPI → in-house systems can be connected

## Differentiation

| System | Difference |
|--------|-------------|
| **Zapier** | Simpler, more apps, task-based pricing; Make goes deeper into routes and iteration |
| **n8n** | Self-hostable, code nodes; Make is pure SaaS |
| **Power Automate** | Microsoft world (M365 integration); Make is platform-neutral |

## Technical details

- **Model**: SaaS (Make.com, EU/US regions), teams/folders
- **Auth**: connections (OAuth2/keys); API: token/OAuth2 app (developer subscription)
- **Pricing**: Free → Core/Pro/Teams/Enterprise (operations quotas)

## Who it is for

- Operational teams with branching-heavy processes (lead routing, synchronization)
- FreeSynergy skins: module-bubble/route paradigm as flow visualization
