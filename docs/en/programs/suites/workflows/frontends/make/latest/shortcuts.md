# Make - Keyboard shortcuts

## Overview

Make documents **no official keyboard shortcuts**; the editor is click- and drag-based.

> As of: 2026.

## Available

| Shortcut | Function |
|----------|----------|
| `Esc` | Close module configuration |
| `Tab`/`Enter` | Form fields |
| `Ctrl/Cmd+F` | Browser search in history/lists |

## Explicitly not available

- No palette, no one-key module creation (click from module list)

## Mac

`Cmd` for browser standards.
