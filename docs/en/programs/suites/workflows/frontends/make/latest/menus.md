# Make - Menu items

## Scenario editor

| Element | Content |
|---------|--------|
| Scenario list (left) | Scenarios, folders, templates |
| Canvas | Modules as bubbles; links (trigger→action); routes (router/filter/iterator) |
| Module click | App module configuration (connection, fields, "Instant preview") |
| Run once / Start | Test run / production scheduling |
| History | Execution list with module data (bubbles clickable) |

## Organization menus

| Area | Content |
|------|---------|
| Connections | Share app connections (OAuth2/API keys) |
| Data stores | Make tables (records) |
| Folders/Teams | Access rights, shared folders |
| Custom apps | "App Builder"/"App Editor": your own modules (OpenAPI import) |
| Webhooks | Custom webhook endpoints as triggers |
| Plans/Billing | Operations budget, reserves |

## Menus by role

Owner · admin · builder (scenarios) · viewer (history); connections per organization/person.
