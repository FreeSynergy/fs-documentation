# Make Documentation

## Overview

Make (formerly Integromat) is the visual SaaS automation platform: scenarios built from modules (trigger → router/iterator/aggregator → actions), 1,500+ apps, visual data paths with bubbles. Pricing model based on "operations". Includes an API for scenario management.

## File structure

- [menu.md](latest/menus.md) - Scenario editor, organization menus, plans
- [features.md](latest/features.md) - Modules, routers, webhooks, what Make CANNOT do
- [description.md](latest/description.md) - Differentiation from Zapier, n8n, Power Automate
- [structure.md](latest/layout.md) - Scenario canvas with module bubbles
- [shortcuts.md](latest/shortcuts.md) - Keyboard shortcuts (no official ones)
- [api.md](latest/api.md) - REST (users/scenarios/webhooks), OAuth2 app system
