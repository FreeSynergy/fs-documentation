# Power Automate - Features

- Cloud flow types: automated, instant, scheduled.
- Create from blank, from a template, or by Copilot prompt (Copilot only in the new designer; admins may disable it).
- Connectors to cloud and on-premises services.
- Environments with role-based access (admin, maker, run-only) and filters by type.
- Navigation items: Approvals, Solutions, Process mining, AI models, Desktop flow activity, Automation center, Tables, Connections.
- Themes and licence view in settings.

## Open

- Desktop flows, error handling, sharing of flows.
