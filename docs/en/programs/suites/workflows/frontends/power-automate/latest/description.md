# Power Automate - Description

## What the program does

A maker creates a flow in a designer (new or classic) or with Copilot. Connectors link cloud and on-premises services. Flows are tied to an environment; people see only flows they may access.

## Differentiation

| System | Difference |
|--------|------------|
| Apple Shortcuts | Personal and on-device. |
| Zapier, Make | Independent SaaS; Power Automate is bound to Microsoft accounts and the Power Platform. |

## Open

- Desktop flows, licence tiers, data-loss policies.
