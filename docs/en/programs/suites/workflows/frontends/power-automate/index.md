# Power Automate

> Category: [workflows](../../index.md)

## What it is

Power Automate is Microsoft's automation service in the Power Platform: flows connect apps and services through connectors, with a web designer and optional Copilot assistance. Note: it is a hosted product, not a suite; it is filed under Workflows because the map lists it there.

## Notable ideas

- **Three trigger kinds in cloud flows**: automated (an event), instant (a button), scheduled.
- **Describe it in words**: Copilot proposes a flow from a plain-language prompt.
- **Environments** separate development from production work, with roles per environment.
- **Approvals, solutions, process mining, AI models** sit in the same navigation.
- Listed here for the idea of environments and approvals around flows (ADR 0013).
