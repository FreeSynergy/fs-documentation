# Snipe-IT - Description

## What the program does

Snipe-IT answers who has which item, and where it is. Each item type has its own lending rule. Items leave stock by check-out and come back by check-in, and the status of the item decides what may happen next.

## Differentiation

| System | Difference |
|--------|------------|
| Grocy | Grocy counts quantities for a household; Snipe-IT tracks single tagged items. |

## Technical details

- PHP 8.2 or later (release 8.8.3).
- Admin settings: branding, alerts, LDAP, two-factor authentication.
- Licence, database: Open.

## Who it suits

Groups that lend equipment and need to know where it is.
