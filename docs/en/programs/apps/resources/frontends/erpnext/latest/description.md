# ERPNext - Description

## What the program does

ERPNext manages the business side of an organisation in one system: accounting, stock, sales, purchasing, manufacturing and assets. Its screens are mostly produced by the Frappe framework from DocType definitions, so all modules look and behave alike.

## Differentiation

| System | Difference |
|--------|------------|
| Odoo | Also modular; ERPNext is built around the DocType model that other apps can extend. |
| Dolibarr, Tryton | Other open ERP systems; not compared here (Open). |

## Technical details

- Built on the Frappe framework (Python server, web "Desk" client). Detail of the database and client stack: Open.
- Licence: Open (not checked this session).

## Who it suits

Organisations that need stock, accounting and sales together. For FreeSynergy it is a reference for generated forms, not for resource booking.
