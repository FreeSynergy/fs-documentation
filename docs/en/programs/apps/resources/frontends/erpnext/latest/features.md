# ERPNext - Features

## Main features

- Accounting, stock, sales, purchasing, manufacturing, assets (named by the project page).
- A DocType defines a record type: fields, naming, and the table. A list view and a form view are provided for each DocType without extra code.
- Records are reachable by route, for example a list at one address and each record at a sub-address.

## Not documented here

- Reservation or booking of rooms and time: Open.
- Custom fields and scripting of DocTypes: Open.
