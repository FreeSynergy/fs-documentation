# Grocy - Features

- **Stock**: log purchases, due dates, camera barcode scanning in the browser.
- **Shopping list**: minimum stock levels add items automatically; products grouped by store section.
- **Recipes**: shows whether ingredients are present, adds missing ones to the list; a score ranks recipes that use soon-to-expire stock.
- **Meal plan**: daily meals from recipes.
- **Household**: chores, to-do list, equipment and manuals, battery charge tracking.
- **Customisation**: custom fields, own object and list types, feature flags.
- Release 4.7.1 mentions a stock-product copy endpoint and a calendar (iCal) export.

Not available: offline use.
