# Odoo - Description

## What the program does

Odoo offers many business apps in one installation: sales, inventory, accounting and others, listed by area in its documentation. Which apps you install decides what the interface offers.

## Differentiation

| System | Difference |
|--------|------------|
| ERPNext | Similar scope; Odoo lists apps as separate modules with their own documentation chapters. |

## Technical details

Open: language, database, licence and edition limits were not verified.

## Who it suits

Organisations that want to start with one app and add others later. For FreeSynergy it shows how modules can be linked without copying data.
