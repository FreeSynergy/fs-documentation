# Exist.io

> Category: [history](../../index.md) · Type: personal analytics · Vendor: Hello Code (Melbourne, Australia) · Licence: proprietary

## What it is
Exist is a self-tracking service that gathers data from other apps and devices, adds manual entries such as mood, and looks for connections between them.

## Notable ideas
- Correlations between unrelated sources (sleep, steps, mood, weather, work). Why: history that answers "why", not only "what".
- Custom tags with several value types (quantity, duration, 1-9 scale, percentage, time of day). Why: one small model for self-reported data.
- Weekly summary and daily insights. Why: History could offer a digest in the same spirit.
- A public API where users can also write attributes. Why: the service is a hub for outside data.
