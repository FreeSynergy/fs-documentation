# Day One

> Category: [history](../../index.md) · Type: journal · Vendor: Day One (Automattic) · Licence: proprietary

## What it is
Day One is a journaling app for Apple devices, Android, Mac, Windows and the web. Entries carry text and media and are enriched with metadata such as place and weather. It resurfaces old entries on the same calendar day.

## Notable ideas
- Metadata added automatically: location, and weather derived from the location. Why: context without effort.
- "On This Day": entries from the same date in earlier years. Why: the past comes back to you without searching.
- Location History: recorded visits that can become entries. Why: a diary that starts from where you were.
- End-to-end encryption with a key the vendor does not hold. Why: a model for private history data.
