# Day One latest — Description

## Overview
A personal journal: write entries with photos, video, drawings or audio, organise them in journals, find them again by date.

## What it does
- Entries get metadata: date, location, weather (via the location), tags, journal, favourite.
- "On This Day" shows entries from the same date of earlier years (web: in the Today tab).
- Location History records visited places on iOS; other platforms show and edit them.
- Shared journals (up to 30 people per the help index).
- Passcode/biometrics, end-to-end encryption, automatic backups, export, printed books.

## Who it suits
People who keep a private diary and want context filled in for them.

## Differentiation
### Day One vs. ActivityWatch
Day One is written by you, with a few automatic fields; ActivityWatch records computer activity automatically. FreeSynergy History sits between: it only keeps one line per event and no content.

## Technical details
Platforms: iPhone, iPad, Apple Watch, Android, Mac, Windows, web, browser extensions. Free basic use, optional Gold plan. Weather source on iOS: Apple WeatherKit (help page, search result). Storage format and sync internals: Open.
