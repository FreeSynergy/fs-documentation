# Day One latest — Features

## Main features
- Rich entries: text, photos, video, drawings, audio.
- Automatic location and weather; per-journal switch on the web app.
- Date and place from photo metadata (iOS, Android, Mac; not Web or Windows).
- On This Day.
- Location History (recording on iOS only; Mac 2026.8 and later, Web, Windows show and edit).
- Shared journals; sync; import and export; book printing.
- Security: passcode, biometrics, end-to-end encryption.

## What it does NOT do (as far as found)
- Not free software; no self-hosting.
- Location History recording on Android: not available.
- Templates, activity metadata, automation: Open.
