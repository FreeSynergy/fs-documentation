# ActivityWatch latest — Features

## Main features
- Official watchers: afk, window, web.
- Buckets and events; heartbeats merge identical consecutive events within a given time gap.
- Query language over time periods.
- Web interface, tray icon, pausing, filtering.
- Categories: add, edit, rules (regular expressions).
- Export and import.

## What it does NOT do
- Window watcher: no Wayland support (X11 only, per docs).
- Syncing between devices: only an old prototype is listed.
- Mobile apps: Open.
