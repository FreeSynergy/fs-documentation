# F-Droid - Description

## What the program does

F-Droid is a store for Android apps that are free software. It consists of a build and publishing pipeline run by the project, and a client app that lists the apps of one or more repositories and installs and updates them.

## Differentiation

| System | Difference |
|--------|------------|
| Obtainium | Takes releases straight from the developer; F-Droid rebuilds from source and publishes the result. |
| Flathub | Different platform (Linux desktop); publisher checks are by app-ID ownership, not by rebuilding. |

## Who it suits

People who want apps whose source can be inspected, and who want warnings before they install.
