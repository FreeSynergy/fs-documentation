# Obtainium - Description

## What the program does

The user adds an app by the address of its release page. Obtainium reads the page, finds the newest installable package, shows it as an available update and installs it on request.

## Differentiation

| System | Difference |
|--------|------------|
| F-Droid | A curated, rebuilt catalogue; Obtainium has no catalogue of its own and trusts the publisher's releases. |
| Play-style stores | No account, no central listing. |

## Notes

- Some sources work by reading web pages and can break when a site changes (stated by the project).
- Open: supported Android versions, update-check scheduling details.
