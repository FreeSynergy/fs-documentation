# Obtainium - Features

## Main features

- Track apps from many source types (see index); version comparison against the installed app.
- Notifications for new releases; installation of updates.
- Community-collected app configurations for common apps.
- Recent changelog entries (v1.7.x) mention: per-app install method, choice of Shizuku or Dhizuku installer backend, an "Update Health" section that flags possibly stale app configurations, disabling an app without removing it, excluding categories from update checks, a global filter for package files, a version-trimming pattern, including draft releases, and filtering F-Droid builds by device architecture.
- A verification tool ("Verified Apps") is integrated.

## Limits

- Android only.
- Only as reliable as each source page.

## Open

- Import and export of the app list, background-check intervals: mentioned indirectly, not confirmed.
