# Flathub - Features

## Main features

- Catalogue of apps with pages per app.
- **Verified mark** on app pages.
- Verification methods for developers: a token file under the well-known path of the domain from the app ID, a DNS TXT record, or login with a code-hosting account for IDs under GitHub, GitLab, GNOME or KDE; manual request for official apps. HTTPS required for the file method.
- Client subsets: verified, free software (floss), verified and free software.
- Separate beta remote for alpha and beta builds; stable and beta branches can coexist.

## Limits

- Newly created IDs under the legacy GitHub and GitLab prefixes are not accepted.

## Open

- Display of permissions on app pages, download statistics, donation links: not confirmed.
