# Flathub - Description

## What the program does

Flathub hosts Flatpak apps. Users find them on the website or in a software centre; the command-line tool or the centre installs them. Apps run in a sandbox with declared permissions.

## Verification

Verified means the developer showed control over the app ID. It usually also means the app is maintained by the developer or someone they authorised. Third-party packages without the developer's involvement cannot be verified. Extensions and runtimes cannot be verified.

## Differentiation

| System | Difference |
|--------|------------|
| F-Droid | Android; rebuilds and labels. Flathub: Linux desktop; publisher proof. |
| Distribution repositories | Flathub is distribution-independent. |
