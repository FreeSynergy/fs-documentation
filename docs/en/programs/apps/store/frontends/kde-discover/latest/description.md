# KDE Discover — Description

> [KDE Discover](../index.md) · version: latest (Plasma 6.8 line per apps.kde.org; the Userbase text is from the Plasma 5 era)

A software centre with a left column of categories, a middle column with the list of programs and a right column with the details of the chosen program ✅ (userbase). It installs applications, Plasma add-ons and add-ons of applications, updates them and removes them ✅.

**Evidence marks:** ✅ stated on an official KDE page read on 2026-11-14 (userbase.kde.org, apps.kde.org); `[nicht belegt]` not found. The official handbook was not reachable. Only function and behaviour are described, nothing is copied (ADR 0013).

## Who it suits

People who want one place for software from the distribution, Flatpak, Snap and the KDE add-on store, without a terminal.

## Differentiation

- One list over several package sources instead of one store per format ✅.
- Add-ons for the desktop itself (Plasma add-ons) are in the same place as applications ✅.
- Search is limited to the open category ✅.
