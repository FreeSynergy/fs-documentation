# KDE Discover — Menus

> [KDE Discover](../index.md) · [description](description.md)

Source: https://userbase.kde.org/Discover and https://userbase.kde.org/Discover/de (fetched 2026-11-14) ✅. Names only, behaviour in own words. The official handbook was not reachable, so the **menu bar, a hamburger menu, sub menus and context menus are `[nicht belegt]`**: the Userbase page does not mention any. What the page does name are the navigation entries of the left column and the buttons of each view; they are listed below as the working menu structure.

- Navigation (left column)
  - Applications {de: Anwendungen}

  - Application Add-ons {de: Erweiterungen für Anwendungen}
  - Installed {de: Installiert}
  - Updates {de: Aktuell}
- Back [Alt+Left] {de: Zurück}
- Program details (right column)
  - Install {de: Installieren}
  - remove {de: Entfernen}

- Updates view

- Settings {de: Einstellungen}
  - Make default {de: Als Standard setzen}
  - Software Sources
- Preferences

## Not found

- Menu bar and hamburger menu: `[nicht belegt]`.
- Context menu on a program, on an installed program, on an update row, on a source: `[nicht belegt]`.
- "Updates" is "Aktuell" on the German page (checked against the same step: Check for updates / Auf Aktualisierungen prüfen); it appears in the text, not as a listed entry.
- The groups "Back", "Program details" and "Updates view" are our own grouping of the named buttons; the page only names the buttons. "Preferences" is a section name, "Settings" a name too; whether one contains the other is `[nicht belegt]` (the German page seems to call both "Einstellungen").
- Where exactly "Settings" lives (a sidebar entry, a button or a menu) and how "Preferences" relates to it: `[nicht belegt]`; the page lists them as parts of the repository handling.
