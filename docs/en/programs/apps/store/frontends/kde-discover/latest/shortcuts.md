# KDE Discover — Shortcuts

> [KDE Discover](../index.md) · [description](description.md)

Platform: Linux with KDE Plasma (the only platform Discover runs on). Windows and Mac: `[nicht belegt]`. Source: https://userbase.kde.org/Discover, section "Navigating with the keyboard" (fetched 2026-11-14) ✅. The fetch returned a summary, not the raw text, so the key spelling is as read there.

## Discover-specific

| Keys | Action | Mark |
|------|--------|------|
| Ctrl+F | Focus the search field | ✅ |
| Alt+Left / Alt+Right | Move between the panes horizontally (the page also names "Back/Forward") | ✅ |
| Enter | Open the selected item of a list | ✅ |
| Up / Down | Move in a vertical list | ✅ |
| Escape | Close the right-most pane (the details); stated "since Plasma 5.10" | ✅ |
| Keys for install, remove, update, check for updates, refresh | | `[nicht belegt]` |
| Help > Keyboard Shortcuts (configurable keys) | | `[nicht belegt]` |

## General KDE keys (background, not Discover-specific)

From https://docs.kde.org/stable_kf6/en/khelpcenter/fundamentals/kbd.html (fetched 2026-11-14); that page does not mention Discover. Whether Discover honours them is `[nicht belegt]`.

| Keys | Action |
|------|--------|
| Ctrl+Q | Quit the program |
| Alt+F4 | Close the window |
| Alt+Tab | Switch between windows |
| Ctrl+Alt+Esc | Force quit |
