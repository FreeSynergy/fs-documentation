# KDE Discover — States

> [KDE Discover](../index.md) · [description](description.md)

✅ = stated on an official KDE page (2026-11-14); `[nicht belegt]` = not found.

| State | What the user sees | What the user can do |
|-------|--------------------|----------------------|
| Start | Search field selected, left column with categories ✅ | Type to search, pick a category ✅ |
| Category open | List in the middle column ✅ | Select a program, Back ✅ |
| Program selected | Details on the right; Install, or "remove" if installed ✅ | Install, choose source, Escape closes the details ✅ |
| Several sources | A Sources button appears ✅ | Choose repository, Snap or Flatpak ✅ |
| Installed list | Installed programs with "remove" ✅ | Remove ✅ |
| Updates waiting | Update entry at the bottom of the left column bright yellow ✅ | Open it, Update; uncheck single entries ✅ |
| No updates / unchecked | Updates view with "Check for updates" ✅ | Check manually ✅ |
| Password question | A password is requested on removal ✅ | Enter or cancel (cancel `[nicht belegt]`) |
| Progress, error, offline, empty search result | | `[nicht belegt]` |
