# Decidim - Description

## What the program does

Decidim is a framework for sites of democratic participation. Cities, associations, universities, NGOs, neighbourhoods and cooperatives use it for strategic planning, participatory budgeting, collaborative rule-making, urban spaces and elections.

## Differentiation

| System | Difference |
|--------|------------|
| Consul | Also for public participation; Decidim stresses configurable spaces and components. |
| Loomio | Loomio is for one group deciding; Decidim for large public processes. |
