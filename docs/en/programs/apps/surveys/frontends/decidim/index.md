# Decidim

> Category: [surveys](../../index.md)

## What it is

Decidim is a participatory democracy platform, started by Barcelona City Hall. An organisation configures a site where people take part in planning, budgeting, rule-making and elections.

## Notable ideas

- **Participatory spaces** (processes, assemblies, initiatives, conferences) hold **components** (proposals, debates, budgets, meetings, surveys, sortitions, accountability, blog, pages). A space is a container; the components are chosen per space. This is a model for how one decision topic can host several kinds of participation.
- Documented because it is the widest of the group (ADR 0013).
