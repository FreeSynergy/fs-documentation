# Loomio - Description

## What the program does

A group opens a thread with context, discusses, gathers input and votes. The result and the reasoning stay searchable.

## Activity

Active: ten releases between 2 Oct and 7 Nov 2026 (latest 3.15.0), described as faster to use on phones and slow connections.

## Differentiation

| System | Difference |
|--------|------------|
| Polis | Polis maps opinions; Loomio reaches a decision. |
| LiquidFeedback | No delegation known (Open). |

## Technical details

- Licence: AGPL-3.0.
- Stack as inferred from file names: Ruby on Rails, Vue, a native iOS app, mail and push services, Docker.

## Who it suits

Small to medium groups that decide by discussion.
