# LiquidFeedback - Description

## What the program does

Participants develop proposals together and decide on them in one process. A voter may delegate their voice on topics they do not follow.

## Activity

The current version is Core 4.2.2 (listed 2021-02-05) with Frontend 4.0.0 (date not found), to be used with WebMCP 2.2.1 and Moonbridge 1.1.3. No newer release was found. This is a **stagnation**, not a discontinuation; the project page is still online.

## Differentiation

| System | Difference |
|--------|------------|
| Loomio | Loomio has discussion and polls; LiquidFeedback has delegation. |

## Technical details

Core and frontend are separate downloads. Licence: MIT (project page). Language and database: Open.

## Who it suits

Groups that want delegated voting. Because of the stagnation, only the ideas are used.
