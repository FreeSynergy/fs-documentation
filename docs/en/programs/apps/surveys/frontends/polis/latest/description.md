# Polis - Description

## What the program does

Polis collects what a large group thinks without a questionnaire. The project calls it more organic than surveys and less effort than focus groups. A math service computes the grouping that feeds the visualisation.

## Differentiation

| System | Difference |
|--------|------------|
| Loomio | Loomio drives to a decision; Polis shows where opinions lie. |
| Decidim | Decidim is a full platform; Polis is a single tool. |

## Who it suits

Groups that must understand many opinions before deciding.
