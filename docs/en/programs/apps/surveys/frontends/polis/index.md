# Polis

> Category: [surveys](../../index.md)

## What it is

Polis is an open-source platform for gathering sentiment from large groups on open-ended questions. It is also run as a hosted service at pol.is.

## Notable ideas

- Instead of fixed survey questions, participants react to statements. The program then maps the opinion space and shows groups of similar opinion (⚠️: the repository only names a methods paper and a Python math service; the exact voting steps are Open).
- Documented because it finds common ground, not a winner (ADR 0013).
