# OBS Studio Documentation

## Overview

OBS Studio records screens, cameras and audio and transmits them via RTMP/SRT into streams; scenes, sources, filters and the mixer turn it into a full-fledged production tool. Stack: C/C++ (libobs), Qt surface, cross-platform, obs-websocket for remote control.

## File structure

- [menu.md](menu.md) - Menu bars, context menus, docks, scene/source menus
- [features.md](features.md) - Scenes, sources, filters, recordings, streaming, what OBS does NOT do
- [description.md](description.md) - How it differs from StreamYard, vMix, Restreamer and ffmpeg
- [structure.md](structure.md) - Preview, scene/source lists, mixer, tabs
- [shortcuts.md](shortcuts.md) - Hotkeys and global keyboard shortcuts
- [api.md](api.md) - obs-websocket 5.x, OBS-Command, libobs, plugins
