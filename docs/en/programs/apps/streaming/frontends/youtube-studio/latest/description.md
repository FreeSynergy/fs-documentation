# YouTube Studio - Description

## What the program does
For live broadcasts, YouTube Studio lets a channel owner prepare a stream, watch its health and audience while it runs, and read analytics afterwards. The Live Control Room is the screen for the running broadcast.

## Advantages
- One place for stream health, viewer numbers and the video's later analytics.
- No own infrastructure; reach is part of the platform.

## Differentiation
| System | Difference |
|--------|------------|
| StreamYard | Studio for guests and layouts; YouTube Studio manages the channel and the broadcast itself. |
| Owncast, PeerTube | Self-hosted; no central audience. |

## Technical details
Hosted only. Open: ingest protocols and limits, chat tools, moderation roles, latency modes.
