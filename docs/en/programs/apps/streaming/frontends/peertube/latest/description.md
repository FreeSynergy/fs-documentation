# PeerTube - Description

## What the program does
PeerTube hosts uploaded videos and live streams, organised in channels, with an embeddable player. Federation lets an instance's content appear in others and in the wider fediverse.

## Advantages
- Free software (AGPL-3.0), no ads or pay-per-view model; creators can add a support link.
- Federation and optional P2P delivery lower the load per instance.
- Documented REST API and a plugin and theme interface.

## Differentiation
| System | Difference |
|--------|------------|
| Owncast | Single-streamer server; PeerTube is a multi-user platform with uploads. |
| YouTube Studio | Central proprietary platform; PeerTube is decentralised. |

## Technical details
Web client Angular; pnpm workspaces; Docker supported (README). Server language and database: Open.
