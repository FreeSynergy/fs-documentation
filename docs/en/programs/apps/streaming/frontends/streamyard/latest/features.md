# StreamYard - Features

## Present
| Function | Evidence |
|----------|----------|
| Invite link generated in the studio and sent by e-mail or chat | help ✅ |
| Guests join in a browser without installing software; no account by default | help ✅ |
| Optional guest sign-in (Google or Facebook) | vendor blog ⚠️ |
| Guest camera and microphone permission in the browser | help ✅ |
| Phone guests: Chrome on Android, Safari on iOS; a separate guest app also exists | help ✅ / store listing ⚠️ |

## Open
Layouts, overlays, comments on screen, recording, multi-destination streaming, limits per plan. Not read from a primary source.

## Known risks (third-party) ⚠️
Strict firewalls and weak browser WebRTC support can make the link fail.
