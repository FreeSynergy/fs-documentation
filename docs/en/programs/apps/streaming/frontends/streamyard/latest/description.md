# StreamYard - Description

## What the program does
The host opens a studio in the browser, invites guests with a link, arranges them on screen and streams or records. Guests need no software and, by default, no account.

## Advantages
- Guest entry is a link in a browser.
- Little to learn compared with encoder software.

## Differentiation
| System | Difference |
|--------|------------|
| OBS Studio | OBS is local encoder software with scenes and sources; StreamYard is a hosted studio with guests. |
| Ecamm Live | Mac application; StreamYard runs in any supported browser. |

## Technical details
Hosted only. Open: codecs, resolution limits, plan limits (a third-party source mentions a six-person limit on the free plan ⚠️).
