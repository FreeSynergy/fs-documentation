# OBS Studio - Menu items

## File menu

| Menu item | Description |
|-----------|-------------|
| New scene/scene-collection group | create scenes and folders |
| Copy current scenes | take the scenes into another profile collection |
| Settings | general, video, audio, output, recordings, stream, advanced, hotkeys, extensions |
| Start/stop screen recordings | quick recording without streaming |
| Stop all screen recordings | end multiple recordings |
| Quit | including saving the scene change |

## View menu

Show/hide docks (scenes, sources, mixer, controls, transitions), full-screen studio
preview, full-screen projector (preview/program), advanced audio dock, scale the user
interface, lock screen resolutions

## Edit menu

Undo/redo (of the last scene change), copy/paste sources, properties clipboard

## Scene and source context menus (right click)

| Object | Actions |
|--------|---------|
| Scene | rename, duplicate, set the switch transition, transform reset |
| Source | rename, lock, visibility, transform (edge/centre), duplicate, filters, properties, scaling (source/output size) |
| Group | ungroup, edit the group source |

## Docks and controls

| Dock | Content |
|------|---------|
| Scenes | list incl. folders, order via drag |
| Sources | the sources of the active scene |
| Audio mixer | channels, mute button, gain, filters, monitoring |
| Transitions | type and duration, "cut" |
| Controls | start streaming, recording, studio mode, replays, settings, captions |
| Advanced audio | noise gate, compressor, level meter per source |

## Right-hand menus (three-dot menus in the controls)

Replays, enable captions, studio mode, start the virtual camera, screen recording, tools:
enhancer, shaders, scripting, manage extensions, WebSocket server settings, stream logging

## Menus by role

OBS is a single-seat program — roles only arise in team operation via profiles/scene files
and obs-websocket (operator, director, moderator).
