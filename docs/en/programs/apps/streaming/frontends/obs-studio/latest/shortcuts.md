# OBS Studio - Keyboard shortcuts

## Overview

In OBS shortcuts are called **hotkeys** and are assigned entirely under *Settings →
Hotkeys*. Many are unassigned out of the box.

> State: OBS Studio 30.x/31.x.

## Scene switching (defaults, mostly empty)

| Action | Assignment |
|--------|------------|
| Switch to scene 1–9 | freely choosable (often `F1`–`F9`) |
| Previous scene | freely choosable |
| Next/previous scene set (folder) | freely choosable |

## Stream and recording

| Action | Default |
|--------|---------|
| Start/stop streaming | ❌ unassigned (recommended: `Ctrl+Shift+S`) |
| Start/stop recording | ❌ unassigned (recommended: `Ctrl+Shift+R`) |
| Stop all recordings | ❌ unassigned |
| Save the replay buffer | ❌ unassigned (recommended: `Ctrl+S`) |
| Toggle studio mode | ❌ unassigned |

## Production

| Action | Default |
|--------|---------|
| Execute transition | `Return` (in studio mode) |
| Mute a source | no `M` key after selecting the source → hotkey per source |
| Mute all sources | ❌ |
| Start/stop the virtual camera | ❌ |
| Full-screen projector program/preview | ❌ |

## Program operation

| Shortcut | Function |
|----------|----------|
| `Tab` / `Shift+Tab` | switch between dock elements |
| `Alt + click` on a source | crop mode |
| `Ctrl + click` on a source | transformation reset (an alternative to the right-click menu) |
| `Esc` | leave the context menu/preview overlay |

## Not available (deliberately)

| Assumed | Status |
|---------|--------|
| Built-in command palette | ❌ |
| Global "emergency" hotkey (stop everything) | ❌ |
| Undo for a deleted scene | ❌ (only for the last change in the Edit menu) |

## Mac

`Cmd` instead of `Ctrl` for program actions; the scene hotkeys are likewise freely assignable.
