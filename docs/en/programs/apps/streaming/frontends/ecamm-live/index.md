# Ecamm Live

> Category: [streaming](../../index.md) · Type: streaming and recording application, macOS only · Vendor: Ecamm Network · Licence: proprietary

## What it is
Ecamm Live is a live-streaming and recording studio for the Mac. It combines cameras, screen, media and scenes in one application and sends the result to streaming platforms or records it.

## Notable ideas
- **Native Mac application** — a platform-specific choice; it shows what a local, integrated studio looks like next to a browser studio (ADR 0013).
- **Scenes prepared ahead, with placeholders for guests** (third-party report ⚠️) — scenes can be built before guests arrive.
- **Guest limit depends on the processor** — a visible example of a capacity limit set by hardware, not by plan (manual statement, see features).
