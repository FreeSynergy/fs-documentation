# Ecamm Live - Description

## What the program does
A single Mac application for live production: choose cameras and other inputs, switch between prepared scenes, bring in interview guests and stream or record.

## Advantages
- Integrated: capture, scenes and output in one application.
- Scenes can be prepared before the broadcast.

## Differentiation
| System | Difference |
|--------|------------|
| OBS Studio | Cross-platform and open source; Ecamm Live is Mac only and proprietary. |
| StreamYard | Browser studio; Ecamm Live runs locally on the Mac. |

## Technical details
Mac only; there are no plans for a Windows version (third-party statement ⚠️). Open: plans, version, supported protocols.
