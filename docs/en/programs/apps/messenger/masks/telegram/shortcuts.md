# Telegram - Keyboard shortcuts

## Overview

Telegram offers extensive keyboard shortcuts for working quickly.

## General shortcuts

| Shortcut | Function |
|----------|----------|
| `F1` | Help |
| `Ctrl+,` | Settings |
| `Ctrl+Shift+N` | New chat |
| `Ctrl+Shift+F` | Global search |

## Chat shortcuts

| Shortcut | Function |
|----------|----------|
| `Enter` | Send a message |
| `Shift+Enter` | New line |
| `Ctrl+Enter` | Send a message (in some configurations) |
| `Ctrl+K` | Search chats |
| `Ctrl+E` | Settings |
| `Ctrl+M` | Voice call |
| `Ctrl+V` | Video call |
| `Ctrl+Shift+M` | Voice call (alternative) |
| `Ctrl+Shift+V` | Video call (alternative) |

## Navigation shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+K` | Search chats |
| `Ctrl+Shift+F` | Global search |
| `Ctrl+.` | Next chat |
| `Ctrl+,` | Previous chat |
| `Ctrl+1` | First chat |
| `Ctrl+2` | Second chat |
| `Ctrl+3` | Third chat |
| `Ctrl+Tab` | Next chat |
| `Ctrl+Shift+Tab` | Previous chat |

## Editing shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+X` | Cut |
| `Ctrl+C` | Copy |
| `Ctrl+V` | Paste |
| `Ctrl+A` | Select all |

## Mac shortcuts

| Shortcut | Function |
|----------|----------|
| `Cmd+K` | Search chats |
| `Cmd+Shift+F` | Global search |
| `Cmd+E` | Settings |
| `Cmd+Enter` | Send a message |
| `Cmd+Shift+M` | Voice call |
| `Cmd+Shift+V` | Video call |

## Keyboard navigation

| Shortcut | Function |
|----------|----------|
| `Tab` | Next focus |
| `Shift+Tab` | Previous focus |
| `Escape` | Leave the focus |
| `Enter` | Activate |
