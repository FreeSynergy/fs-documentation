# Telegram - Features

## Overview

Telegram is a cloud-based messenger with a focus on speed and security. It is available on many platforms and offers encrypted chats, large groups, and channels for broadcasting.

## Main Features

### 1. Chat Communication
- **One-on-one conversations**: Direct messages to individual users
- **Groups**: Groups up to 200,000 members
- **Channels**: Channels with unlimited subscribers for broadcasting
- **Secret Chats**: Encrypted chats with E2E encryption
- **Self-destruct**: Messages with self-destruct timer
- **Status**: Online/Away/Last seen
- **Read receipts**: Display read receipts

### 2. Voice and Video Calls
- **One-on-one calls**: Audio and video calls with one participant
- **Group calls**: Group calls with multiple participants
- **Screen sharing**: Screen sharing during calls
- **Call tools**: Mute, volume control
- **Call history**: Display call history

### 3. File Transfer
- **File attachments**: Sending files up to 2 GB
- **Drag & Drop**: Drag & drop for file transfer
- **File preview**: Preview images, videos, documents
- **Media upload**: Upload photos, videos, documents
- **Cloud storage**: Files are stored in the cloud

### 4. Group Management
- **Create groups**: Groups up to 200,000 members
- **Group settings**: Configure group settings
- **Group roles**: Manage roles for members
- **Group permissions**: Configure permissions for roles
- **Group history**: Search history in groups

### 5. Channel Management
- **Create channels**: Channels with unlimited subscribers
- **Channel settings**: Configure channel settings
- **Channel notifications**: Notifications for channels
- **Channel history**: Search history in channels
- **Channel operators**: Operator tools for channels

### 6. Bots and Integrations
- **Bots**: Extensive bot system for automation
- **Webhooks**: Webhooks for external integrations
- **OAuth2**: OAuth2 integration for external services
- **Random functions**: Random functions for entertainment
- **Integration manager**: Manager for external integrations

### 7. Security
- **E2E encryption**: In "Secret Chats" with self-destruct
- **Password protection**: Password protection for accounts
- **Two-factor authentication**: Two-factor authentication
- **Device management**: Manage all devices
- **Security hints**: Display security hints

### 8. Profile
- **Own profile**: Manage your own profile
- **Notifications**: Manage notifications
- **Privacy settings**: Configure privacy settings
- **Profile photo**: Change profile photo

## What Telegram Cannot Do

- No native support for email (must be combined with email client)
- No native support for IRC
- No native support for Signal/WhatsApp
- No native Mastodon integration (only via webhooks)
- No native support for open source (proprietary)
