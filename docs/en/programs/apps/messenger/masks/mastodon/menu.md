# Mastodon - Menu Items

## Overview

Mastodon is an open-source microblogging network based on the ActivityPub protocol. It is decentralized and consists of many independent servers (instances) that can communicate with each other.

## Main Menu Items

### 1. Menu (Left)
- **Function**: Navigation and main functions
- **Details**:
  - Open home timeline
  - Open local timeline
  - Open federated timeline
  - Open direct messages
  - Open notifications

### 2. Toot Menu (Center)
- **Function**: Toot communication
- **Details**:
  - New toot
  - Edit/delete toot
  - Quote toot
  - Bookmark toot
  - Share toot (boost)
  - Upload media

### 3. Timeline Menu (Center)
- **Function**: Timeline management
- **Details**:
  - Home timeline
  - Local timeline
  - Federated timeline
  - Hashtag timeline
  - Apply timeline filters

### 4. User Menu (Right)
- **Function**: User management
- **Details**:
  - Open user profile
  - Follow/unfollow user
  - Block/ignore user
  - Report user

### 5. Notifications Menu (Right)
- **Function**: Notification management
- **Details**:
  - Follow notifications
  - Toot notifications
  - Mention notifications
  - Direct message notifications

### 6. Settings
- **Function**: Manage settings
- **Details**:
  - General settings
  - Media settings
  - Security settings
  - Theme settings
  - Language settings

### 7. Help Functions
- **Function**: Help functions
- **Details**:
  - Help documentation
  - About Mastodon
  - Troubleshooting
