# Element - Features

## Overview

Element is an open-source messenger for the Matrix protocol community. It is a complete client implementation of the Matrix protocol, designed for secure, decentralized communication.

## Main Features

### 1. Chat Communication
- **One-on-one conversations**: Direct messages to individual users
- **Group rooms**: Chat rooms with multiple participants
- **E2E encryption**: End-to-end encryption for secure communication
- **Status**: Online/Away/Inactive
- **Read receipts**: Display read receipts
- **Synchronization**: Synchronization across all devices

### 2. Audio and Video Calls
- **One-on-one calls**: Audio and video calls with one participant
- **Group calls**: Audio and video calls with multiple participants
- **Screen sharing**: Screen sharing during calls
- **Call history**: Display call history
- **Mute**: Control microphone and camera

### 3. File Transfer
- **File attachments**: Sending files of any size
- **Drag & Drop**: Drag & drop for file transfer
- **File preview**: Preview images, videos, documents
- **File hosting**: Optional own file hosting

### 4. Room Features
- **Room description**: Description and topic for rooms
- **Room image**: Custom room image
- **Room subscriptions**: Subscribe/pin rooms
- **Room notifications**: Notifications for rooms
- **Room invitations**: Send invitations to users
- **Room permissions**: Configure permissions for rooms

### 5. Integrations
- **Giphy**: Embed GIFs in messages
- **Webhooks**: Webhooks for external integrations
- **Bots**: Bot support for automation
- **Random functions**: Random functions for entertainment
- **Integration manager**: Manager for external integrations

### 6. Security
- **E2E encryption**: Enabled by default
- **Device management**: Manage all devices
- **Security hints**: Display security hints
- **Authentication**: Two-factor authentication
- **Password protection**: Password protection for accounts

### 7. Navigation
- **Room history**: Search history in rooms
- **Search**: Search in rooms and globally
- **Quick selection**: Quick selection of rooms
- **Marking**: Mark messages
- **Replying**: Reply to messages

## What Element Cannot Do

- No native support for email (must be combined with email client)
- No native support for IRC
- No native support for Signal/WhatsApp
- No native Mastodon integration (only via webhooks)
- No native Office integration (like Word/Excel)

## Extensions and Bot Functions

### Popular Bots
- **Giffy**: Embed GIFs in messages
- **Polls**: Create polls in rooms
- **Music bots**: Play music in rooms
- **Moderation bots**: Room moderation
- **Integration bots**: Integration with external services

### Popular Extensions
- **Theme**: Custom themes
- **Emoji**: Extended emoji support
- **Markdown**: Markdown support for formatting
- **Code block**: Code block support
