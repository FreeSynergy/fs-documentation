# Element - Keyboard shortcuts

## Overview

Element offers extensive keyboard shortcuts for working quickly.

## General shortcuts

| Shortcut | Function |
|----------|----------|
| `F1` | Help |
| `Ctrl+,` | Settings |
| `Ctrl+K` | Search rooms |
| `Ctrl+Shift+F` | Global search |
| `Ctrl+E` | Settings |

## Chat shortcuts

| Shortcut | Function |
|----------|----------|
| `Enter` | Send a message |
| `Shift+Enter` | New line |
| `Ctrl+Enter` | Send a message (in some configurations) |
| `Ctrl+P` | Room preferences |
| `Ctrl+U` | Mention a user |
| `Ctrl+Shift+U` | Pick an emoji |
| `Ctrl+Shift+M` | Voice call |
| `Ctrl+Shift+V` | Video call |

## Navigation shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+K` | Search rooms |
| `Ctrl+Shift+F` | Global search |
| `Ctrl+Shift+R` | Next unread room |
| `Ctrl+Shift+P` | Previous unread room |
| `Ctrl+.` | Next room |
| `Ctrl+,` | Previous room |
| `Ctrl+1` | First room |
| `Ctrl+2` | Second room |
| `Ctrl+3` | Third room |

## Editing shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+X` | Cut |
| `Ctrl+C` | Copy |
| `Ctrl+V` | Paste |
| `Ctrl+A` | Select all |

## Markdown shortcuts (in chat)

| Shortcut | Function |
|----------|----------|
| `**Text**` | Bold |
| `*Text*` | Italic |
| `~Text~` | Strikethrough |
| `` `Text` `` | Code |
| `> Text` | Quote |

## Mac shortcuts

| Shortcut | Function |
|----------|----------|
| `Cmd+K` | Search rooms |
| `Cmd+Shift+F` | Global search |
| `Cmd+E` | Settings |
| `Cmd+Enter` | Send a message |
| `Cmd+Shift+M` | Voice call |
| `Cmd+Shift+V` | Video call |

## Keyboard navigation

| Shortcut | Function |
|----------|----------|
| `Tab` | Next focus |
| `Shift+Tab` | Previous focus |
| `Escape` | Leave the focus |
| `Enter` | Activate |
