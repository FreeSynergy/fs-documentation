# Outlook - Keyboard shortcuts

## Overview

Outlook offers extensive keyboard shortcuts for working quickly.

## General shortcuts

| Shortcut | Function |
|----------|----------|
| `F12` | Save as |
| `Ctrl+S` | Save (in a draft) |
| `Ctrl+N` | New email |
| `Ctrl+Shift+M` | New email |
| `Ctrl+Shift+A` | Create an appointment |
| `Ctrl+Shift+K` | New contact |
| `Ctrl+Shift+L` | Create a distribution list |
| `Ctrl+Shift+T` | New note |
| `Ctrl+O` | Open |
| `Ctrl+F` | Search |
| `Ctrl+Shift+F` | Advanced search |
| `Ctrl+Shift+D` | Quick search |
| `Ctrl+E` | Exit |

## Custom shortcuts

Outlook allows customising shortcuts via:
- **Quick steps**: custom actions with a shortcut
- **Customise the menus**: via File > Options > Customise the ribbon
- **Add-ins**: extensions for custom shortcuts
