# Thunderbird - Keyboard shortcuts

## Overview

Thunderbird offers extensive keyboard shortcuts for working quickly.

## General shortcuts

| Shortcut | Function |
|----------|----------|
| `F1` | Help |
| `F5` | Refresh |
| `Ctrl+Q` | Quit |
| `Ctrl+W` | Close the window |
| `Ctrl+N` | New window |
| `Ctrl+Shift+N` | New window (private) |

## Email shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Shift+M` | New email |
| `Ctrl+R` | Reply |
| `Ctrl+Shift+R` | Reply to all |
| `Ctrl+Shift+F` | Forward |
| `Ctrl+Enter` | Send the email |
| `Ctrl+D` | Delete the email |
| `Ctrl+E` | Edit the message |
| `Ctrl+V` | Move the message |
| `Ctrl+C` | Copy the message |
| `Ctrl+Shift+V` | Paste as a quote |
| `Ctrl+P` | Print the email |
| `Ctrl+S` | Save the draft |
| `Ctrl+L` | Open the address book |

## Add-on shortcuts

Some add-ons define their own shortcuts:
- **Enigmail**: `Ctrl+Shift+E` for signing/encryption
- **ImportExportTools**: `Ctrl+Shift+E` for export
- **QuickFolders**: `Ctrl+Shift+Q` for quick access
