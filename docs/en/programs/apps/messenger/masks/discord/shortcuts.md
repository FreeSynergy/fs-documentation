# Discord - Keyboard shortcuts

## Overview

Discord offers extensive keyboard shortcuts for working quickly.

## General shortcuts

| Shortcut | Function |
|----------|----------|
| `F1` | Help |
| `Ctrl+Shift+A` | Change presence |
| `Ctrl+Shift+X` | Open keybindings |
| `Ctrl+Shift+M` | Voice call |
| `Ctrl+Shift+V` | Video call |
| `Ctrl+Shift+N` | New server |
| `Ctrl+Shift+K` | Search servers |
| `Ctrl+K` | Search channels |

## Chat shortcuts

| Shortcut | Function |
|----------|----------|
| `Enter` | Send a message |
| `Shift+Enter` | New line |
| `Ctrl+Enter` | Send a message (in some configurations) |
| `Ctrl+U` | Mention a user |
| `Ctrl+Shift+U` | Pick an emoji |
| `Ctrl+P` | Open the profile |
| `Ctrl+Shift+P` | Open the profile (of others) |

## Navigation shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+K` | Search channels |
| `Ctrl+Shift+K` | Search servers |
| `Ctrl+.` | Next channel |
| `Ctrl+,` | Previous channel |
| `Ctrl+1` | First channel |
| `Ctrl+2` | Second channel |
| `Ctrl+3` | Third channel |
| `Ctrl+Tab` | Next server |
| `Ctrl+Shift+Tab` | Previous server |

## Voice shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Shift+D` | Screen sharing |
| `Ctrl+Shift+S` | Mute |
| `Ctrl+Shift+M` | Voice call |
| `Ctrl+Shift+V` | Video call |
| `Ctrl+Shift+K` | Leave the channel |

## Editing shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+X` | Cut |
| `Ctrl+C` | Copy |
| `Ctrl+V` | Paste |
| `Ctrl+A` | Select all |

## Mac shortcuts

| Shortcut | Function |
|----------|----------|
| `Cmd+K` | Search channels |
| `Cmd+Shift+K` | Search servers |
| `Cmd+E` | Settings |
| `Cmd+Enter` | Send a message |
| `Cmd+Shift+M` | Voice call |
| `Cmd+Shift+V` | Video call |

## Keyboard navigation

| Shortcut | Function |
|----------|----------|
| `Tab` | Next focus |
| `Shift+Tab` | Previous focus |
| `Escape` | Leave the focus |
| `Enter` | Activate |
