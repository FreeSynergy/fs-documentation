# Kontact - Menu Items

## Overview

Kontact is an integrated Personal Information Manager (PIM) application for the KDE desktop environment. It combines several well-known KDE applications into a single, consolidated application.

## Main Menu Items

### 1. File (Backstage View)
- **Function**: File and account management
- **Details**:
  - Add/remove account (email, news, calendar)
  - Account settings
  - Import/export (vCard, CSV, ICS)
  - Settings
  - Quit

### 2. Edit
- **Function**: Edit objects
- **Details**:
  - Undo/Redo
  - Cut/Copy/Paste
  - Find/Replace
  - Select
  - Select all

### 3. Actions
- **Function**: Context-sensitive actions
- **Details**:
  - Send/receive email
  - Update calendar
  - Synchronize contacts
  - Update tasks
  - Start full-text search

### 4. View
- **Function**: Layout and display
- **Details**:
  - Refresh
  - Change view mode (List, Tiles)
  - Sort (by date, subject, etc.)
  - Group
  - Show/hide columns
  - Show/hide toolbars
  - Show/hide navigation pane

### 5. Email
- **Function**: Email management (in email window)
- **Details**:
  - New email
  - Reply/Forward
  - Move/copy email
  - Mark email
  - Categorize email
  - Delete email
  - Print
  - Properties

### 6. Calendar
- **Function**: Appointment management (in calendar window)
- **Details**:
  - New appointment
  - New recurring appointment
  - Open/edit appointment
  - Copy/delete appointment
  - Move appointment
  - Calendar sharing
  - Import/export calendar

### 7. Contacts
- **Function**: Address management (in contacts window)
- **Details**:
  - New contact
  - New contact folder
  - Open/edit contact
  - Copy/delete contact
  - Import/export contacts
  - Create distribution list

### 8. Tasks
- **Function**: Task management (in tasks window)
- **Details**:
  - New task
  - Open/edit task
  - Copy/delete task
  - Change task status
  - Reminders

### 9. Notes
- **Function**: Manage notes (in notes window)
- **Details**:
  - New note
  - Edit note
  - Delete note
  - Copy note

### 10. Extras
- **Function**: Extensions and extras
- **Details**:
  - Manage plugins
  - Run scripts
  - Import (Outlook, Thunderbird)
  - Export
  - Settings

### 11. Help
- **Function**: Help functions
- **Details**:
  - Help documentation
  - About Kontact
  - About KDE
  - License information
