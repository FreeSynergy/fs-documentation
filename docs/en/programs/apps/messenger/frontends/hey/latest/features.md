# HEY — Features

From the vendor's feature page:

- **The Screener**: decides whether first-time senders may mail again.
- **Imbox**: focused inbox for important mail.
- **The Feed**: newsletters in one place, already open, newest at the top.
- **Paper Trail**: receipts and transactional mail, out of the way but findable.
- **Set Aside**, **Reply Later**: piles for reference and for answering later.
- **Bubble Up**: send a mail away for a while; it returns to the top of the Imbox.
- **Clips**: save text such as phone numbers, links or confirmation numbers.
- **Collections**: several threads on one named page; sharing with one invite on "HEY for Domains".
- @hey.com addresses; "Send-as" for external addresses through SMTP.
- Mandatory two-factor authentication for paying customers.
- The page also mentions a HEY command-line tool and AI-agent support.
