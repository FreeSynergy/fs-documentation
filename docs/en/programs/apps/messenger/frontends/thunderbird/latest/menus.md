# Thunderbird - Menu Items

## Overview

Thunderbird is an open-source email and messaging client developed by the Mozilla Foundation. It is part of the Mozilla ecosystem and was specifically designed for email communication, with optional calendar and address book functions via extensions.

## Main Menu Items

### 1. File
- **Function**: File and account management
- **Details**:
  - Add/remove account
  - Account settings
  - Import/export (CSV, vCard, EML)
  - Print
  - Save as
  - Quit

### 2. Edit
- **Function**: Edit objects
- **Details**:
  - Undo/Redo
  - Cut/Copy/Paste
  - Find/Replace
  - Select
  - Select all
  - Find in messages

### 3. Actions
- **Function**: Context-sensitive actions
- **Details**:
  - Send/receive email
  - Filter message
  - Mark message
  - Move/copy message
  - Get sent messages

### 4. View
- **Function**: Layout and display
- **Details**:
  - Refresh
  - Change view mode (List, Tiles)
  - Sort (by date, subject, etc.)
  - Group
  - Show/hide columns
  - Show/hide toolbars
  - Show/hide navigation pane
  - Show/hide preview pane

### 5. Email
- **Function**: Email management (in email window)
- **Details**:
  - New email
  - Reply/Forward
  - Move/copy email
  - Mark email
  - Categorize email
  - Delete email
  - Print
  - Properties
  - Add/verify GPG signature

### 6. Calendar (Lightning)
- **Function**: Appointment management (in calendar window)
- **Details**:
  - New appointment
  - New recurring appointment
  - Open/edit appointment
  - Copy/delete appointment
  - Move appointment
  - Calendar sharing
  - Import/export calendar

### 7. Address Book (Lightning)
- **Function**: Address management
- **Details**:
  - New contact
  - New contact folder
  - Open/edit contact
  - Copy/delete contact
  - Import/export contacts
  - Create distribution list

### 8. Extras
- **Function**: Extensions and extras
- **Details**:
  - Manage add-ons
  - Run scripts
  - Import (Outlook, Outlook Express, Eudora)
  - Export
  - Settings
  - Developer tools

### 9. Tools
- **Function**: Tools and utilities
- **Details**:
  - Account settings
  - Edit filters
  - Rebuild search indices
  - Offline status
  - Manage storage

### 10. Help
- **Function**: Help functions
- **Details**:
  - Help documentation
  - About Thunderbird
  - About Mozilla
  - License information
  - Troubleshooting
