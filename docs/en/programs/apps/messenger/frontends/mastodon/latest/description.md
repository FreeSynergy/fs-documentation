# Mastodon - Description

## Overview

Mastodon is an open-source microblogging network based on the ActivityPub protocol. It is decentralized and consists of many independent servers (instances) that can communicate with each other.

## What Mastodon Does

Mastodon is a microblogging service that functions as an alternative to Twitter/X. It enables publishing short messages (toots), following users, sharing content, and participating in discussions in hashtags. Mastodon is not a single service but organized as a decentralized network.

## Advantages

- **Open Source**: Free and open source under AGPL license
- **Decentralization**: Many independent servers that communicate with each other
- **Privacy**: No central control, no advertising
- **ActivityPub**: Open protocol for social web
- **Community-focused**: Community-driven, no algorithms for timeline
- **Censorship-resistant**: Censorship-resistant through decentralization
- **Interoperability**: Communication with other ActivityPub networks
- **Transparency**: Open development, public code review
- **Customizability**: Each instance can have its own rules and features

## Distinction from Other Systems

### Mastodon vs. Twitter/X
- **Mastodon** is decentralized and open source, **Twitter/X** is centralized and proprietary
- **Mastodon** has no advertising, **Twitter/X** has advertising
- **Mastodon** has no algorithms for timeline, **Twitter/X** has algorithms
- **Mastodon** is community-driven, **Twitter/X** is company-driven

### Mastodon vs. Discord
- **Mastodon** is for microblogging, **Discord** is for chat and groups
- **Mastodon** has no voice/video, **Discord** has native voice/video
- **Discord** is for community servers, **Mastodon** is for microblogging

### Mastodon vs. Element
- **Mastodon** is for microblogging, **Element** is for chat and groups
- **Mastodon** has no E2E encryption, **Element** has E2E encryption
- **Element** is for direct messages, **Mastodon** is for public toots

## Technical Details

- **Platform**: Web, iOS, Android (third-party)
- **Protocol**: ActivityPub, OStatus
- **Backend**: Ruby on Rails
- **Encryption**: TLS for data transmission, no E2E encryption
- **Authentication**: OAuth2, Email/Password
- **Hosting**: Own Mastodon server or public instances
- **Programming Language**: Ruby on Rails (backend), TypeScript (frontend)

## Who is Mastodon Suitable For?

- **Privacy-conscious**: For those who value privacy
- **Community users**: For those who want community-driven networks
- **Open Source users**: For those who prefer open source software
- **Alternative users**: For those who seek alternative to Twitter/X
- **Decentralization users**: For those who want decentralized networks
