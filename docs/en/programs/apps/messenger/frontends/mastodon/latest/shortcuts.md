# Mastodon - Keyboard shortcuts

## Overview

Mastodon offers extensive keyboard shortcuts for working quickly.

## General shortcuts

| Shortcut | Function |
|----------|----------|
| `F1` | Help |
| `Ctrl+,` | Settings |
| `Ctrl+Shift+M` | New direct message |
| `Ctrl+Shift+E` | New public post |

## Toot shortcuts

| Shortcut | Function |
|----------|----------|
| `Enter` | Send the toot |
| `Shift+Enter` | New line |
| `Ctrl+Enter` | Send the toot (in some configurations) |
| `Ctrl+K` | Search toots |
| `Ctrl+Shift+F` | Search profiles |

## Navigation shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+K` | Search toots |
| `Ctrl+Shift+F` | Search profiles |
| `Ctrl+.` | Next toot |
| `Ctrl+,` | Previous toot |
| `Ctrl+Shift+N` | Next unread toot |
| `Ctrl+Shift+P` | Previous unread toot |

## Editing shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+X` | Cut |
| `Ctrl+C` | Copy |
| `Ctrl+V` | Paste |
| `Ctrl+A` | Select all |

## Markdown shortcuts (in toots)

| Shortcut | Function |
|----------|----------|
| `**Text**` | Bold |
| `*Text*` | Italic |
| `~Text~` | Strikethrough |
| `` `Text` `` | Code |
| `> Text` | Quote |

## Web app shortcuts

| Shortcut | Function |
|----------|----------|
| `Home` | Start page |
| `Local` | Local timeline |
| `Federated` | Federated timeline |
| `Notifications` | Notifications |
| `Messages` | Direct messages |
| `Bookmarks` | Bookmarks |

## Mac shortcuts

| Shortcut | Function |
|----------|----------|
| `Cmd+K` | Search toots |
| `Cmd+Shift+F` | Search profiles |
| `Cmd+E` | Settings |
| `Cmd+Enter` | Send the toot |
| `Cmd+Shift+M` | New direct message |

## Keyboard navigation

| Shortcut | Function |
|----------|----------|
| `Tab` | Next focus |
| `Shift+Tab` | Previous focus |
| `Escape` | Leave the focus |
| `Enter` | Activate |
