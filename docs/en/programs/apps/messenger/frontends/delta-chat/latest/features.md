# Delta Chat — Features

- Add contacts by QR code or invitation link; no public directory.
- Chatmail relays (defaults, can be changed); classic mail account only if used exclusively with chatmail apps.
- End-to-end encryption by default (OpenPGP subset, Autocrypt, Secure-Join), attachments included; fingerprints shown under "Encryption Info" for comparison.
- Push notifications designed not to expose profile data, IP addresses or content.
- Channels: owner posts, subscribers receive.
- Multi-device: second device by QR code on the same network, manual backup as fallback; several profiles per device.
- webxdc: sandboxed `.xdc` apps (games, polls, collaboration) without internet access.
- One-to-one audio and video calls on desktop, Ubuntu Touch, iOS and Android 8+.
- Independent security audits; latest named is rPGP in 2024.
