# Apple Mail iOS 26 — Menus

There is no menu bar on iOS. Commands sit in sheets, long-press menus and the "…" button.
✅ = seen · ⚠️ = inferred. Entries summarised in our own words.

## Main menu
### "…" button in the list ✅ (contents not opened ⚠️)
### Mailboxes (edit mode) ✅
Tick and reorder: Inbox, VIP, Flagged, Unread, To/Cc, Attachments, Thread notifications, Remind Me,
Follow Up, Send Later, Muted threads, … ; New mailbox.

### Message action sheet ✅
Reply · Reply All · Forward · Delete (red) as large tiles; then Remind Me; Unflag / Flag;
a row of flag colours (orange, red, purple, cyan, yellow, green, grey).

### Move sheet ✅
Header with a stacked preview of the selected mails and their senders/count; account title; list of
mailboxes with counts (Inbox, Drafts, Sent, Junk, Trash, Archive, own folders); search field.

### Contact card ✅
Add to VIP · (block contact ⚠️) · Search mails of this contact · Send message · Share contact ·
Add to favourites · Add to list. Edit button top right.

### Settings ✅
Privacy Protection → Protect Mail Activity. Mark Addresses → list of allowed domain endings.

### macOS View menu (current) ✅
Tab bar · Sort by › (attachments, date, Remind Me, Send Later, flags, from, size, subject, to, unread;
ascending/descending; inbox only/all mailboxes) · Filter › · Column layout · Preview below ·
Show date & time / To-Cc / size / contact photo / mail categories · About categories ·
Highlight conversations · Organise by conversation · Expand / collapse all conversations.

### macOS composer attach menu ✅
Attach files · Include attachments (disabled when not replying) · Photos · from a nearby iPad: take
photo, scan documents, add sketch.

## Context menus
### Long press on a message ✅
Preview of the mail on top; below: reply, reply all, forward as icons; Mark ›; Notify Me; Mute.

### Swipe menu ✅
Left swipe: More · Flag · Delete. Right swipe ⚠️ (known: read/unread).

## Menus by role
None — single-user client ✅ (no role-dependent entries seen).

## Outdated (macOS 10.12, 2016) ✅
Application menu: About, Settings (⌘,), Accounts, Add account, Services, Hide, Quit (⌘Q).
Preferences tabs: General, Accounts, Junk mail, Fonts & colours, Viewing, Composing, Signatures, Rules.
