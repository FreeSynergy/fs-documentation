# Spark

> Category: [messenger](../../index.md) · Type: e-mail client · Vendor: Spark Mail Limited (footer links to Readdle) · Licence: proprietary

## What it is

Spark is an e-mail client for existing accounts, available for Windows, Android, Mac, iPhone, iPad and Apple Watch. Besides personal mail it has team functions around single mails.

## Notable ideas

Why this program is documented here (ADR 0013):

- **Team comments**: private comments on a mail, turning a thread into a discussion visible only to collaborators; the sender never sees them. Relevant for us: discussion about a message without sending another mail.
- **Shared draft**: several people write a reply together.
- **Shared inbox** with roles under one address.
- **Smart Inbox** (priority versus rest) and **Send later**.
