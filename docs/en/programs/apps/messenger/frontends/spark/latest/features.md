# Spark — Features

From the vendor page:

- **Team Comments**: private, chat-like comments on an e-mail thread.
- **Private Comments**: visible only to collaborators.
- **Shared Draft**: real-time co-writing of a reply.
- **Shared Inbox**: team roles under one address.
- **Smart Inbox**: priority mail separated from the rest.
- **Send Later**: schedule delivery.
- Platforms: Windows, Android, Mac, iPhone, iPad, Apple Watch.
