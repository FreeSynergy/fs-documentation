# Zulip — Features

- Channels with topics; the topic is chosen when sending.
- Automatic reply into the open topic.
- Finding topics: left sidebar (recent topics), Inbox (unread topics), Recent conversations.
- Move content to another topic, resolve a topic, mute a topic (named in the help index).
- Use by e-mail: message a channel by e-mail.
- Integrations and bots through API documentation.
- Keyboard shortcuts, for example next unread topic.
