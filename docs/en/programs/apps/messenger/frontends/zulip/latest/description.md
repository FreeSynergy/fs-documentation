# Zulip — Description

## What the program does

Zulip splits each channel into topics. To write, you choose a channel and give a topic name; replies join the topic in view. Topics are started from the sidebar, the compose box or the mobile app.

## Differentiation

| Compared with | Difference |
|---------------|------------|
| Telegram topics | Telegram topics are admin-created spaces in large groups; in Zulip every message has one and anyone names it. |
| Discord/Element threads | Threads are optional side branches; in Zulip the topic is the main structure. |

## Who it suits

Teams and communities where several discussions run in parallel and people read asynchronously.
