### Help

### Message / Insert / Format text / Options (composer)

Later today · Tomorrow · This weekend · Next week · Choose a date — each with the resolved time.

### Settings → General ✅
Language and time · Appearance · Notifications · Accessibility · Distribution groups · Privacy and
data · Search · Offline · Links · Startup · About.

### Settings → Mail ✅
Layout · Compose and reply (undo send, celebration animations, autofill) · Smart suggestions ·
Attachments · Rules · Sweep · Junk email · Quick Steps · Customise actions · Message handling ·
Forwarding · Retention policies · Groups.

### Settings → Accounts ✅
Email accounts · Automatic replies · Signatures · Categories · Mobile devices · Storage.

### Classic: File backstage ✅
Info (account information) with: account settings, name and sync settings, delegate access,
download address book, change profile, manage profiles; automatic replies; cleanup; rules and alerts;
manage add-ins. Open & export, save as, save attachments, print.

### Classic: Send/Receive tab ✅
Send/receive all folders · update folder · send all · send/receive groups · show progress ·
cancel all · download headers · mark / unmark to download · process marked headers · work offline.
