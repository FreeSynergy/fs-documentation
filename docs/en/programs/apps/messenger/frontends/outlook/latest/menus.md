# Outlook - Menu Items

## Overview

Outlook is Microsoft's most popular email client, part of Microsoft 365. It combines email, calendar, tasks, and contacts in a single application.

## Main Menu Items

### 1. File (Backstage View)
- **Function**: File and account management
- **Details**:
  - Add/remove account
  - Account settings
  - Print options
  - Export/Import (PST, OST)
  - Options (Settings)

### 2. Home
- **Function**: Main email view
- **Details**:
  - New email
  - Reply/Forward
  - Folder navigation
  - Search
  - Filter and sort

### 3. Send/Receive
- **Function**: Email transmission
- **Details**:
  - Send/receive all folders
  - Refresh
  - Send/receive settings

### 4. View
- **Function**: Layout and display
- **Details**:
  - Refresh
  - Change current layout
  - Sort
  - Groups
  - Display options

### 5. Send/Receive
- **Function**: Email transmission
- **Details**:
  - Send/receive all folders
  - Refresh
  - Send/receive settings

### 6. Message
- **Function**: Message management (in message window)
- **Details**:
  - Reply/Forward
  - Move message
  - Mark
  - Categorize
  - Actions (Print, Forward)

### 7. Calendar
- **Function**: Appointment management
- **Details**:
  - New appointment
  - New recurring appointment
  - Open/edit appointment
  - Calendar sharing

### 8. Contacts
- **Function**: Contact management
- **Details**:
  - New contact
  - New contact folder
  - Edit contact
  - Import/export contacts

### 9. Tasks
- **Function**: Task management
- **Details**:
  - New task
  - Edit task
  - Change task status
  - Reminders

### 10. Notes
- **Function**: Manage notes
- **Details**:
  - New note
  - Edit note
  - Delete note

### 11. Share
- **Function**: Share folders
- **Details**:
  - Share calendar
  - Share contacts
  - Share emails
