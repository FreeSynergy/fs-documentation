# Signal — Description

## What the program does

Signal sends messages and makes calls over the data connection, encrypted end to end; the vendor states it cannot read messages or listen to calls. It supports groups and encrypted stickers.

## Differentiation

| Compared with | Difference |
|---------------|------------|
| Telegram | Encryption is the default for all chats, not a separate mode. |
| Delta Chat | One operator and its own protocol, versus mail-like relays. |

## Who it suits

People who want a simple, privacy-first messenger.

## Open

Phone-number requirement, usernames, disappearing messages, backups, linked devices, polls, stories: known from the product but not verified on a source read here. Not described.
