# Discord - Description

## Overview

Discord is a proprietary communication platform and chat client originally developed for gaming communities but now used for all kinds of communities. Discord offers voice-over-IP, video, text chat, and screen sharing.

## What Discord Does

Discord is a communication platform specifically designed for creating and managing communities. It enables group chat in servers with multiple channels, voice and video calls, as well as screen sharing for streaming and gaming.

## Advantages

- **Voice and Video Calls**: Native voice and video calls with high quality
- **Server Structure**: Organizing communities in servers with channels
- **Screen Sharing**: Native screen sharing for streaming
- **Gaming Focus**: Optimized for gaming communities
- **Cross-Platform**: Works on Windows, macOS, Linux, iOS, Android, Web
- **Integrations**: Many integrations with external services
- **Bots**: Extensive bot system for automation
- **Moderation**: Extensive moderation tools
- **Free**: Free for all features (with premium options)

## Distinction from Other Systems

### Discord vs. Element
- **Discord** is proprietary and centralized, **Element** is open source and decentralized
- **Discord** has native voice/video, **Element** has it via VoIP protocol
- **Element** has E2E encryption by default, **Discord** only in private messages
- **Discord** has more gaming features, **Element** has more privacy

### Discord vs. Telegram
- **Discord** has native voice/video, **Telegram** has it via VoIP
- **Discord** has server structure, **Telegram** has channels/groups
- **Telegram** has secret chats with E2E encryption, **Discord** only in private messages
- **Discord** has more moderation tools

### Discord vs. Mastodon
- **Discord** is for chat and groups, **Mastodon** is for microblogging
- **Discord** has voice/video, **Mastodon** has no voice/video
- **Discord** is centralized, **Mastodon** is decentralized across instances

## Technical Details

- **Platform**: Windows, macOS, Linux, iOS, Android, Web
- **Protocol**: Proprietary Discord protocol
- **Backend**: Custom Discord backend
- **Voice/Video**: WebRTC for voice/video calls
- **Encryption**: TLS for data transmission, no E2E encryption
- **Authentication**: OAuth2, Email/Password
- **Bots**: Discord bots via API
- **Programming Language**: TypeScript, React (Web), Kotlin (Android), Swift (iOS)

## Who is Discord Suitable For?

- **Gaming Communities**: For those who want to run gaming communities
- **Leisure Communities**: For those who want to run leisure communities
- **Companies**: For those who want to run team communication
- **Streamers**: For those who want to run streaming communities
- **Large Communities**: For those who want to run large communities
