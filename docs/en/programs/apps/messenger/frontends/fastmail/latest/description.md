# Fastmail — Description

## What the program does

Fastmail provides mail, calendar and contacts. The standout function is Masked Email: instead of giving out a real address, the person creates a random one for each service, sees it labelled, and can disable it.

## Differentiation

| Compared with | Difference |
|---------------|------------|
| Aliases (any provider) | Masked addresses are random, per login, disposable; aliases are meant to stay. |
| HEY | HEY decides about senders; Fastmail decides about the address you hand out. |

## Who it suits

People who want to give each service its own address and cut off leaks.

## Open

Deletion rules, limits and plan requirements for masked addresses: not stated on the page read.
