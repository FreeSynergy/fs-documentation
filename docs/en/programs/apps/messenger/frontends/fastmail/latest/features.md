# Fastmail — Features

- **Masked Email**: any user can create an address in the app; one per login; not linkable by companies; shown with a masked icon and the label given; disable an address at once; use of own domain possible.
- Connection with 1Password and Bitwarden.
- **Aliases** with own sender name or signature.
- Calendar and contacts apps exist; migration to Fastmail is offered.
