# Superhuman Mail — Description

## What the program does

It presents a person's existing mail in a fast interface. The inbox is split into lists (default and custom splits), and most actions run from the keyboard or from the command palette. Splits can be based on sender, domain, recipient, subject or label.

## Differentiation

| Compared with | Difference |
|---------------|------------|
| HEY | Keeps the usual inbox and speeds it up; no approval step for senders. |
| Spark | Spark stresses team work on mail; Superhuman stresses individual speed. |

## Who it suits

People with a very high mail volume who accept a paid, closed client.
