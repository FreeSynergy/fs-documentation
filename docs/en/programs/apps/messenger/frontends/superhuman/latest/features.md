# Superhuman Mail — Features

- **Split Inbox**: default and custom splits; created from a selected conversation through the command palette ("New Split Inbox"); conversations can be added to an existing split; splits can be enabled, disabled, deleted; a split can hide itself when empty and stays reachable through the palette.
- **Command palette** (Cmd+K, Ctrl+K on Windows); two-finger tap on mobile.
- Vendor page: Auto Drafts, Auto Labels, Auto Archive, availability sharing.
