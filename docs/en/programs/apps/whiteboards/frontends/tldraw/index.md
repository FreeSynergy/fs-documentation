# tldraw

> Category: [whiteboards](../../index.md)

## What it is

tldraw is an open-source infinite-canvas whiteboard library and app in TypeScript: ready to use on tldraw.com and as a React SDK (`tldraw`) for your own canvas applications. Files are local-first, multi-user operation runs via sync servers or the hosted sync cloud.
