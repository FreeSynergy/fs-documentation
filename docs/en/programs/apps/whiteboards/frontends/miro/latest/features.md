# Miro - Features

## Main features

### Canvas and content
- Infinite canvas with shapes, sticky notes (colours, grouping), frames, tables, mindmap/organisation-chart auto-layout, diagram libraries (UML, flow, network)
- Images/video/PDF slides, upload import (PDF→frames), "image editor" (AI cut-out, plan-dependent)

### Real-time moderation
- Multiplayer cursor, presenter/follow mode, timer, voting, sections, reactions
- Comment mode for asynchronous reviews

### Structure and templates
- Thousands of templates (retros, EPIC, canvas formats), team templates, board status/folders
- **Miro Academy** learning paths (Enterprise)

### Apps and integrations
- Miro apps (Jira/Confluence sync, Asana, Slack, forms, developers: your own apps in the App Kit)
- MiroIQ analytics, enterprise search

## What Miro does NOT do

- **no self-hosting** (data residency only as a US/EU choice, Enterprise)
- **not usable offline** (web/app are live)
- **free tier is limited**: 3 boards, guest limits
- **no real file storage**: export/PDF, but no folder/DMS model
- The API covers items, but **no external live presentation control** (the presenter API is restricted)
