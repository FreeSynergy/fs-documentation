# Miro - Menu items

## Board menu (Miro logo, top left)

- Export board (PNG/PDF/Miro format), board settings, print, version history ("board history"), accessibility options

## Left toolbar

Selection · hand · connectors (arrows) · shapes · sticky notes · frames · text · pen · connector arrows · tables · code blocks · mindmap · diagram libraries · apps (counter, timer, voting, scrum apps, FigJam/Notion bridges)

## Right sidebar (pages)

- Board pages (sheets) with thumbnails, duplication, templates

## Moderation menu (for workshop facilitation)

- Multiplayer controls: presenter mode, "follow me", timer, mute, sections, heatmap (Enterprise)

## Team/admin menu (avatar)

| Area | Content |
|------|---------|
| Teams & boards | team boards, favourites, search |
| Templates | manage team templates |
| Analytics (MiroIQ) | board usage, activity metrics (Enterprise) |
| Admin (Enterprise) | SSO/SAML, SCIM, guest access, data residency (EU/US) |

## Menus by role

Owner · editor · commentator · viewer — the tool toolbar only for editor and above.
