# Miro - Description

## What the program does

Miro is the virtual workshop room: an unlimited whiteboard where teams paste, draw, vote and present at the same time. It replaces moderation walls — with templates so that nobody has to start from a blank page.

## Advantages

- **Moderation tools** (timer, voting, presenter) out of the box
- **Template quality** is the industry reference
- **API + App Kit** for integrations into tool landscapes

## Differentiation

| System | Difference |
|--------|------------|
| **Mural** | similar focus (workshops), older, smaller app ecosystem |
| **Excalidraw** | minimalist, OSS; Miro is the full build-out |
| **tldraw** | SDK/developer perspective; Miro is an end-user suite |

## Technical details

- **Model**: SaaS (teams, guest boards), data residency EU/US (Enterprise)
- **Clients**: web, desktop (Electron), iPad optimisation
- **Authentication**: email/Google/Microsoft/SSO (SAML/SCIM Enterprise); API OAuth2
- **Pricing**: Free/Starter/Business/Enterprise (board/guest limits in the free plan)

## Who it suits

- Workshop and product teams with a large need for moderation
- FreeSynergy skins: frame/sticky/connector elements as the standard building-block set ([components](../../../../../../components/index.md)))
