# Miro Documentation

## Overview

Miro is the commercial online whiteboard (SaaS) for visual collaboration: infinite canvas, shapes/sticky notes, frames, template library (retros, workshops, customer journeys), voting/timer and board apps. REST API (REST + GraphQL beta), no self-host option.
