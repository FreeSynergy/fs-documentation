# OpenBoard - Menu items

## Full-screen tool strips

OpenBoard has no classic menu bar — the strips fold out sideways:

| Strip/area | Content |
|------------|---------|
| Main toolbar (left, vertical) | Pen, highlighter, eraser, selection, text, shapes, image, screenshot tool |
| Pen submenu (expanded) | Colours, line widths, highlighter mode |
| Document tools | new page/duplicate page, duplicate/delete pages, thumbnail overview |
| Library (bottom, collapsible) | Images, stacks/object collections, documents (.obz), web browser tool, document viewer |
| Capture | Screen recording (video) + playback overlay |

## Document menu

- New / open / save / save as (.obz) / export PDF / print
- Page management: add, duplicate, delete, reorder

## Menus by role

No accounts/roles — a single-workstation application (shared whiteboards via machine/OS profiles).
