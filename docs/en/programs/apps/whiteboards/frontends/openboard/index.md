# OpenBoard Documentation

## Overview

OpenBoard is a free interactive whiteboard tool (C++, Qt) for teaching and presentations: multi-page "boards", pens/text/images, integrated browser, document and note tools, offline-first with a local library. The open-source successor to the SMART Notebook way of thinking.
