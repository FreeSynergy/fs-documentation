# Mural - Keyboard shortcuts

## Overview

Mural lists its shortcuts in the menu ("Keyboard shortcuts"). This entry is reduced to the safe ones; please verify the rest in the client.

> As of: 2026.

## Available

| Shortcut | Purpose |
|----------|---------|
| `V` | Selection |
| `H` | Hand/pan |
| `N` | New note |
| `T` | Text |
| `Ctrl/Cmd+Z` / `+Shift+Z` | Undo / redo |
| `Ctrl/Cmd+C` / `+V` / `+D` | Copy / paste / duplicate |
| `Del` | Delete selection |
| `Ctrl/Cmd+A` | Select all |
| `Esc` | Leave selection/editor |

## Explicitly unconfirmed

- Single-letter shape keys (`R`/`O`) differ by version — use the menu legend

## Mac

`Cmd` instead of `Ctrl`.
