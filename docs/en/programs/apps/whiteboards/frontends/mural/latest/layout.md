# Mural - Structure and UI/UX

## Page structure

```
┌───────────────────────────────────────────────────────────────────┐
│ ◀ Workspace   "Q4 Retro"   ⋯ Share   👥 (7)                      │
│ ┌Sequence: step 2/5 · Retro collection · 10:00 ⏱┐                │
│ ├────────────────────────────────────────────────┤                │
│ │      (canvas with areas/notes)                 │                │
│ │   🟦🟦🟦   🟨🟨   🟩🟩🟩                        │                │
│ └────────────────────────────────────────────────┘                │
│        [V N T R …]  (toolbar at the bottom)     Zoom 43%          │
└───────────────────────────────────────────────────────────────────┘
```

- The sequence bar at the top shows moderation steps plus timer; the toolbar sits bottom centre

## UI/UX

- Reduced, dark chrome elements, light canvas; areas as structured zones
- Notes carry the author's colour

## Interactions

- Multiplayer cursors, "follow the facilitator", notes can be grouped
- Drag & drop, Shift+drag = selection rectangle

## Responsive design

- Web + desktop app; mobile for viewing/quick edits

## Accessibility

- Keyboard for note/shape tools; sequence control by click/keyboard
- Mural publishes accessibility statements (enterprise area)
