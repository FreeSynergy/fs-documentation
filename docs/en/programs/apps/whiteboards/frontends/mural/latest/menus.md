# Mural - Menu items

## Mural menu (Mural logo)

- Export mural (PNG), duplicate, print, activity log, versions

## Toolbar (bottom/left)

Selection · text · shapes · freehand · note (Post-it) · connector arrows · image · table · frame · "shape" libraries · voting · timer · "sequence" (moderation flow) · reaction

## Mural settings (⋯)

- Title/visibility (private/team/public link), invitations (editor/commentator), "follow" control, areas divide large mural surfaces

## Sessions/facilitation

- Moderator mode: name display, timer, "silence" control, highlighting participants
- "Breakout boards" (Enterprise)

## Workspace menu (top)

| Area | Content |
|------|---------|
| Mural overviews | search, favourites, workspace folders |
| Template library | moderation formats, team templates |
| Admin (Enterprise) | SSO (SAML/SCIM), data residency (EU), guest rules |

## Menus by role

Owner · editor · commentator · viewer; sequence control only for the facilitator.
