# Mural

> Category: [whiteboards](../../index.md)

## What it is

Mural is the workshop whiteboard suite (SaaS) with strong facilitation: canvas with shapes/notes, "Facilitation Sequence" (moderation flows), participation control and templates. The API surface is markedly smaller than Miro's.
