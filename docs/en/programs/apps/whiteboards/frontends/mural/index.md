# Mural Documentation

## Overview

Mural is the workshop whiteboard suite (SaaS) with strong facilitation: canvas with shapes/notes, "Facilitation Sequence" (moderation flows), participation control and templates. The API surface is markedly smaller than Miro's.

## File structure

- [menus.md](latest/menus.md) - Toolbar, Mural menu, moderation points
- [features.md](latest/features.md) - Sequences, sessions, what Mural does NOT do
- [description.md](latest/description.md) - How it differs from Miro, Jamboard, FigJam
- [layout.md](latest/layout.md) - Mural canvas, area layout
- [shortcuts.md](latest/shortcuts.md) - Shortcuts
- [api.md](latest/api.md) - REST (Mural's own API), no broad public API (current state)
