# Mural Documentation

## Overview

Mural is the workshop whiteboard suite (SaaS) with strong facilitation: canvas with shapes/notes, "Facilitation Sequence" (moderation flows), participation control and templates. The API surface is markedly smaller than Miro's.

## File structure

- [menu.md](../../masks/mural/menu.md) - Toolbar, Mural menu, moderation points
- [features.md](../../masks/mural/features.md) - Sequences, sessions, what Mural does NOT do
- [description.md](../../masks/mural/description.md) - How it differs from Miro, Jamboard, FigJam
- [structure.md](../../masks/mural/structure.md) - Mural canvas, area layout
- [shortcuts.md](../../masks/mural/shortcuts.md) - Shortcuts
- [api.md](../../masks/mural/api.md) - REST (Mural's own API), no broad public API (current state)
