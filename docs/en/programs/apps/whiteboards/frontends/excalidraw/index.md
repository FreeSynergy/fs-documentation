# Excalidraw - Documentation

## Overview

Excalidraw is a free, open-source collaborative whiteboard in a hand-drawn style. It runs in the browser, requires no sign-up and shares canvases via end-to-end-encrypted links.

## File structure

- [description.md](../../masks/excalidraw/description.md) - Description, advantages and how it differs from draw.io, Miro and tldraw
- [menu.md](../../masks/excalidraw/menu.md) - All menu items, plus menu and context menus
- [features.md](../../masks/excalidraw/features.md) - Drawing tools, object model, collaboration, libraries
- [structure.md](../../masks/excalidraw/structure.md) - UI/UX, canvas layout, colour scheme and themes
- [shortcuts.md](../../masks/excalidraw/shortcuts.md) - All keyboard shortcuts and gestures
