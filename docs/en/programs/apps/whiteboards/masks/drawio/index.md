# draw.io - Documentation

## Overview

draw.io (diagrams.net) is a free diagram tool for flowcharts, network plans, UML and BPMN. Diagrams are stored as an open XML format; the app exists as a web app, a desktop program (Electron) and a self-hosted instance.

## File structure

- [description.md](description.md) - Description, advantages and how it differs from Excalidraw, Miro and PlantUML
- [menu.md](menu.md) - Menu bar (File, Edit, View, Arrange, Extras, Help) and context menus
- [features.md](features.md) - Shape libraries, mxCell object model, realtime sync, exports
- [structure.md](structure.md) - UI/UX, panels and canvas layout
- [shortcuts.md](shortcuts.md) - All keyboard shortcuts of the surface
- [api.md](api.md) - Embedding (postMessage), URL parameters, plugins, CLI (no public REST API)
