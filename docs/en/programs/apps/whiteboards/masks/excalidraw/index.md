# Excalidraw - Documentation

## Overview

Excalidraw is a free, open-source collaborative whiteboard in a hand-drawn style. It runs in the browser, requires no sign-up and shares canvases via end-to-end-encrypted links.

## File structure

- [description.md](description.md) - Description, advantages and how it differs from draw.io, Miro and tldraw
- [menu.md](menu.md) - All menu items, plus menu and context menus
- [features.md](features.md) - Drawing tools, object model, collaboration, libraries
- [structure.md](structure.md) - UI/UX, canvas layout, colour scheme and themes
- [shortcuts.md](shortcuts.md) - All keyboard shortcuts and gestures
- [api.md](api.md) - File format, collaboration protocol and embedding (no public REST API)
