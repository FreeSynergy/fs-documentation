# Miro Documentation

## Overview

Miro is the commercial online whiteboard (SaaS) for visual collaboration: infinite canvas, shapes/sticky notes, frames, template library (retros, workshops, customer journeys), voting/timer and board apps. REST API (REST + GraphQL beta), no self-host option.

## File structure

- [menu.md](menu.md) - Toolbar, board menu, moderation tools
- [features.md](features.md) - Templates, MiroIQ, apps, what Miro does NOT do
- [description.md](description.md) - How it differs from Mural, Excalidraw, tldraw
- [structure.md](structure.md) - Canvas + toolbar + page tabs
- [shortcuts.md](shortcuts.md) - Miro shortcuts
- [api.md](api.md) - REST board/items/members, OAuth2, webhooks
