# Mural Documentation

## Overview

Mural is the workshop whiteboard suite (SaaS) with strong facilitation: canvas with shapes/notes, "Facilitation Sequence" (moderation flows), participation control and templates. The API surface is markedly smaller than Miro's.

## File structure

- [menu.md](menu.md) - Toolbar, Mural menu, moderation points
- [features.md](features.md) - Sequences, sessions, what Mural does NOT do
- [description.md](description.md) - How it differs from Miro, Jamboard, FigJam
- [structure.md](structure.md) - Mural canvas, area layout
- [shortcuts.md](shortcuts.md) - Shortcuts
- [api.md](api.md) - REST (Mural's own API), no broad public API (current state)
