# tldraw - Documentation

## Overview

tldraw is an open-source infinite-canvas whiteboard library and app in TypeScript: ready to use on tldraw.com and as a React SDK (`tldraw`) for your own canvas applications. Files are local-first, multi-user operation runs via sync servers or the hosted sync cloud.

## File structure

- [description.md](description.md) - Description, advantages and how it differs from Excalidraw, draw.io and Miro
- [menu.md](menu.md) - Main menu, toolbar, style panel and context menus
- [features.md](features.md) - Tools, Record data model, multiplayer, SDK
- [structure.md](structure.md) - UI/UX, panels and canvas layout
- [shortcuts.md](shortcuts.md) - Keyboard shortcuts of the app and build commands of the SDK
- [api.md](api.md) - SDK API, sync protocol, snapshot format (no public REST API)
