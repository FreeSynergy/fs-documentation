# Logseq - Features

## Main features

- Block references (window onto another block) versus block embeds (portal that can be edited in place) — per a forum post; official page for this was not readable (Open).
- Nodes have Linked and Unlinked References sections.
- DB graphs: tags with inherited properties and multiple parents; property types Text, Number, Date, DateTime, Checkbox, Url, Node; pages unique per tag.
- Tasks: status property (Backlog, Todo, Doing, In Review, Done, Canceled), per-block status history, repeats.
- Queries tagged Query, via query builder or advanced queries; views table, list, gallery.
- File to DB importer for Markdown graphs.
- Platforms: desktop, web app, iOS (DB version alpha per repository), plugin API; Docker web app guide.
- DB version status: a third-party review says public beta began 2026-07-13 (Open, not vendor-confirmed).
