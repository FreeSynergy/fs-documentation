# MediaWiki - Keyboard Shortcuts

## Overview

MediaWiki offers extensive keyboard shortcuts for working quickly with the two
main editors: the visual VisualEditor and the source-code editor (WikiText).

---

## General shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Shift+P` / `Cmd+Shift+P` | Open the command palette |
| `Ctrl+,` / `Cmd+,` | Open the settings |
| `F1` | Help |
| `Ctrl+K` / `Cmd+K` | Add a link |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | Global search |

## Source-code editor (WikiText) shortcuts

### Formatting (Wiki syntax)

| Shortcut | Function |
|----------|----------|
| `Ctrl+B` / `Cmd+B` | Bold (`'''text'''`) |
| `Ctrl+I` / `Cmd+I` | Italic (`''text''`) |
| `Ctrl+Shift+L` / `Cmd+Shift+L` | Bullet list (`*`) |
| `Ctrl+Shift+N` / `Cmd+Shift+N` | Numbered list (`#`) |
| `Ctrl+Shift+1` / `Cmd+Shift+1` | H2 (`==`) |
| `Ctrl+Shift+2` / `Cmd+Shift+2` | H3 (`===`) |
| `Ctrl+Shift+3` / `Cmd+Shift+3` | H4 (`====`) |
| `Ctrl+K` / `Cmd+K` | Link (`[[Page|Name]]`) |
| `Ctrl+Shift+M` / `Cmd+Shift+M` | Quote (`>`) |

### Navigation in the code

| Shortcut | Function |
|----------|----------|
| `Enter` | New line |
| `Tab` / `Shift+Tab` | Indent |
| `Ctrl+Z` / `Cmd+Z` | Undo |
| `Ctrl+Y` / `Cmd+Y` | Redo |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | Toggle syntax highlighting |

### Quick access to the Wiki syntax

| Shortcut | Function | Example |
|----------|----------|---------|
| `Ctrl+Shift+L` / `Cmd+Shift+L` | Internal link | `[[Page|Name]]` |
| `Ctrl+Shift+E` / `Cmd+Shift+E` | External link | `[http://example.com Name]` |
| `Ctrl+Shift+D` / `Cmd+Shift+D` | Image | `[[File:Image.jpg|Thumb]]` |
| `Ctrl+Shift+V` / `Cmd+Shift+V` | Template | `{{Template}}` |
| `Ctrl+Shift+T` / `Cmd+Shift+T` | Table | `{| ... |}` |

## Summary

MediaWiki offers extensive shortcuts for:
- **Visual editor**: standard formatting, tables, templates
- **Source-code editor**: quick access to the wiki syntax, code navigation
- **Navigation**: inside the editor and between components
- **File operations**: save, open, print, export
- **Search**: local and global
- **View**: full screen, sidebar, preview

Mac users get the same shortcuts with `Cmd` instead of `Ctrl`.
