# MediaWiki - Description

## Overview

MediaWiki is the most popular wiki software, used among others by Wikipedia.
The menu depends heavily on user rights.

## What MediaWiki does

MediaWiki is a free software wiki application developed specifically for
creating multilingual knowledge bases. It is the most widely used wiki software
in the world.

## Advantages

- **Established**: very stable and well tested
- **Scalable**: can manage large communities with millions of pages
- **Community**: a large community with many extensions
- **Free**: open source and free
- **Multiple languages**: strong multi-language support
- **Powerful templates**: complex template system
- **API**: extensive API for integrations

## Differentiation from other systems

### MediaWiki vs. Wiki.js
- **MediaWiki** is established (Wikipedia) but more complex
- **Wiki.js** is more modern and easier to use
- **MediaWiki** has more extensions, **Wiki.js** is more lightweight

### MediaWiki vs. XWiki
- **XWiki** is enterprise-ready with complex permissions
- **MediaWiki** is simpler for community projects
- **XWiki** has a better macro system, **MediaWiki** is more widespread

### MediaWiki vs. Confluence
- **Confluence** is commercial and comes with licence costs
- **MediaWiki** is open source and free
- **Confluence** has better Jira integration, **MediaWiki** is freer

## Technical details

- **Backend**: PHP
- **Database**: PostgreSQL, MySQL, MariaDB
- **Frontend**: JavaScript, PHP templates
- **Authentication**: local accounts, OAuth, LDAP
- **Hosting**: self-hosted or cloud

## Who MediaWiki suits

- **Large community projects**: like Wikipedia, Wiktionary, etc.
- **Open-source projects**: for community documentation
- **Educational institutions**: for teaching materials and wikis
- **Technical documentation**: with the right extensions
