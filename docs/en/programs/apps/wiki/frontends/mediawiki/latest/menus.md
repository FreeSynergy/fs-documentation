# MediaWiki - Menu Items

## Overview

MediaWiki is the most popular wiki software, used by Wikipedia among others. The menu depends heavily on user permissions.

## Main Menu Items

### 1. Main Page
- **Function**: Navigates to the main page
- **Details**: Standard start page, can be customized individually

### 2. Pages
- **Function**: List all available pages
- **Details**:
  - Special pages
  - Categories
  - Files
  - Templates

### 3. Actions (Sidebar)
- **Function**: Page-related actions
- **Details**:
  - Read (view)
  - Edit (edit)
  - View source (view source)
  - History (history)
  - Discussion (talk)
  - Version differences (history)
  - Watch/unwatch (watch/unwatch)
  - Print page

### 4. Tools (Sidebar)
- **Function**: System tools
- **Details**:
  - What links here?
  - Related changes
  - New pages
  - Special pages
  - Printable version

### 5. Special Pages
- **Function**: Call system functions
- **Details**:
  - User contributions
  - Upload
  - List of uncategorized pages
  - List of untranslated pages
  - Random page

### 6. User Menu (top right)
- **Function for registered users**:
  - Discussion page
  - Contributions
  - Create account
  - Log in
  - Log out

- **Function for logged-in users**:
  - Discussion page
  - Contributions
  - Watchlist
  - Changes in the watchlist
  - Preferences
  - Login status

### 7. Interwiki Links
- **Function**: Links to other wikis
- **Details**: References to related projects

## Menus by User Role

### Anonymous (Guest)
- Main page
- Page
- Discussion
- Read
- Edit
- Source
- History
- View
- Special pages
- Tools

### Registered User
- All functions of a guest user plus:
- Watchlist
- User account
- Preferences
- Notifications

### Administrator (Sysop)
- All functions plus:
- Delete/restore pages
- Protect page
- Block users
- Rename
- Delete files
- View logs

## Context Menus

### Edit Menu
- Edit source
- Visual Editor
- Preview
- Summarize changes

### Version Menu
- Show differences
- Restore page
- History

### Discussion Menu
- Add new section
- Edit section
- Close discussion
