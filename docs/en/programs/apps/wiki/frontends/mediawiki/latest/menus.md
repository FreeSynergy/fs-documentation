# MediaWiki - Menu items

## Overview

MediaWiki is the most popular wiki software, used among others by Wikipedia.
The menu depends heavily on user rights.

## Main menu items

### 1. Main page
- **Function**: navigates to the main page
- **Details**: the standard start page, can be customised

### 2. Pages
- **Function**: list all available pages
- **Details**:
  - special pages
  - categories
  - files
  - templates

### 3. Actions (sidebar)
- **Function**: actions for the current page
- **Details**:
  - read (view)
  - edit
  - view source
  - history
  - discussion (talk)
  - version differences (history)
  - watch/unwatch the page
  - print the page

### 4. Tools (sidebar)
- **Function**: system tools
- **Details**:
  - what links here
  - related changes
  - new pages
  - special pages
  - printable version

### 5. Special pages
- **Function**: call system functions
- **Details**:
  - user contributions
  - upload
  - list of orphaned pages
  - list of unlocalised pages
  - random page

### 6. User menu (top right)
- **Function for registered users**:
  - discussion page
  - contributions
  - create an account
  - log in
  - log out

- **Function for logged-in users**:
  - discussion page
  - contributions
  - watchlist
  - changes on the watchlist
  - settings
  - login status

### 7. Interwiki links
- **Function**: links to other wikis
- **Details**: references to related projects

## Menus by user role

### Anonymous (guest)
- main page
- page
- discussion
- read
- edit
- source
- history
- view
- special pages
- tools

### Registered user
- all functions of a guest user plus:
- watchlist
- user account
- settings
- notifications

### Administrator (sysop)
- all functions plus:
- delete/restore pages
- protect a page
- block users
- rename
- delete files
- view the logs

## Context menus

### Editing menu
- edit the source
- visual editor
- preview
- summarise the changes

### Version menu
- show the differences
- restore the page
- history

### Discussion menu
- add a new section
- edit a section
- end the discussion
