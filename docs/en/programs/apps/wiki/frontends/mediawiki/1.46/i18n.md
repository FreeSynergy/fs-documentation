## RTL in Vector 2022

- Core sets `dir` per language through the localisation data. Vector 2022 uses the Codex tokens and LESS; whether Vector flips each layout rule for RTL (logical properties or a separate RTL stylesheet) was not verified in this run.
- Do not assume a mirrored layout from the existing page. It did not state RTL behaviour, and this file does not claim it.

## Plural and grammar

MediaWiki messages use a parameter syntax (`{{PLURAL:...}}`, `{{GENDER:...}}`) in message text. Examples: `tooltip-pt-userpage` uses `{{GENDER:|Your user}}`, `tooltip-pt-mycontris` uses `{{GENDER:|your}}`. Source: `languages/i18n/en.json`.

## Notes for our frontend

- Keep every UI string in a message table with named parameters. Do not build sentences by concatenation.
- Use the locale's direction per text, and handle the direction mark for mixed content.
- Gender and plural rules need a plural engine in our own i18n; MediaWiki's syntax is not required as a format.
