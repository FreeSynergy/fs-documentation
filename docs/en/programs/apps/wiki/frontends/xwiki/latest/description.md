# XWiki - Description

## Overview

XWiki is a powerful enterprise wiki platform with advanced functions for
knowledge management and collaboration.

## What XWiki does

XWiki is an enterprise wiki platform based on Java, conceived for large
businesses and organisations with high demands on scalability, security and
integration.

## Advantages

- **Enterprise-ready**: scalable for large organisations with many users
- **Java-based**: stable and robust at the Java level
- **Macro system**: an extremely flexible macro system for complex content
- **Velocity scripting**: a powerful server-side scripting language
- **Two-level permissions**: page-level and space-level permissions
- **Import/export**: several formats (Word, PDF, HTML, XML)
- **REST API**: extensive API for integrations

## Differentiation from other systems

### XWiki vs. MediaWiki
- **MediaWiki** is optimised for large community projects like Wikipedia
- **XWiki** is optimised for enterprise users with complex permissions
- **XWiki** has a flexible macro system, **MediaWiki** is simpler

### XWiki vs. Confluence
- **Confluence** is commercial and comes with licence costs
- **XWiki** is open source and free (an enterprise version is available)
- **Confluence** has better Jira integration, **XWiki** is more flexible

### XWiki vs. Notion
- **Notion** is for agile teams and quick writing
- **XWiki** is for structured enterprise documentation
- **XWiki** has better versioning and audit logs

## Technical details

- **Backend**: Java (servlet container)
- **Database**: PostgreSQL, MySQL, HSQLDB, Oracle
- **Frontend**: JavaScript, Velocity templates
- **Authentication**: LDAP, SSO, OpenID Connect
- **Hosting**: self-hosted or cloud

## Who XWiki suits

- **Large businesses**: for complex knowledge management systems
- **Open-source projects**: for structured documentation
- **Businesses using Jira/Confluence**: as an open-source alternative
- **Educational institutions**: for structured teaching materials
