# XWiki - Menu items

## Overview

XWiki is a powerful enterprise wiki platform with advanced functions for
knowledge management and collaboration.

## Main menu items

### 1. Home / start page
- **Function**: navigates to the main page
- **Details**: a personalised start page with activities, favourites and important documents

### 2. All pages
- **Function**: browse all the wiki pages
- **Details**:
  - hierarchical display
  - search function
  - filter options
  - sorting by date, name, etc.

### 3. Dashboard
- **Function**: overview dashboard
- **Details**:
  - activity stream
  - my tasks
  - notifications
  - statistics

### 4. Watchlist
- **Function**: manage the watched pages
- **Details**:
  - change notifications
  - watched documents
  - notification settings

### 5. Tags
- **Function**: tag management
- **Details**:
  - show tags
  - tag-based search
  - tag cloud

### 6. Templates
- **Function**: manage templates
- **Details**:
  - create templates
  - template library
  - applying templates

### 7. Administration
- **Function**: system administration
- **Details**:
  - wiki settings
  - user management
  - group management
  - rights management
  - preferences

### 8. Tools
- **Function**: additional tools
- **Details**:
  - import/export
  - migration
  - backup
  - monitoring

### 9. Extensions
- **Function**: extension manager
- **Details**:
  - installed extensions
  - new extensions
  - extension updates

### 10. Search
- **Function**: advanced search
- **Details**:
  - full-text search
  - filter by type, author, date
  - faceted search

### 11. Notifications
- **Function**: notification centre
- **Details**:
  - system notifications
  - mentions
  - update notifications

### 12. Profile
- **Function**: user profile
- **Details**:
  - personal data
  - avatar
  - preference settings
  - notification settings
