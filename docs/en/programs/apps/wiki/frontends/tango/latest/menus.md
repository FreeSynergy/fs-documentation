# Tango: menus

Only items confirmed in help text are listed. No full menu tree was found.

## Entry points

- **Browser toolbar icon** (Tango): opens the side panel ([install](https://help.tango.ai/en/articles/5971659-how-do-i-install-tango-for-the-first-time), [pin](https://help.tango.ai/en/articles/5971657-how-do-i-pin-my-chrome-extension)). Help article: "How do I install Tango for the first time?"
- **Side panel, purple button** on the starting page: starts a capture ([documentation how-to](https://help.tango.ai/en/articles/7966907-how-do-i-use-tango-for-documentation)). Label reported as "Start Capture" in [start capture](https://help.tango.ai/en/articles/5971654-how-do-i-start-capturing-a-workflow).
- **Capture controller:** Complete, Pause, Restart, Discard.
- **Editor:** Edit; Add steps → Capture more steps ([step limit](https://help.tango.ai/en/articles/6325769-are-there-limits-to-how-many-steps-i-can-capture-in-a-workflow)).
- **Share & Export:** share link, email to teammate, Copy HTML, copy link, embed; export PDF/Markdown/HTML on Pro/Ent ([documentation how-to](https://help.tango.ai/en/articles/7966907-how-do-i-use-tango-for-documentation)).
- **Team Library bulk bar:** Edit Author (admins), Move to, Duplicate, Share, Delete (to archive) ([bulk actions](https://help.tango.ai/en/articles/16652169-how-do-i-use-bulk-actions-in-the-team-library)).
- **Settings & members → Branding** (admins) ([branding](https://help.tango.ai/en/articles/5971709-can-i-add-my-own-branding-to-tango-workflows)).

## Menus by role

- **Admin:** Edit Author, branding, members, audit log download ([audit log](https://help.tango.ai/en/articles/13259730-how-do-i-download-a-workspace-wide-audit-log)).
- **Creator:** capture, edit, share. Exact permission list not read.
- **View-only / Guest:** can view shared guides in the workspace. Exact limits not read ([team workspaces](https://help.tango.ai/en/collections/3466202-team-workspaces)).
