# Tango: limits

## Capture

- Browsers: Google Chrome and Microsoft Edge only. "Other browsers are not supported, including Arc." No Firefox or Safari extension ([where it works](https://help.tango.ai/en/articles/17359491-where-does-tango-work), [capture limits](https://help.tango.ai/en/articles/7216290-are-there-limitations-to-what-tango-can-capture)).
- Desktop app: Mac (ARM, x64) and Windows 10/11 only. No Linux ([where it works](https://help.tango.ai/en/articles/17359491-where-does-tango-work)). Requires Pro or Enterprise ([desktop](https://help.tango.ai/en/collections/3462416-desktop)).
- Desktop app capture is "less precise" than the extension's instructions ([capture limits](https://help.tango.ai/en/articles/7216290-are-there-limitations-to-what-tango-can-capture)).
- Not captured well: iframes, interactive canvas apps. Google Docs, Sheets, Slides document areas (canvas). Figma and Webflow unsupported ([capture limits](https://help.tango.ai/en/articles/7216290-are-there-limitations-to-what-tango-can-capture)).
- Excluded: Chrome Settings pages, Chrome Web Store ([where it works](https://help.tango.ai/en/articles/17359491-where-does-tango-work)).
- Certain modals: not listed; unverified.
- Remote desktops (Citrix, Splashtop, VDI): only when the extension or Desktop app runs inside the session ([where it works](https://help.tango.ai/en/articles/17359491-where-does-tango-work)).
- Phones and tablets: no capture, no mobile app. Shared guides open in a mobile browser ([where it works](https://help.tango.ai/en/articles/17359491-where-does-tango-work)).

## Guides

- Up to 1000 steps per guide. Very long guides may load slowly ([step limit](https://help.tango.ai/en/articles/6325769-are-there-limits-to-how-many-steps-i-can-capture-in-a-workflow)).
- Desktop-captured guides: no Guide Me, no Live Blur, no Voice Transcription ([where it works](https://help.tango.ai/en/articles/17359491-where-does-tango-work)).
- AI Agent: web apps in Chrome or Edge only; no desktop software ([where it works](https://help.tango.ai/en/articles/17359491-where-does-tango-work)).

## Plans and seats

- Free: 5 shared workflows, up to 10 users per workspace ([pricing](https://www.tango.ai/pricing)).
- Pro: unlimited workflows; each extra Pro user is a paid seat ([pricing](https://www.tango.ai/pricing)).
- Pro: version history 14 days; Enterprise: 365 days ([pricing](https://www.tango.ai/pricing), [security](https://help.tango.ai/en/collections/3337935-security)).
- Pricing (annual vs. monthly mapping is inferred from the page order; the page does not label it clearly, so verify before use): Pro $22 (1–2 users) / $15 (3+ users) per user per month, annual; $30 / $20 monthly. Enterprise: custom.

## Not documented

- Storage quotas, file size limits, screenshot count limits, API rate limits (none exist).
