# Tango: themes and visual style

## What is customisable (admins, Pro/Enterprise)

Via Settings & members → Branding ([branding](https://help.tango.ai/en/articles/5971709-can-i-add-my-own-branding-to-tango-workflows)):

- **Logo**: applied to shared links, embeds, PDFs and other exports.
- **Action box colours**: custom colours for the action box on steps.
- **Badge**: "Created with Tango" badge can be hidden in all formats (Show Tango Badge toggle).
- **Logo on title slide** (embeds) and **final page** (PDF).
- **Watermarks**: Tango watermarks can be removed from screenshots in PDF, HTML and Markdown exports.

## Not documented

- Light/dark theme choice for viewers or editor: none found.
- Fonts, font sizes, spacing, radii, grid: none found. The branding article lists no font setting.
- Colours of the web app UI: not user-selectable as far as sources show.

## Viewer style

Guides are shown in a fixed layout per view type (link, embed, Guide Me, export). A rebuild in another style needs the step data (title, description, image, highlight position), not the Tango CSS. Visual details of the highlight box were not documented in any source read.

## Rebuild notes

- "What can be rebuilt": the step sequence with per-step text and screenshot, the branding fields above, and the view types (scroll, slideshow, walkthrough).
- The look of the Tango UI itself (colours, icons) must not be copied. Describe layout in our own terms.
