# Tango: description

## What it does

Records a process as the user performs it in a web app (Chrome or Edge extension) or in desktop software (Desktop app, Pro/Enterprise). It creates a list of steps. Each step has a screenshot, a highlight, and a generated description. The user can edit titles, descriptions and images, then share or export the guide ([start capture](https://help.tango.ai/en/articles/5971654-how-do-i-start-capturing-a-workflow), [documentation how-to](https://help.tango.ai/en/articles/7966907-how-do-i-use-tango-for-documentation)).

Vendor positions it as process documentation and in-app guidance: "Turn any process into a shareable how-to guide in minutes." It also offers automations and data-extraction rules on the product page ([tango.ai](https://www.tango.ai/)).

## Unit of content

- A **Tango** (also "Workflow" in older help articles) is the guide object: title, steps, images, text, sharing settings.
- Sits in a **Workspace**. Users join by invitation or by company domain. Folders and a **Team Library** group guides ([team workspaces](https://help.tango.ai/en/collections/3466202-team-workspaces)).
- Roles exist (admin, creator, view-only, guest). Only admins change branding ([roles](https://help.tango.ai/en/articles/8400111-what-are-the-different-user-roles), [branding](https://help.tango.ai/en/articles/5971709-can-i-add-my-own-branding-to-tango-workflows)).

## Differentiation

The vendor's pitch is capture speed: no writing of steps. The capture pipeline is the product. Pages are not authored as a free document. Versus a wiki: the guide is generated from a recording, not typed. Versus Guide-style tools: the same recording can be shared as a link, an embed, a PDF or a live walkthrough.

Other comparison claims on third-party sites (Scribe, Docsie, guidde) were not checked and are not used here.

## Who it suits

Teams that document repeated software procedures (support, onboarding, IT). The help centre's Team and Enterprise pages assume a company with SSO, audit logs and SCIM ([plans](https://www.tango.ai/pricing), [security](https://help.tango.ai/en/collections/3337935-security)).

## Not a wiki

No page tree with free-text authoring is documented. No public API (see [api.md](api.md)). No real-time co-editing documented: unverified.
