## Cannot do (documented)

- No capture in Firefox, Safari, Arc. No Linux desktop app. No mobile apps; no capture on phones or tablets ([where it works](https://help.tango.ai/en/articles/17359491-where-does-tango-work)).
- No public API or webhooks documented (see [api.md](api.md)).
- Capture of Google Docs, Sheets, Slides content, Figma, Webflow, Chrome Settings and the Chrome Web Store is limited or excluded ([limits](limits.md)).
- Desktop-captured guides: no Guide Me, no Live Blur, no Voice Transcription ([where it works](https://help.tango.ai/en/articles/17359491-where-does-tango-work)).
- Free: 5 shared workflows, up to 10 users per workspace ([pricing](https://www.tango.ai/pricing)).
- No Markdown authoring in the editor; Markdown is an export format only (Pro) (inferred from export list).
