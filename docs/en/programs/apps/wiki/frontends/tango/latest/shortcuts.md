# Tango: keyboard shortcuts

Almost none are documented. The earlier pages in the docs tree listed many shortcuts; they could not be verified and are removed (see [corrections](../changelog.md)).

## Verified

| Action | Windows | Mac | Context | Source |
|---|---|---|---|---|
| Undo change in guide editor | Ctrl+Z | Cmd+Z | Edit mode | [undo](https://help.tango.ai/en/articles/17747616-how-do-i-undo-changes-in-the-tango-editor) |
| Redo change | Ctrl+Y | Cmd+Y | Edit mode | same |
| Extend selection to clicked item | Shift+Click | Shift+Click | Team Library | [bulk actions](https://help.tango.ai/en/articles/16652169-how-do-i-use-bulk-actions-in-the-team-library) |
| Select all items in filtered view | Ctrl+A | Cmd+A | Team Library | same |
| Open guide in new tab, keep selection | Ctrl+Click | Cmd+Click | Team Library | same |
| Exit selection mode | Esc | Esc | Team Library | same |
| Search guides by keyword | unverified | Cmd+K | Tango app | search snippet of [store/search](https://help.tango.ai/en/articles/7231409-can-i-store-and-search-for-tangos-in-my-workspace); article not fetched |

## Unverified

- Capture start/stop/pause/resume by keyboard in the Desktop app: a search snippet says such shortcuts exist but gives no keys.
- Any shortcut for a step, block, heading or formatting in the editor.
- Any shortcut in the browser side panel.

Source for the unverified line: only a search snippet of the desktop collection; no keys listed in the page read.
