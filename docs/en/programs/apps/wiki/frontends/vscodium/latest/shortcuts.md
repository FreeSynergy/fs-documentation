# VSCodium - Keyboard Shortcuts

## Overview

VSCodium offers extensive keyboard shortcuts for working quickly with the code
editor, the integrated Git, the terminal and the debugger.

---

## General shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Shift+P` / `Cmd+Shift+P` | Open the command palette |
| `Ctrl+,` / `Cmd+,` | Open the settings |
| `F1` | Open the command palette |
| `Ctrl+K Ctrl+S` / `Cmd+K Cmd+S` | Show the keyboard shortcuts |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | Global search |
| `Ctrl+H` / `Cmd+H` | Replace |
| `Ctrl+Shift+J` / `Cmd+Shift+J` | Open the search window |

## Summary

VSCodium offers extensive shortcuts for:
- **Navigation**: file, editor, Git, debugging
- **Code editing**: text selection, copy/paste, formatting
- **Git**: repository management, branches, sync
- **Debugging**: breakpoints, step-by-step
- **Terminal**: integrated terminal access
- **View**: sidebar, menus, previews

Mac users get the same shortcuts with `Cmd` instead of `Ctrl`.
