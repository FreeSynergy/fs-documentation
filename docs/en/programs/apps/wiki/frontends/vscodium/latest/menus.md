# VSCodium - Menu items

## Overview

VSCodium is an open-source version of Microsoft Visual Studio Code. It is a
free, cross-platform source-code editor with extensive functions for
developers.

## Main menu items

### 1. File
- **Function**: file operations
- **Details**:
  - new file
  - open
  - save
  - save as
  - close
  - settings
  - user settings
  - select a colour scheme

### 2. Edit
- **Function**: editing operations
- **Details**:
  - undo/redo
  - cut/copy/paste
  - search & replace
  - format
  - rewrap lines

### 3. View
- **Function**: layout and views
- **Details**:
  - explorer (file tree)
  - search (file search)
  - source control (Git)
  - run & debug
  - extensions
  - custom layout
  - pane manager (sidebar, activity bar)

### 4. Go
- **Function**: navigation
- **Details**:
  - back/forward
  - jump to definition
  - show definition
  - implementations
  - search for a symbol in the file
  - go to line

### 5. Terminal
- **Function**: terminal operations
- **Details**:
  - open the terminal
  - create a new terminal
  - split the terminal
  - close the terminal
  - run commands

### 6. Help topics
- **Function**: help and information
- **Details**:
  - welcome
  - version information
  - licence
  - feature requests
  - privacy statement

### 7. Context menu (right mouse button)
- **Function**: context-sensitive actions
- **Details**:
  - copy/copy path
  - open file
  - reveal in explorer
  - open terminal here
  - compare with the saved file

## Menus by view

### Explorer menu
- open a folder
- add a file
- add a folder
- delete
- rename

### Source control menu
- commit the changes
- push/pull
- manage branches
- resolve conflicts

### Debugging menu
- start (F5)
- manage breakpoints
- watch expressions
- show the call stack
