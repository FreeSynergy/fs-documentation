# VSCodium - Description

## Overview

VSCodium is an open-source version of Microsoft Visual Studio Code. It is a
free, cross-platform source-code editor with extensive functions for
developers.

## What VSCodium does

VSCodium is a source-code editor built specifically for developing software. It
offers extensive functions for writing, editing and debugging code.

## Advantages

- **Open source**: completely free software, driven by the community
- **No telemetry**: no data sent to Microsoft
- **Cross-platform**: works on Windows, macOS and Linux
- **Extensible**: 1000+ extensions available
- **IntelliSense**: intelligent autocompletion
- **Git integration**: native Git integration
- **Debugging**: built-in debugger for many languages
- **Terminal**: built-in terminal
- **Snippets**: code templates for quick writing

## Differentiation from other editors

### VSCodium vs. XWiki
- **XWiki** is a wiki platform
- **VSCodium** is a code editor
- **XWiki** is for documentation, **VSCodium** for code development

### VSCodium vs. Confluence
- **Confluence** is a wiki platform
- **VSCodium** is a code editor
- **Confluence** is for documentation, **VSCodium** for code development

### VSCodium vs. Notion
- **Notion** is an all-in-one platform
- **VSCodium** is a specialised code editor
- **Notion** is for notes, **VSCodium** for code

## Technical details

- **Backend**: Electron (Chromium + Node.js)
- **Frontend**: TypeScript, React
- **Authentication**: OAuth2, SSO (via extensions)
- **Hosting**: desktop application (self-hosted)

## Who VSCodium suits

- **Developers**: for code development and debugging
- **Teams**: for a shared development environment
- **Startups**: for low-cost development
- **Freelancers**: for individual development
