# Tana - Features

## Main features

- Supertag: turns a node into an object (Task, Person, Meeting).
- Fields are saved in the tag's template; optional fields are suggested when needed; pinned fields appear at the top and in filter/sort/group menus.
- Title expression builds a node title from field values.
- Extend: a tag inherits another's template; inherited parts cannot be removed, but fields and defaults can be added.
- Each supertag page shows a table of all tagged nodes by default; more tabs and views can be added.
- Search nodes find tagged nodes anywhere and can be customised per supertag.
- AI features, input API, sync and platforms: Open (not read).
