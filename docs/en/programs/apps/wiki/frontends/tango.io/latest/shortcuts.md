# Tango.io - Keyboard Shortcuts

## Overview

Tango.io offers extensive keyboard shortcuts for working quickly with the
block-based visual editor.

---

## General shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Shift+P` / `Cmd+Shift+P` | Open the command palette |
| `Ctrl+,` / `Cmd+,` | Open the settings |
| `F1` | Help |
| `Ctrl+K` / `Cmd+K` | Add a link |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | Global search |

---

## Editor shortcuts (block editor)

### Block navigation

| Shortcut | Function |
|----------|----------|
| `Enter` | Create a new line / block |
| `Shift+Enter` | Line break (inside a block) |
| `Tab` | Indent (lists) |
| `Shift+Tab` | Remove indentation (lists) |
| `Escape` | Leave the block / lose focus |
| `Ctrl+Enter` / `Cmd+Enter` | Run the block (e.g. tick the checkbox) |
| `Ctrl+↑` / `Cmd+↑` | Move the block upwards |
| `Ctrl+↓` / `Cmd+↓` | Move the block downwards |

## Summary

Tango.io offers extensive shortcuts for:
- **Block navigation**: working quickly with the block-based editor
- **Block actions**: duplicate, delete, copy, move
- **Formatting**: all the common formats
- **Block types**: switch between different block types
- **Code syntax**: switch language directly in the code blocks
- **Navigation**: inside the editor and between components
- **File operations**: save, open, print, export
- **Search**: local and global
- **View**: full screen, sidebar, preview

Mac users get the same shortcuts with `Cmd` instead of `Ctrl`.
