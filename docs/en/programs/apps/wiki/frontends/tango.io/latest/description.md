# Tango.io - Description

## Overview

Tango.io is a modern knowledge-management platform that focuses on
collaboration and document management.

## What Tango.io does

Tango.io is a modern platform for knowledge management and collaboration that
focuses on ease of use, visual organisation and strong integrations.

## Advantages

- **Modern UI**: very user-friendly design
- **Block-based**: intuitive block-based editing
- **Strong embeds**: support for 100+ embeds (YouTube, Figma, etc.)
- **Collaborative**: real-time collaboration
- **Flexible**: very varied document organisation
- **Fast**: fast loading and editing
- **Affordable**: cheaper than Confluence and the like

## Differentiation from other systems

### Tango.io vs. Notion
- **Notion** is more established with more features (databases, formulas)
- **Tango.io** is simpler and quicker to use
- **Notion** has better databases, **Tango.io** better embeds

### Tango.io vs. Confluence
- **Confluence** is enterprise software with high costs
- **Tango.io** is cheaper and simpler
- **Confluence** has better Jira integration, **Tango.io** a more modern UI

### Tango.io vs. Wiki.js
- **Wiki.js** is open source with more customisation
- **Tango.io** is commercial and comes with support
- **Wiki.js** offers more editor options, **Tango.io** better embeds

## Technical details

- **Backend**: Node.js
- **Database**: PostgreSQL
- **Frontend**: React
- **Authentication**: OAuth2, SSO
- **Hosting**: cloud option (SaaS)

## Who Tango.io suits

- **Teams**: for collaboration and knowledge management
- **Agile projects**: for quick writing and organisation
- **Startups**: for low-cost documentation
- **Design teams**: for visual organisation and embeds
