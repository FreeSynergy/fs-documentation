# Tango.io - Menu Items

## Overview

Tango.io is a modern knowledge management platform focused on collaboration and document management.

## Main Menu Items

### 1. Home / Start page
- **Function**: Personalized start page
- **Details**:
  - Activity stream
  - Short info
  - Important documents
  - Quick access

### 2. Workspace
- **Function**: Workspace management
- **Details**:
  - Create workspace
  - Workspace overview
  - Workspace settings
  - Workspace template

### 3. Pages
- **Function**: Document management
- **Details**:
  - Create new page
  - Browse pages
  - Filter pages
  - Organize pages

### 4. Templates
- **Function**: Template library
- **Details**:
  - Create templates
  - Use templates
  - Share templates
  - Custom templates

### 5. Files
- **Function**: File management
- **Details**:
  - File upload
  - File organization
  - File sharing
  - Versioning

### 6. People (Members)
- **Function**: Member management
- **Details**:
  - Add members
  - Manage roles
  - Create groups
  - Access control

### 7. Settings
- **Function**: System settings
- **Details**:
  - Workspace settings
  - Notifications
  - Security
  - Integrations

### 8. Search
- **Function**: Global search
- **Details**:
  - Search across all documents
  - Filter options
  - Search history
  - Search results

### 9. Dashboard
- **Function**: Overview & statistics
- **Details**:
  - Activities
  - User activity
  - System statistics
  - Important dates

### 10. Notifications
- **Function**: Notification center
- **Details**:
  - Mentions
  - Comments
  - Changes
  - System notifications

### 11. Bookmark
- **Function**: Remember important documents
- **Details**:
  - Add bookmarks
  - Organize bookmarks
  - Quick access

### 12. Recently Viewed
- **Function**: History
- **Details**:
  - Recently visited pages
  - Quick access
  - Clear history
