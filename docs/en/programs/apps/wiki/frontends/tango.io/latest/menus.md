# Tango.io - Menu items

## Overview

Tango.io is a modern knowledge-management platform that focuses on
collaboration and document management.

## Main menu items

### 1. Home / start page
- **Function**: personalised start page
- **Details**:
  - activity stream
  - short summaries
  - important documents
  - quick access

### 2. Workspace (work areas)
- **Function**: workspace management
- **Details**:
  - create a workspace
  - workspace overview
  - workspace settings
  - workspace template

### 3. Pages
- **Function**: document management
- **Details**:
  - create a new page
  - browse the pages
  - filter the pages
  - organise the pages

### 4. Templates
- **Function**: template library
- **Details**:
  - create templates
  - use templates
  - share templates
  - custom templates

### 5. Files
- **Function**: file management
- **Details**:
  - upload files
  - organise files
  - share files
  - versioning

### 6. People (members)
- **Function**: member management
- **Details**:
  - add members
  - manage roles
  - create groups
  - access control

### 7. Settings
- **Function**: system settings
- **Details**:
  - workspace settings
  - notifications
  - security
  - integrations

### 8. Search
- **Function**: global search
- **Details**:
  - search in all documents
  - filter options
  - search history
  - search results

### 9. Dashboard
- **Function**: overview & statistics
- **Details**:
  - activities
  - user activity
  - system statistics
  - important dates

### 10. Notifications
- **Function**: notification centre
- **Details**:
  - mentions
  - comments
  - changes
  - system notifications

### 11. Bookmark
- **Function**: mark important documents
- **Details**:
  - add a bookmark
  - organise bookmarks
  - quick access

### 12. Recently viewed
- **Function**: history
- **Details**:
  - the pages you visited last
  - quick access
  - clear the history
