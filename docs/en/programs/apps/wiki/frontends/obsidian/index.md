# Obsidian

> Category: [wiki](../../index.md) · Type: local-first Markdown notes · Vendor: Dynalist Inc. (Obsidian) · Licence: proprietary app; free for personal use, Commercial licence available (per help home)

## What it is
Obsidian edits a folder of plain Markdown files (a vault), with links between notes, plugins and optional paid Sync and Publish.

## Notable ideas
Why this program is documented here (ADR 0013). Function analysis only, own wording.

- Backlinks: for every note, a list of notes that link to it and of unlinked mentions of its name — automatic reverse index without a database.
- Canvas: an infinite 2D board of notes, media and web pages with labelled connections, stored in the open JSON Canvas format.
- Plain files plus a plugin system; command palette.
