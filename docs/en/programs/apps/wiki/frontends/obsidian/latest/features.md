# Obsidian - Features

## Main features

- Backlinks pane in the right sidebar: linked mentions and unlinked mentions, with collapse, context and sort options; pinned backlinks tab; backlinks shown at the end of a note.
- Canvas (core plugin): `.canvas` files; text cards, note cards (narrowable to a heading or block), media cards, web page cards, Base cards, folders; directed, undirected or bidirectional labelled connections; groups; PNG export on desktop.
- Text cards do not appear in backlinks until converted to notes.
- Core plugins, community plugins, themes, CSS snippets.
- Obsidian Sync, Obsidian Publish, Web Clipper, a command-line control.
- Platforms and licence terms in detail: Open.
