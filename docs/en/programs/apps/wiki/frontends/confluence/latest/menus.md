# Confluence - Menu items

## Overview

Confluence is an enterprise wiki platform by Atlassian for team collaboration
and knowledge management.

## Main menu items

### 1. Home / start page
- **Function**: personalised start page
- **Details**:
  - activity stream
  - recommendations
  - my tasks
  - notifications

### 2. Create
- **Function**: create new content
- **Details**:
  - create a page
  - create a blog post
  - create a question (Answers)
  - use a template

### 3. Spaces
- **Function**: choosing a space
- **Details**:
  - list all spaces
  - my spaces
  - recently visited
  - create a space

### 4. Created
- **Function**: my own content
- **Details**:
  - my pages
  - my blog posts
  - my questions
  - last edited

### 5. Saved
- **Function**: favourites/saved pages
- **Details**:
  - show saved pages
  - manage saved pages

### 6. Mentions
- **Function**: manage my mentions
- **Details**:
  - show mentions
  - change the status
  - comment

### 7. Notifications
- **Function**: notification centre
- **Details**:
  - new notifications
  - all notifications
  - notification settings

### 8. Dashboard
- **Function**: overview dashboard
- **Details**:
  - team activity
  - popular pages
  - my tasks
  - statistics

### 9. Search
- **Function**: global search
- **Details**:
  - content search
  - user search
  - filter options
  - quick search (Cmd/Ctrl+.)

### 10. Profile
- **Function**: personal settings
- **Details**:
  - edit the profile
  - notifications
  - preferences
  - sign out

## Context menus

### Page menu (three dots top right)
- Edit
- Copy
- Move
- Delete
- Archive
- Page versions
- Permissions
- Print
- Export (PDF, Word)

### Blog post menu
- Edit
- Publish
- Save as draft
- Delete

### Comment menu
- Reply
- Edit
- Delete
- Send a message

### Space menu (sidebar)
- Space information
- Space settings
- Change the theme
- Organise the content

## Advanced features

### Space menus
- Space overview
- Edit the space template
- Space statistics
- Space backup

### Dashboard menus
- Edit the dashboard
- Add/remove a widget
