# Wiki.js - Keyboard Shortcuts

## Overview

Wiki.js offers extensive keyboard shortcuts for working quickly with both editors: the visual WYSIWYG editor and the Markdown editor.

---

## General Shortcuts

| Shortcut | Function |
|----------|----------|
| `Ctrl+Shift+P` / `Cmd+Shift+P` | Open command palette |
| `Ctrl+,` / `Cmd+,` | Open settings |
| `F1` | Help |
| `Ctrl+K` / `Cmd+K` | Add link |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | Global search |

## Summary

Wiki.js offers extensive shortcuts for:
- **Formatting**: All common formatting (bold, italic, headings)
- **Navigation**: Within the editor and between components
- **File operations**: Save, open, print
- **Search**: Local and global
- **View**: Full screen, sidebar, preview

Mac users benefit from the same shortcuts with `Cmd` instead of `Ctrl`.
