# Wiki.js - Description

## Overview

Wiki.js is a modern, lightweight wiki system based on Node.js. The menu gives
access to all the main functions of the system.

## What Wiki.js does

Wiki.js is modern wiki software built on modern web technologies. It offers a
user-friendly interface for creating and managing knowledge bases,
documentation and collaboration platforms.

## Advantages

- **Lightweight**: based on Node.js, fast and efficient
- **Modern design**: UI/UX aligned with current web standards
- **Two editor modes**: WYSIWYG for beginners, Markdown for advanced users
- **Modularly extensible**: plugin system for additional functions
- **Open source**: free and open software with an active community
- **Good performance**: fast loading and editing of pages

## Differentiation from other systems

### Wiki.js vs. MediaWiki
- **MediaWiki** is established (Wikipedia) but more complex
- **Wiki.js** is more modern and easier to use
- **MediaWiki** has more extensions, **Wiki.js** is more lightweight

### Wiki.js vs. Confluence
- **Confluence** is an enterprise solution with high licence costs
- **Wiki.js** is open source and free
- **Confluence** has better enterprise features (SSO, audit logs)
- **Wiki.js** is simpler to set up and to maintain

### Wiki.js vs. Notion
- **Notion** is an all-in-one platform with databases
- **Wiki.js** is specialised in wiki/documentation
- **Notion** has better visual design, **Wiki.js** better text formatting
- **Wiki.js** is better suited for technical documentation

## Technical details

- **Backend**: Node.js
- **Database**: PostgreSQL, MySQL, SQLite
- **Frontend**: Vue.js
- **Authentication**: OAuth2, LDAP, SAML (via extensions)
- **Hosting**: self-hosted or cloud

## Who Wiki.js suits

- **Small to medium businesses**: for documentation and knowledge management
- **Open-source projects**: for community documentation
- **Developer teams**: for technical documentation
- **Educational institutions**: for teaching materials and wiki systems
