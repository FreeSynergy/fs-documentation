# Wiki.js - Description

## Overview

Wiki.js is a modern, lightweight wiki system based on Node.js. The menu provides access to all main functions of the system.

## What Wiki.js Does

Wiki.js is modern wiki software built on current web technologies. It provides a user-friendly interface for creating and managing knowledge bases, documentation and collaboration platforms.

## Advantages

- **Lightweight**: Based on Node.js, fast and efficient
- **Modern design**: UI/UX oriented to current web standards
- **Two editor modes**: WYSIWYG for beginners, Markdown for advanced users
- **Modularly extensible**: Plugin system for additional functions
- **Open source**: Open-source software with an active community
- **Good performance**: Fast loading and editing of pages

## Distinction from Other Systems

### Wiki.js vs. MediaWiki
- **MediaWiki** is established (Wikipedia) but more complex
- **Wiki.js** is more modern and easier to use
- **MediaWiki** has more extensions, **Wiki.js** is more lightweight

### Wiki.js vs. Confluence
- **Confluence** is an enterprise solution with high license costs
- **Wiki.js** is open source and free
- **Confluence** has better enterprise features (SSO, audit logs)
- **Wiki.js** is easier to set up and maintain

### Wiki.js vs. Notion
- **Notion** is an all-in-one platform with databases
- **Wiki.js** specializes in wikis/documentation
- **Notion** has better visual design, **Wiki.js** has better text formatting
- **Wiki.js** is better suited for technical documentation

## Technical Details

- **Backend**: Node.js
- **Database**: PostgreSQL, MySQL, SQLite
- **Frontend**: Vue.js
- **Authentication**: OAuth2, LDAP, SAML (via extensions)
- **Hosting**: Self-hosted or cloud

## Who Is Wiki.js Suited For?

- **Small to medium-sized companies**: For documentation and knowledge management
- **Open-source projects**: For community documentation
- **Developer teams**: For technical documentation
- **Educational institutions**: For teaching materials and wiki systems
