# Wiki.js - Menu items

## Overview

Wiki.js is a modern, lightweight wiki system based on Node.js. The menu gives
access to all the main functions of the system.

## Main menu items

### 1. Home / start page
- **Function**: navigates to the main/start page of the wiki
- **Details**: shows the newest content, activity and important pages

### 2. Pages
- **Function**: manages all wiki pages
- **Details**:
  - an overview of all available pages
  - search for pages
  - creation of new pages
  - sorting and filtering

### 3. Editor
- **Function**: access to the page editor
- **Details**:
  - visual editor (WYSIWYG)
  - Markdown editor
  - preview function
  - formatting tools

### 4. Trash
- **Function**: manage deleted pages
- **Details**:
  - keeping hold of deleted pages
  - a restore function
  - permanent deletion

### 5. Media
- **Function**: file and image management
- **Details**:
  - uploading files
  - managing the media library
  - image galleries

### 6. Users
- **Function**: user management
- **Details**:
  - add/remove users
  - manage roles and permissions
  - user profiles

### 7. Groups
- **Function**: group management
- **Details**:
  - create and edit groups
  - manage members
  - group permissions

### 8. Access (access control)
- **Function**: manage permissions
- **Details**:
  - control access to pages
  - role-based access control
  - permission profiles

### 9. Settings
- **Function**: system configuration
- **Details**:
  - general settings
  - Appearance (design)
  - Authentication
  - e-mail configuration
  - SEO settings

### 10. Appearance (design)
- **Function**: adjust the look
- **Details**:
  - theme selection
  - colour schemes
  - header/footer customisation

### 11. Extensions
- **Function**: plugin management
- **Details**:
  - manage installed extensions
  - add new extensions
  - extension configuration

### 12. Logs
- **Function**: view the system logs
- **Details**:
  - access logs
  - error logs
  - change logs

### 13. Search
- **Function**: content search
- **Details**:
  - global search
  - filter options
  - display of search results
