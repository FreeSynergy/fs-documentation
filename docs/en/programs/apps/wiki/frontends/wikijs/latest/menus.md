# Wiki.js - Menu Items

## Overview

Wiki.js is a modern, lightweight wiki system based on Node.js. The menu provides access to all main functions of the system.

## Main Menu Items

### 1. Home / Start page
- **Function**: Navigates to the main/start page of the wiki
- **Details**: Shows the latest content, activities and important pages

### 2. Pages
- **Function**: Management of all wiki pages
- **Details**:
  - Overview of all available pages
  - Search for pages
  - Creation of new pages
  - Sorting and filtering

### 3. Editor
- **Function**: Access to the page editor
- **Details**:
  - Visual editor (WYSIWYG)
  - Markdown editor
  - Preview function
  - Formatting tools

### 4. Trash
- **Function**: Manage deleted pages
- **Details**:
  - Retention of deleted pages
  - Restore function
  - Permanent deletion

### 5. Media
- **Function**: File and image management
- **Details**:
  - Uploading files
  - Managing the media library
  - Image galleries

### 6. Users
- **Function**: User management
- **Details**:
  - Add/remove users
  - Manage roles and permissions
  - User profiles

### 7. Groups
- **Function**: Group management
- **Details**:
  - Create and edit groups
  - Manage members
  - Group permissions

### 8. Access (Access control)
- **Function**: Manage permissions
- **Details**:
  - Control access to pages
  - Role-based access control
  - Permission profiles

### 9. Settings
- **Function**: System configuration
- **Details**:
  - General settings
  - Appearance (design)
  - Authentication
  - Email configuration
  - SEO settings

### 10. Appearance (Design)
- **Function**: Customize the look and feel
- **Details**:
  - Theme selection
  - Color schemes
  - Header/footer customization

### 11. Extensions
- **Function**: Plugin management
- **Details**:
  - Manage installed extensions
  - Add new extensions
  - Extension configuration

### 12. Logs
- **Function**: View system logs
- **Details**:
  - Access logs
  - Error logs
  - Change logs

### 13. Search
- **Function**: Content search
- **Details**:
  - Global search
  - Filter options
  - Search result display
