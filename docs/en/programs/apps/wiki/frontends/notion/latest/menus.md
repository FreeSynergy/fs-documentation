# Notion - Menu items

## Overview

Notion is an all-in-one platform for notes, documentation and collaboration.
The menu gives access to all the main functions of the platform.

## Main menu items

### 1. Workspace
- **Function**: main view of the current workspace
- **Details**:
  - all the pages and databases of the workspace
  - a customisable start page
  - quick access to frequently used pages

### 2. Pages
- **Function**: managing all the pages
- **Details**:
  - an overview of all available pages
  - search for pages
  - create new pages
  - sorting and filtering
  - spell check
  - show the history

### 3. Databases
- **Function**: database management
- **Details**:
  - table databases
  - kanban boards
  - calendar views
  - gallery views
  - list views
  - projects, tasks, CRM

### 4. Trash
- **Function**: manage deleted pages
- **Details**:
  - retention of deleted pages and databases
  - restore function
  - permanent deletion
  - retention period (30 days)

### 5. Media
- **Function**: file and image management
- **Details**:
  - upload files
  - manage the media library
  - image galleries
  - file links

### 6. Users
- **Function**: user management
- **Details**:
  - add/remove users
  - manage roles and permissions
  - user profiles
  - manage invitations

### 7. Settings
- **Function**: system configuration
- **Details**:
  - general settings
  - appearance (design/theme)
  - language settings
  - notifications
  - security settings

### 8. Notifications
- **Function**: notification management
- **Details**:
  - activity on shared pages
  - @mentions
  - comments
  - reminders
  - editing conflicts

### 9. Search
- **Function**: content search
- **Details**:
  - global search
  - filter options
  - search result display
  - in-page search
  - database search

### 10. Templates
- **Function**: template management
- **Details**:
  - create and edit templates
  - template categories
  - share templates
  - personal templates
  - team templates

### 11. Integrations
- **Function**: third-party integrations
- **Details**:
  - GitHub integration
  - Figma integration
  - Google Drive
  - Zapier integration
  - API access
  - manage embeds

### 12. Resources
- **Function**: help materials
- **Details**:
  - help centre
  - tutorial videos
  - community posts
  - blog articles
  - forum access

### 13. Preferences
- **Function**: user-specific settings
- **Details**:
  - editor settings
  - shortcut display
  - automatic saving
  - preview settings
  - export settings

## Context menus

### Page menu
- Edit
- Move
- Copy
- Delete
- Show the history
- Permissions
- Share the page
- Create a template
- Export

### Database menu
- Change the view (table/kanban/calendar)
- Sort
- Filter
- Manage the fields
- Share the view
- Export

### Block menu (inside pages)
- Duplicate the block
- Delete the block
- Copy the block
- Indent
- Run (to-dos)
- Change the block type
- Copy the link

### User menu (top right)
- Edit the profile
- Settings
- Manage the workspaces
- Sign out
- Help
- Give feedback

## Menu shortcuts

| Menu | Shortcut | Function |
|------|----------|----------|
| Command palette | `Ctrl+Shift+P` / `Cmd+Shift+P` | browse all commands |
| Quick search | `Ctrl+P` / `Cmd+P` | search for a page |
| Global search | `Ctrl+Shift+F` / `Cmd+Shift+F` | search the whole database |
| Block menu | `/` | call up block actions |

## Summary

Notion offers extensive menu items for:
- **Workspace**: main view and personalisation
- **Content**: pages, databases, templates
- **Administration**: users, permissions, integrations
- **Help**: support, resources, tutorials
- **Personalisation**: settings, preferences, shortcuts

The menu is context-sensitive and adapts to the current view.
