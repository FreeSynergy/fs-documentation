# Notion - Menu Items

## Overview

Notion is an all-in-one platform for notes, documentation and collaboration. The menu provides access to all main features of the platform.

## Main Menu Items

### 1. Workspace
- **Function**: Main view of the current workspace
- **Details**:
  - All pages and databases of the workspace
  - Personalizable start page
  - Quick access to frequently used pages

### 2. Pages
- **Function**: Management of all pages
- **Details**:
  - Overview of all available pages
  - Search for pages
  - Creation of new pages
  - Sorting and filtering
  - Spell check
  - View history

### 3. Databases
- **Function**: Database management
- **Details**:
  - Table databases
  - Kanban boards
  - Calendar views
  - Gallery views
  - List views
  - Projects, tasks, CRM

### 4. Trash
- **Function**: Manage deleted pages
- **Details**:
  - Retention of deleted pages and databases
  - Restore function
  - Permanent deletion
  - Retention period (30 days)

### 5. Media
- **Function**: File and image management
- **Details**:
  - Uploading files
  - Managing the media library
  - Image galleries
  - File links

### 6. Users
- **Function**: User management
- **Details**:
  - Add/remove users
  - Manage roles and permissions
  - User profiles
  - Manage invitations

### 7. Settings
- **Function**: System configuration
- **Details**:
  - General settings
  - Appearance (design/theme)
  - Language settings
  - Notifications
  - Security settings

### 8. Notifications
- **Function**: Notification management
- **Details**:
  - Activity on shared pages
  - @mentions
  - Comments
  - Reminders
  - Editing conflicts

### 9. Search
- **Function**: Content search
- **Details**:
  - Global search
  - Filter options
  - Search result display
  - In-page search
  - Database search

### 10. Templates
- **Function**: Template management
- **Details**:
  - Create and edit templates
  - Template categories
  - Share templates
  - Personal templates
  - Team templates

### 11. Integrations
- **Function**: Third-party integrations
- **Details**:
  - GitHub integration
  - Figma integration
  - Google Drive
  - Zapier integration
  - API access
  - Manage embeds

### 12. Resources
- **Function**: Help materials
- **Details**:
  - Help Center
  - Tutorial videos
  - Community posts
  - Blog articles
  - Forum access

### 13. Preferences
- **Function**: User-specific settings
- **Details**:
  - Editor settings
  - Shortcut display
  - Automatic saving
  - Preview settings
  - Export settings

## Context Menus

### Page Menu
- Edit
- Move
- Copy
- Delete
- View history
- Permissions
- Share page
- Create template
- Export

### Database Menu
- Change view (table/Kanban/calendar)
- Sort
- Filter
- Manage fields
- Share view
- Export

### Block Menu (within pages)
- Duplicate block
- Delete block
- Copy block
- Indent
- Execute (to-dos)
- Change block type
- Copy link

### User Menu (top right)
- Edit profile
- Settings
- Manage workspaces
- Log out
- Help
- Give feedback

## Menu Shortcuts

| Menu | Shortcut | Function |
|------|----------|----------|
| Command palette | `Ctrl+Shift+P` / `Cmd+Shift+P` | Search all commands |
| Quick search | `Ctrl+P` / `Cmd+P` | Search for a page |
| Global search | `Ctrl+Shift+F` / `Cmd+Shift+F` | Search entire database |
| Block menu | `/` | Call block actions |

## Summary

Notion offers comprehensive menu items for:
- **Workspace**: Main view and personalization
- **Content**: Pages, databases, templates
- **Administration**: Users, permissions, integrations
- **Help**: Support, resources, tutorials
- **Personalization**: Settings, preferences, shortcuts

The menu is context-sensitive and adapts to the current view.
