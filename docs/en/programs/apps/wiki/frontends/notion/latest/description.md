# Notion - Description

## Overview

Notion is an all-in-one platform for notes, documentation and collaboration.
The menu is strongly oriented towards workspace organisation.

## What Notion does

Notion is an all-in-one platform that combines notes, wiki, databases, projects
and collaboration in a single application.

## Advantages

- **All-in-one**: notes, databases and projects on one platform
- **Block-based**: intuitive block-based editing
- **Databases**: strong database functions (kanban, calendar, tables)
- **Formulas**: formulas for calculations in databases
- **Embeds**: support for 100+ embeds (YouTube, Figma, etc.)
- **Templates**: extensive template system
- **Mobile app**: strong mobile apps for iOS and Android
- **Cloud-first**: cloud-based without any server setup

## Differentiation from other systems

### Notion vs. Tango.io
- **Notion** is more established with more features (databases, formulas)
- **Tango.io** is simpler and quicker to use
- **Notion** has better databases, **Tango.io** better embeds

### Notion vs. Confluence
- **Confluence** is enterprise software with high costs
- **Notion** is cheaper and more flexible
- **Confluence** has better Jira integration, **Notion** a more modern UI

### Notion vs. XWiki
- **XWiki** is enterprise software with complex permissions
- **Notion** is simpler and quicker to use
- **XWiki** has better audit logs, **Notion** better databases

## Technical details

- **Backend**: Node.js, PostgreSQL
- **Database**: PostgreSQL
- **Frontend**: React, TypeScript
- **Authentication**: OAuth2, SSO
- **Hosting**: cloud option (SaaS)

## Who Notion suits

- **Teams**: for collaboration and knowledge management
- **Agile projects**: for quick writing and organisation
- **Personal productivity**: for individual organisation
- **Startups**: for low-cost documentation
