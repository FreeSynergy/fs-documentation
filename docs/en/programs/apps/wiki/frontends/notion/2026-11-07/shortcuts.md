# Notion — keyboard shortcuts (2026-11-07)

Source: [S11] keyboard shortcuts page, unless marked. Notion writes `cmd/ctrl`: cmd on macOS, ctrl on Windows and Linux. `option/alt` and `shift` are written as shown.

## Most used

| Key | Function |
|-----|----------|
| cmd/ctrl + F | Search inside a page |
| cmd/ctrl + P or cmd/ctrl + K | Open search, or jump to a recently viewed page |
| cmd/ctrl + L | Copy the page URL |
| cmd/ctrl + [ / ] | Back / forward |
| cmd/ctrl + shift + L | Toggle dark and light mode |
| cmd/ctrl + N | New page (desktop) |
| cmd/ctrl + T | New tab (desktop) |

## Typing and formatting

| Key | Function |
|-----|----------|
| Enter | New line / new block |
| shift + Enter | Line break inside a block |
| cmd/ctrl + B / I / U | Bold / italic / underline (with text selected) |
| cmd/ctrl + shift + S | Strikethrough (with text selected) |
| cmd/ctrl + E | Inline code (with text selected) |
| cmd/ctrl + K | Add link (with text selected) |
| cmd/ctrl + shift + M | Create a comment |
| `---` + Enter | Divider (typed as Markdown) |
| `**text**`, `*text*`, `` `text` ``, `~text~` | Markdown inline styles while typing |
| `* `, `- `, `+ ` | Bulleted list |
| `[] ` | To-do |
| `1. `, `a. `, `i. ` | Numbered list |
| `# `, `## `, `### ` | Heading 1–3 |
| `> ` | Toggle list |
| `" ` | Quote block |

## Blocks

| Key | Function |
|-----|----------|
| Tab / shift + Tab | Nest / un-nest |
| Esc | Select current block, or clear selection |
| cmd/ctrl + A | Select the block the cursor is in |
| arrow keys | Select another block |
| shift + up/down | Expand selection |
| shift + click | Select a range |
| cmd/ctrl + shift + click (Mac) / alt + shift + click (Windows) | Select or deselect one block |
| cmd/ctrl + D | Duplicate selected blocks |
| backspace / delete | Delete selected blocks |
| cmd/ctrl + shift + arrow | Move the selected block |
| option/alt + drag | Duplicate content |
| Enter | Edit the text of a selected block |
| cmd/ctrl + / | Edit or change selected blocks (also multiple database rows) |
| cmd/ctrl + Enter | Act on the current block: open a page, tick to-do, toggle, full-screen embed or image |
| cmd/ctrl + option/alt + T | Expand or close all toggles |
| cmd/ctrl + option/shift + 0–9 | 0 text, 1–3 headings, 4 to-do, 5 bullet, 6 numbered, 7 toggle, 8 code block, 9 new page |
| cmd/ctrl + shift + H | Apply the last text or highlight colour |
| cmd/ctrl + shift + U | Go up one level in the page hierarchy |
| cmd/ctrl + + / - | Zoom in / out |
| space | Open or close a full-screen image |

## Slash commands [S11]

Type the command and press Enter, for example `/h1` then Enter.

| Command | Block |
|---------|-------|
| `/text`, `/plain`, `/page`, `/bullet`, `/num`, `/todo`, `/toggle`, `/div`, `/quote`, `/h1`, `/h2`, `/h3`, `/link` | Basic blocks |
| `/mention`, `/date`, `/reminder`, `/equation`, `/emoji` | Inline |
| `/image`, `/pdf`, `/book`, `/video`, `/audio`, `/code`, `/file`, `/embed` | Media |
| `/duplicate`, `/moveto`, `/delete`, `/toc`, `/button`, `/template`, `/bread`, `/math`, `/latex` | Advanced |
| `/turn`, `/color`, `/default` | Change type and colour |

## Removed (not on the official page)

The earlier shortcut page listed many shortcuts that the official page does not document, including Ctrl+Shift+P command palette, Ctrl+S save, Ctrl+Shift+E export, Ctrl+Shift+F share, Ctrl+Shift+A app manager, F11, and language slash commands such as `/js` and `/python`. Each is unverified and removed. See [changelog.md](../changelog.md).

## Notes

- The official page lists Windows and Mac keys. Linux is not named; cmd/ctrl means ctrl there.
- Some shortcuts differ by platform only in the key name (cmd vs ctrl). Others differ in key (option vs alt).
