# Notion — menus (2026-11-07)

Only menus named in official pages are listed. Other menu structures from the earlier page (Workspace, Pages, Users, Integrations, Resources, Preferences and their sub-items) are unverified and removed.

## Sidebar items [S12]

| Item | Purpose (as stated) |
|------|---------------------|
| Search | Opens the search window (cmd/ctrl+K) |
| Home | Pages and tasks that need attention; sections Recents, Favorites, Teamspaces |
| Chats with Notion AI | Custom agents and AI chat history |
| Meetings | Upcoming events and meeting notes |
| Inbox | Notifications (top right) |
| Library | Browse and manage all workspace content |
| Templates | Templates |
| Trash | Deleted pages |
| Settings | Settings |
| New item menu | Creates a page; the 📝 button creates a page in preview mode [S12] |
| Workspace switcher | Switch, create or leave workspaces [S12] |

## Page menu (••• at top right) [S15]

- Appearance & layout: Font (Default, Serif, Mono), Small text, Full width, Table of contents.
- Mobile: discussion settings are under "Customize page" [S15].

Other items in the page menu (move, share, export, history) are not in the official pages read. Trash and sub-page deletion are documented via the sidebar [S12] and the block handle ⋮⋮ [S14].

## Block menu [S11, S14]

- Slash menu opened with `/`: turn into another block type with `/turn`, colour with `/color`, default colour with `/default`.
- Block handle ⋮⋮: delete a sub-page or block [S14].
- Keyboard: select a block with Esc or arrow keys; cmd/ctrl+D duplicates selected blocks; backspace or delete removes them [S11].

- Database menu items "Share the view", "Manage fields" (not read).
