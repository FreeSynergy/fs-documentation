# Notion Documentation

## Overview

Notion is an all-in-one platform for notes, documentation and collaboration.

## File structure

- [menu.md](menu.md) - All menu items
- [features.md](features.md) - Editor features and functionality
- [description.md](description.md) - Description and differentiation
- [structure.md](structure.md) - UI/UX and structure
- [shortcuts.md](shortcuts.md) - All keyboard shortcuts
- [api.md](api.md) - API documentation (REST, GraphQL, etc.)
