# Cal.com - Description

## What the program does

Lets a person or team publish bookable meeting types. Visitors choose a slot; the booking is written to the owner's connected calendars. ⚠️ (flow inferred from help-index titles.)

## Differentiation

- Against Notion Calendar links: a full booking product with event types, teams and an API.
- Against FreeSynergy Booking: Booking also covers resources (rooms, devices); Cal.com books people's time.

## Licence and hosting

The code base was open core with enterprise parts. A fork, Cal.diy, is MIT without enterprise code, self-hosted only ✅. Current licence of Cal.com itself: Open. Platform plan: no new sign-ups since 2025-12-15 ✅.

## Who it suits

Anyone who offers appointments to people outside their organisation.
