# Fantastical - Description

## What the program does

A calendar and task client that reads the user's existing calendar accounts and lets them add items by typing one sentence. Commercial, closed source. ✅

## Differentiation

- Against account-bound calendars (Google, Outlook): the input parser and calendar sets are the point, not the storage.
- Against Merkuro: Merkuro is a free KDE client; Fantastical is a paid product on Apple and Windows.

## Who it suits

People who create many items quickly and use several calendar accounts. Details of pricing and supported account types: Open.
