# Notion Calendar - Features

| Feature | Seen | Note |
|---------|------|------|
| Several time zones with custom labels | ✅ | Search snippet of the help centre; the page itself only links to it |
| "Travel" to a zone (temporary primary zone) | ✅ | Shortcut Z |
| Scheduling link, one-off | ✅ | Times by dragging or entering |
| Scheduling link, recurring | ✅ | Several ranges per day; takes several bookings |
| Booking window (minimum, maximum), expiry, location, video or phone details, description | ✅ | |
| "Avoid conflicts": availability follows new conflicts | ✅ | |
| Invitee can reschedule or cancel | ✅ | Not for single-use one-off links |
| Considering other people's availability | ❌ | Listed as not supported |
| Mobile sharing of availability | Open | Page names desktop and web only |
