# Reclaim - Description

## What the program does

Reads the user's calendar, then creates calendar events for habits, tasks and focus time and shifts them as meetings come and go. Commercial; a free plan exists ⚠️ (third-party review).

## Differentiation

- Against Motion: both place tasks; the sources read do not allow a finer comparison. Open.
- Against plain to-do lists: the task becomes a real calendar event.

## Who it suits

Employees with many meetings who want protected working time.
