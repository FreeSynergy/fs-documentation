# Total Commander — API

> [Total Commander](../index.md) · [description](description.md)

- **Internal commands** `cm_*` (and `em_*` for the editor): every function has a name, usable on the command line, on buttons, in menus and key bindings ✅ (the full list was not reachable `[nicht belegt]`).
- **Plugins:** archive, file-system, viewer (lister) and content plugins ✅ (named; search can read content plugin properties ✅).
- **Protocols:** FTP, FTPS, HTTP proxy ✅.
- **Configuration files:** `wincmd.ini` holds options such as `CopyOverwriteDefault` (added in 7.56) and `QuickSearchAutoFilter` ✅.
- **Search syntax:** `ev:` / `ed:` prefixes call the Everything tool ✅.
- Public programming API / automation interface beyond commands and plugins: `[nicht belegt]`.
