| Overwrite | Dialog with details of both files (thumbnails, custom fields): overwrite, overwrite all, skip, skip all, cancel, overwrite all older, rename, append, compare, rename target, auto-rename (copied or target), rename older/skip newer, older-or-same, larger only, smaller only; unattended defaults; extra questions for read-only and hidden/system | ✅ |
| Progress | Copy progress dialog (files and bytes, remaining), Background button for copy, move, pack, unpack, delete; background transfer manager with queue, pause, speed limit, URL download; "as administrator" retry | ✅ |
| Rename | Shift+F6 in place (also Up/Down to neighbours); F6 dialog with masks; Multi-Rename Tool (mask, counter, search and replace, case, regex, preview, undo, log) | ✅ |
| Delete | F8 / Delete; to the recycle bin or directly by setting, Shift flips; extra confirmations for non-empty, read-only, hidden/system; deletion in archives is direct | ✅ |
| Recycle bin | Virtual folder "Recycle bin", system bin on the Desktop, local menu on the F8 button; restore/empty is done in the system bin | ✅ (entries inside the virtual folder `[nicht belegt]`) |
| Undo | In the Multi-Rename Tool and the compare tool ✅; general undo of copy/move/delete not found in the help | `[nicht belegt]` |
| New | F7 new folder (multi-level, several, counter ranges); Shift+F4 new text file (several, counter ranges) with editor; "New" submenu of the panel menu for other types | ✅ |
| Properties | Alt+Enter / Files > Properties (system dialog); change attributes and dates; calculate occupied space | ✅ |
| Search | Alt+F7 dialog: name patterns, regex, folders, drives, archives, depth, text in files with encodings, "Everything", results panel, go to file, feed to list box | ✅ |
| Quick search | Ctrl+S; optional live filter | ✅ |
| Sort | Show menu or Ctrl+F3..F7: name, extension, time, size, unsorted, reversed | ✅ (click on column titles `[nicht belegt]`) |

| Tabs | Folder tabs per panel: open (Ctrl+T, Ctrl+Up, drag), switch (Ctrl+Tab, list Ctrl+Shift+A), close (Ctrl+W), lock/rename, duplicate, copy to other panel, save/load sets, recently closed, icons, multi-line; each tab keeps sort, view and selection | ✅ |
| Open with | Enter (program, associated program, folder, archive, command line), F3 / F4, associations dialog | ✅ |
| Archives | ZIP, 7Z, RAR, TAR, GZ, CAB, ACE etc. as folders; pack Alt+F5, unpack Alt+F6 / Alt+F9, test, self-extracting, encryption (ZIP AES), multi-disk | ✅ |
| History | Back/forward (Alt+Left/Right, 50 per panel), history list with thinning, frequently used folders, command-line history, directory hotlist | ✅ |
| Menus | Eight menu bar menus, user-changeable; context menus for items, path, drive, tabs, buttons | ✅ |
| FTP | FTP, FTPS, HTTP proxy | ✅ |
| Compare | By content; synchronize directories (asymmetric, subdirs, by content, ignore date, per-file direction, confirm) | ✅ |
| Other | File split/combine, viewer (text, hex, binary), plugins, dark mode, Unicode, many languages | ✅ (Wikipedia + home) |
