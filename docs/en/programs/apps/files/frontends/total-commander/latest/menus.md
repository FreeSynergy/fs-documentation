# Total Commander — Menus

> [Total Commander](../index.md) · [description](description.md)

The menu structure of the manual (F1) is offline and was not read. `[nicht belegt]` unless marked. Named on official pages: Commands > Search ✅, Commands > Directory Hotlist ✅, Show > separate tree ✅, Configuration > Options > Quick search ✅.

## Menu bar

Files, Mark (select), Commands, Net (FTP), Show, Configuration, Start, Help ⚠️ — the entries below each are `[nicht belegt]`, except those named above. Every menu entry is an internal `cm_` command ✅ (commands can be bound to keys, buttons and the command line ✅).

## Context menus (right button)

Right-click can be set to **select** instead of open a menu ✅ (selection mode). Entries per object are `[nicht belegt]`; the product shows the Windows shell menu of the item plus its own `[nicht belegt]`.

| Object | Entries | Mark |
|--------|---------|------|
| File or folder | Windows shell menu (Open, Open with, Send to, Properties ...) | `[nicht belegt]` |
| Several selected | Same | `[nicht belegt]` |
| Panel empty space | Sort, view, new | `[nicht belegt]` |
| Folder tab | Close, lock, duplicate | `[nicht belegt]` |
| Drive button | Drive menu | `[nicht belegt]` |
| Directory hotlist entry | Add current dir, Remove current dir, Configure (menu items) | ✅ |
| Archive | Unpack, test | `[nicht belegt]` |
| Search result | Go to file, feed to listbox, view, edit | ✅ |
| Multi-Rename list item | Reorder (Shift+cursor or drag) | ✅ |

## Directory hotlist menu

Entries open folders, network folders, FTP, file-system-plugin folders, websites, internal functions, programs and documents ✅. Bottom: Add current dir (hidden if listed), Remove current dir (shown only if listed), Configure (editor to add, change, reorder, delete) ✅.
