# Total Commander — Description

> [Total Commander](../index.md) · version: latest (11.58.1)

An "orthodox" file manager: two file lists side by side, each with folder tabs, a command line, a button bar, function-key bar (F3..F8) and drive buttons ✅ (function-key bar, drive buttons: ⚠️ navigation page lists drive buttons ✅; bar `[nicht belegt]`). It is shareware for Windows ✅.

**Evidence marks:** ✅ stated on an official page read on 2026-11-13 (ghisler.com, wiki ghisler.ch); ⚠️ only from third-party lists or the Wikipedia article; `[nicht belegt]` not found. Only function and behaviour are described, nothing is copied (ADR 0013).

## Who it suits

People who move many files between two places, work by keyboard, batch rename, compare and synchronise folders, or work inside archives and FTP.

## Differentiation

- Two permanent panes; Explorer and Files have one (Files can split).
- Everything is a keyboard command (function keys), configurable ✅ (Num keys reassignable ✅).
- Archives and FTP behave like folders ✅.
- Plugins extend archive, file-system, viewer and search ✅.
