# Total Commander — Shortcuts

> [Total Commander](../index.md) · [description](description.md)

Sources: ✅ = the official default key list (`KEYBOARD.TXT`) and the official English help of Total Commander 11.58 (installer from totalcommander.ch, retrieved 2026-11-13), plus the official wiki. All keys can be reassigned (Configuration > Options > Misc: hotkeys, aliases) ✅. Behaviour is described in own words. `[nicht belegt]` = not found in these sources. Some Ctrl+letter keys are not remapped while the cursor is in the command line ✅.

## Function keys

| Keys | Action | Mark |
|------|--------|------|
| F1 | Open the help | ✅ |
| F2 / Ctrl+R | Reread the source panel | ✅ |
| F3 | View file(s) in the internal viewer (Lister); Shift+F3 flips between "selected files" and "file under the cursor"; Alt+F3 flips between internal and external viewer; Alt+Shift+F3 starts the viewer without plugins | ✅ |
| F4 / Shift+F4 | Edit file / create a new text file and edit it | ✅ |
| F5 / Shift+F5 | Copy to the other panel / copy within the same folder under a new name | ✅ |
| Ctrl+Shift+F5 | Create shortcuts (links) of the selection in the target folder | ✅ |
| F6 / Shift+F6 | Move or rename via dialog / rename in place (inline) | ✅ |
| F7 / Shift+F7 | New folder in the source / in the target panel | ✅ |
| F8 or Del | Delete (recycle bin or direct, by setting); with Shift the opposite way | ✅ |
| F9 | Activate the menu above the active panel | ✅ |
| F10 | Activate the left menu / leave the menu | ✅ |
| Alt+F1 / Alt+F2 | Choose drive for the left / right panel | ✅ |
| Alt+F4 | Exit (or minimise, by option) | ✅ |
| Alt+F5 / Alt+Shift+F5 | Pack selection / pack and delete the originals | ✅ |
| Alt+F6 or Alt+F9 | Unpack the archive under the cursor or selected archives | ✅ |
| Alt+Shift+F9 | Test archives | ✅ |
| Alt+F7 / Alt+Shift+F7 | Search dialog / search in a separate process | ✅ |
| Alt+F8 | List of recent command lines | ✅ |
| Alt+F10 | Dialog with the directory tree | ✅ |
| Alt+F11 / Alt+F12 | Open the left / right current-directory bar | ✅ |
| Alt+Shift+F11 / F12 | Put keyboard focus on the horizontal / vertical button bar | ✅ |
| Shift+F1 | Menu of custom column views | ✅ |
| Shift+F2 | Compare file lists | ✅ |
| Shift+F10 | Context menu of the item | ✅ |
| Shift+Esc | Minimise to an icon | ✅ |

## Panels, folders, history

| Keys | Action | Mark |
|------|--------|------|
| Tab | Switch between left and right panel | ✅ |
| Shift+Tab | Switch between file list and separate tree (when shown) | ✅ |
| Backspace or Ctrl+PgUp | Parent folder | ✅ |
| Ctrl+PgDn or Enter | Open folder / archive / run program or associated program | ✅ |
| Ctrl+\ (or Ctrl+<) | Jump to the root folder | ✅ |
| Ctrl+Left / Ctrl+Right | Show the folder or archive under the cursor in the other panel; if none, show the current folder there | ✅ |
| Ctrl+U / Ctrl+Shift+U | Swap the two panels / swap panels and their tabs | ✅ |
| Ctrl+I | Jump to the target folder | ✅ |
| Alt+Left / Alt+Right | Back / forward in the visited-folder history (up to 50 per panel) | ✅ |
| Alt+Down / Alt+Shift+Down | Open the history list / the same list without thinning | ✅ |
| Ctrl+D | Directory hotlist (bookmarks); with Shift it opens the folder in a new tab | ✅ |
| Ctrl+B / Ctrl+Shift+B | Branch view: all files of the folder and its subfolders in one list / only for selected folders | ✅ |
| Alt+Enter | Properties (the system dialog) | ✅ |
| Alt+Shift+Enter | Count the sizes of all subfolders in the current folder; abort by holding Esc | ✅ |
| Shift+Enter | Run via the shell and keep the window; in the history list: open in a new tab; for ZIP: use the alternative handling | ✅ |

## Selection

| Keys | Action | Mark |
|------|--------|------|
| Insert | Select / deselect and move down | ✅ |
| Space | Select / deselect; on a folder it also counts and shows its size (option "Selection with Space") | ✅ |
| Shift+Up/Down, Shift+Home/End, Shift+click | Range | ✅ (from the earlier wiki pass) |
| Num+ / Num- | Select / deselect by pattern (dialog) | ✅ |
| Shift+Num+ / Shift+Num- | The "other" variant of files-only vs. files+folders; Shift+Num- always files only | ✅ |
| Ctrl+Num+ / Ctrl+Num- | Select all / deselect all (Num- always files and folders) | ✅ |
| Ctrl+A | Select all | ✅ |
| Alt+Num+ / Alt+Num- | Select / deselect all with the same extension | ✅ |
| Num* / Shift+Num* | Invert selection (files-only or files+folders by setting) | ✅ |
| Num/ | Restore the selection that was active before the last operation | ✅ |
