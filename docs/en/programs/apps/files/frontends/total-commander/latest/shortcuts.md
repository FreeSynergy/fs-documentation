# Total Commander — Shortcuts

> [Total Commander](../index.md) · [description](description.md)

The complete default list is in `KEYBOARD.TXT` in the install folder and the offline help ⚠️ — **not reachable**, so this page is **incomplete** `[nicht belegt]`. ✅ = official wiki (2026-11-13); ⚠️ = third-party shortcut lists, not official. All keys can be reassigned ✅ (Num keys ✅).
