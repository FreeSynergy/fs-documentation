# Syncthing - Description

## What the program does

Runs on each device, finds the other devices and copies changes in shared folders. The user manages it through a browser page of the local program. ✅

## Differentiation

- Against Seafile and Nextcloud: no server, no accounts; only devices.
- Against rclone: continuous two-way sync between peers, not a tool for storage services.

## Who it suits

Users who want their own devices in sync without a cloud. Conflict handling, versioning, ignore rules: Open (not on the pages read).
