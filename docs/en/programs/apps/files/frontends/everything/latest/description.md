# Everything - Description

## What the program does

Keeps a list of all file and folder names on local volumes and filters it live. It does not open or move files itself; it is a finder. ✅

## Differentiation

- Against Dolphin or Finder search: those search inside the file manager and can look into contents; Everything answers faster but only on names.
- Windows only (XP to 11) ✅.

## Who it suits

People with very many files who know part of a name. Current version number: Open.
