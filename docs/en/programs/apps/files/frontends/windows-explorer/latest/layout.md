## Views (these are views, not frontends)

Icons (several sizes), list, details, compact ✅; tiles and content `[nicht belegt]`. Ctrl+Shift+number picks a style, Ctrl+wheel resizes icons ✅. Details columns can be fitted to the text (Ctrl + numpad plus) ✅.
