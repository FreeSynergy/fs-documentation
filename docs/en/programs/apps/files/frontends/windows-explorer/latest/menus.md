## Context menu — general

Windows 11 shows a short menu with the common actions at the top ✅ (Cut, Copy, Rename, Delete named ✅; the icon row and order `[nicht belegt]`). **Show more options** (or Shift+right-click ✅, Shift+F10 opens the menu for the selected item ✅) shows the full legacy menu with entries added by other programs ✅ (that other programs add entries: `[nicht belegt]` on the page).

## Bar menus

Command bar buttons: Cut, Copy, Paste, Rename, Share, Delete, View ✅ (partly named). View menu: layouts, Compact view, Show > Navigation pane, Preview pane, Item check boxes, File name extensions, Hidden items ✅. Options: start page (Home or This PC), show extensions, hidden items ✅.
