# Windows Explorer 11 — Themes

> [Windows Explorer](../index.md) · [description](description.md)

Explorer follows the Windows light/dark setting and accent colour `[nicht belegt]` on the pages read. The pages describe no theme of its own; only layout switches (Compact view, icon sizes, navigation pane on/off) ✅. Nothing to rebuild beyond those switches. Colours and typography are not recorded (ADR 0013).
