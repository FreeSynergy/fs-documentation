# Windows Explorer 11 — Shortcuts

> [Windows Explorer](../index.md) · [description](description.md)

Source: Microsoft's keyboard-shortcut page, retrieved 2026-11-13 ✅. Ctrl+C / Ctrl+V / Ctrl+X are in the general section of that page, not in the Explorer table ✅.

| Group | Keys | Action |
|-------|------|--------|
| Window | Win+E | Open File Explorer |
| Window | Ctrl+N | New window |
| Window | F11 | Maximise / minimise |
| Window | F6 | Cycle through elements |
| Window | F5 | Refresh |
| Navigate | Alt+Left or Backspace | Previous folder |
| Navigate | Alt+Right | Next folder |
| Navigate | Alt+Up | Up one level |
| Navigate | Alt+D, Ctrl+L, F4 | Focus address bar |
| Navigate | Ctrl+E, Ctrl+F, F3 | Search box / search |
| Navigate | Ctrl+Shift+E | Expand all folders in the pane |
| Navigate | Left / Right arrow | Collapse/expand, or go to parent / first subfolder |
| Navigate | Home / End | Top / bottom |
| Select | Shift+arrows | Extend selection |
| Select | Ctrl+arrow, Space | Select separate items |
| Edit | Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut, paste |
| Edit | F2 | Rename |
| Edit | Ctrl+D or Delete | To Recycle Bin |
| Edit | Shift+Delete | Delete permanently |
| Edit | Ctrl+Shift+N | New folder |
| Edit | Alt+Enter | Properties |
| Edit | Shift+F10 | Context menu |
| Edit | Shift+right-click | "Show more options" menu |
| Drag | Ctrl+drag / Shift+drag / Alt+drag | Copy / move / make shortcut |
| View | Ctrl+wheel | Icon size |
| View | Ctrl+Shift+1..9 | View style (e.g. 2 large icons, 6 details) |
| View | Ctrl + numpad plus | Fit columns |
| View | Alt+P / Alt+Shift+P | Preview pane / details pane |
| Tabs | Ctrl+T / Ctrl+W | New tab / close tab (or window if last) |
| Tabs | Ctrl+Tab / Ctrl+Shift+Tab | Next / previous tab |
| Tabs | Ctrl+1..9 | Go to tab n |
| Undo | Ctrl+Z, Ctrl+Y | Undo, redo — `[nicht belegt]` in the Explorer table |
| Select all | Ctrl+A | `[nicht belegt]` in the Explorer table |
