# Dropbox - Description

## What the program does

Stores files in the provider's cloud and syncs them to devices; sharing by link or by invitation; file requests collect files from outside people. Closed, commercial. ✅

## Differentiation

- Against Nextcloud Files and Seafile: not self-hostable.
- Against Google Drive: same class; file requests are the item worth studying here.

## Who it suits

Users who exchange files with people who have no account. Sync internals, versioning, plans: Open.
