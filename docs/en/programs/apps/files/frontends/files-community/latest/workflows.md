# Files — Workflows

> [Files](../index.md) · [description](description.md) · [acceptance](acceptance.md) · [gaps](gaps.md)

Format: goal, steps (user does X → program shows Y), errors, undo. ✅ = stated on the docs (2026-11-13); `[nicht belegt]` = not stated. IDs W1..W21 match the other two file-manager dossiers.

## W1 Browse the local file system
1. Start Files → Home page with widgets Quick access, Drives, Network locations, Tags, Recent files ✅.
2. Click a drive in the sidebar **Drives** or the widget → its folders ✅. USB sticks appear as drives `[nicht belegt]` (sidebar lists connected drives ✅).
3. **Network** in the sidebar → network locations and mapped drives ✅. Cloud-client folders under **Cloud Drives** ✅; Linux distributions under **WSL** ✅.
4. Home folder: Pinned Desktop/Documents/Downloads ✅ or alias `@documents` ✅.
Errors: unreachable location → message `[nicht belegt]`. Undo: n/a.

## W2 Navigate
1. Double-click folder → opens `[nicht belegt]` (click setting ✅ single or double).
2. Alt+Left back, Alt+Up up, F5 refresh ✅; double-click blank space goes up (option ✅); the folder just left is scrolled into view (option ✅).
3. Breadcrumb in the Omnibar: click a segment; chevron lists sub-folders ✅.
4. Ctrl+L or click empty space in the bar → path editable, fully selected ✅; type, Enter.
5. Type `@` → alias list narrows as you type ✅.
Errors: bad path `[nicht belegt]`.

## W3 Select
1. Click → one item. Ctrl+A → all ✅. Check boxes (option ✅). Select on hover (option ✅).
2. Shift/Ctrl multiselect `[nicht belegt]`. Pattern selection `[nicht belegt]`.

## W4 Copy / move with the clipboard
1. Select; Ctrl+C or Ctrl+X ✅. 2. Navigate. 3. Ctrl+V ✅ → items appear. Errors: clash W7. Undo: Ctrl+Z ✅.

## W5 Drag and drop
1. Drag items onto a sidebar place → place outlined in accent colour ✅ → drop moves or copies (default and keys `[nicht belegt]`).
2. Drag over a tab and hold → tab switches; drop there ✅.
3. Drag into a second pane (W6) `[nicht belegt]` in detail.

## W6 Second pane (dual pane)
1. Actions button (top left) → choose vertical or horizontal arrangement ✅; or right-click folder > open in new pane ✅; or Alt+Shift+V / Alt+Shift+H ✅; or drag a tab into the file area ✅.
2. Ctrl+Shift+Right → focus the other pane ✅. New panes open to Home ✅.
3. Copy: select in one pane, drag to the other or copy and paste there `[nicht belegt]`. Dedicated "copy to other pane" key: none stated.

## W9 Rename one
1. F2 ✅ → name editable. 2. Enter. Changing the extension → warning (option ✅). Undo: Ctrl+Z ✅.

## W11 Delete
1. Delete → recycle bin ✅; confirmation per setting ✅. 2. Shift+Delete → permanent ✅ (confirm per setting ✅). Undo: Ctrl+Z `[nicht belegt]` for bin items.

## W12 Recycle Bin

## W13 Undo / redo
Ctrl+Z / Ctrl+Y ✅. Scope (which actions) `[nicht belegt]`.

## W14 New file / folder
Action "Create item" ✅ (Ctrl+Shift+I, listed twice ✅); item types `[nicht belegt]`.

## W15 Properties
Alt+Enter ✅ → properties. Info pane (Ctrl+Alt+I ✅) shows details; tags editable there ✅.

## W16 Search
1. Ctrl+F or F3 or search icon ✅ → Omnibar in search mode. 2. Type → suggestions; first entry "Search for" opens results on Enter ✅. 3. `tag:name` filter ✅. 4. Natural language on Copilot+ PCs ✅. Scope: current folder or indexed content ✅.

## W17 Sort / group
Sort by (name, modified, created, size, type, tag), descending, folders-first rule; group by same + date unit ✅. Where the menu is: `[nicht belegt]` (palette actions ✅).

## W18 Views
Details, List, Cards, Grid, Columns, Adaptive ✅; Ctrl+Shift+1..5 ✅; size slider, Ctrl+Plus/Minus ✅; per folder unless sync on ✅.

## W19 Tabs
1. Ctrl+T ✅ / plus button ✅ → new tab on Home. 2. Middle-click a folder, or ctrl+click in sidebar, or context menu ✅. 3. Drag to reorder, tear off, move between windows ✅. 4. Ctrl+W close; Ctrl+Shift+T reopen ✅. Restored on restart: depends on startup setting ✅.
