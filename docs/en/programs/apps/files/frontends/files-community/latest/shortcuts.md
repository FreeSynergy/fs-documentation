## Additions (retrieved 2026-11-14, platform Windows)

Source: https://files.community/docs/features/command-palette (table "Supported actions", 63 rows; the page says "150+ actions" but does not say the table is complete) ✅, plus /docs/features/tabs, /docs/features/omnibar, /docs/features/terminal. The page was read through a summarising fetch, so single keys should be checked once in the app.

| Group | Keys | Action |
|-------|------|--------|
| Edit | Ctrl+Shift+C / Alt+Ctrl+C | Copy item path / copy item path with quotes |
| Edit | Ctrl+Shift+V | Paste into the selected folder |
| Edit | Enter | Open item |
| Edit | Ctrl+R (besides F5) | Refresh |
| Edit | Ctrl+Space | Toggle selection of an item |
| Edit | Ctrl+D (besides Delete) | Delete |
| Edit | Alt+Shift+Enter (page writes "AltShift+Enter") | Open the system properties |
| Navigate | Backspace (besides Alt+Left) | Back |
| View | Ctrl+Shift+6 | Adaptive layout (view 6; Ctrl+Shift+1..5 are details, list, cards, grid, columns) |
| Window | Ctrl+Alt+Up / Ctrl+Alt+Down | Enter / leave compact overlay |
| Tabs | Ctrl+F4 (besides Ctrl+W) | Close tab |
| Panes | Ctrl+Alt+W | Close the active pane |
| Tools | Ctrl+Shift+. | Open the folder of the log file |

Conflict between pages: Ctrl+Shift+W is "close all tabs" in the Command Palette table and "close current window" on the Tabs page `[nicht belegt]` which is right. Actions without a default key (e.g. dot files, sort, group, dual pane toggle, pin, archive create, recycle bin) have `[nicht belegt]` as a key on the page; the user can bind keys (Settings > Actions).
