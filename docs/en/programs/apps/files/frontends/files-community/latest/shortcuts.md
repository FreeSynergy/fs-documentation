Source: Command Palette, Tabs and Omnibar docs pages, retrieved 2026-11-13 ✅. The page says the list is "examples, not exhaustive" and that not every action has a default key. Keys are editable (Settings > Actions) ✅; only Ctrl+Shift+P is stated as default there.

| Navigate | Alt+Left / Alt+Up / F5 | Back / up / refresh |

| Navigate | Ctrl+F, F3 | Search |
| Navigate | Ctrl+Shift+P | Command Palette |
| Tabs | Ctrl+T, Ctrl+W, Ctrl+Shift+T | New, close, reopen |
| Tabs | Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+1..9 | Next, previous, number |
| Tabs | Ctrl+Shift+K, Ctrl+Shift+W | Duplicate tab, close window |
| Window | Ctrl+N, F11, F12 | New window, fullscreen, compact overlay |
| Panes | Alt+Shift+H / Alt+Shift+V | Split horizontally / vertically |
| Panes | Ctrl+Shift+Right | Focus other pane |
