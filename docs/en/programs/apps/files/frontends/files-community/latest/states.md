# Files — States

> [Files](../index.md) · [description](description.md)

The docs pages describe few states. ✅ = stated; `[nicht belegt]` = not stated (product knowledge or unknown; verify by running the app).

| State | What the user sees | What the user can do |
|-------|--------------------|----------------------|
| Start | By setting: new tab (Home page with widgets ✅), last tabs restored, or chosen pages ✅ | Open place, search |
| Home page | Widgets: Quick access, Drives, Network, Tags, Recent files (each switchable) ✅ | Open an item |
| Empty folder | Empty file area with a hint `[nicht belegt]` | New item, paste |
| Loading | List fills / progress indicator `[nicht belegt]` | Navigate away |
| Error | Message that a location cannot open `[nicht belegt]` | Retry (F5 ✅), edit path |
| FTP login | Prompt for user name and password "when needed" ✅ | Enter or cancel `[nicht belegt]` |
| FTP connected | Server folders as a tab ✅ | Close the tab or window to disconnect ✅ |
| One item selected | Highlight (check box if enabled ✅); info pane shows details ✅ | Actions of the toolbar mode `[nicht belegt]` |
| Several selected | Same; tags can be set for all ✅ | Open folders in tabs ✅, tag, copy, delete |
| Select on hover | Items select under the pointer (option) ✅ | Turn off |
| Rename (editing) | Name editable (F2 ✅) | Enter / Esc `[nicht belegt]` |
| Extension changed | Warning prompt (option) ✅ | Confirm or keep `[nicht belegt]` |
| Delete | Confirmation by setting: always, only permanent, never ✅ | Confirm or cancel |
| Conflict | Dialog for name clash | `[nicht belegt]` see [dialogs](dialogs.md) |
| Copy in progress | Progress of the operation | `[nicht belegt]` |
| Drag over tab | The tab switches after holding ✅ | Drop |
| Drag over sidebar place | Place outlined in the accent colour ✅ | Drop |
| Two panes | Two file areas, one has focus (Ctrl+Shift+Right ✅) | Split, close pane, switch |
| Recycle Bin | Own toolbar mode ✅ | Restore, empty `[nicht belegt]` |
| Offline / locked | Cloud drive missing if its client is not running (implied ✅ "client must be installed and running"); locked file `[nicht belegt]` | Start the client |
| Tags on non-NTFS | Tags do not work ✅ | — |
| Folder sizes | Calculated on request, costs CPU ✅ | Turn on or off |
