# Files — Description

> [Files](../index.md) · version: latest

A modern file manager for Windows 10/11 ✅ (minimum version `[nicht belegt]`). It browses local drives, network locations, cloud-client folders, WSL distributions and FTP/FTPS servers, with tabs, an optional second pane, tags and a searchable list of actions.

**Evidence marks (whole dossier):** ✅ stated on the official docs page read on 2026-11-13; `[nicht belegt]` not stated there. Only functions are described, nothing is copied (ADR 0013).

## Who it suits

People who want Explorer's familiarity with tabs, dual pane, tags and keyboard control, without Total Commander's learning curve.

## Differentiation

- Fluent look like Windows 11 ✅ (README); Explorer-like single click navigation plus Omnibar.
- Second pane inside any tab ✅; Total Commander has two panes always.
- Every action reachable through the Command Palette; key bindings editable ✅.
