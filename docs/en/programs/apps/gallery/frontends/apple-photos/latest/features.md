# Apple Photos - Features

## Main features

- Library with iCloud Photos sync across devices.
- Search for photos and videos, filters.
- People and pets recognition and naming.
- Memories with music and titles.
- Shared albums; iCloud Shared Photo Library (the duplicates view has a library selector).
- Live Text in photos.
- Duplicates album: merge keeps one original in place; others go to Recently Deleted for recovery.
- How duplicates are decided: Open (the guide does not say).
- Clean Up (retouching) on supported devices.
