# Immich

> Category: [gallery](../../index.md)

## What it is

Immich is a self-hosted photo and video management solution (server + mobile app): uploads from the phone, face and object recognition, timelines, albums, shared galleries and a complete REST API. Stack: NestJS server + PostgreSQL + machine-learning jobs, frontend Svelte/React, apps for iOS/Android.
