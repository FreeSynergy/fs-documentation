# Immich - Menu Items

## Main navigation (left bar of the web app)

| Menu | Description |
|------|-------------|
| Photos | Timeline of all your own captures (day/month/year) |
| Albums | Own albums, albums shared by others |
| Explore | People, places, objects, tags, favourite views |
| Favourites | Captures marked as favourite |
| Shared | Captures/albums shared by other users |
| Archive | Archived material (hidden from the timeline) |
| Trash | Deleted captures, recoverable for 30 days |
| Upload | File selection, duplicate detection, background upload |

## User menu (avatar bottom left)

Settings (language, theme, date format), share links, sign out, storage space

## Administration menu (administration, admin only)

| Menu | Content |
|------|---------|
| Users | Create, roles (admin/user), quotas, deletion |
| Libraries | Mount external folders as a library (SCAN) |
| Jobs | Re-trigger the queues (thumbnail, ML, duplicates, face, upload) |
| Storage template | Path/naming scheme for stored files |
| Machine learning | Models, devices (CPU/GPU), activation |
| Server status / logs | Versions, model downloads, log search |
| PARTNER | Partner account for a shared timeline |
| Webhooks / notifications | Report events externally |

## Context menus

| Object | Actions |
|--------|---------|
| Single capture | Favourite, archive, download, delete, edit (crop), info, similar |
| Multi-selection | Add to album, share, tag, archive, delete, merge (stack) |
| Album | Share (link/user), edit, delete, set cover |
| Person | Set name, birthday, merge people, favourite, cover |

## Menus by role

| Role | Visible |
|------|---------|
| User | Photos, albums, search, sharing, trash |
| Admin | Additionally the full administration area |
| Guest (share link) | Only the shared gallery, download depending on the permission |
