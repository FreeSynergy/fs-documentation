# Immich - Keyboard Shortcuts

## Overview

The web app knows shortcuts for navigation, selection and actions in the viewer. In input fields the keys are disabled except `Esc`.

> State: Immich 1.1xx (web app). The mobile apps have no keyboard shortcuts.

## Global

| Shortcut | Function |
|----------|----------|
| `/` | Focus the search field |
| `Esc` | Close viewer/selection/dialog |
| `u` | Open the upload dialog |
| `a` | Select everything in the current view area |
| `Ctrl/Cmd+A` | Select all (in selection mode) |

## Selection and actions

| Shortcut | Function |
|----------|----------|
| `Shift + click` | Select a range |
| `Shift + arrow key` | Extend the selection |
| `Backspace`/`Del` | Move the selection to the trash |
| `Ctrl/Cmd+S` | Toggle favourite (heart) |
| `Ctrl/Cmd+D` | Download the selection |
| `i` | Detail/EXIF panel in the viewer |

## Viewer

| Shortcut | Function |
|----------|----------|
| `←` / `→` | Previous / next medium |
| `Space` | Start/pause the slideshow |
| `m` | Map view of the capture location |
| `e` | Edit (crop/rotate) |
| `h` | In the viewer: favourite |

## Not present (deliberately)

| Assumed | Status |
|---------|--------|
| Single-key command mode (Vim-like) | ❌ |
| Shortcut for "create album" | ❌ (menu/toolbar only) |
| Global delete-undo shortcut | ❌ (open the trash) |

## Mac

`Cmd` instead of `Ctrl`, e.g. `Cmd+S` (favourite), `Cmd+D` (download).
