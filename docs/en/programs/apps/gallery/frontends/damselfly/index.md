# Damselfly

> Category: [gallery](../../index.md)

## What it is

Damselfly is a lightweight, fast-starting photo gallery with AI recognition (faces, scenes, text/OCR, similarity search) based on PostgreSQL vectors. Stack: C#/.NET 8, React frontend, PostgreSQL with pgvector, container-oriented.
