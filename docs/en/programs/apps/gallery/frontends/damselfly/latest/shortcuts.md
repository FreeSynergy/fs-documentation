# Damselfly - Keyboard Shortcuts

## Overview

Shortcuts cover search, selection and the viewer; the administration has no shortcuts of its own.

> State: Damselfly 2.x.

## Search and selection

| Shortcut | Function |
|----------|----------|
| `/` or `S` | Focus the search field |
| `Ctrl/Cmd+A` | Select all visible images |
| `Shift + click` | Range selection |
| `Esc` | Close selection, filter or viewer |
| `Del` | Delete the selection (with a confirmation prompt) |

## Viewer

| Shortcut | Function |
|----------|----------|
| `←` / `→` | Previous / next image |
| `i` | Detail/EXIF drawer |
| `f` | Toggle favourite |
| `d` | Download |
| `Space` | Start/pause the slideshow |
| `Esc` | Close the viewer |

## Not present (deliberately)

| Assumed | Status |
|---------|--------|
| Command palette | ❌ |
| Shortcut for creating an album | ❌ (menu) |
| Undo | ❌ |

## Mac

`Cmd` instead of `Ctrl`, letter keys unchanged.
