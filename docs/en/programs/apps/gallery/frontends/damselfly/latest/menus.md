# Damselfly - Menu Items

## Main navigation

| Menu | Description |
|------|-------------|
| Search | Text/similarity search, filters (folder, period, type, label) |
| Albums | Saved collections, folder albums |
| People | Face clusters with names |
| Scenes / labels | Recognised scenes, objects, texts (OCR) |
| Folders | A reflection of the watched library folder |
| Favourites | Marked images |
| Sharing | Public links and embedded galleries |

## Upload and sync

- **Upload**: drag & drop, whole folder, bulk actions
- **Folder sync**: "push" (upload) and "pull" (import from the server folder)
- **Duplicates**: checksum comparison with a cleanup view

## Administration (admin)

| Area | Content |
|------|---------|
| Index | Scan status, pending tasks, re-apply models |
| Models | Activated AI models (faces, labels, OCR, similarity), GPU note |
| Users | Accounts, roles, quotas |
| Gallery | Watermarks, download permissions, public links |
| System | Logs, storage usage, backups |

## Menus by role

| Role | Visible |
|------|---------|
| Guest | Public albums and links |
| User | Own library, upload, albums, search |
| Admin | Additionally administration, models, sync |
