# PhotoPrism - Keyboard shortcuts

## Overview

The shortcuts apply in search, mosaic and viewer; in text fields they are disabled except `Esc`/`Enter`.

> State: PhotoPrism CE/Plus 24.x–25.x.

## Search and selection

| Shortcut | Function |
|----------|----------|
| `S` or `/` | Focus the search field |
| `A` | Select all visible photos |
| `Shift + click` | Range selection |
| `Esc` | Close selection/dialog |
| `F1` | Shortcut overview |

## Actions

| Shortcut | Function |
|----------|----------|
| `L` | Label dialog for the selection |
| `B` | Move to / add to album |
| `F` | Toggle favourite |
| `H` | Publish / hide |
| `R` | As folder-album view (refresh folder) |
| `Del` | Remove from the index (does not delete from the disk) |
| `Ctrl/Cmd+A` | Select everything in the current result |

## Viewer

| Shortcut | Function |
|----------|----------|
| `←` / `→` | previous / next image |
| `Space` | Start/pause the slideshow |
| `I` | INFO panel (EXIF) |
| `M` | Map of the capture location |
| `P` | Share dialog |
| `Esc` | Close the viewer |

## Not present (deliberately)

| Assumed | Status |
|---------|--------|
| Vim-like mode keys | ❌ |
| Shortcut for renaming | ❌ (context menu) |
| Undo shortcut | ❌ |

## Mac

`Cmd` instead of `Ctrl` (`Cmd+A`), the other keys identical.
