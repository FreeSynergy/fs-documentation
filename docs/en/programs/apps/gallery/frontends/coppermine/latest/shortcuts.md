# Coppermine - Keyboard Shortcuts

## Overview

Coppermine ships with **no keyboard shortcuts of its own**. Only what the browser and the lightbox plugins in use provide has any effect.

> State: Coppermine 1.6.x / current development branches.

## Browser and plugin behaviour

| Shortcut | Function | Origin |
|----------|----------|--------|
| `←` / `→` | Previous/next image | Only with a lightbox plugin |
| `Esc` | Close the lightbox | Plugin |
| `Tab` / `Shift+Tab` | Form fields | Browser |
| `Enter` | Submit forms | Browser |

## Gallery navigation (website)

| Assumed | Status |
|---------|--------|
| Letter navigation (`n`/`p`) | ❌ |
| Command palette | ❌ |
| Shortcut for upload | ❌ |
| Undo for batch actions | ❌ |

## Mac

Browser standard (`Cmd` instead of `Ctrl`), beyond that no program shortcuts.

## Frontend note

When recreating this in FreeSynergy, the shortcuts usual in the other gallery frontends (`←`/`→`, `Esc`, `f` for favourite) should be added and marked as a **FreeSynergy extension**.
