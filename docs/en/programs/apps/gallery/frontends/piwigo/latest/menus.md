# Piwigo - Menu items

## Visitor navigation

| Menu | Description |
|------|-------------|
| Start pages | last visits, random, most seen, best rated images |
| Albums (categories) | hierarchical category tree, sub-allocations |
| Tags | tag cloud with image counts |
| Calendar | year/month/day view by capture date |
| Search | full text, tags, period, "who uploaded" |
| Comments | latest comments from the community |
| My albums | private albums of registered users |
| Notifications | reply to comments, new images (depending on plugin) |

## User menu

Edit profile, password, notifications, favourites, highres download (depending on right), log out

## Admin menus (administration)

| Menu | Content |
|------|---------|
| Tools → management | Image management (batch), category management, sync (folder ↔ database) |
| Tags | Create tags, merge, assign automatically |
| Users | Users, groups, access rights per category |
| Settings | General, themes, languages, comments, notifications |
| Plugins | Install, update, configure |
| Statistics | Visits, image counts, best rating |
| Site history | Change log |

## Context menus

| Object | Actions |
|--------|---------|
| Image (admin batch) | Rotate, edit (metadata), delete, assign category, tag, status (published/pending) |
| Category | Rename, sub-albums, permission assignment, set cover, description |
| Image (visitor) | Favourite, comment, share (social/link), download (depending on right) |

## Menus by role

| Role | Visible |
|------|---------|
| Guest | Public categories, comments depending on the setting |
| User | Own albums, favourites, upload depending on right |
| Webmaster | Administration without the system level |
| Admin | Full administration incl. plugins and config |
