# Piwigo - Keyboard shortcuts

## Overview

The shortcuts exist mainly on the image page and in the slideshow; the administration uses no own keys.

> State: Piwigo 14.x / 15.x (standard themes).

## Image page and slideshow

| Shortcut | Function |
|----------|----------|
| `←` / `→` | previous / next image |
| `n` | Next image (alternative) |
| `p` | Previous image |
| `s` | Start/pause the slideshow |
| `i` | Show/hide image information |
| `c` | Focus the comment field (depending on theme) |
| `f` | Mark favourite (when signed in) |
| `Esc` | Close the lightbox |
| `h` | Open the image at full size (depending on right) |

## Administration

| Shortcut | Function |
|----------|----------|
| `Tab` / `Shift+Tab` | Form fields |
| `Ctrl/Enter` | Submit the comment |
| `Esc` | Close dialog/lightbox |

## Not present (deliberately)

| Assumed | Status |
|---------|--------|
| Command palette in the admin area | ❌ |
| Global upload shortcut | ❌ |
| Undo for batch actions | ❌ |

## Mac

`Cmd` instead of `Ctrl` (submit comment), letter keys unchanged.
