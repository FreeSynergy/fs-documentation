# Piwigo Documentation

## Overview

Piwigo is a classic web-toolkit photo gallery: category tree, roles and permissions per folder, themes, extensions and a complete webservice API. Stack: PHP/MySQL, its own template system, admin and visitor areas separated.

## File structure

- [menus.md](latest/menus.md) - Visitor navigation, admin menus, permissions by role
- [features.md](latest/features.md) - Categories, tags, comments, plugins, what Piwigo does NOT do
- [description.md](latest/description.md) - How it differs from Immich, PhotoPrism and Coppermine
- [layout.md](latest/layout.md) - Category tree, image page, admin masks
- [shortcuts.md](latest/shortcuts.md) - Slideshow and admin keyboard shortcuts
- [api.md](latest/api.md) - Webservice `ws.php`, method catalogue, signatures, plugins
