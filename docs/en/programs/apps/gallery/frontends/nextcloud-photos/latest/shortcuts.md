# Nextcloud Photos - Keyboard shortcuts

## Overview

The shortcuts of the Nextcloud web interface apply (viewer and file view); Photos itself brings no own keys.

> State: Nextcloud 29/30, Photos app 6.x.

## Global

| Shortcut | Function |
|----------|----------|
| `/` | Focus the search field |
| `Esc` | Close viewer/dialog |
| `F1` | Short help (the help app is required) |
| `c` | New comment field (in the file view) |

## Viewer / file view

| Shortcut | Function |
|----------|----------|
| `←` / `→` | previous / next element |
| `Space` | Start/pause the slideshow |
| `i` | Detail page of the file |
| `d` | Download |
| `Ctrl/Cmd+A` | Select everything in the view |
| `Shift + click` | Select a range |

## Not present (deliberately)

| Assumed | Status |
|---------|--------|
| Photos' own command palette | ❌ |
| Shortcut for creating an album | ❌ |
| Undo for moving | ❌ (versioning of the Files app instead of undo) |

## Mac

`Cmd` instead of `Ctrl`, the other keys identical.
