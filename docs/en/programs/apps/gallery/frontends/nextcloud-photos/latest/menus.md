# Nextcloud Photos - Menu items

## Photos app (top app bar: "Photos")

| Area | Description |
|------|-------------|
| Latest / chronology | All folders released for the gallery, by capture date |
| Albums | Own albums, system albums (holidays etc. depending on version) |
| Folders | Alternative view by folder structure |
| Shared with me | Albums and folders shared by others |
| Favourites | Images marked as favourite |
| People / recognition | Face clusters (only with the app activated) |
| Maps | Location view (the "Maps" app is required) |

## Folder selection (Settings → Photos)

- Define which folders appear in the chronology (default: `Fotos`, `Camera`)
- Excluded folders, order, "video in chronology"

## Albums dialog

Create album, edit, set cover, add/remove images, save as folder album, share (users/groups/link)

## Nextcloud platform menus (relevant for the gallery)

| Menu | Content |
|------|---------|
| Files sharing | Link policies, expiry, password, download permission |
| Recognizer / face recognition | Models, index run, data-protection opt-in |
| Administration → settings | Password links, public uploads, preview sizes |

## Menus by role

| Role | Visible |
|------|---------|
| Guest (link) | Shared albums/folders, upload depending on the setting |
| User | Own gallery, albums, shared content |
| Group admin | Group folder gallery, the group's permissions |
| Nextcloud admin | Global settings, apps, recognition |
