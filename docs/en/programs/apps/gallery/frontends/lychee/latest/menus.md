# Lychee - Menu items

## Gallery navigation

| Menu | Description |
|------|-------------|
| Albums | Own and shared albums, nested albums |
| Public | Albums marked as public |
| Search | Search by title, description, album |
| Favourites | Captures marked with a star |
| Shared | Own shares (links, users, password) |
| New | Upload area (files, folders, URL import) |

## Album menus

| Menu | Content |
|------|---------|
| Album actions (⋮) | Rename, description, cover, sorting, delete, download (ZIP) |
| Share dialog | Public link, password, expiry, permissions (read/download) |
| Captures | Favourite, rotate, edit (crop), delete, move, tag |

## Settings / administration

| Area | Content |
|------|---------|
| Users | Accounts, roles (admin/user/guest), quotas |
| Gallery | Watermark, size of the thumbnails, sort order |
| Security | 2FA, session lifetime, registration on/off |
| System | Logs, diagnostics (`php artisan diagnose`), update |
| Intelligence | Smart album (recurring search as an album) |

## Menus by role

| Role | Visible |
|------|---------|
| Guest | Public albums and shared links |
| User | Own albums, upload, shares |
| Admin | Additionally administration and diagnostics |
