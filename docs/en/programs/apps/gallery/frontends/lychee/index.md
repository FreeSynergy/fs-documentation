# Lychee

> Category: [gallery](../../index.md)

## What it is

Lychee is a lean, self-hosted photo gallery with albums, sharing via links and a clean REST API. Stack: PHP/Laravel, MySQL/MariaDB/PostgreSQL, React frontend (Lychee-front), version 5 with a separate frontend.
