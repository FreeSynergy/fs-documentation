# LibrePhotos - Keyboard shortcuts

## Overview

The web interface covers search, selection and viewer keys. In search fields only `Enter` and `Esc` apply.

> State: LibrePhotos 0.9.x.

## Search and navigation

| Shortcut | Function |
|----------|----------|
| `/` | Focus the search field |
| `Esc` | Close search/viewer/dialog |
| `←` / `→` | In the viewer: previous / next image |

## Selection and actions

| Shortcut | Function |
|----------|----------|
| `Ctrl/Cmd+A` | Select all visible captures |
| `Shift + click` | Select a range |
| `Backspace` / `Del` | Move to the trash |
| `F` | Toggle favourite |
| `D` | Download the selection |

## Not present (deliberately)

| Assumed | Status |
|---------|--------|
| Command palette | ❌ |
| Album shortcut | ❌ (menu only) |
| Undo | ❌ |

## Mac

`Cmd` instead of `Ctrl`, arrow keys unchanged.
