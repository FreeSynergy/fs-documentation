# Piwigo Documentation

## Overview

Piwigo is a classic web-toolkit photo gallery: category tree, roles and permissions per folder, themes, extensions and a complete webservice API. Stack: PHP/MySQL, its own template system, admin and visitor areas separated.

## File structure

- [menu.md](menu.md) - Visitor navigation, admin menus, permissions by role
- [features.md](features.md) - Categories, tags, comments, plugins, what Piwigo does NOT do
- [description.md](description.md) - How it differs from Immich, PhotoPrism and Coppermine
- [structure.md](structure.md) - Category tree, image page, admin masks
- [shortcuts.md](shortcuts.md) - Slideshow and admin keyboard shortcuts
- [api.md](api.md) - Webservice `ws.php`, method catalogue, signatures, plugins
