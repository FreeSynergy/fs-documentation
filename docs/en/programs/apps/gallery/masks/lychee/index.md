# Lychee Documentation

## Overview

Lychee is a lean, self-hosted photo gallery with albums, sharing via links and a clean REST API. Stack: PHP/Laravel, MySQL/MariaDB/PostgreSQL, React frontend (Lychee-front), version 5 with a separate frontend.

## File structure

- [menu.md](menu.md) - Gallery navigation, album menus, settings
- [features.md](features.md) - Albums, sharing, slideshow, what Lychee does NOT do
- [description.md](description.md) - How it differs from Piwigo, PhotoPrism and Immich
- [structure.md](structure.md) - Album tiles, lightbox, admin panel
- [shortcuts.md](shortcuts.md) - Lightbox and album keyboard shortcuts
- [api.md](api.md) - REST `/api`, token auth, album/photo endpoints
