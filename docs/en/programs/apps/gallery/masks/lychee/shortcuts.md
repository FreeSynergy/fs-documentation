# Lychee - Keyboard shortcuts

## Overview

The shortcuts concern the album overview, the album view and the lightbox. In dialogs only `Enter` and `Esc` work.

> State: Lychee v5 (Lychee-front).

## Lightbox

| Shortcut | Function |
|----------|----------|
| `←` / `→` | previous / next image |
| `Esc` | Close the lightbox |
| `i` | EXIF/info overlay |
| `Space` | Start/pause the slideshow |
| `f` | Toggle favourite |
| `d` | Download the current image |
| `Del` | Delete the image (with confirmation) |

## Gallery and albums

| Shortcut | Function |
|----------|----------|
| `/` | Focus the search |
| `n` | New album (when signed in) |
| `u` | Upload dialog |
| `Ctrl/Cmd+A` | Select all captures in the album |
| `Shift + click` | Range selection |

## Not present (deliberately)

| Assumed | Status |
|---------|--------|
| Command palette | ❌ |
| Undo for delete actions | ❌ |
| Shortcut for sharing an album | ❌ (menu ⋮) |

## Mac

`Cmd` instead of `Ctrl`, the other keys identical.
