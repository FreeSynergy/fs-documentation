# Immich Documentation

## Overview

Immich is a self-hosted photo and video management solution (server + mobile app): uploads from the phone, face and object recognition, timelines, albums, shared galleries and a complete REST API. Stack: NestJS server + PostgreSQL + machine-learning jobs, frontend Svelte/React, apps for iOS/Android.

## File structure

- [menu.md](menu.md) - Navigation in the web app and the app, administration menus
- [features.md](features.md) - Upload, search index, sharing, what Immich does NOT do
- [description.md](description.md) - How it differs from PhotoPrism, LibrePhotos and Nextcloud Photos
- [structure.md](structure.md) - Timeline grid, viewer, album and shared pages
- [shortcuts.md](shortcuts.md) - Shortcuts of the web app
- [api.md](api.md) - REST `/api`, API keys/OAuth2, BullMQ jobs, SDKs
