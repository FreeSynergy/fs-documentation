# Coppermine - Menu Items

## Visitor navigation

| Menu | Description |
|------|-------------|
| Home pages | last uploads, popular, top rated, random images |
| Albums | Albums and category tree, "last uploads" albums |
| Search | by file extension, keyword, time period, "titled only" |
| Members area | my favourites, uploads, notifications |
| Guestbook / comments | Moderation and own posts |
| Links/blocks | theme-dependent additional blocks (RSS, calendar) |

## User menu

Login/registration, profile, password, language, notification settings, upload ("My album")

## Admin menu (cuPCP)

| Menu | Content |
|------|---------|
| Configuration | general gallery, image and comment settings |
| Albums & categories | create, move, permissions per album |
| Users & groups | accounts, group names, permissions matrix |
| Image management | batch edit, move, rotate, moderate |
| Comments & ratings | approval, locking, reports |
| Themes & plugins | theme switching, plugin management (`plugin_api`) |
| Maintenance | watermark cron, thumbnail rebuild, check reports |

## Menus by role

| Role | Visible |
|------|---------|
| Guest | Public albums, comments depending on permission |
| Logged-in user | Own uploads, favourites, private albums |
| Moderator | Album upkeep without system permissions |
| Admin | Full cuPCP |
