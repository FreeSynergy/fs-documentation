# Coppermine Documentation

## Overview

Coppermine (CPG) is a classic web toolkit for photo galleries with albums, categories, comments, ratings and role permissions. Stack: PHP/MySQL, template-based, in use for many years; the current branches maintain PHP 8 compatibility.

## File structure

- [menu.md](menu.md) - Visitor navigation, admin menus, role permissions
- [features.md](features.md) - Albums, comments, watermarks, what Coppermine does NOT do
- [description.md](description.md) - How it differs from Piwigo, Lychee and Zenphoto
- [structure.md](structure.md) - Theme layouts, album pages, admin masks
- [shortcuts.md](shortcuts.md) - Image navigation and admin keyboard shortcuts
- **api.md**: Coppermine has no documented public API; the route is custom plugins (`plugin_api`) — see [api.md](api.md)
