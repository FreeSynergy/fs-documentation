# LibrePhotos Documentation

## Overview

LibrePhotos is the open-source alternative to Google Photos: automatic backup via an app, face and object recognition, timeline, albums and shared galleries. Stack: Django/Python backend, React frontend, PostgreSQL, machine-learning pipeline (CLIP, Face-Recognition).

## File structure

- [menu.md](menu.md) - Navigation, album/people menus, administration
- [features.md](features.md) - Scan pipeline, search, sharing features, what LibrePhotos does NOT do
- [description.md](description.md) - How it differs from Immich and PhotoPrism
- [structure.md](structure.md) - Timeline, search overlay, album pages
- [shortcuts.md](shortcuts.md) - Shortcuts of search and viewer
- [api.md](api.md) - REST `/api/...`, token auth, administrative tasks
