# Nextcloud Photos Documentation

## Overview

The Photos app of Nextcloud is the gallery surface on top of the Files app: chronology, albums, Shared view, folder selection and (from NC 25+) Recognizer/facial-recognition integration. Stack: PHP backend of the Nextcloud platform, Vue frontend, WebDAV plus OCS endpoints.

## File structure

- [menu.md](menu.md) - Photos navigation, folder selection, albums, shared areas
- [features.md](features.md) - Chronology, albums, recognition, what Photos does NOT do
- [description.md](description.md) - How it differs from Immich, PhotoPrism and Piwigo
- [structure.md](structure.md) - Chronology grid, viewer, album pages
- [shortcuts.md](shortcuts.md) - Shortcuts of the Nextcloud web surface
- [api.md](api.md) - WebDAV, OCS albums, Photos endpoints, sharing API

## Note

The gallery is part of the Nextcloud platform; permissions, users and links come from the core app **Files Sharing**.
