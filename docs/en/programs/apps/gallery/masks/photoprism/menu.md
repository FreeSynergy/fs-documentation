# PhotoPrism - Menu items

## Main navigation (top bar)

| Menu | Description |
|------|-------------|
| Search | Full-text, label, colour, place and face filters |
| Albums | Own albums, story/album folders, upload albums |
| Folders | File tree of the indexed library folder |
| Label | Label cloud with frequency, also from AI suggestions |
| Calendar | Timeline by capture date |
| Places | Map and place list (reverse geocoding) |
| Faces | People with names and birthday |
| Photos / videos / files | Filter by media type |

## Favourites and archive

- Favourites (star), archive (hidden from search), hidden objects (`private`), deleted (index removal)

## Settings (gear)

| Area | Content |
|------|---------|
| Account | Password, language, theme, two-factor |
| Gallery | Watermark options (Plus), preview scales, sorting, blurring |
| Index | Collection folder, import folder, update interval, offline mode |
| Face detection | Model, threshold, face recognition on/off |
| Lab | Experimental features, OCR, vector search |

## Admin menu (admin only, `/admin`)

| Menu | Content |
|------|---------|
| Users | Roles (admin, viewer, contributor), quotas, shares |
| Media | Preview/sidecar sizes, transcoding options |
| Server | Log, restart, licence status, original display |
| Import / index | "Update", "rescan", "clear" for the index |
| API | API client management, access keys |

## Context menus (multi-selection)

Add/remove label, assign album, favourite, publish/hide, edit (crop, rotation, time), download, delete, share via link, "search similar"

## Menus by role

| Role | Visible |
|------|---------|
| Viewer | Search, albums, viewer functions, no editing |
| Contributor | Additionally upload and own albums |
| Admin | Everything incl. settings and `/admin` |
