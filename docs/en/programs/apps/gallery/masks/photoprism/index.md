# PhotoPrism Documentation

## Overview

PhotoPrism indexes an existing photo collection, recognises content and faces, and presents it as a searchable web gallery with albums and sharing. Stack: Go backend (Plus variant with extended AI), Vue frontend, MariaDB/SQLite, index over its own folder.

## File structure

- [menu.md](menu.md) - Main navigation, folder/album menus, settings, admin
- [features.md](features.md) - Indexing, labels, faces, albums, what PhotoPrism does NOT do
- [description.md](description.md) - How it differs from Immich, LibrePhotos and Piwigo
- [structure.md](structure.md) - Search bar, mosaic, detail panel, folder view
- [shortcuts.md](shortcuts.md) - Shortcuts of search and viewer
- [api.md](api.md) - REST `/api/v1`, Basic/Bearer, batch index, webhooks
