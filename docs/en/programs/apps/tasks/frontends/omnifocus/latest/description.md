# OmniFocus - Description

## What the program does

OmniFocus holds an outline of folders, projects and actions with tags, flags, defer and due dates. Perspectives decide what is visible; Forecast shows dated actions beside calendar events; Review keeps projects current.

## Who it suits

OmniFocus is a task manager for Mac, iPhone, iPad, Apple Watch and Vision Pro, plus OmniFocus for the Web, aimed at long-term projects and the weekly review.
