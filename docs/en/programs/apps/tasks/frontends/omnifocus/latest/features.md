# OmniFocus - Features

## Main features

- Standard perspectives: Inbox, Projects, Tags, Forecast, Flagged, Nearby (tags with locations, list or map), Review, Completed, Changed.
- Custom perspectives (Pro): can be favourited, duplicated, deleted; rule details Open (text truncated).
- Forecast: actions plus calendar events in one reorderable list; Pro adds more sources (notification dates, a forecast tag, custom notifications, on-hold items).
- Review: periodic reminder to check projects; mark as reviewed.
- Project types: parallel, sequential, single-action list.
- Tags with status (active, on hold, dropped); selecting tags in the sidebar filters the outline.
- Back/forward between perspectives; Quick Open to jump to a perspective.
- Capture: Quick Entry, sharing and other methods (chapter exists; details Open).
- Automation (Pro): Omni Automation plug-ins (cross-platform) and AppleScript (Mac only).
- Sync: between Apple devices and OmniFocus for the Web; pricing is one-time purchase or subscription.

## What it does not do

- Full features such as custom perspectives and automation need Pro.
- Apple platforms plus a web client; no self-hosting.
