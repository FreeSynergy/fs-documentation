# Linear - Features

## Main features

- Triage actions: accept (optional comment, default status), decline (cancelled with reason), mark as duplicate (merge, move attachments), snooze (until a time or new activity), ask for more information.
- Triage Intelligence (Business and Enterprise plans): suggests assignee, labels and related issues or duplicates.
- Cycles: 1 to 8 weeks, up to 15 future cycles auto-created, rollover of unfinished issues, optional cooldown, progress graph with historical snapshots.
- Projects, custom views, initiatives, insights, inbox (doc pages exist; details Open).
