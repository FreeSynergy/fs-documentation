# Linear - API

GraphQL API covering all entities, changes visible in real time. API keys (personal or workspace, with scopes such as read, write, admin, create issues, create comments, optionally limited to teams) and OAuth applications. Webhooks for issues, comments, attachments, documents, reactions, projects, project updates, cycles, labels, users and SLAs; payload includes the object and previous values; admin permission needed. Rate limits: Open (not stated on the page).
