# Linear

> Category: [tasks](../../index.md) · Type: issue tracker / product planning · Vendor: Linear Orbit, Inc. · Licence: proprietary

## What it is
Linear is a team issue tracker built for speed: keyboard-driven, with cycles (time-boxed iterations), projects, initiatives and a triage inbox.

## Notable ideas
Why this program is documented here (ADR 0013). Function analysis only, own wording.

- Triage: a dedicated inbox for issues from integrations or from people outside the team; a person accepts, declines, marks as duplicate or snoozes before work enters the flow.
- Cycles: repeating time-boxed iterations, auto-created, unfinished work rolls over, optional cooldown, saved progress graph.
- Speed: single-key actions and a command menu; real-time sync of API changes to all clients.
