# Jira - Menu items

## Global sidebar

| Menu | Content |
|------|---------|
| Your apps (⌘) | Jira Software, service management, Confluence… |
| Projects | Project list, create a project |
| Filters | Your filters, favourites, "all" (issue navigator) |
| Dashboards | Board dashboards, gadget builder |
| Settings (⚙, admin) | Issues (types, statuses, screens, fields), users/groups, apps, system, product permissions |

## Project pages (left)

| Menu | Content |
|------|---------|
| Boards (kanban/scrum) | The active board, reports tab |
| Backlog | Plan, start/complete sprints (scrum) |
| Issues | Full-text view with a filter |
| Reports | Velocity, burn-up, control chart, created vs. resolved |
| Project settings | Details, people, integrations, workflows/screens (admin/project rights) |

## Issue actions (top/⋯)

Transitions (transition buttons per workflow), assign, priority, labels, epics/components, links (blocks, relates), attachments, comments, "more…" (move, delete, watch)

## Menus by role

| Role | View |
|------|------|
| Project admin | Project settings |
| Developer/member | Issues, boards, backlog |
| Viewer (read plan) | View/comment only per permission |
| Jira admin | The global ⚙ menu (instance) |
