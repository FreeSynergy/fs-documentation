# Things 3 - Description

## What the program does

Things 3 organises work in Areas (long-lived responsibilities), Projects (finite goals with headings) and loose to-dos. A day is planned by moving items into Today, This Evening or Someday; repeating and dated items surface in Upcoming.

## Who it suits

Things 3 is a personal to-do app for Mac, iPhone, iPad, Apple Watch and Vision Pro, built around a small set of fixed lists and a calm, fast capture flow.
