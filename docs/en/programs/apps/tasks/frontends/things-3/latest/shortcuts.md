# Things 3 — Shortcuts

> [Things 3](../index.md) · [features](features.md) · [menus](menus.md)

Source: official support article, keyboard shortcuts of Things for Mac, https://culturedcode.com/things/support/articles/2785159/ (retrieved 2026-11-14). **Platform: Mac.** The page lists Mac shortcuts only; shortcuts for Windows or the web are `[nicht belegt]` (Things 3 has no Windows or web app, per the vendor's features page). iPhone, iPad and Vision shortcuts are on a separate vendor page, https://culturedcode.com/things/support/articles/2939808/, `[nicht belegt]` here (not read in this pass). Function names are the vendor's names; the table is a list of facts, no help text copied (ADR 0013). `Cmd` = Command, `Opt` = Option, `Ctrl` = Control.

Reading note: the page was read through a summarising fetch; every row was then compared with the raw page text by a reviewer, no deviation found (BERICHT.md).

## Create items

| Shortcut (Mac) | Function |
|----------------|----------|
| `Cmd+N` | New to-do |
| `Space` | New to-do below selection |
| `Cmd+V` | New to-dos from clipboard |
| `Shift+Cmd+C` | New checklist in open to-do |
| `Opt+Cmd+N` | New project |
| `Shift+Cmd+N` | New heading |
| `Opt+Shift+Cmd+N` | New heading with selection |
| `Ctrl+Space` | Open Quick Entry |
| `Ctrl+Opt+Space` | Open Quick Entry with Autofill |

## Open in a new window (Mac)

Several clicks and keys open lists, projects, areas or Things links in a new window; the exact pairing of key to target is `[nicht belegt]` beyond: `Cmd+Return` or `Cmd`+click (Quick Find result list), `Cmd+Return` or `Cmd`+double click (project or area), `Cmd`+click on a heading, `Opt`+New Window (same list in a new window), `Cmd`+click on a Things link. (Source as above.)
