# Things 3 - Features

## Main features

- Lists: Inbox, Today, This Evening, Upcoming, Anytime, Someday, Logbook.
- Areas, projects, headings inside projects, tags, notes, checklists, deadlines.
- Time-based reminders; dates can be typed in plain words (for example a weekday and time) or spoken to Siri.
- Calendar events of chosen calendars shown in Today and Upcoming.
- Repeating to-dos appear in Upcoming.
- Quick Entry popover; Magic Plus button to drop a to-do into a place in a list.
- Quick Find: start typing a name to jump (on Mac also type-to-travel).
- Sync through Things Cloud; reminders are pushed to all devices at once.
- URL scheme with commands such as add, add-project, show; the show command can open Today, Anytime, Someday and others; add accepts a `when` value including evening.

## What it does not do

- Not an open format; no self-hosting; Apple platforms only (per features page).
