Platform: Mac. `[nicht belegt]` = not found on a page read.

Known from earlier: tapping the destination in Quick Entry files the to-do into another list (https://culturedcode.com/things/support/articles/2803582/, 2026-11-10).

**Gap in the sources:** the vendor pages name only a few menu-bar paths. The full menu bar is not listed on any page read; where a command has a shortcut but no named menu, it is listed under the branch *Commands without a documented menu path*, not under a guessed menu.

## Not found

- Context menus of areas, checklists, tags and sidebar lists on the Mac: `[nicht belegt]` (areas page read, no entry listed).
- Menu names for most shortcuts, and the complete items of View > Go To: `[nicht belegt]`.
- Menus named *To-Do*, *Project*, *Area*, *List*, *Tag* in the menu bar: `[nicht belegt]`.
- `Open in New Window` as a context-menu entry of projects and areas is stated for Vision only, not for the Mac.
- Menu paths and shortcuts are joined only where one page states both; the sample check (BERICHT.md) found that four first-pass menu paths (View > Show Sidebar, View > Show Navigation Popover, Window > New Window, File > New Heading with Selection) were not stated by any page read, so they were moved to the branch without a documented path.
