# Todoist - Features

## Main features

- Filter operators: `|` or, `&` and, `!` not, parentheses, `,` for separate lists in one view.
- Filter keywords: today, overdue, no date, no deadline, no time, recurring, priority p1-p4, label, project (with or without sub-projects), section, free-text search, assigned to / assigned by / added by with me and others.
- Wildcard `*` for partial names.
- Built-in Today, Upcoming and Priority views cannot be edited by query.
- Filters can be favourited and reordered.
- Labels are written with `%` in filters; the older `@` form is announced to be retired by the end of 2026 (per the help article).
