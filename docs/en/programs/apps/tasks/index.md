# Tasks

`FreeSynergy.Tasks` (`fs-tasks`) answers one question: **what do I, or we, do next?** Kanban boards, lists and timelines
are different ways of looking at the same tasks.

**Status (2026-11-06): the [core exists](https://github.com/FreeSynergy/fs-tasks), version 0.4.1, no GUI yet; boards are not implemented.** The interface is a draft. See the [overall plan](../roadmap.md).
