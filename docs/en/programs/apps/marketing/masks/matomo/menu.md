# Matomo - Menu items

## Main navigation

| Menu | Content |
|------|---------|
| Dashboard | Configurable widgets (KPI, graphs) |
| Visits | Visitor log (the visitor's actions individually!), geographic, devices |
| Behaviour | Pages, exits, site search, timing |
| Acquisition | Campaign URLs (`mtm` parameters), channels, referrers |
| Goals/e-commerce | Conversions, funnels |
| Maps/reports | Geo maps, custom segments |

## Administration (⚙)

| Area | Content |
|------|---------|
| Websites | Create a property (site ID), domain sharding |
| Users/roles | Viewer/write/admin + 2FA |
| Plugins | Marketplace (HeatmapSessionRecording, Funnels (paid), ContentTracking) |
| Settings | Consent mode, cookieless configuration, deletion periods (data protection by design) |
| Personal | API access (`token_auth` management), tracking code generators |

## Menus by role

Super user (administration/plugins) · write · standard · read; site permissions per website.
