# Matomo Documentation

## Overview

Matomo (GPL, formerly Piwik) is the leading **self-hostable web-analytics platform** (PHP/MySQL): visitor analysis capable of running cookieless, cookies with consent integration, heatmaps/session replay (paid), roles, raw data in your own database. Cloud optional.

## File structure

- [menu.md](menu.md) - Dashboard, visits/behaviour, administration
- [features.md](features.md) - Plugins, raw-data sovereignty, what Matomo does NOT do
- [description.md](description.md) - How it differs from GA4, Plausible, etracker
- [structure.md](structure.md) - Report tables, visitor log, heatmap view
- [shortcuts.md](shortcuts.md) - none
