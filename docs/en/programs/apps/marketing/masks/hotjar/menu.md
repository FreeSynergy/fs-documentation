# Hotjar - Menu items

## Main area (site dashboard)

| Menu | Content |
|------|---------|
| Heatmaps | Create a click/move/scroll heatmap per URL pattern |
| Recordings | Session replay list (filters: device, goal, duration), rage-click markers |
| Surveys | Onsite questions (popup/inline), targeting |
| Feedback | Feedback surveys ("how satisfied…"), notes board |
| Funnel analytics | Heatmap funnel (plan dependency) |
| Recording settings | Sampling rate, exclusions (URLs/CSS classes), masks for personal content |

## Account management

| Area | Content |
|------|---------|
| Teams/members | Roles (admin/editor/viewer) |
| Tracking | Hotjar tag via GTM, Identify (`userId`) |
| Data protection | Consent linkage (cookie/consent coupling), EU infrastructure choice |

## Menus by role

Admin/editor/viewer per site; API keys per team.
