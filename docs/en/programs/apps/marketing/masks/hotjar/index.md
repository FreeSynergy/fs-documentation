# Hotjar Documentation

## Overview

Hotjar (commercial) supplements web analytics with the **how**: heatmaps (clicks/scrolls/moves), session replays, surveys (onsite surveys), feedback/rage-click detection and funnel coupling. Script-based, EU data-residency option.

## File structure

- [menu.md](menu.md) - Heatmaps/replays/surveys, recording rules
- [features.md](features.md) - Heatmap types, surveys, what Hotjar does NOT do
- [description.md](description.md) - How it differs from Matomo plugins, FullStory, Microsoft Clarity
- [structure.md](structure.md) - Heatmap overlay, replay player, survey editors
- [shortcuts.md](shortcuts.md) - none
- [api.md](api.md) - REST (recordings/surveys), Identify API, no open heatmap export API
