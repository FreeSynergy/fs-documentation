# Hotjar - Keyboard shortcuts

## Overview

Hotjar documents **no shortkeys**.

> State: 2026.

## Present

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Editors (survey/heatmap targets) |
| `Esc` | Close previews |
| `Ctrl/Cmd+F` | Recording lists (browser) |

## Explicitly not present

- Palette, replay player keys (the player uses its own buttons)

## Mac

`Cmd` for browser standards.
