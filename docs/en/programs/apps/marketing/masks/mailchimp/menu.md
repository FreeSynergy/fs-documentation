# Mailchimp - Menu items

## Main navigation (left)

| Menu | Content |
|------|---------|
| Dashboard | Campaign overview, growth tips |
| Campaigns | Campaigns, templates, A/B tests |
| Audience → all contacts | Contacts, tags, segments, fields, import/export (CSV) |
| Automations (customer journeys) | Build journeys (trigger → emails/actions), e-commerce flows |
| Content studio | Templates, landing pages, popups, forms |
| Analytics/reports | Opens/clicks, e-commerce conversion, heatmap (add-on) |
| Integrations | App connections, **API keys** (extras → API keys) |

## Audience sub-menus

| Area | Content |
|------|---------|
| Segments | Rules ("opened last 30d AND tag=spende") |
| Tags/fields | Custom fields (merge fields) |
| Settings | Double opt-in, sender, GDPR options (per region) |

## Menus by role

Owner/admin/manager/employee/contributor — API access follows the account rights.
