# Mailchimp Documentation

## Overview

Mailchimp (Intuit, commercial) is the newsletter/marketing-automation platform: lists + segments, campaign editor, e-mail automations (journeys), landing pages, CRM-lite and analytics. API v3 with OAuth2.

## File structure

- [menu.md](menu.md) - Audience/campaign/automation menus
- [features.md](features.md) - Journeys, segments, what Mailchimp does NOT do
- [description.md](description.md) - How it differs from Brevo, Mautic, benchmark EU tools
- [structure.md](structure.md) - Dashboard, list workspace, journey builder
- [shortcuts.md](shortcuts.md) - Shortcuts (none)
- [api.md](api.md) - REST v3 (members, campaigns, reports), OAuth2, webhooks
