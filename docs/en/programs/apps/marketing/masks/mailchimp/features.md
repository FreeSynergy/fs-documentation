# Mailchimp - Features

## Main features

- **Contact management** with tags, custom fields, segments, profiles (e-commerce history)
- **Campaign editor** (drag blocks, templates, A/B tests, send optimisation)
- **Customer journeys**: trigger events (signup, purchase, cart abandonment) → automated sequences
- Landing pages/forms/popups, social posts, simple websites
- **Reports**: opens/clicks/maps, conversions; add-ons: heatmaps, retargeting ads

## What Mailchimp does NOT do

- **GDPR difficulties** (US cloud; order processing is possible, but review the data flows critically — the EU alternatives Mautic/Brevo)
- Prices rise with the contact count (quotas, nothing "unlimited")
- **No self-hosting option**
- Limited CRM depth (deals only light; pipeline features rudimentary)
- Transactional emails (SMTP API) only in higher plans
