# Mautic - Keyboard shortcuts

## Overview

Mautic documents **no shortkeys**.

> State: Mautic 5.x.

## Present

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Forms/canvas dialogs |
| `Esc` | Close modals |
| `Ctrl/Cmd+F` | Contact/campaign lists (browser) |

## Explicitly not present

- Palette, canvas key shortcuts

## Mac

`Cmd` for browser standards.
