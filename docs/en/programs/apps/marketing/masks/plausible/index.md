# Plausible Documentation

## Overview

Plausible (MIT/AGPL dual depending on edition) is minimalist web analytics: one script, one numbers view, cookieless and GDPR-friendly, self-hosted or cloud. Goal: "understand traffic without hoarding data".

## File structure

- [menu.md](menu.md) - Stats dashboard, filters, settings
- [features.md](features.md) - Events/goals, stats API, what Plausible does NOT do
- [description.md](description.md) - How it differs from Matomo, GA4, GoatCounter
- [structure.md](structure.md) - One-page dashboard with time series + sources
- [shortcuts.md](shortcuts.md) - none
- [api.md](api.md) - Events API (`/api/event`), stats API (filterable), imports
