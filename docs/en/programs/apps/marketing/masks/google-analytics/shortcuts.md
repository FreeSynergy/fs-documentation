# Google Analytics - Keyboard shortcuts

## Overview

Google Analytics has **no documented shortkeys**.

> State: 2026.

## Present

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Report forms |
| `Ctrl/Cmd+F` | Browser search on tables |
| `Esc` | Close dropdowns |

## Explicitly not present

- A Google suite palette (`Cmd+K` exists in Docs, not in GA)

## Mac

`Cmd` for browser standards.
