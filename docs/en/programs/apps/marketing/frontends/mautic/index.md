# Mautic Documentation

## Overview

Mautic (GPL, PHP/Symfony) is open-source marketing automation: contacts + segments, e-mail campaigns, **campaign tree** (triggers/actions), landing pages/forms, point scoring — self-hosted with full data sovereignty (an alternative to Mailchimp/Brevo).

## File structure

- [menu.md](latest/menus.md) - Contacts/campaigns/e-mails, configuration
- [features.md](latest/features.md) - Segments, campaigns, point scoring, what Mautic does NOT do
- [description.md](latest/description.md) - How it differs from Mailchimp, Brevo, Odoo marketing
- [structure.md](latest/layout.md) - Contact record, campaign canvas
- [shortcuts.md](latest/shortcuts.md) - none
- [api.md](latest/api.md) - REST `/api/…` (contacts, segments, campaigns), OAuth2/Basic, webhooks
