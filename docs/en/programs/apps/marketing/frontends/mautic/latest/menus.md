# Mautic - Menu items

## Main menu

| Menu | Content |
|------|---------|
| Dashboard | Widgets (campaign statistics) |
| Contacts | List, segments, import (CSV), custom fields, an activity feed per contact |
| Campaigns | Tree builder: trigger → conditions/actions (email, tag, wait, point change) |
| Emails | Segments (newsletters), templates, A/B, sender profiles |
| Forms/landing pages | Builder + embedding (JS embed), double opt-in |
| Reports | Campaign/email open/click reports |
| Assets/points | Downloads, the point-leading rule catalogue |

## Configuration (⚙)

| Area | Content |
|------|---------|
| Email settings | SMTP/transport, tracking domain (CNAME!) |
| Webhooks | Events → target URLs (contact created/changed…) |
| API access | OAuth2 clients, Basic auth switch |
| Points/fields | Custom fields (frontend mapping!), point rules |
| Security/GDPR | Mandatory double opt-in, deletion workflows (GDPR tools) |

## Menus by role

Permission vectors (view/create/edit/delete/full) per object type; admin globally.
