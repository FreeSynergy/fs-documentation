# Umami - Description

## What the program does
Site owners add one script and read traffic and behaviour in a dashboard. Custom events record actions beyond page views.

## Advantages
- No cookies, no cross-site tracking, no automatic personal data collection (docs).
- MIT licence, self-hostable.
- Reports beyond page counts: funnels, retention, journeys.

## Differentiation
| System | Difference |
|--------|------------|
| Plausible | One simple view; Umami offers more report types for product analytics. |
| Matomo | Larger feature set (heatmaps and more); Umami is lighter. |

## Technical details
Node.js with Next.js and TypeScript; Prisma; PostgreSQL 12.14 or later; Docker, Compose, Podman (README ✅). Optional two-factor authentication.
