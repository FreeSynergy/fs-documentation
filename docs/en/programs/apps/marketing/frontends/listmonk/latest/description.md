# Listmonk - Description

## What the program does
It manages subscribers and lists, builds campaigns from templates, sends them and processes bounces.

## Advantages
- High performance as a standalone binary (docs wording).
- AGPL-3.0, self-hosted.
- Roles, permissions and OIDC sign-in.

## Differentiation
| System | Difference |
|--------|------------|
| Mautic | Full marketing automation with campaign trees; Listmonk is newsletters and lists only. |
| Mailchimp | Hosted commercial service with audiences and automations; Listmonk is self-hosted. |

## Technical details
Go backend, Vue with Buefy frontend, PostgreSQL (docs ✅). Hardware needs: Open.
