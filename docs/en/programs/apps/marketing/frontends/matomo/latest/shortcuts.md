# Matomo - Keyboard shortcuts

## Overview

Matomo documents **no shortkeys**.

> State: Matomo 5.x.

## Present

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Date/segment pickers |
| `Esc` | Close calendars/dropdowns |
| `Ctrl/Cmd+F` | Browsing reports (browser) |

## Explicitly not present

- Palette/jump search

## Mac

`Cmd` for browser standards.
