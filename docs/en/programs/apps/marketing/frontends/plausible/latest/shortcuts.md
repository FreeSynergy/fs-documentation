# Plausible - Keyboard shortcuts

## Overview

Plausible has **no documented shortkeys**; the dashboard is click-based.

> State: 2026.

## Present

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Period/filter pickers |
| `Esc` | Close dropdowns |
| `Ctrl/Cmd+F` | Browser search |

## Explicitly not present

- Palette, date commands

## Mac

`Cmd` for browser standards.
