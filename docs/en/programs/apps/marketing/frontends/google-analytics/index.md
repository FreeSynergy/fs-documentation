# Google Analytics Documentation

## Overview

Google Analytics (GA4, commercial) is the standard workhorse of web/app analytics: event-based measurement (events + parameters), audiences, funnels, attribution — linked with Google Ads/Search Console. Measurement via gtag.js/Tag Manager; APIs: Data API v4, Analytics 360 etc.
