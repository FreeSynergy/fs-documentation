# Hotjar - Description

## What the program does

Hotjar shows how people use pages: where they click, where they drop off, why they rage (rage clicks). It answers usability questions that number systems do not see.

## Advantages

- Immediately intuitive visual feedback (team sharing!)
- Rage/dead-click analyses as an early-warning system for UX that works for free
- Surveys without dev effort

## Differentiation

| System | Difference |
|--------|------------|
| **Microsoft Clarity** | Replays/heatmaps free of charge (Microsoft's data storage) |
| **Matomo plugins** | Everything in one self-hosted environment (premium plugins) |
| **FullStory/LogRocket** | Enterprise session intelligence |

## Technical details

- **Model**: SaaS (EU data-storage option), script + GTM
- **Authentication**: email/SSO (higher plans), API token
- **Data protection**: masking on by default; a consent link is required (cookie category)

## Who it suits

- Product/web teams with an optimisation roadmap
- FreeSynergy scenarios: usability feedback loops to frontend interfaces (observe compliance)
