# Mailchimp - Keyboard shortcuts

## Overview

Mailchimp documents **no shortkeys**; wizards and buttons guide you.

> State: 2026.

## Present

| Shortcut | Function |
|----------|----------|
| `Tab`/`Enter` | Form blocks (editor) |
| `Esc` | Close modals/previews |
| `Ctrl/Cmd+F` | Contact/report lists (browser) |

## Explicitly not present

- Palette, editor shortkeys (copying works like a word processor without special commands)

## Mac

`Cmd` for browser standards.
