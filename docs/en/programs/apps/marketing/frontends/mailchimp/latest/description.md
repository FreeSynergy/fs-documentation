# Mailchimp - Description

## What the program does

Mailchimp sends newsletters and accompanies contacts with automations — from the double opt-in to the abandoned-purchase follow-up. The de-facto entry point for email marketing, for years with ever more suite elements (CRM/websites/ads).

## Advantages

- The fastest path to professional campaigns
- The API is solidly documented, webhooks for event chains
- Templates/editor without design skills

## Differentiation

| System | Difference |
|--------|------------|
| **Mautic** | Open source, self-hostable, EU hosting possible |
| **Brevo** | An EU provider (FR), a similar scope, cheaper when scaling |
| **Sendinblue/Benchmark** | The name per market — compare by data protection |

## Technical details

- **Model**: SaaS (Intuit); API: OAuth2 + API key (the dc identifier in the endpoint!)
- **Pricing**: contact tiers + send volumes
- **Compliance**: DPA with EU standard clauses; a US provider → document who checks what

## Who it suits

- Teams with tolerable US data storage and a focus on campaign pace
- FreeSynergy skins: the member/tag model as a reference for the [contact/segment fields](../../../../../../data/fields.md)
