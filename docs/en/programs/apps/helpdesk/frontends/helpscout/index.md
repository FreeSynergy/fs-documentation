# Help Scout Documentation

## Overview

Help Scout is support as a shared inbox: customers write to an e-mail address ("Conversations"), the team replies as if from a personal mail — without the ticket-number feel. Plus the Beacon widget, knowledge-base docs, light-CRM fields and a REST API.
