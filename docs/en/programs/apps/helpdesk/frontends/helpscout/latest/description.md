# Help Scout - Description

## What the program does

Help Scout handles support like a team inbox: everyone writes to the same address, but sees personalised conversations with history. It is deliberately "anti-ticketing": support should sound like personal email contact, not like a case number.

## Advantages

- **learned in a flash** — agents do not need to understand a mask
- **price per mailbox user** is manageable, free-seat models
- **Beacon** provides self-service where the customers are

## Differentiation

| System | Difference |
|--------|------------|
| **Zendesk/Freshdesk** | A ticket/workflow machine with full SLA build-out |
| **Front** | A similar shared-inbox model, broader (shared calendars/SMS) |
| **Zammad** | Free code, a real ticket mask, the same mailbox root (email) |

## Technical details

- **Model**: SaaS, company workspace; mailboxes = your own support addresses
- **Authentication**: email + password, Google login, 2FA; API OAuth2 client
- **Plans**: standard/plus/premium; docs/chat partly add-on
- **Data**: US/EU regions selectable

## Who it suits

- Small teams that understand support as "people answering people"
- FreeSynergy frontends that show a mailbox/thread presentation instead of a ticket mask
