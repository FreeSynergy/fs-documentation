# Help Scout - Features

## Main features

### Conversations (inbox)
- Shared mailboxes with a personal reply appearance (no ticket numbers for customers)
- Snooze, assignments, tags, "shared"/"inactive"; chat replies (plan-dependent)
- Saved replies/snippets with variables, "move to" folder logic

### Knowledge base
- Docs: public help centres, private wiki articles, "guides" topic-based
- Beacon widget: form + KB search + chat on your own website

### Light CRM
- Person profiles with history, custom fields, tags
- "Customers" view + API contacts (identity via email)

### Automation and collaboration
- Rules per mailbox, auto-replies, surveys (CSAT), collision detection ("who is already writing?")
- Mobile apps and desktop app

## What Help Scout does NOT do

- **no classic ticket workflows** (status chains/SLA business rules are rudimentary; no OTRS feel)
- **no integrated telephony**
- **no self-hosting**, the API objects remain in the Help Scout cloud
- **no macros in the Zendesk sense** (saved replies = text blocks without an action side)
- **flat reports** compared to enterprise suites

## Extensions and integrations
