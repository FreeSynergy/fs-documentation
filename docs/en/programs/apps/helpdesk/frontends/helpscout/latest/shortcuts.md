# Help Scout - Keyboard shortcuts

## Overview

Help Scout documents a small set of mail shortkeys.

> State: Help Scout app (2026).

## Present

| Shortcut | Function |
|----------|----------|
| `/` | Focus the search |
| `J` / `K` | next/previous conversation |
| `R` | Reply |
| `F` | Forward |
| `N` | Internal note |
| `S` | Snooze |
| `E` | Mark as resolved ("resolve") |
| `A` | Assign |
| `Shift+A` | Assign to yourself |
| `Ctrl/Cmd+Enter` | Send |
| `Esc` | Discard the editor |
| `?` | Shortcuts overlay |

## Explicitly not present

- Ticket number jump, macro keys

## Mac

`Cmd` instead of `Ctrl`, single letters identical.
