# Chatwoot - Features

## Present (docs ✅)
| Area | Function |
|------|----------|
| Channels | Website live chat; e-mail; WhatsApp; Facebook; Instagram; Twitter/X; SMS; Telegram; Line; TikTok; API channel; voice through Twilio |
| Inboxes | One inbox per channel; agents and teams; assignment rules; agent capacity |
| Conversations | Labels, priorities, filters, saved filter folders, canned responses, macros, automation, SLAs, private notes, mentions |
| Customers | Contact profiles with custom attributes, segments, pre-chat forms |
| Calls | Voice from the conversation, logged with recordings; video for website chats |
| Help centre | Multilingual articles on a custom domain |
| Reports | Live overview, CSAT, conversation, bot, SLA, agent, team, label, inbox |
| Productivity | Command bar, keyboard shortcuts |
| Integrations | Slack, Dialogflow, OpenAI, Google Translate, Linear, Shopify, webhooks |
