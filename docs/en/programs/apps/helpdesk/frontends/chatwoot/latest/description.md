# Chatwoot - Description

## What the program does
Support teams answer customers from one inbox, whichever channel the customer used. Conversations get labels, priorities, assignment and notes; customers have profiles with history.

## Advantages
- Many channels in one place, including a website widget.
- Teams, assignment rules (round-robin and others), capacity limits per agent, business hours, SLAs.
- Reports and a help centre in several languages.

## Differentiation
| System | Difference |
|--------|------------|
| Zammad | Ticket-centred; Chatwoot is conversation-centred with live chat first. |
| Help Scout | E-mail-first shared inbox; Chatwoot starts from chat and messengers. |

## Technical details
Backend Ruby on Rails, frontend Vue.js (repository topics ✅); Docker deployment; MIT licence (README footer). An AI assistant (Captain) is credit-based.
