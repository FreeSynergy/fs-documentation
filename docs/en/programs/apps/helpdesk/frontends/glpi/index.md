# GLPI Documentation

## Overview

GLPI is a French-flavoured open-source ITSM: helpdesk tickets plus complete IT asset management (computers, software, contracts, network), reporting that supports projects and budgets. PHP/MySQL, web UI with Markdown articles, REST API, strong plugin ecosystem (GLPI Agent, inventory via FusionInventory/GLPI Agent).
