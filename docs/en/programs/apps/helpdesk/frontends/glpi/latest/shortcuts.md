# GLPI - Keyboard shortcuts

## Overview

GLPI knows **no documented app shortcuts** apart from browser/form standards and the "alt-letter" access keys of individual buttons (access keys in some language versions).

> State: GLPI 10.x/11.x.

## What works

| Shortcut | Function |
|----------|----------|
| `Tab` | Form fields |
| `Enter` | Save/confirm dialog |
| `Esc` | Close popover/search |
| `Ctrl/Cmd+F` | Page browser search |

## Explicitly not present

- no palette / no "goto" dialog
- no key shortcuts for status changes or mass actions
- no "C" for a new ticket (portal button/use of the menu)

## Mac

`Cmd` for browser standards.
