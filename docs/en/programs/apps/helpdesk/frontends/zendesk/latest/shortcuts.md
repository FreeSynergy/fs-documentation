# Zendesk - Keyboard shortcuts

## Overview

Zendesk documents shortkeys for agents; `Ctrl+/` (or `Cmd+/`) opens the official overview.

> State: Zendesk support (Act). Bindings may vary per suite version.

## Ticket list and navigation

| Shortcut | Function |
|----------|----------|
| `C` | New ticket |
| `J` / `K` | next/previous ticket in the list |
| `F` | Focus the search |
| `V` | Switch between views (in some versions) |
| `Ctrl/Cmd+/` | Shortcuts overlay |

## In the ticket

| Shortcut | Function |
|----------|----------|
| `R` | Public reply |
| `N` | Internal note |
| `E` | Focus the ticket properties (status/priority…) |
| `Esc` | Discard the reply |
| `Ctrl/Cmd+Enter` | Send the reply |

## Not documented / not present

| Assumed | Status |
|---------|--------|
| Vim palette | ❌ |
| Global hotkey without page focus | ❌ |

## Mac

`Cmd` instead of `Ctrl`; single-letter keys the same.
