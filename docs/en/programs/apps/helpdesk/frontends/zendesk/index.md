# Zendesk Documentation

## Overview

Zendesk is the commercial support platform (SaaS) with tickets, Help Center, chat/messaging, voice and analytics. Frontend-relevant are the very complete **REST API v2** (JSON, token/OAuth), webhooks and the app/widget ecosystem.

## File structure

- [menus.md](latest/menus.md) - Admin/agent navigation, ticket actions
- [features.md](latest/features.md) - Views, triggers/automations, Help Center, what Zendesk does NOT do
- [description.md](latest/description.md) - How it differs from Freshdesk, Zammad, Intercom
- [layout.md](latest/layout.md) - Ticket sidedness, sidebar widgets, app panel
- [shortcuts.md](latest/shortcuts.md) - documented agent shortcuts
- [api.md](latest/api.md) - REST v2, OAuth/token, webhooks, rate limits
