# Helodesk

> Category: [helpdesk](../../index.md)

## What it is

Helodesk is a French SaaS customer-service suite (contact centre): telephony/softphone, e-mail, chat, SMS and callback in one surface, plus cases (tickets), knowledge base, IVR and reporting. REST API with token auth and webhooks. For FreeSynergy, Helodesk is the frontend case "call centre + tickets from a single surface".
