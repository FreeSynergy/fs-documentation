# Helodesk - Description

## What the program does

Helodesk bundles telephony and written support in a single interface: agents carry a softphone in the browser, calls, emails, chats and SMS become cases with a shared history. Administration covers numbers, IVR, routes and SLAs — an "all-in-one" contact centre from France.

## Advantages

- **telephony without an extra tool** (no separate Aircall/Freshcaller contract needed)
- **EU data protection** (hosting in France, a GDPR-close provider)
- **one case concept across all channels** — the call log and the mail thread in the same object

## Differentiation

| System | Difference |
|--------|------------|
| **Zendesk** | The ticket world first, telephony (voice) as an add-on; Helodesk is phone-first |
| **Freshdesk + Freshcaller** | Two fresh products with a seamless bridge — Helodesk is one product |
| **Aircall** | A pure telephony cloud + Zapier; Helodesk brings cases/SLA along |

## Technical details

- **Model**: SaaS (France/EU), browser softphone (WebRTC) + desktop/mobile apps
- **Telephony**: own numbers/DIDs, SIP trunk option, recordings (configurable, legal notices per country)
- **Authentication**: email + password, 2FA; API token
- **Pricing**: packages by users + numbers/minutes, sales runs the subscriptions

## Who it suits

- Small/medium service teams with a high share of calls (real estate, trades, authority hotlines)
- FreeSynergy frontends that want to model a **call-centre case model** (contact + channel + case)
