# Zammad Documentation

## Overview

Zammad is a modern, open-source helpdesk: tickets from e-mail, web form, chat, phone and Telegram converge in one surface, with SLAs, text modules, knowledge base and a fully-fledged REST API. Stack: Ruby on Rails + Elasticsearch (search index), frontend Vue.

## File structure

- [menus.md](latest/menus.md) - Global navigation, admin/manager menus, ticket actions
- [features.md](latest/features.md) - Channels, SLA, knowledge base, what Zammad does NOT do
- [description.md](latest/description.md) - Description and how it differs from osTicket, GLPI and Request Tracker
- [layout.md](latest/layout.md) - Three-column ticket mask, bulk dialogs, themes
- [shortcuts.md](latest/shortcuts.md) - documented Zammad shortcuts (incl. `Ctrl+Shift+K` palette)
- [api.md](latest/api.md) - REST /api/v1, token/OAuth2, webhooks, triggers
