# Zammad

> Category: [helpdesk](../../index.md)

## What it is

Zammad is a modern, open-source helpdesk: tickets from e-mail, web form, chat, phone and Telegram converge in one surface, with SLAs, text modules, knowledge base and a fully-fledged REST API. Stack: Ruby on Rails + Elasticsearch (search index), frontend Vue.
