# Zammad - Keyboard shortcuts

## Overview

Zammad documents a **command palette** and few global keys; further shortcuts are in progress. Unassigned actions remain marked.

> State: Zammad 6.x. Help: the `?` icon or `Ctrl+Shift+K` → "shortcuts".

## Global

| Shortcut | Function |
|----------|----------|
| `Ctrl/Cmd+Shift+K` | **Command palette**: navigation, open a ticket, actions by text |
| `Ctrl/Cmd+F` | Full-text search |
| `?` | Shortkey overview |
| `Esc` | Close overlay/dialog |

## In the ticket mask

| Shortcut | Function |
|----------|----------|
| `Tab` | Controls |
| `Ctrl+Enter` | Send the reply |
| `#` | Insert text blocks |
| `!` | Set the priority in the reply header (version-dependent) |
| `Alt+arrow keys` | previous/next ticket in the filter list |

## Not present (deliberately)

| Assumed | Status |
|---------|--------|
| Vim-like single-key maps | ❌ |
| Global "new ticket" key | ❌ (plus menu or palette) |

## Mac

`Cmd` instead of `Ctrl`, palette: `Cmd+Shift+K`.
