# Zammad - Menu items

## Global navigation (left edge, icons)

| Icon/menu | Description |
|-----------|-------------|
| Dashboard | Personalised tiles (tickets per status, SLA ticker) |
| Tickets | Filtered ticket lists (own, open, shared) |
| Customers & organisations | CRM-like customer profiles, history, links |
| Products | (optional) product/contract management |
| Calendars | Service appointments/holiday times for SLA calculation |
| Knowledge base | Article editor and publication |
| Reports | Predefined and custom evaluations |
| Online chat | Chat transcripts |

## Plus menu (top right)

- New ticket, new task, new customer, new chat

## User menu (avatar)

Profile, absence, notifications, theme, language, enter the admin area (with the right)

## Admin menus (⚙)

| Menu | Content |
|------|---------|
| Channels | Email (fetch/push), web form, telephone (CTI), Telegram, chat, Jira/synchronisations |
| Tickets | Status, status types, SLA, texts (text blocks), tags, article types |
| Calendars & times | Working hours, public holidays, absences |
| Systems | Roles, organisations, users, LDAP/SSO (OIDC/SAML), webhooks, triggers, schedulers, backups, store apps |
| Knowledge base | Administration/publication settings |

## Manager/agent ticket menu (⋮ in the ticket)

Set owner, change group, priority, state (open/pending…/closed), tags, share link, print, delete, merge, follow-up, splitting

## Menus by role

| Role | Visible |
|------|---------|
| Agent | Tickets, customers, own dashboards |
| Manager | + Reports, knowledge administration, team administration |
| Admin | + the complete ⚙ area |
| Customer (portal) | Their own customer portal: own tickets, knowledge base (public) |
