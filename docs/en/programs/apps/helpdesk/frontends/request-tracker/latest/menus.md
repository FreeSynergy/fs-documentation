# Request Tracker - Menu items

## Main menu bar (classic web UI)

| Menu | Entries |
|------|---------|
| **Create Ticket** | Create a ticket in the current queue |
| **New Search** | Query builder: queue/status/owner/custom fields |
| **Saved Searches** | Private + public saved searches (sidebar) |
| **Logs** | Transactions of all tickets (admin) |
| **Tools** | User preferences, dashboard, charts |
| **Admin** | Global configuration, queues, users/groups/rights, scrips, custom fields, sessions, Article/article actions (article module) |

## Ticket pages (update page)

- **Reply** (to the requestor), **Correspond** (to all participants), **Comment** (internal)
- Actions without right-click: status (new/open/stalled/resolved/rejected), owner, queue (move), CC/BCC, time worked
- Attachments at the bottom, history block per page

## Sidebar (left)

- Personal saved searches ("my tickets", "overdue …")
- Dashboards per queue/role

## Menus by role

| Role | Effect |
|------|--------|
| Everyone/anonymous | Their own tickets via email key |
| Requestor | View/reply to their own tickets |
| Owner (queue rights) | The update page of their queues |
| SuperUser | Admin menu in full |
