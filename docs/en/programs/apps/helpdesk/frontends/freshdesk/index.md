# Freshdesk Documentation

## Overview

Freshdesk (Freshworks) is a SaaS helpdesk with tickets, knowledge base, SLAs, omnichannel e-mail/phone/chat and Freddy AI. REST API (JSON), webhooks and marketplace apps; self-service portal included.

## File structure

- [menus.md](latest/menus.md) - Navigation, ticket actions, admin
- [features.md](latest/features.md) - Automations, SLA, Freddy, what Freshdesk does NOT do
- [description.md](latest/description.md) - How it differs from Zendesk, Zammad, Help Scout
- [layout.md](latest/layout.md) - Ticket mask, Growth UI
- [shortcuts.md](latest/shortcuts.md) - Shortcuts (few, but real ones)
- [api.md](latest/api.md) - REST /api/v2, API key/OAuth, webhooks, rate limits
