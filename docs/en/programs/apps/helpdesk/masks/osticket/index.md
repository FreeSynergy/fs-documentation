# osTicket Documentation

## Overview

osTicket is the classic among open-source helpdesks: PHP/MySQL, e-mail ingest, help topics, filter rules and a plain agent and customer portal. No bells and whistles, but proven for decades and easy to host.

## File structure

- [menu.md](menu.md) - Agent and admin menus, ticket actions
- [features.md](features.md) - Filters, help topics, SLA, what osTicket does NOT do
- [description.md](description.md) - Description and how it differs from Zammad, RT and GLPI
- [structure.md](structure.md) - Table masks, ticket view, e-mail workflow
- [shortcuts.md](shortcuts.md) - Shortcuts (practically none; web standards)
- [api.md](api.md) - API v1 (tickets, users) with API key, e-mail subject control
