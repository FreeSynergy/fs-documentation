# osTicket - Keyboard shortcuts

## Overview

osTicket has **no documented shortkeys**. Operation is via clicks and form standards.

> State: osTicket 1.17/1.18.

## What works

| Shortcut | Function |
|----------|----------|
| `Tab` / `Shift+Tab` | Form fields |
| `Enter` | Confirm dialogs (in the editor: new line) |
| `Esc` | Close dialogs |
| `Ctrl/Cmd+Enter` | (not documented — sending remains a button) |
| `Ctrl+F` | Browser search on the ticket page |

## Explicitly not present

- no palette, no single-key actions
- no shortcuts for status changes (actions menu)

## Mac

`Cmd` replaces `Ctrl` for browser standards.
