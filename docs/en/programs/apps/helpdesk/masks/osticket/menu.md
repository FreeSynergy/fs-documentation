# osTicket - Menu items

## Agent navigation (top)

| Menu | Content |
|------|---------|
| Dashboard | Ticket tiles by status/age/SLA |
| Tickets | Filtered lists (mine, open, overdue, all) |
| Customers | Customer/organisation search and profiles |
| Knowledge base | FAQ articles, topics |
| Files | Upload library |

## Ticket view (tabs and actions)

- Tabs: **General**, **history (log)**, **notes**, **attachments**
- Actions menu (⋮): answer, forward, note, merge, share, lock, delete, set status (new/open/pending/closed), assign, priority, help topic, manual SLA

## Admin menus (admin tab)

| Menu | Content |
|------|---------|
| Tickets | Settings, priorities, SLA plans, help topics, ticket status |
| Email | Mail fetching, auto-respond, filter rules (incoming + outgoing) |
| Customers | Fields (forms), organisations, customer portals, passwords |
| Team/roles/staff | Teams, roles, staff, groups |
| Knowledge | Article categories, templates (email templates) |
| Files | Upload limits, virus-scan options |

## Customer portal

- List/create tickets, reply, read articles, password reset
- No menus per role beyond "customer" (login-based only)

## Menus by role

| Role | Menu |
|------|------|
| Administrator | Admin tab in full |
| Agent | Group tickets assigned to them, no admin menus |
| Customer | Portal, only their own tickets |
