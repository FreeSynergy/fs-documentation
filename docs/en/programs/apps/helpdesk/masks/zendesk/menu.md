# Zendesk - Menu items

## Agent navigation (left column)

| Menu | Content |
|------|---------|
| Views | Predefined ticket sets ("my unsolved…") |
| Tickets | Own/shared/all tickets |
| Users | End-user profiles |
| Organization | Company accounts |
| Forums/help centre | Articles, categories (per plan) |
| Reporting | Dashboards, Explore |
| Apps | App panel on the right of the ticket page |

## Ticket page

- Action bar: **Resolve / Pending / Hold**, brand, group, assignee, priority, tags, SLA badge
- Conversation: public reply / internal note / comment
- Sidebar: custom fields, context (user history), apps

## Admin centre (⚙)

| Area | Content |
|------|---------|
| Business rules | **Triggers** (real-time), **automations** (time-based), schedulable automations, macros, SLAs |
| Objects | Ticket types, custom object types (Sunshine), tags |
| Users/orgs | Roles, groups, business rules access |
| Channels | Email, chat/messaging, voice, social |
| Apps and integrations | Marketplace, API token, webhooks, OAuth clients |
| Help centre | Theme, localisation, workflow |
| Security | SSO (SAML/OIDC), 2FA, hosting endpoints |

## Menus by role

| Role | View |
|------|------|
| End-user (client portal) | Their own requests + help centre |
| Agent | Views/tickets, macros |
| Team lead | + report filters for the group |
| Admin | Admin centre in full |
