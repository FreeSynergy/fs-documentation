# Zendesk Documentation

## Overview

Zendesk is the commercial support platform (SaaS) with tickets, Help Center, chat/messaging, voice and analytics. Skin-relevant are the very complete **REST API v2** (JSON, token/OAuth), webhooks and the app/widget ecosystem.

## File structure

- [menu.md](menu.md) - Admin/agent navigation, ticket actions
- [features.md](features.md) - Views, triggers/automations, Help Center, what Zendesk does NOT do
- [description.md](description.md) - How it differs from Freshdesk, Zammad, Intercom
- [structure.md](structure.md) - Ticket sidedness, sidebar widgets, app panel
- [shortcuts.md](shortcuts.md) - documented agent shortcuts
- [api.md](api.md) - REST v2, OAuth/token, webhooks, rate limits
