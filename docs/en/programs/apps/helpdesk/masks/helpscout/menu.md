# Help Scout - Menu items

## Main navigation

| Menu | Content |
|------|---------|
| Conversations | Inbox view per mailbox (folders: needs to respond, active, everyone, closed) |
| Reports | Response times, volume, agents |
| Docs / knowledge base | Public and private articles (help centre + "guides") |
| Customers | Person profile: history, fields, tags |
| Settings | Mailboxes, users/teams, auto-signature, saved replies, rules, beacons, integrations, API |

## Conversation view

- Actions: **reply / forward / note**, status (active/pending/inactive), assignee, tags, "delete spam"
- On the right: person card (custom fields, previous conversations), snippets

## Automations (settings → rules)

- Rules per mailbox: case handling (tags, assignment, auto-reply "out of office", snooze, assign to first responder)
- Workflows: chat/escalations (plan-dependent)

## Menus by role

| Role | View |
|------|------|
| Admin | Settings in full |
| Agent (full) | Conversations + replies |
| Restricted/light | Assigned mailboxes, read/reply only |
| Customer | Only their own beacon forms/docs |
