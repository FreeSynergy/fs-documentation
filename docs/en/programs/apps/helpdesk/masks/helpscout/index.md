# Help Scout Documentation

## Overview

Help Scout is support as a shared inbox: customers write to an e-mail address ("Conversations"), the team replies as if from a personal mail — without the ticket-number feel. Plus the Beacon widget, knowledge-base docs, light-CRM fields and a REST API.

## File structure

- [menu.md](menu.md) - Conversations, folders, docs, admin
- [features.md](features.md) - Mailbox model, saved replies, automations, what it does NOT do
- [description.md](description.md) - How it differs from Zendesk/Freshdesk/Front
- [structure.md](structure.md) - Three-column inbox
- [shortcuts.md](shortcuts.md) - Mail-typical shortcuts
- [api.md](api.md) - REST v2, OAuth2, webhooks
