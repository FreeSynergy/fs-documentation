# Helodesk - Menu items

## Main navigation

| Menu | Content |
|------|---------|
| Contact centre | Dialler, call history, queues, IVR blind transfer, callback queues |
| Cases | Ticket lists by status/queue, own cases, due-date filters |
| Contacts | Contact profiles with channel context (numbers, emails, history) |
| Knowledge base | Internal and customer articles |
| Reports | Call statistics, case SLA, agent load |
| Administration | Users/roles, numbers and SIP, mailboxes/domain, IVR designer, forms/custom fields, webhooks/API, tariffs |

## Case mask

- Actions: status (new/open/pending/closed), assignment, priority, tags, channel origin (call/email/chat/SMS)
- Communication block: call log, email history, chat transcript, note
- "Screen pop": on an incoming call the contact + case template opens

## Administration

| Area | Content |
|------|---------|
| Numbers | DID phone numbers, SIP trunk, routing, IVR tree (drag-and-drop editor) |
| Channels | Mailbox ingest, chat/callback widget (embed script), SMS sender |
| Workflows | Escalations, automatic assignment by skills |
| API | API token, webhook endpoints, app integrations |

## Menus by role

| Role | View |
|------|------|
| Agent | Own cases + softphone |
| Supervisor | Queues, reports, assignment |
| Admin | Administration in full |
