# Helodesk - Features

## Main features

### Contact centre (telephony integrated)
- Web softphone with click-to-dial, warm/cold transfer, conference, recording (plan-/law-dependent)
- Queues with announcements, IVR designer (trees, skills, times), callback appointments
- Number management (DIDs), SIP trunk connection, call analysis per agent/queue

### Cases (tickets)
- Cross-channel cases: call → case with log, email reply, chat, SMS
- SLA/business hours, escalation rules, assignment by skills/round-robin
- Custom fields and forms per case type

### Contacts and knowledge
- Contact profile with all channel contacts (phone, mail, chat)
- Knowledge articles (internal + customer portal), reply templates

### Web widgets
- Chat widget, callback button, contact forms (embed script on your own website)

## What Helodesk does NOT do

- **no self-hosting** (SaaS, hosting in France/EU — a data-protection advantage, but no instance of your own)
- **no own database system/BI**; reports limited to the supplied measures
- **API coverage is patchy**: contacts/cases yes, telephony configuration only partly automatable
- **no marketplace breadth** like Zendesk/Freshdesk (integrations via connectors/Zapier)
- **no public price list without sales** (number/tariff bundles)

## Extensions and integrations

| Integration | Method |
