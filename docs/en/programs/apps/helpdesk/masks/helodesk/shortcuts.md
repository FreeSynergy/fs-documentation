# Helodesk - Keyboard shortcuts

## Overview

Helodesk documents **no comprehensive shortcut list**. What is useful is softphone and form standard behaviour.

> State: Helodesk web app (2026). Individual key bindings may change.

## Present

| Shortcut | Function |
|----------|----------|
| Digits in the softphone | DTMF/number entry |
| `Enter` | Forms, search field |
| `Tab` | Fields |
| `Esc` | Close dialogs |
| `Ctrl/Cmd+F` | Browser search in the case history |

## Explicitly not present

- no palette, no single-letter case actions (status only via dropdown)
- no documented global "answer/hang up" key (softphone buttons; headset signals work via WebRTC devices)

## Mac

`Cmd` for browser standards.
