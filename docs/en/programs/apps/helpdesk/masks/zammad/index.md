# Zammad Documentation

## Overview

Zammad is a modern, open-source helpdesk: tickets from e-mail, web form, chat, phone and Telegram converge in one surface, with SLAs, text modules, knowledge base and a fully-fledged REST API. Stack: Ruby on Rails + Elasticsearch (search index), frontend Vue.

## File structure

- [menu.md](menu.md) - Global navigation, admin/manager menus, ticket actions
- [features.md](features.md) - Channels, SLA, knowledge base, what Zammad does NOT do
- [description.md](description.md) - Description and how it differs from osTicket, GLPI and Request Tracker
- [structure.md](structure.md) - Three-column ticket mask, bulk dialogs, themes
- [shortcuts.md](shortcuts.md) - documented Zammad shortcuts (incl. `Ctrl+Shift+K` palette)
- [api.md](api.md) - REST /api/v1, token/OAuth2, webhooks, triggers
