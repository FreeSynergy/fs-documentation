# Freshdesk - Keyboard shortcuts

## Overview

Freshdesk documents few shortcut keys; the rest is click work.

> State: Freshdesk growth/pro (2026).

## Present

| Shortcut | Function |
|----------|----------|
| `T` then ticket number | Jump to a ticket by ID (in ticket lists) |
| `F` | Focus the filter/search (list) |
| `R` | Reply (in the open ticket) |
| `Shift+R` | Reply all |
| `N` | Private note |
| `Ctrl/Cmd+Enter` | Send the reply |
| `Esc` | Close the editor |
| `J`/`K` | Page down/up through the list (list open) |

## Explicitly not present

- no overlay with all shortcuts (the list is only in the help docs)
- no palette

## Mac

`Cmd` instead of `Ctrl`; letter keys the same.
