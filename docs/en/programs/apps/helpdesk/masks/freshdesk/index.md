# Freshdesk Documentation

## Overview

Freshdesk (Freshworks) is a SaaS helpdesk with tickets, knowledge base, SLAs, omnichannel e-mail/phone/chat and Freddy AI. REST API (JSON), webhooks and marketplace apps; self-service portal included.

## File structure

- [menu.md](menu.md) - Navigation, ticket actions, admin
- [features.md](features.md) - Automations, SLA, Freddy, what Freshdesk does NOT do
- [description.md](description.md) - How it differs from Zendesk, Zammad, Help Scout
- [structure.md](structure.md) - Ticket mask, Growth UI
- [shortcuts.md](shortcuts.md) - Shortcuts (few, but real ones)
- [api.md](api.md) - REST /api/v2, API key/OAuth, webhooks, rate limits
