# Freshdesk - Menu items

## Agent navigation (left)

| Menu | Content |
|------|---------|
| Home | Work list, favourite views |
| Tickets | All/unresolved/assigned; saved filters |
| Conversations | Asynchronous conversations (newer plans) |
| Contacts | Customers + organisations |
| Products / KB | Knowledge articles |
| Reports | Predefined reports, surveys |
| Apps | Marketplace left/right in the ticket page |

## Ticket page

- Actions: **Reply / Reply All / Private note**, status (open/pending/resolved/closed), priority, source, product, group, owner, tags, due-by (SLA)
- TIME block (timer), attachments, "incoming"/history at the bottom

## Admin (admin tab)

| Area | Content |
|------|---------|
| Helpdesk | Products, business hours, SLA assistant, ticket forms/custom fields |
| Automations | Workflows (triggers + automations + schedulers), Dispatch'r (rules), escalations, assistant |
| Customer portal | Domains, forms, forum, knowledge base |
| Channels | Mailboxes, telephony (Freshcaller), chat (Freshchat), social |
| Users | Agents (full/light/…), roles, SSO (SAML) |
| Integrations | Marketplace, API keys, webhooks, "solution"/Freddy AI |

## Menus by role

| Role | View |
|------|------|
| Customer (portal) | Own tickets + articles |
| Agent | Tickets of their groups |
| Dispatcher/supervisor | + Reports, assignment |
| Admin | Admin tab in full |
