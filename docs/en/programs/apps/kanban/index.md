# Kanban

`FreeSynergy.Kanban` (`fs-kanban`) organises work on boards with columns and cards. A card is the same task object the
calendar shows, so a due date appears there without being copied.

**Status: planned, no code yet (2026-11-06).** See the [roadmap](../roadmap.md).
