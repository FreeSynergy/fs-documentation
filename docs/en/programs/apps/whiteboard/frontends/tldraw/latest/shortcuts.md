# tldraw - Keyboard shortcuts

## Overview

tldraw is extremely shortcut-driven; the keys are officially documented and available in the app via `?` (help dialog).

> As of: tldraw 2.x/3.x (app and SDK use identical assignments).

## Tools

| Shortcut | Tool |
|----------|------|
| `V` | Select |
| `H` | Hand (pan) |
| `S` | Laser pointer |
| `D` | Pen (draw) |
| `E` | Eraser |
| `A` | Arrow |
| `R` | Rectangle |
| `O` | Ellipse |
| `L` | Line |
| `T` | Text |
| `N` | Note |
| `F` | Frame |
| `I` | Image |
| `B` | Bookmark |

## Editing

| Shortcut | Purpose |
|----------|---------|
| `Ctrl/Cmd+C` / `+V` / `+X` | Copy / paste / cut |
| `Ctrl/Cmd+D` | Duplicate |
| `Ctrl/Cmd+A` | Select all |
| `Del` / `Backspace` | Delete selection |
| `Ctrl/Cmd+Z` / `+Shift+Z` | Undo / redo |
| `Ctrl/Cmd+G` / `+Shift+G` | Group / ungroup |
| `Ctrl/Cmd+]` / `+[` | To front / to back |
| `Ctrl/Cmd+L` | Lock/unlock |
| `Arrow keys` | Move the selection by 1 px (`Shift` = 10 px) |

## View

| Shortcut | Purpose |
|----------|---------|
| `Ctrl/Cmd+=` / `+-` | Zoom in/out |
| `Ctrl/Cmd+0` | Reset zoom |
| `Ctrl/Cmd+1` | Zoom to selection |
| `Ctrl/Cmd+Shift+1` | Zoom to all content |
| `Spacebar` + drag | Move the canvas |
| `Ctrl/Cmd+wheel` | Zoom |

## Files

| Shortcut | Purpose |
|----------|---------|
| `Ctrl/Cmd+S` | Save (local-first, there is auto-save anyway) |
| `Ctrl/Cmd+P` | Print |

## Mac

All `Ctrl` combinations with `Cmd`; the letter tool keys are identical.

## Explicitly not available

- No Vim mode
- No "today" or folder navigator — files are opened through the app start screen (respectively your own implementation in the SDK)
