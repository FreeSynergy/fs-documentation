# FigJam - Keyboard Shortcuts

Tool keys from the help page (macOS names):

| Key | Function |
|-----|----------|
| `S` | Sticky note |
| `T` | Text |
| `M` | Marker |
| `Shift+M` | Highlighter |
| `W` | Washi tape |
| `C` | Comment |
| `E` | Stamps |
| `L` | Straight connector |
| `X` or `Shift+L` | Elbow connector |
| `Shift+S` | Section |
| `/` | Cursor chat |
| `Esc` | Leave the current tool |

Open: shortcuts for zoom, align, group, and the Windows/Linux key names.
