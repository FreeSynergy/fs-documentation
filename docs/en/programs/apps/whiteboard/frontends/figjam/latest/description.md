# FigJam - Description

## What the program does
FigJam is a collaborative board for brainstorming, retrospectives and diagrams. People add sticky notes, text, shapes, connectors and drawings, group them in sections and react to each other with stamps. Facilitation tools (timer, voting) support guided sessions.

## Advantages
- Very low entry barrier: a note, a stamp and a vote are one click each.
- Social presence: named stickies, cursor chat, emotes.
- Widgets embed outside data (for example task-tracker items).

## Differentiation
| System | Difference |
|--------|------------|
| Miro, Mural | Larger template and facilitation catalogues; FigJam is lighter and sits next to the same vendor's design tool. |
| tldraw, Excalidraw | Open, canvas-first; no built-in voting or timer. |

## Technical details
- Hosted service only; no self-hosting. Open: file format, client technology.
- Access: Figma account; API with access token or OAuth2.
