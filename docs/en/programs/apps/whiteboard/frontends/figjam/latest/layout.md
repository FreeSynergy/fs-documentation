# FigJam - Layout

Three regions are documented: the board (canvas), a file toolbar at the top, and a toolbar for tools and objects at the bottom.

| Region | Content |
|--------|---------|
| Left panel | Pages of the file |
| Right sidebar | Templates |
| Bottom toolbar | Tools, for example sections |
| Top toolbar | File menu and file actions |
| Timer, voting and music panel | Opened from an icon; has a results tab; the timer can be hidden and keeps running in the toolbar |

Open: exact positions of the zoom controls, the share button and the member list; behaviour on small screens and tablets.
