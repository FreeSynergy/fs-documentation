# FigJam - Menus

| Menu | Content |
|------|---------|
| File (top toolbar) | File actions, including import from CSV |
| Right-click on a selection | Create a section from the selection |
| Stamp wheel | Pick a stamp; people who used all votes can leave voting mode from it |
| Properties menu | Object properties, for example hiding the author name on a sticky note |

Open: the complete main menu, context menu per object type, menus by role (view-only, can-edit; the help pages state that can-edit access is needed for stamps, timer and music).
