# FigJam - Features

## Present
| Area | Function | Evidence |
|------|----------|----------|
| Notes | Sticky notes; the author's name is shown by default and can be switched off | help page ✅ |
| Drawing | Text, marker, highlighter, washi tape, shapes | shortcut list ✅ |
| Structure | Sections group and move objects together; connectors (straight, elbow) between objects | ✅ |
| Reactions | Stamps (curated stickers) on the board or on objects; emotes as temporary bursts | ✅ |
| Facilitation | Timer; voting with a vote count per participant; results hidden until the session ends; results tab per session | ✅ (voting details ⚠️) |
| Presence | Cursor chat (a message in one's own cursor) | ✅ |
| Extension | Widgets (custom objects, external data) | ✅ |
| Import | Import from CSV | ✅ |
| Templates | Template sidebar | ✅ |

## Not present or Open
| Function | Status |
|----------|--------|
| Self-hosting | not offered (assumed; no statement found) Open |
| Comments anchored to a place | comment tool exists (`C`) ✅; details Open |
| Export formats | Open |
| Offline use | Open |
