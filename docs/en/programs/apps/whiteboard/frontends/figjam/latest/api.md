# FigJam - API

## Overview
Figma offers a REST API at `https://api.figma.com`, with personal access tokens and OAuth2. Webhook endpoints exist for events.

| Type | Status |
|------|--------|
| REST | official ✅ |
| Webhooks | official ✅ (event list Open) |
| Plugin / widget API | widgets exist ✅; API details Open |
| FigJam-specific REST coverage | Open (the API page does not say) |
| Rate limits | documented on a separate page; values Open |
