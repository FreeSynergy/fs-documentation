# Miro - Keyboard shortcuts

## Overview

Miro documents its shortcuts; `?` respectively the menu "Help → Keyboard shortcuts" shows the list.

> As of: Miro (2026).

## Tools

| Shortcut | Tool |
|----------|------|
| `V` | Selection |
| `H` | Hand (pan) |
| `S` | Sticky note |
| `R` | Rectangle |
| `O` | Ellipse |
| `L` | Line |
| `P` | Pen |
| `T` | Text |
| `C` | Connector |
| `F` | Frame |

## View and editing

| Shortcut | Purpose |
|----------|---------|
| `Ctrl/Cmd+C` / `+V` / `+X` | Copy / paste |
| `Ctrl/Cmd+Z` / `+Shift+Z` | Undo / redo |
| `Ctrl/Cmd+A` | Select all |
| `Del` | Delete selection |
| `Ctrl/Cmd+=` / `+-` | Zoom |
| `Ctrl/Cmd+0` | Reset zoom |
| `Ctrl/Cmd+Shift+H` | Fit everything in view (zoom to fit) |
| `Spacebar` + drag | Move the canvas |
| `G` | Group |
| `Ctrl/Cmd+G` | (newer builds) groups — check the version |
| `?` | Shortcut help |

## Explicitly not available

- Vim/palette mode

## Mac

`Cmd` instead of `Ctrl`; the tool letters are identical.
