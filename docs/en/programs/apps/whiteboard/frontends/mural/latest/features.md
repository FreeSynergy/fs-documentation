# Mural - Features

## Main features

- Infinite canvas: shapes, notes, text, freehand, tables, images, frames, connector arrows with anchor points
- **Facilitation**: sequences (step-by-step procedures for workshops), timer, voting (distributing dots), breakout mural groups (Enterprise), areas for structuring
- **Templates**: moderation formats (retro, impact mapping, service design), workspace team templates
- **Access**: guest links with roles, SSO (SAML/SCIM), EU data residency
- **Export**: PNG, PDF (pages), activity log (CSV, Enterprise)

## What Mural does NOT do

- **no open developer platform** like the Miro App Kit: the API surface is narrow (mainly SSO/workspace administration, content only in restricted form)
- **no offline mode**
- **no code/diagram special features** (UML auto-layout is weaker than specialised tools)
- Free plan: 3 murals, basic templates
