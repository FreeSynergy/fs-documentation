# OpenBoard - Features

## Main features

- **Boards** (multi-page blackboards) with pens (colours/widths/highlighters), erasers, shapes with auto-completion, text fields, images
- Tools: **web browser** (integrated, pages can be inserted as image), **document/file viewer** (embed PDFs), **note tool**, **times/alarm clock/ruler/geometry square** (teaching aids)
- Library: your own images/objects plus bundled media, "stacks" (object collections)
- Capturing: screen video recording ("capture" module), presentation in full screen, pen/touch/multitouch support (interactive whiteboards)
- Offline-first, local document library, export PDF/.obz

## What OpenBoard does NOT do

- **no collaboration SaaS** (no multiplayer; only file/presentation exchange)
- **no API/webhook**
- **no infinite-canvas organisation** (page-based like a blackboard)
- **no vector editor** (shapes are simple; not a draw.io replacement)
- Windows/macOS builds exist, but the Linux/school environment is its home

## Extensions and integrations

| Integration | Route |
|-------------|-------|
| Media library | your own folders, drag & drop |
| Interactive whiteboards | driver level (eBeam/eInstruction), multitouch |
| Export | PDF, .obz archives |
