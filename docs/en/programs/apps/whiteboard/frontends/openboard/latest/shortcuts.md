# OpenBoard - Keyboard shortcuts

## Overview

OpenBoard is pen/touch-centred; the keyboard keys are basics. An overview is in the application help ("?" tool).

> As of: OpenBoard 1.7.

## Available

| Shortcut | Purpose |
|----------|---------|
| `Esc` | Close tool strips/modals |
| `Tab` | Switch tool (cycle) — check the current state |
| `Del` | Delete the selected element |
| `Ctrl/Cmd+Z` / `+Y`/`+Shift+Z` | Undo / redo |
| `Page Down/Up` | Next/previous page |
| `Full screen F5` (presentation) | Presentation mode — check the key assignment per version |

## Explicitly not available

- No single-letter tool selection (click the strips)

## Mac

`Cmd` variant for the Ctrl keys.
