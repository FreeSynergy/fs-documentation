# Wekan Documentation

## Overview

Wekan is the open Trello clone (Meteor/Node, MongoDB): boards, lists, cards, swimlanes, labels and checklists — self-hosted, with OAuth2/LDAP and outgoing webhooks. For FreeSynergy the reference skin "kanban with self-hosting and organisational swimlanes".

## File structure

- [menu.md](../../masks/wekan/menu.md) - Board menus, card menu, admin panel
- [features.md](../../masks/wekan/features.md) - Swimlanes, invoke webhooks, what Wekan does NOT do
- [description.md](../../masks/wekan/description.md) - How it differs from Planka, Trello, Focalboard
- [structure.md](../../masks/wekan/structure.md) - Board with swimlanes/lists, card modal
