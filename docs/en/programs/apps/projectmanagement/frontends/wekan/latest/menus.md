# Wekan - Menu items

## Board menu (☰ top right)

| Item | Content |
|------|---------|
| Members | invite by username/e-mail, permissions (admin/normal) |
| Manage labels | colour + text |
| List menu ("…") | sort, archive, colour borders |
| Swimlane menu ("…") | title, colour coding, archive |
| Board actions | archive/close, save as template, import (Trello CSV/JSON), export (JSON/CSV) |
| Activity | feed on the right, collapsible |

## Card menu (card → "…" or click)

- edit, due date, labels, members, checklists, attachments, comments
- move (list/swimlane), duplicate, archive, watch
- own card fields (custom fields per board)

## Admin panel (⚙, instance)

| Area | Content |
|------|---------|
| Users | create, role assignment, deactivate |
| Authentication | password, LDAP, OAuth2 (Casdoor/etc.), SAML |
| Boards/organisations | overview, templates, imports |
| Webhooks/integrations | outgoing hooks per board; invoke webhooks (incoming) |
| Settings | set the first admin, SMTP, registration on/off |

## Menus by role

Admins (instance) vs. board admin vs. board member vs. observer; organisations encapsulate boards.
