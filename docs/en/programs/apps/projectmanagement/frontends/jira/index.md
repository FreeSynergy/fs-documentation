# Jira Documentation

## Overview

Jira (Atlassian) is issue and project tracking with workflows: issues move through statuses (To Do→In Progress→Done), with sprints (Jira Software), types, priorities and powerful JQL. SaaS (Cloud) and Data Center; REST API v2/v3.

## File structure

- [menus.md](latest/menus.md) - Sidebar, project menus, issue actions
- [features.md](latest/features.md) - Workflows, sprints, JQL, what Jira does NOT do
- [description.md](latest/description.md) - How it differs from Trello, OpenProject, Redmine
- [layout.md](latest/layout.md) - Board, backlog, issue view, dashboards
- [shortcuts.md](latest/shortcuts.md) - documented Jira shortcuts (`c`, `.` etc.)
- [api.md](latest/api.md) - REST `/rest/api/3`, Basic/PAT/OAuth, webhooks
