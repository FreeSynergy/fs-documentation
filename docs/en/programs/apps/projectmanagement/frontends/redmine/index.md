# Redmine Documentation

## Overview

Redmine is a free, web-based project management and issue tracking application based on Rails: multiple projects with issue trackers, time tracking, wiki, forums, Gantt/calendar and role-based permissions. The plain, feature-dense surface has been maintained for over 15 years and is highly extensible via plugins.
