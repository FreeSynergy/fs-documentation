# Trello Documentation

## Overview

Trello (Atlassian) is the digital kanban board: boards with lists and cards, due dates, labels, members, checklists and automation via "Butler". SaaS with a very good REST API; the template for practically every kanban frontend.

## File structure

- [features.md](latest/features.md) - Butler, Power-Ups, what Trello does NOT do
