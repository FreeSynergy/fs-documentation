# Planka Documentation

## Overview

Planka is a self-hosted, plain kanban board (fair-code: free Community Edition plus a commercial Pro Edition) with projects, boards, lists and cards in real-time collaboration. The surface consists of a project sidebar, board header and cards arranged by column.

## File structure

- [menus.md](latest/menus.md) - Sidebar, project/board menus and card dialog
- [features.md](latest/features.md) - Cards, labels, checklists, real time, webhooks
- [description.md](latest/description.md) - Description and how it differs from Trello, Wekan and OpenProject
- [layout.md](latest/layout.md) - UI/UX, board layout and themes
- [shortcuts.md](latest/shortcuts.md) - Keyboard control (and shortcuts clearly marked as missing)
- [api.md](latest/api.md) - API documentation (REST with Swagger reference, tokens, webhooks)
