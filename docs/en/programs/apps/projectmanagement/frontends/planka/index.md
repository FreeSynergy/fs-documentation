# Planka

> Category: [projectmanagement](../../index.md)

## What it is

Planka is a self-hosted, plain kanban board (fair-code: free Community Edition plus a commercial Pro Edition) with projects, boards, lists and cards in real-time collaboration. The surface consists of a project sidebar, board header and cards arranged by column.
