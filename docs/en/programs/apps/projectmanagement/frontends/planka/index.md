# Planka Documentation

## Overview

Planka is a self-hosted, plain kanban board (fair-code: free Community Edition plus a commercial Pro Edition) with projects, boards, lists and cards in real-time collaboration. The surface consists of a project sidebar, board header and cards arranged by column.

## File structure

- [menu.md](../../masks/planka/menu.md) - Sidebar, project/board menus and card dialog
- [features.md](../../masks/planka/features.md) - Cards, labels, checklists, real time, webhooks
- [description.md](../../masks/planka/description.md) - Description and how it differs from Trello, Wekan and OpenProject
- [structure.md](../../masks/planka/structure.md) - UI/UX, board layout and themes
- [shortcuts.md](../../masks/planka/shortcuts.md) - Keyboard control (and shortcuts clearly marked as missing)
- [api.md](../../masks/planka/api.md) - API documentation (REST with Swagger reference, tokens, webhooks)
