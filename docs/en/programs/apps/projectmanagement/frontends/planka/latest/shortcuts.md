# Planka - Keyboard shortcuts

## Overview

Planka documents **hardly any own keyboard shortcuts**; the operation follows
web/React conventions. Short list of what actually exists, missing ones deliberately
marked.

> State: Planka 1.x/2.x. Check after updates.

## Available

| Shortcut | Function |
|----------|----------|
| `Esc` | close modal/editor |
| `Enter` | confirm title/description editing |
| `Tab` / `Shift+Tab` | form fields |
| `Del` (in the card title while editing) | empties the field |
| `Ctrl/Cmd+K` | quick search (project/board switcher) — present since v2 |
| `?` | shortcut overlay — **(not documented in all versions)** |

## Not available (deliberately marked)

| Assumed | Status |
|---------|--------|
| `C` new card | ❌ not available — card via "+ card" in the column |
| `N` new project | ❌ not available |
| Arrow-key card navigation | ❌ not available (mouse only) |
| Drag & drop via keyboard | ❌ not available |

## Browser standard

`Ctrl+F` (search in the browser, not app search), `F5` reload, `Alt+←/→` back/forward.

## Mac variants

`Cmd` instead of `Ctrl` (e.g. `Cmd+K`).
