# Taiga - Features

## Main features

### Agile project work
- scrum projects (product backlog, sprints with points/burndown) and kanban projects (board, swimlanes)
- epics with subtasks and epic progress; classic issues in parallel
- story status/point values adjustable per project

### Project knowledge
- wiki, attachment management, activity log (history), notifications
- timeline with milestones; statistics (burn-down/chart, cycle)

### Native integrations
- GitHub/GitLab: commit references `#123`, branch linking, merge → status change
- Slack/Telegram chats, webhooks per project
- import from Jira/Asana/Trello/GitHub issues (assistant)

## What Taiga does NOT do

- **no portfolio/resource planning** (workloads à la Asana: ❌)
- **no Gantt CPM calculation** (the timeline is a presentation)
- **limited dashboard gadgets** (statistics are rigid)
- **no official mobile app** (responsive web; third-party clients)
- **coarse permission model** (roles per project, no field permissions)
