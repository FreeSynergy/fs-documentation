# Asana Documentation

## Overview

Asana is task and project work at portfolio level: tasks with fields (due date, assignees, dependencies, custom fields) in projects (list/table/timeline/kanban), teams, workloads and rules automation. SaaS with a broad REST API and webhooks.

## File structure

- [menu.md](latest/menus.md) - Sidebar, project views, task actions
- [features.md](latest/features.md) - Portfolios, workloads, rules, what Asana does NOT do
- [description.md](latest/description.md) - How it differs from Jira, Trello, OpenProject
- [structure.md](latest/layout.md) - My tasks, multi-view projects
- [shortcuts.md](latest/shortcuts.md) - documented shortcuts (selection, verify state)
- [api.md](latest/api.md) - REST /v1, PAT/OAuth2, webhooks, rate response headers
