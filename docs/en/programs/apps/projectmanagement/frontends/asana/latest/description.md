# Asana - Description

## What the program does

Asana structures work as tasks with clear responsibilities and dates, and scales that across projects, portfolios and workloads. It is "to-do discipline as software" — less ticket workflow, more project everyday life.

## Advantages

- **very good UX** — quickly learned
- **fields + views** cover both operational and management work
- **The API/webhooks are clean** for automations

## Differentiation

| System | Difference |
|--------|------------|
| **Jira** | Issue workflows/agile depth; Asana is broader outside engineering |
| **Trello** | Board only; Asana has portfolios/workloads |
| **OpenProject** | OSS incl. Gantt/CPM; Asana is SaaS-comfortable |

## Technical details

- **Model**: SaaS (US/EU data-protection options), workspace → teams → projects
- **Authentication**: email/Google/SSO (SAML); API: PAT or OAuth2
- **Plans**: basic (15 users formerly → now free 10–15), advanced, premium/enterprise
- **Mobile**: full iOS/Android apps

## Who it suits

- Marketing/operations/agencies under date and responsibility pressure
- FreeSynergy skins: task + custom fields + dependency as a generic [task model](../../../../../../data/models.md)
