# Asana - Menu items

## Sidebar

| Menu | Content |
|------|---------|
| Search (top) | Global search/"jump to" |
| My workspace | **My tasks** (today/all), notifications, inbox |
| Projects | Projects per team, views: list, board (kanban), timeline, calendar, table |
| Portfolios | Collections with status/traffic lights (advanced/enterprise) |
| Workloads | Capacity utilisation per person (advanced+) |
| Goals | OKR-like goals with tracking |
| Forms | Forms as a task entry point |

## Task panel (right-click/click)

- Edit: title, description, due, assigned to, participants, dependencies, attachments, tags, custom fields
- Subtask list, comments, "watch"

## Admin/settings

| Area | Content |
|------|---------|
| Workspace settings | Members, guest sharing, manage custom fields |
| Apps/integrations | Marketplace, **REST API token**, webhooks (app configuration) |
| Rules (advanced) | Automation rules per project ("if due < today then …") |
| Billing/security | SSO/SAML, domain capturing (enterprise) |

## Menus by role

Member/guest differs little (guests have restricted projects); admins see billing/API.
