# OpenProject Documentation

## Overview

OpenProject is an open-source project management system for self-hosting (Community Edition plus a commercial Enterprise Edition) with work packages, Gantt planning, agile boards, time and cost tracking, wiki, meetings and discussion forums. The surface is a classic web application with a main menu, project selector and module bar.

## File structure

- [menu.md](menu.md) - All menu items, module bar and role menus
- [features.md](features.md) - Work packages, planning, agile boards, workflows
- [description.md](description.md) - Description and how it differs from Redmine, Jira and Planka
- [structure.md](structure.md) - UI/UX, window structure and colour scheme
- [shortcuts.md](shortcuts.md) - Keyboard control (and shortcuts marked as missing)
- [api.md](api.md) - API documentation (REST v3, OAuth2, webhooks)
