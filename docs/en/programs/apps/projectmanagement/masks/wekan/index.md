# Wekan Documentation

## Overview

Wekan is the open Trello clone (Meteor/Node, MongoDB): boards, lists, cards, swimlanes, labels and checklists — self-hosted, with OAuth2/LDAP and outgoing webhooks. For FreeSynergy the reference skin "kanban with self-hosting and organisational swimlanes".

## File structure

- [menu.md](menu.md) - Board menus, card menu, admin panel
- [features.md](features.md) - Swimlanes, invoke webhooks, what Wekan does NOT do
- [description.md](description.md) - How it differs from Planka, Trello, Focalboard
- [structure.md](structure.md) - Board with swimlanes/lists, card modal
- [shortcuts.md](shortcuts.md) - Shortcuts (Trello-like, verify state)
- [api.md](api.md) - REST /api with a personal token, invoke hooks, webhooks
