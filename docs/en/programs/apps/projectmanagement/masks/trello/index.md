# Trello Documentation

## Overview

Trello (Atlassian) is the digital kanban board: boards with lists and cards, due dates, labels, members, checklists and automation via "Butler". SaaS with a very good REST API; the template for practically every kanban skin.

## File structure

- [menu.md](menu.md) - Board menus, card actions, workspace level
- [features.md](features.md) - Butler, Power-Ups, what Trello does NOT do
- [description.md](description.md) - How it differs from Jira, Planka, Asana
- [structure.md](structure.md) - Board → lists → cards, overlay masks
- [shortcuts.md](shortcuts.md) - well-documented Trello shortcuts
- [api.md](api.md) - REST /1/…, API key + token, webhooks
