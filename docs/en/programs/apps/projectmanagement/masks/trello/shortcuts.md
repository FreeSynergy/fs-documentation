# Trello - Keyboard shortcuts

## Overview

Trello has one of the best shortcut sets among web tools; `?` shows the overview.

> State: Trello (2026).

## Board

| Shortcut | Function |
|----------|----------|
| `N` | new list |
| `C` | new card (in the focused list) |
| `A` | (card open) assign members |
| `L` | (card open) labels |
| `D` | (card open) due date |
| `Space` | (card open) assign yourself |
| `E` | (card open) edit the title |
| `[` / `]` | (card focused) move left/right |
| `←↑↓→` | move the card focus |
| `F` | filters |
| `/` | search in the board |
| `Ctrl/Cmd+K` | board quick switcher (workspace) |
| `?` | shortcuts overlay |
| `Esc` | close the overlay |

## Explicitly not present

- No "archive card" shortcut documented (menu "…" → archive; older builds: `S`)

## Mac

All `Ctrl` keys use `Cmd`; the single letters are identical.
