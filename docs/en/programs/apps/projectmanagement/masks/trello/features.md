# Trello - Features

## Main features

### Kanban core
- Boards → lists → cards; drag & drop, checklists, due dates with reminders, labels (colour + text), attachments, card colours
- Comments with @-mentions, watching, activity feed

### Views (premium/enterprise)
- Calendar, timeline (Gantt-like), table (Excel-like, editable), map (card locations — a link to the maps category)

### Automation
- **Butler**: a rule library per board (when card moved → set due date → notify), card and board buttons, scheduled commands

### Collaboration
- Members/guests, observers, workspace-wide board templates, card templates, a "movements" audit trail

## What Trello does NOT do

- **no real subtask trees** (checklists are flat, cards cannot have cards)
- **no dependencies between cards** as an object (the timeline only shows rows)
- **no self-hosting** (Atlassian Cloud)
- **reports are rudimentary** (counts per list; no own aggregation without Power-Ups)
- **time tracking only via Power-Up**

## Extensions and integrations

| Integration | Method |
|-------------|--------|
| Power-Ups (marketplace) | Calendar, Custom Fields, Voting, the Jira bridge |
| REST API + webhooks | official |
| Atlassian routing | Jira/Confluence connection (team plans) |
