# Asana - Features

## Main features

### Task model
- Tasks/sections within projects, subtasks, dependencies (blocks/blocked-by with a warning)
- Due date + time, several assignees/participants, tags, custom fields (number, selection, text, user)
- Inbox as the notification hub, "my tasks" smart lists

### Multiple views per project
- List, kanban board, calendar, table, **timeline** (Gantt-like with dependencies)

### Steering level
- **Portfolios** (project groups with status updates), **workloads** (capacities), goals
- **Rules** (a rule engine per advanced project), forms as an entry point, templates

### Integrations
- Marketplace (Slack, Teams, Google Drive), Asana AI (smart summary), universal app (Jira/GitHub sync, plan limits)

## What Asana does NOT do

- **no self-hosting** (SaaS)
- **no real workflow engine** (the status is free; no transition rules like Jira)
- **Gantt without a critical path** (the timeline shows dependencies, no CPM calculation)
- **Time-based effort tracking only via integration**
- Custom field logic is limited (no calculations across fields)

## Extensions and integrations

| Integration | Method |
|-------------|--------|
