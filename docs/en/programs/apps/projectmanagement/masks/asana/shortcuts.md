# Asana - Keyboard shortcuts

## Overview

Asana documents shortkeys (`?` shows the overlay). The set is smaller than Trello/Jira — anything uncertain is marked.

> State: 2026.

## Global

| Shortcut | Function |
|----------|----------|
| `/` | Focus the search |
| `Esc` | Close panel/search |
| `?` | Shortcuts overlay |
| `Ctrl/Cmd+K` | Quick navigation (jump-to) — in current versions, check the state |

## Task (panel open)

| Shortcut | Function |
|----------|----------|
| `Q` | Set the due date |
| `A` | Assign |
| `C` | Focus the comments |
| `E` | Edit the title — check the status |
| `Ctrl/Cmd+Enter` | Send the comment |

## Not documented

- Board/portfolio level: no letter actions

## Mac

`Cmd` instead of `Ctrl`; letter keys identical.
