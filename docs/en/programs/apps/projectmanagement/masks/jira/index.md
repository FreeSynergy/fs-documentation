# Jira Documentation

## Overview

Jira (Atlassian) is issue and project tracking with workflows: issues move through statuses (To Do→In Progress→Done), with sprints (Jira Software), types, priorities and powerful JQL. SaaS (Cloud) and Data Center; REST API v2/v3.

## File structure

- [menu.md](menu.md) - Sidebar, project menus, issue actions
- [features.md](features.md) - Workflows, sprints, JQL, what Jira does NOT do
- [description.md](description.md) - How it differs from Trello, OpenProject, Redmine
- [structure.md](structure.md) - Board, backlog, issue view, dashboards
- [shortcuts.md](shortcuts.md) - documented Jira shortcuts (`c`, `.` etc.)
- [api.md](api.md) - REST `/rest/api/3`, Basic/PAT/OAuth, webhooks
