# Taiga Documentation

## Overview

Taiga is the agile open-source project management tool (AGPL, Python/Django + a modern frontend "Taigo"): Scrum (sprints, points) and kanban in one, plus epics, issues, wiki and a CRM module. Self-hosted (Docker) or as Taiga Cloud.

## File structure

- [menu.md](menu.md) - Project modules, epic tracker, admin centre
- [features.md](features.md) - Scrum/kanban, epics, import, what Taiga does NOT do
- [description.md](description.md) - How it differs from OpenProject, Redmine, Jira
- [structure.md](structure.md) - Module navigation, sprint board, backlogs
- [shortcuts.md](shortcuts.md) - Shortcuts (very few; web standards)
- [api.md](api.md) - REST /api/v1, token/OAuth2, webhooks
