# Redmine Documentation

## Overview

Redmine is a free, web-based project management and issue tracking application based on Rails: multiple projects with issue trackers, time tracking, wiki, forums, Gantt/calendar and role-based permissions. The plain, feature-dense surface has been maintained for over 15 years and is highly extensible via plugins.

## File structure

- [menu.md](menu.md) - Header, project tabs and administration menus
- [features.md](features.md) - Issues, time tracking, wiki, workflows, plugins
- [description.md](description.md) - Description and how it differs from OpenProject, Jira and Trac
- [structure.md](structure.md) - UI/UX, table layout and themes
- [shortcuts.md](shortcuts.md) - Keyboard control (incl. `/` for search) and what is missing
- [api.md](api.md) - API documentation (REST XML/JSON, Atom, ICS)
