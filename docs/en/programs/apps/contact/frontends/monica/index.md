# Monica Documentation

## Overview

Monica is a self-hosted personal CRM: capture people with all their relationships, activities, gifts, tasks and notes — as a web app (Laravel/Vue) with a REST API. For FreeSynergy, Monica is the skin reference case "contact with a history" as opposed to plain address books.

## File structure

- [menu.md](latest/menus.md) - Main navigation, person menu, settings
- [features.md](latest/features.md) - Activities, relationships, tasks, what Monica does NOT do
- [description.md](latest/description.md) - Description and how it differs from Nextcloud Contacts, Trekk, People CRM
- [structure.md](latest/layout.md) - Person detail masks, timeline, responsive
- [shortcuts.md](latest/shortcuts.md) - Shortcuts (web standard)
- [api.md](latest/api.md) - REST API /api/ with token, endpoints, webhooks
