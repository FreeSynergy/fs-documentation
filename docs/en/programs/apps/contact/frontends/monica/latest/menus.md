# Monica - Menu Items

## Main navigation (top)

| Menu item | Description |
|-----------|-------------|
| dashboards | Personal dashboard (next activities, birthdays) |
| contact | Contact list with filter/search |
| activities | Activity chronicle of all contacts |
| tasks | Task list |
| gifts | Gifts overview and ideas |
| notes | All notes |
| journals | Journal books (entries with moods) |
| reports | Statistics and year in review |
| settings | Account, import/export, api, relationship types, activity types, modules on/off |

## Person detail (contact page)

Tabs: **About** (master data) · **Activities** · **Reminders** · **Tasks** · **Relationships** · **Gifts** · **Notes** · **Debt** (debts) · **Life events**

Header menu per contact:
- Edit, favourite, public vCard page (share link), print/PDF view
- "Important information" (height, clothing, allergies …) as custom fields
- Delete / archive contact

## Settings area

| Menu | Content |
|------|---------|
| User settings | Language, time zone, units, generate API token |
| Personalisation | Relationship types, activity types, contact field categories |
| Modules | Gifts, tasks, task journal, debts, life events on/off |
| Import/export | vCard/CSV import, JSON/vCard export, "Google contacts" import |

## Menus by role

| Role | What is visible |
|------|-----------------|
| Owner | Everything |
| Monitor (read-only access) | Content without edit menus |
| Contact manager | Edit contacts/activities, no settings |

("Circles" separate instance content between users — each user only sees their own circle.)
