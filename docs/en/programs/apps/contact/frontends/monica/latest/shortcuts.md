# Monica - Keyboard Shortcuts

## Overview

Monica has **no documented app shortcuts**; the keyboard follows browser/form standards.

> State: Monica 4.x.

## Present (web standard)

| Shortcut | Function |
|----------|----------|
| `Tab` / `Shift+Tab` | Form fields |
| `Enter` | Save the form / confirm the search field |
| `Esc` | Close modals (create contact, activity dialog) |
| `/` | Focus the search field — **only in some views**, otherwise a `Tab` tour |
| `Ctrl/Cmd+F` | Browser search on the page |

## Not present (marked)

| Assumed | Status |
|---------|--------|
| `N` new contact | ❌ |
| `A` new activity | ❌ |
| Global navigation by letter | ❌ |

## Mac

`Cmd` instead of `Ctrl` for browser keys.
