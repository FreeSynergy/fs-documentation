# KAddressBook

> Category: [contact](../../index.md)

## What it is

KAddressBook is the contact management application of KDE PIM: vCard-based, managed through Akonadi resources (local folders, IMAP-Contacts, CardDAV, LDAP). It runs as a standalone program or embedded in Kontact, and is the reference for desktop contacts on Linux.
