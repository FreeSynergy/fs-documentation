# GNOME Contacts Documentation

## Overview

GNOME Contacts is the lean contact app for GNOME: create contacts, link them, synchronise them with Evolution Data Server sources (local address books, CalDAV/CardDAV accounts, Google, LDAP). Deliberately minimal — operation almost entirely via keyboard and popover menus.

## File structure

- [menu.md](latest/menus.md) - Main menu, contact actions, sources
- [features.md](latest/features.md) - EDS sources, card merging, import/export, what it does NOT do

- [api.md](latest/api.md) - libebook/EDS as the interface, vCard files, no REST
