# GNOME Contacts Documentation

## Overview

GNOME Contacts is the lean contact app for GNOME: create contacts, link them, synchronise them with Evolution Data Server sources (local address books, CalDAV/CardDAV accounts, Google, LDAP). Deliberately minimal — operation almost entirely via keyboard and popover menus.

## File structure

- [menu.md](menu.md) - Main menu, contact actions, sources
- [features.md](features.md) - EDS sources, card merging, import/export, what it does NOT do
- [description.md](description.md) - Description and how it differs from KAddressBook, Nextcloud Contacts and Evolution
- [structure.md](structure.md) - Window without a menu, HeaderBar, contact view
- [shortcuts.md](shortcuts.md) - GTK keyboard shortcuts
- [api.md](api.md) - libebook/EDS as the interface, vCard files, no REST
