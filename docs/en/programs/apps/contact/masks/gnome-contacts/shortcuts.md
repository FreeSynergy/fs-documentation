# GNOME Contacts - Keyboard Shortcuts

## Overview

GNOME Contacts supports the GNOME standard keys; they are listed in the help overlay (`?`).

> State: gnome-contacts 45+.

## Global

| Shortcut | Function |
|----------|----------|
| `Ctrl+N` | New contact |
| `Ctrl+F` or typing directly | Focus the search |
| `Esc` | Leave detail/edit |
| `F10` or `.` | Open the main menu ⋮ (GTK/GNOME convention) |
| `Ctrl+I` | Import (in newer versions in the menu; verify the key binding) |

## Editing

| Shortcut | Function |
|----------|----------|
| `Tab` | Next field |
| `Enter` | Confirm the field |
| `Del` | Delete the marked field (in editing mode) |

## GNOME-global (app switching)

| Shortcut | Function |
|----------|----------|
| `Super` | Activities — find contacts by typing |
| `Alt+Tab` | Switch app |

## Mac variants

Not applicable (Linux only).

## Explicitly not present

- no single-letter actions such as `m` mail, `p` phone
- no shortcut for printing (menu "⋮ → Print")
