# Nextcloud Contacts Documentation

## Overview

Nextcloud Contacts is the contact app of the Nextcloud suite: address books in the browser, synchronised over CardDAV with all devices, linked to user accounts, circles/groups and the people area of the dashboard. The data lives as vCards in the Nextcloud database.

## File structure

- [menu.md](menu.md) - App navigation, contact actions, sharing menus
- [features.md](features.md) - CardDAV, circles, import/export, what Contacts does NOT do
- [description.md](description.md) - Description and how it differs from KAddressBook, Monica and GNOME Contacts
- [structure.md](structure.md) - List-detail layout, fields, responsive design
- [shortcuts.md](shortcuts.md) - Shortcuts (few; web standards)
- [api.md](api.md) - CardDAV (RFC 6352), OCS sharing, status keys
