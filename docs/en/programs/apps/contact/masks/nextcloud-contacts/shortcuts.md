# Nextcloud Contacts - Keyboard Shortcuts

## Overview

The Contacts app defines **no shortcuts of its own**; the Nextcloud global keys and browser standards apply. Missing ones are marked.

> State: Contacts 5.x/6.x on Nextcloud 28+.

## Nextcloud global

| Shortcut | Function |
|----------|----------|
| `/` | Focus the search field (Nextcloud header) |
| `Ctrl/Cmd+K` | Universal search / command palette |
| `Esc` | Close the detail panel/search |
| `Enter` | Open the first search hit; confirm field editing |

## List and detail

| Shortcut | Function |
|----------|----------|
| `Tab` | Move through the fields in the form |
| `Shift+Tab` | Backwards |
| `Del` | (not documented — delete only via button) |
| `N` new contact | ❌ Not present — button "New contact" |

## Mac

`Cmd` instead of `Ctrl`.

## Explicitly not present

- No single-letter navigation as in mail clients
- No shortcut for creating address books
