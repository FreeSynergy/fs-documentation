# KAddressBook - Keyboard Shortcuts

## Overview

KAddressBook follows the KDE standard shortcuts; the most important ones are visible in the menus ("Configure Shortcuts" lets you remap freely).

> State: KDE Gear 23.x/24.x.

## File and creating contacts

| Shortcut | Function |
|----------|----------|
| `Ctrl+N` | New contact |
| `Ctrl+Shift+V` | New distribution list (in many versions; otherwise via the menu) |
| `Ctrl+I` | Import assistant |
| `Ctrl+E` | Export assistant |
| `Ctrl+P` | Print (addresses/business cards) |
| `Ctrl+W` / `Ctrl+Q` | Close window / application |

## Editing

| Shortcut | Function |
|----------|----------|
| `Enter` / `Return` | Edit the marked contact |
| `Del` | Delete contact |
| `Ctrl+C` / `Ctrl+V` | Copy contact / paste into another address book |
| `Ctrl+Z` | Undo (within the session) |

## Navigation and search

| Shortcut | Function |
|----------|----------|
| `Ctrl+F` | Focus the search field |
| `Arrow keys` / `PgUp/PgDn` | Move in the list |
| `Home` / `End` | Start/end of the list |
| `F5` | Refresh the Akonadi resources |

## Mac variants

KAddressBook has no official Mac build; Qt substitute `Cmd`↔`Ctrl`, if built.

## Explicitly not present

- No single-letter filter as in Evolution
- No global hotkey to open it (has to be assigned via Plasma's own keyboard settings)
