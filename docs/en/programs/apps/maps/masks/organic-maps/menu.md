# Organic Maps - Menu items

## Main areas

| Element | Content |
|---------|---------|
| Search field (bottom) | Addresses/POIs/categories (offline search) |
| Category grid (map empty) | Food, shopping, health, outdoor … |
| Layer switch icon (right) | Contour lines, overlays (bike/winter), 3D buildings |
| Compass/layer buttons | North alignment, scale |
| "Saved" (bottom tab) | Favourites, lists/collections, tracks |

## Detail sheet (POI sheet)

- Name, address, opening hours (if tagged), "build route", "share", note field

## Settings

| Area | Content |
|------|---------|
| Map download | Regions automatically/wifi |
| Bookmarks | Import/export (`.kml`, `.bm2`), "save as KML" |
| Navigation | Voice package, vehicle profiles |

## Menus by role

No accounts/roles (deliberately local).
