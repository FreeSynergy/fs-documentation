# Organic Maps - Description

## What the program does

Organic Maps is OSM for your pocket: map on, destination in, start walking — everything offline, everything without an account. It deliberately forgoes mountains of features in favour of speed and simplicity.

## Advantages

- **very fast** (C++ rendering, compact data)
- **bookmarks as shareable collections** — an uncomplicated group solution
- Nonprofit model (subscription optional), F-Droid version

## Differentiation

| System | Difference |
|--------|------------|
| **OsmAnd** | Feature abundance; the focus of Organic Maps |
| **Google Maps** | Live/proprietary; Organic is offline/open |
| **Locus** | A professional tool, commercial; Organic is non-profit |

## Technical details

- **Stack**: C++ (a Maps.me descendant), Android/iOS, desktop preview
- **Data**: .mwm regions (OSM, ODbL)
- **Authentication**: none needed
- **Licence**: GPL (2.0+)

## Who it suits

- Casual navigation + simple group points (an alternative to OsmAnd in [standpunkte.md](../../standpunkte.md))
