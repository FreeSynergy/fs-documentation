# Organic Maps Documentation

## Overview

Organic Maps (GPL, subscription-free nonprofit app) is the lean offline map/navigation app (Android/iOS/desktop): fast, sparing with data (no tracking/advertising logic), OSM-based, with own places (bookmarks) and offline routing.

## File structure

- [menu.md](menu.md) - Search bar, categories, layers menu, "Saved"
- [features.md](features.md) - Offline routing, bookmarks, what Organic Maps does NOT do
- [description.md](description.md) - How it differs from OsmAnd, Google Maps, MagicEarth
- [structure.md](structure.md) - Full-screen map, search/detail sheets
- [shortcuts.md](shortcuts.md) - Gesture control
- [api.md](api.md) - Geo intents, bookmark file formats (.bm2/.kml), no API
