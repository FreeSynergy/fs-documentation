# OsmAnd - Keyboard shortcuts

## Overview

OsmAnd is a touch app: **no keyboard shortcuts**, control is via gestures/context menus (a Bluetooth keyboard is not advertised as a control path).

> State: OsmAnd 4.x.

## Gestures instead of shortcuts

| Gesture | Function |
|---------|----------|
| Tap | Center the map |
| Double tap | Zoom in |
| Two fingers | Zoom/rotate/tilt (3D) |
| Long tap | Context menu (set destination, note, route) |
| Swipe | Move the map |

## External control

- Android intents as a "shortkey from outside" (see [api.md](api.md))

Not present (mobile app).
