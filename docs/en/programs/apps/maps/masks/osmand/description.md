# OsmAnd - Description

## What the program does

OsmAnd brings OSM to the phone as full-fledged navigation: maps offline, routing offline, your own places as GPX folders. It is the power-user variant of the open map apps — features before elegance.

## Advantages

- **a genuine offline adventure** (maps, elevations, POIs)
- **My Places as a distributed address book**: group points exchangeable via GPX
- Open source, fork-friendly (community builds)

## Differentiation

| System | Difference |
|--------|------------|
| **Organic Maps** | Leaner/faster; OsmAnd is richer in features (plugins, truck profiles) |
| **Locus Map** | Commercial, a similar mountain of features |
| **Google Maps** | Proprietary/live; OsmAnd is offline/data-sovereign |

## Technical details

- **Stack**: C++ core (OsmAnd Core), Android/iOS interfaces
- **Data**: .obb tiles + .ipn index (derived from OSM PBF, ODbL)
- **Authentication**: none (local); the Plus subscription unlocks features
- **Licence**: Apache-2.0 (OsmAnd)

## Who it suits

- Hiking/club groups with location point exchange + a navigation need ([standpunkte.md](../../standpunkte.md))
