# OsmAnd Documentation

## Overview

OsmAnd (Apache-2.0) is the offline navigation app based on OSM (Android/iOS): downloadable map regions, routing (car/bike/foot; public-transport planner available offline), POI search, track recording, "My Places" with own points/layers — the OSMPlus spirit: an open-source map app full of features.

## File structure

- [menu.md](menu.md) - Main navigation (bottom), sidebars, "My Places"
- [features.md](features.md) - Offline maps, routing, track log, what OsmAnd does NOT do
- [description.md](description.md) - How it differs from Organic Maps, Google Maps, Locus Map
- [structure.md](structure.md) - Full-screen map + panels + navigation mode
- [shortcuts.md](shortcuts.md) - Gestures instead of keys
- [api.md](api.md) - "My Places"/GPX data exchange, OsmAnd intents (Android), no server API
