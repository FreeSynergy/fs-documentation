# OsmAnd - Menu items

## Main navigation (bottom, bar)

| Tab | Content |
|-----|---------|
| Navigation | Start routing to a destination (address/POI/map/My Places) |
| Plan (route) | Route via a chain of points, intermediate stops, elevation profile, GPX export/GPX share |
| My Places | Folders + points + GPX files (layers), import/export |
| Wiki/nearby | POI categories, search |
| configure… | Settings/plugins (the "planning & navigation" module, live updates) |

## Side bars

| Bar | Content |
|-----|---------|
| Left bar ("hamburger") | Download offline maps, app settings, disabled features |
| Right bar ("configure map") | Contour lines, POI layers, 3D view, night mode, measuring tool |

## Navigation mode

- Turn tiles, lane assistant, TMC traffic (online), "trip statistics"

## Import/export menu

- GPX/KML/KMZ import, save "My Places" as `.ovf/.gpx`; sharing via file
