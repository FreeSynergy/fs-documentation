# uMap Documentation

## Overview

uMap (uMap Project, free software) is **collaborative map diagramming**: own layers with markers/polylines/polygons, popup contents (HTML), sharing via link, multi-user editing. Built on OSM tiles; self-hostable (Django/PostgreSQL) or public instances (uMap.org).

## File structure

- [menu.md](menu.md) - Map toolbar, layers panel, settings, share
- [features.md](features.md) - Layers/formats, data exchange, what uMap does NOT do
- [description.md](description.md) - How it differs from Google My Maps, Fusion Tables, QGIS
- [structure.md](structure.md) - Map + layer list + popup editor
- [shortcuts.md](shortcuts.md) - Shortcuts (minimal set)
- [api.md](api.md) - Data API (GeoJSON), import/export formats
