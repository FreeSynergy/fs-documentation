# uMap - Keyboard shortcuts

## Overview

uMap has **no documented shortkeys**; the Leaflet mouse/touch standard suffices.

> State: uMap (2026).

## Present

| Shortcut | Function |
|----------|----------|
| `+` / `-` (keys) | Zoom (Leaflet) |
| `Esc` | Close popup/dialog |
| `Tab`/`Enter` | Popup forms |
| `Ctrl/Cmd+scroll` | Zoom |

## Explicitly not present

- Palette, tool letters

## Mac

`Cmd` for browser standards.
