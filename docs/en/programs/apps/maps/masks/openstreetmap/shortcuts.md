# OpenStreetMap - Keyboard shortcuts

## Overview

The shortkeys belong to the editor, not to the map: **iD** (web) and **JOSM** (desktop) have extensive, documented lists.

> State: iD 2.x / JOSM stable (2026).

## iD (web editor)

| Shortcut | Function |
|----------|----------|
| `?` | Shortcuts overlay |
| `Ctrl/Cmd+Z` / `+Shift+Z` | Undo / redo |
| `Ctrl/Cmd+C` / `+V` / `+X` | Copy / paste / cut |
| `Enter` | Confirm preset/tag entry |
| `Esc` | Close selection/panel |
| `Tab`/`Shift+Tab` | Field navigation |
| `+` / `-` | Zoom |

## JOSM (desktop)

| Shortcut | Function |
|----------|----------|
| `s` / `w` / `p` | Map modes: select / walk / line (menu confirmation recommended) |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+A` | Select all |
| `Del` | Delete the selection (with a warning) |
| `F6` / `F7` … | Apply preset etc. — check the menu ("Tools → Shortcuts") |
| `Upload` | `Ctrl+Shift+O` (changeset dialog) — check the current state |

## Map view openstreetmap.org

| Shortcut | Function |
|----------|----------|
| `+`/`-`, arrow keys | Zoom/pan (mouse-first) |

## Mac

`Cmd` in the web editors; the JOSM Linux/macOS builds use `Ctrl`/`Cmd` per platform.
