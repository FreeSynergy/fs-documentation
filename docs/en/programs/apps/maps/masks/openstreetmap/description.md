# OpenStreetMap - Description

## What the program does

OpenStreetMap is **the data**, not an application: volunteers capture roads, POIs, waterways; services (uMap, OsmAnd, GraphHopper…) build on it. The web presence is the starting point: view the map, leave notes, edit in the browser.

## Advantages

- **free to use (ODbL)**, worldwide, current in active cities
- **open API chain**: edit → diff files → Overpass — automation without licence negotiations
- A lively community with forums/mailing lists (regional groups)

## Differentiation

| System | Difference |
|--------|------------|
| **Google/Apple Maps** | Proprietary data; OSM = open data + community |
| **MapLibre/Leaflet** | Rendering/map libraries; OSM = the data stock |
| **Commercial POI providers** | Curated/licensed; OSM = crowdsourced |

## Technical details

- **APIs**: OSM API 0.6 (OSM-XML/PBF), Overpass, Nominatim, diff downloads (planet.osm)
- **Account**: OSM login, OAuth2 for third-party apps
- **Licence**: ODbL (attribution, share-alike for derived data)

## Who it suits

- All map skins — OSM is the shared data basis (see the [location point (Standpunkte) docs](../../standpunkte.md))
