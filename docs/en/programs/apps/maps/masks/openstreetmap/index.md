# OpenStreetMap Documentation

## Overview

OpenStreetMap (OSM) is the worldwide collaborative mapping platform: everyone edits the geodata ("the wiki of maps"). Ecosystem: iD/JOSM editors, Overpass API (data queries), OSM API (nodes/ways/relations), Nominatim (search), third-party tile/vector services. ODbL licence (attribution required!).

## File structure

- [menu.md](menu.md) - openstreetmap.org map view, editing tools, community menus
- [features.md](features.md) - Tagging, changesets, Overpass, what OSM does NOT do
- [description.md](description.md) - How it differs from Google Maps, MapLibre tiles, commercial POI databases
- [structure.md](structure.md) - Map UI, editing modes, layers
- [shortcuts.md](shortcuts.md) - iD/JOSM shortcuts (JOSM has many)
- [api.md](api.md) - OSM API 0.6, Overpass QL, Nominatim, changesets
