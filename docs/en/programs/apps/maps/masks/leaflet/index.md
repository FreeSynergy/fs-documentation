# Leaflet Documentation

## Overview

Leaflet (BSD-2-Clause) is the lightweight JavaScript map library: raster tiles, markers, polygons, layer switching, touch support — the standard on which uMap and thousands of map widgets sit.

## File structure

- [menu.md](menu.md) - UI controls that Leaflet brings along (zoom/attribution/layers)
- [features.md](features.md) - Layer types, plugins, what Leaflet does NOT do
- [description.md](description.md) - How it differs from MapLibre, OpenLayers, Google Static Maps
- [structure.md](structure.md) - DOM layout (tile layers + overlay layer)
- [shortcuts.md](shortcuts.md) - Keyboard navigation of the map
- [api.md](api.md) - JS API (class `L`), no server interface
