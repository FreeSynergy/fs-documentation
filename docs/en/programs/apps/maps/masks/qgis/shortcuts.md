# QGIS - Keyboard shortcuts

## Overview

QGIS has an extensive, editable shortcut overview under **settings → keyboard shortcuts**. Base list:

> State: QGIS 3.x (current LTS).

## Present

| Shortcut | Function |
|----------|----------|
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | New project / open / save |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / redo (edits) |
| `F2` (layer tree) | Rename the layer |
| `Del` (layer) | Remove the layer |
| `Esc` | Cancel selection/tool |
| `Spacebar` + drag | Pan (move) |
| `Shift+drag` | Rectangle selection (selection tool) |
| `Ctrl+Shift+V` | Paste as a new layer (copy/paste geometries) — check the current state |

## Customising

Shortcuts freely assignable (dialog above).

## Mac

`Cmd` variants for the file/edit commands.
