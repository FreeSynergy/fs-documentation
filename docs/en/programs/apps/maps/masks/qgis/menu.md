# QGIS - Menu items

## Menu bar (classes)

| Menu | Content |
|------|---------|
| Project | New/open (QGS), properties (CRS!), print layouts |
| Edit | Make a layer editable, insert/move, digitising tools |
| Vector | Geometries, analyses (buffer, convex hull), data management |
| Raster | Analysis, sampling, mosaics |
| Database | DB manager (PostGIS/GeoPackage/layer import/export) |
| Processing | The **processing toolbox** (hundreds of algorithms, build models) |
| Plugins | Install/manage (Grass7, QuickMapServices, profile tools…) |
| Vector tools + map tools (toolbars) | Snapping, measure line, selections, identify |

## Panels

| Panel | Content |
|-------|---------|
| Layer (tree) | Order, groups, identifiers |
| Browser | Data sources (folders, DBs, WMS/WFS catalogues) |
| Coordinates/time control | Nudge/spatio-temporal |

## Menus by role

QGIS is a single-seat tool; server roles (OGC access) per service configuration.
