# MapLibre - Menu items

## Built-in controls

| Control | Content |
|---------|---------|
| NavigationControl | Zoom + compass (pitch/yaw reset) |
| GeolocateControl | Location button (browser API) |
| ScaleControl | Scale |
| AttributionControl | Credits (short/full) |
| FullscreenControl | Fullscreen |

## Style tools (officially maintained)

| Tool | Content |
|------|---------|
| **Maputnik** | Style studio in the browser (layers, colours, texts, sprites/glyphs) |
| Style spec docs | The JSON schema of the map styles |

## Menus by role

A library without user roles; style/tile administration lies with the operator (S3/tiler).
