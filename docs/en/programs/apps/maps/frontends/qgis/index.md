# QGIS Documentation

## Overview

QGIS (GPL) is the professional desktop GIS: layers (shapefile/GeoPackage/PostGIS/WMS), analysis tools (buffers, overlays, geoprocessing), print layouts, **QGIS Server** (OGC services) and Python (PyQGIS). De facto standard in the open geoworld.

## File structure

- [menu.md](latest/menus.md) - Menu bar (vector/raster/processing), panels, toolbars
- [features.md](latest/features.md) - Analyses, printing, server, what QGIS does NOT do
- [description.md](latest/description.md) - How it differs from ArcGIS, uMap, Leaflet
- [structure.md](latest/layout.md) - Layer tree, map view, browser panel, processing
- [shortcuts.md](latest/shortcuts.md) - well-documented QGIS keyboard shortcuts
- [api.md](latest/api.md) - PyQGIS, QGIS Server OGC, GeoPackage/PostGIS
