# OpenStreetMap

> Category: [maps](../../index.md)

## What it is

OpenStreetMap (OSM) is the worldwide collaborative mapping platform: everyone edits the geodata ("the wiki of maps"). Ecosystem: iD/JOSM editors, Overpass API (data queries), OSM API (nodes/ways/relations), Nominatim (search), third-party tile/vector services. ODbL licence (attribution required!).
