# OpenStreetMap - Menu items

## openstreetmap.org (map view)

| Element | Content |
|---------|---------|
| Search bar | Nominatim geocoding (places, addresses) |
| Layer tabs | Standard/cycle/trace (tile choice) |
| Layers switch | Base, labels, image overlays |
| Direction arrow | Routing (OSRM/GraphHopper/Valhalla, transit via transit maps) |
| "Share" | View links, embed code |
| Note "+" | Error notices on the map (not editing) |

## Edit (login)

- **iD editor** (web): point selection, presets (station, shop…), shapes, rectangles, raw ways
- **JOSM** (desktop Java): the full data model, plugins, preset tab, "upload changes"

## Community menus (top)

| Menu | Content |
|------|---------|
| Log in/sign up | OSM account (also an OAuth provider for third-party apps) |
| Traces (GPS traces) | Upload your own tracks/share them publicly |
| Users/changesets/notes | View activities |
| Help/about/wiki | Community resources (wiki.openstreetmap.org) |

## Editor areas (iD)

- Left preset bar, right field panel (tags), "finish" dialog with a changeset comment
