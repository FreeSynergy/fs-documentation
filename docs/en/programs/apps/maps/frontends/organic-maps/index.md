# Organic Maps

> Category: [maps](../../index.md)

## What it is

Organic Maps (GPL, subscription-free nonprofit app) is the lean offline map/navigation app (Android/iOS/desktop): fast, sparing with data (no tracking/advertising logic), OSM-based, with own places (bookmarks) and offline routing.
