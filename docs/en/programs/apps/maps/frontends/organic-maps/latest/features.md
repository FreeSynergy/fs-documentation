# Organic Maps - Features

## Main features

- **Offline maps + routing** (car/bike/on foot), offline search, contour lines
- **Bookmarks/collections**: points with notes, lists, KML/BM2 import/export — group folders shareable via file
- **Track planning** (newer versions: route waypoints, GPX import for tours)
- Data protection: no mandatory accounts, no tracking; open source (F-Droid)

## What Organic Maps does NOT do

- **no truck profile/lane-assistant fine-tuning** (OsmAnd's depth of detail)
- **no live traffic/public-transit routing**
- Bookmarks without tagging/relations (flat, lists)
- No map editing; sync only via files (no service)
