# Organic Maps - Keyboard shortcuts

## Overview

A touch app without documented keyboard shortcuts; control is via gestures and sheets.

> State: Organic Maps 2026.

## Gestures

| Gesture | Function |
|---------|----------|
| Tap | Select POI/open sheet |
| Double tap | Zoom |
| Two fingers | Zoom/rotate/tilt |
| Swiping on the sheet | Change the level of detail |
| Long tap | Point marker (context) |

## Explicitly not present

- Shortcuts, a desktop keyboard concept (mobile)

## Mac

Desktop preview: scroll zoom, no shortkeys documented.
