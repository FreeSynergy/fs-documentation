# MapLibre Documentation

## Overview

MapLibre (BSD, a fork from Mapbox GL JS after the licence change) is the **vector-map engine**: tiles + style JSON (GL Style Spec), WebGL rendering with 3D tilts, custom styles (Maputnik), self-hosting of the tiles (Tilemaker/Martin). The modern standard for free map apps (OsmAnd maps, Organic tiles, many web maps).
