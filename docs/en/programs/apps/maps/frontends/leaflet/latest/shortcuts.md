# Leaflet - Keyboard shortcuts

## Overview

The **map** (not the library) has keyboard navigation — enableable via `keyboard: true` (default).

> State: Leaflet 1.9.

## Present

| Shortcut | Function |
|----------|----------|
| `Arrow keys` | Move the map |
| `+` / `-` | Zoom in/out |
| `Esc` | Close popup/tooltip |
| `Tab` | Controls/markers (the app's DOM focus) |

## Explicitly not present

- Global shortkeys (to be built on the app side yourself)

## Mac

Identical (arrows/characters).
