# Leaflet - Menu items

## Built-in controls

| Control | Content |
|---------|---------|
| Zoom (+/−) | Stepwise, mouse wheel/double-click optional |
| Layers box | Radio/checkbox for base/overlay layers |
| Scale | Scale bar (metric/imperial) |
| Attribution | Mandatory credits per layer (OSM notice!) |

## What the developer builds from it

- Own toolbars (buttons `L.Control`), draw-plugin toolboxes (feature group editors)
- Popups/tooltips as micro-menus (HTML in the map)

## Menus by role

Built-in roles: none — roles/permissions are the concern of the calling app.
