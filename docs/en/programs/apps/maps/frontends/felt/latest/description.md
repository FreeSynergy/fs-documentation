# Felt latest — Description

## Overview
A web GIS aimed at teams: upload or connect data, style it, annotate, analyse, share.

## What it does
- Upload many geodata formats (up to 100 GB per file per the vendor) and geocode address spreadsheets.
- Connect data sources (Postgres, BigQuery, Snowflake, S3, WFS, WMTS, STAC and others).
- Edit maps together; comments; sharing with view/comment/edit permissions.
- Basic analysis (buffer, clip, intersect), AI-assisted questions, a field app.
- Embed maps; export images, PDFs and data.

## Who it suits
Teams who need a shared map without desktop GIS software.

## Differentiation
### Felt vs. uMap
uMap is free software for quick own maps; Felt is a commercial service with data connections and analysis. Felt vs. QGIS: browser and sharing first, not deep desktop analysis.

## Technical details
Hosted service. Enterprise plan: SSO, regional hosting, run in the customer's own AWS account. Self-hosting for everyone else: not offered as far as found. Pricing tiers: Open.
