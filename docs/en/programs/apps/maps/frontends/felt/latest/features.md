# Felt latest — Features

## Main features
- Live shared editing of one map.
- Layers: legend, organise, filter, create and edit features.
- Annotations (called "elements" in the API) drawn on the map.
- Comments, also by people without a paid seat.
- Sharing by link (no login needed to view) with permission levels; embedding.
- Upload Anything: files, URLs and data-source connections.
- Export and print: images, PDF, data.
- Analysis and dashboards; Felt AI; field app.

## What it does NOT do
- Not free software; no general self-hosting (Enterprise AWS option only).
- Details of drawing tools and offline use: Open.

## Extensions and integrations
JavaScript SDK, REST API, Python library, webhooks.
