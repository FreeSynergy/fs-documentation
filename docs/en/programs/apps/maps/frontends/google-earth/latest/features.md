# Google Earth latest — Features

## Main features
- 3D globe, terrain, buildings; tilt and rotate.
- Search for places; "I'm feeling lucky" style discovery (2017 launch; current status Open).
- Voyager guided tours (⚠️ current scope not confirmed).
- Measure tool for distance, path and area; elevation profile (April 2026).
- Street View and historical Street View via a Pegman control.
- Projects: draw, add text and media, share via Google Drive; mobile apps can view them; a project can be pinned as a reference project in the basemap settings.

## What it does NOT do (as far as found)
- No self-hosting (proprietary service).
- Real-time co-editing of a project: Open.

## Extensions and integrations
Google Drive for sharing projects. A developer area for Google Earth exists (see [api](api.md)); its content: Open.
