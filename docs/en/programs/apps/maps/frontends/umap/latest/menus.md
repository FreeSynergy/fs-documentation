# uMap - Menu items

## Toolbar (left on the map)

| Tool | Content |
|------|---------|
| Place marker/shape | Point, line, area, circle, rectangle (icons/symbols selectable) |
| Manage layers | Create/toggle layers (visible/selectable), "base data" vs. own layers |
| Filter/sort | Search field for marker attributes |

## Layers panel (left)

- Layer list with counter, "edit this layer" (colour, symbol, cluster options, pop-ups)
- Data per layer: a table-like listing of the objects

## Edit map (gear at the top)

| Menu | Content |
|------|---------|
| Map settings | Name/description, base layer, zoom/bounds, "map as start page" |
| Formats | Icon sets, popup size, date format |
| Share | Links (editable/viewable), embedding (iframe), QR |
| Import/export | Import/export GeoJSON/GPX/KML/KCSV |
| Permissions | Edit anonymously?, "edit token" link, limited password protection |

## Menus by role

- **Everyone** (in private mode: nobody) · **Editors via token link** · **Owner** (settings)
