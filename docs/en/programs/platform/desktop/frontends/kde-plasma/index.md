# KDE Plasma

> Category: [desktop](../../index.md)

## What it is

KDE Plasma is the free desktop environment of the KDE community. It is notable here for Activities: named work contexts, such as Work or Gaming, on top of virtual desktops.

## Notable ideas

- **Activities as contexts**: separate from virtual desktops, an Activity changes the whole working context.
- **Per-activity items** (per KDE blog, Jan 2026): favourites and pinned apps, widgets, wallpaper, desktop icons, window rules.
- **Privacy per Activity**: file and app usage tracking can be switched off for one, several or all Activities, also automatic screen-off and sleep.
- Listed here for the idea of switching context, not only windows (ADR 0013).
