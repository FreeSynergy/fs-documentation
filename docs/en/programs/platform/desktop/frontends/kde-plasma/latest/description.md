# KDE Plasma (Activities) - Description

## What it does

Plasma is a complete desktop shell: panels, widgets, launcher, settings. Activities let a user keep several contexts and switch between them; virtual desktops remain for tasks inside one context.

## Scope of this analysis

Only the Activities function. The rest of Plasma is not analysed here.

## Reliability

Per-activity scope is narrower than the name suggests: forum and bug reports say per-activity power management was removed in Plasma 6, panel layout is shared, and per-activity desktop effects were declined. A 2025 sprint note proposes more per-activity items. Treat these as informal.

## Open

- Minimum Plasma version for each item.
