# KDE Plasma (Activities) - Features

- Create, change and delete Activities in System Settings, or in the Activities Manager.
- Per Activity: favourites and pinned apps, widgets, wallpaper, desktop icons (via the location "files linked to current activity"), window rules (for example, an app on all Activities).
- Items can be pinned so they appear in every Activity.
- Per Activity privacy: usage tracking, automatic screen-off, automatic sleep.
- Switching via keyboard shortcuts or the Activities Manager.

## Not per Activity (informal sources)

Panel layout; desktop effects; power management.

## Open

- Whether tracked file and app usage feeds recent-items lists per Activity.
