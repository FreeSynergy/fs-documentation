# Homarr Documentation

## Overview

Homarr is a self-hosted dashboard for homelabs: services, containers and links are collected in freely configurable boards (widget grids), monitored live and opened with a click. The server runs as a Next.js application; the entire interface is configured via the web interface.

## File structure

- [menu.md](latest/menus.md) - All menu items, board and widget menus
- [features.md](latest/features.md) - Widgets, integrations and configuration
- [description.md](latest/description.md) - Description and distinction from Heimdall, Homer and Dashy
- [structure.md](latest/layout.md) - UI/UX, board layout and structure
- [shortcuts.md](latest/shortcuts.md) - Keyboard control (and shortcuts clearly marked as missing)
- [api.md](latest/api.md) - API documentation (tRPC, OpenAPI reference, integrations)
