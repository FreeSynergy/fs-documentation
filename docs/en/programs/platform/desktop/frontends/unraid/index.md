# Unraid Documentation

## Overview

Unraid is a proprietary server operating system for NAS, media and game servers: an array mixes hard drives of different sizes, a dedicated parity drive protects the data, and Docker containers and virtual machines run alongside. Everything is managed via the web UI on port 80/443; Community Applications provides the app store, API keys and a GraphQL interface handle automation.
