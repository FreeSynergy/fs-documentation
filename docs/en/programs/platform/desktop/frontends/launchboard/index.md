# LaunchBoard

> Category: [desktop](../../index.md)

## What it is

LaunchBoard is a **commercial, proprietary homelab dashboard**: boards are built by drag and drop without configuration files, widgets deliver live data for containers, media and network services, and access runs through local accounts or OAuth/OIDC. It is available as a **cloud subscription** or as a **self-hosted container**.

> Note on factual accuracy: LaunchBoard does **not publish a freely accessible API reference**. Information on prices, image names and endpoint paths is found in the customer portal; where this cannot be verified here, it is explicitly marked as "not publicly documented".
