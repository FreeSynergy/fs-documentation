# Raycast - Description

## What the program does

Raycast replaces several small utilities with one window opened by a hotkey. The user types; results mix installed applications, files, commands from built-in modules and from installed extensions. Many results offer further actions in an action panel.

## Differentiation

| System | Difference |
|--------|------------|
| Alfred | Similar launcher on macOS; workflows are built from connected objects. Raycast extensions are code with a shared component library. |
| KDE Plasma | A whole desktop shell; Raycast is a layer over an existing system. |
