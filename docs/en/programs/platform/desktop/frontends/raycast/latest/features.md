# Raycast - Features

## Documented modules (manual table of contents)

- Core: snippets, quicklinks, clipboard history, notes, focus, file search, applications, extensions, translate, emoji and symbols, calendar, calculator, screenshots, window management, navigation.
- Basics: search bar, action panel, command aliases and hotkeys, keyboard shortcuts, import and export, settings.
- Power features: hyper key, cloud sync, dynamic placeholders, system commands, script commands, themes, auto quit.
- AI: quick AI, chat, dictation, screen awareness, AI commands and extensions, agents, MCP, local models, custom providers, bring your own key.
- iOS: keyboard, widgets and controls, link to Apple Shortcuts, share extension.
- Teams and enterprise: accounts, billing, teams, SSO, SCIM, MDM, admin controls.
