# Alfred - Features

## Powerpack features (vendor page)

- Workflows: connect objects, start by hotkey, keyword or remote button.
- Clipboard history: text, images and file paths, searchable.
- Snippets: text expanded from a short keyword; can be created from clipboard history.
- Universal actions, including a preview of Markdown, images, PDFs and text.
- File actions: keyboard navigation, Quick Look, email, move, copy, reveal.
- 1Password bookmarks, contacts (view, email, call), running commands in Terminal.

## Other (help sections)

Custom web searches, calculator, appearance themes, Alfred Remote, troubleshooting file indexing.
