# Alfred

> Category: [desktop](../../index.md)

## What it is

Alfred is a launcher and productivity tool for macOS: a hotkey opens an input field to launch apps, find files, search the web and run actions. A paid add-on called Powerpack unlocks workflows and more.

## Notable ideas

- **Workflows without code**: objects (triggers, inputs, actions, outputs) are connected on a canvas and started by hotkey, keyword or a button in a companion remote app.
- **Universal and file actions**: pick an item, then choose what to do with it from the keyboard.
- **One-time purchase** instead of a subscription.
- Listed here for the idea of connecting small building blocks into personal commands (ADR 0013).
