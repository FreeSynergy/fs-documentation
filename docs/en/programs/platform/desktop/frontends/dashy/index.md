# Dashy Documentation

## Overview

Dashy is a customizable self-hosted dashboard for your own network: app tiles, status indicators, widgets, themes and search are described via `conf.yml` (or JSON) and can optionally be edited in an interactive interface. An optional REST API reads and writes the configuration.

## File structure

- [menu.md](latest/menus.md) - Header, settings panel, right-click menus, roles
- [features.md](latest/features.md) - Tiles, status checks, widgets, themes, authentication
- [description.md](latest/description.md) - Description and distinction from Homarr, Heimdall and Homer
- [structure.md](latest/layout.md) - UI/UX, sections, grid and view variants
- [shortcuts.md](latest/shortcuts.md) - Keyboard control (typing searches, `Esc`, `Alt+Enter`, hotkeys)
- [api.md](latest/api.md) - Optional REST API, authentication, config access
