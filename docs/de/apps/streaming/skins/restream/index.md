# Restream Dokumentation

## Übersicht

Restream (restream.io) ist ein **Cloud-Multistreaming-Dienst**: Ein Encoder-Sendestrom wird angenommen und gleichzeitig an viele Plattformen (YouTube, Twitch, Facebook, LinkedIn, TikTok u. a.) weitergegeben. Dazu kommen Browser-Studio, einheitlicher Chat, Events/Planung und Analytics. Kein Selbstbetrieb — alles läuft über das Web-Dashboard und dessen APIs.
