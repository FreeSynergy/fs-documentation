# OBS Studio - Tastatur-Shortcuts

## Übersicht

Shortcuts heißen in OBS **Hotkeys** und werden vollständig unter *Einstellungen → Hotkeys* vergeben. Viele sind ab Werk unbelegt.

> Stand: OBS Studio 30.x/31.x.

## Szenenwechsel (Vorgabe, meist leer)

| Aktion | Belegung |
|--------|----------|
| Szene 1–9 wechseln | frei wählbar (häufig `F1`–`F9`) |
| Vorherige Szene | frei wählbar |
| Nächstes/ vorheriges Szenen-Set (Ordner) | frei wählbar |

## Stream und Aufnahme

| Aktion | Standard |
|--------|----------|
| Streaming starten/beenden | ❌ unbelegt (empfohlen: `Ctrl+Shift+S`) |
| Aufnahme starten/beenden | ❌ unbelegt (empfohlen: `Ctrl+Shift+R`) |
| Alle Aufnahmen stoppen | ❌ unbelegt |
| Replay-Puffer speichern | ❌ unbelegt (empfohlen: `Ctrl+S`) |
| Studio-Modus umschalten | ❌ unbelegt |

## Produktion

| Aktion | Standard |
|--------|----------|
| Übergang ausführen | `Return` (im Studio-Modus) |
| Quelle stummschalten | Quelle auswählen + `M` nicht vorhanden → Hotkey je Quelle |
| Alle Quellen stummschalten | ❌ |
| Virtuelle Kamera starten/stoppen | ❌ |
| Vollbild-Projektion Ausgang/Vorschau | ❌ |

## Programmbedienung

| Shortcut | Funktion |
|----------|----------|
| `Tab` / `Shift+Tab` | Dock-Elemente wechseln |
| `Alt + Klick` auf Quelle | Zuschneiden-Modus |
| `Strg + Klick` auf Quelle | Transformations-Reset (Rechtsklick-Menü Alternative) |
| `Esc` | Kontextmenü/Vorschau-Overlay verlassen |

## Nicht vorhanden (bewusst)

| Angenommen | Status |
|------------|--------|
| Eingebaute Kommandopalette | ❌ |
| Globaler „Notaus“-Hotkey (alles stoppen) | ❌ |
| Undo für Szenenlöschung | ❌ (nur für letzte Änderung im Bearbeiten-Menü) |

## Mac

`Cmd` statt `Strg` bei Programmaktionen; Hotkeys für Szenen sind ebenfalls frei belegbar.
