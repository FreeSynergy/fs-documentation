# Google Kalender - Tastatur-Shortcuts

## Übersicht

Google Kalender (Weboberfläche) **hat echte, offiziell dokumentierte Tastaturkürzel**. Sie sind einzelbuchstabig und greifen nur, wenn gerade kein Textfeld fokussiert ist - beim Tippen in Titel, Suche oder Beschreibung schreiben die Tasten Text. Die vollständige, aktuelle Liste zeigt die Anwendung selbst: Zahnrad → **Tastatur-Shortcuts** oder die Taste `?`. Mobile Apps (Android, iOS) haben **keine eigenen Shortcuts**; eine angeschlossene physische Tastatur folgt den Betriebssystem-Standards.

> Stand: Weboberfläche von Google Kalender. Google ändert Kurzbefehle gelegentlich; vor dem Einsatz die In-App-Übersicht (`?`) prüfen. Als "nicht dokumentiert" markierte Kürzel sind nicht verlässlich.

---

## Allgemein

| Shortcut | Funktion |
|----------|----------|
| `?` | Übersicht aller Tastenkürzel öffnen |
| `c` | Neuen Termin anlegen |
| `q` | Termin per Schnellerstellung anlegen (Freitext) |
| `t` | Zum heutigen Datum springen |
| `s` | Einstellungen öffnen |
| `p` | Drucken (Druckdialog) |
| `Esc` | Popup, Dialog oder Suchergebnisse schließen |
| `Backspace` / `Entf` | Im Suchfeld: Text löschen; im Raster: markierten Termin löschen |
| `F5` / `Ctrl+R` | Seite neu laden (Browser) |

## Bearbeiten (mit fokussiertem Termin)

Termine werden mit `Tab` angesteuert; erst danach wirken die Kürzel.

| Shortcut | Funktion |
|----------|----------|
| `Enter` | Termindetails anzeigen |
| `e` | Termin bearbeiten (Voll-Editor) |
| `Backspace` / `Entf` | Termin löschen (mit Nachfrage bei Serienterminen) |
| `Esc` | Popup oder Editor ohne Speichern schließen |
| `Enter` (im Dialog) | Standardaktion "Speichern"/"Fertig" auslösen |
| `Tab` / `Shift+Tab` | Felder im Termin-Editor durchlaufen |
| `Space` | Checkboxen (Ganztägig, Gastrechte) umschalten, Schalter aktivieren |
| `↑` / `↓` | In Auswahllisten (Kalender, Erinnerung, Wiederholung) blättern |
| `Backspace` | Inhalt des fokussierten Textfelds löschen |

**Nicht vorhanden:**

| Erwarteter Shortcut | Status |
|---------------------|--------|
| `Ctrl+C` / `Ctrl+V` für Termin kopieren | ❌ Nicht vorhanden - dafür "Duplizieren" im Drei-Punkte-Menü oder `c` mit angepassten Werten |
| `Ctrl+Z` für Rückgängig | ⚠️ In der Kurzreferenz nicht eindeutig dokumentiert - der **Rückgängig-Hinweis** (Toast) nach einer Änderung ist der offizielle Weg |
| Pfeiltasten zum Verschieben eines Termins | ❌ Nicht vorhanden - Verschieben nur per Drag & Drop (Maus/Touch) |
| `Entf` ohne vorherige Markierung | ❌ Ohne fokussierten Termin passiert nichts |
| Modus-Umschaltung (Ansichts-/Bearbeitungsmodus) per Taste | ❌ Gibt es nicht - Google Kalender hat keinen Bearbeitungsmodus |

| Shortcut | Funktion |
|----------|----------|

| `q` | Schnellerstellung: Terminbeschreibung als Satz eintippen, `Enter` bestätigt |

| `↑` / `↓` | Werte in Datums-/Uhrzeitauswahl und Listen ändern |
| `Space` | "Ganztägig" und Gastrechte umschalten |

## Mac-Varianten

Die einzelbuchstabigen Kürzel (`c`, `q`, `t`, `d`, `w`, `m`, `a`, `u`, `f`, `g`, `/`, `s`, `p`, `?`) gelten unter macOS unverändert. Browserbezogene Tasten nutzen `Cmd` statt `Strg`:

| Shortcut | Funktion |
|----------|----------|
| `Cmd+R` | Neu laden |
| `Cmd+P` | Drucken |
| `Cmd+F` | Text auf der Seite suchen (Browser, nicht Google Kalender) |
| `Cmd+K` | Adressleiste fokussieren (Browser) |
| `Cmd+↑` / `Cmd+↓` | Seitenanfang/-ende (Browser) |
| `Cmd+Plus` / `Cmd+Minus` | Oberfläche vergrößern/verkleinern |
| `Cmd+0` | Zoom zurücksetzen |
| `Esc` | Popup/Dialog schließen |
| `Fn`-Tastenkürzel | Systemsprache/Emoji-Auswahl (macOS, nicht Kalender) |

**Nicht vorhanden:** `Cmd+E` als globale Kalenderaktion außer mit fokussiertem Termin, `Cmd+K` als Kalender-Befehlspalette (❌ existiert nicht), `Cmd+Z` als Rückgängig (⚠️ nicht dokumentiert).

## Zusammenfassung

Google Kalender bietet **richtige, dokumentierte Kurzbefehle** für Ansicht, Sprungziele, Suche und Terminanlage:

- **`c` / `q`** anlegen, **`t`** heute, **`g`** Datum, **`d`/`w`/`m`/`a`/`x`** Ansichten, **`u`/`f`** blättern, **`/`** suchen, **`s`** Einstellungen, **`?`** Hilfe
- **`Tab` + `Enter`/`e`/`Entf`** für Termine, **`Esc`** zum Abbrechen
- **Rückgängig** über den Hinweis nach der Änderung, nicht über eine dokumentierte Taste
- **Keine Shortcuts** in den mobilen Apps; Verschieben und Umskalieren bleiben Maus- und Touch-Aufgaben

Wer die Kürzel deaktivieren möchte, findet die Schalter beim Anlegen von Terminen nicht - die Kurzbefehle der Weboberfläche sind fest aktiviert und lassen sich laut Help-Center nicht abschalten.
