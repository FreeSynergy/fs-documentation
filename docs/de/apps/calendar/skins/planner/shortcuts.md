# GNOME Planner - Tastatur-Shortcuts

## Übersicht

Planner nutzt überwiegend GTK-Standardtasten; echte Planner-eigene Kurzbefehle sind sparsam dokumentiert. Was nicht offiziell belegt ist, steht unten als „nicht dokumentiert".

> Stand: Planner 0.14x (GTK3). Nach Updates prüfen.

## Datei

| Shortcut | Funktion |
|----------|----------|
| `Strg+N` | Neues Projekt |
| `Strg+O` | Öffnen |
| `Strg+S` | Speichern |
| `Strg+Shift+S` | Speichern unter |
| `Strg+P` | Drucken (aktive Ansicht) |
| `Strg+W` / `Strg+Q` | Fenster schließen / beenden |

## Bearbeiten

| Shortcut | Funktion |
|----------|----------|
| `Strg+Z` / `Strg+Shift+Z` | Rückgängig / Wiederholen |
| `Strg+C` / `Strg+V` / `Strg+X` | Kopieren / Einfügen / Ausschneiden (Zeilen) |
| `Entf` | markierte Aufgabe/Ressource löschen |

## Navigation und Ansichten

| Shortcut | Funktion |
|----------|----------|
| `Tab` / `Pfeiltasten` | durch Aufgabenbaum/Tabellen |
| `Bild auf/ab` | Liste scrollen |
| `Strg+1` / `Strg+2` / `Strg+3` | Ansichten Aufgaben/Ressourcen/Abhängigkeiten — **(nicht dokumentiert; in aktuellen Versionen per Tabs/klicken)** |

## Aufgaben

| Shortcut | Funktion |
|----------|----------|
| `Einfg` | neue Aufgabe unter der markierten — **(nicht dokumentiert; Anlage sicher über Menü/Rechtsklick)** |
| `Enter` | Zellbearbeitung (Dauer, Name) beginnen |
| `F2` | Zellbearbeitung — GTK-Standard, in Planner-Versionen unterschiedlich |

## Mac-Varianten

Planner läuft nativ unter Linux; auf dem Mac (Homebrew-Build) ersetzt `Cmd` die `Strg`-Taste.

## Ausdrücklich nicht vorhanden

- Keine One-Klick-Taste für Meilensteine (Menü „Aufgaben → Neuer Meilenstein")
- Keine Shortcuts für Abhängigkeitstypen (Dialog)
