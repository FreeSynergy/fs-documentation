# Organic Maps Dokumentation

## Übersicht

Organic Maps (GPL, Abo-freie Nonprofit-App) ist die schlanke Offline-Karten-/Navigations-App (Android/iOS/Desktop): schnell, datensparsam (keine Tracking-Werbelogik), OSM-basiert, mit eigenen Orten (Bookmarks) und Offline-Routing.

## Dateistruktur

- [menu.md](menu.md) - Suchleiste, Kategorien, Ebenen-Menü, „Gespeichert“
- [features.md](features.md) - Offline-Routing, Bookmarks, Was Organic Maps NICHT kann
- [description.md](description.md) - Abgrenzung zu OsmAnd, Google Maps, MagicEarth
- [structure.md](structure.md) - Vollbildkarte, Such-/Detailsheets
- [shortcuts.md](shortcuts.md) - Gestensteuerung
- [api.md](api.md) - Geo-Intents, Bookmark-Dateiformate (.bm2/.kml), keine API
