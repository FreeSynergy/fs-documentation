# Organic Maps - Beschreibung

## Was das Programm macht

Organic Maps ist OSM für die Hosentasche: Karte auf, Ziel rein, loslaufen — alles offline, alles ohne Konto. Es verzichtet bewusst auf Funktionsberge zugunsten von Tempo und Einfachheit.

## Vorteile

- **rasend schnell** (C++-Rendering, kompakte Daten)
- **bookmarks als teilbare Sammlungen** — unkomplizierte Gruppenlösung
- Nonprofit-Modell (Abo optional), F-Droid-Version

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **OsmAnd** | Feature-Fülle; Organic Maps Fokus |
| **Google Maps** | live/proprietär; Organic offline/offen |
| **Locus** | Profi-Tool kommerziell; Organic gemeinnützig |

## Technische Details

- **Stack**: C++ (Maps.me-Nachkomme), Android/iOS, Desktop-Vorschau
- **Daten**: .mwm-Regionen (OSM, ODbL)
- **Authentifizierung**: keine nötig
- **Lizenz**: GPL (2.0+)

## Für wen geeignet

- Gelegenheits-Naviagation + schlichte Gruppenpunkte (Alternative zu OsmAnd in [standpunkte.md](../../standpunkte.md))
