# Organic Maps - Menüpunkte

## Hauptflächen

| Element | Inhalt |
|---------|--------|
| Suchfeld (unten) | Adressen/POI/Kategorien (Offline-Suche) |
| Kategorien-Grid (Karte leer) | Gastronomie, Einkaufen, Health, Outdoor … |
| Ebenen-Schicht-Icon (rechts) | Konturlinien, Overlays (Fahrrad/Winter), 3D-Gebäude |
| Kompass/Layer-Buttons | Nord-Ausrichtung, Maßstab |
| „Gespeichert“ (unten Reiter) | Favoriten, Listen/Sammlungen, Tracks |

## Detailsheet (POI-Blatt)

- Name, Adresse, Öffnungszeiten (wenn getaggt), „Route bauen“, „Teilen“, Notiz-Feld

## Einstellungen

| Bereich | Inhalt |
|---------|--------|
| Karten-Download | Regionen automatisch/wlan |
| Bookmarks | Import/Export (`.kml`, `.bm2`), „Als KML speichern“ |
| Navigation | Sprachpaket, Fahrzeugprofile |

## Menüs nach Rolle

keine Konten/Rollen (bewusst lokal).
