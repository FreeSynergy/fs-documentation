# OsmAnd - Tastatur-Shortcuts

## Übersicht

OsmAnd ist eine Touch-App: **keine Tastatur-Shortcuts**, Steuerung über Gesten/Kontextmenüs (Bluetooth-Tastatur wird nicht als Steuerweg beworben).

> Stand: OsmAnd 4.x.

## Gesten statt Shortcuts

| Geste | Funktion |
|-------|----------|
| Tippen | Karte zentrieren |
| Doppeltippen | Zoom hinein |
| Zwei Finger | Zoom/Rotieren/Kippen (3D) |
| Langtippen | Kontextmenü (Ziel setzen, Notiz, Route) |
| Wischen | Karte bewegen |

## Externe Steuerung

- Android-Intents als „Kurzbefehl von außen“ (siehe [api.md](api.md))
