# OsmAnd Dokumentation

## Übersicht

OsmAnd (Apache-2.0) ist die Offline-Navigations-App auf OSM-Basis (Android/iOS): herunterladbare Kartenregionen, Routing (Auto/Rad/Fuß/ÖPNV-Routenplan offline möglich), POI-Suche, Track-Aufzeichnung, „My Places“ mit eigenen Punkten/Ebenen — der OSMPlus-Geist: Open-Source-Karten-App voller Funktionen.
