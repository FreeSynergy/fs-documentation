# Leaflet - Menüpunkte

## Eingebaute Steuerelemente („Controls“)

| Control | Inhalt |
|---------|--------|
| Zoom (+/−) | Stufenweise, Mausrad/Doubleclick optional |
| Layers-Box | Radio/Checkbox für Basis-/Overlay-Ebenen |
| Scale | Maßstabsbalken (metrisch/imperial) |
| Attribution | Pflicht-Credits je Layer (OSM-Hinweis!) |

## Was der Entwickler daraus baut

- eigene Toolbars (Buttons `L.Control`), Draw-Plugin-Werkzeugkästen (FeatureGroup-Editoren)
- Popups/Tooltips als Mikro-Menüs (HTML-in-Karte)

## Menüs nach Rolle

Built-in-Rollen: keine — Rollen/Rechte sind Sache der Aufrufer-App.
