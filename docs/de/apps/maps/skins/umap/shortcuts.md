# uMap - Tastatur-Shortcuts

## Übersicht

uMap hat **keine dokumentierten Kurzbefehle**; Leaflet-Maus/Touch-Standard genügt.

> Stand: uMap (2026).

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `+` / `-` (Tasten) | Zoom (Leaflet) |
| `Esc` | Popup/Dialog schließen |
| `Tab`/`Enter` | Popup-Formulare |
| `Strg/Cmd+Scroll` | Zoom |

## Ausdrücklich nicht vorhanden

- Palette, Werkzeugbuchstaben

## Mac

`Cmd` bei Browser-Standards.
