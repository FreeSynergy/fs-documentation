# OpenStreetMap - Tastatur-Shortcuts

## Übersicht

Kurzbefehle gehören zum Editor, nicht zur Karte: **iD** (Web) und **JOSM** (Desktop) haben umfangreiche, dokumentierte Listen.

> Stand: iD 2.x / JOSM stabil (2026).

## iD (Web-Editor)

| Shortcut | Funktion |
|----------|----------|
| `?` | Shortcuts-Overlay |
| `Strg/Cmd+Z` / `+Shift+Z` | Undo / Redo |
| `Strg/Cmd+C` / `+V` / `+X` | Kopieren / Einfügen / Ausschneiden |
| `Enter` | Preset/Tag-Eingabe bestätigen |
| `Esc` | Auswahl/Panel schließen |
| `Tab`/`Shift+Tab` | Feldnavigation |
| `+` / `-` | Zoom |

## JOSM (Desktop)

| Shortcut | Funktion |
|----------|----------|
| `s` / `w` / `p` | Mapmodes: Auswahl / Gehen / Linie (Menübestätigung empfohlen) |
| `Strg+Z` / `Strg+Y` | Undo / Redo |
| `Strg+A` | alles auswählen |
| `Entf` | Auswahl löschen (mit Warnung) |
| `F6` / `F7` … | Preset-Anwenden etc. — Menü `Werkzeuge → Shortcuts` prüfen |
| `Hochladen` | `Strg+Shift+O` (Changeset-Dialog) — Stand prüfen |

## Kartenansicht openstreetmap.org

| Shortcut | Funktion |
|----------|----------|
| `+`/`-`, Pfeiltasten | Zoom/Verschieben (Maus-Primat) |

## Mac

`Cmd` bei Web-Editoren; JOSM Linux-/Mac-Builds nutzen `Strg`/`Cmd` je Platform.
