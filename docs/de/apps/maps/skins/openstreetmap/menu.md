# OpenStreetMap - Menüpunkte

## openstreetmap.org (Kartenansicht)

| Element | Inhalt |
|---------|--------|
| Suchleiste | Nominatim-Geocoding (Orte, Adressen) |
| Ebenen-Reiter | Standard/Cycle/Trace (Kachelauswahl) |
| Layers-Schalter | Basis, Beschriftungen, Bild-Overlays |
| Richtungs-Pfeil | Routing (OSRM/GraphHopper/Valhalla, ÖPNV via ÖPNV-Karten) |
| „Share“ | Ausschnitt-Links, Embed-Code |
| Notiz-„+“ | Fehlerhinweise auf der Karte (nicht Editieren) |

## Bearbeiten (Login)

- **iD-Editor** (Web): Punktauswahl, Presets (Bahnhof, Laden…), Formen, Rechtecke, Rohlinge
- **JOSM** (Desktop-Java): volles Datenmodell, Plugins, Preset-Reiter, „Änderungen hochladen“

## Community-Menüs (oben)

| Menü | Inhalt |
|------|--------|
| Log-in/Anmelden | OSM-Konto (auch OAuth-Provider für Dritt-Apps) |
| Aufzeichnungen (GPS Traces) | eigene Tracks hochladen/öffentlich teilen |
| Nutzer/Changesets/Notizen | Aktivitäten ansehen |
| Help/About/Wiki | Community-Ressourcen (wiki.openstreetmap.org) |

## Editor-Flächen (iD)

- linke Preset-Leiste, rechtes Feld-Panel (Tags), „Fertig“-Dialog mit Changeset-Kommentar
