# OpenStreetMap - Beschreibung

## Was das Programm macht

OpenStreetMap sind **die Daten**, nicht eine Anwendung: Freiwillige erfassen Straßen, POIs, Gewässer; Dienste (uMap, OsmAnd, GraphHopper…) bauen darauf. Der Web-Auftritt ist Startpunkt: Karte ansehen, Notizen, im Browser editieren.

## Vorteile

- **frei nutzbar (ODbL)**, weltweit, aktuell in aktiven Städten
- **offene API-Kette**: Edit → Diff-Dateien → Overpass — Automatisierung ohne Lizenzverhandlung
- Belebte Community mit Foren/Mailinglisten (de.regionale Gruppen)

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Google/Apple Maps** | proprietäre Daten; OSM = offene Daten + Community |
| **MapLibre/Leaflet** | Rendering-/Kartenbibliotheken; OSM = der Datenbestand |
| **kommerzielle POI-Anbieter** | kuratiert/lizenziert; OSM = crowdsourct |

## Technische Details

- **APIs**: OSM API 0.6 (OSM-XML/PBF), Overpass, Nominatim, Diff-Downloads (planet.osm)
- **Konto**: OSM-Login, OAuth2 für Dritt-Apps
- **Lizenz**: ODbL (Namensnennung, Share-Alike für abgeleitete Daten)

## Für wen geeignet

- alle Kartenskins — OSM ist die gemeinsame Datenbasis (siehe [Standpunkte-Doku](../../standpunkte.md))
