# MapLibre - Menüpunkte

## Eingebaute Controls

| Control | Inhalt |
|---------|--------|
| NavigationControl | Zoom + Kompass (Pitch/Yaw-Reset) |
| GeolocateControl | Standort-Button (Browser-API) |
| ScaleControl | Maßstab |
| AttributionControl | Credits (kurz/voll) |
| FullscreenControl | Vollbild |

## Stil-Werkzeuge (offiziell gepflegt)

| Werkzeug | Inhalt |
|----------|--------|
| **Maputnik** | Stil-Studio im Browser (Layer, Farben, Texte, Sprites/Glyphs) |
| Style-Spec-Doku | JSON-Schema der Kartenstile |

## Menüs nach Rolle

Bibliothek ohne Nutzerrollen; Stil-/Kachel-Verwaltung liegt beim Betrieb (S3/Tiler).
