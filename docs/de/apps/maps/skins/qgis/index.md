# QGIS Dokumentation

## Übersicht

QGIS (GPL) ist das professionelle Desktop-GIS: Layer (Shapefile/GeoPackage/PostGIS/WMS), Analyse-Werkzeuge (Puffer, Überlagerungen, Geoprocessing), Druck-Layouts, **QGIS Server** (OGC-Dienste) und Python (PyQGIS). De-facto-Standard im offenen Geowesen.

- [features.md](features.md) - Analysen, Drucken, Server, Was QGIS NICHT kann
- [description.md](description.md) - Abgrenzung zu ArcGIS, uMap, Leaflet
- [structure.md](structure.md) - Layertree, Kartenansicht, Browser-Panel, Processing
