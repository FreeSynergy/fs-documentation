# QGIS - Menüpunkte

## Menüleiste (Klassen)

| Menü | Inhalt |
|------|--------|
| Projekt | Neu/Öffnen (QGS), Eigenschaften (CRS!), Druck-Layouts |
| Bearbeiten | Layer editierbar schalten, Einfügen/Verschieben, Digital-Werkzeuge |
| Vektor | Geometrien, Analysen (Puffer, Convex Hull), Data-Management |
| Raster | Analyse, Proben, Mosaiken |
| Datenbank | DB-Manager (PostGIS/GeoPackage/Layer import/export) |
| Verarbeitung | **Processing-Toolbox** (hundert Algorithmen, Modelle bauen) |
| Plugins | Installieren/Verwalten (Grass7, QuickMapServices, Profile-Tools…) |
| Vector-Werkzeuge + Kartenwerkzeuge (Symbolleisten) | Snapping, Messlinie, Auswahlen, Identify |

## Panels

| Panel | Inhalt |
|-------|--------|
| Layer (Baum) | Reihenfolge, Gruppen, Bezeichner |
| Browser | Datenquellen (Ordner, DBs, WMS/WFS-Kataloge) |
| Koordinaten-/Zeitsteuerung | Nudge/Spatio-temporal |

## Menüs nach Rolle

QGIS ist Einzelplatz; Server-Rollen (OGC-Zugriff) je Dienst-Konfiguration.
