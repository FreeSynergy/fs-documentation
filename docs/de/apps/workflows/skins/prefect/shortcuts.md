# Prefect - Tastatur-Shortcuts

## Übersicht

Prefect dokumentiert nur eine globale Such-/Sprungpalette; sonst keine Kurzbefehle.

> Stand: Prefect 3.x.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Strg/Cmd+K` (bzw. `⌘K`) | Such-/Befehlspalette (UI) — Version prüfen |
| `Esc` | Dialoge/Drawer schließen |
| `Tab`/`Enter` | Formularnavigation |

## Ausdrücklich nicht vorhanden

- keine Run-/Pause-Tasten im Stil von Airflow-Tabellenaktionen

## Zentrale Befehle = CLI

| Befehl | Wirkung |
|--------|---------|
| `prefect deployment run <name>` | Run starten |
| `prefect deployment pause/resume` | Zeitplan |
| `prefect worker start --pool …` | Infrastruktur starten |
