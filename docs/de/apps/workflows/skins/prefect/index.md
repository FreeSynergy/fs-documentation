# Prefect Dokumentation

## Übersicht

Prefect (Apache-2.0) ist modernes Workflow-Orchestering in Python: `@flow`/`@task`-Dekoratoren, Deployments (Work Pools/Workers), Scheduling, Events/Automations, Observability-UI. Self-hosted Server oder Prefect Cloud.

- [features.md](features.md) - Deployments, Events, Was Prefect NICHT kann
- [description.md](description.md) - Abgrenzung zu Airflow, Dagster, n8n
- [structure.md](structure.md) - Flow/Task/Deployment-Objekte, Run-Logs
- [shortcuts.md](shortcuts.md) - Kurzbefehle (keine)
- [api.md](api.md) - REST-API (flows/deployments/runs), Events API
