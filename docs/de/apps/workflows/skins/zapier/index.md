# Zapier Dokumentation

## Übersicht

Zapier ist die größte SaaS-Automatisierungsbibliothek (8.000+ Apps): „Zaps“ verknüpfen Trigger→Aktionen, mehrstufige Zaps und Paths für Verzweigungen, Interfaces/Tables/Forms als Mini-Apps. Kein Self-Hosting; API für eigene Integrationen und Plattform-Partner.
