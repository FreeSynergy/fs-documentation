# Zapier - Beschreibung

## Was das Programm macht

Zapier verbindet Apps ohne Infrastruktur: Trigger einer App starten Aktionen in anderen. Der Wert liegt in der Auswahl (8.000 Apps) und der Null-Wartung — der Preis in Tasks, Polling-Latenz und Cloud-Zwang.

## Vorteile

- **größte App-Bibliothek**, sofort einsatzbereit
- **Interfaces/Tables** ersetzen kleine Eigenbauten
- Platform-API: eigene Kunden-App als Zap-Connector veröffentlichen

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Make** | günstigere Operations, visuell tiefer; Zapier hat mehr Apps |
| **n8n** | self-hosted/kostenkontrolliert; Zapier fully managed |
| **Power Automate** | M365-Fokus; Zapier neutral |

## Technische Details

- **Modell**: SaaS (US), EU-Datenaufbereitung über Sub-Processor-Setups (DSGVO-Kapitel in Trust-Center)
- **Auth**: OAuth2/Keys pro App; API: Session-/Secret-Token, OAuth2 für Partner
- **Preise**: Free (100 Tasks) → Professional/Team/Enterprise

## Für wen geeignet

- Fachteams, die sofort breite App-Abdeckung brauchen
- FreeSynergy-Skins: Zap-Metapher (Trigger→Steps) als niedrigster Einstieg für Automatisierungs-Templates
