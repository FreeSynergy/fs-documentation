# Zapier - Menüpunkte

## Zap-Editor

| Element | Inhalt |
|---------|--------|
| Trigger-Step | App + Trigger-Event (Instant/Polling), Testdaten abrufen |
| Action-Steps (+) | Apps/Aktionen hintereinander, „Format“ (Text/Code/Daten-Umwandlung) |
| Paths | Verzweigungen („Wenn Bedingung A…“ / „sonst…“) |
| Test/Publish | Schritt-Tests, Name, Auto-Reload |

## Workspace-Menüs

| Menü | Inhalt |
|------|--------|
| Zaps | Liste, Ordner, Geteilte Zaps |
| Explorer | Vorlagen (tausende), App-Kombinationen |
| Tables | Tabellen (Records, Automationen) |
| Interfaces | Formulare/Mini-Webseiten aus Zap-Logik |
| Forms | Formulare als Zap-Auslösung |
| Analytics/Catalog | Run-Historie, Metriken; Enterprise: App-Steuerung |
| Settings | Verbindungen, Einladungen, Pläne/API-Keys für eigene Integrationen |

## Developer-Bereich (platform.zapier.com)

- Zapier Platform: eigene App-Definitionen (UI-Builder/CLI `zapier`), Prefill-Webhooks, OAuth-Setups

## Menüs nach Rolle

Admin · Member · Limited (Zaps ansehen) · Zap-Besitzer; Enterprise-Workspaces mit Governance.
