# Dashy Dokumentation

## Übersicht

Dashy ist ein anpassbares Self-Hosted-Dashboard für das eigene Netzwerk: App-Kacheln, Statusanzeigen, Widgets, Themes und Suche werden über `conf.yml` (oder JSON) beschrieben und lassen sich optional in einer interaktiven Oberfläche bearbeiten. Eine optionale REST-API liest und schreibt die Konfiguration.

## Dateistruktur

- [menu.md](menu.md) - Kopfzeile, Einstellungspanel, Rechtsklick-Menüs, Rollen
- [features.md](features.md) - Kacheln, Statusprüfungen, Widgets, Themes, Authentifizierung
- [description.md](description.md) - Beschreibung und Abgrenzung zu Homarr, Heimdall und Homer
- [structure.md](structure.md) - UI/UX, Sektionen, Raster und Ansichtsvarianten
- [shortcuts.md](shortcuts.md) - Tastatursteuerung (Tippen sucht, `Esc`, `Alt+Enter`, Hotkeys)
- [api.md](api.md) - Optionale REST-API, Authentifizierung, Config-Zugriff
