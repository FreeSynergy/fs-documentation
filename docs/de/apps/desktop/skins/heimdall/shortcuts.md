# Heimdall - Tastatur-Shortcuts

## Übersicht

Heimdall stellt **keine eigenen Tastatur-Shortcuts** bereit und dokumentiert auch keine. Die Bedienung folgt den üblichen Browser-Tasten und den Standardtasten der HTML-Formulare. Diese Datei hält fest, was tatsächlich funktioniert, und markiert verbreitet erwartete Shortcuts ausdrücklich als **nicht vorhanden**.

> Stand: aktuelle Heimdall-Versionen (v2.x). Details können sich mit Updates ändern.

---

## Allgemein (Browser-Standard)

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Zum nächsten Bedienelement (Link, Feld, Schaltfläche) springen |
| `Shift+Tab` | Vorheriges Bedienelement wählen |
| `Enter` | Fokussierte Kachel öffnen, Formular speichern |
| `Space` | Checkbox „in neuem Tab öffnen“ umschalten |
| `Esc` | Dialogfeld des Browsers abbrechen, Fokus aus manchen Feldern |
| `F5` / `Ctrl+R` | Seite neu laden (Statistikwerte werden neu geholt) |
| `Alt+←` | Zurück zur vorherigen Seite (Browser) |
| `Strg+P` | Startseite ausdrucken |

## Navigation auf der Startseite

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Panels und Kacheln in Lesereihenfolge ansteuern |
| `Enter` | Angekommene Kachel öffnet die Ziel-URL |
| `↑` / `↓` | In Auswahllisten (Suchmaschine, Enhanced-App-Typ) blättern |
| `Leertaste` | Auswahlliste öffnen, wenn sie fokussiert ist |
| `Pos1` / `Ende` | Seitenanfang / -ende (Browser) |

**Nicht vorhanden:**

| Gewünschter Shortcut | Status |
|----------------------|--------|
| `/` für Suchfeld | ❌ Nicht vorhanden — Suchfeld muss angeklickt oder per `Tab` erreicht werden |
| Ziffern `1`–`9` für Kacheln | ❌ Nicht vorhanden |
| Buchstaben-Schnellstart einer App | ❌ Nicht vorhanden |
| `↑`/`↓` zum Wechseln zwischen Panels | ❌ Nicht vorhanden — nur Scrollen oder Tastatur-Scrollen |

## Bearbeitung (Apps, Panels, Layout)

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Bearbeitungssymbole an der Kachel und Dialogfelder erreichen |
| `Enter` | Dialog „App bearbeiten“ öffnen bzw. speichern |
| `Esc` | Browser-Dialog („Wirklich löschen?“) abbrechen |
| `Backspace` | Text in Titel-/URL-Feldern löschen |
| `Enter` (in URL-Feld) | Feld bestätigen, nicht die App öffnen |

### Kacheln und Panels anordnen

| Geste | Funktion |
|-------|----------|
| Ziehen an der Kachel | Kachel innerhalb des Panels verschieben |
| Kachel auf ein anderes Panel ziehen | Kachel in einen anderen Bereich einordnen |
| Ziehen an der Panel-Griffzone | Panels untereinander umsortieren |
| Panel-Werkzeug „umbrechen“ | Bereich teilen, damit Kacheln nebeneinander stehen |

**Nicht vorhanden:**

| Gewünschter Shortcut | Status |
|----------------------|--------|
| `e` für Layout-Bearbeitung | ❌ Nicht vorhanden — nur über die Einstellungs-Schaltfläche |
| `Entf` zum Löschen einer Kachel | ❌ Nicht vorhanden — Lösch-Symbol oder Dialog nutzen |
| `Strg+Z` für Rückgängig | ❌ Nicht vorhanden — Änderungen sind sofort gespeichert |
| Pfeiltasten zur Kachel-Umordnung | ❌ Nicht vorhanden — Drag & Drop mit Maus oder Touch |

## Suche

| Shortcut | Funktion |
|----------|----------|
| Klick in das Suchfeld + Text | Suchbegriff eingeben |
| `Enter` | Suche bei der eingestellten Suchmaschine starten |
| `Backspace` | Zeichen löschen |
| `Esc` | Kein eigenes Verhalten in Heimdall (Suchfeld bleibt gefüllt) |
| `Strg+F` | Text auf der Seite suchen (Browser), um App-Namen zu finden |

| `Enter` | Standardaktion „Speichern“ auslösen |
| `Space` | Schalter und Ankreuzfelder umschalten |

## Mac-Varianten

Unter macOS ersetzen `Cmd`-Kombinationen die `Strg`-Varianten.

| Shortcut | Funktion |
|----------|----------|
| `Cmd+R` | Neu laden, Statistikwerte aktualisieren |
| `Cmd+F` | Text auf der Seite suchen |
| `Cmd+P` | Drucken |
| `Cmd+K` | Adressleiste fokussieren (Browser) |
| `Cmd+↑` / `Cmd+↓` | Seitenanfang / -ende |
| `Cmd+Plus` / `Cmd+Minus` | Oberflächen-Zoom |
| `Cmd+0` | Zoom zurücksetzen |
| `Esc` | Browserdialog abbrechen |

**Nicht vorhanden:** `Cmd+E` (Layout-Bearbeitung), `Cmd+/` (Suchfeld), `Cmd+Z` (Rückgängig im Layout).

---

## Barrierefreie Bedienung

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Alle Links, Felder und Schaltflächen erreichbar |
| `Enter` | Kachel und Schaltflächen auslösen |
| `Esc` | Bestätigungsdialoge abbrechen |
| `↑` / `↓` | Auswahlfelder bedienen |
| `Shift+Tab` | Rückwärts navigieren |

**Einschränkung**: Das Umsortieren von Kacheln und Panels ist ausschließlich mit Zeigergeräten möglich, dafür existieren keine Tastaturbefehle.

---

## Zusammenfassung

Heimdall bietet **keine anwendungsspezifischen Shortcuts**. Nutzbar sind:

- **Browser-Tasten** für Neuladen, Suchen im Text, Drucken und Zoom
- **`Tab`, `Enter`, `Space`, `Esc`** in Formularen, Dialogen und Bestätigungsabfragen
- **Drag & Drop** für alle Layout-Änderungen

Schneller wird die Arbeit nicht über Tasten, sondern über Organisation: wenige Panels, eindeutige Kachelnamen und eine eingestellte Suchmaschine.
