# Helodesk - Menüpunkte

## Hauptnavigation

| Menü | Inhalt |
|------|--------|
| Contact Center | Wählscheibe, Anrufhistorie, Warteschlangen, IVR-BlindTRANSFER, Callback-Queues |
| Cases | Ticketlisten nach Status/Queue, eigene Cases, Fälligkeitsfilter |
| Contacts | Kontaktprofile mit Kanalkontext (Nummern, E-Mails, Historie) |
| Knowledge base | interne und Kundenartikel |
| Reports | Anrufstatistik, Case-SLA, Agentenlast |
| Administration | Nutzer/Rollen, Nummern und SIP, Mailboxen/Domain, IVR-Designer, Formulare/Custom Fields, Webhooks/API, Tarife |

## Case-Maske

- Aktionen: Status (New/Open/Pending/Closed), Zuweisung, Priorität, Tags, Kanalherkunft (Anruf/E-Mail/Chat/SMS)
- Kommunikationsblock: Anruf-Protokoll, E-Mail-Verlauf, Chat-Transkript, Notiz
- „Screen pop“: bei eingehendem Anruf öffnet sich Kontakt + Case-Vorlage

## Administration

| Bereich | Inhalt |
|---------|--------|
| Nummern | DID-Rufnummern, SIP-Trunk, Routing, IVR-Baum (Drag-Drop-Editor) |
| Kanäle | Mailbox-Ingest, Chat-/Callback-Widget (Embed-Skript), SMS-Absender |
| Workflows | Eskalationen, automatische Zuweisung nach Skills |
| API | API-Token, Webhook-Endpunkte, App-Einbindungen |

## Menüs nach Rolle

| Rolle | Sicht |
|-------|-------|
| Agent | eigene Cases + Softphone |
| Supervisor | Queues, Reports, Zuweisung |
| Admin | Administration voll |
