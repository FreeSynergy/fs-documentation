# Helodesk - Tastatur-Shortcuts

## Übersicht

Helodesk dokumentiert **keine umfassende Shortcut-Liste**. Nützliches ist Softphone- und Formular-Standard.

> Stand: Helodesk Web-App (2026). Einzelne Belegungen können sich ändern.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| Ziffern im Softphone | DTMF/Nummerneingabe |
| `Enter` | Formulare, Suchfeld |
| `Tab` | Felder |
| `Esc` | Dialoge schließen |
| `Strg/Cmd+F` | Browser-Suche in Case-Verlauf |

## Ausdrücklich nicht vorhanden

- keine Palette, keine Ein-Buchstaben-Case-Aktionen (Status nur per Dropdown)
- keine dokumentierte „Annehmen/Hängen“-Global-Taste (Softphone-Buttons; Headset-Signale funktionieren über WebRTC-Geräte)

## Mac

`Cmd` bei Browser-Standards.
