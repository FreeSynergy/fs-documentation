# Helodesk - Beschreibung

## Was das Programm macht

Helodesk bündelt Telefonie und schriftlichen Support in einer Oberfläche: Agenten tragen ein Softphone im Browser, Anrufe, E-Mails, Chats und SMS werden zu Cases mit gemeinsamer Historie. Administration deckt Nummern, IVR, Routen und SLAs ab — ein „All-in-One“-Contactcenter aus Frankreich.

## Vorteile

- **Telefonie ohne Zusatz-Tool** (kein separater Aircall-/Freshcaller-Vertrag nötig)
- **EU-Datenschutz** (Hosting in Frankreich, DSGVO-naher Anbieter)
- **ein Case-Begriff über alle Kanäle** — Anrufprotokoll und Mail-Thread im selben Objekt

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Zendesk** | Ticket-Welt zuerst, Telefonie (Voice) als Zusatz; Helodesk ist Telefon-first |
| **Freshdesk + Freshcaller** | zwei frische Produkte mit nahtloser Brücke — Helodesk ist ein Produkt |
| **Aircall** | reine Telefonie-Cloud + Zapier; Helodesk bringt Cases/SLA mit |

## Technische Details

- **Modell**: SaaS (Frankreich/EU), Browser-Softphone (WebRTC) + Desktop-/Mobil-Apps
- **Telefonie**: eigene Nummern/DIDs, SIP-Trunk-Option, Aufzeichnungen (einstellbar, rechtliche Hinweise je Land)
- **Authentifizierung**: E-Mail+Passwort, 2FA; API-Token
- **Preise**: Pakete nach Benutzern + Nummern/Minuten, Vertrieb führt Abos

## Für wen geeignet

- kleine/mittlere Service-Teams mit hohem Anrufanteil (Immobilien, Handwerk, Behördenhotlines)
- FreeSynergy-Skins, die ein **Call-Center-Case-Modell** (Kontakt + Kanal + Case) abbilden wollen
