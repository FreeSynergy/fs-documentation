# GLPI - Tastatur-Shortcuts

## Übersicht

GLPI kennt **keine dokumentierten App-Shortcuts** außer Browser-/Formularstandards und den „Alt-Buchstaben“ einzelner Buttons (Access-Keys in manchen Sprachversionen).

> Stand: GLPI 10.x/11.x.

## Funktionierendes

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Formularfelder |
| `Enter` | Speichern/Dialog bestätigen |
| `Esc` | Popover/Suche schließen |
| `Strg/Cmd+F` | Seiten-Browser-Suche |

## Ausdrücklich nicht vorhanden

- keine Palette / kein „Goto“-Dialog
- keine Tastenkürzel für Statuswechsel oder Mass Actions
- kein „C“ neues Ticket (Portal-Button/ Menünutzung)

## Mac

`Cmd` für Browser-Standards.
