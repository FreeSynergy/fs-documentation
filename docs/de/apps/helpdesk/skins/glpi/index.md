# GLPI Dokumentation

## Übersicht

GLPI ist ein französisch geprägtes Open-Source-ITSM: Helpdesk-Tickets plus vollständige IT-Asset-Verwaltung (Rechner, Software, Verträge, Netzwerk), projekt- und budgetfähige Reportings. PHP/MySQL, Web-ui mit Markdown-Artikeln, REST-API, starker Plugin-Ökosystem (GLPI Agent, Inventory via FusionInventory/GLPI Agent).
