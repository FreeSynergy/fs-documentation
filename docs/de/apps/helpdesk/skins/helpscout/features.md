# Help Scout - Funktionen

## Hauptfunktionen

### Conversations (Postfach)
- gemeinsame Mailboxen mit persönlicher Antwort-Optik (keine Ticketnummern für Kunden)
- Snooze, Assignments, Tags, „Shared“/„Inactive“; Chat-Antworten (planabhängig)
- Saved Replies/Snippets mit Variablen, „Move to“ Ordnerlogik

### Knowledge Base
- Docs: öffentliche Help-Center, private Wiki-Artikel, „Guides“ themenbasiert
- Beacon-Widget: Formular + KB-Suche + Chat auf der eigenen Website

### Light-CRM
- Personenprofile mit Historie, benutzerdefinierten Feldern, Tags
- „Customers“-View + API-Contacts (Identität über E-Mail)

### Automatisierung und Zusammenarbeit
- Rules pro Mailbox, Auto-replies, Umfragen (CSAT), collision detection („wer schreibt schon?“)
- mobile Apps und Desktop-App

## Was Help Scout NICHT kann

- **keine klassischen Ticket-Workflows** (Statusketten/SLA-Business-Rules sind rudimentär; kein OTRS-Gefühl)
- **keine Telefonie** integriert
- **kein Self-Hosting**, API-Objekte bleiben HelpScout-Cloud
- **keine Makros im Zendesk-Sinn** (Saved Replies = Textbausteine ohne Aktionenseite)
- **Berichte flach** im Vergleich zu Enterprise-Suiten
