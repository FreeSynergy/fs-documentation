# Help Scout - Beschreibung

## Was das Programm macht

Help Scout behandelt Support wie ein Team-Postfach: Alle schreiben an dieselbe Adresse, sehen aber personifizierte Konversationen mit Historie. Es ist bewusst „anti-Ticketing“: Support soll nach persönlichem E-Mail-Kontakt klingen, nicht nach Vorgangsnummer.

## Vorteile

- **Blitzschnell gelernt** — Agenten brauchen keine Maske zu verstehen
- **Preis pro Mailbox-Nutzer** überschaubar, Free-Seat-Modelle
- **Beacon** liefert Self-Service dort, wo Kunden sind

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Zendesk/Freshdesk** | Ticket-/Workflow-Maschine mit SLA-Vollausbau |
| **Front** | ähnliches Shared-Inbox-Modell, breiter (geteilte Kalender/SMS) |
| **Zammad** | freier Code, echte Ticketmaske, gleiche Postfach-Wurzel (E-Mail) |

## Technische Details

- **Modell**: SaaS, Firmen-Arbeitsbereich; Mailboxen = eigene Support-Adressen
- **Authentifizierung**: E-Mail+Passwort, Google-Login, 2FA; API OAuth2-Client
- **Pläne**: Standard/Plus/Premium; Docs/Chat teils add-on
- **Data**: US/EU-Regionen wählbar

## Für wen geeignet

- kleine Teams, die Support als „Menschen antworten Menschen“ verstehen
- FreeSynergy-Skins, die Mailbox-/Thread-Darstellung statt Ticketmaske zeigen
