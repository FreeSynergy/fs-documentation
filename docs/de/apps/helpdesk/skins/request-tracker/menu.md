# Request Tracker - Menüpunkte

## Hauptmenüleiste (klassische Web-UI)

| Menü | Einträge |
|------|----------|
| **Create Ticket** | Ticket im aktuellen Queue anlegen |
| **New Search** | Query-Builder: Queue/Status/Owner/Custom Fields |
| **Saved Searches** | private + öffentliche gespeicherte Suchen (Sidebar) |
| **Logs** | Transaktionen aller Tickets (Admin) |
| **Tools** | User Preferences, Dashboard, Charts |
| **Admin** | Global Configuration, Queues, Users/Groups/Rights, Scrips, Custom Fields, Sessions, Article/Article-Actions (Artikel-Modul) |

## Ticketseiten (Update-Page)

- **Reply** (an Requestor), **Correspond** (an alle Beteiligten), **Comment** (intern)
- Rechtsklick-freie Aktionen: Status (new/open/stalled/resolved/rejected), Owner, Queue (Move), CC/BCC, Time Worked
- Attachments unten, History-Block je Seite

## Sidebar (Links)

- persönliche Saved Searches („Meine Tickets“, „Overdue …“)
- Dashboards je Queue/Rolle

## Menüs nach Rolle

| Rolle | Wirkung |
|-------|---------|
| Everyone/Anonymous | eigene Tickets via E-Mail-Key |
| Requestor | eigene Tickets sehen/antworten |
| Owner (Queue-Rechte) | Update-Page seiner Queues |
| SuperUser | Admin-Menü voll |
