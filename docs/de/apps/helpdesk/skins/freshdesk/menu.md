# Freshdesk - Menüpunkte

## Agenten-Navigation (links)

| Menü | Inhalt |
|------|--------|
| Home | Arbeitsliste, Favoriten-Views |
| Tickets | alle/ungelöste/zugewiesene; saved filters |
| Anfragen (Conversations) | asynchrone Unterhaltungen (neuere Pläne) |
| Kontakte | Kunden + Organisationen |
| Produkte / KB | Wissensartikel |
| Berichte | vordefinierte Reports, Umfragen |
| Apps | Marketplace links/rechts in Ticketseite |

## Ticketseite

- Aktionen: **Reply / Reply All / Private note**, Status (Open/Pending/Resolved/Closed), Priority, Source, Product, Group, Owner, Tags, Due-by (SLA)
- TIME-Block (Tick), Attachments, „Incoming“/History unten

## Admin (Admin-Tab)

| Bereich | Inhalt |
|---------|--------|
| Helpdesk | Products, Business Hours, SLA-Assistent, Ticket-Formulare/Custom Fields |
| Automatisierungen | Workflows (Triggers + Automations + Schedulers), Dispatch'r (Regeln), Escalations, Assistent |
| Kundenportal | Domains, Formulare, Forum, Knowledge Base |
| Kanäle | Mailboxes, Telefonie (Freshcaller), Chat (Freshchat), Social |
| Nutzer | Agents (Full/Light/…), Rollen, SSO (SAML) |
| Integrations | Marketplace, API-Keys, Webhooks, „Solution“/Freddy AI |

## Menüs nach Rolle

| Rolle | Sicht |
|-------|-------|
| Customer (Portal) | eigene Tickets + Artikel |
| Agent | Tickets seiner Gruppen |
| Dispatcher/Supervisor | + Reports, Zuweisung |
| Admin | Admin-Tab voll |
