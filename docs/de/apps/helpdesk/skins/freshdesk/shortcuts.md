# Freshdesk - Tastatur-Shortcuts

## Übersicht

Freshdesk dokumentiert wenige Kurzbefehle; der Rest ist Klickarbeit.

> Stand: Freshdesk Growth/Pro (2026).

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `T` dann Ticketnummer | Ticket per ID springen (in Ticketlisten) |
| `F` | Filter/Suche fokussieren (Liste) |
| `R` | Reply (im offenen Ticket) |
| `Shift+R` | Reply All |
| `N` | private Notiz |
| `Ctrl/Cmd+Enter` | Antwort senden |
| `Esc` | Editor schließen |
| `J`/`K` | Liste runter/hoch durchblättern (Liste offen) |

## Ausdrücklich nicht vorhanden

- kein Overlay mit allen Shortcuts (Liste nur in der Hilfe-Doku)
- keine Palette

## Mac

`Cmd` statt `Ctrl`; Buchstabentasten gleich.
