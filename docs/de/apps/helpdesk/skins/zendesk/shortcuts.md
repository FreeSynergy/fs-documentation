# Zendesk - Tastatur-Shortcuts

## Übersicht

Zendesk dokumentiert Kurzbefehle für Agenten; `Ctrl+/` (bzw. `Cmd+/`) öffnet die offizielle Übersicht.

> Stand: Zendesk Support (Act). Belegungen können je Suite-Version variieren.

## Ticketliste und Navigation

| Shortcut | Funktion |
|----------|----------|
| `C` | neues Ticket |
| `J` / `K` | nächstes/vorheriges Ticket in der Liste |
| `F` | Suche fokussieren |
| `V` | zwischen Views wechseln (in manchen Versionen) |
| `Ctrl/Cmd+/` | Shortcuts-Overlay |

## Im Ticket

| Shortcut | Funktion |
|----------|----------|
| `R` | öffentliche Antwort (Reply) |
| `N` | interne Notiz |
| `E` | Ticket-Eigenschaften (Status/Priority…) fokussieren |
| `Esc` | Antwort verwerfen |
| `Ctrl/Cmd+Enter` | Antwort senden |

## Nicht dokumentiert / nicht vorhanden

| Angenommen | Status |
|------------|--------|
| Vim-Palette | ❌ |
| Globaler Hotkey ohne Seitenfokus | ❌ |

## Mac

`Cmd` statt `Ctrl`; Ein-Buchstaben-Tasten gleich.
