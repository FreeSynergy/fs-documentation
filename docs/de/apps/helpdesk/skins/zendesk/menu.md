# Zendesk - Menüpunkte

## Agent-Navigation (linke Spalte)

| Menü | Inhalt |
|------|--------|
| Views | vordefinierte Ticketmengen („Meine ungelösten…“) |
| Tickets | eigene/geteilte/alle Tickets |
| Users | Endnutzerprofile |
| Organization | Firmenkonten |
| Forums/Help Center | Artikel, Kategorien (je Plan) |
| Reporting | Dashboards, Explore |
| Apps | App-Panel rechts in der Ticketseite |

## Ticketseite

- Aktionenleiste: **Resolve / Pending / Hold**, Brand, Group, Assignee, Priority, Tags, SLA-Badge
- Konversation: Public Reply / Internal Note / Comment
- Seitenleiste: Custom Fields, Context (Nutzerhistorie), Apps

## Admin-Center (⚙)

| Bereich | Inhalt |
|---------|--------|
| Business Rules | **Triggers** (Echtzeit), **Automations** (zeitbasiert), **Schedulable Automations**, Macros, SLAs |
| Objects | Tickets-Typen, Custom Object Types (Sunshine), Tags |
| Users/Orgs | Rollen, Groups, Business Rules-Zugriff |
| Channels | E-Mail, Chat/Messaging, Voice, Social |
| Apps and integrations | Marketplace, API-Token, Webhooks, OAuth-Clients |
| Help Center | Theme, Lokalisierung, Workflow |
| Security | SSO (SAML/OIDC), 2FA, Hosting-Endpunkte |

## Menüs nach Rolle

| Rolle | Sicht |
|-------|-------|
| End-user (Client-Portal) | eigene Anfragen + Help Center |
| Agent | Views/Tickets, Macros |
| Team-Lead | + Berichtsfilter für Gruppe |
| Admin | Admin-Center vollständig |
