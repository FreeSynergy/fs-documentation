# Zammad - Tastatur-Shortcuts

## Übersicht

Zammad dokumentiert eine **Befehlspalette** und wenige globale Tasten; weitere Shortcuts sind in Arbeit. Unbelegte Aktionen bleiben markiert.

> Stand: Zammad 6.x. Hilfe: `?`-Icon oder `Ctrl+Shift+K` → „shortcuts“.

## Global

| Shortcut | Funktion |
|----------|----------|
| `Ctrl/Cmd+Shift+K` | **Befehlspalette**: Navigation, Ticket öffnen, Aktionen per Text |
| `Ctrl/Cmd+F` | Volltextsuche |
| `?` | Kurzbefehl-Übersicht |
| `Esc` | Overlay/Dialog schließen |

## In der Ticketmaske

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Bedienelemente |
| `Strg+Enter` | Antwort senden |
| `#` | Textbausteine einfügen |
| `!` | Priorität im Antwort-Header setzen (je Version) |
| `Alt+Pfeiltasten` | vorheriges/nächstes Ticket in der Filterliste |

## Nicht vorhanden (bewusst)

| Angenommen | Status |
|------------|--------|
| Vim-Artige Single-Key-Maps | ❌ |
| Globale „neues Ticket“-Taste | ❌ (Plus-Menü oder Palette) |

## Mac

`Cmd` statt `Ctrl`, Palette: `Cmd+Shift+K`.
