# Mautic Dokumentation

## Übersicht

Mautic (GPL, PHP/Symfony) ist quelloffene Marketing-Automation: Kontakte + Segmente, E-Mail-Kampagnen, **Kampagnen-Baum** (Trigger/Actions), Landingpages/Formulare, point scoring — self-hosted mit voller Datenhoheit (Alternative zu Mailchimp/Brevo).

## Dateistruktur

- [menu.md](menu.md) - Kontakte/Kampagnen/E-Mails, Konfiguration
- [features.md](features.md) - Segmente, Kampagnen, point scoring, Was Mautic NICHT kann
- [description.md](description.md) - Abgrenzung zu Mailchimp, Brevo, Odoo-Marketing
- [structure.md](structure.md) - Kontakt-Datensatz, Kampagnen-Canvas
- [shortcuts.md](shortcuts.md) - keine
- [api.md](api.md) - REST `/api/…` (contacts, segments, campaigns), OAuth2/Basic, Webhooks
