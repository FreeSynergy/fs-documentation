# Mailchimp - Menüpunkte

## Hauptnavigation (links)

| Menü | Inhalt |
|------|--------|
| Dashboard | Kampagnen-Übersicht, Growth-Tipps |
| Campaigns | Kampagnen, Templates, A/B-Tests |
| Audience → All contacts | Kontakte, Tags, Segmente, Fields, Import/Export (CSV) |
| Automations (Customer Journeys) | Journeys bauen (Trigger→E-Mails/Actions), E-commerce-Flows |
| Content Studio | Templates, Landingpages, Popups, Forms |
| Analytics/Reports | Opens/Clicks, E-Commerce-Conversion, Heatmap (Add-on) |
| Integrations | App-Verknüpfungen, **API keys** (Extras → API keys) |

## Audience-Unter-Menüs

| Bereich | Inhalt |
|---------|--------|
| Segments | Regeln („opened last 30d AND tag=spende“) |
| Tags/Fields | benutzerdefinierte Felder (merge fields) |
| Settings | Double-Opt-in, Absender, DS-GVO-Optionen (DSGVO-Bestandteil je Region) |

## Menüs nach Rolle

Owner/Admin/Manager/Employee/Contributor — API-Zugang folgt Account-Rechten.
