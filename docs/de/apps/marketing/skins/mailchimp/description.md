# Mailchimp - Beschreibung

## Was das Programm macht

Mailchimp verschickt Newsletter und begleitet Kontakte mit Automatisierungen — vom Double-Opt-in bis zum Kauf-Abbruch-Follow-up. Der De-facto-Einstieg für E-Mail-Marketing, seit Jahren mit immer mehr Suite-Elementen (CRM/Websites/Ads).

## Vorteile

- schnellster Weg zu professionellen Kampagnen
- API solide dokumentiert, Webhooks für Ereignisketten
- Templates/Editor ohne Designkenntnisse

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Mautic** | Open Source, self-hostbar, EU-Hosting möglich |
| **Brevo** | EU-Anbieter (FR), ähnlicher Umfang, günstiger Skalierung |
| **Sendinblue/Benchmark** | Name je Markt — vergleichen nach Datenschutz |

## Technische Details

- **Modell**: SaaS (Intuit); API: OAuth2 + API-Key (dc-Kennung im Endpoint!)
- **Preise**: Kontaktstufen + Send-Volumina
- **Compliance**: AVV mit EU-Standardklauseln; US-Anbieter → dokumentieren, wer was prüft

## Für wen geeignet

- Teams mit US-tolerabler Datenhaltung und Fokus auf Kampagnen-Tempo
- FreeSynergy-Skins: Member-/Tag-Modell als Referenz für [Kontakt-/Segmentfelder](../../../../data/felder.md)
