# Google Analytics Dokumentation

## Übersicht

Google Analytics (GA4, kommerziell) ist das Web-/App-Analyse-Standardwerk: ereignisbasierte Messung (Events + Parameter), Zielgruppen, Trichter, Attribution — verknüpft mit Google Ads/Search Console. Messung per gtag.js/Tag Manager; APIs: Data API v4, Analytics 360 etc.
