# Google Analytics - Menüpunkte

## Berichte (links)

| Bericht | Inhalt |
|---------|--------|
| Berichte im Überblick | Sessions/Aktive Nutzer-Kärtchen |
| Lebenszyklus | Akquise, Engagement, Monetarisierung, Retention |
| Nutzer | Attribute, Journey (Bereiche) |
| Echtzeit | Current users, Ereignisquellen |
| Explore (Explorieren) | Freie Reports: Trichter, Pfad, Überlappung, Segment-Overlays |
| Zielgruppen | Auto-/Custom-Segmente (für Ads nutzbar) |
| Anzeigen (Ads) | Kampagnen-Integration |

## Admin

| Bereich | Inhalt |
|---------|--------|
| Konto | Nutzer/Rollen, Daten-Verarbeitungen (DSGVO-Auftragsverarbeitung) |
| Property | Daten-Streams (Web/App), Kanäle, Custom Dimensions/Metrics, Datenschutz (Löschfristen) |
| Produkteinbindung | Search Console, Google Ads, BigLink (BigQuery Export) |

## Tag-Ökosystem

Google Tag Manager (eigene Konsole) + gtag.js + Consent Mode v2 — Konfiguration „neben“ GA.

## Menüs nach Rolle

Konto-Admin/Editor/Viewer/Nutzer verwalten; property-Rechte (analysieren vs. ändern).
