# Hotjar - Beschreibung

## Was das Programm macht

Hotjar zeigt, wie Menschen Seiten benutzen: Wo klicken sie hin, wo brechen sie ab, warum wüten sie (Rage Clicks). Es beantwortet Usability-Fragen, die Zahlensysteme nicht sehen.

## Vorteile

- sofort einsichtiges visuelles Feedback (Team-Sharing!)
- Rage-/Dead-Click-Analysen als kostenlos wirkendes UX-Frühwarnsystem
- Surveys ohne dev-Aufwand

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Microsoft Clarity** | Replays/Heatmaps gratis (Microsoft-Datenhaltung) |
| **Matomo-Plugins** | alles in einer Self-Host-Umgebung (Premium-Plugins) |
| **FullStory/LogRocket** | Enterprise-Session-Intelligenz |

## Technische Details

- **Modell**: SaaS (EU-Datenhaltungsoption), Skript + GTM
- **Authentifizierung**: E-Mail/SSO (höhere Pläne), API-Token
- **Datenschutz**: Maskierung default-on; Consent-Anbindung erforderlich (Cookie-Kategorie)

## Für wen geeignet

- Produkt-/Web-Teams mit Optimierungs-Roadmap
- FreeSynergy-Szenarien: Usability-Feedback-Schleifen zu Skin-Oberflächen (Compliance beachten)
