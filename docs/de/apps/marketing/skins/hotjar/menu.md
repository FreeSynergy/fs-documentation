# Hotjar - Menüpunkte

## Hauptbereich (Site-Dashboard)

| Menü | Inhalt |
|------|--------|
| Heatmaps | Klick/Move/Scroll-Heatmap je URL-Muster anlegen |
| Aufzeichnungen (Recordings) | Session-Replay-Liste (Filter: Gerät, Ziel, Dauer), Rage-Click-Marker |
| Umfragen (Surveys) | Onsite-Fragen (Popup/Inline), Targeting |
| Feedback | Feedback-Umfragen („Wie zufrieden…“), Notiz-Board |
| Funnel-Analytics | Heatmap-Funnel (Planabhängigkeit) |
| Aufnahme-Einstellungen | Sampling-Rate, Ausnahmen (URLs/CSS-Klassen), Masken für personenbezogene Inhalte |

## Kontoverwaltung

| Bereich | Inhalt |
|---------|--------|
| Teams/Mitglieder | Rollen (Admin/Editor/Viewer) |
| Tracking | Hotjar Tag via GTM, Identify (`userId`) |
| Datenschutz | Consent-Anbindung (Cookie-/Consent-Kopplung), EU-Infra-Auswahl |

## Menüs nach Rolle

Admin/Editor/Viewer je Site; API-Keys pro Team.
