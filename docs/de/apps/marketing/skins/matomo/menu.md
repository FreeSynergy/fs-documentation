# Matomo - Menüpunkte

## Hauptnavigation

| Menü | Inhalt |
|------|--------|
| Dashboard | Widgets konfigurierbar (KPI, Graphen) |
| Besuche | Besucher-Protokoll (Besucher-Aktionen einzeln!), Geografisch, Geräte |
| Verhalten | Seiten, Ausgänge, Site-Search, Timing |
| Akquise | Kampagnen-URLs (`mtm`-Parameter), Kanäle, Verweiser |
| Ziele/E-Commerce | Conversions, Trichter |
| Karten/Berichte | Geo-Karten, benutzerdefinierte Segmente |

## Verwaltung (⚙)

| Bereich | Inhalt |
|---------|--------|
| Websites | Property anlegen (Site-ID), Domain-Sharding |
| Benutzer/Rollen | viewer/write/admin + 2FA |
| Plugins | Marktplatz (HeatmapSessionRecording, Funnels (Paid), ContentTracking) |
| Einstellungen | Consent-Modus, cookieless-Konfiguration, Löschfristen (Datenschutz per Design) |
| Personal | API-Zugriff (`token_auth`-Verwaltung), Tracking-Code-Generatoren |

## Menüs nach Rolle

Super User (Administration/Plugins) · Write · · Standard · Read; Sites-Permissions pro Website.
