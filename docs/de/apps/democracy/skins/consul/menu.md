# Consul - Menüpunkte

## Bürgerbereich

| Menü | Inhalt |
|------|--------|
| Teilnahme (Participación) | Vorschläge, Prozesse, Kampagnen |
| Bürgerhaushalt (Presupuestos participativos) | Budget-Gruppen → Investitionen mit Support/Abstimmung |
| Konsultationen/Abstimmungen | Fragen mit Ja/Nein/Mehrheit, Ergebnisse |
| Debatten | Kommentare mit Supports |
| Law/Reglamento processes | Gesetzentwürfe mit Artikel-Kommentaren |
| Mein Konto | Verifizierung, Benachrichtigungen, eigene Inhalte |

## Verwaltung (Admin-Konsole)

| Bereich | Inhalt |
|---------|--------|
| Teilnahme-Manager | Vorschläge/Prozesse anlegen, Phasen, Ergebnisse publizieren |
| User-Manager | Nutzer, Verifizierungsressourcen, Berechtigungsstufen (Person/Verification…) |
| Moderation | Meldungen, Verstecken, Sperren |
| Einstellungen | Login-Methoden (Konto-/Verifizierungsstufen), Abstimmungs-Optionen, E-Mails |

## Menüs nach Rolle

Administrator · Moderator · Manager · Viewer · Nutzer (mit Verifizierungsstufen).
