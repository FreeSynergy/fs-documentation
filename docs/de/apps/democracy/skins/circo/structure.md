# Circo - Struktur und UI/UX

## Projekttrichter

```
Projektseite (Leitfrage)
  → Phase 1: Beiträge schreiben (Listen-/Kartenansicht)
  → Phase 2: Bewerten (Symbole je Beitrag, Filter)
  → Phase 3: Moderations-Bündel (Zusammenfassungen)
  → Ergebnis: Berichtseite (PDF/Download)
```

- Phasen-Banner mit Fortschritt; Beiträge in Karten-Listen
- Moderationsansicht als Extra-Layout (nur Veranstalter)

## UI/UX

- nüchtern-funktional, deutschsprachige Führungstexte
- Rollenrechte verstecken Phasen, die gerade nicht relevant sind

## Interaktionen

- Beitrag anlegen (Kurzfassung + Detail), Bewertungen mit Kommentaren
- Drag-Ordnung nur moderativ (keine freie Sortierung durch Teilnehmende)

## Responsive Design

- responsiv; Mobil-Teilnahme vorgesehen

## Accessibility

- Standard-Web; keine besonderen Shortcuts

## Performance

- projektskalierbar (hunderte Beiträge unkritisch)
