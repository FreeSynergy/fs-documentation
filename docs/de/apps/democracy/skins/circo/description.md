# Circo - Beschreibung

## Was das Programm macht

Circo moderiert Beteiligung unter professioneller Regie: Veranstalter setzen Leitfragen, eingeladenen Gruppen diskutieren und bewerten, Moderation bündelt zu Berichten. Es ist das **Moderations-Backend** für Konsultationen, bei denen Ergebnisqualität vor offener Menge geht.

## Vorteile

- DACH-erprobt, deutschsprachiger Service
- klare Phasen + Berichte (Verwertbarkeit in Gremien)
- geschützte Räume (Einladung) für sensible Formate

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **pol.is** | offene Masse + automatisch Cluster; Circo moderierte Kreise |
| **Decidim** | öffentliche Verfahren; Circo Begleitprozess |
| **Mural/Workshop-Tools** | Visualisierung; Circo Beitragstrichter + Berichte |

## Technische Details

- **Modell**: SaaS/Betrieb beim Anbieter; Details (Serverstand, Lizenz) projektindividuell
- **Authentifizierung**: Einladungskonten/SSO je Projekt (Anbieter fragen)
- Dokumentationslage bewusst schmal gehalten (kein erfundenes API-Wissen)

## Für wen geeignet

- Verbände/Kommunen mit begleiteten Konsultationen
- FreeSynergy-Szenarien: Import von Ergebnis-Exporten in Wiki-Berichte
