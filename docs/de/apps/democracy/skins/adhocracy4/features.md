# Adhocracy4 - Funktionen

## Hauptfunktionen

### Phasen-Module
- Brainstorming (Ideen sammeln), Sichtung (Redaktion prüft), Bewertung/Diskussion, Umfragen, **Kiezkasse** (Bürger:innen schlagen Investitionen vor + stimmen über Budgetanteil ab)
- Phasenwechsel automatisch (Datum), Projekt-Roadmap sichtbar

### Beteiligungstiefe
- Kommentare + Ratings mit Zähler, Geo-Verortung von Ideen (Stadtplan), Bildanhänge
- Moderationsfluss: „in Prüfung“, „wird umgesetzt“-Marken — Transparenz über Weitergabe an Verwaltung

### Betrieb
- Multi-Organisationen (Träger-Instanz), Newsletter, Import/Export (CSV), Mehrsprachigkeit (DE-first)
- **API** für Auswertungs-Dashboards; Statistik-Widgets

## Was Adhocracy4 NICHT kann

- **keine Entscheidung/Abstimmung im Sinne von Wahlen** (Bewertung ≠ Votum; Kiezkasse-„Abstimmung“ ist Meinungsbild mit vertraglicher Bindung im echten Leben)
- keine delegierten Stimmen (Liquid-Modell: ❌)
- kein pol.is-Clustering
- Setup ist Django-Projektarbeit (kein Klick-Baukasten wie SaaS)
