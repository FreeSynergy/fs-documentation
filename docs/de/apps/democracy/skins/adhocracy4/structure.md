# Adhocracy4 - Struktur und UI/UX

## Projektansicht

```
┌──────────────────────────────────────────────────────────────────┐
│ Projekt „Platz am Kanal“   Phase: Brainstorming (bis 20.11)     │
│ [Projektinfo | Ideen(142) | Karte | Diskussion]                 │
├──────────────────┬───────────────────────────────────────────────┤
│ Filter/Sortierung│ Ideen-Karten: Titel · Autor (Pseudonym)       │
│ (Karte/ Liste)   │   ▲ 31 ▼ 2 · Kommentare 7 · Moderationsmarke │
│                  │ Detail: Text, Bild, Standortpinn, Thread      │
└──────────────────┴───────────────────────────────────────────────┘
```

- Phasenbalken oben; Karten ⇄ Listenansichten umschaltbar
- Moderationsmarken als Farbband an der Karte

## UI/UX

- freundlich-kommunal (viel Weiß, große Buttons), DE-Texte durchgängig
- Pseudonym-Pflicht für Beiträge (Klarnamen-Option je Verfahren)

## Interaktionen

- Rating per ▲/▼ (ein Votum pro Person/Modul), Kommentare threaded
- Ideen per Drag auf Stadtplan verorten

## Responsive Design

- voll responsiv (Stadtplan-Teilnahme mobil üblich)

## Accessibility

- WCAG-Basis; Karten mit Textalternativen-Listen

## Performance

- große Ideensammlungen: Kartensegmentierung; Rating-Zähler serverseitig
