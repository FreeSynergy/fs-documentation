# LiquidFeedback - Beschreibung

## Was das Programm macht

LiquidFeedback ist gelebte Delegative Demokratie: Mitglieder bringen Anträge ein, diskutieren argumentbasiert und entscheiden — wobei sie ihre Stimme thematisch an Vertraute weitergeben. Es löst das Repräsentationsproblem kleiner und mittlerer Organisationen.

## Vorteile

- Delegationsketten + Counter-Initiativen = **Interessen sichtbar statt Fraktionszwang**
- Erprobt in Parteien/Verbänden (PIRATEN-Parteitage prägten es)
- Selbst gehostet, offene Lizenz

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Decidim/Consul** | öffentliche Beteiligung (Antragskatalog); Liquid = Gremien-Entscheidung |
| **pol.is** | Massen-Deliberation ohne Anträge |
| **Ademeco/other e-voting** | reine Wahlsysteme |

## Technische Details

- **Stack**: PHP (klassisch), MySQL; Web-UI templatisch
- **Auth**: Konten mit Verifizierung; Passworthygiene Organisationsache
- **Lizenz**: frei (Apache), Pflege unregelmäßig — Stand prüfen

## Für wen geeignet

- Verbände/Initiativen mit satzungsfesten Entscheidungsprozessen
- FreeSynergy-Skins: Delegationsmodell als Beispiel für Stimm-Relationen ([modelle.md](../../../../data/modelle.md))
