# Pol.is - Beschreibung

## Was das Programm macht

Pol.is dreht Beteiligung um: statt abzustimmen bewerten die Leute Aussagen anderer — daraus entstehen automatisch Meinungsgruppen und überraschender Konsens. Es ist das Instrument für **Dialogformate** („Was bewegt euch?“) statt Antragsstellerei.

## Vorteile

- skaliert Deliberation (hunderte→100k Teilnehmer)
- zeigt, wo Lager sich berühren (Konsens-Karten)
- **barrierenarm**: ein Kommentar reicht zum Einstieg

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Decidim/Consul** | Antrags-/Haushaltsformate; pol.is Stimmungs-Landkarte |
| **Liquid** | interne Beschlussfassung (delegativ) |
| **Umfragetools** | vordefinierte Fragen; pol.is generiert aus Teilertexten |

## Technische Details

- **Modell**: SaaS (pol.is), Codebasis offen (historisch polis project)
- **Authentifizierung**: participant-Identifikatoren (Cookie/IP-Heuristik), optional Login
- **Sprachen**: mehrsprachig, Moderation mehrsprachig nutzbar

## Für wen geeignet

- große Dialogformate (Stadtentwicklung, Vernehmlassungen) mit Auswertungsressourcen
- FreeSynergy-Skins: Data-API-Auswertung als Ergebnis-Widget ([modelle.md](../../../../data/modelle.md) → Cluster/Konsensmodell)
