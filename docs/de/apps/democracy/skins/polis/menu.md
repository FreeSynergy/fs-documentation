# Pol.is - Menüpunkte

## Teilnehmeransicht (Conversation)

| Element | Inhalt |
|---------|--------|
| Eingabefeld | eigener Kommentar (nach Trivia-Frage) |
| Kommentarkarten | bewerten: 👍 agreeing / 👎 disagree / pass — mit „important“-Flag |
| Gruppen-Chips („A/B/C…“) | Meinungspolen mit repräsentativen Aussagen |
| Meinungskarte | Scatter der Teilnehmenden (Konsens/Grenzen) |

## Organisator-/Moderationsbereich

| Bereich | Inhalt |
|---------|--------|
| Conversation anlegen | Fragen, Trivia (Mehrparteien-Fragen zur Cluster-Färbung) |
| Moderation | Kommentare zusammenführen (merge), sperren, featured |
| Ergebnisse | Gruppenberichte, Konsensaussagen, Exporte (CSV) |
| Einbettung | iFrame/JS-Embed, Domain-Whitelist |

## Menüs nach Rolle

Anonym teilnehmbar (mit Schutz gegen Missbrauch), Moderation/Organisation = geschützte Konten.
