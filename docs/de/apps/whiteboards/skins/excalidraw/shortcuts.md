# Excalidraw - Tastatur-Shortcuts

## Übersicht

Excalidraw dokumentiert seine Kurzbefehle direkt in der App (Hilfe-Fenster mit `/`). Grundlage dieser Liste ist die offizielle Shortcut-Übersicht von docs.excalidraw.com. Unter macOS ersetzt `Cmd` die `Strg`-Taste. Randfälle ändern sich mit den Versionen und sind als versionsabhängig markiert.

---

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Z` / `Cmd+Z` | Rückgängig |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Wiederholen |
| `Ctrl+A` / `Cmd+A` | Alle Elemente auswählen |
| `Ctrl+C` / `Cmd+C` | Auswahl kopieren |
| `Ctrl+X` / `Cmd+X` | Auswahl ausschneiden |
| `Ctrl+V` / `Cmd+V` | Einfügen |
| `Ctrl+S` / `Cmd+S` | Als `.excalidraw` speichern |
| `Entf` / `Backspace` | Auswahl löschen |
| `Esc` | Werkzeug abbrechen; zweimal drücken hebt die Auswahl auf |
| `/` | Hilfe-Fenster (Shortcut-Übersicht) ein-/ausblenden |
| `?` | Zen-Modus (UI ausblenden) ein-/ausschalten |
| `Ctrl+'` / `Cmd+'` | Gitter ein-/ausblenden |

| Shortcut | Funktion |
|----------|----------|

| `Alt`+Klick | Tiefenauswahl: überlappende Elemente darunter treffen |
| `Tab` / `Shift+Tab` | Nächstes / vorheriges Element auswählen (versionsabhängig) |
| `Strg`+Scrollen | Zoomen |
| `Ctrl+=` / `Cmd+=` | Zoom vergrößern |

| `Ctrl+Shift+1` / `Cmd+Shift+1` | Zoom auf Auswahl |

## Suche

Excalidraw besitzt **keine Suche im Canvas**. Gefunden wird nur über die Bibliotheks-Suche (Panel) und die Browser-Funktion `Strg+F` für die Oberfläche selbst.

## Zusammenfassung

Excalidraw hält seine Shortcuts bewusst klein:

- **Buchstaben** schalten Werkzeuge (`V H E R D O A L P X`), `Q` sperrt das Werkzeug
- **`Strg`/`Cmd` + Klassiker** für Zwischenablage, Undo/Redo, Speichern, Auswählen
- **Zoom und Ansicht** vollständig tastaturbedienbar, ebenso Ausrichten
- **Suche und Befehlspalette existieren nicht** und werden über Panels bzw. das Menü ersetzt
