# OpenBoard - Tastatur-Shortcuts

## Übersicht

OpenBoard ist stift-/touch-zentriert; Tastaturkürzel sind basics. Übersicht in der Anwendungshilfe („?“-Werkzeug).

> Stand: OpenBoard 1.7.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Esc` | Werkzeugbögen/Modals schließen |
| `Tab` | Werkzeug wechseln (cycle) — Stand prüfen |
| `Entf` | ausgewähltes Element löschen |
| `Strg/Cmd+Z` / `+Y`/`+Shift+Z` | Rückgängig / Wiederholen |
| `Bild ab/auf` | nächste/vorherige Seite |
| `Vollbild F5` (Presentation) | Präsentationsmodus — Tastenbelegung je Version prüfen |

## Ausdrücklich nicht vorhanden

- keine Ein-Buchstaben-Werkzeugwahl (Bögen anklicken)

## Mac

`Cmd`-Variante bei den Strg-Tasten.
