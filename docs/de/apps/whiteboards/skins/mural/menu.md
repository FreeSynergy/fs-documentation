# Mural - Menüpunkte

## Mural-Menü (Mural-Logo)

- Mural exportieren (PNG), Duplizieren, Drucken, Aktivitäten-Log, Versionen

## Toolbar (unten/links)

Auswahl · Text · Formen · Freihand · Notiz (Post-it) · Verknüpfungspfeile · Bild · Tabelle · Frame · „Shape“-Bibliotheken · Voting · Timer · „Sequence“ (Moderationsablauf) · Reaction

## Mural-Einstellungen (⋯)

- Titel/Sichtbarkeit (Private/Team/Public-link), Einladungen (Editor/Kommentator), „Follow“-Steuerung, Bereiche (Areas) aufteilen große Mural-Flächen

## Sessions/Facilitation

- Moderatoren-Modus: Namensanzeige, Timer, „Silence“-Steuerung, Teilnehmende hervorheben
- „Breakout Boards“ (Enterprise)

## Workspace-Menü (oben)

| Bereich | Inhalt |
|---------|--------|
| Mural-Übersichten | Suche, Favoriten, Workspace-Ordner |
| Vorlagenbibliothek | Moderationsformate, Team-Vorlagen |
| Admin (Enterprise) | SSO (SAML/SCIM), Data Residency (EU), Gast-Regeln |

## Menüs nach Rolle

Eigentümer · Editor · Kommentator · Betrachter; Sequence-Steuerung nur Moderator:in.
