# Miro - Beschreibung

## Was das Programm macht

Miro ist der virtuelle Workshop-Raum: ein unbegrenztes Whiteboard, in dem Teams gleichzeitig kleben, zeichnen, abstimmen und präsentieren. Es ersetzt Moderationswände — mit Vorlagen, damit niemand beim weißen Blatt anfängt.

## Vorteile

- **Moderations-Werkzeuge** (Timer, Votings, Presenter) out of the box
- **Vorlagenqualität** ist Branchenreferenz
- **API + App-Kit** für Integrationen in Tool-Landschaften

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Mural** | ähnlicher Fokus (Workshops), älter, weniger App-Ökosystem |
| **Excalidraw** | minimalistisch, OSS; Miro ist Vollausbau |
| **tldraw** | SDK/Entwickler-Perspektive; Miro Endnutzer-Suite |

## Technische Details

- **Modell**: SaaS (Teams, Gast-Boards), Datenresidenz EU/US (Enterprise)
- **Clients**: Web, Desktop (Electron), iPad-Optimierung
- **Authentifizierung**: E-Mail/Google/Microsoft/SSO (SAML/SCIM Enterprise); API OAuth2
- **Preise**: Free/Starter/Business/Enterprise (Board-/Gastlimits im Free-Plan)

## Für wen geeignet

- Workshop-/Produktteams mit großem Moderationsbedarf
- FreeSynergy-Skins: Frame/Sticky/Connector-Elemente als Standard-Baustein-Set ([components](../../components/))
