# Miro - Tastatur-Shortcuts

## Übersicht

Miro dokumentiert Kurzbefehle; `?` bzw. Menü „Help → Keyboard shortcuts“ zeigt die Liste.

> Stand: Miro (2026).

## Werkzeuge

| Shortcut | Werkzeug |
|----------|----------|
| `V` | Auswahl |
| `H` | Hand (Pan) |
| `S` | Sticky Note |
| `R` | Rechteck |
| `O` | Ellipse |
| `L` | Linie |
| `P` | Pen (Stift) |
| `T` | Text |
| `C` | Connector |
| `F` | Frame |

## Ansicht und Bearbeiten

| Shortcut | Funktion |
|----------|----------|
| `Strg/Cmd+C` / `+V` / `+X` | Kopieren / Einfügen |
| `Strg/Cmd+Z` / `+Shift+Z` | Rückgängig / Wiederholen |
| `Strg/Cmd+A` | Alles auswählen |
| `Entf` | Auswahl löschen |
| `Strg/Cmd+=` / `+-` | Zoom |
| `Strg/Cmd+0` | Zoom zurücksetzen |
| `Strg/Cmd+Shift+H` | Alles einpassen (Zoom-to-fit) |
| `Leertaste` + Ziehen | Canvas bewegen |
| `G` | Gruppieren |
| `Strg/Cmd+G` | (neuere Builds) Gruppen — Version prüfen |
| `?` | Shortcuts-Hilfe |

## Ausdrücklich nicht vorhanden

- Vim-/Palette-Modus

## Mac

`Cmd` statt `Strg`; Werkzeugbuchstaben identisch.
