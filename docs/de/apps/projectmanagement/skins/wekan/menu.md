# Wekan - Menüpunkte

## Board-Menü (☰ rechts oben)

| Eintrag | Inhalt |
|---------|--------|
| Mitglieder | Invite per Username/E-Mail, Rechte (Admin/Normal) |
| Labels verwalten | Farbe + Text |
| Listen-Menü („…“) | Sortieren, Archivieren, Farbsäume |
| Swimlane-Menü („…“) | Titel, Farbcodierung, archive |
| Board-Aktionen | Archivieren/Schließen, Vorlage speichern, Import (Trello CSV/JSON), Export (JSON/CSV) |
| Aktivitäten | Feed rechts einklappbar |

## Kartenmenü (Karte → „…“ bzw. Klick)

- Bearbeiten, Fälligkeit, Labels, Mitglieder, Checklisten, Anhänge, Kommentare
- Verschieben (Liste/Swimlane), Duplizieren, Archivieren, Beobachten
- Eigene Kartenfelder (Custom Fields pro Board)

## Admin-Panel (⚙, Instanz)

| Bereich | Inhalt |
|---------|--------|
| Benutzer | anlegen, Rollenzuweisung, Deaktivieren |
| Authentifizierung | Passwort, LDAP, OAuth2 (Casdoor/etc.), SAML |
| Boards/Organisationen | Übersicht, Vorlagen, Importe |
| Webhooks/Integrationen | ausgehende Hooks pro Board; Invoke-Webhooks (eingehend) |
| Einstellungen | Ersten Admin festlegen, SMTP, Registrierung an/aus |

## Menüs nach Rolle

Admins (Instanz) vs. Board-Admin vs. Board-Mitglied vs. Beobachter; Organisationen kapseln Boards.
