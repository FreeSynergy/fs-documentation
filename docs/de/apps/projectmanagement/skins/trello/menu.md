# Trello - Menüpunkte

## Workspace-Ebene

| Menü | Inhalt |
|------|--------|
| Workspaces | Board-Sammlungen pro Team/Firma, Mitglieder |
| Vorlagen-Center | Board- und Karten-Vorlagen |
| Power-Ups | Add-Ons verwalten (Jira, Calendar, Custom Fields …) |

## Board-Menü (☰ oben rechts)

- **Menü**: Mitglieder einladen, Einschränkungen, Legend (Labels), Power-Ups, Aktivitäten, Einstellungen (Hintergrund, Ansichten: Tabelle/Kalender/Liste/Timeline (Premium), Map (Power-Up))
- **Filter**: Labels, Mitglieder, Fälligkeiten
- **Teilen/Privatsphäre**: Workspace, Board-Mitglieder, Lese-/Schreibrechte

## Kartenmenü (Karte anklicken)

| Bereich | Inhalt |
|---------|--------|
| Titel/Beschreibung | inline editierbar |
| Checklisten, Anhänge, Labels, Mitglieder, Fälligkeit, Ort | als Buttons |
| Aktionen | Archivieren, Kopieren, Verschieben, Beobachten, Kartenvorlage |
| Automatisierung („Zauberstab“) | Karten-Regeln (Butler) |

## Menüs nach Rolle

| Rolle | Rechte |
|-------|--------|
| Admin (Board) | alles, Mitglieder |
| Mitglied | Karten bearbeiten |
| Beobachter | nur lesen/kommentieren |
| Gast (eingeschränkt) | zugewiesene Karten |
