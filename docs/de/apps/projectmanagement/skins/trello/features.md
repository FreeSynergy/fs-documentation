# Trello - Funktionen

## Hauptfunktionen

### Kanban-Kern
- Boards → Listen → Karten; Drag & Drop, Checklisten, Fälligkeiten mit Erinnerungen, Labels (farbig+Text), Anhänge, Kartenfarben
- Kommentare mit @-Erwähnung, Beobachten, Aktivitäten-Feed

### Ansichten (Premium/Enterprise)
- Kalender, Timeline (Gantt-artig), Table (Excel-artig, editierbar), Map (Karten-Orte — Bezug zur Maps-Kategorie)

### Automatisierung
- **Butler**: Regel-Bibliothek pro Board (When card moved → set due date → notify), Karten- und Board-Buttons, Scheduled Commands

### Kollaboration
- Mitglieder/Gäste, Beobachter, Workspace-Weite Board-Vorlagen, Karten-Vorlagen, „Bewegungen“-Audit

## Was Trello NICHT kann

- **keine echten Subtasks-Bäume** (Checklisten sind flach, keine Karten-haben-Karten)
- **keine Abhängigkeiten zwischen Karten** als Objekt (Timeline zeigt nur Reihen)
- **kein Self-Hosting** (Atlassian Cloud)
- **Berichte rudimentär** (Zahlen pro Liste; keine eigene Aggregation ohne Power-Ups)
- **Zeit-Tracking nur via Power-Up**

## Erweiterungen und Integrationen

| Integration | Weg |
|-------------|-----|
| Power-Ups (Marktplatz) | Calendar, Custom Fields, Voting, Jira-Brücke |
| REST-API + Webhooks | offiziell |
| Atlassian-Routing | Jira-Confluence-Anbindung (Team-Pläne) |
