# Jira - Tastatur-Shortcuts

## Übersicht

Jira Cloud hat dokumentierte Kurzbefehle; `?` blendet die Übersicht ein.

> Stand: Jira Cloud (2026). Data Center ähnelt, kann abweichen.

## Global

| Shortcut | Funktion |
|----------|----------|
| `c` | Issue anlegen (Schnellerfassung) |
| `/` | Schnellsuche fokussieren |
| `u` | eigene aktive Issues öffnen („Meine Änderungen“ je Version) |
| `g` dann Buchstabe | Navigation: `g d` Dashboards, `g p` Projekte, `g b` Boards |
| `?` | Kurzbefehle-Overlay |
| `Esc` | Panels schließen |

## Issue-Liste/Board

| Shortcut | Funktion |
|----------|----------|
| `j` / `k` | nächstes/vorheriges Issue (fokussiert) |
| `x` | Issue öffnen |
| `z` | Issue schließen |

## Im Issue

| Shortcut | Funktion |
|----------|----------|
| `m` | Kommentieren |
| `a` | Zuweisen |
| `l` | Labels |
| `e` | alle Bearbeiten-Felder (Detail) |
| `d` | (manchen Builds) Details-Panel — nicht offiziell |

## Ausdrücklich nicht vorhanden

- frei belegbare Workflows-Tasten (Transitionen bleiben Buttons)

## Mac

`Cmd` ersetzt `Strg` (z.B. `Cmd+K` Suche in Apps); Einzelbuchstaben wie oben.
