# Jira - Menüpunkte

## Globale Sideleiste

| Menü | Inhalt |
|------|--------|
| Ihre Apps (⌘) | Jira Software, Service Management, Confluence… |
| Projekte | Projektliste, Projekt anlegen |
| Filter | Ihre Filter, Favoriten, „Alle“ (Issue-Navigator) |
| Dashboards | Board-Dashboards, Gadget-Builder |
| Einstellungen (⚙, Admin) | Issues (Typen, Statuses, Screens, Fields), Users/Groups, Apps, System, Product permissions |

## Projektseiten (links)

| Menü | Inhalt |
|------|--------|
| Boards (Kanban/Scrum) | aktives Board, Berichts-Tab |
| Backlog | Planen, Sprints starten/abschließen (Scrum) |
| Issues | Volltextansicht mit Filter |
| Reports | Velocity, Burn-up, Control Chart, Created-vs-Resolved |
| Project settings | Details, People, Integrations, Workflows/Bildschirme (Admin/Projektrechte) |

## Issue-Aktionen (oben/⋯)

Übergänge (Transition-Buttons nach Workflow), Zuweisen, Priorität, Labels, Epics/Moduls, Links (Blocks, Relates), Anhänge, Kommentare, „Mehr…“ (Move, Delete, Watch)

## Menüs nach Rolle

| Rolle | Sicht |
|-------|-------|
| Project Admin | Project settings |
| Entwickler/Member | Issues, Boards, Backlog |
| Viewer (Leseplan) | nur Ansehen/Kommentieren je Berechtigung |
| Jira-Admin | globales ⚙-Menü (Instance) |
