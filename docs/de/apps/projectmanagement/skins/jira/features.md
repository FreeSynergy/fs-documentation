# Jira - Funktionen

## Hauptfunktionen

### Issues und Workflows
- Issue-Typen (Story, Task, Bug, Epic, Subtask) mit eigenen Workflows (Status + Transitionen + Conditions Validators)
- Custom Fields (Text, Auswahl, Datum, Benutzer…), Screens/Screen Schemes, Issue Types per Projekt (Company-managed)
- Links (Blocks/Is blocked by/Relates), Epics und (neue) Initiatives, Fix Versions, Components

### Agiles Arbeiten
- Scrum-Boards mit Backlog, Sprints, Story Points, Velocity; Kanban-Boards mit WIP-Limits
- Advanced Roadmaps/Plans (Premium), Automation for Jira (Regeln „When… then…“)

### Abfragen und Berichte
- **JQL**: `project = WEB AND status changed to Done AFTER -7d ORDER BY Rank`
- Filter/Subscriptions, Dashboards (Gadgets), Control Chart/Cycle Time, Burn-up

### Integrationen
- Confluence (Issue↔Seite), Bitbucket/Git-Commits (#KEY), Branch-Entwicklung, Marketplace (tausende Apps: ScriptRunner, Tempo…)

## Was Jira NICHT kann

- **kein leichtes Tool** — Admin-Overhead (Schemes, Permission Schemes) ist berüchtigt
- **keine Offline-Nutzung** (Cloud/Data Center brauchen Verbindung)
- **kostenpflichtig** ab 10 Nutzern (Cloud-Abo)
- **Berichte tiefer als Trello, flacher als dedizierte BI-Tools**
- **keine Gantt-Kanone nativ** (Plans erst Premium; sonst Add-ons wie BigPicture)
