# Asana - Funktionen

## Hauptfunktionen

### Aufgabenmodell
- Aufgaben/Bereiche in Projekten, Unteraufgaben, Abhängigkeiten (blocks/blocked-by mit Warnung)
- Fälligkeit + Uhrzeit, mehrere Assignees/Teilnehmer, Tags, benutzerdefinierte Felder (Zahl, Auswahl, Text, Benutzer)
- Inbox als Benachrichtigungszentrale, „Meine Aufgaben“-Smart-Listen

### Mehrfachansichten je Projekt
- Liste, Kanban-Tafel, Kalender, Tabelle, **Timeline** (Gantt-artig mit Abhängigkeiten)

### Steuerungsebene
- **Portfolios** (Projektgruppen mit Statusaktualisierung), **Workloads** (Kapazitäten), Goals
- **Regeln** (Regel-Engine pro Advanced-Projekt), Forms als Eingang, Templates

### Integrationen
- Marketplace (Slack, Teams, Google Drive), Asana AI (Smart Summary), Universal App (Jira/GitHub-Sync plangrenzen)

## Was Asana NICHT kann

- **kein Self-Hosting** (SaaS)
- **keine echte Workflow-Engine** (Status ist frei; keine Transition-Regeln wie Jira)
- **Gantt ohne kritischen Pfad** (Timeline zeigt Abhängigkeiten, keine CPM-Berechnung)
- **zeitbasierte Leistungserfassung nur via Integration**
- Custom-Field-Logik begrenzt (keine Berechnungen über Felder hinweg)
