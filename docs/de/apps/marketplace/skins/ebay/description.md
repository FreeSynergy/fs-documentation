# eBay - Beschreibung

## Was das Programm macht

eBay vermietet Marktplatz-Reichweite: Einstellen, Verhandeln/Auktionieren, Bezahlen (Managed Payments), Versenden, Bewerten — unter Plattformregeln mit Käuferschutz. FreeSynergy-Skins lesen/verwalten darüber **fremde** Verkäufe (Dashboards, ERP-Brücken).

## Vorteile

- größte Reichweite für Secondhand/Sonderposten
- durchdachte Verkäufer-APIs (Sell API Family)
- Auktion als Preisfindungs-Werkzeug

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Etsy** | Handmade/Design-Kuration; eBay offen + Auktion |
| **Kleinanzeigen** | regional/lokal ohne Zahlungs-/Schutz-Infrastruktur |
| **Sharetribe (eigener MP)** | eigene Regeln/Gebühren; eBay fremde |

## Technische Details

- **Modell**: SaaS-Plattform (eBay Group), Ländersites
- **Authentifizierung**: eBay-Konto + OAuth2 (App ID/ Cert ID, User-Access-Token)
- **APIs**: Rest-artig + traditionelle XML (Trading API) — moderne APIs bevorzugen

## Für wen geeignet

- Wiederverkauf-/Sonderposten-Logistik mit ERP-Anbindung
- FreeSynergy-Skins: Order-/Listing-Reader für Auswertungen ([modelle.md](../../../../data/modelle.md))
