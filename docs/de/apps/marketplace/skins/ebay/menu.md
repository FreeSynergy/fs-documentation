# eBay - Menüpunkte

## Käuferseite

- Suchleiste + Filter (Preis/Zustand/Standort/Versand)
- Produktdetail: Preisformat, Versand, Bewertungen, „Sofort kaufen“/Preisvorschlag
- Mein eBay: Käufe, Nachrichten, Bewertungen

## Verkäuferseite (Seller Hub)

| Bereich | Inhalt |
|---------|--------|
| Inserate erstellen | Formular oder **File Exchange/CSV**, Vorlagen |
| Aktive Verkäufe | Preis/Aktionen (Enden, Überarbeiten) |
| Outgoing Orders | Zahlung/Versandstatus, Sendungsverfolgung |
| Finanzen | Gebühren, Auszahlung (Managed Payments) |
| Marketing | Promotions, Versandrabatte |
| Einstellungen | Geschäftsinformationen, Zahlungsrichtlinien, API-Schlüssel (Developer Portal separat) |

## Developer-Portal (developer.ebay.com)

- Apps anlegen (OAuth2), API-Katalog (Sell, Browse, Inventory, Fulfillment, Marketing), Test-OAuth-Keys

## Menüs nach Rolle

Gast · Käufer · Verkäufer (Gewerblich/Privat) · PowerSeller; API-Rechte je App-Zulassung.
