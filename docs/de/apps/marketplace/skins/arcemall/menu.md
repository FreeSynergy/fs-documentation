# Arcemall - Menüpunkte

## Endnutzerseite (beispielhafter Marktplatz)

| Element | Inhalt |
|---------|--------|
| Suche/Kartenansicht | Angebote in Region/Kategorie |
| Angebotsdetail | Beschreibung, Preis/Buchung, Anbieterprofil, Bewertungen |
| Konto | Meine Angebote, Buchungen, Chat |

## Betreiber-Editor (Low-Code)

| Bereich | Inhalt |
|---------|--------|
| Modell-Editor | Entitätstypen (Listing, Booking, User), Felder, Relationen |
| UI-Editor | Seitenbausteine (Listen, Karten, Formulare) |
| Zahlungs-/Prozess-Editor | Zahlungsflüsse (Stripe), Transaktionsschritte |
| Integrationen | API-Keys, Webhooks, Importer |

## Menüs nach Rolle

Betreiber (Editor) · Anbieter (Listings) · Kunde (Suche/Buchung) — Rollen im Modell-Editor definierbar.
