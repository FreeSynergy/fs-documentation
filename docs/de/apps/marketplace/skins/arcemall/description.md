# Arcemall - Beschreibung

## Was das Programm macht

Arcemall will Marktplatz-Baukasten sein: Statt bei null zu starten, modelliert man Angebote, Buchungen, Zahlungen und Suche in einer Low-Code-Umgebung und bekommt API + UI-Bausteine dazu — für Initiativen, die einen **eigenen** Marktplatz (regional, thematisch) wollen.

## Vorteile

- own-your-data-Ansatz (Open-Source-Kern, selbst hostbar — Deployment-Modelle prüfen)
- Modellierbarkeit schlägt Sharetribe-Konfigurationskorsett
- Karten-/Geo-Suche eingebaut (FreeSynergy-Anschluss)

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Sharetribe** | ausgereifter SaaS-Komfort; Arcemall flexibleres Modellieren |
| **CS-Cart MV** | Shop-Welt (Produkte/Versand); Arcemall Vermittlungslogik |
| **eBay/Etsy** | bestehende Marktplätze (fremde Regeln) |

## Technische Details

- **Modell**: Plattform + selbst gehostete Instanzen je nach Lizenzweg (Stand prüfen)
- **Zahlen**: Stripe Connect-Muster
- **Dokumentationslage**: bewusst knapp gehalten; Detail-APIs im Projekt verifizieren

## Für wen geeignet

- FreeSynergy-umfeld-nahe Projekte mit eigenem Marktplatz-Wunsch und IT-Ressource
- Skins: Modell-Editor-Muster für eigene Angebotsmodelle ([modelle.md](../../../../data/modelle.md))
