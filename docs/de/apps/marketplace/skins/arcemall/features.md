# Arcemall - Funktionen

## Hauptfunktionen

- Modellierbare Marktplatz-Typen (Produkte, Dienstleistungen, Vermietung, Termine)
- Karten-/Regionssuche, Buchungskalender, Bewertungen, Anbieterprofile
- Zahlungsflüsse mit Split (Anbieter/Plattform) via Stripe
- API-/Webhook-Zugriff für eigene Frontends und Integrationen; Templates beschleunigen den Start

## Was Arcemall NICHT kann

- **kein riesiges Feature-Register** wie eBay (Auktionen/Käuferschutz-Imperium) — Plattform zum **Bauen**, nicht Super-Marktplatz
- weniger reifes Ökosystem/Community als Sharetribe (jüngeres Projekt)
- tiefe Lager-/Versandlogistik: begrenzt (Fokus Vermittlung)
- Doku/Einzelheiten wandeln sich — API-Stand vor Projektstart verifizieren
