# Arcemall - Struktur und UI/UX

## Bausteine

```
Marktplatz-Seite:  Suchleiste + Karten/Listen-Umschalter
  Angebotskacheln: Bild · Preis · Anbieter · Bewertung
  Detail: Galerie · Buchungsmaske (Kalender) · Chat · Bewertungen
Betreiber-Cockpit: Modell-Editor (Entitäten/Felder) · UI-Bausteine ·
                   Zahlungsregeln · Webhooks
```

## UI/UX

- Template-basiert, aber vom Betreiber gestaltbar; Geo-Karten zentral
- Statusanzeigen pro Buchung (angefragt/angenommen/abgeschlossen)

## Interaktionen

- Drag-Modeling im Editor (Beziehungen per Klick)
- Buchungsablauf mit Bestätigungsstufen (anfragend → bestätigt)

## Responsive Design

- Templates responsiv; Kartenansicht mobil optimiert

## Accessibility

- Standard-Web-Bausteine; Editor-Formulare tastaturbedienbar

## Performance

- Suchindex plattformintern; große Angebotsmengen mit Kategorisierung
