# CS-Cart Multi-Vendor - Funktionen

## Hauptfunktionen

- **Echte Shop-Engine** mit Multivendor: Produktverwaltung je Händler, Freigabe-Workflows, Provision/Fee-Modelle, Payout-Reports
- Versand-/Zahlungs-Add-ons (PayPal, Stripe, DHL-Versandlabels), Lagerlogik, B2B-Module
- Mehrere Frontends (Multi-Storefront), SEO-Ausrüstung, Theme-System
- **REST-API** (Produkte, Bestellungen, Kategorien…) für ERP/CRM-Sync

## Was CS-Cart Multi-Vendor NICHT kann

- **keine Vermietungs-/Terminlogik** (Buchungsprozesse à la Sharetribe nur über Add-ons)
- Lizenzkosten + Add-on-Kosten (kein freies Produkt)
- Auktionsmechaniken fehlen
- Self-Hosting erfordert Betrieb (PHP/MySQL-Stack)
