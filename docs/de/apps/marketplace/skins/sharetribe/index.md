# Sharetribe Dokumentation

## Übersicht

Sharetribe ist die führende **Marktplatz-Software**: Open-Source (Marktplatz zum Selbstbauen, Ruby on Rails — „Sharetribe Flex“: API-first mit Web App/Marketplace Console) sowie SaaS-Versionen (Sharetribe One/Go für Einsteiger). Damit betreibt man eigene C2C-/Dienstleistungs-Marktplätze: Listings, Durchsuchen/Karte, Buchungen/Bestellungen, Zahlungen (Stripe), Bewertungen.
