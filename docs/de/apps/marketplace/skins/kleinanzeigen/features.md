# Kleinanzeigen - Funktionen

## Hauptfunktionen

- **lokale Reichweite**: Standort/Umkreis, Kartenansicht, Abhol-Logik (Versand optional mit „Sicher bezahlen“-Treuhand)
- unkomplizierte Anzeigenaufnahme (Fotos per Handy), Such-Alarme, Favoriten
- Vertrauenslayer: Verifizierungen, Nachrichten-Chats, Melde-/Moderationssystem, Betrugswarnhinweise
- Kategorien mit Gebraucht-/Dienstleistungsmix (auch Wohnungen/Jobs)

## Was Kleinanzeigen NICHT kann

- **keine öffentliche API** für Automatisierung (Scraping widerspricht AGB — nicht empfehlen)
- keine Auktionen/Preisvorschläge; Zahlungsabwicklung nur als optionale Plattformfunktion
- keine Shop-/Lagerverwaltung für Anbieter (nur Anzeigen)
- Datenexport für Normalnutzer begrenzt (DSGVO-Auskussionswege)
