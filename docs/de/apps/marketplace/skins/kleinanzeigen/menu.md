# Kleinanzeigen - Menüpunkte

## Endnutzer-App/Web

| Element | Inhalt |
|---------|--------|
| Kategorien-Baum | Haushaltsgeräte, Möbel, Jobs, Wohnung, Freizeit… |
| Suche/Umkreis | Stichwort + Radius/Umkreis-Karte |
| „+ Anzeige erstellen“ | Kategorie, Titel, Beschreibung, Fotos, Preis, Standort, Abholung/Versand |
| Nachrichten | Chat je Anfrage (mit Teilen von Zahlungs-/Übergabe-Links) |
| Mein Bereich | aktive Anzeigen, Such-Alarme, Favoriten, Sicherheitshinweise |

## Gewerbliche Bereiche

| Bereich | Inhalt |
|---------|--------|
| Unternehmenskonto | Marken-/Händlerprofile, Volumenspakete |
| Partner-Import | für große Händler: **Kooperations-Feeds** (nur nach Vertragsverhältnis) |

## Menüs nach Rolle

Privatnutzer · Gewerbliche (verifizierte Konten) · Moderation (plattformintern).
