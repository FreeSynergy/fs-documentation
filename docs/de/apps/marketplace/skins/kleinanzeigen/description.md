# Kleinanzeigen - Beschreibung

## Was das Programm macht

Kleinanzeigen ist der digitale Dorfmarkt: Anzeigen mit Standort, Chat, Übergabe ums Eck. Als Marktplatz-Referenz steht es für **lokale C2C-Vermittlung ohne Zahlungs- und Logistikkomplexität** — und für die Grenze „Plattform ohne API“.

## Vorteile

- größte lokale Reichweite in DE
- null Hürden für Private
- Karten-/Umkreislogik als Blaupause für Standpunkte-Skins

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **eBay** | Versand/Auktion/Bezahlschicht + APIs |
| **Etsy** | kuratierte Maker-Welt |
| **Sharetribe/Arcemall** | eigener Marktplatz mit API statt fremder Plattform |

## Technische Details

- **Modell**: SaaS-App (Nowint/AVENUE A), Web + iOS/Android
- **Authentifizierung**: Konto (Telefon/E-Mail-Verifizierung)
- **Schnittstellenlage**: keine offene API → Automatisierung nur über Partnerprogramme

## Für wen geeignet

- Community-Projekte, die lokale Angebote **auf** der Plattform pflegen (manuell) — nicht automatisieren
- FreeSynergy-Skins: Kategorien-/Umkreis-Modell nachbauen ([standpunkte.md](../../../maps/standpunkte.md))
