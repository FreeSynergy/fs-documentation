# Etsy - Funktionen

## Hauptfunktionen

- **Kuratierter Marktplatz**: Handmade/Vintage/Design + digitale Download-Artikel, Material-/Anlass-Taxonomie fürs Auffinden
- Shop-Verwaltung mit Varianten, personalisierbaren Listings (Notizfeld bei Kauf), Gutschein-/Sale-Aktionen
- Bewertungen, Lieblingslisten, Geschenk-Guides
- **Open API v3**: Listings (r/w), Receipts (Bestellungen), Shop-Statistiken, Bewertungen — App-Zulassungsprozess (non-commercial vs. commercial)

## Was Etsy NICHT kann

- **keine Auktionen/Preisvorschläge**
- App-Schreibzugriff nur mit zugelassener App/Scopes; keine Marktplatz-Community-Features per API
- keine Warenlager-Komplexität (Chargen/Produktion nur rudimentär)
- Gebühren-/Policy-Regime fest; Kontosperrungen hart
