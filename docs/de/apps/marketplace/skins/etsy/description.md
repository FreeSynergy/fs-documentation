# Etsy - Beschreibung

## Was das Programm macht

Etsy gibt Maker:innen (Näherinnen, Drucker, Illustrator:innen) einen gemeinsamen Marktplatz mit Wiedererkennungs-Ästhetik: Suche über Materialien/Anlässe, Shops mit Geschichte, Bewertungen als Vertrauen. Digitale Produkte erweitern das ohne Versand.

## Vorteile

- zahlungskräftige Nische (Geschenke, Unikat)
- API für Listing-/Order-Automation (mit Zulassung)
- niedrige Einstiegshürde für Kreative

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **eBay** | offene Masse + Auktion |
| **Kleinanzeigen** | regional, ohne Zahlungs-/Schutzschicht |
| **eigener Marktplatz (Sharetribe)** | eigene Marke/Regeln |

## Technische Details

- **Modell**: SaaS, Ländershops (etsy.de)
- **Authentifizierung**: Etsy-Konto; API: API-Key + OAuth2 (Authorization Code + **PKCE**)
- **Zulassung**: App-Akzeptanz erforderlich (bes. Schreibzugriff)

## Für wen geeignet

- Kreative mit Verkaufsautomatisierung (Listing-Pflege, Order-Export in ERP)
- FreeSynergy-Skins: Listing-/Receipt-Reader ([modelle.md](../../../../data/modelle.md))
