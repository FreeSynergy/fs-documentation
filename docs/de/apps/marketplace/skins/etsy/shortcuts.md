# Etsy - Tastatur-Shortcuts

## Übersicht

Etsy dokumentiert **keine Kurzbefehle**.

> Stand: 2026.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Tab`/`Enter` | Kauf-/Listingformulare |
| `Esc` | Overlay (Suchvorschläge) schließen |
| `Strg/Cmd+F` | Seiten (Browser) |

## Ausdrücklich nicht vorhanden

- Speed-Keys

## Mac

`Cmd` bei Browser-Standards.
