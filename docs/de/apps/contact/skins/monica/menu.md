# Monica - Menüpunkte

## Hauptnavigation (oben)

| Menüpunkt | Beschreibung |
|-----------|--------------|
| dashboards | persönliches Dashboard (nächste Aktivitäten, Geburtstage) |
| contact | Kontaktliste mit Filter/Suche |
| activities | Aktivitäten-Chronik aller Kontakte |
| tasks | Aufgabenliste |
| gifts | Geschenke-Übersicht und -Ideen |
| notes | alle Notizen |
| journals | Journal-Bücher (Einträge mit Stimmungen) |
| reports | Statistiken und Jahresrückblick |
| settings | Konto, import/export, api, relationship types, activity types, modules an/aus |

## Personen-Detail (Kontaktseite)

Reiter: **About** (Stammdaten) · **Activities** · **Reminders** · **Tasks** · **Relationships** · **Gifts** · **Notes** · **Debt** (Schulden) · **Life events**

Kopfmenü je Kontakt:
- Bearbeiten, Favorit, Öffentliche VCard-Seite (Share-Link), Druck-/PDF-Ansicht
- „Wichtige Informationen“ (Körpergröße, Kleidung, Allergien …) als benutzerdefinierte Felder
- Kontakt löschen / archivieren

## Settings-Bereich

| Menü | Inhalt |
|------|--------|
| User settings | Sprache, Zeitzone, Einheiten, API-Token erzeugen |
| Personalisation | Beziehungstypen, Aktivitäten-Typen, Kontakt-Feldkategorien |
| Modules | Geschenke, Aufgaben, Aufgaben-Journal, Schulden, life-events an/aus |
| Import/Export | vCard/CSV-Import, JSON/vCard-Export, „Google-Kontakte“-Import |

## Menüs nach Rolle

| Rolle | Sichtbares |
|-------|-----------|
| Inhaber | alles |
| Monitor (lesender Zugang) | Inhalte ohne Bearbeiten-Menüs |
| Contact manager | Kontakte/Aktivitäten bearbeiten, keine Settings |

(„Circles“ teilen Instanzinhalte zwischen Nutzern — jeder sieht nur seinen Circle.)
