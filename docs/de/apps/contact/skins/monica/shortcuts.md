# Monica - Tastatur-Shortcuts

## Übersicht

Monica besitzt **keine dokumentierten App-Shortcuts**; Tastatur folgt den Browser-/Formular-Standards.

> Stand: Monica 4.x.

## Vorhanden (Web-Standard)

| Shortcut | Funktion |
|----------|----------|
| `Tab` / `Shift+Tab` | Formularfelder |
| `Enter` | Formular speichern / Suchfeld bestätigen |
| `Esc` | Modals (Kontakt anlegen, Aktivitäten-Dialog) schließen |
| `/` | Suchfeld fokussieren — **nur in manchen Views**, sonst `Tab`-Tour |
| `Strg/Cmd+F` | Browser-Suche auf der Seite |

## Nicht vorhanden (markiert)

| Angenommen | Status |
|------------|--------|
| `N` neuer Kontakt | ❌ |
| `A` neue Aktivität | ❌ |
| Globale Navigation per Buchstaben | ❌ |

## Mac

`Cmd` statt `Strg` bei Browser-Tasten.
