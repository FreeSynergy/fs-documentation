# GNOME Contacts - Menüpunkte

## Übersicht

GNOME Contacts hat **keine Menüleiste** — alles hängt an der HeaderBar und den Kontext-Menüs (⋮).

## Hauptmenü (⋮ rechts oben)

| Eintrag | Beschreibung |
|---------|--------------|
| Neuer Kontakt | leere Karte anlegen |
| Importieren… | vCard-Datei importieren |
| Exportieren… | alle Kontakte als `.vcf` |
| Kontakte zusammenführen | Duplikate zusammenführen |
| Print | Kontaktliste drucken |
| Help / Keyboard Shortcuts / About | Standard-GNOME-Punkte |

## Kontaktansicht

- Bearbeiten-Schalter (Schalter „Edit“): alle Felder inline; „+“ fügt Feldtypen hinzu (Telefon, E-Mail, Adresse, Geburtstag, Notiz, Website, Zusammenhang)
- Kopfaktion-Menü des Kontakts: **Löschen**, **Kontakt als vCard speichern**, **Zusammenführen mit…**
- Foto per Drag&Drop ins Porträt

## Quellen (Primär-/Zweitadressbücher)

- Quelle wird im Feld „Adresse“ der Karte gewählt
- Konto-Quellen kommen aus **GNOME-Online-Konten** (Google, ownCloud/Nextcloud CardDAV, LDAP via EDS)

## Menüs nach Rolle

Keine Konten/Rollen — Zugriff ergibt sich aus den EDS-Quellen (schreibbar/readonly, z.B. LDAP = readonly).
