# GNOME Contacts - Tastatur-Shortcuts

## Übersicht

GNOME Contacts unterstützt die GNOME-Standardtasten; im Help-Overlay (`?`) sind sie aufgelistet.

> Stand: gnome-contacts 45+.

## Global

| Shortcut | Funktion |
|----------|----------|
| `Strg+N` | Neuer Kontakt |
| `Ctrl+F` bzw. direktes Tippen | Suche fokussieren |
| `Esc` | Detail/Bearbeitung verlassen |
| `F10` oder `.` | Hauptmenü ⋮ öffnen (GTK/GNOME-Konvention) |
| `Strg+I` | Import (in neueren Versionen im Menü; Tastenbelegung prüfen) |

## Bearbeiten

| Shortcut | Funktion |
|----------|----------|
| `Tab` | nächstes Feld |
| `Enter` | Feld bestätigen |
| `Entf` | markiertes Feld löschen (im Editiermodus) |

## GNOME-Global (App-Wechsel)

| Shortcut | Funktion |
|----------|----------|
| `Super` | Activities — Kontakte durch Tippen finden |
| `Alt+Tab` | App-Wechsel |

## Mac-Varianten

Entfällt (nur Linux).

## Ausdrücklich nicht vorhanden

- keine Ein-Buchstaben-Aktionen wie `m` mail, `p` phone
- kein ShortCut zum Drucken (Menü „⋮ → Print“)
