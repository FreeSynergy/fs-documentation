# Immich - Menüpunkte

## Hauptnavigation (linke Leiste der Web-App)

| Menü | Beschreibung |
|------|--------------|
| Fotos | Zeitleiste aller eigenen Aufnahmen (Tag/Monat/Jahr) |
| Alben | eigene Alben, von anderen geteilte Alben |
| Durchsuchen | Personen, Orte, Objekte, Schlagwörter, Lieblingsansichten |
| Favoriten | als Favorit markierte Aufnahmen |
| Geteilt | von anderen Nutzern geteilte Aufnahmen/Alben |
| Archive | archiviertes Material (aus Zeitleiste ausgeblendet) |
| Mülleimer | gelöschte Aufnahmen, 30 Tage aufhebbar |
| Upload | Datei-Auswahl, Duplikaterkennung, Hintergrund-Upload |

## Benutzer-Menü (Avatar unten links)

Einstellungen (Sprache, Theme, Datumsformat), Freigabe-Links, Abmelden, Speicherplatz

## Verwaltungs-Menü (Administration, nur Admin)

| Menü | Inhalt |
|------|--------|
| Benutzer | anlegen, Rollen (Admin/Benutzer), Quotas, Löschung |
| Bibliotheken | externe Ordner als Bibliothek einbinden (SCAN) |
| Jobs | Warteschlangen (Thumbnail, ML, Duplikate, Face, Upload) neu anstoßen |
| Storage-Template | Pfad-/Namensschema für gespeicherte Dateien |
| Machine Learning | Modelle, Geräte (CPU/GPU), Aktivierung |
| Server-Status / Logs | Versionen, Modell-Downloads, Log-Suche |
| PARTNER | Partnerkonto für gemeinsame Zeitleiste |
| Webhooks / Notifications | Ereignisse nach extern melden |

## Kontextmenüs

| Objekt | Aktionen |
|--------|----------|
| Einzelne Aufnahme | Favorit, Archive, Download, Löschen, Bearbeiten (Crop), Info, similar |
| Mehrfachauswahl | Album hinzufügen, teilen, Tag, Archive, Löschen, Zusammenführen (Stack) |
| Album | Teilen (Link/Benutzer), Bearbeiten, Löschen, Cover setzen |
| Person | Name setzen, Geburtstag, Personen zusammenführen, Favorit, Cover |

## Menüs nach Rolle

| Rolle | Sichtbar |
|-------|----------|
| Benutzer | Fotos, Alben, Suche, Teilen, Mülleimer |
| Admin | zusätzlich kompletter Verwaltungs-Bereich |
| Gast (Share-Link) | nur die freigegebene Galerie, Download je nach Erlaubnis |
