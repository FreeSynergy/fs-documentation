# Immich - Tastatur-Shortcuts

## Übersicht

Die Web-App kennt Shortcuts für Navigation, Auswahl und Aktionen im Viewer. In Eingabefeldern sind die Tasten außer `Esc` deaktiviert.

> Stand: Immich 1.1xx (Web-App). Mobile Apps haben keine Tastatur-Shortcuts.

## Global

| Shortcut | Funktion |
|----------|----------|
| `/` | Suchfeld fokussieren |
| `Esc` | Viewer/Auswahl/Dialog schließen |
| `u` | Upload-Dialog öffnen |
| `a` | Alles im aktuellen Ansichtsbereich auswählen |
| `Ctrl/Cmd+A` | Auswahl alles (im Auswahlmodus) |

## Auswahl und Aktionen

| Shortcut | Funktion |
|----------|----------|
| `Shift + Klick` | Bereich auswählen |
| `Shift + Pfeiltaste` | Auswahl erweitern |
| `Backspace`/`Entf` | Auswahl in den Mülleimer |
| `Ctrl/Cmd+S` | Favorit umschalten (Heart) |
| `Ctrl/Cmd+D` | Download der Auswahl |
| `i` | Detail-/EXIF-Panel im Viewer |

## Viewer

| Shortcut | Funktion |
|----------|----------|
| `←` / `→` | vorheriges / nächstes Medium |
| `Space` | Diashow starten/pausieren |
| `m` | Kartenansicht des Aufnahmorts |
| `e` | Bearbeiten (Crop/Rotate) |
| `h` | im Viewer: Favorit |

## Nicht vorhanden (bewusst)

| Angenommen | Status |
|------------|--------|
| Ein-Tasten-Kommandomodus (Vim-artig) | ❌ |
| Shortcut für „Album erstellen“ | ❌ (nur Menü/Toolbar) |
| Globaler Delete-Undo-Shortcut | ❌ (Mülleimer öffnen) |

## Mac

`Cmd` statt `Ctrl`, etwa `Cmd+S` (Favorit), `Cmd+D` (Download).
