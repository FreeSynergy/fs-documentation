# Damselfly - Menüpunkte

## Hauptnavigation

| Menü | Beschreibung |
|------|--------------|
| Suche | Text-/Ähnlichkeitssuche, Filter (Ordner, Zeitraum, Typ, Label) |
| Alben | gespeicherte Sammlungen, Ordner-Alben |
| Personen | Gesicht-Cluster mit Namen |
| Szenen / Labels | erkannte Szenen, Objekte, Texte (OCR) |
| Ordner | Abbild des überwachten Bibliotheksordners |
| Favoriten | markierte Bilder |
| Teilen | öffentliche Links und eingebettete Galerien |

## Upload und Sync

- **Upload**: Drag & Drop, ganzer Ordner, Bulk-Aktionen
- **Ordner-Sync**: „Push“ (Hochladen) und „Pull“ (Import vom Server-Ordner)
- **Duplikate**: Prüfsummenvergleich mit Bereinigungsansicht

## Verwaltung (Admin)

| Bereich | Inhalt |
|---------|--------|
| Index | Scan-Status, ausstehende Aufgaben, Modelle neu anwenden |
| Modelle | aktivierte KI-Modelle (Faces, Labels, OCR, Similarity), GPU-Hinweis |
| Benutzer | Konten, Rollen, Quotas |
| Galerie | Wasserzeichen, Download-Rechte, öffentliche Links |
| System | Logs, Storage-Belegung, Backups |

## Menüs nach Rolle

| Rolle | Sichtbar |
|-------|----------|
| Gast | öffentliche Alben und Links |
| Benutzer | eigene Bibliothek, Upload, Alben, Suche |
| Admin | zusätzlich Verwaltung, Modelle, Sync |
