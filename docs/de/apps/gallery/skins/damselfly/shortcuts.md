# Damselfly - Tastatur-Shortcuts

## Übersicht

Kurzbefehle decken Suche, Auswahl und Viewer ab; die Verwaltung hat keine eigenen Kürzel.

> Stand: Damselfly 2.x.

## Suche und Auswahl

| Shortcut | Funktion |
|----------|----------|
| `/` oder `S` | Suchfeld fokussieren |
| `Ctrl/Cmd+A` | alle sichtbaren Bilder auswählen |
| `Shift + Klick` | Bereichsauswahl |
| `Esc` | Auswahl, Filter oder Viewer schließen |
| `Del` | Auswahl löschen (mit Rückfrage) |

## Viewer

| Shortcut | Funktion |
|----------|----------|
| `←` / `→` | vorheriges / nächstes Bild |
| `i` | Detail-/EXIF-Drawer |
| `f` | Favorit umschalten |
| `d` | Download |
| `Space` | Diashow starten/pausieren |
| `Esc` | Viewer schließen |
