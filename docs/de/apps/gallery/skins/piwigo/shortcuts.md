# Piwigo - Tastatur-Shortcuts

## Übersicht

Shortcuts gibt es vor allem auf der Bildseite und in der Slideshow; die Administration nutzt keine eigenen Kürzel.

> Stand: Piwigo 14.x / 15.x (Standard-Themes).

## Bildseite und Slideshow

| Shortcut | Funktion |
|----------|----------|
| `←` / `→` | vorheriges / nächstes Bild |
| `n` | nächstes Bild (Alternative) |
| `p` | vorheriges Bild |
| `s` | Slideshow starten/pausieren |
| `i` | Bildinformationen ein-/ausblenden |
| `c` | Kommentarfeld fokussieren (je Theme) |
| `f` | Favorit markieren (angemeldet) |
| `Esc` | Lightbox schließen |
| `h` | Bild in Originalgröße öffnen (je Recht) |

## Administration

| Shortcut | Funktion |
|----------|----------|
| `Tab` / `Shift+Tab` | Formularfelder |
| `Strg/Enter` | Kommentar absenden |
| `Esc` | Dialog/Lightbox schließen |

## Nicht vorhanden (bewusst)

| Angenommen | Status |
|------------|--------|
| Kommandopalette im Admin-Bereich | ❌ |
| Globaler Upload-Shortcut | ❌ |
| Undo für Batch-Aktionen | ❌ |

## Mac

`Cmd` statt `Strg` (Kommentar senden), Buchstabentasten unverändert.
