# Coppermine - Tastatur-Shortcuts

## Übersicht

Coppermine bringt **keine eigenen Tastaturkürzel** mit. Wirkt nur, was Browser und eingesetzte Lightbox-Plugins bereitstellen.

> Stand: Coppermine 1.6.x / aktuelle Entwicklungszweige.

## Browser- und Plugin-Verhalten

| Shortcut | Funktion | Herkunft |
|----------|----------|----------|
| `←` / `→` | vorheriges/nächstes Bild | nur mit Lightbox-Plugin |
| `Esc` | Lightbox schließen | Plugin |
| `Tab` / `Shift+Tab` | Formularfelder | Browser |
| `Enter` | Formulare absenden | Browser |

## Gallery-Navigation (Webseite)

| Angenommen | Status |
|------------|--------|
| Buchstaben-Navigation (`n`/`p`) | ❌ |
| Kommandopalette | ❌ |
| Shortcut für Upload | ❌ |
| Undo für Batch-Aktionen | ❌ |

## Mac

Browser-Standard (`Cmd` statt `Strg`), weiter keine Programm-Shortcuts.

## Skin-Hinweis

Bei der Nachbildung in FreeSynergy sollten die in anderen Galerie-Skins üblichen Kürzel (`←`/`→`, `Esc`, `f` für Favorit) ergänzt und als **FreeSynergy-Erweiterung** gekennzeichnet werden.
