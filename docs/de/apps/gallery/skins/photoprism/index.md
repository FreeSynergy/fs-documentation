# PhotoPrism Dokumentation

## Übersicht

PhotoPrism indexiert eine vorhandene Fotosammlung, erkennt Inhalte und Gesichter und präsentiert sie als durchsuchbare Web-Galerie mit Alben und Freigaben. Stack: Go-Backend (Plus-Variante mit erweiterter KI), Vue-Frontend, MariaDB/SQLite, Index auf eigenem Ordner.

## Dateistruktur

- [menu.md](menu.md) - Hauptnavigation, Ordner-/Alben-Menüs, Einstellungen, Admin
- [features.md](features.md) - Indexierung, Labels, Gesichter, Alben, Was PhotoPrism NICHT kann
- [description.md](description.md) - Abgrenzung zu Immich, LibrePhotos und Piwigo
- [structure.md](structure.md) - Suchleiste, Mosaik, Detail-Panel, Ordneransicht
- [shortcuts.md](shortcuts.md) - Shortcuts von Suche und Viewer
- [api.md](api.md) - REST `/api/v1`, Basic/Bearer, Batch-Index, Webhooks
