# PhotoPrism - Tastatur-Shortcuts

## Übersicht

Shortcuts gelten in Suche, Mosaik und Viewer; in Textfeldern sind sie außer `Esc`/`Enter` deaktiviert.

> Stand: PhotoPrism CE/Plus 24.x–25.x.

## Suche und Auswahl

| Shortcut | Funktion |
|----------|----------|
| `S` oder `/` | Suchfeld fokussieren |
| `A` | alle sichtbaren Fotos auswählen |
| `Shift + Klick` | Bereichsauswahl |
| `Esc` | Auswahl/Dialog schließen |
| `F1` | Shortcut-Übersicht |

## Aktionen

| Shortcut | Funktion |
|----------|----------|
| `L` | Label-Dialog für die Auswahl |
| `B` | in Album verschieben / hinzufügen |
| `F` | Favorit umschalten |
| `H` | veröffentlichen / verstecken |
| `R` | als Ordner-Alben-Ansicht (Ordner aktualisieren) |
| `Del` | aus dem Index entfernen (nicht vom Datenträger löschen) |
| `Ctrl/Cmd+A` | alles im aktuellen Ergebnis auswählen |

## Viewer

| Shortcut | Funktion |
|----------|----------|
| `←` / `→` | vorheriges / nächstes Bild |
| `Space` | Diashow starten/pausieren |
| `I` | INFO-Panel (EXIF) |
| `M` | Karte des Aufnahmeorts |
| `P` | Teilen-Dialog |
| `Esc` | Viewer schließen |

## Nicht vorhanden (bewusst)

| Angenommen | Status |
|------------|--------|
| Vim-artige Modus-Tasten | ❌ |
| Shortcut zum Umbenennen | ❌ (Kontextmenü) |
| Undo-Shortcut | ❌ |

## Mac

`Cmd` statt `Ctrl` (`Cmd+A`), übrige Tasten identisch.
