# Lychee Dokumentation

## Übersicht

Lychee ist eine schlanke, selbst gehostete Fotogalerie mit Alben, Freigaben per Link und einer sauberen REST-API. Stack: PHP/Laravel, MySQL/MariaDB/PostgreSQL, React-Frontend (Lychee-front), Version 5 mit getrenntem Frontend.

## Dateistruktur

- [menu.md](menu.md) - Galerie-Navigation, Album-Menüs, Einstellungen
- [features.md](features.md) - Alben, Freigaben, Diashow, Was Lychee NICHT kann
- [description.md](description.md) - Abgrenzung zu Piwigo, PhotoPrism und Immich
- [structure.md](structure.md) - Album-Kacheln, Lightbox, Admin-Panel
- [shortcuts.md](shortcuts.md) - Lightbox- und Album-Tastenkürzel
- [api.md](api.md) - REST `/api`, Token-Auth, Album-/Photo-Endpunkte
