# VSCodium - Menüpunkte

## Übersicht

VSCodium ist eine Open-Source-Version von Microsoft Visual Studio Code. Es ist ein quelloffener, plattformübergreifender Quellcode-Editor mit umfangreichen Funktionen für Entwickler.

## Hauptmenüpunkte

### 1. Datei
- **Funktion**: Datei-Operationen
- **Details**:
  - Neue Datei
  - Öffnen
  - Speichern
  - Speichern unter
  - Schließen
  - Einstellungen
  - Benutzer-Einstellungen
  - Farbschema auswählen

### 2. Bearbeiten
- **Funktion**: Bearbeitungs-Operationen
- **Details**:
  - Rückgängig/Wiederholen
  - Ausschneiden/Kopieren/Einfügen
  - Suche & Ersetzen
  - Formatieren
  - Zeilen umschreiben

### 3. Ansicht
- **Funktion**: Layout und Ansichten
- **Details**:
  - Explorer (Dateibaum)
  - Suchen (Dateisuche)
  - Quellcode-Management (Git)
  - Ausführen & Debuggen
  - Erweiterungen
  - Benutzerdefiniertes Layout
  - Pane-Manager (Sidebar, Activity Bar)

### 4. Go
- **Funktion**: Navigation
- **Details**:
  - Zurück/Zurück
  - Sprungdefinition
  - Definition anzeigen
  - Implementierungen
  - Symbol in Datei suchen
  - Zeile springen

### 5. Terminal
- **Funktion**: Terminal-Operationen
- **Details**:
  - Terminal öffnen
  - Terminal neu erstellen
  - Terminal teilen
  - Terminal schließen
  - Befehle ausführen

### 6. Hilfethemen
- **Funktion**: Hilfe und Informationen
- **Details**:
  - Willkommen
  - Versionsinformationen
  - Lizenz
  - Feature-Anfragen
  - Datenschutzerklärung

### 7. Kontext-Menü (rechte Maustaste)
- **Funktion**: Kontextbezogene Aktionen
- **Details**:
  - Kopieren/Pfad kopieren
  - Datei öffnen
  - In Explorer zeigen
  - Terminal hier öffnen
  - Vergleichen mit gespeicherter Datei

## Menüs nach Ansicht

### Explorer-Menü
- Ordner öffnen
- Datei hinzufügen
- Ordner hinzufügen
- Löschen
- Umbenennen

### Source Control-Menü
- Änderungen committen
- Push/Pull
- Branches verwalten
- Konflikte beheben

### Debugging-Menü
- Starten (F5)
- Haltepunkte verwalten
- Ausdrucksüberwachung
- Call Stack anzeigen
