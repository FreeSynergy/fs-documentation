# XWiki - Beschreibung

## Übersicht

XWiki ist eine leistungsstarke Enterprise-Wiki-Plattform mit erweiterten Funktionen für Wissensmanagement und Zusammenarbeit.

## Was XWiki macht

XWiki ist eine Enterprise-Wiki-Plattform, die auf Java basiert und für große Unternehmen und Organisationen mit hohen Anforderungen an Skalierbarkeit, Sicherheit und Integration konzipiert ist.

## Vorteile

- **Enterprise-Ready**: Skalierbar für große Organisationen mit vielen Benutzern
- **Java-basiert**: Stabil und robust auf Java-Ebene
- **Makro-System**: Extrem flexibles Makro-System für komplexe Inhalte
- **Velocity-Skripting**: Mächtige Server-seitige Skripting-Sprache
- **Zweigeteilte Berechtigung**: Page-level und Space-level Berechtigungen
- **Import/Export**: Mehrere Formate (Word, PDF, HTML, XML)
- **REST API**: Umfangreiche API für Integrationen

## Abgrenzung zu anderen Systemen

### XWiki vs. MediaWiki
- **MediaWiki** ist für große Community-Projekte wie Wikipedia optimiert
- **XWiki** ist für Enterprise-Nutzer mit komplexen Berechtigungen optimiert
- **XWiki** hat ein flexibles Makro-System, **MediaWiki** ist einfacher

### XWiki vs. Confluence
- **Confluence** ist kommerziell mit Lizenzkosten
- **XWiki** ist Open Source und kostenlos (Enterprise-Version verfügbar)
- **Confluence** hat bessere Jira-Integration, **XWiki** ist flexibler

### XWiki vs. Notion
- **Notion** ist für agile Teams und schnelles Schreiben
- **XWiki** ist für strukturierte Enterprise-Dokumentation
- **XWiki** hat bessere Versionierung und Audit-Logs

## Technische Details

- **Backend**: Java (Servlet Container)
- **Database**: PostgreSQL, MySQL, HSQLDB, Oracle
- **Frontend**: JavaScript, Velocity Templates
- **Authentication**: LDAP, SSO, OpenID Connect
- **Hosting**: Self-Hosted oder Cloud

## Für wen ist XWiki geeignet?

- **Große Unternehmen**: Für komplexe Wissensmanagementsysteme
- **Open-Source-Projekte**: Für strukturierte Dokumentation
- **Unternehmen mit Jira/Confluence**: Als Open-Source-Alternative
- **Bildungseinrichtungen**: Für strukturierte Lehrmaterialien
