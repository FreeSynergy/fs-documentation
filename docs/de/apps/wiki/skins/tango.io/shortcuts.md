# Tango.io - Tastatur-Shortcuts

## Übersicht

Tango.io bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten mit dem blockbasierten visuellen Editor.

---

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Shift+P` / `Cmd+Shift+P` | Befehlspalette öffnen |
| `Ctrl+,` / `Cmd+,` | Einstellungen öffnen |
| `F1` | Hilfe |
| `Ctrl+K` / `Cmd+K` | Link hinzufügen |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | Global Suche |

---

## Editor Shortcuts (Block-Editor)

### Block-Navigation

| Shortcut | Funktion |
|----------|----------|
| `Enter` | Neue Zeile / Block erstellen |
| `Shift+Enter` | Zeilenumbruch (innerhalb eines Blocks) |
| `Tab` | Einrücken (Listen) |

| `Escape` | Block verlassen / Fokus verlieren |

## Zusammenfassung

Tango.io bietet umfangreiche Shortcuts für:
- **Block-Navigation**: schnelles Arbeiten mit dem blockbasierten Editor
- **Block-Aktionen**: duplizieren, löschen, kopieren, verschieben
- **Formatierung**: Alle gängigen Formatierungen
- **Block-Typen**: zwischen verschiedenen Block-Typen wechseln
- **Codesyntax**: direkt in der Code-Blöcken-Sprache wechseln
- **Navigation**: editor-intern und zwischen Komponenten
- **Datei-Operationen**: Speichern, Öffnen, Drucken, Export
- **Suche**: Lokal und global
- **Ansicht**: Vollbild, Sidebar, Vorschau

Mac-Nutzer profitieren von den gleichen Shortcuts mit `Cmd` anstelle von `Ctrl`.
