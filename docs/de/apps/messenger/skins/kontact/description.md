# Kontact - Beschreibung

## Übersicht

Kontact ist eine integrierte Personal Information Manager (PIM)-Anwendung für das KDE-Desktop-Environment. Es kombiniert mehrere bekannte KDE-Anwendungen (KMail, KAddressBook, KOrganizer, KNotes) zu einer einzigen, konsolidierten Anwendung.

## Was Kontact macht

Kontact ist eine umfassende Informationsverwaltungsanwendung, die speziell für Linux-Benutzer entwickelt wurde, die eine integrierte Lösung für E-Mail, Kalender, Kontakte, Aufgaben und Notizen suchen. Es ist Teil der KDE PIM (Personal Information Management) Suite.

## Vorteile

- **Open Source**: Kostenlos und quelloffen unter GPL-Lizenz
- **Linux-nativ**: Optimale Integration mit KDE Plasma
- **Integrierte Lösung**: E-Mail, Kalender, Kontakte, Aufgaben, Notizen in einer Anwendung
- **KDE-Integration**: Nahtlose Integration mit anderen KDE-Anwendungen
- **KMail**: Eine der leistungsstärksten E-Mail-Clients mit fortgeschrittenen Filterfunktionen
- **KOrganizer**: Umfassender Kalender mit Kalenderfreigaben und Abonnements
- **KAddressBook**: Vollständiges Adressbuch mit VCard-Unterstützung
- **KNotes**: Einfache Notizverwaltung
- **Synchronisation**: Sync mit CardDAV, CalDAV, IMAP, Exchange (via WebDAV)
- **Plugins**: Erweiterbare Architektur mit Plugin-System

## Abgrenzung zu anderen Systemen

### Kontact vs. Outlook
- **Kontact** ist Open Source und kostenlos, **Outlook** ist kommerziell mit Microsoft 365-Lizenz
- **Kontact** hat native KDE-Integration, **Outlook** hat native Microsoft-Integration
- **Outlook** hat bessere Exchange-Integration über MAPI, **Kontact** über WebDAV/IMAP
- **Kontact** ist plattformunabhängig (Linux, Windows, macOS), **Outlook** primär Windows/macOS

### Kontact vs. Thunderbird
- **Kontact** ist KDE-native Anwendung mit integrierter UI, **Thunderbird** ist eigener E-Mail-Client
- **Kontact** hat bessere Kalender-Integration (KOrganizer), **Thunderbird** über Erweiterungen
- **Thunderbird** hat breitere Plattformunterstützung, **Kontact** primär Linux

### Kontact vs. Element/Discord
- **Kontact** ist für E-Mail und PIM-Funktionen, **Element/Discord** für Chat und Community
- **Kontact** hat Kalender und Aufgaben, **Element/Discord** haben keine integrierten PIM-Funktionen

## Technische Details

- **Platform**: Linux (primär), Windows, macOS
- **Desktop Environment**: KDE Plasma
- **Backend**: IMAP, POP3, SMTP, CardDAV, CalDAV, WebDAV (Exchange)
- **Datenspeicher**: Maildir, MBOX
- **Authentication**: OAuth2, Basic Auth, NTLM
- **Verschlüsselung**: GnuPG (GPG), S/MIME
- **Synchronisation**: WebDAV, CardDAV, CalDAV
- **Programming Language**: C++ (Qt-Framework)

## Für wen ist Kontact geeignet?

- **Linux-Benutzer**: Vor allem für KDE Plasma-Nutzer
- **Open Source Enthusiasten**: Für diejenigen, die quelloffene Software bevorzugen
- **E-Mail-Nutzer**: Für professionelle E-Mail-Kommunikation mit fortgeschrittenen Funktionen
- **KDE-Nutzer**: Für diejenigen, die bereits KDE Plasma verwenden
- **PIM-Nutzer**: Für diejenigen, die E-Mail, Kalender, Kontakte in einer Anwendung verwalten wollen
