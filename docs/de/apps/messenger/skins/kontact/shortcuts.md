# Kontact - Tastatur-Shortcuts

## Übersicht

Kontact bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten in allen Komponenten.

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `F1` | Hilfe |
| `F5` | Aktualisieren |
| `Ctrl+Q` | Beenden |
| `Ctrl+W` | Fenster schließen |
| `Ctrl+Shift+W` | Alle Fenster schließen |
