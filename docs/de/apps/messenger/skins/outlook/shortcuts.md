# Outlook - Tastatur-Shortcuts

## Übersicht

Outlook bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten.

## Benutzerdefinierte Shortcuts

Outlook erlaubt das Anpassen von Shortcuts über:
- **Quick Steps**: Benutzerdefinierte Aktionen mit Shortcut
- **Menü anpassen**: Über Datei > Optionen > Band anpassen
- **Add-ins**: Erweiterungen für benutzerdefinierte Shortcuts
