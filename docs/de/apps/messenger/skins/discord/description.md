# Discord - Beschreibung

## Übersicht

Discord ist ein proprietary Communication-Plattform und Chat-Client, der ursprünglich für Gaming-Communities entwickelt wurde, mittlerweile aber für alle Arten von Communities verwendet wird. Discord bietet voice-over-IP, Video, Textchat und Bildschirmfreigabe.

## Was Discord macht

Discord ist eine Kommunikationsplattform, die speziell für die Erstellung und Verwaltung von Communities entwickelt wurde. Sie ermöglicht Gruppenchat in Servern mit mehreren Kanälen, voice und video calls, sowie Bildschirmfreigabe für Streaming und Gaming.

## Vorteile

- **Voice- und Videoanrufe**: Native Voice- und Videoanrufe mit hoher Qualität
- **Server-Struktur**: Organisieren von Communities in Servern mit Kanälen
- **Bildschirmfreigabe**: Native Bildschirmfreigabe für Streaming
- **Gaming-Fokus**: Optimiert für Gaming-Communities
- **Cross-Platform**: Funktioniert auf Windows, macOS, Linux, iOS, Android, Web
- **Integrationen**: Viele Integrationen mit externen Diensten
- **Bots**: Umfangreiches Bot-System für Automatisierung
- **Moderation**: Umfangreiche Moderationswerkzeuge
- **Kostenlos**: Kostenlos für alle Funktionen (mit Premium-Optionen)

## Abgrenzung zu anderen Systemen

### Discord vs. Element
- **Discord** ist proprietär und zentral, **Element** ist Open Source und dezentral
- **Discord** hat native Voice/Video, **Element** hat es via VoIP-Protokoll
- **Element** hat E2E-Verschlüsselung standardmäßig, **Discord** nur in Privatnachrichten
- **Discord** hat mehr Gaming-Features, **Element** hat mehr Privacy

### Discord vs. Telegram
- **Discord** hat native Voice/Video, **Telegram** hat es via VoIP
- **Discord** hat Server-Struktur, **Telegram** hat Channels/Groups
- **Telegram** hat Secret Chats mit E2E-Verschlüsselung, **Discord** nur in Privatnachrichten
- **Discord** hat mehr Moderations-Tools

### Discord vs. Mastodon
- **Discord** ist für Chat und Gruppen, **Mastodon** ist für Mikroblogging
- **Discord** hat Voice/Video, **Mastodon** hat keine Voice/Video
- **Discord** ist zentral, **Mastodon** ist dezentral über Instanzen

## Technische Details

- **Platform**: Windows, macOS, Linux, iOS, Android, Web
- **Protokoll**: Proprietäres Discord-Protokoll
- **Backend**: Eigenes Discord-Backend
- **Voice/Video**: WebRTC für Voice/Video-Anrufe
- **Verschlüsselung**: TLS für Datenübertragung, keine E2E-Verschlüsselung
- **Authentication**: OAuth2, Email/Password
- **Bots**: Discord-Bots via API
- **Programming Language**: TypeScript, React (Web), Kotlin (Android), Swift (iOS)

## Für wen ist Discord geeignet?

- **Gaming-Communities**: Für diejenigen, die Gaming-Communities betreiben wollen
- **Freizeit-Communities**: Für diejenigen, die Freizeit-Communities betreiben wollen
- **Unternehmen**: Für diejenigen, die Team-Kommunikation betreiben wollen
- **Streamer**: Für diejenigen, die Stream-Communities betreiben wollen
- **Large Communities**: Für diejenigen, die große Communities betreiben wollen
