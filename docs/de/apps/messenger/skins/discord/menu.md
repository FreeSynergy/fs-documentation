# Discord - Menüpunkte

## Übersicht

Discord ist ein proprietary Communication-Plattform und Chat-Client, der ursprünglich für Gaming-Communities entwickelt wurde, mittlerweile aber für alle Arten von Communities verwendet wird.

## Hauptmenüpunkte

### 1. Server-Menü (Links)
- **Funktion**: Server-Verwaltung
- **Details**:
  - Server erstellen/betreten
  - Server-Einstellungen
  - Server-Icon/Name ändern
  - Server-Rollen verwalten

### 2. Kanal-Menü (Links)
- **Funktion**: Kanal-Verwaltung
- **Details**:
  - Text-Kanal betreten
  - Voice-Kanal betreten
  - Kanal-Einstellungen
  - Kanal-Berechtigungen

### 3. Chat-Menü (Mitte)
- **Funktion**: Chat-Kommunikation
- **Details**:
  - Nachrichten senden
  - Nachrichten bearbeiten/löschen
  - Nachrichten markieren
  - Nachrichten zitieren
  - Emoji einfügen
  - GIFs einfügen

### 4. Voice-Menü (Rechts)
- **Funktion**: Voice- und Video-Anrufe
- **Details**:
  - Audio-Anruf starten
  - Video-Anruf starten
  - Bildschirmfreigabe
  - Mikrofon steuern
  - Lautstärke steuern

### 5. Mitglieder-Menü (Rechts)
- **Funktion**: Mitglieder verwalten
- **Details**:
  - Mitgliederliste anzeigen
  - Mitglieder einladen
  - Mitglieder kicken
  - Mitglieder verbannen
  - Mitglieder-Rollen ändern

### 6. Einstellungen
- **Funktion**: Einstellungen verwalten
- **Details**:
  - Allgemeine Einstellungen
  - Medieneinstellungen
  - Sicherheitseinstellungen
  - Theme-Einstellungen
  - Spracheinstellungen

### 7. Hilfefunktionen
- **Funktion**: Hilfefunktionen
- **Details**:
  - Hilfedokumentation
  -Über Discord
  - Problemlösung
