# Telegram - Menüpunkte

## Übersicht

Telegram ist ein Cloud-basierter Messenger mit Fokus auf Geschwindigkeit und Sicherheit. Er ist für viele Plattformen verfügbar und bietet verschlüsselte Chats, große Gruppen und Kanäle für Broadcasts.

## Hauptmenüpunkte

### 1. Chat-Menü (Links)
- **Funktion**: Chat-Verwaltung
- **Details**:
  - Neuer Chat starten
  - Gruppen erstellen
  - Kanal erstellen
  - Geheime Chats starten
  - Chat-Suchfeld

### 2. Chat-Liste (Links)
- **Funktion**: Chat-Übersicht
- **Details**:
  - Aktive Chats anzeigen
  - Gruppen anzeigen
  - Kanäle anzeigen
  - Geheime Chats anzeigen
  - Chat-Sortierung

### 3. Nachrichten-Menü (Mitte)
- **Funktion**: Nachrichten verwalten
- **Details**:
  - Nachrichten senden
  - Nachrichten bearbeiten/löschen
  - Nachrichten markieren
  - Nachrichten zitieren
  - Nachrichten weiterleiten
  - Medien senden

### 4. Media-Menü (Mitte)
- **Funktion**: Medien verwalten
- **Details**:
  - Fotos hochladen
  - Videos hochladen
  - Dokumente hochladen
  - Medien vorschau
  - Medien herunterladen

### 5. Mitglieder-Menü (Rechts)
- **Funktion**: Mitglieder verwalten
- **Details**:
  - Mitgliederliste anzeigen
  - Mitglieder einladen
  - Mitglieder kicken
  - Mitglieder bearbeiten
  - Rollen verwalten

### 6. Einstellungen
- **Funktion**: Einstellungen verwalten
- **Details**:
  - Allgemeine Einstellungen
  - Medieneinstellungen
  - Sicherheitseinstellungen
  - Theme-Einstellungen
  - Spracheinstellungen

### 7. Hilfefunktionen
- **Funktion**: Hilfefunktionen
- **Details**:
  - Hilfedokumentation
  -Über Telegram
  - Problemlösung
