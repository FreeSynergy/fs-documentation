# Telegram - Beschreibung

## Übersicht

Telegram ist ein Cloud-basierter Messenger mit Fokus auf Geschwindigkeit und Sicherheit. Er ist für viele Plattformen verfügbar und bietet verschlüsselte Chats, große Gruppen und Kanäle für Broadcasts.

## Was Telegram macht

Telegram ist ein Cloud-basierter Nachrichtendienst, der speziell für schnelle und sichere Kommunikation entwickelt wurde. Er ermöglicht Einzel- und Gruppenchats, große Kanäle für Broadcasts, verschlüsselte "Geheime Chats" und die Übertragung großer Dateien.

## Vorteile

- **Geschwindigkeit**: Sehr schnelle Übertragung von Nachrichten
- **Cloud-basiert**: Nachrichten werden in der Cloud gespeichert
- **Verschlüsselung**: Verschlüsselte "Geheime Chats" mit E2E-Verschlüsselung
- **Große Gruppen**: Gruppen bis zu 200.000 Mitglieder
- **Große Kanäle**: Kanäle mit unbegrenzten Abonnenten
- **Dateigröße**: Dateien bis zu 2 GB senden
- **Cross-Platform**: Funktioniert auf Windows, macOS, Linux, iOS, Android, Web
- **Bots**: Umfangreiches Bot-System für Automatisierung
- **Open API**: Offene API für Entwickler
- **Kostenlos**: Kostenlos für alle Funktionen

## Abgrenzung zu anderen Systemen

### Telegram vs. Discord
- **Telegram** ist für Messaging und Broadcasts, **Discord** ist für Chat und Community-Server
- **Discord** hat native Voice/Video, **Telegram** hat Voice/Video über VoIP
- **Telegram** hat große Gruppen/Kanäle, **Discord** hat Server mit Limits
- **Discord** hat mehr Gaming-Features, **Telegram** hat mehr Broadcast-Features

### Telegram vs. Element
- **Telegram** ist proprietär, **Element** ist Open Source
- **Telegram** hat Cloud-basierte Chats, **Element** hat dezentrale Chats
- **Element** hat standardmäßig E2E-Verschlüsselung, **Telegram** nur in "Geheimen Chats"
- **Element** ist für dezentrale Kommunikation, **Telegram** ist für zentrale Kommunikation

### Telegram vs. Mastodon
- **Telegram** ist für Messaging und Gruppen, **Mastodon** ist für Mikroblogging
- **Telegram** hat keine E2E-Verschlüsselung (außer Geheime Chats), **Mastodon** hat keine E2E-Verschlüsselung
- **Mastodon** ist dezentral, **Telegram** ist zentral

## Technische Details

- **Platform**: Windows, macOS, Linux, iOS, Android, Web
- **Protokoll**: MTProto (eigenes Protokoll)
- **Backend**: Cloud-basiertes Telegram-Backend
- **Verschlüsselung**: MTProto für Cloud-Chats, AES-256 + RSA für Geheime Chats
- **Authentication**: OAuth2, Phone Number
- **Bots**: Telegram-Bots via Bot-API
- **Programming Language**: C++ (Core), JavaScript (Web), Kotlin (Android), Swift (iOS)

## Für wen ist Telegram geeignet?

- **Geschwindigkeitssucher**: Für diejenigen, die schnelle Kommunikation wollen
- **Große Communities**: Für diejenigen, die große Gruppen/Kanäle betreiben wollen
- **Dateiübertragung**: Für diejenigen, die große Dateien übertragen wollen
- **Bots-Nutzer**: Für diejenigen, die Bot-Integrationen nutzen wollen
- **Cross-Platform-Nutzer**: Für diejenigen, die auf mehreren Plattformen kommunizieren wollen
