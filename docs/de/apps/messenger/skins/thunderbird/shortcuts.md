# Thunderbird - Tastatur-Shortcuts

## Übersicht

Thunderbird bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten.

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `F1` | Hilfe |
| `F5` | Aktualisieren |
| `Ctrl+Q` | Beenden |
| `Ctrl+W` | Fenster schließen |
| `Ctrl+N` | Neues Fenster |
| `Ctrl+Shift+N` | Neues Fenster (privat) |

## E-Mail Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Shift+M` | Neue E-Mail |
| `Ctrl+R` | Antwort |

## Add-on Shortcuts

Einige Add-ons definieren eigene Shortcuts:
- **Enigmail**: `Ctrl+Shift+E` für Signatur/Verschlüsselung
- **ImportExportTools**: `Ctrl+Shift+E` für Export
- **QuickFolders**: `Ctrl+Shift+Q` für Schnellzugriff
