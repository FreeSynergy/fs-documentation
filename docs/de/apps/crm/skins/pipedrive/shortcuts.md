# Pipedrive - Tastatur-Shortcuts

## Übersicht

Pipedrive veröffentlicht **keine umfassende Liste anwendungseigener Tastatur-Shortcuts**. Gearbeitet wird mit Maus und Touch plus den üblichen Browser-Tasten; Dialoge, Filter und Formulare folgen den Standard-Tastaturen der Weboberfläche. Diese Datei beschreibt, was tatsächlich funktioniert, und kennzeichnet verbreitet erwartete Kurzzeichen ausdrücklich als **nicht vorhanden**.

> Stand: aktuelle Pipedrive-Version im Browser. Die Oberfläche wird laufend geändert; nach Updates diese Liste erneut prüfen.

---

## Allgemein (Browser-Standard)

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Zum nächsten Bedienelement springen (Navigation, Filter, Kachel) |
| `Shift+Tab` | Zum vorherigen Bedienelement springen |
| `Enter` | Fokussierte Schaltfläche oder Kachel auslösen |
| `Space` | Auswahlkästchen und Schaltflächen auslösen |
| `Esc` | Detailbereich, Dialog oder Vorschlagsliste schließen |
| `F5` / `Strg+R` | Ansicht neu laden |
| `Alt+←` / `Alt+→` | Browser zurück/vor |
| `Strg+F` | Text auf der Seite suchen (Browser, nicht Pipedrive) |
| `Strg+P` | Aktuelle Ansicht drucken |
| `Strg+C` / `Strg+V` | Kopieren und Einfügen in Feldern |

## Navigation

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Punkte der linken Navigationsleiste ansteuern |
| `Enter` | Navigationspunkt ausführen (Modul öffnen) |
| `↑` / `↓` | In Dropdowns (Pipeline, Stage, Bearbeiter) blättern |
| `↑` / `↓` | In Autocomplete-Vorschlägen der Suche blättern |
| `Enter` | Markierten Suchvorschlag öffnen |
| `Esc` | Suche und Vorschlagsliste verlassen |
| `Backspace` | Suchtext löschen, wenn das Suchfeld fokussiert ist |

**Nicht vorhanden:**

| Erwarteter Shortcut | Status |
|---------------------|--------|
| `/` für Suchfokus | ❌ Nicht vorhanden — Suchfeld anklicken oder per `Tab` erreichen |
| `Strg+K` Befehlspalette / Sprung zu Modul | ❌ Nicht dokumentiert |
| `1`–`8` für Module der Navigationsleiste | ❌ Nicht vorhanden |
| `D` für Deals, `A` für Aktivitäten | ❌ Nicht vorhanden |
| `?` für Shortcut-Übersicht | ❌ Nicht vorhanden — es gibt keine Hilfe-Übersicht dieser Art |
| `g` dann `d` (zu Deals springen) | ❌ Nicht vorhanden |

## Bearbeitung (Deals, Aktivitäten, Felder)

| Shortcut | Funktion |
|----------|----------|
| `Tab` / `Shift+Tab` | Felder des Formulars in Reihenfolge durchlaufen |
| `Enter` | Standardaktion im Dialog (meist Speichern) |
| `Esc` | Dialog ohne Änderung verlassen |
| `Backspace` / `Entf` | Feldinhalt löschen |
| `Strg+Z` | Rückgängig **innerhalb eines Textfelds** (Browser-Funktion) |
| `↑` / `↓` | Auswahlfelder (Stage, Person, Aktivitätstyp) bedienen |
| `Enter` (in Liste) | Fokussierte Zeile öffnet den Detailbereich |

**Nicht vorhanden:**

| Erwarteter Shortcut | Status |
|---------------------|--------|
| `Strg+S` Deal speichern | ❌ Nicht dokumentiert — Speichern-Schaltfläche nutzen |
| `Entf` Deal in der Liste löschen | ❌ Nicht vorhanden — Aktion im Detailbereich oder im Kachel-Menü |
| `Strg+Z` Stage-Wechsel rückgängig | ❌ Nicht vorhanden — Deal manuell zurückziehen |
| Pfeiltasten zum Verschieben einer Kachel | ❌ Nicht vorhanden — Drag & Drop mit Maus oder Touch |
| `N` neuer Deal | ❌ Nicht vorhanden — Aktionsschaltfläche "Add" verwenden |
| `E` Datensatz bearbeiten | ❌ Nicht vorhanden |

## Suche und Filter

| Shortcut | Funktion |
|----------|----------|
| Klick in das Suchfeld oben + Text | Globaler Suchdialog mit Kontakten, Firmen und Deals |
| `↑` / `↓` | Ergebnistypen und Treffer durchlaufen |
| `Enter` | Markierten Treffer öffnen |
| `Esc` | Suche schließen |
| `Tab` | Filterleiste ansteuern, Filterwert-Feld erreichen |
| `↑` / `↓` | Werte in Filter-Dropdowns wählen |

Kurzbefehle im Suchfeld (Operatoren oder Bangs) sind nicht dokumentiert; die Suche arbeitet mit Freitext und Filtern.

---

## Dialoge und Formulare

| Shortcut | Funktion |
|----------|----------|
| `Tab` / `Shift+Tab` | Felder im Dialog durchlaufen (Deal anlegen, Feld hinzufügen) |
| `Enter` | Nächsten Dialogschritt auslösen, wenn ein Eingabefeld fokussiert ist |
| `Esc` | Abbrechen, sofern der Dialog es zulässt |
| `Space` | Kontrollkästchen und Schalter umschalten |
| `↑` / `↓` | Auswahllisten (Währung, Stage, Nutzer) bedienen |
| `Backspace` | Mehrfachauswahl in Personenfeldern entfernen |

---

## Pipeline-Board

| Geste / Taste | Funktion |
|---------------|----------|
| Ziehen an der Kachel | Deal in andere Stage-Spalte verschieben, Zielspalte wird hervorgehoben |
| `Tab` | Kacheln in Lesereihenfolge ansteuern |
| `Enter` | Fokussierte Kachel öffnet den Detailbereich |
| `Esc` | Detailbereich schließen und zum Board zurückkehren |
| Langes Drücken (Touch) | Kachel aufnehmen und verschieben |

Ein Verschieben per Tastatur ist nicht vorgesehen; bei Verlust-Entscheidung erscheint ein Bestätigungsdialog, der mit `Tab` und `Enter` bedient wird.

## Mac-Varianten

Unter macOS gelten die Browser-Tasten mit `Cmd` statt `Strg`.

| Shortcut | Funktion |
|----------|----------|
| `Cmd+R` | Neu laden |
| `Cmd+P` | Drucken |
| `Cmd+F` | Text auf der Seite suchen (Browser) |
| `Cmd+C` / `Cmd+V` | Kopieren und Einfügen |
| `Cmd+Z` | Rückgängig im Textfeld |
| `Cmd+A` | Alles markieren |
| `Cmd+↑` / `Cmd+↓` | Seitenanfang / Seitenende (Browser) |
| `Cmd+Plus` / `Cmd+Minus` | Zoom der Oberfläche |
| `Cmd+0` | Zoom zurücksetzen |
| `Esc` | Detailbereich und Dialoge schließen |

**Nicht vorhanden:** `Cmd+K` (Befehlspalette), `Cmd+S` (Speichern), `Cmd+/` (Suchfokus), `Cmd+N` (neuer Deal).

## Barrierefreie Tastaturbedienung

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Navigation, Filter, Kacheln, Detailbereich und Dialoge in Lesereihenfolge |
| `Enter` / `Space` | Aktion des fokussierten Elements auslösen |
| `Esc` | Overlay verlassen und zum Inhalt zurückkehren |
| `↑` / `↓` | Auswahlfelder und Vorschlagslisten bedienen |
| `Shift+Tab` | Rückwärts navigieren |

## Sinnvolle Alternativen statt Shortcuts

Da Kurzbefehle fehlen, beschleunigen in Pipedrive vor allem diese Einstellungen die Arbeit:

- **Gespeicherte Filter** je Pipeline statt wiederholter Filterarbeit
- **Eigene Felder mit Standardwerten**, um Formulare kurz zu halten
- **Workflows**, die Aufgaben und Feldwerte automatisch setzen
- **Startseite mit Fälligkeitsliste**, statt Aktivitäten zu suchen
- **Browser-Lesezeichen** auf gefilterte Deal-Ansichten (URL enthält die Filter)

---

## Zusammenfassung

Pipedrive bietet **keine anwendungsspezifischen Shortcuts**. Nutzbar sind:

- **Browser-Tasten** für Neu laden, Drucken, Zoom und Textsuche
- **`Tab`, `Enter`, `Space`, `Esc`, `↑`/`↓`** in Navigation, Formularen, Filtern und Dialogen
- **Drag & Drop und Touch-Gesten** für Stage-Wechsel im Pipeline-Board

Wer Abkürzungen braucht, verknüpft gefilterte Ansichten als Lesezeichen und verlagert Routinearbeit in Workflows.
