# HubSpot - Menüpunkte

## Hauptnavigation (Hub-Umschalter oben)

| Hub | Menüs (Auswahl) |
|-----|-----------------|
| **CRM** | Kontakte, Firmen, Deals, Tickets, Aufgaben, Termine (Meetings-Tool), Pipelines, Berichte |
| **Marketing** | E-Mails, Kampagnen, Formulare, Landing Pages, Blog/Content, Automation (Workflows), Social, Ads |
| **Sales** | Sequenzen, Playbooks, Prospects, Quotes, Call-Logging |
| **Service** | Tickets, Conversations ( Inbox), Knowledge Base, SLA, Bots |
| **Website** | Pages, Menüs, Domain, A/B-Tests |
| **Operations** | Objects-Editor, Routing, Workflows (plattformweit) |

## Record-Seite (z.B. Kontakt)

- Aktionen: Email, Call, Task, Meeting, Property bearbeiten, Associeren (Firma/Deal)
- Tabs: Aktivitäten-Chronik, E-Mails, Meetings, Associzierte Objekte, Buying signals (planabhängig)

## Einstellungen (⚙)

| Bereich | Inhalt |
|---------|--------|
| Properties | eigene Felder je Objekt |
| Objects (Pro) | eigene Objekttypen |
| Pipelines & Deals | Stages, Deal-Eigenschaften |
| Integrations | Apps installieren, **Private Apps + Token**, Webhooks |
| Users & Teams | Sitze, Berechtigungen (Teams, Views) |
| Tracking & Analytics | Tracking-Code, Quellen, Cookies (Consent Banner) |

## Menüs nach Rolle

Sitze (Marketing/Sales/Service Seat) + Team-Rechte; Kontakte-Lese-/Schreibrechte pro Team-View.
