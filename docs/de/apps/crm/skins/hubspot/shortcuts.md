# HubSpot - Tastatur-Shortcuts

## Übersicht

HubSpot dokumentiert keine umfassende Shortcut-Liste; Schnellsuche funktioniert in vielen Ansichten.

> Stand: 2026. Einzelne Belegungen hubsabhängig.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Cmd/Ctrl+K` | Globale Suche/„Quick find“ (in den meisten Hubs) |
| `Esc` | Dialoge/Overlays schließen |
| `Tab`/`Enter` | Formulare |
| `Strg/Cmd+Enter` | E-Mail im Editor senden (Status: verbreitet, offiziell nicht überall gelistet) |

## Ausdrücklich nicht vorhanden

- keine Ein-Buchstaben-Aktionen (Create/Task per Taste)
- keine Makro-Kürzel

## Mac

`Cmd`-Variante dominant; Windows `Strg`.
