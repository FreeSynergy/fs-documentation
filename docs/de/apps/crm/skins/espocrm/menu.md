# EspoCRM - Menüpunkte

## Globales Menü (links)

| Menü | Inhalt |
|------|--------|
| Dashboard | Portlets (Mein Pipeline, Fällig, Aktivitäten) |
| Streams | aktivitatenbezogener Feed (wie Timeline) |
| Calls / Meetings / Tasks / Emails | Aktivitäten |
| Leads → convert | Lead in Account/Kontakt/Opportunity umwandeln |
| Opportunities | Pipeline-Ansicht + Tabelle |
| Accounts / Contacts | Hauptentitäten |
| (custom) | eigene Entities aus dem Entity-Manager |

## Record-Aktionen (Detailseite)

Bearbeiten · Löschen · Follow (Abo) · Drucken/Vorlagen (PDF) · Mass Actions (Dropdown über Listen) · Related-Tabs anlegen

## Admin-Menü (⚙)

| Bereich | Inhalt |
|---------|--------|
| User Management | Users, Roles, Teams, Portal Users |
| Entity Management | **Entity Manager** (neue Entities/Felder/Relationen), Layout-Editor, Formula |
| Customization | Menüs, Portlets, Templates (Handlebars), Maps-Konfiguration |
| Workflow | Workflows (Trigger/Conditions/Actions), Scheduled Jobs, Recipes |
| Email | SMTP/IMAP-Accounts, Group Mailboxes, Mass Mail (Campaign) |
| System | Auswahllisten, Preferences, Extensions-Installation, API-Zugänge |

## Menüs nach Rolle

Rollen definieren Rechte je Entity und Feld (Portal-Nutzer: nur eigene Records über das Portal).
