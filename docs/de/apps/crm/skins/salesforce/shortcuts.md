# Salesforce - Tastatur-Shortcuts

## Übersicht

Salesforce Lightning dokumentiert eine kleine, offizielle Shortcut-Liste (Hilfe: `Ctrl+/` bzw. `Ctrl+Shift+?` je Version).

> Stand: Lightning Experience (2026).

## Global

| Shortcut | Funktion |
|----------|----------|
| `Strg/Cmd+K` | Globale Suche fokussieren |
| `Strg/Cmd+J` | „Action“-Button (New/Quick Actions) |
| `Esc` | Modals/Dropdowns schließen |
| `Strg+/` (bzw. `?`) | Shortcuts-Overlay |
| `Alt+Shift+←/→` | zum vorherigen/nächsten Tab |

## Auf Listen

| Shortcut | Funktion |
|----------|----------|
| `N` | neues Record (in Listen mit Tastenunterstützung; sonst Action-Button) — statusabhängig |
| `Klick auf Spaltenkopf` | Sortieren (keine Taste) |

## Record-Detail

| Shortcut | Funktion |
|----------|----------|
| `Tab` | zu Aktionen/Feldern |
| `Enter` im Editiermodus | Speichern |

## Ausdrücklich nicht vorhanden

- frei belegbare Vim-Maps (nur per Browser-Extension nachrüstbar)

## Mac

alle `Strg`-Tasten mit `Cmd`.
