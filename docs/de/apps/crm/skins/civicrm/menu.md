# CiviCRM - Menüpunkte

## Civi-Menüleiste (im CMS, oben)

| Menü | Einträge |
|------|----------|
| **Contacts** | New Contact (Individual/Organization/House), Import, Export, Find Contacts, Groups, Search Builder, Advanced Search |
| **Contributions** | New Contribution, Import, Contribution Pages, PCP (Personal Campaign Pages) |
| **Events** | New Event, Event Registration (Backend), Import, Event Templates |
| **Memberships** | New Membership, Membership Types, Status Types, Import |
| **Campaigns** | Campaigns, Petitions, Surveys |
| **Cases** (aktivierbar) | New Case, Case Types, Manager |
| **Grants** (aktivierbar) | Grant Application, Grant Status |
| **Administer** | Customize Data and Screens (Custom Fields), Communications (Mailings, Templates), CiviContribute/CiviEvent/CiviMember-Einstellungen, Locations, API Explorer, Extensions, Scheduler Jobs |

## Kontaktseite (Reiter)

Activities · Mailings · Contributions · Events · Memberships · Relationships · Cases · Grants · Notes · Tags · Custom Fields

Aktionsmenü („Actions“): Email (Bulk), Print/Email Labels, Add Activity, Add Relationship, Tag, Add to Group, Merge Contacts, Delete, Export

## Menüs nach Rolle

| Rolle (CMS-Permission) | Sicht |
|------------------------|-------|
| authenticated (Mitgliederportal) | eigene Beiträge/Registrierungen (Contribution/Membership Pages) |
| CiviCRM-Benutzer (basic) | Contacts/Find + eigene Aktivitäten |
| Administrator-Rollen | Administer-Menü (feingranular über „Access CiviCRM“-Permissions) |
