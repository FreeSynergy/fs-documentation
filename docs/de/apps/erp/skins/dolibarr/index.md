# Dolibarr Dokumentation

## Übersicht

Dolibarr (GPL, PHP) ist das schlanke KMU-ERP/CRM: Dritte, Angebote/Bestellungen, Rechnungen, Lager, Projekte, Basis-Buchhaltung — einfach zu hosten (LAMP), stabiler Funktionskern, Extension-Markt. REST-API v3 mit API-Keys.

- [features.md](features.md) - Module, Trigger/Hooks, Was Dolibarr NICHT kann
- [description.md](description.md) - Abgrenzung zu Odoo, ERPNext, Lexware
- [structure.md](structure.md) -Frames-Layout, Listen/Formulare
- [shortcuts.md](shortcuts.md) - Kurzbefehle (keine offiziellen)
