# Dolibarr - Menüpunkte

## Hauptmenü (links, modular)

| Menü | Inhalt |
|------|--------|
| Accueil (Start) | Dashlets, Wiedervorlagen, Suche |
| Tiers | Kunden/Lieferanten (Fiche Tiers), Kontakte, Kategorien |
| Commercial | Proformat (Angebote), Bestellungen, Rechnungen, Credits, „Evennements“ |
| Produits/Services | Artikel, Lager, Preise, Fabrikation (Modul) |
| Comptabilité | Kunden-/Lieferantenbuchung, Journal, Kontoauszug (ab Version „Accounting“ standard) |
| Projets | Aufgaben, Zeiterfassung (modulabhängig) |
| Adhérents (Vereine) | Mitgliederbeiträge (NPO-Szenario!) |
| Outils | Werkzeuge (Massendruck, Import/Export) |

## Verwaltung (⚙ Setup)

| Bereich | Inhalt |
|---------|--------|
| Module aktivieren/deaktivieren | Funktionsschalter + **API REST**, Webhooks |
| Benutzer/Gruppen/Rechte | Profile (VRAC…), perimeters |
| Modellwahl | Nummernfolgen, PDF-Modelle, Steuersätze |
| Technische Parameter | SMTP, Mails, API-Keys erzeugen |

## Menüs nach Rolle

Rechteprofile je Modul (lesen/nehmen/verwalten/supprimer); „Super-Admin“ für Setup.
