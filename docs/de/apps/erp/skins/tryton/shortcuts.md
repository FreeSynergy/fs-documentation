# Tryton - Tastatur-Shortcuts

## Übersicht

Der Desktop-Client nutzt GTK-Standardtasten plus Tryton-eigene (in Menüs sichtbar).

> Stand: Tryton 7.x.

## Vorhanden (Desktop)

| Shortcut | Funktion |
|----------|----------|
| `Strg+S` | Datensatz speichern |
| `Strg+N` | neuer Datensatz (Liste/Form) |
| `F5` | Liste aktualisieren |
| `F2` (Liste) | Form öffnen / Feld editieren |
| `Esc` | Editierung abbrechen |
| `Tab`/`Shift+Tab` | Felder |
| `Strg+Shift+C` | Client-Einstellungen — Stand prüfen |

## Web-Client

reduziert auf Formularstandards.

## Mac

Linux-first; GTK-Tasten ohne `Cmd`-Pendants.
