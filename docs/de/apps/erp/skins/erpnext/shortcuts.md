# ERPNext - Tastatur-Shortcuts

## Übersicht

Frappe/ERPNext dokumentiert wenige, aber wichtige Kurzbefehle.

> Stand: ERPNext 15 (Frappe 15).

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Strg/Cmd+G` | „Go to“-Palette (Doctypes/Menü) |
| `Strg/Cmd+S` | Dokument speichern |
| `Esc` | Dialog/Dialogfeld schließen |
| `Tab`/`Enter` | Feldnavigation |
| `↑↓` (Liste) | Datensatznavigation — Stand prüfen |

## Ausdrücklich nicht vorhanden

- Ein-Buchstaben-Modulsprünge; keine `?`-Übersicht überall

## Mac

`Cmd` statt `Strg`.
