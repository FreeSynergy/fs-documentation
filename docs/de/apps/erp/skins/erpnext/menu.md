# ERPNext - Menüpunkte

## Desk-Navigation

| Element | Inhalt |
|---------|--------|
| Suchpalette (`Ctrl+G`/Suchfeld) | „Go to“: Doctypes, Listen, Reports, Einstellungen |
| Workspaces (links) | Module als Karten: Accounting, Selling, Buying, Stock, Manufacturing, HR, Projects, Quality |
| List-Ansicht | Filter, Tags, Bulk-„Actions“, Reports-Links |
| Form-Ansammlung | Kreispfad-Status (z.B. Quotation→Sales Order→Delivery→Invoice), Links unten |

## Setup-Menüs

| Menü | Inhalt |
|------|--------|
| Settings (pro Modul) | Firmenstruktur, Kontenplan, Seriennummern-Regeln |
| Users & Permissions | Rollen („Sales Manager“…), User-Regeln |
| Developer-Tools (einmal aktivieren) | DocType-Designer, Webhooks, Print Formats, Server Scripts, Scheduler-Tasks |

## Menü nach Rolle

Standardrollen (Website Visitor → Guest → Employee → Modul-Manager); API-Zugriff über Rollen des API-Users.
