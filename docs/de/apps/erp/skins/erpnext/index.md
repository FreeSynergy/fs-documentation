# ERPNext Dokumentation

## Übersicht

ERPNext (GPLv3) ist das vollständige Open-Source-ERP auf dem **Frappe-Framework** (Python/MariaDB): Accounting, Inventory, Buying/Selling, HR, Manufacturing, Projects — komplett ohne Lizenzkosten, mit sauberer JSON-REST-API und Webhooks.
