# Axelor - Menüpunkte

## App-Menüs

| Menü | Inhalt |
|------|--------|
| CRM | Leads, Opportunités (Chancen), Kontakte |
| Sales | Quotes, Sale Orders, Invoices |
| Purchasing/Stock/Manufacturing | Bestellungen, Lagerbewegungen, Fertigungsaufträge |
| Account | Customer/Supplier Invoices, Payments, Journals |
| Project/HR | Projekte, Timesheet, Leave (Expense) |

## App Builder (Entwickler-Konsole)

- **Models** (Feldmodell), Views (Grid/Form/Kanban/Calendar), Menüs, Actions, **BPM** (jBPM-basierte Workflows), Reporting, „Modeling“-Assistenten

## Administration

| Bereich | Inhalt |
|---------|--------|
| Users/Groups/Perms | Rechte (Records/Rules) |
| Company/Templates | Nummernfolgen, E-Mail-Templates |
| REST-API-Schalter | Modell-Endpunkte aktivieren (`api`-Adapter) |

## Menüs nach Rolle

Sichtbarkeit folgt Gruppen + „Business rules“; BPM rollenbasierte Aufgabenlisten („My tasks“).
