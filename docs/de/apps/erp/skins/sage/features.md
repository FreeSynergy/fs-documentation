# Sage - Funktionen

## Hauptfunktionen (je Produkt)

### Sage Business Cloud
- Online-Buchhaltung: Rechnungen, Angebote, Zahlungen, Bank-Feeds, Umsatzsteuermeldungen (landabhängig),leichtes CRM (Produktvarianten wechseln!)
- REST-API + Webhooks für die Cloud-Produkte (developer.sage.global)

### Sage 50 / Sage 100 / Sage X3 (DE relevant)
- Finanzbuchhaltung mit GOBD-Exporten, Anlagen, MAHNWesen; 100/X3 mit WaWi, Fertigung, Multi-Site
- Schnittstellen: Datei-/DB-Schnittstellen, Sage 100 „Connectoren“, X3 REST-APIs (versionsspezifisch!)

## Was Sage NICHT kann

- **kein einheitliches Produkt** — „die Sage-API“ existiert nicht; jede Linie hat eigene Schnittstelle/Lizenz
- **Open-Source/Self-Hosting: nein** (kommerziell, Lizenzpflicht)
- **moderne UI durchgehend**: Windows-Altlasten in 50/100
- FreeSynergy-eigene Skin-Bastelbarkeit begrenzt (herstellerabhängige SDKs)
