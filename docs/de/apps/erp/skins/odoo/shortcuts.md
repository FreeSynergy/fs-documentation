# Odoo - Tastatur-Shortcuts

## Übersicht

Odoo dokumentiert Shortcuts sparsam; die Befehlspalette `c` (Odoo 16+) ist der offizielle Navigationsweg.

> Stand: Odoo 17/18.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `c` | Befehlspalette (Apps/Menüs „jump to“) |
| `?` | Kurzbefehle-Overlay (in maskierten Versionen direkt Liste) |
| `Enter` | Feld bestätigen / Zeile speichern |
| `Esc` | Bearbeitung abbrechen / Dialog schließen |
| `↑↓` | Feld/Zeilen-Navigation in Listen |
| `Tab`/`Shift+Tab` | Felder vor/rück |
| `Alt+F5` o. Browser-Reload | Seite neu laden (kein offizieller) |

## Ausdrücklich ungesichert

| Angenommen | Status |
|------------|--------|
| `Shift+C` neuer Datensatz | ❌ nicht dokumentiert |
| `n` neuer Datensatz | ❌ (Button „Neu“) |

## Mac

`Cmd`-Variante nur bei Browser-Standards; `c`/`?` identisch.
