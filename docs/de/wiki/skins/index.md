# Wiki Skin Dokumentation

## Übersicht

Dieses Verzeichnis enthält Dokumentationen zu den Menüpunkten verschiedener Wiki-Software-Systeme.

## Enthaltene Dokumentationen

- [Wiki.js](./wikijs.md) - Moderne, leichtgewichtige Wiki-Software
- [XWiki](./xwiki.md) - Enterprise-Wiki-Plattform
- [MediaWiki](./mediawiki.md) - Die beliebteste Wiki-Software (Wikipedia)
- [Tango.io](./tango.io.md) - Wissensmanagement-Plattform
- [Notion](./notion.md) - All-in-one-Plattform für Zusammenarbeit
- [Confluence](./confluence.md) - Enterprise-Wiki von Atlassian
