# Ribbon - Beispiele

## Beispiel 1: Microsoft Word-Stil

```
┌─────────────────────────────────────────────────────────┐
│ Datei │ Start │ Einfügen │ Layout │ Referenzen │ ...   │
├─────────────────────────────────────────────────────────┤
│ Schrift │ Absatz │ Stile                                  │
│ [A] [B] [I] [U] [●] [1] [2] [→]  [A+] [T-]            │
├─────────────────────────────────────────────────────────┤
│ Schriftart │ Schriftgröße                             │
│ Arial ▼ │ 12 pt ▼                               │
└─────────────────────────────────────────────────────────┘
```

└─────────────────────────────────────────────────────────┘
