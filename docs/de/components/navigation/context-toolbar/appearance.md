# Context Toolbar - Aussehen

## Grundlayout

Eine Context Toolbar ist eine Toolbar, die nur bei Auswahl eines Elements erscheint.

## Layout

```
┌─────────────────────────────────────────────────────┐
│ [A] [B] [I] [U] [❌]                                │
└─────────────────────────────────────────────────────┘
```

## Positionierung

Die Context Toolbar erscheint:
- **Direkt über dem selektierten Element**
- **Nahe am Mauszeiger (Desktop)**
- **Unter dem Element (Mobile)**

## Größe-Varianten

| Größe | Icon-Größe | Verwendung |
|-------|------------|------------|
| Small | 16px | Wenige Aktionen |
| Medium | 24px | Standard |
| Large | 32px | Viele Aktionen |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Default** | Primärfarbe | Standard-Aktionen |
| **Danger** | Rot | Gefährliche Aktionen |
| **Disabled** | Grau | Deaktivierte Aktionen |

## Button-Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Icon Only** | Nur Icon |
| **Icon + Text** | Icon und Text |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `color` | Farbe ändert sich |
| `background` | Hintergrund ändert sich |
| `scale` | Leichte Vergrößerung |

## Animationen

| Effekt | Beschreibung |
|--------|--------------|
| `Fade In` | Einfade-Effekt |
| `Slide Up` | Schiebe-Effekt von unten |
| `Pop` | Pop-Effekt |
