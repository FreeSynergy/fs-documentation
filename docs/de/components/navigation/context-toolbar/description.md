# Context Toolbar

## Beschreibung

Eine Context Toolbar ist eine Toolbar, die nur bei Auswahl eines Elements erscheint. Sie zeigt kontextbezogene Aktionen an.

## Verwendungszweck

- Aktionen für ausgewählte Elemente anzeigen
- Weniger Platz verbrauchen (nur bei Bedarf)
- Schneller Zugriff auf kontextbezogene Funktionen

## Beispiele

| Szenario | Toolbar |
|----------|---------|
| Text selektieren | Formatierungs-Toolbar |
| Bild selektieren | Bearbeitungs-Toolbar (Beschneiden, Rotieren) |
| Datei selektieren | Datei-Aktionen (Umbenennen, Löschen) |

## Features

- Auto-Positionierung (nahe am selektierten Element)
- Hidden (wenn kein Element selektiert)
- Customizable (benutzerdefiniert)
- Animation (Einglide/Einschweben)

## Best Practices

- Nur relevante Aktionen anzeigen
- Wichtigste Aktionen zuerst
- Konsistente Aktionen für gleiche Elemente
- Hover-Effekt
