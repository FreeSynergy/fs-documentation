# Language Switcher (Sprachumschalter)

## Beschreibung

Ein Language Switcher ist ein UI-Element zum Wechseln der Anwendungssprache.

## Verwendung

- Spracheinstellungen ändern
- Mehrsprachigkeit
- Regionale Anpassung

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Dropdown** | Sprachliste im Dropdown |
| **Buttons** | Direkt-Buttons für jede Sprache |
| **Icons** | Landesflaggen-Icons |
| **Combined** | Dropdown + aktuelle Sprache angezeigt |

## Größe-Varianten

| Größe | Verwendung |
|-------|------------|
| Small | In der Header-Leiste |
| Medium | In den Einstellungen |
| Large | Auf der Startseite |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Default** | Normal | Standard-Style |
| **Active** | Primärfarbe | Aktive Sprache |

## Sprachen

| Sprache | Code | Flagge |
|---------|------|--------|
| Deutsch | de | 🇩🇪 |
| English | en | 🇬🇧 |
| Français | fr | 🇫🇷 |
| Españo | es | 🇪🇸 |
| Italiano | it | 🇮🇹 |

## Features

- Automatische Erkennung
- Persistente Einstellung
- Live-Wechsel
- Kein Reload nötig
