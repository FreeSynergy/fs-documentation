# Tabs (Reiter)

## Beschreibung

Tabs sind Reiter zum Umschalten zwischen Ansichten.

## Verwendungszweck

- Ansichten
- Kategorien
- Optionen

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Default** | Standard-Reiter |
| **Pill** | Pillenform |
| **Card** | In Karte integriert |

## Features

- Active Tab
- Closable
- Keyboard-Navigation

## Best Practices

- Clear-Titles
- Icons
- Accessibility
- Feedback
