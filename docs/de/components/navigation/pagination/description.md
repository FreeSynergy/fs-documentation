# Pagination (Seitennavigation)

## Beschreibung

Pagination ist eine Navigationselement für große Listen, die Daten in_pages aufteilt.

## Verwendungszweck

- Große Datenmengen übersichtlich darstellen
- Performance verbessern (nur sichtbare Daten laden)
- Benutzerfreundlichkeit erhöhen

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Numeric** | 1, 2, 3, ... |
| **Previous/Next** | Nur Vor/Zurück |
| **Load More** | "Mehr laden"-Button |
| **Infinite Scroll** | Automatisches Nachladen |

## Features

- Total Items (Gesamtanzahl)
- Current Page (aktuelle Seite)
- Items per Page (Elemente pro Seite)
- Jump to Page (direkt zu Seite springen)
- Page Size Selector (Anzahl pro Seite ändern)

## Best Practices

- Mindestens 25 Elemente pro Seite
- Clear-Indicator (welche Seite gerade aktiv)
- Keyboard-Navigation
- Accessibility (Barrierefreiheit)
