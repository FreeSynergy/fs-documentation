# Context Menu - Beispiele

## Beispiel 1: Datei-Explorer

```
└─ Rechtsklick auf Datei ───────────────┐
   📋 Bearbeiten                          │
   📄 Kopieren                            │
   📄 Einfügen                            │
   ─────────────────────                   │
   🗑️ Löschen                             │
   ℹ️ Eigenschaften                        │
└─────────────────────────────────────────┘
```

```
└─ Rechtsklick auf Nachricht ───────────┐

   ⭐ Markieren                            │
   ─────────────────────                   │
   🗑️ Löschen (nur für mich)              │
```
