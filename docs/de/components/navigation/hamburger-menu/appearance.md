# Hamburger Menu - Aussehen

## Grundlayout

Ein Hamburger Menu ist ein Drei-Striche-Menü (☰) für mobile Navigation.

## Layout-Varianten

### Hamburger Icon
```
☰
```

### Arrow Back (in Modal)
```
←
```

### Custom Icon
```
⚠️
```

## Größe-Varianten

| Größe | Icon-Größe | Verwendung |
|-------|------------|------------|
| Small | 16px | Inline |
| Medium | 24px | Standard |
| Large | 32px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Default** | Schwarz/Dunkel | Standard |
| **Light** | Weiß | Auf dunklem Hintergrund |
| **Primary** | Primärfarbe | Markiert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `color` | Farbe ändert sich |
| `background` | Hintergrund ändert sich |
| `scale` | Leichte Vergrößerung |

## Overlay (Hintergrund abdunkeln)

```
┌─────────────────────────────────────────┐
│                                         │
│  ┌─────────────────────────────────┐   │
│  │                                 │   │
│  │  Menu-Items                     │   │
│  │                                 │   │
│  └─────────────────────────────────┘   │
│                                         │
└─────────────────────────────────────────┘
```

## Animationen

| Effekt | Beschreibung |
|--------|--------------|
| `Fade In` | Einfade-Effekt |
| `Slide In` | Schiebe-Effekt |
| `Pop` | Pop-Effekt |
