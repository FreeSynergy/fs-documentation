# Hamburger Menu

## Beschreibung

Ein Hamburger Menu ist ein Drei-Striche-Menü (☰) für mobile Navigation.

## Verwendungszweck

- Navigation auf Mobile
- Platz sparen
- Standard-Navigation-Muster

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Hamburger Icon** | Drei horizontale Striche |
| **Arrow Back** | Zurück-Pfeil (wenn in Modal) |
| **Custom Icon** | Benutzerdefiniertes Icon |

## Verhalten

- Öffnet Sidebar/Drawer beim Klick
- Schließen durch Klick außerhalb
- Schließen durch Escape-Taste
- Schließen durch X-Button

## Features

- Animated (Animation beim Öffnen/Schließen)
- Overlay (Hintergrund abdunkeln)
- Keyboard-Navigation
- Accessibility (Barrierefreiheit)

## Best Practices

- Nur auf Mobile (oder wenn Platz knapp)
- Clear-Label (Menü)
- Konsistente Navigation
- Schneller Zugriff
