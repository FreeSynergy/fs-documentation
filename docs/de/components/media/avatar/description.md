# Avatar

## Beschreibung

Ein Avatar ist ein visuelles Repräsentations-Element für einen Benutzer. Es kann aus einem Foto, Initialen oder einem Icon bestehen.

## Verwendungszweck

- Benutzerprofile in Listen und Chat anzeigen
- Aktivitätsanzeige (Wer hat was gemacht?)
- Nutzerzuordnung in Kommentaren, Aufgaben, etc.

## Form-Varianten

| Form | Beschreibung | Verwendung |
|------|-------------|------------|
| **Circular (Rund)** | Runde Form | Standard bei Avataren (Chat, Profile) |
| **Square (Viereckig)** | Quadratische Form | Profilbilder, Dashboard |
| **Pill (Pillenform)** | Abgerundete Rechtecke | Chat-Avatare, schnelle Ansicht |

## Größe-Varianten

| Größe | Pixel | Verwendung |
|-------|-------|------------|
| XSmall | 24px | In List-Items, Chat-Minimal |
| Small | 32px | Standard in Listen |
| Medium | 48px | Profile, Cards |
| Large | 64px | Featured-Profile |
| XL | 96px | Grosszügige Darstellung |
| XXL | 128px+ | Hero-Sectionen |

## Inhalt-Varianten

| Typ | Beschreibung |
|-----|--------------|
| **Image** | Benutzerfoto ( Foto-Upload) |
| **Initials** | Initialen (z.B. "JD" für John Doe) |
| **Icon** | Icon als Platzhalter |
| **Placeholder** | Generischer Platzhalter (wenn kein Bild vorhanden) |

## Status-Badges

Avatare können Status-Badges anzeigen:

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Online** | Grün | Benutzer ist online |
| **Offline** | Grau | Benutzer ist offline |
| **Away** | Orange | Benutzer ist abwesend |
| **Busy** | Rot | Benutzer ist beschäftigt |
| **In-Meeting** | Blau | Benutzer ist in Meeting |

## Hover-Effekte

- **Zoom**: Avatar vergrößert sich leicht
- **Border**: Rand leuchtet auf
- **Shadow**: Schatten wird stärker

## Best Practices

- Avatar immer mit Alt-Text (Name des Benutzers)
- Fallback auf Initialen, wenn kein Bild vorhanden
- Konsistente Form innerhalb einer Anwendung
- Hover-Effekt für Interaktivität
