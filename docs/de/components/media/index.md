# Media

Medien-Elemente dienen zur Darstellung von visuellen Inhalten, Icons, Avataren, Bildern, Videos und Audio.

## Kategorien

- **icon** - Symbolische Darstellungen (rund, viereckig, sechseckig, etc.)
- **avatar** - Benutzerbilder oder Initialen
- **image** - Bilder und Grafiken
- **video** - Video-Wiedergabe
- **audio** - Audio-Wiedergabe
- **gallery** - Bildergalerien

## Was ist hier dokumentiert?

Jedes Element wird in eigenen Verzeichnissen dokumentiert mit:

- **description.md** - Was ist das Element? Wozu dient es?
- **appearance.md** - Wie sieht das Element aus? Farben, Abstände, etc.
- **attributes.md** - Welche Attribute/Optionen hat das Element?
- **usage.md** - Wie wird das Element verwendet?
- **examples.md** - Praktische Beispiele
