# Reaction Bar (Reaktionsleiste) - Aussehen

## Grundlayout

```
 [👍 2] [❤ 1] [😂 3]  [+]
```

## Varianten

| Variante | Aussehen |
|---|---|
| **inline** | Chips mit 1 px Rahmen; eigene Reaktion mit Akzentfüllung |
| **compact** | ein einzelner Chip „3 Reaktionen“ |

## Größen

| Größe | Höhe | Verwendung |
|---|---|---|
| `small` | 20 px | in dichten Blasen |
| `medium` | 28 px | Standard |

## Farben und Zustände

| Zustand | Aussehen |
|---|---|
| Standard | neutraler Rahmen |
| Eigene Reaktion | Akzentfüllung |
| Hover | hellere Fläche |
| Deaktiviert | grau (keine Schreibberechtigung) |

## Hover- und Fokus-Effekte

| Effekt | Beschreibung |
|---|---|
| `background` | Chip wird hervorgehoben |
| `tooltip` | Namen der reagierenden Personen |

## Reaktiv

- Chips brechen in mehrere Zeilen um.
- Die Berührungsfläche ist mindestens 44 px hoch, auch wenn der Chip kleiner ist.
