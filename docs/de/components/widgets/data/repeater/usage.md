# Repeater - Verwendung

!!! note
    Die Beispiele sind syntaxneutral gehalten. Sobald die Umsetzung auf Rust und
    Blinc umgestellt wird, werden die Beispiele in `usage.md` in einem eigenen Durchlauf
    ersetzt.

## Anwendung

Ein Repeater ist ein sich wiederholendes Layout für Listen.

- Produkte
- Kontakte
- Artikel
- Listen

## Beispiele

### Produkte

```jsx
<Repeater items={entries} />
```

### Kontakte

```jsx
<Repeater items={entries} interactive={false} />
```

### Artikel

```jsx
<Repeater items={entries} interactive={false} />
```
