# Link Preview (Linkvorschau) - Aussehen

## Grundlayout

```
┌────────────────────────────────────┐
│ ▢ image   Title of the page        │
│           Short description …      │
│           example.org              │
└────────────────────────────────────┘
```

## Varianten

| Variante | Aussehen |
|---|---|
| **card** | Bild links oder oben, bis zu drei Textzeilen |
| **compact** | eine Zeile mit einem Bild in Favicon-Größe ⚠️ |

## Größen

| Größe | Höhe | Verwendung |
|---|---|---|
| `small` | 64 px | kompakt |
| `medium` | 120 px | Standard |
| `large` | 200 px | Bild oben |

## Farben und Zustände

| Zustand | Aussehen |
|---|---|
| Standard | Kartenoberfläche |
| Hover | hellere Fläche |
| Nicht verfügbar | gedämpft, zeigt nur die URL |

## Hover- und Fokus-Effekte

| Effekt | Beschreibung |
|---|---|
| `background` | Oberfläche ändert sich |
| `underline` | Titel unterstrichen |

## Reaktiv

- Auf schmalen Bildschirmen rutscht das Bild über den Text.
- Die Beschreibung wird nach zwei Zeilen abgeschnitten.
