# Call Controls (Anrufsteuerung) - Aussehen

## Grundlayout

```
 [🎤] [📷] [🖥 share] [⚙]      [ 📞 hang up ]
```

## Varianten

| Variante | Aussehen |
|---|---|
| **bar** | zentrierte Reihe runder Schaltflächen, Auflegen in Fehlerfarbe |
| **compact** | zwei Schaltflächen |

## Größen

| Größe | Höhe | Verwendung |
|---|---|---|
| `small` | 32 px | Mini-Leiste |
| `medium` | 44 px | Standard |
| `large` | 56 px | Touch |

## Farben und Zustände

| Zustand | Aussehen |
|---|---|
| Standard | neutrale Schaltflächen |
| Aktiver Schalter | Akzentfüllung |
| Stumm oder aus | durchgestrichenes Symbol |
| Auflegen | Fehlerfarbe |

## Hover- und Fokus-Effekte

| Effekt | Beschreibung |
|---|---|
| `background` | Schaltflächen-Hover |
| `tooltip` | Name der Aktion |

## Reaktiv

- Sekundäre Bedienelemente wandern auf schmalen Bildschirmen in ein Überlaufmenü.
- Die Auflegen-Schaltfläche bleibt sichtbar.
