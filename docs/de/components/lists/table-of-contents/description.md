# Table of Contents (Inhaltsverzeichnis)

## Beschreibung

Ein Table of Contents ist eine Übersicht über Kapitel/Sectionen.

## Verwendungszweck

- Dokumentation
- Bücher
- Webseiten
- Kapitelübersicht

## Features

- Scroll Spy (Markiert aktuelle Section)
- Click to Scroll (Springen zu Section)
- Collapsible Sections (Ein/Ausklappen)

## Layout

```
┌─────────────────────────────────────────┐
│ 📚 Inhaltsverzeichnis                   │
│                                         │
│  1. Kapitel 1                           │
│  2. Kapitel 2                           │
│  3. Kapitel 3                           │
│    3.1. Unterkapitel 1                  │
│    3.2. Unterkapitel 2                  │
└─────────────────────────────────────────┘
```

## Best Practices

- Clear-Labels
- Hierarchie anzeigen
- Click to Scroll
- Feedback
