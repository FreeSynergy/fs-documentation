# List (Aufzählung) - Aussehen

## Grundlayout

Eine List ist eine einfache vertikale Liste von Elementen.

## Layout

```
┌─────────────────────────────────────────┐
│ Element 1                               │
│ Element 2                               │
│ Element 3                               │
│ Element 4                               │
└─────────────────────────────────────────┘
```

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Simple** | Nur Text |
| **With Icons** | Mit Icons |
| **With Avatars** | Mit Bilder |
| **With Badges** | Mit Status-Badges |
| **With Actions** | Mit Buttons/Links |

## Größe-Varianten

| Größe | Breite | Verwendung |
|-------|--------|------------|
| Small | 200px | Inline |
| Medium | 300px | Standard |
| Large | 400px | Featured |
| Full | 100% | Volle Breite |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Default** | Hell | Standard |
| **Hover** | Heller | Hover-Zustand |
| **Active** | Primärfarbe | Aktiver Zustand |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `background` | Hintergrund ändert sich |
| `border` | Rand leuchtet auf |
