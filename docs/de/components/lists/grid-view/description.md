# Grid View (Rasteransicht)

## Beschreibung

Grid View ist eine Karten/Raster-Darstellung von Elementen.

## Verwendungszweck

- Bildergalerien
- Produktkataloge
- Kartenansichten
- Dateiverzeichnisse

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Fixed Grid** | Feste Spaltenanzahl |
| **Responsive Grid** | Anpassbare Spalten |
| **Masonry Grid** | Unregelmäßige Karten |

## Features

- Responsive
- Hover-Effect
- Selection
- Drag-and-Drop

## Best Practices

- Konsistente Größe
- Hover-Effect
- Accessibility
- Feedback
