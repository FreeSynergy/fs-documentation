# Slideshow (Slideshow)

## Beschreibung

Eine Slideshow ist eine Bilder- oder Inhaltsschleife.

## Verwendungszweck

- Bildergalerien
- Produktpräsentationen
- Werbung
- Karussells

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Auto-play** | Automatisches Wechseln |
| **Manual** | Nur manuelle Steuerung |
| **Thumbnails** | Vorschaubilder |
| **Fade Effect** | Übergangseffekt |

## Features

- Navigation (Vor/Zurück)
- Autoplay
- Thumbs (Vorschaubilder)
- Touch-Swipe (Mobile)

## Best Practices

- Clear-Images
- Navigation
- Auto-play (optional)
- Feedback
