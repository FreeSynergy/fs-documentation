# Slideshow - Aussehen

## Grundlayout

Eine Slideshow ist eine Bilder- oder Inhaltsschleife.

## Layout

```
┌─────────────────────────────────────────┐
│ [◀]   🖼️   [▶]                         │
│      Bild 1                             │
│  ● ○ ○ ○                                │
└─────────────────────────────────────────┘
```

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Auto-play** | Automatisches Wechseln |
| **Manual** | Nur manuelle Steuerung |
| **Thumbnails** | Vorschaubilder |
| **Fade Effect** | Übergangseffekt |

## Größe-Varianten

| Größe | Breite | Verwendung |
|-------|--------|------------|
| Small | 300px | Kleine Slideshows |
| Medium | 500px | Standard |
| Large | 700px | Große Slideshows |
| Full | 100% | Volle Breite |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Active Dot** | Primärfarbe | Aktiver Punkt |
| **Inactive Dot** | Grau | Inaktive Punkte |
| **Hover** | Heller | Hover-Zustand |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `zoom` | Bild vergrößert sich |
| `overlay` | Overlay mit Info |
