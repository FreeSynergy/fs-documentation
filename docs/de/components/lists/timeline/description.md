# Timeline (Zeitlinie)

## Beschreibung

Eine Timeline ist eine chronologische Darstellung von Ereignissen.

## Verwendungszweck

- Verlauf anzeigen
- Aktivitäten
- Historie
- Projektphasen

## Layout

```
┌─────────────────────────────────────────┐
│  📅 20. Januar 2024                     │
│  📝 Erster Schritt                      │
├─────────────────────────────────────────┤
│  📅 21. Januar 2024                     │
│  ✅ Schritt abgeschlossen               │
├─────────────────────────────────────────┤
│  📅 22. Januar 2024                     │
│  📝 Zweiter Schritt                     │
└─────────────────────────────────────────┘
```

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Horizontal** | Horizontal (seltener) |
| **Vertical** | Vertikal (häufiger) |
| **Timeline with Cards** | Mit Karten |
| **Timeline with Events** | Mit Icons und Text |

## Features

- Date
- Title
- Description
- Icon
- Actions

## Best Practices

- Chronologische Reihenfolge
- Clear-Date
- Icons
- Feedback
