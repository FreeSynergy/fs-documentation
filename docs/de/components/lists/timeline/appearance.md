# Timeline - Aussehen

## Grundlayout

Eine Timeline ist eine chronologische Darstellung von Ereignissen.

## Layout

```
┌─────────────────────────────────────────┐
│  📅 20. Januar 2024                     │
│  📝 Erster Schritt                      │
├─────────────────────────────────────────┤
│  📅 21. Januar 2024                     │
│  ✅ Schritt abgeschlossen               │
├─────────────────────────────────────────┤
│  📅 22. Januar 2024                     │
│  📝 Zweiter Schritt                     │
└─────────────────────────────────────────┘
```

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Horizontal** | Horizontal (seltener) |
| **Vertical** | Vertikal (häufiger) |
| **Timeline with Cards** | Mit Karten |
| **Timeline with Events** | Mit Icons und Text |

## Größe-Varianten

| Größe | Schriftgröße | Verwendung |
|-------|-------------|------------|
| Small | 12px | Inline |
| Medium | 14px | Standard |
| Large | 16px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Event** | Primärfarbe | Event |
| **Date** | Grau |Datum |
| **Completed** | Grün | Abgeschlossen |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `color` | Farbe ändert sich |
| `border-left` | Linie leuchtet auf |
