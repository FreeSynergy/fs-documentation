# Dashboard - Aussehen

## Grundlayout

Ein Dashboard ist eine Übersichtsseite mit Widgets.

## Layout

```
┌─────────────────────────────────────────┐
│ [Widget 1] [Widget 2] [Widget 3]        │
│                                         │
│ [Widget 4] [Widget 5] [Widget 6]        │
│                                         │
│ [Widget 7] [Widget 8] [Widget 9]        │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Breite | Verwendung |
|-------|--------|------------|
| Small | 800px | Kleines Dashboard |
| Medium | 1200px | Standard |
| Large | 1600px | Großes Dashboard |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Background** | Hell | Hintergrund |
| **Widget** | Weiß | Widget-Hintergrund |
| **Border** | Grau | Rand |

## Widget-Typen

| Type | Beschreibung |
|------|--------------|
| **Card** | Karte |
| **Chart** | Diagramm |
| **List** | Liste |
| **Table** | Tabelle |
| **Stat** | Statistik |
| **Calendar** | Kalender |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `shadow` | Schatten stärker |
| `border` | Rand leuchtet auf |
