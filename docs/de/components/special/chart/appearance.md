# Chart - Aussehen

## Grundlayout

Ein Chart ist eine Datenvisualisierung (Diagramme).

## Layout-Varianten

### Line Chart
```
┌─────────────────────────────────────────┐
│  100 ┤  ╱╲                               │
│      │ ╱  ╲                              │
│   50 ┤╱    ╲                             │
│      │      ╲                            │
│    0 ┼────────╲────────                  │
│      └───────────────────                │
└─────────────────────────────────────────┘
```

### Bar Chart
```
┌─────────────────────────────────────────┐
│  100 ┤  ▓▓                               │
│      │  ▓▓                               │
│   50 ┤  ▓▓  ▓▓                           │
│      │  ▓▓  ▓▓  ▓▓                       │
│    0 ┤  ▓▓  ▓▓  ▓▓  ▓▓                   │
│      └───────────────────                │
└─────────────────────────────────────────┘
```

### Pie Chart
```
┌─────────────────────────────────────────┐
│      ╱─────╲                            │
│    ╱         ╲                          │
│   │    50%    │                         │
│    ╲         ╱                          │
│      ╲_____/                            │

```

## Größe-Varianten

| Größe | Breite/Höhe | Verwendung |
|-------|-------------|------------|
| Small | 300x200px | Inline |
| Medium | 500x300px | Standard |
| Large | 700x400px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Background** | Weiß | Hintergrund |
| **Grid** | Grau | Gitterlinien |
| **Data** | Farben | Daten-Serien |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `tooltip` | Tooltip erscheint |
| `highlight` | Segment hervorheben |

## Chart-Typen

| Type | Beschreibung |
|------|--------------|
| **Line** | Liniendiagramm |
| **Bar** | Balkendiagramm |
| **Pie** | Kuchendiagramm |
| **Doughnut** | Ringdiagramm |
| **Scatter** | Streudiagramm |
| **Heatmap** | Heatmap |
| **Radar** | Radardiagramm |
