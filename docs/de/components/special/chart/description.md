# Chart (Diagramm)

## Beschreibung

Ein Chart ist eine Datenvisualisierung (Diagramme).

## Verwendungszweck

- Statistiken
- Diagramme
- Grafiken

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Line Chart** | Liniendiagramm |
| **Bar Chart** | Balkendiagramm |
| **Pie Chart** | Kuchendiagramm |
| **Scatter Chart** | Streudiagramm |

## Features

- Interaktiv
- Responsive
- Animations
- Export
