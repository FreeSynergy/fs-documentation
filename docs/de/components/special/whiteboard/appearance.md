# Whiteboard - Aussehen

## Grundlayout

Ein Whiteboard ist eine Zeichenfläche für Kollaboration.

## Layout

```
┌─────────────────────────────────────────┐
│ [Pencil] [Eraser] [Shapes] [Text]       │  ← Toolbar
├─────────────────────────────────────────┤
│                                         │
│      🖌️                                  │
│      Whiteboard-Fläche                  │
│                                         │
│      (Zeichenfläche)                    │
│                                         │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Breite/Höhe | Verwendung |
|-------|-------------|------------|
| Small | 400x300px | Inline |
| Medium | 600x400px | Standard |
| Large | 800x600px | Featured |
| Full | 100% | Volle Breite |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Background** | Weiß/Grün | Hintergrund |
| **Pencil** | Schwarz | Stift |
| **Shapes** | Farbig | Formen |
| **Text** | Schrift | Text |

## Toolbar-Buttons

| Button | Funktion |
|--------|----------|
| **Pencil** | Stift |
| **Eraser** | Radiergummi |
| **Shapes** | Formen |
| **Text** | Text |
| **Color** | Farbe |
| **Clear** | Alles löschen |
| **Export** | Exportieren |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `scale` | Vergrößerung |
| `shadow` | Schatten stärker |
