# Widget Embed - Aussehen

## Grundlayout

Ein Widget Embed ist die Einbettung kleiner Anwendungen.

## Layout

```
┌─────────────────────────────────────────┐
│  ┌─────────────────────────────┐        │
│  │   Wetter                    │        │
│  │   🌤️ 22°C                  │        │
│  │   Berlin                    │        │
│  └─────────────────────────────┘        │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Breite/Höhe | Verwendung |
|-------|-------------|------------|
| Small | 200x150px | Inline |
| Medium | 300x200px | Standard |
| Large | 400x300px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Background** | Weiß | Hintergrund |
| **Border** | Grau | Rand |

## Responsive

| Breakpoint | Verhalten |
|------------|-----------|
| Desktop (>768px) | Volle Größe |
| Tablet (480-768px) | Skaliert |
| Mobile (<480px) | Fullscreen |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `border` | Rand leuchtet auf |
