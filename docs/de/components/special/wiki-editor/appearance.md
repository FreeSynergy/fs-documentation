# Wiki Editor - Aussehen

## Grundlayout

Ein Wiki Editor ist ein WYSIWYG-Editor für Wiki-Inhalte.

## Layout

```
┌─────────────────────────────────────────┐
│ [B] [I] [U] [ Heading] [ List]           │  ← Toolbar
├─────────────────────────────────────────┤
│                                         │
│  (Editor-Bereich)                       │
│                                         │
│  # Überschrift                          │
│                                         │
│  Dies ist der Text...                   │
│                                         │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Höhe | Verwendung |
|-------|------|------------|
| Small | 200px | Inline |
| Medium | 400px | Standard |
| Large | 600px | Featured |
| Full | 100% | Volle Breite |

## Toolbar-Buttons

| Button | Funktion |
|--------|----------|
| **B** | Fett |
| **I** | Kursiv |
| **U** | Unterstrichen |
| ** Heading** | Überschriften |
| ** List** | Listen |
| ** Link** | Links |
| ** Image** | Bilder |
| ** Table** | Tabelle |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `border` | Rand leuchtet auf |
| `shadow` | Schatten stärker |
