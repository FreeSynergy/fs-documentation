# Special

Spezielle Elemente für spezifische Anwendungsfälle.

## Elemente

- **map-view** - Interaktive Karte
- **whiteboard** - Zeichenfläche mit Stencils
- **wiki-editor** - WYSIWYG-Editor für Wiki-Inhalte
- **iframe-embed** - Webseiten einbetten (iFrame)
- **widget-embed** - Kleine Anwendungen einbetten
- **app-embed** - Ganze Apps einbetten
- **media-player** - Video- und Audio-Wiedergabe
- **code-editor** - Editor für Quellcode
- **dashboard** - Übersichtsseite mit Widgets
- **chart** - Datenvisualisierung (Diagramme)
