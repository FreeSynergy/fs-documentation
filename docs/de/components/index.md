# UI-Komponenten & Elemente

Diese Dokumentation beschreibt die UI-Elemente, die in FreeSynergy-Programmen verwendet werden.

## Kategorien

- **navigation** - Menüs, Leisten und Pfadnavigation
- **containers** - Boxen, Overlays und Layout-Elemente
- **lists** - Tabellen, Bäume und einfache Listen
- **inputs** - Formularfelder und Eingabemöglichkeiten
- **media** - Bilder, Icons, Avatare, Video, Audio
- **special** - Spezielle Elemente (Karten, Whiteboards, Embeds)

## Was ist hier dokumentiert?

Jedes Element wird in eigenen Verzeichnissen dokumentiert mit:

- **description.md** - Was ist das Element? Wozu dient es?
- **appearance.md** - Wie sieht das Element aus? Farben, Abstände, etc.
- **attributes.md** - Welche Attribute/Optionen hat das Element?
- **usage.md** - Wie wird das Element verwendet?
- **examples.md** - Praktische Beispiele

## Anzahl der Elemente

- **73 Elemente** insgesamt
- **97 Markdown-Dateien** dokumentiert
- Alle Elemente haben mindestens eine `description.md`
