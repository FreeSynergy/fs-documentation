# Inputs

Input-Elemente ermöglichen die Eingabe von Daten durch den Benutzer.

## Elemente

- **text-input** - Einzeiliges Textfeld
- **number-input** - Nummernfeld
- **email-input** - E-Mail-Adresse
- **url-input** - URL-Eingabe
- **phone-input** - Telefonnummer
- **search-input** - Suchfeld
- **date-input** - Datumsauswahl
- **time-input** - Zeitauswahl
- **datetime-input** - Datum + Zeit
- **color-input** - Farbauswahl
- **textarea** - Mehrzeiliges Textfeld
- **switch** - Ein/Aus-Schalter
- **radio-group** - Optionsfelder (einzelfach)
- **checkbox** - Ja/Nein-Auswahl
- **file-upload** - Dateiauswahl und Upload
- **slider** - Schieberegler
- **range-slider** - Bereichsschieberegler
- **rating** - Sterne- oder Punktebewertung
- **tags-input** - Liste von Tags/Etiketten
- **rich-text-editor** - WYSIWYG-Editor
- **mention-input** - Benutzer-/Kontakt-Erwähnung
- **combobox** - Textfeld + Dropdown
- **emoji-picker** - Emoji-Auswahl
- **dropdown** - Auswahlliste
- **search-field** - Suchfeld mit Filtermöglichkeiten
