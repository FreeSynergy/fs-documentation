# Text Input (Einzeiliges Textfeld) - Aussehen

## Grundlayout

Ein Text Input ist ein einzeiliges Eingabefeld für Text.

## Layout-Varianten

### Standard
```
┌─────────────────────────────────────────┐
│ Name                                    │
├─────────────────────────────────────────┤
│  Max Mustermann                         │
│                                         │
└─────────────────────────────────────────┘
```

### Floating Label
```
┌─────────────────────────────────────────┐
│  Name                                   │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━    │
│  Max Mustermann                         │
└─────────────────────────────────────────┘
```

### Underline
```
┌─────────────────────────────────────────┐
│ Name                                    │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━     │
│ Max Mustermann                          │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Höhe | Verwendung |
|-------|------|------------|
| Small | 32px | Inline |
| Medium | 48px | Standard |
| Large | 64px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Default** | Hell | Standard |
| **Primary** | Primärfarbe | Primär |
| **Active** | Dunkel | Aktiver Zustand |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `border` | Rand leuchtet auf |
| `shadow` | Schatten stärker |

## Validation States

| State | Beschreibung |
|-------|--------------|
| **Valid** | Grün |
| **Invalid** | Rot |
| **Warning** | Orange |
