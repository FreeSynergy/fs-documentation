# Text Input (Einzeiliges Textfeld)

## Beschreibung

Ein Text Input ist ein einzeiliges Eingabefeld für Text.

## Verwendungszweck

- Namen
- Adressen
- Nachrichten

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Standard** | Normal |
| **Floating Label** | Label schwebt über |
| **Underline** | Nur Unterstreichung |

## Features

- Placeholder
- Error-State
- Validation
