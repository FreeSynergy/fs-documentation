# Text Input (Einzeiliges Textfeld) - Beispiele

## Beispiel 1: Name

```
┌─────────────────────────────────────────┐
│ Name                                    │
├─────────────────────────────────────────┤
│  Max Mustermann                         │
│                                         │
└─────────────────────────────────────────┘
```

## Beispiel 2: E-Mail

```
┌─────────────────────────────────────────┐
│ E-Mail                                  │
├─────────────────────────────────────────┤
│  📧 max@example.com                     │
│                                         │
└─────────────────────────────────────────┘
```
