# Radio Group - Aussehen

## Grundlayout

Eine Radio Group ist eine Gruppe von Optionsfeldern (einzelfach).

## Layout

```
┌─────────────────────────────────────────┐
│ Option 1  (•)                           │
│ Option 2  ( )                           │
│ Option 3  ( )                           │
└─────────────────────────────────────────┘
```

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Default** | Standard-Kreis |
| **Toggle** | Schalter-Stil |
| **Radio Group** | Option mit anderen Optionen |

## Größe-Varianten

| Größe | Breite | Verwendung |
|-------|--------|------------|
| Small | 20px | Inline |
| Medium | 24px | Standard |
| Large | 28px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Selected** | Primärfarbe | Ausgewählt |
| **Unselected** | Grau | Nicht ausgewählt |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `scale` | Vergrößerung |
| `shadow` | Schatten stärker |
| `border` | Rand leuchtet auf |

## With Icons
