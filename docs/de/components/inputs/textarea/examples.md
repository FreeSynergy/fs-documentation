# Textarea (Mehrzeiliges Textfeld) - Beispiele

## Beispiel 1: Nachricht

```
┌─────────────────────────────────────────┐
│ Nachricht                               │
├─────────────────────────────────────────┤
│                                         │
│  Dies ist eine Nachricht...             │
│  Mehrzeiliger Text                      │
│                                         │
│                                         │
└─────────────────────────────────────────┘
```

## Beispiel 2: Kommentar

```
┌─────────────────────────────────────────┐
│ Kommentar                               │
├─────────────────────────────────────────┤
│  👤 John Doe                            │
│  Sehr gut!                              │
│                                         │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━    │
│  (123/500 Zeichen)                      │
└─────────────────────────────────────────┘
```
