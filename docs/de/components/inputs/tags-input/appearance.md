# Tags Input - Aussehen

## Grundlayout

Ein Tags Input ist eine Liste von Tags/Etiketten.

## Layout

```
┌─────────────────────────────────────────┐
│ Tags:                                   │
├─────────────────────────────────────────┤
│  [Java] [Python] [React]                │
│  + Neue Tag                             │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Breite | Verwendung |
|-------|--------|------------|
| Small | 200px | Inline |
| Medium | 300px | Standard |
| Large | 400px | Featured |
| Full | 100% | Volle Breite |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Tag** | Primärfarbe | Tag-Farbe |
| **Hover** | Heller | Hover-Zustand |
| **Disabled** | Grau | Deaktiviert |

## Tag-Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Simple** | Nur Text |
| **With Icon** | Mit Icon |
| **With Remove** | Mit X zum Entfernen |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `background` | Hintergrund ändert sich |
| `shadow` | Schatten stärker |
