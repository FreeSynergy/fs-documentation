# Checkbox (Ankreuzfeld) - Beispiele

## Beispiel 1: Einzelne Checkbox

```
┌─────────────────────────────────────────┐
│ [✓] Einverstanden                       │
└─────────────────────────────────────────┘
```

## Beispiel 2: Mit Icon

```
┌─────────────────────────────────────────┐
│ [✓] Wichtig   ⭐                        │
└─────────────────────────────────────────┘
```

## Beispiel 3: Formular

```
┌─────────────────────────────────────────┐
│ [✓] Newsletter abonnieren               │
│ [✓] Terms akzeptieren                   │
│ [ ] Sonderangebote erhalten             │
└─────────────────────────────────────────┘
```

## Beispiel 4: Indeterminate

```
┌─────────────────────────────────────────┐
│ [■] Alle auswählen                      │
│   [ ] Element 1                         │
│   [✓] Element 2                         │
│   [✓] Element 3                         │
└─────────────────────────────────────────┘
```

## Beispiel 5: mit Icons

```
┌─────────────────────────────────────────┐
│ [✓] Wichtig   ⭐                        │
│ [✓] Dringend  ⚠️                        │
│ [✓] Erledigt  ✓                         │
└─────────────────────────────────────────┘
```
