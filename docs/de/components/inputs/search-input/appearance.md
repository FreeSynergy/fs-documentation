# Search Input - Aussehen

## Grundlayout

Ein Search Input ist ein Suchfeld mit Autovervollständigung.

## Layout

```
┌─────────────────────────────────────────┐
│ 🔍 Suche...                             │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Breite | Verwendung |
|-------|--------|------------|
| Small | 150px | Inline |
| Medium | 250px | Standard |
| Large | 350px | Featured |
| Full | 100% | Volle Breite |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Default** | Hell | Standard |
| **Primary** | Primärfarbe | Primär |
| **Active** | Dunkel | Aktiver Zustand |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `border` | Rand leuchtet auf |
| `shadow` | Schatten stärker |

## Clear-Button

```
┌─────────────────────────────────────────┐
│ 🔍 Suche...                    [✕]      │
└─────────────────────────────────────────┘
```

## Auto-Complete

```
┌─────────────────────────────────────────┐
│ 🔍 Suche...                             │
```
