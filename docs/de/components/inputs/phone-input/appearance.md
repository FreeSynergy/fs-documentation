# Phone Input - Aussehen

## Grundlayout

Ein Phone Input ist ein Eingabefeld für Telefonnummern.

## Layout

```
┌─────────────────────────────────────────┐
│ Telefon                                 │
├─────────────────────────────────────────┤
│  🇩🇪 +49 123 456789                      │
│                                         │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Höhe | Verwendung |
|-------|------|------------|
| Small | 32px | Inline |
| Medium | 48px | Standard |
| Large | 64px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Default** | Hell | Standard |
| **Primary** | Primärfarbe | Primär |
| **Active** | Dunkel | Aktiver Zustand |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `border` | Rand leuchtet auf |
| `shadow` | Schatten stärker |

## Country Code

```
┌─────────────────────────────────────────┐
│ Telefon                                 │
├─────────────────────────────────────────┤
│  🇩🇪 +49  │  123 456789                  │
│          │                              │
└─────────────────────────────────────────┘
```

## Validation States

| State | Beschreibung |
|-------|--------------|
| **Valid** | Grün |
| **Invalid** | Rot |
| **Warning** | Orange |
