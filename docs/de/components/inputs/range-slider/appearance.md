# Range Slider - Aussehen

## Grundlayout

Ein Range Slider ist ein Schieberegler mit zwei Schiebern für einen Bereich.

## Layout

```
┌─────────────────────────────────────────┐
│ Preisbereich                            │
├─────────────────────────────────────────┤
│ 10€ [━━━━●━━━━━━━━━━━━━━●━━━━━━] 1000€ │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Breite | Verwendung |
|-------|--------|------------|
| Small | 200px | Inline |
| Medium | 300px | Standard |
| Large | 400px | Featured |
| Full | 100% | Volle Breite |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Track** | Grau | Track-Farbe |
| **Filled** | Primärfarbe | Filled-Farbe |
| **Thumb 1** | Primärfarbe | Erster Thumb |
| **Thumb 2** | Primärfarbe | Zweiter Thumb |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `scale` | Vergrößerung |
| `shadow` | Schatten stärker |
