# Switch - Aussehen

## Grundlayout

Ein Switch ist ein Ein/Aus-Schalter (Toggle).

## Layout-Varianten

### Standard (Rechteck)
```
┌─────────────────────────────────────────┐
│ [   ON   ]                              │
│                                         │
└─────────────────────────────────────────┘
```

### Round (Rund)
```
┌─────────────────────────────────────────┐
│ (   ON   )                              │
│                                         │
└─────────────────────────────────────────┘
```

### Pill (Pillenform)
```
┌─────────────────────────────────────────┐
│  [ ON ]                                 │
│                                         │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Breite | Verwendung |
|-------|--------|------------|
| Small | 40px | Inline |
| Medium | 56px | Standard |
| Large | 72px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Off** | Grau | Aus |
| **On** | Primärfarbe | Ein |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `scale` | Vergrößerung |
| `shadow` | Schatten stärker |
| `border` | Rand leuchtet auf |

## Animationen

| Effekt | Beschreibung |
|--------|--------------|
| `Slide` | Schiebe-Effekt |
| `Fade` | Einfade-Effekt |

## With Labels

```
┌─────────────────────────────────────────┐
│ Feature aktivieren        [   ON   ]    │
└─────────────────────────────────────────┘
```
