# Switch (Schalter)

## Beschreibung

Ein Switch ist ein Ein/Aus-Schalter (Toggle).

## Verwendungszweck

- Einstellungen
- Features
- Status

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Standard** | Rechteck |
| **Round** | Rund |
| **Pill** | Pillenform |

## Features

- Checked/Unchecked
- Animation
- Hover-Effect
