# File Upload (Datei-Upload)

## Beschreibung

Ein File Upload ist ein Element für Dateiauswahl und Upload.

## Verwendungszweck

- Dateien hochladen
- Bilder
- Dokumente

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **File Picker** | Dateiauswahl |
| **Drag & Drop** | Drag&Drop |
| **Image Preview** | Vorschau |

## Features

- Progress
- Preview
- Validation
