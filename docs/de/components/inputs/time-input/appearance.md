# Time Input - Aussehen

## Grundlayout

Ein Time Input ist ein Zeitauswahl-Feld.

## Layout

```
┌─────────────────────────────────────────┐
│Uhrzeit                                  │
├─────────────────────────────────────────┤
│  🕑 14:30                                │
│                                         │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Höhe | Verwendung |
|-------|------|------------|
| Small | 32px | Inline |
| Medium | 48px | Standard |
| Large | 64px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Default** | Hell | Standard |
| **Primary** | Primärfarbe | Primär |
| **Active** | Dunkel | Aktiver Zustand |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `border` | Rand leuchtet auf |
| `shadow` | Schatten stärker |

## Uhrzeiger

```
┌─────────────────────────────────────────┐
│  🕒                                    │
│                                         │
│      🕗                                │
│                                         │
│  🕓                                    │
└─────────────────────────────────────────┘
```

## AM/PM

```
┌─────────────────────────────────────────┐
│Uhrzeit                                  │
├─────────────────────────────────────────┤
│  🕐 02:30    [AM] [PM]                  │
│                                         │
└─────────────────────────────────────────┘
```
