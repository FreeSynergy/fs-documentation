# Rating (Bewertung)

## Beschreibung

Ein Rating ist eine Sterne- oder Punktebewertung.

## Verwendungszweck

- Produktbewertung
- Service-Bewertung
- Sterne

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Star Rating** | Sterne |
| **Heart Rating** | Herzen |
| **Number Rating** | Zahlen |

## Features

- Max Stars (meist 5)
- Read-only
- Interactive
