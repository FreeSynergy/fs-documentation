# Rating - Aussehen

## Grundlayout

Ein Rating ist eine Sterne- oder Punktebewertung.

## Layout-Varianten

### Star Rating
```
┌─────────────────────────────────────────┐
│ ⭐⭐⭐⭐☆                                   │
└─────────────────────────────────────────┘
```

### Heart Rating
```
┌─────────────────────────────────────────┐
│ ❤️❤️❤️❤️                                 │
└─────────────────────────────────────────┘
```

### Number Rating
```
┌─────────────────────────────────────────┐
│ 4/5                                     │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Breite | Verwendung |
|-------|--------|------------|
| Small | 80px | Inline |
| Medium | 120px | Standard |
| Large | 160px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Filled** | Gold | Gefüllte Symbole |
| **Empty** | Grau | Leere Symbole |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `scale` | Vergrößerung |
| `transform` | Hebung |

## With Count

```
┌─────────────────────────────────────────┐
│ ⭐⭐⭐⭐☆ (4.5)                            │
└─────────────────────────────────────────┘
```

## Read-only

```
┌─────────────────────────────────────────┐
│ ⭐⭐⭐⭐☆ (123 Bewertungen)                │
└─────────────────────────────────────────┘
```
