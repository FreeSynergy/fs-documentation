# Search Field (Suchfeld mit Filter)

## Beschreibung

Ein Search Field ist ein Suchfeld mit Filtermöglichkeiten.

## Verwendungszweck

- Suche
- Filter
- Schnellsuche

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Simple** | Einfache Suche |
| **Filter** | Mit Filtern |
| **Auto-complete** | Mit Vorschlägen |

## Features

- Filter
- Auto-complete
- Recent Searches
