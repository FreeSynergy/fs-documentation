# Number Input - Aussehen

## Grundlayout

Ein Number Input ist ein Eingabefeld für Zahlen.

## Layout

```
┌─────────────────────────────────────────┐
│ Anzahl                                  │
├─────────────────────────────────────────┤
│  [ 123 ]                                │
│                                         │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Höhe | Verwendung |
|-------|------|------------|
| Small | 32px | Inline |
| Medium | 48px | Standard |
| Large | 64px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Default** | Hell | Standard |
| **Primary** | Primärfarbe | Primär |
| **Active** | Dunkel | Aktiver Zustand |
| **Disabled** | Grau | Deaktiviert |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `border` | Rand leuchtet auf |
| `shadow` | Schatten stärker |

## Step-Buttons

```
┌─────────────────────────────────────────┐
│ Anzahl                                  │
├─────────────────────────────────────────┤
│  [ 123 ]   [▲]                          │
│            [▼]                          │
└─────────────────────────────────────────┘
```

## Validation States

| State | Beschreibung |
|-------|--------------|
| **Valid** | Grün |
| **Invalid** | Rot |
| **Warning** | Orange |
