# Rich Text Editor - Aussehen

## Grundlayout

Ein Rich Text Editor ist ein WYSIWYG-Editor für formatierten Text.

## Layout

```
┌─────────────────────────────────────────┐
│ [B] [I] [U] [ Strikes] [ Color]         │  ← Toolbar
├─────────────────────────────────────────┤
│                                         │
│  (Editor-Bereich)                       │
│                                         │
│  Hier ist der Text...                   │
│                                         │
└─────────────────────────────────────────┘
```

## Größe-Varianten

| Größe | Höhe | Verwendung |
|-------|------|------------|
| Small | 200px | Inline |
| Medium | 400px | Standard |
| Large | 600px | Featured |
| Full | 100% | Volle Breite |

## Toolbar-Buttons

| Button | Funktion |
|--------|----------|
| **B** | Fett |
| **I** | Kursiv |
| **U** | Unterstrichen |
| ** Strikes** | Durchgestrichen |
| ** Color** | Farbe |
| ** Heading** | Überschriften |
| ** List** | Listen |
| ** Link** | Links |
| ** Image** | Bilder |
| ** Code** | Code-Block |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `border` | Rand leuchtet auf |
| `shadow` | Schatten stärker |

## Placeholder

```
┌─────────────────────────────────────────┐
│ [B] [I] [U] ...                         │
├─────────────────────────────────────────┤
│  Dies ist ein Platzhalter...            │
└─────────────────────────────────────────┘
```
