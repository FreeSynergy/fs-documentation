# Dropdown (Auswahlliste) - Beispiele

## Beispiel 1: Länderauswahl

```
┌─────────────────────────────────────────┐
│ Land                                    │
├─────────────────────────────────────────┤
│  Deutschland ▼                          │
├─────────────────────────────────────────┤
│  Österreich                             │
│  Schweiz                                │
│  Frankreich                             │
│  Italien                                │
└─────────────────────────────────────────┘
```

## Beispiel 2: Benutzer-Auswahl

```
┌─────────────────────────────────────────┐
│ Verantwortlicher                        │
├─────────────────────────────────────────┤
│  John Doe ▼                             │
├─────────────────────────────────────────┤
│  John Doe                               │
│  Jane Smith                             │
│  Bob Müller                             │
│  Alice Winter                           │
└─────────────────────────────────────────┘
```

## Beispiel 3: Kategorien (Multi-Select)

```
┌─────────────────────────────────────────┐
│ Kategorien                              │
├─────────────────────────────────────────┤
│  [Java] [Python] [React] ▼             │
├─────────────────────────────────────────┤
│  [✓] Java                               │
│  [✓] Python                             │
│  [ ] React                              │
│  [ ] Node.js                            │
│  [ ] Angular                            │
└─────────────────────────────────────────┘
```
