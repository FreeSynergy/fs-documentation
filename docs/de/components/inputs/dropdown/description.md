# Dropdown (Auswahlliste)

## Beschreibung

Ein Dropdown ist eine Auswahlliste mit vielen Optionen.

## Verwendungszweck

- Auswahl
- Filter
- Kategorien

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Simple** | Einfache Liste |
| **Multi-select** | Mehrfachauswahl |
| **Searchable** | Mit Suche |
| **Custom** | Benutzerdefiniert |

## Features

- Search
- Multi-select
- Customizable
