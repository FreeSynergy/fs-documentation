# Block Editor (Blockeditor) - Aussehen

## Grundlayout

```
┌─────────────────────────────────────────┐
│ ⋮⋮ # Heading                            │
│ ⋮⋮ Paragraph of text …                  │
│ ⋮⋮ ☐ Task block                         │
│ ⋮⋮ [ Contact block ]                    │
│ + Add block                             │
└─────────────────────────────────────────┘
```

## Varianten

| Variante | Aussehen |
|---|---|
| **edit** | Ziehgriff links neben jedem Block, Einfügezeile dazwischen |
| **read** | keine Griffe |
| **template** | Platzhalter hervorgehoben |

## Größen

| Größe | Höhe | Verwendung |
|---|---|---|
| `medium` | 400 px | Standard |
| `large` | 600 px | Seite |
| `full` | 100% | gesamter Bereich |

## Farben und Zustände

| Zustand | Aussehen |
|---|---|
| Standard | Oberfläche des Themes |
| Ausgewählter Block | Akzentrahmen |
| Markierungsebene | Unterstreichung oder Tönung je Typ |
| Platzhalter | gestrichelter Rahmen |

## Hover- und Fokus-Effekte

| Effekt | Beschreibung |
|---|---|
| `handle` | Ziehgriff erscheint |
| `background` | Blockhervorhebung |

## Reaktiv

- Auf schmalen Bildschirmen werden die Griffe zu einem Blockmenü-Button.
- Blöcke stapeln sich über die volle Breite.
