# Stepper (Schrittzähler)

## Beschreibung

Ein Stepper ist eine visuelle Fortschrittsanzeige für Schritte.

## Verwendungszweck

- Visueller Fortschritt
- Schritt-für-Schritt-Abläufe
- Onboarding
- Multi-Step-Forms

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Horizontal** | Horizontal (häufiger) |
| **Vertical** | Vertikal |
| **Dots** | Punkte-Stepper |
| **Lines** | Linien-Stepper |

## States

| State | Beschreibung |
|-------|--------------|
| **Active** | Aktueller Schritt |
| **Completed** | Abgeschlossener Schritt |
| **Pending** | Ausstehender Schritt |
| **Error** | Schritt mit Fehler |

## Features

- Clickable (Klickbar)
- Animated (Animation)
- Keyboard-Navigation
- Accessibility (Barrierefreiheit)

## Best Practices

- Clear-Labels
- Konsistente States
- Feedback
- Progress
