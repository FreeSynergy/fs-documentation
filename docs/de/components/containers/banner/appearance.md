# Banner - Aussehen

## Grundlayout

Ein Banner ist eine große Benachrichtigung, die meist oben am Bildschirm angezeigt wird.

## Layout

```
┌─────────────────────────────────────────────────────────┐
│ [✕]  📢 Titel                                            │
│      Beschreibungstext...                                │
│                                                          │
│          [Aktion] [Aktion]                               │
└─────────────────────────────────────────────────────────┘
```

## Varianten

| Variant | Farbe | Beschreibung |
|---------|-------|--------------|
| **Info** | Blau | Informationsbanner |
| **Success** | Grün | Erfolgsmeldung |
| **Warning** | Orange/Gelb | Warnbanner |
| **Error** | Rot | Fehlerbanner |

## Größe-Varianten

| Größe | Höhe | Verwendung |
|-------|------|------------|
| Small | 48px | Kurze Nachrichten |
| Medium | 64px | Standard |
| Large | 96px | Lange Nachrichten |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Info** | Blau | Informationsbanner |
| **Success** | Grün | Erfolgsmeldung |
| **Warning** | Orange | Warnbanner |
| **Error** | Rot | Fehlerbanner |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `shadow` | Schatten stärker |
| `border-bottom` | Linie leuchtet auf |
