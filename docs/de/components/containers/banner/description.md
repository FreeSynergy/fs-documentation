# Banner (Banner-Benachrichtigung)

## Beschreibung

Ein Banner ist eine große Benachrichtigung, die meist oben am Bildschirm angezeigt wird.

## Verwendungszweck

- Wichtige Nachrichten
- Systemnachrichten
- Updates
- Aktionen (z.B. "Jetzt upgraden")

## Varianten

| Variant | Farbe | Beschreibung |
|---------|-------|--------------|
| **Info** | Blau | Informationsbanner |
| **Success** | Grün | Erfolgsmeldung |
| **Warning** | Orange/Gelb | Warnbanner |
| **Error** | Rot | Fehlerbanner |

## Layout

```
┌─────────────────────────────────────────────────────────┐
│ [✕]  📢 Titel                                            │
│      Beschreibungstext...                                │
│                                                          │
│          [Aktion] [Aktion]                               │
└─────────────────────────────────────────────────────────┘
```

## Features

- Dismissible (Schließbar)
- Action Buttons (Mehrere Aktionen)
- Sticky (Fixiert oben)
- Animated (Animation)

## Best Practices

- Clear-Text
- Action-Buttons
- Sticky (Fixiert oben)
- Non-intrusive (Nicht störend)
