# Modal (Modaler Dialog) - Beispiele

## Beispiel 1: Bestätigungs-Modal

```
┌─────────────────────────────────────────┐
│ [✕] Bestätigung                         │
├─────────────────────────────────────────┤
│                                         │
│   Möchten Sie wirklich löschen?         │
│                                         │
├─────────────────────────────────────────┤
│  [Nein]               [Ja]              │
└─────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────┐
│ [✕] Benutzer bearbeiten                 │
├─────────────────────────────────────────┤
│ Name                                    │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━        │
│ Email                                   │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━        │
│                                         │
├─────────────────────────────────────────┤
│  [Abbrechen]        [Speichern]         │
└─────────────────────────────────────────┘
```
