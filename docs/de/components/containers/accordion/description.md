# Accordion (Akkordeon)

## Beschreibung

Ein Accordion ist ein Stapel von Kopfzeilen, die Inhalte ein-/ausklappen können.

## Verwendungszweck

- Platz sparen durch Ein-/Ausklappen
- FAQ-Sectionen
- Einstellungs-Gruppen
- Kategorien mit Unterpunkten

## Verhalten

| Verhalten | Beschreibung |
|-----------|--------------|
| **Single Expand** | Nur einer offen |
| **Multiple Expand** | Mehrere offen |
| **Accordion Group** | Gruppen von Accordion-Items |

## Features

- Expand/Collapse
- Animation (Ein-/Ausklapp-Animation)
- Keyboard-Navigation
- Accessibility (Barrierefreiheit)

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Default** | Standard-Akkordeon |
| **Expanded** | Alle initial expandiert |
| **Disabled** | Deaktivierte Elemente |
| **Collapsible** | Klickbare Header |

## Best Practices

- Klarer Header-Text
- Konsistente Icon
- Animation
- Accessibility
