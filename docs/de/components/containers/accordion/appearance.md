# Accordion - Aussehen

## Grundlayout

Ein Accordion ist ein Stapel von Kopfzeilen, die Inhalte ein-/ausklappen können.

## Layout

```
┌─────────────────────────────────────────┐
│ ▶ Kopfzeile 1                           │
├─────────────────────────────────────────┤
│   Inhalt 1                              │
├─────────────────────────────────────────┤
│ ▶ Kopfzeile 2                           │
├─────────────────────────────────────────┤
│   Inhalt 2                              │
├─────────────────────────────────────────┤
│ ▶ Kopfzeile 3                           │
└─────────────────────────────────────────┘
```

## Varianten

| Variant | Beschreibung |
|---------|--------------|
| **Single Expand** | Nur einer offen |
| **Multiple Expand** | Mehrere offen |
| **Accordion Group** | Gruppen von Items |

## Größe-Varianten

| Größe | Schriftgröße | Verwendung |
|-------|-------------|------------|
| Small | 12px | Inline |
| Medium | 14px | Standard |
| Large | 16px | Featured |

## Farb-Varianten

| Status | Farbe | Beschreibung |
|--------|-------|--------------|
| **Active Header** | Primärfarbe | Aktiver Header |
| **Inactive Header** | Grau | Inaktiver Header |
| **Content** | Dunkel | Inhalt |

## Hover-Effekte

| Effekt | Beschreibung |
|--------|--------------|
| `color` | Farbe ändert sich |
| `background` | Hintergrund ändert sich |
| `border-bottom` | Unterstrich erscheint |

## Animationen

| Effekt | Beschreibung |
|--------|--------------|
| `Fade In` | Einfade-Effekt |
| `Slide Down` | Schiebe-Effekt nach unten |
| `Rotate` | Icon rotiert |
