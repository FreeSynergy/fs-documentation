# Drawer (Seitenleiste)

## Beschreibung

Ein Drawer ist ein seitliches Overlay-Fenster (einklappbar).

## Verwendungszweck

- Navigation
- Filter
- Profile

## Varianten

| Variant | Position | Beschreibung |
|---------|----------|--------------|
| **Left Drawer** | Links | Links |
| **Right Drawer** | Rechts | Rechts |
| **Bottom Drawer** | Unten | Unten |
| **Full Drawer** | Voll | Vollständig |

## Features

- Header
- Body
- Footer
- Close
- Dismissible

## Best Practices

- Clear-Content
- Close-Button
- Accessibility
- Feedback
