# Container

Container-Elemente gruppieren Inhalt und organisieren das Layout.

## Elemente

- **card** - Inhalt in einer Box mit Titel
- **modal** - Overlay-Fenster für Aktionen
- **drawer** - Seitliches Ein/Ausklappfenster
- **accordion** - Stapel von Kopfzeilen mit Ein-/Ausklappen
- **panel** - Großer Container mit Header, Inhalt und Footer
- **wizard** - Schritt-für-Schritt-Formular
- **stepper** - Visuelle Fortschrittsanzeige für Schritte
- **alert** - Status-Meldung (Info, Warning, Error, Success)
- **toast** - Pop-up-Benachrichtigung
- **banner** - Große Benachrichtigung (oft oben)
- **split-view** - Zwei Bereiche side-by-side
