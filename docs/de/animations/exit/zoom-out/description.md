# Zoom Out

## Beschreibung

Zoom Out lässt ein Element von voller Größe auf eine Skalierung nahe null schrumpfen und dabei ausblenden – der Gegenpart zu Zoom In. Das Element zieht sich sichtbar „zurück“ und verschwindet.

## Verwendung

- Modal-Dialoge und Lightboxen beim Schließen verkleinern
- Gelöschte Listenelemente zusammenschrumpfen lassen
- Kontextmenüs und Popovers weich schließen
- Deaktivierte Icons beim Aufräumen verschwinden lassen
- Seiten-Exit in Assistenten: alte Seite schrumpft hinaus
- Miniaturisierte Fenster in eine Dock-Position „saugen“

## Dauer

- Typisch: 150–300ms
- Ausgänge kürzer als Eingänge, damit Nutzende nicht warten müssen
- Minimieren in Dock/Icon-Position: bis 350ms, da Wegstrecke sichtbar ist

## Unterschied zu Zoom In

- Zoom Out: Die Skalierung fällt von 1 auf nahe 0, das Element verschwindet
- Zoom In: Die Skalierung steigt von unter 1 auf 1, das Element erscheint
