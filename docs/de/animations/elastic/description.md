# Elastic

## Beschreibung

Elastic führt eine Bewegung mit Überschießen aus: Das Element schießt über seine Zielposition hinaus und federt anschließend in sie zurück.
Die Bewegung wirkt federnd und physisch.
Zielposition und Zeitpunkt stehen dabei von Anfang an fest.

## Verwendung

- Element in einen Ablagebereich einrasten lassen
- Schalter-Knopf, der über die Endlage hinausschießt
- Menü- oder FAB-Elemente mit federndem Charakter öffnen
- Slider, der in ein Raster einrastet
- Listenzeilen beim Umsortieren weich abfedern lassen
- Button wächst federnd in seine neue Größe

## Dauer

- Typisch: 400–800 ms (inkl. Abklingen der Schwingung)

## Unterschied zu Bounce In und Rubber Band

- Bounce In: Eingang mit mehreren Bodenkontakten, während das Element
  erscheint; Elastic bewegt ein bereits sichtbares Element in eine feste Endlage.
- Rubber Band: Der Inhalt folgt dem Finger über den Rand und federt erst nach
  dem Loslassen zurück; Elastic überschießt ohne Gestik von selbst.
