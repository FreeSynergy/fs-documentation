# Shake

## Beschreibung

Shake rüttelt ein Element kurz horizontal um seine Ruhelage und klingt dabei ab. Es ist ein Feedback der Oberfläche: Die Anwendung signalisiert damit einen Fehler oder eine abgelehnte Aktion.

## Verwendung

- Falsches Passwort oder falscher Code im Login
- Formularfeld wird als ungültig abgelehnt
- Aktion ist an dieser Stelle nicht erlaubt
- Drag & Drop auf ein unpassendes Ziel
- Erinnerung an ein noch leeres Pflichtfeld

## Dauer

- Typisch: 300–500 ms
- Standardwert: 400 ms

## Unterschied zu Wiggle

- Wiggle: leichte Rotation um wenige Grad, länger oder endlos, als Hinweis auf den Bearbeitungsmodus
- Shake: horizontale Verschiebung mit größerer Amplitude, einmalig, als Fehlermeldung

## Unterschied zur Geste Shake

- Animation Shake: Das Element bewegt sich von selbst - die Anwendung gibt Feedback an den Nutzer
- Geste Shake (siehe [Shake-Geste](../../../gestures/device/shake/description.md)): Der Nutzer schüttelt das Gerät - eine Eingabe, auf die die Anwendung reagiert
- Kurz: Bei der Animation bewegt sich das Element als Ausgabe, bei der Geste schüttelt der Mensch das Gerät als Eingabe
