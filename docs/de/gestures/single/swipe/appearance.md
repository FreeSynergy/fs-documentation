# Swipe - Aussehen

## Grundlayout

Ein Swipe ist ein Wischen in eine Richtung.

## Visuelles Feedback

```
┌─────────────────────────────────────────┐
│  ←─────                                 │
│    ←─────                               │
│      ←─────                             │
│        ←─────                           │
└─────────────────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Velocity** | Geschwindigkeit anzeigen |
| **Direction** | Pfeil in Swipe-Richtung |
| **None** | Kein Feedback |

## Richtungen

| Richtung | Pfeil | Beschreibung |
|----------|-------|--------------|
| Left | ← | Nach links wischen |
| Right | → | Nach rechts wischen |
| Up | ↑ | Nach oben wischen |
| Down | ↓ | Nach unten wischen |

## Distanz

- Typisch: > 50px
