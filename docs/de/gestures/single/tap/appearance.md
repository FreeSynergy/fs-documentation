# Tap - Aussehen

## Grundlayout

Ein Tap ist eine kurze Berührung auf den Bildschirm.

## Visuelles Feedback

```
┌─────────────────────────────────────────┐
│                                         │
│     [Klick]                             │
│                                         │
└─────────────────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Ripple** | Welle bei Berührung |
| **Scale** | Leichte Vergrößerung |
| **Color** | Farbe ändert sich |
| **None** | Kein Feedback |

## Dauer

- Typisch: < 250ms

## Unterschied zu Long Press

- Tap: Kurz (< 250ms)
- Long Press: Lang (> 500ms)
