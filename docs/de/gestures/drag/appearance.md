# Drag - Aussehen

## Grundlayout

Drag ist das Ziehen eines Elements auf den Bildschirm.

## Visuelles Feedback

```
┌─────────────────────────────────────────┐
│  [Element]                              │
│     ↓                                   │
│     ↓                                   │
│     ↓                                   │
│        [Element]                        │
└─────────────────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Ghost** | Halbtransparentes Element |
| **Scale** | Vergrößerung beim Ziehen |
| **Shadow** | Schatten unter dem Element |

## Distanz

- Typisch: > 10px

## Phasen

| Phase | Beschreibung |
|-------|--------------|
| **Start** | Drag-Start |
| **Move** | Element folgen |
| **End** | Drop an der neuen Position |
