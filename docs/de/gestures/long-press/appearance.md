# Long Press - Aussehen

## Grundlayout

Ein Long Press ist eine lange Berührung auf den Bildschirm.

## Visuelles Feedback

```
┌─────────────────────────────────────────┐
│                                         │
│     [──────]                            │
│                                         │
└─────────────────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Ripple** | Welle bei Berührung |
| **Scale** | Leichte Vergrößerung |
| **Color** | Farbe ändert sich |
| **Haptic** | Haptisches Feedback (Vibration) |

## Dauer

- Typisch: > 500ms

## Unterschied zu Tap

- Tap: Kurz (< 250ms)
- Long Press: Lang (> 500ms)
