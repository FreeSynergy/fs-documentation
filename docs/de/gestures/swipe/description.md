# Swipe

## Beschreibung

Ein Swipe ist ein Wischen in eine Richtung.

## Verwendung

- Navigation (z.B. Seite wechseln)
- Switchen zwischen Ansichten
- Löschen durch Wischen

## Richtungen

| Richtung | Beschreibung |
|----------|--------------|
| Left | Nach links wischen |
| Right | Nach rechts wischen |
| Up | Nach oben wischen |
| Down | Nach unten wischen |

## Distanz

- Typisch: > 50px
