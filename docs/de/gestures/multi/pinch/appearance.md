# Pinch - Aussehen

## Grundlayout

Pinch ist das Zusammenziehen der Finger - mindestens zwei, beliebig viele mehr.

## Visuelles Feedback

```
┌─────────────────────────────────────────┐
│      (  )                               │
│     (    )                              │
│    (      )                             │
│   (        )                            │
└─────────────────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Zoom** | Zoom-Faktor anzeigen |
| **Scale** | Element skaliert sich |
| **None** | Kein Feedback |

## Richtung

- Zwei oder mehr Finger bewegen sich zueinander

## Distanz

- Typisch: > 20px Bewegung

## Zoom-Faktor

- Typisch: 0.5x (Halbieren)
