# Rotate - Aussehen

## Grundlayout

Rotate ist das Drehen von zwei Fingern um einen Mittelpunkt.

## Visuelles Feedback

```
┌─────────────────────────────────────────┐
│      ↻                                  │
│    ↻                                    │
│  ↻                                      │
│↻                                          │
└─────────────────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Angle** | Winkel anzeigen |
| **Rotate** | Element dreht sich |
| **None** | Kein Feedback |

## Richtung

- Zwei Finger drehen im Uhrzeigersinn oder gegen den Uhrzeigersinn

## Winkel

- Typisch: > 10° Drehung

## Drehrichtung

| Richtung | Symbol | Beschreibung |
|----------|--------|--------------|
| Clockwise | ↻ | Im Uhrzeigersinn |
| Counter-Clockwise | ↺ | Gegen den Uhrzeigersinn |
