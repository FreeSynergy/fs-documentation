# Spread - Aussehen

## Grundlayout

Spread ist das Auseinanderziehen von zwei Fingern.

## Visuelles Feedback

```
┌─────────────────────────────────────────┐
│   (        )                            │
│    (      )                             │
│     (    )                              │
│      (  )                               │
└─────────────────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Zoom** | Zoom-Faktor anzeigen |
| **Scale** | Element skaliert sich |
| **None** | Kein Feedback |

## Richtung

- Zwei Finger bewegen sich voneinander weg

## Distanz

- Typisch: > 20px Bewegung

## Zoom-Faktor

- Typisch: 2.0x (Verdoppeln)
