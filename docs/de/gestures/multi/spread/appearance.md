# Spread - Aussehen

## Grundlayout

Spread (Strecken) ist das Auseinanderziehen der Finger - mindestens zwei,
beliebig viele mehr.

## Visuelles Feedback

```
┌─────────────────────────────────────────┐
│   (        )                            │
│    (      )                             │
│     (    )                              │
│      (  )                               │
└─────────────────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Zoom** | Zoom-Faktor anzeigen |
| **Scale** | Element skaliert sich |
| **None** | Kein Feedback |

## Richtung

- Zwei oder mehr Finger bewegen sich voneinander weg

## Distanz

- Typisch: > 20px Bewegung

## Zoom-Faktor

- Typisch: 2.0x (Verdoppeln)
