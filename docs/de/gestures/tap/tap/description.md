# Tap

## Beschreibung

Ein Tap ist eine kurze Berührung auf den Bildschirm.

## Fingeranzahl

Von 1 bis zur Gerätegrenze (typisch 5–10 Finger). Mehrere gleichzeitige
Finger werden als eine Geste am Mittelpunkt aller Zeiger erkannt.

## Verwendung

- Button-Klicks
- Item-Auswahl
- Navigation

## Dauer

- Typisch: < 250ms

## Unterschied zu Long Press

- Tap: Kurz (< 250ms)
- Long Press: Lang (> 500ms)
