# Rotate

## Beschreibung

Rotate ist das Drehen der Finger um einen Mittelpunkt - mindestens zwei,
beliebig viele mehr.

Die Anzahl spielt keine Rolle: mit drei oder fünf Fingern ist es dieselbe
Geste, gewertet wird die Winkeländerung der Zeiger zum Mittelpunkt.

## Fingeranzahl

Ab 2 bis zur Gerätegrenze (üblich genau 2); die Mindestanzahl stellt
`pointerCount` ein.

## Verwendung

- Rotieren von Bildern
- Rotieren von Objekten

## Richtung

- Zwei oder mehr Finger drehen im Uhrzeigersinn oder gegen den Uhrzeigersinn

## Winkel

- Typisch: > 10° Drehung
