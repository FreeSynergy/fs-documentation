# Wave - Aussehen

## Grundlayout

Das Gerät zeigt einen vorbereitenden Countdown; die Hand erscheint im
Sensorkegel oberhalb des Displays.

```
┌───────────────────────────────┐
│          ✋ (Hand über Gerät)  │
│          ┆ Sensorkegel        │
│  ┌─────────────────────┐      │
│  │ Anruf von Anna      │      │
│  │ ⏱ 3…2…1 annehmen    │      │
│  └─────────────────────┘      │
└───────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Countdown** | Zeitfenster zum Winken läuft sichtbar |
| **Hand Cursor** | Zeiger folgt der Hand über der UI |
| **Haptic + Ton** | Quittierung nach Erkennung |
| **Privacy Dot** | dauerhaft: Sensor aktiv |

## Countdown-Längen

| Länge | Verwendung |
|-------|------------|
| 3s | Anruf annehmen |
| 5s | Assistent-/Medienbefehle |

## Dauer

- Gestenerkennung: < 500ms nach Musterende
- Vorbereitungs-Countdown: 3–5s

## Unterschied zu Shake

- Wave: Sensor zeigt nach außen, Nutzer bewegt Hand
- Shake: Sensor im Gerät, Nutzer bewegt Gerät
