# Hilfe zu Maps

Maps merkt sich deine Orte: einen Namen, eine Position und ein paar Worte zu jedem. Heute ist das Fenster eine Liste der Orte mit einer Seite für jeden. Eine gezeichnete Karte gibt es noch nicht.

## Die Ansichten

- [Orte](places.md): die Liste der Orte und die Suche.
- [Ort](place.md): die Seite eines Orts.
- [Ort bearbeiten](edit-place.md): das Formular, um einen Ort zu ändern oder neu anzulegen.
- [Ort löschen](delete-place.md): die beiden Schritte, um einen Ort zu entfernen.

## So startest du

Starte `fs-maps` ohne Argumente. Das Fenster öffnet sich. Antwortet kein Maps-Server, startet das Fenster im Hintergrund einen für dich. Du kannst den Server auch selbst mit `fs-maps serve` starten.
