# Hilfe zu Groups

Groups behält im Blick, wer zusammengehört: eine Familie, ein Team, ein Verein. Heute zeigt das Fenster deine Gruppen und bei jeder, wozu sie gehört und wer Mitglied ist. Du kannst Gruppen anlegen, umbenennen, in ihrer Art ändern und löschen.

## Die Ansichten

- [Groups](groups.md): die Liste der Gruppen und die Suche.
- [Gruppe](group.md): die Seite einer Gruppe.
- [Gruppe bearbeiten](edit-group.md): das Formular, um eine Gruppe zu ändern oder neu anzulegen.
- [Gruppe löschen](delete-group.md): die beiden Schritte, um eine Gruppe zu entfernen.

## So startest du

Starte `fs-groups` ohne Argumente. Das Fenster öffnet sich. Antwortet kein Groups-Server, startet das Fenster im Hintergrund einen für dich. Du kannst den Server auch selbst mit `fs-groups serve` starten.
