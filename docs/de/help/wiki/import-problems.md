# Importprobleme

## Was du siehst

Eine Seite namens "Importprobleme", im [Seitenbaum](page-tree.md) als "(Importprobleme)" aufgeführt. Sie existiert nur, wenn der Import etwas gefunden hat, das eine Person braucht. Sie kann diese Teile haben:

- "Nicht importiert": Dateien, die nicht importiert werden konnten, jeweils mit dem Grund.
- "In Datei und Wiki geändert": Das Wiki behält seinen Text, nichts wird überschrieben, und die Version aus der Datei wird gezeigt, damit nichts verloren geht.
- "Dateien, die fehlen": Dateien, die einmal importiert wurden; ihre Texte bleiben erhalten.
- "Auf dem Server fehlend": Dateien, die einmal importiert wurden, deren Text der Server nicht mehr hat. Sie werden nicht erneut importiert.
- "Nicht angesehen": Einträge des Ordners, die ausgelassen wurden.

Ein ungespeicherter Entwurf einer Seite, die verschoben oder gelöscht wurde, wird hier ebenfalls aufgeführt.

## Was du tun kannst

1. Öffne "(Importprobleme)" im Baum.
2. Lies die Teile. Bei einem Konflikt kopierst du, was du brauchst, aus dem gezeigten Text.
3. Um eine fehlende Datei zurückzuholen, importiere sie von Hand.

## Tastatur

Keine eigene.
