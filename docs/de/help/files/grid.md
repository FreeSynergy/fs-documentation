# Grid

## Was du siehst

Dieselben Dateien und Ordner wie in der [Liste](list.md), aber als Kacheln. Jede Kachel zeigt den Namen, den Typ und die Größe. Eine sensible Datei trägt die Markierung "Sensitive". Ein leerer Ordner zeigt "This folder is empty.".

## Was du tun kannst

1. Drücke "Grid" in der Werkzeugleiste, um auf Kacheln umzuschalten. Drücke "List", um zurückzugehen.
2. Klicke eine Kachel an, um sie auszuwählen. Der [Seitenbereich](selected-item.md) zeigt sie an.
3. Klicke die ausgewählte Kachel noch einmal an, um sie zu öffnen, wenn es ein Ordner ist.
4. Suchen, Sortieren und Filtern funktionieren wie in der Liste.

## Tastatur

Left, Right, Up und Down bewegen dich zwischen den Kacheln. Page Up und Page Down bewegen dich seitenweise durch die Kacheln. Home geht zur ersten Kachel und End zur letzten. Am Rand bewirkt eine Taste nichts und öffnet keinen Ordner.
