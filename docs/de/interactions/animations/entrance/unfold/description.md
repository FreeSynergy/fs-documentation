# Unfold

## Beschreibung

Unfold öffnet ein Element wie ein Blatt Papier: Die obere Kante bleibt verankert, der Rest schwingt aus der Ebene heraus in die Betrachterebene, mit Perspektive (`rotateX`). Das Ergebnis ist ein räumlicher Falteffekt und keine bloße Größenänderung.

## Verwendung

- einklappbare Menü-"Blätter" und Kartenstapel
- Notiz- oder Postkarten-Optik im Onboarding
- einklappbare Bild- und Zitatbereiche
- papierähnliche Umschläge (Einladung, Bericht)
- auffällige Öffnungssequenzen in Marketingbereichen
- der Umschlag einer digitalen Einladung

## Dauer

- Typisch: 300–600 ms
- Standardwert: 450 ms

## Unterschied zu Expand

- Expand: eine reine Höhenänderung von 0 bis zur Inhaltshöhe, ohne Drehung und ohne Perspektive.
- Flip: dreht das ganze Element um 180° und zeigt währenddessen eine andere Rückseite. Unfold öffnet nur einen Teil und zeigt denselben Inhalt.
- Slide In: das Element verschiebt sich nur. Durch die Drehung verändert Unfold auch die sichtbare Höhe.
