# Unfold

## Beschreibung

Unfold klappt ein Element wie ein Blatt Papier auf: Der obere Rand bleibt verankert, der Rest schwenkt mit Perspektive (`rotateX`) aus der Ebene heraus in die Betrachterebene. Es entsteht ein räumlicher Klapp-Effekt, keine reine Größenänderung.

## Verwendung

- Aufklappbare Menü-„Blätter“ und Kartenstapel
- Notiz- oder Postkarten-Ästhetik im Onboarding
- Aufklappbare Bild- und Zitatbereiche
- Papierhafte Umschläge (Einladung, Bericht)
- Effektvolle Öffnungsvorgänge in Marketing-Bereichen
- Umschlag einer digitalen Einladung

## Dauer

- Typisch: 300–600 ms
- Standardwert: 450 ms

## Unterschied zu Expand

- Expand: reine Höhenänderung von 0 auf Inhaltshöhe, ohne Drehung und ohne Perspektive
- Flip: dreht das komplette Element um 180° und zeigt dabei eine andere Rückseite; Unfold klappt nur einen Teil auf und zeigt denselben Inhalt
- Slide In: das Element verschiebt sich nur; Unfold verändert durch die Drehung auch die sichtbare Höhe
