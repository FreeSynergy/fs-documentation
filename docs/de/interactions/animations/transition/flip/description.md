# Flip

## Beschreibung

Flip dreht ein Element um 180° um eine waagerechte oder senkrechte Achse und zeigt dabei seine Rückseite – wie beim Umdrehen einer Spielkarte. Der Inhaltswechsel passiert beim Wendepunkt von 90°. Die Perspektive erzeugt einen räumlichen Eindruck.

## Verwendung

- Vokabel- und Lernkarten umdrehen (Frage ↔ Antwort)
- Kreditkartenformular: Vorderseite ↔ Rückseite (CVV-Feld)
- Buttons wechseln beim Klick ihre Vorder- und Rückseite
- Dashboard-Kacheln mit zusätzlichen Informationen auf der Rückseite
- Details eines Elements auf der Rückseite der Karte zeigen
- Schalter-Icons tauschen, indem sie gegen die Rückseite gedreht werden
- Postkarten- und Galerieeffekte auf Landing Pages

## Dauer

- Typisch: 300–600 ms
- Icon-Flip: 300 ms, Karten mit Text: 500–600 ms

## Unterschied zu Rotate

- Flip: eine Drehung um 180° mit Seitenwechsel – danach ist die Rückseite sichtbar
- Rotate: eine Drehung um einen beliebigen Winkel um die eigene Achse, die Vorderseite bleibt sichtbar
