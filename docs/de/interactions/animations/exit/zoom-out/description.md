# Zoom Out

## Beschreibung

Zoom Out schrumpft ein Element von seiner vollen Größe auf eine Skalierung nahe null und blendet
es dabei aus. Es ist das Gegenstück zu Zoom In. Das Element zieht sich sichtbar „zurück“ und
verschwindet.

## Verwendung

- modale Dialoge und Lightboxen beim Schließen verkleinern
- gelöschte Listeneinträge gemeinsam schrumpfen lassen
- Kontextmenüs und Popovers sanft schließen
- deaktivierte Icons beim Aufräumen verschwinden lassen
- Seitenaustritt in Assistenten: Die alte Seite schrumpft hinaus
- ein minimiertes Fenster in eine Dock-Position „einsaugen“

## Dauer

- Typisch: 150–300 ms
- Austritte kürzer als Eintritte, damit Nutzer nicht warten müssen
- Minimieren in eine Dock- oder Icon-Position: bis 350 ms, da die zurückgelegte Strecke
  sichtbar ist

## Unterschied zu Zoom In

- Zoom Out: die Skalierung fällt von 1 auf nahe 0, das Element verschwindet
- Zoom In: die Skalierung steigt von unter 1 auf 1, das Element erscheint
