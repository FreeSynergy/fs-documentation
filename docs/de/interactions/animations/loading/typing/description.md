# Typing

## Beschreibung

Typing ist der Schreibindikator: Drei Punkte (oder Balken) bewegen sich wellenförmig und zeigen, dass ein Chatpartner gerade schreibt. Der Indikator erscheint meist in einer kleinen Sprechblase über dem Eingabefeld. Er verschwindet, sobald die Nachricht gesendet ist oder das Schreiben endet.

## Verwendung

- Chats: der antwortende Partner schreibt gerade
- Assistent und KI-Antworten ("denkt nach")
- Kommentarspalten und Foren
- Gruppenchats, in denen mehrere Personen schreiben (mehrere Indikatoren)
- Wartezustand in Dialogen, wenn die Antwort verzögert ist

## Dauer

- Typisch: 1000–1400 ms pro Zyklus (eine Schleife, solange geschrieben wird)

## Unterschied zu Pulse und Glow

- Pulse: ein einzelnes Element schwillt als Ganzes an und schrumpft. Typing ist eine wandernde Welle aus mehreren kleinen Punkten.
- Glow: ein Statussignal als Leuchten um eine Kontur. Typing kündigt eine konkrete nächste Aktion an (eine eingehende Nachricht).
