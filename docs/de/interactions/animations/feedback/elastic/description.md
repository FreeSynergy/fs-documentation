# Elastic

## Beschreibung

Elastic führt eine Bewegung mit Überschwingen aus: Das Element schießt über seine Zielposition
hinaus und federt dann in sie zurück. Die Bewegung wirkt federnd und körperlich. Die Zielposition
und der Moment der Ankunft stehen von Anfang an fest.

## Verwendung

- ein Element in einen Ablagebereich einrasten lassen
- ein Schalterknopf, der über seine Endposition hinausschießt
- Menü- oder FAB-Elemente mit federndem Charakter öffnen
- ein Schieberegler, der in ein Raster einrastet
- Listenzeilen beim Umsortieren weich einpendeln lassen
- ein Button wächst federnd auf seine neue Größe

## Dauer

- Typisch: 400–800 ms (inklusive dem Abklingen der Schwingung)

## Unterschied zu Bounce In und Rubber Band

- Bounce In: ein Eintritt mit mehreren Bodenberührungen, während das Element erscheint; Elastic
  bewegt ein bereits sichtbares Element in eine feste Endposition.
- Rubber Band: der Inhalt folgt dem Finger über den Rand hinaus und federt erst nach dem Loslassen
  zurück; Elastic schießt ohne jede Geste von allein über das Ziel hinaus.
