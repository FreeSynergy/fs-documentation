# Shake

## Beschreibung

Shake lässt ein Element kurz waagerecht um seine Ruheposition rütteln und klingt dabei ab. Es ist
eine Rückmeldung der Oberfläche: Die Anwendung nutzt sie, um einen Fehler oder eine abgelehnte
Aktion anzuzeigen.

## Verwendung

- falsches Passwort oder falscher Code bei der Anmeldung
- ein Formularfeld wird als ungültig abgelehnt
- die Aktion ist an dieser Stelle nicht erlaubt
- Drag & Drop auf ein ungeeignetes Ziel
- ein Hinweis auf ein Pflichtfeld, das noch leer ist

## Dauer

- Typisch: 300–500 ms
- Standardwert: 400 ms

## Unterschied zu Wiggle

- Wiggle: eine leichte Drehung um wenige Grad, länger oder endlos, als Hinweis auf den
  Bearbeitungsmodus
- Shake: eine waagerechte Verschiebung mit größerer Amplitude, einmalig, als Fehlermeldung

## Unterschied zur Shake-Geste

- Animation Shake: Das Element bewegt sich von allein – die Anwendung gibt dem Nutzer
  Rückmeldung
- Shake-Geste (siehe [Shake-Geste](../../../gestures/device/shake/description.md)): Der Nutzer
  schüttelt das Gerät – eine Eingabe, auf die die Anwendung reagiert
- Kurz gesagt: Bei der Animation bewegt sich das Element als Ausgabe, bei der Geste schüttelt der
  Mensch das Gerät als Eingabe
