# Drag

## Beschreibung

Drag ist das Ziehen eines Elements auf den Bildschirm.

## Fingeranzahl

Von 1 bis zur Gerätegrenze (typisch 5–10 Finger). Mehrere gleichzeitige
Finger werden als eine Geste am Mittelpunkt aller Zeiger erkannt.

## Verwendung

- Elemente neu anordnen
- Scrollen
- Reorder in Listen

## Phasen

1. Touch starten
2. Element folgen
3. Drop an der neuen Position

## Distanz

- Typisch: > 10px
