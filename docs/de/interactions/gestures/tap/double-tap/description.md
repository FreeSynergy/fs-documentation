# Double Tap

## Beschreibung

Ein Double Tap ist zwei schnelle Berührungen in kurzer Folge.

## Fingeranzahl

Von 1 bis zur Gerätegrenze (typisch 5–10 Finger). Mehrere gleichzeitige
Finger werden als eine Geste am Mittelpunkt aller Zeiger erkannt.

## Verwendung

- Zoom ein/aus
- Öffnen von Elementen
- Markieren

## Dauer

- Zwischen den Taps: < 300ms

## Unterschied zu Tap

- Tap: Einzelne Berührung
- Double Tap: Zwei schnelle Berührungen
