# Double Tap - Aussehen

## Grundlayout

Ein Double Tap ist zwei schnelle Berührungen in kurzer Folge.

## Visuelles Feedback

```
┌─────────────────────────────────────────┐
│                                         │
│     [Klick] [Klick]                     │
│                                         │
└─────────────────────────────────────────┘
```

## Feedback-Optionen

| Option | Beschreibung |
|--------|--------------|
| **Ripple** | Welle bei jeder Berührung |
| **Scale** | Leichte Vergrößerung |
| **Color** | Farbe ändert sich |
| **None** | Kein Feedback |

## Dauer

- Zwischen den Taps: < 300ms

## Unterschied zu Tap

- Tap: Einzelne Berührung
- Double Tap: Zwei schnelle Berührungen
