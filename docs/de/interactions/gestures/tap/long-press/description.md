# Long Press

## Beschreibung

Ein Long Press ist eine lange Berührung auf den Bildschirm.

## Fingeranzahl

Von 1 bis zur Gerätegrenze (typisch 5–10 Finger). Mehrere gleichzeitige
Finger werden als eine Geste am Mittelpunkt aller Zeiger erkannt.

## Verwendung

- Kontextmenü öffnen
- Markierung
- Drag-Start

## Dauer

- Typisch: > 500ms

## Unterschied zu Tap

- Tap: Kurz (< 250ms)
- Long Press: Lang (> 500ms)
