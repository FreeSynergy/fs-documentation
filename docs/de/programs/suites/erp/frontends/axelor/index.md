# Axelor Dokumentation

## Übersicht

Axelor Open Suite (AGPL, Java) verbindet ERP (CRM, Sales, Purchasing, Stock, Manufacturing, Account, HR, Project) mit **Low-Code/BPM**: Masken, Modelle und Workflows werden im „App Builder“ modelliert; REST-Endpunkte entstehen automatisch.
