# Odoo - Menüpunkte

## App-Switcher (oben links)

| Bereich | Inhalt |
|---------|--------|
| Apps | installierbare Module (Community/Enterprise), Store |
| App-Kacheln | CRM · Verkäufe · Lager · Buchhaltung · Projekte · HR · Website · POS … |

## Innerhalb einer App

| Element | Inhalt |
|---------|--------|
| Favoritenstern / Ansichten | Kanban, Liste, Kalender, Gantt (Ent), Pivot/Graph (Ent) |
| „Neu“ / Import / Export | CSV/XLSX, Feld-Mapping |
| Aktionen (Liste) | Etiketten, Emails, Löschen, „Export selection“ |
| Einstellungen (App) | Konfiguration, Benutzerrechte je App |

## Entwicklermodus (⚙ → Activate developer mode)

- Feld-Tooltips, „View edit“/„Fields“ im Form-Header, benutzerdefinierte Aktionen
- Menü **Technisches → Benutzer & Unternehmen / Datenbankstruktur / Automatisierte Aktionen (ir.ql) / Webhooks (Enterprise)**

## Globales ⚙-Menü

- Meine Einstellungen, Benutzer, Unternehmen, Vorlagen, Automatisierungen, „Approvals“

## Menüs nach Rolle

Gruppenrechte (z.B. „Vertrieb / Benutzer / Manager“) bestimmen Menübaum; Portal-/Website-Nutzer sehen eigenes Kundenportal.
