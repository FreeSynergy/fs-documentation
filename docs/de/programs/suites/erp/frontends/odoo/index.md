# Odoo Dokumentation

## Übersicht

Odoo ist die offene Business-Suite (LGPL-Core + kommerzielle Enterprise-Apps): CRM, Vertrieb, Einkauf, Lager, Fertigung, Buchhaltung, Projekte, HR — als integrierte Module mit gemeinsamer ORM-Schicht. Python-basiert, Community Edition self-hosted, Odoo.sh/Cloud optional.
