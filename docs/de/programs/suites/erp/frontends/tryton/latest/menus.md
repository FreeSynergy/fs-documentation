# Tryton - Menüpunkte

## Modultrees (Client links)

| Modul | Inhalt |
|-------|--------|
| Accounting | Parteien (Kunde/Lieferant), Journals, Accounts, Invoices, Payments |
| Sale | Quotations, Sales, Sale Configuration |
| Purchase | Purchase Orders |
| Stock | Warehouses, Moves, Inventory, Production (Modul) |
| Project/Time | Projects, Timesheets, Working times |
| CRM | Leads, Activities (Modul) |
| Analytics | Timesheet-Analysen, Reports |

## Einstellungen (⚙)

| Bereich | Inhalt |
|---------|--------|
| Configuration (je Modul) | Charts of Accounts, Series/Sequenzen, Tax Rules, Shipment/Invoice-Freigaben |
|administration | Benutzer, Gruppen (record rules), Modelle/Felder lesen |

## Clients

| Client | Charakter |
|--------|-----------|
| Tryton Desktop (GTK) | voller Funktionsumfang, Offline-Pufferung |
| Web-Client (trytond-web) | lighter, im Server integriert |

## Menüs nach Rolle

Record Rules + Feldrechte; group-based (z.B. `account.group_account_invoice`).
