# Tryton Dokumentation

## Übersicht

Tryton (GPL, Python) ist das ruhige, modulare ERP für technische Anwender: Module für Buchhaltung, Vertrieb, Einkauf, Lager, Projekte, Zeiterfassung — mit starker Datenintegrität, Desktop-Client (GTK) und Web-Client. RPC-Schnittstelle schlank und stabil.
