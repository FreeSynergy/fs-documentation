# Dolibarr Dokumentation

## Übersicht

Dolibarr (GPL, PHP) ist das schlanke KMU-ERP/CRM: Dritte, Angebote/Bestellungen, Rechnungen, Lager, Projekte, Basis-Buchhaltung — einfach zu hosten (LAMP), stabiler Funktionskern, Extension-Markt. REST-API v3 mit API-Keys.
