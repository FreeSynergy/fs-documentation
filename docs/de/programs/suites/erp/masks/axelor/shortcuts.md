# Axelor - Tastatur-Shortcuts

## Übersicht

Axelor dokumentiert **keine Kurzbefehle**; Navigation über Menüs/Suche.

> Stand: Axelor Open Suite 8.x.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Tab`/`Enter` | Formularfelder |
| `Esc` | Popups/Pickers schließen |
| `Strg/Cmd+F` | Browser-Suche in Grids |

## Ausdrücklich nicht vorhanden

- keine Palette, keine Save-Taste

## Mac

`Cmd` bei Browser-Standards.
