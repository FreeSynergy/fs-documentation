# Sage - Tastatur-Shortcuts

## Übersicht

Kurzbefehle sind **produktspezifisch**; Windows-Produkte haben klassische Funktions-/Navigationstasten.

> Stand: 2026, je Version prüfen.

## Sage 50/100 (Windows) — typisch

| Shortcut | Funktion |
|----------|----------|
| `F2`/`F4` | Feldhilfen/Suchen (belegabhängig) |
| `Esc` | Eingabe abbrechen |
| `Tab`/`Shift+Tab` | Felder |
| `Strg+D` | Druckdialog (Maske) — Stand prüfen |
| Funktionsbaum | per Alt-Buchstabe (Menübuchstaben sichtbar) |

## Business Cloud (Web)

| Shortcut | Funktion |
|----------|----------|
| `Tab`/`Enter` | Belegformulare |
| `Strg/Cmd+F` | Listen (Browser) |

## Ausdrücklich nicht vorhanden

- einheitliche Sage-Palette über Produkte hinweg

## Mac

Cloud-Produkte: `Cmd`; Windows-Produkte: Windows-Tasten.
