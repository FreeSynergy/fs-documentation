# Decidim - Menüpunkte

## Teilnehmenden-Ansicht

| Element | Inhalt |
|---------|--------|
| Prozesse | Beteiligungsprozesse (mit Phasen: Diskussion→Priorisierung→Ergebnis) |
| Mein Profil | eigene Vorschläge, Supports, Benachrichtigungen, Verifizierung (Konten nach Wahl) |
| Komponenten (im Prozess) | Vorschläge · Debatten · Treffen · Budgets · Umfragen · Blogs · Seiten · Abstimmungen |

## Admin-Konsole (Organisationsadministrator:in)

| Bereich | Inhalt |
|---------|--------|
| Organisation | Nutzer/Rollen, Verifizierungsregeln (z.B. Altersnachweis), Sprache, Themen/Kategorien |
| Prozesse | anlegen, Phasen planen, Komponenten hinzufügen |
| Moderation | Meldungen, Unsichtbarmachen, Nutzer-Sperren (Moderator-Rolle) |
| Reports | Aktivitäten, Vorschlagsstatistik |

## Menüs nach Rolle

Teilnehmende · Moderator:in (Content) · Administrator:in (Struktur) · Entwickler/Technik (Instanz).
