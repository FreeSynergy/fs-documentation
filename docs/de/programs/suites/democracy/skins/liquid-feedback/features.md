# LiquidFeedback - Funktionen

## Hauptfunktionen

### Delegationsmaschine
- Stimme an vertraute Person delegierbar (Kettenbildung, jederzeit widerruflich)
- **Flüssige Abstimmung**: Delegation wandert mit Themenpräferenz (Issue-based)
- Counter-Initiativen: Gegenanträge rivalisieren (die mit Mehrheit gewinnt)

### deliberative Strukturen
- Argumentationsbäume Pro/Contra mit Ampel-Bewertung
- Phasen: Förderung (Support), Diskussion, Abstimmung mit Quorum (Ablehnungs-Quorum als Bremse)

### Organisation
- Räume je Gremium/Thema, Mitglieder-/Verifizierungsmodelle, innerorganisatorische Kandidaturen
- Export-Tabellen (PDF/HTML-Protokolle) für protokollpflichtige Organisationen

## Was LiquidFeedback NICHT kann

- **keine öffentliche API** (Integration nur Datenbank-/Exportwege)
- **keine offene Moderationssuite** wie Decidim (Meldewesen schlank)
- PHP-Altbestand: Modernisierung stockt (Community-Forks beobachten)
- keine anonyme Stimmabgabe (Konten + Verifizierung)
- UI nicht modern (Funktional vor Schönheit)
