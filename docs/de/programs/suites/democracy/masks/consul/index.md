# Consul Dokumentation

## Übersicht

Consul („Decide Madrid“-Software, Apache-2.0, Ruby on Rails) ist die Beteiligungsplattform für Kommunen: Vorschläge, Beteiligungsprozesse, **Bürgerhaushalte**, Abstimmungen/Polls, Debatten, Gesetzgebungs-Beteiligung (+ Mailing/Verifizierung). Betrieben von vielen Städten weltweit.

## Dateistruktur

- [menu.md](menu.md) - Bürgermenüs, Verwaltungs-/Moderationsbereiche
- [features.md](features.md) - Budgets, Polls mit Abstimmung, Was Consul NICHT kann
- [description.md](description.md) - Abgrenzung zu Decidim, pol.is
- [structure.md](structure.md) - Beteiligungsarten als Kacheln, Vorschlagslisten
- [shortcuts.md](shortcuts.md) - keine
- [api.md](api.md) - REST-API (public JSON), OAuth2, Webhooks (neuere Versionen)
