# Decidim Dokumentation

## Übersicht

Decidim (AGPL, Ruby on Rails) ist die Plattform für **partizipative Demokratie**: Prozesse (Bürgerhaushalt, Beteiligung, Planung), Vorschläge mit Kommentaren/Supports, Debatten, Treffen/Events, Abstimmungen, Budgets (partizipative Haushalte), Moderation — modular und mehrsprachig.Genutzt von hunderten Städten.

## Dateistruktur

- [menu.md](menu.md) - Teilnehmende-Ansicht, Admin-Konsole, Moderation
- [features.md](features.md) - Module (Proposals, Budgets, Meetings), Was Decidim NICHT kann
- [description.md](description.md) - Abgrenzung zu Consul, Liquid, pol.is
- [structure.md](structure.md) - Prozess → Komponenten, Karten-/Listenansichten
- [shortcuts.md](shortcuts.md) - keine
- [api.md](api.md) - GraphQL-API (öffentlich!), REST-Entwurfs-Reste, Webhooks (Modul)
