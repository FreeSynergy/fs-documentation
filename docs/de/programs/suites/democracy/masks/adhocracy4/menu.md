# Adhocracy4 - Menüpunkte

## Teilnehmenden-Navigation

| Element | Inhalt |
|---------|--------|
| Projekte | laufende/abgeschlossene Vorhaben (Kacheln mit Phase) |
| Projekt-Startseite | Beschreibung, Phasenübersicht, Karte (Geo-Bezug!) |
| Modul-Ansichten | Brainstorming (Ideenliste), Ideas Sichtung, Bewertungen, Umfragen, Kiezkasse (Budget-Module) |
| Beitrag | Detail mit Kommentaren, Rating (▲/▼), Moderationsvermerk |
| Mein Bereich | eigene Beiträge, Benachrichtigungen |

## Moderation/Verwaltung

| Bereich | Inhalt |
|---------|--------|
| Moderationsbereich | Beiträge prüfen,Markierung „weitergeleitet“ (Organisationshinweis), Löschen/Sperren |
| Projektverwaltung (betreibende Organisation) | Projekte anlegen, Phasen/Timing, Modulwahl, Karten-/Kiezkassen-Budgets |
| Plattform-Admin | Nutzer, Startseite, Moderatoren-Rollen |

## Menüs nach Rolle

Gast (lesen, je Projekt) · Teilnehmer (beitragen/bewerten) · Moderator · Projektbetreuer · Admin.
