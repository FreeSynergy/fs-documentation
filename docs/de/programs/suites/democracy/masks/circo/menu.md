# Circo - Menüpunkte

## Mitmach-Oberfläche (Teilnehmende)

| Element | Inhalt |
|---------|--------|
| Projektseite | Leitfrage, Phasen, Beitritt/Start |
| Beitragsflächen | Aussagen/Ideen schreiben, andere bewerten/kommentieren |
| Umfragen | Fragenblöcke (skaliert/Auswahl) |
| Ergebnis-Seiten | publizierte Berichte je Phase |

## Projektsteuerung (Veranstalter)

| Bereich | Inhalt |
|---------|--------|
| Projekt anlegen | Phasen (Frage→Sammlung→Bewertung→Ergebnis), Zeiträume |
| Teilnehmende | Einladungslisten, Zugangsregeln (Einladung nur/offen) |
| Moderation | Beiträge sichten/freischalten, zusammenfassen |
| Auswertung | Diagramme, Export (CSV/PDF-Berichte) |

## Menüs nach Rolle

Veranstalter · Moderation · Teilnehmende (teils eingeladene Kreise — Circo arbeitet oft **eingeladen**, nicht öffentlich).
