# LiquidFeedback - Menüpunkte

## Hauptnavigation

| Menü | Inhalt |
|------|--------|
| Räume (Areas) | Themenräume (öffentliche/geschlossene), Beitrittslogik |
| Initiativen | laufende Anträge:Status-Balken (Diskussion→Quorum→Entscheidung) |
| Mein Bereich | meine Initiativen, Delegationsverwaltung (an/über mich) |
| Delegierte | Personen mit Delegationen + Stimmhistorie |
| Abstimmungen | anstehende und abgeschlossene Abstimmungen je Raum |
| Kandidaten | innerparteilische Wahlen (Kandidat-Modul) |

## Initiative-Detail (Drei-Spalten)

- **Antrag** (Text mit Änderungsanträgen = „Alternative Initiativen“ als Konkurrenzvorschlag)
- **Argumentation** (Pro/Contra-Stränge mit Bewertungen)
- **Abstimmung** (Zustimmung/Neutral/Ablehnung + Delegiertenfluss)

## Administration

| Bereich | Inhalt |
|---------|--------|
| Policy/Quorums | Quorumformeln, Entscheidungsfenster, Fluss-Prinzipien |
| Nutzer/Räume | Konten, Rechte, Raumtypen |
| Verifizierung | Anmelde-/Prüfketten |

## Menüs nach Rolle

Mitglied · Raum-Admin (Committee) · Admin; Delegierte sind Rolle-on-top.
