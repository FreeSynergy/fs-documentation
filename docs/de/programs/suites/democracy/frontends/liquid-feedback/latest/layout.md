# LiquidFeedback - Struktur und UI/UX

## Initiative-Dreiteilung

```
┌──────────────────────────────────────────────────────────────────┐
│ Initiative LI-34 „Satzungsänderung §5“   Raum: Programm          │
│ Phase: [Diskussion] → Quorum 12/20 → Abstimmung (bis 12.11)      │
├────────────────┬─────────────────────┬───────────────────────────┤
│ Antrag (Text)  │ Argumente Pro/Contra│ Abstimmung                │
│ + Änderung…    │  ▸ Pro 14 (Ampel)   │ ✓ Zustimmung 22           │
│                │  ▸ Contra 8         │ ○ Neutral 4               │
│                │                     │ ✗ Ablehnung 3             │
│                │                     │ Delegations-Graph ▽       │
└────────────────┴─────────────────────┴───────────────────────────┘
```

## UI/UX

- textlastig, tabellarisch; Statusbalken zeigen Phase + Quorum-Fortschritt
- Delegationsverwaltung als Liste (wer für mich stimmt, wem ich gebe)

## Interaktionen

- Votum per Radiobutton; Delegation per Klick auf Person
- Argumentbewertung (Pro/Contra/Ampel) statt Likes

## Responsive Design

- Desktop-fokussiert; Mobil lesbar, aber nicht für Sitzungen gebaut

## Accessibility

- Standard-HTML-Tabellen; keine besonderen Vorkehrungen dokumentiert

## Performance

- Organisationsgröße (hunderte Aktivmitglieder) unkritisch
