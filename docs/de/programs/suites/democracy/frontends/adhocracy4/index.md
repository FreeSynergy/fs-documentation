# Adhocracy4 Dokumentation

## Übersicht

Adhocracy4 (AGPL, Python/Django) ist das Beteiligungs-Framework hinter vielen kommunalen Portalen (u.a. Berlin-Portal „mein.berlin.de“): Projekte mit Phasen (Brainstorming, Ideen-Sichtung, Bewertung, Umfrage, **Kiezkasse/partizipatives Budget**), Beiträge mit Kommentaren/Ratings, Moderation.
