# Consul Dokumentation

## Übersicht

Consul („Decide Madrid“-Software, Apache-2.0, Ruby on Rails) ist die Beteiligungsplattform für Kommunen: Vorschläge, Beteiligungsprozesse, **Bürgerhaushalte**, Abstimmungen/Polls, Debatten, Gesetzgebungs-Beteiligung (+ Mailing/Verifizierung). Betrieben von vielen Städten weltweit.

- [description.md](latest/description.md) - Abgrenzung zu Decidim, pol.is
