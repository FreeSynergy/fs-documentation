# Consul - Funktionen

## Hauptfunktionen

- **Vorschläge + Supports** (thematisch, geolokalisiert), Verlinkung mit Prozessen
- **Bürgerhaushalte**: Budget-Abschnitte, Projekte mit Unterstützung + Abstimmungsphase (Kopf-ab-Zählung pro Abschnitt)
- **Konsultationen/Polls**: Ja/Nein und Multiple-Choice, Kampagnen mit Zeitplan
- **Gesetzgebungsprozesse**: Artikel-Nummerierung mit Randkommentaren
- **Partizipative Panels** ( zufallsausgewählte Gruppen; Version prüfen), Debatte-Funktionen
- Verifizierungsstufen (z.B. Alter/Wohnort), Mehrsprachigkeit (ES-first, DE-Übersetzung vorhanden)

## Was Consul NICHT kann

- **kein delegiertes Votum** (Liquid-Modell: ❌)
- keine zertifizierte e-Voting-Kryptografie (Polls = Meinungs-/Beteiligungsumfragen; rechtssichere Wahlen: anderes Tool)
- Prozess-Phasen-Modell schwächer als Decidim (freier, aber weniger formstrenge)
- Admin-Oberfläche funktional (Rails-Alt-Look)
