# CS-Cart Multi-Vendor Dokumentation

## Übersicht

CS-Cart Multi-Vendor (kommerzielle Software, PHP) verwandelt einen Shop in einen **Marktplatz mit vielen Anbieter:innen**: Produkte, Lager, Versand, Zahlungs-Gateways, Anbieter-Provisionen, Admin-Konsolen. Klassischer E-Commerce-Ansatz (vs. Vermittlungs-Marktplätze wie Sharetribe).
