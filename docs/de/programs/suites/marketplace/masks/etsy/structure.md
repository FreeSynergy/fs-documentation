# Etsy - Struktur und UI/UX

## Layout

```
Listing: Galerie (links) · Kaufblock (rechts: Varianten, Menge,
         Notiz-Feld, Versand) · Shop-Info + Bewertungen darunter
Suche:   Filterleiste links (Material, Anlass, Preis, Standort)
Shop-Manager: Seitenmenü · Listings-Tabelle (Vorschau+Status) ·
         Orders mit Detail-Drawer (Nachrichten/Adressen)
```

## UI/UX

- heller, bildzentrierter Marktplatz-Look; Personalisierungs-Hinweise prominent
- mobile App für Einkaufen + „Sell Manager“ (Bestellungen mobil verwalten)

## Interaktionen

- Varianten-Picker, Notizfeld fürs Unikat; Warenkorb-Gutscheine
- Verkäufer: Massen-Statuswechsel (Aktiv/Ruhestand), Varianten-Vorlagen

## Responsive Design

- responsiv; App stark (Etsy setzt auf Mobil-Einkauf)

## Accessibility

- Standard-Web; Alternativtext-Pflicht für Listing-Bilder (Verkäuferpflicht)

## Performance

- Bild-CDN; Suchfilter client-/serverseitig verzahnt
