# Etsy - Menüpunkte

## Käuferseite

- Suche/Filter (Kategorie, Material, Anlass, Preis, Standort)
- Listing-Seite: Bilder/Videos, Varianten, Versand, Shop-Karte, Bewertungen
- „Lieblingslisten“, Nachrichten, Käufe/Downloads (digital)

## Verkäuferseite (Shop-Manager)

| Bereich | Inhalt |
|---------|--------|
| Listings | anlegen (Varianten, Tags, Materialien), Vorlagen |
| Bestellungen | Aufträge, Etiketten (Versand), Nachrichten |
| Finanzen | Gebühren, Auszahlung |
| Shop-Statistiken | Besuche, Conversion, SEO-Hinweise |
| Shop-Einstellungen | Banner/About, Ruhestands-Modus, Zahlungsarten |
| Apps/API | verbundene Drittanbieter-Apps (API-Nutzung läuft über registrierte Apps) |

## Developer (developers.etsy.com)

- App registrieren (API-Key + OAuth2 PKCE), Scopes (`email_r`, `listings_r`, `listings_w`, …), Zulassungsregeln

## Menüs nach Rolle

Gast · Käufer · Verkäufer · API-App (Scope-basiert).
