# Etsy Dokumentation

## Übersicht

Etsy (börsgelistet) ist der Kuratierungs-Marktplatz für **Handgemachtes, Vintage und Design** mit digitalen Produkten. Automatisierung über **Open API v3** (OAuth2, REST): Listings, Bestellungen, Shops, Bewertungen — mit Zulassungsprozess.
