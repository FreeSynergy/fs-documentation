# eBay - Struktur und UI/UX

## Layouts

```
Suche:  Ergebnisliste (Kacheln: Preisformat, Versand, Standort-Entfernung)
Listing: Bildergalerie · Preis/Auktions timer · Verkäufer-Karte ·
         Versand-/Rückgabeblöcke · Bewertungen
Seller Hub: Seitenmenü · Dashboards (Umsatz/Offene Bestellungen) ·
         Tabellen mit Massenaktionen
```

## UI/UX

- funktional, informationsdicht (Preisformate/Timers dominieren Listing)
- Mobile-App mit Leisten-Navigation (Suche/Verkaufen/Nachrichten)

## Interaktionen

- watch/best offer als Buttons; Verkäufer: Preisvorschläge annehmen/ablehnen
- Seller Hub: Checkbox-Massenaktionen (End-/Verlängerungs-/Preisänderung)

## Responsive Design

- Web responsiv; Apps voll funktional (In-App-Einkauf/Listing-Basis)

## Accessibility

- Standard-Web; Timer als Live-Element (screenreader-hinweise am Anbieter)

## Performance

- Suchergebnisse schnell; Seller-Hub-Tabellen mit Large-Account-Cursor
