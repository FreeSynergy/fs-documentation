# CS-Cart Multi-Vendor - Beschreibung

## Was das Programm macht

CS-Cart Multi-Vendor macht aus einem vollwertigen Shop einen Marktplatz: viele Händler verkaufen über eine gemeinsame storefront mit eigener Produktverwaltung; der Betreiber kassiert Provisionen und behält Katalog-/Rechtskontrolle.

## Vorteile

- **Shop-Reife** (Lager, Versand, Checkout) die reine Vermittlungs-Plattformen fehlt
- API für ERP-Anbindung vorhanden
- DE-Add-ons (Recht, Versand) verfügbar

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Sharetribe** | Dienstleistung/Vermietung im Fokus |
| **WooCommerce+WC Vendors** | WP-Bastelei, kostenlos startbar |
| **eBay** | Marktplatz mieten statt besitzen |

## Technische Details

- **Stack**: PHP/MySQL, selbst gehostet oder CS-Cart Cloud
- **Authentifizierung**: Backend-Logins; API: API-Schlüssel (Admin je Scope)
- **Lizenz**: kommerziell (Annual/Permanent)

## Für wen geeignet

- Händlerverbünde/Kaufleute, die **Ware** gemeinsam online verkaufen wollen
- FreeSynergy-Szenarien: Produkt-/Order-Sync mit ERP-Skins (Odoo/ERPNext-Adapter)
