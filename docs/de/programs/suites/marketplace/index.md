# Marktplätze

## Überblick

Marktplätze sind Plattformen, auf denen **verschiedene Personen und Organisationen** einander etwas anbieten, wie eBay oder Etsy, **nicht** wie ein eigener Shop. Die Kategorie umfasst sowohl Marktplatz-Software (mit der du selbst einen Marktplatz betreiben kannst) als auch bestehende Marktplätze, die du über eine API anbindest.

## Verfügbare Systeme

- **sharetribe** - quelloffene Marktplatz-Software (lokale Marktplätze und Dienstleistungen)
- **arcemall** - Baukasten für Marktplätze
- **cs-cart-multivendor** - Erweiterung für Multivendor-Betrieb im E-Commerce
- **ebay** - globaler C2C/B2C-Marktplatz
- **etsy** - Marktplatz für handgemachte Waren und Designprodukte
- **kleinanzeigen** - regionaler Kleinanzeigenmarkt (DE)
