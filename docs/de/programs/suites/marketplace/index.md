# Marktplätze

## Übersicht

Marktplätze sind Plattformen, auf denen **verschiedene Menschen und Organisationen** einander Angebote machen — wie bei eBay oder Etsy, **nicht** wie ein eigener Online-Shop. Die Kategorie umfasst sowohl Marktplatz-Software (mit der man selbst einen Marktplatz betreiben kann) als auch bestehende Marktplätze, die man per API anzapft.

## Verfügbare Systeme

- **sharetribe** - Open-Source-Marktplatz-Software (Lokal-/Dienstleistungs-Marktplätze)
- **arcemall** - Marktplatz-Baukasten
- **cs-cart-multivendor** - Multivendor-Erweiterung für E-Commerce
- **ebay** - globaler C2C/B2C-Marktplatz
- **etsy** - Marktplatz für Selbstgemachtes und Design
- **kleinanzeigen** - regionaler Kleinanzeigen-Marktplatz (DE)
