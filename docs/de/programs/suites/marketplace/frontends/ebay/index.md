# eBay Dokumentation

## Übersicht

eBay ist der globale Marktplatz für C2C/B2C mit Auktions- und Festpreisformaten. Für Automatisierung: **Sell API** (Listings/Bestellungen), **Browse API** (Katalog/Suche), **Findation/Finding-APIs**, OAuth2 (Application ID + User-Token). Regeln/Gebühren/Käuferschutz stammen vom Betreiber — Skins andocken, nicht ersetzen.
