# Sharetribe - Menüpunkte

## Marktplatz-UI (Endnutzer)

| Element | Inhalt |
|---------|--------|
| Suche | Stichwort, Kategorien, **Karte** (Umkreis), Preis-/Datumsfilter |
| Listing-Detail | Beschreibung, Preise/Varianten, Bewertungen, „Anfragen/Buchen“-Button |
| Profil | Angebote („Meine Listings“), Anfragen, Bewertungen, Auszahlungen |
| Nachrichten | Chat zwischen Anbieter und Kunde (pro Transaktion) |
| Konto | Zahlungen (Stripe-Account), Verifizierung, Benachrichtigungen |

## Betreiber-Konsole (Console)

| Bereich | Inhalt |
|---------|--------|
| Branding/Design | Farben, Logo, Landingpage |
| Marktplatz-Inhalt | Kategorien, Such-Texte, E-Mail-Texte |
| Transaktionen | Prozess-Typ (Pre-Booking/Purchase/Inquiry), Preisregeln |
| Analytics | Traffic, Transaktionen (neuere Versionen) |
| Entwickler | **API-Client anlegen**, Webhooks, Marketplace-API |

## Menüs nach Rolle

Unregistriert (suchen) · Nutzer (anfragen) · Anbieter (listen + Chat) · Admin (Console).
