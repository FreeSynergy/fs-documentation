# CS-Cart Multi-Vendor - Menüpunkte

## Admin-Center (Marktplatz-Betreiber)

| Bereich | Inhalt |
|---------|--------|
| Verkäufer | Händler anlegen/freischalten, Verträge/Provisionsschemas |
| Katalog | Kategorien, Attribute, Produkt-Freigabe-Workflows |
| Bestellungen | zentrale Order-Verwaltung, Split pro Händler |
| Finanzen | Payouts an Händler, Gebühren, Steuern |
| Add-ons | Add-ons Marketplace (Versand-/Zahlungs-Erweiterungen) |

## Händler-Dashboard

| Menü | Inhalt |
|------|--------|
| Produkte | anlegen (Varianten/Lager), Import (CSV) |
| Bestellungen | eigene Aufträge, Versandstatus |
| Finanzen | Umsatz, Auszahlungsbericht |
| Shop-Design | eigene Händler-Shopseite (Vendor Design-Tools) |

## Kunden-Frontend

Kategorien/Suche, Produktseiten mit „Verkauft von“-Anzeige, Warenkorb (multi-vendor-Split), Checkout mit Zahlungs-Gateways.

## Menüs nach Rolle

Admin · Händler (mit Rechten) · Kunde · Gast.
