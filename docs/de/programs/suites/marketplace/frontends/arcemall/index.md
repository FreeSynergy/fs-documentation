# Arcemall Dokumentation

## Übersicht

Arcemall ist eine **Low-Code-Plattform für eigene Marktplätze** (Open-Source-Ansatz): Marktplatz-Modelle (Produkte/Dienstleistungen, Buchungen, Zahlungen, Suche/Karte) werden mit Own-Code-Bausteinen und Templates gebaut. Jungeres Projekt mit API-Fokus.

> Dokumentationslage schmal: API-Einzelheiten nur so beschrieben, wie sie offiziell publiziert sind — übriges mit „Stand prüfen“.
