# Salesforce - Menüpunkte

## Navigation (Lightning)

| Element | Inhalt |
|---------|--------|
| App-Launcher (waffle) | Apps: Sales, Service, Marketing, eigene Custom-Apps |
| Tab-Leiste je App | Standard-Tabs: Accounts, Contacts, Leads, Opportunities, Cases, Reports, Campaigns, Dashboards, Quotes (planabhängig) |
| Globale Suche + **Action-Button** | „New…“ für alle sichtbaren Objekte |
| Chatter-Feed | Kollaborationsstrom |
| Setup (Zahnrad) | Administration |

## Objekt-Detailseite

- Header: Name, Aktionen (Bearbeiten, Follow, Call-Center, Quick Actions)
- Pfad-Balken (Stage-Track), Detail-Felder, **Related Lists** (Activities, Kontakte, Opportunities…)
- Related Lists unten; Links-Rechts-Sidebar (Wissensartikel, Aktivitäten, Apps) je nach Seitenlayout konfigurierbar

## Setup-Menü (Auswahl)

| Bereich | Inhalt |
|---------|--------|
| Users / Profiles / Permission Sets | Rechte-Modell |
| Object Manager | Standard-/Custom-Objects, Fields, Page Layouts, Record Types |
| Flow Builder | Automatisierung (bildlich), Approval Processes |
| Reports & Dashboards | Report-Typen, Analyse-Cloud (Extra) |
| Data Management | Import/Export (Data Loader), Duplikatregeln |
| Platform | Apex Classes, Process Builder (alt), Connect/REST-Setup, API-Nutzung |
| Integration | Connected Apps (OAuth), Identity, Single Sign-On |

## Menüs nach Lizenz/Rolle

Lizenzen (Sales/Service/Platform/…) + Profile/Permission Sets + Rollenhierarchie bestimmen Tabs und Datensichtbarkeit.
