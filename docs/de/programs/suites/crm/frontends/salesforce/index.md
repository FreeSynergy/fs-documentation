# Salesforce Dokumentation

## Übersicht

Salesforce ist die führende kommerzielle CRM-Plattform (SaaS): Leads, Accounts, Contacts, Opportunities und Dutzende Clouds (Service, Marketing, Commerce, Analytics) auf einem modellierbaren Datenkern (Standard- + Custom Objects). Skin-relevant: REST-/Tooling-API, Metadaten-API, Apex-Ökosystem.
