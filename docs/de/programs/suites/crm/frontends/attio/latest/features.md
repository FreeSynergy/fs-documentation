# Attio - Funktionen

| Funktion | Beleg |
|----------|-------|
| Anreicherung jedes Datensatzes automatisch | Hilfe ✅ |
| Standardobjekte Personen und Unternehmen; Geschäfte, Nutzende, Arbeitsbereiche lassen sich aktivieren | Hilfe ⚠️ (Quellen unterscheiden sich, welche standardmäßig aktiv sind) |
| Eigene Objekte, nur für Administrierende, in kostenpflichtigen Tarifen | Hilfe ⚠️ |
| E-Mail- und Kalender-Synchronisation | Hilfe ✅ |
| Ask Attio (KI), Workflows, eigene Agenten, Sequenzen, Gesprächsauswertung, Berichte und Prognosen | Hilfe ✅ (nur genannt) |
