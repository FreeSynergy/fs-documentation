# n8n - Tastatur-Shortcuts

## Übersicht

n8n dokumentiert Editor-Kurzbefehle (Übersicht: `?`-Icon im Editor).

> Stand: n8n 1.x.

## Editor

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Node-Palette öffnen |
| `Strg/Cmd+S` | Workflow speichern |
| `Strg/Cmd+Z` / `+Shift+Z` | Undo / Redo |
| `Strg/Cmd+C` / `+V` / `+D` | Node kopieren / einfügen / duplizieren |
| `Strg/Cmd+A` | alle Nodes auswählen |
| `Entf`/`Backspace` | Auswahl löschen |
| `Esc` | Auswahl/Dropdown aufheben |
| `Strg/Cmd+=` / `+-` | Zoom |
| `Strg+Mausrad` | Zoomen |
| `Leertaste` + Ziehen / mittlere Maustaste | Canvas verschieben |

## Ausdrücklich nicht vorhanden

- Shortcuts zum Ausführen (Buttons), kein Kommando-Palette-Äquivalent neben `Tab`
