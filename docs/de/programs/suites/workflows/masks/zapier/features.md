# Zapier - Funktionen

## Hauptfunktionen

- **Zaps**: Trigger→Aktionen (Multi-Step, Paths als Verzweigungen), Error-Replay, Versionierung pro Zap
- **Apps**: 8.000+ (Instant-Triggers, Polling, „Integrations“ mit Custom-APIs)
- **Zapier Platform**: eigene Apps (UI-Builder/CLI), Prefill-Webhooks (Formular-Auffüllen), Embed (Zaps im eigenen Produkt)
- **Zapier Interfaces/Tables/Forms/Maps/Drafts**: Mini-Apps & Datenhaltung ohne Frontend-Code
- **Enterprise**: SSO, Data retention, Zap-Governance, AI-Actions

## Was Zapier NICHT kann

- **kein Self-Hosting / Datenhaltung nur bei Zapier**
- **keine tiefen Daten-Transformationen** (Format-Steps einfach; Code nur via „Code by Zapier“ Python/JS, begrenzt)
- **Polling statt Push** bei vielen Triggers → Latenz + Task-Verbrauch
- **kein Scheduling feiner Intervalle** (Standard-Polling je Plan)
- Preise nach **Tasks** — hohe Volumina teuer
