# Make - Beschreibung

## Was das Programm macht

Make baut Automatisierungen als Szenario: Ein Trigger erzeugt Datensätze, Module verarbeiten sie sichtbar (Router, Iteratoren), Aktionen schreiben sie in Apps. Alles läuft in Make-Cloud-Rechenzentren, Abrechnung nach verbrauchten Operationen.

## Vorteile

- **visuellste Datenpfade** am Markt (Datensätze als Blasen), stark für verschachtelte Logik
- gutfähiger Free-Plan zum Lernen
- Custom-Apps per OpenAPI → firmeninterne Systeme andockbar

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Zapier** | simpler, mehr Apps, Preismodell Tasks; Make tiefer in Routen/Iteration |
| **n8n** | self-hostbar, Code-Nodes; Make reines SaaS |
| **Power Automate** | Microsoft-Welt (M365-Verzahnung); Make plattformneutral |

## Technische Details

- **Modell**: SaaS (Make.com, EU-/US-Regionen), Teams/Ordner
- **Auth**: Connections (OAuth2/Keys); API: Token/OAuth2-App (Developer-Abo)
- **Preise**: Free → Core/Pro/Teams/Enterprise (Operations-Kontingente)

## Für wen geeignet

- operative Teams mit verzweigungsreichen Prozessen (Lead-Routing, Synchronisation)
- FreeSynergy-Skins: Modul-Blasen-/Routen-Paradigma als Flow-Visualisierung
