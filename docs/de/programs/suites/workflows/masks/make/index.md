# Make Dokumentation

## Übersicht

Make (früher Integromat) ist die visuelle SaaS-Automatisierungsplattform: Szenarien aus Modulen (Trigger → Router/Iterator/Aggregator → Aktionen), 1.500+ Apps, visuelle Datenpfade mit Bubbles. Preismodell nach „Operations“. API zur Szenario-Verwaltung inklusive.

- [features.md](features.md) - Module, Router, Webhooks, Was Make NICHT kann
- [description.md](description.md) - Abgrenzung zu Zapier, n8n, Power Automate
