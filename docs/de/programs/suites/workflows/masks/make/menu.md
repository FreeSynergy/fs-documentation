# Make - Menüpunkte

## Szenario-Editor

| Element | Inhalt |
|---------|--------|
| Szenario-Liste (links) | Szenarien, Ordner, Templates |
| Canvas | Module als Blasen; Links (Trigger→Aktion); Routen (Router/Filter/Iterator) |
| Modalklick auf Modul | App-Modul-Konfiguration (Connection, Fields, „Instant preview“) |
| Run once / Start | Testlauf / Produktions-Scheduling |
| History | Ausführungsliste mit Modul-Daten (Blasen anklickbar) |

## Organisations-Menüs

| Bereich | Inhalt |
|---------|--------|
| Connections | App-Verbindungen (OAuth2/API-Keys) teilen |
| Data stores | Make-Tabellen (Records) |
| Folders/Teams | Zugriffsrechte, geteilte Ordner |
| Custom apps | „App Builder“/„App Editor“: eigene Module (OpenAPI-Import) |
| Webhooks | Custom-webhook-Endpunkte als Trigger |
| Pläne/Billing | Operations-Budget, Reserver |

## Menüs nach Rolle

Inhaber · Admin · Builder (Szenarien) · Viewer (History); Connections pro Organisation/Person.
