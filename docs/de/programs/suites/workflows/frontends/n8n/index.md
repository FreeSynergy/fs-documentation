# n8n Dokumentation

## Übersicht

n8n ist das quelloffene Workflow-Automatisierungswerkzeug (Node.js, „fair-code“): Nodes grafisch zu Workflows verdrahten, Hunderte Integrationen, eigene JS/Python-Code-Nodes, Webhooks als Trigger, Self-Hosting oder Cloud.
