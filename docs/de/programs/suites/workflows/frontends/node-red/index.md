# Node-RED Dokumentation

## Übersicht

Node-RED ist die Flow-basierte Programmier-Umgebung (Node.js, Apache-2.0) aus IBMs IoT-Schmiede: Knoten verdrahtet man per Drähten (Nachrichten fließen darüber), mit Dashboard, MQTT/OPC-UA-Support und tausenden Community-Paketen. Der Standard für Selbstbau-Automatisierung und Embedded-Anbindung.
