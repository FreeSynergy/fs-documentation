# Node-RED - Tastatur-Shortcuts

## Übersicht

Node-RED dokumentiert Editor-Kurzbefehle (Liste in der offiziellen Doku).

> Stand: Node-RED 4.x.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Strg/Cmd+Space` | Node-Suche (Palette) |
| `Strg/Cmd+Z` / `+Y` | Undo / Redo |
| `Strg/Cmd+C` / `+X` / `+V` | Kopieren / Ausschneiden / Einfügen |
| `Strg/Cmd+A` | alle Nodes des Tabs auswählen |
| `Entf` | Auswahl löschen |
| `Esc` | Auswahl aufheben / Node-Config schließen |
| `Strg+Mausrad` | zoomen |
| mittlere Maustaste / `Leertaste`+Ziehen | Canvas verschieben |
| `Tab` | Nodes in Auswahlreihenfolge (verbreitet, Stand prüfen) |

## Ausdrücklich nicht vorhanden

- Kein „Deploy“-Shortcut garantiert (Button); Shortcuts-Liste der Doku maßgeblich

## Mac

`Cmd` statt `Strg`.
