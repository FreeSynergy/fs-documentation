# Power Automate - Funktionen

- Arten von Cloud-Flows: automatisiert, sofort, geplant.
- Anlegen aus einer leeren Vorlage, aus einer Vorlage oder per Copilot-Eingabe (Copilot nur im neuen Designer; Administrierende können es abschalten).
- Konnektoren zu Cloud- und lokalen Diensten.
- Umgebungen mit rollenbasiertem Zugriff (Administration, Erstellen, nur Ausführen) und Filtern nach Typ.
- Navigationspunkte: Genehmigungen, Lösungen, Prozessanalyse, KI-Modelle, Aktivität von Desktop-Flows, Automatisierungszentrum, Tabellen, Verbindungen.
- Designs und Lizenzansicht in den Einstellungen.

## Offen

- Desktop-Flows, Fehlerbehandlung, Teilen von Flows.
