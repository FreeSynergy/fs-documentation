# Huginn - Funktionen

- Agenten für Web-Scraping, RSS, IMAP-Postfächer, Webhooks, MQTT; Ausgaben an Dienste wie Slack, Telegram, Twilio.
- Ereignisse, die über einen gerichteten Graphen zwischen Agenten weitergereicht werden.
- Logik in JavaScript, Liquid oder jq; komplexe Agenten lassen sich als externe Gems ergänzen.
- Weboberfläche: Agentenliste, Ereignisfluss-Diagramm, Durchsuchen der Ereignisse.
- Bereitstellung: Docker-Image, Compose, Dokku, Hosting-Plattformen, manuelle Installation.
