## Was das Programm macht

Die Nutzenden legen in einer Weboberfläche Agenten an, setzen ihre Optionen und verbinden sie. Ein Agent kann einen RSS-Feed lesen oder eine Seite auslesen; ein anderer kann eine Nachricht an einen Chatdienst senden, wenn ein Ereignis zutrifft. Die Daten bleiben auf dem eigenen Server der Nutzenden.
