# Windmill - Funktionen

- Sprachen: TypeScript (Bun), Python, Go, PHP, Bash, PowerShell, C#, SQL, Rust, Ruby, R, Java, Ansible oder jedes Docker-Image (einige nur im vollständigen Image).
- Auslöser: Zeitpläne, Webhooks, HTTP-Routen, Kafka, WebSockets, E-Mail.
- Flows: visueller Editor, YAML, Workflows als Code.
- Apps: vollständig in Code mit React/Svelte, dazu ein älterer Low-Code-Editor.
- Datentabellen, DuckDB; Pipelines (Alpha).
- KI-Sitzungen in einer Abspaltung des Arbeitsbereichs, mit Vorschau und Prüfung der Unterschiede.
- Rollen im Arbeitsbereich, Schutzregelwerke, Entwicklungs-Arbeitsbereiche, SSO/OAuth.
- CLI, VS-Code-Erweiterung, Git-Synchronisation, MCP-Server.
- Bereitstellung: Docker Compose oder Helm.
