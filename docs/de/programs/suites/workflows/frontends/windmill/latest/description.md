# Windmill - Beschreibung

## Was das Programm macht

Entwickelnde schreiben Skripte; Windmill leitet das Eingabeformular aus der Funktionssignatur ab, führt es auf einem Worker aus und bewahrt die Ergebnisse auf. Skripte werden danach zu Flows verknüpft oder über eine Benutzeroberfläche als App bereitgestellt.

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| n8n | Knotenfläche mit Integrationen im Vordergrund; Windmill beginnt beim Code. |
| Airflow, Prefect | Orchestrierung mit Schwerpunkt Python; Windmill ist mehrsprachig und enthält einen Oberflächenbaukasten. |

## Lizenz

Community-Edition unter AGPLv3; API-Clients und OpenAPI-Spezifikation unter Apache 2.0; der Betrieb als verwalteter Dienst erfordert eine kommerzielle Lizenz (README).

## Offen

- Aufteilung der Funktionen zwischen Community- und Enterprise-Edition.
