# Apple Kurzbefehle - APIs und Protokolle

URL-Schema, um Kurzbefehle zu öffnen, anzulegen und auszuführen oder die Galerie zu öffnen oder zu durchsuchen; x-callback-url, damit Ergebnisse an den Aufrufer zurückgehen. Apps stellen Aktionen für Kurzbefehle bereit (der Leitfaden verwendet den Begriff App Intents nicht). Offen: Authentifizierung, Grenzen.
