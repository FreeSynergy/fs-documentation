# Unraid Dokumentation

## Übersicht

Unraid ist ein proprietäres Server-Betriebssystem für NAS-, Medien- und Spielserver: Ein Array mischt unterschiedlich große Festplatten, ein dediziertes Paritätslaufwerk schützt die Daten, und Docker-Container sowie virtuelle Maschinen laufen direkt daneben. Verwaltet wird alles über die Web-UI auf Port 80/443; Community Applications liefert den App-Store, API-Keys und eine GraphQL-Schnittstelle die Automatisierung.
