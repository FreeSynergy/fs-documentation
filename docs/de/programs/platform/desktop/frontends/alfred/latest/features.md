## Powerpack-Funktionen (Anbieterseite)

- Workflows: Objekte verbinden, per Tastenkürzel, Schlüsselwort oder Fernbedienungs-Schaltfläche starten.
- Zwischenablage-Verlauf: Text, Bilder und Dateipfade, durchsuchbar.
- Textbausteine: Text, der aus einem kurzen Schlüsselwort eingefügt wird; kann aus dem Zwischenablage-Verlauf erstellt werden.
- Universelle Aktionen, einschließlich einer Vorschau von Markdown, Bildern, PDFs und Text.
- Dateiaktionen: Tastaturnavigation, Schnellansicht, E-Mail, Verschieben, Kopieren, im Finder zeigen.
- 1Password-Lesezeichen, Kontakte (anzeigen, E-Mail, anrufen), Ausführen von Befehlen im Terminal.
