# Alfred - Beschreibung

## Was das Programm macht

Ein Tastenkürzel öffnet ein Textfeld. Die Nutzenden starten Anwendungen, finden Dateien, suchen im Web, rechnen oder führen Workflows aus. Die kostenlose Version deckt die Grundlagen ab; Powerpack ergänzt Workflows, Zwischenablage-Verlauf, Textbausteine und mehr.

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| Raycast | Erweiterungen als Code mit gemeinsamer Oberfläche; Alfred stellt von Nutzenden gebaute Workflow-Graphen in den Mittelpunkt. |
