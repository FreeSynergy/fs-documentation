## Was das Programm macht

Raycast ersetzt mehrere kleine Werkzeuge durch ein Fenster, das per Tastenkürzel geöffnet wird. Die Nutzenden tippen; die Ergebnisse mischen installierte Anwendungen, Dateien, Befehle aus eingebauten Modulen und aus installierten Erweiterungen. Viele Ergebnisse bieten weitere Aktionen in einem Aktionsfeld.

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| Alfred | Ähnlicher Launcher unter macOS; Workflows entstehen aus verbundenen Objekten. Raycast-Erweiterungen sind Code mit einer gemeinsamen Komponentenbibliothek. |
| KDE Plasma | Eine ganze Desktop-Oberfläche; Raycast ist eine Schicht über einem bestehenden System. |
