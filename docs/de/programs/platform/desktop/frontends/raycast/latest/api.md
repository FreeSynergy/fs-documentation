# Raycast - APIs und Protokolle

## Erweiterungs-API

Erweiterungen nutzen React, Node.js und TypeScript mit dem npm-Ökosystem, eingebaute Oberflächenkomponenten, strenge Typisierung und Hot Reload. Sie werden im Store veröffentlicht oder mit einem Team geteilt.
