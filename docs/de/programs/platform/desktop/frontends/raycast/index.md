# Raycast

> Kategorie: [desktop](../../index.md)

## Was es ist

Raycast ist ein tastaturgesteuerter Launcher: eine Suchleiste, die Anwendungen und Dateien findet, Befehle und Erweiterungen ausführt und KI-Funktionen anbietet. Das Handbuch deckt Mac, Windows und iOS ab.

## Bemerkenswerte Ideen

- **Eine Palette für alles**: Apps, Dateien, Befehle, Erweiterungen, Zwischenablage-Verlauf, Textbausteine, Schnelllinks und Fensterverwaltung sind alle über dieselbe Suchleiste erreichbar.
- **Aktionsfeld**: jedes Ergebnis hat eine zweite Ebene an Aktionen, per Tastatur geöffnet.
- **Erweiterungen in einem Store**, geschrieben mit React und TypeScript, mit gemeinsamen Oberflächenkomponenten, damit sie gleich aussehen.
- **Skriptbefehle** und **Aliasse/Tastenkürzel** je Befehl.
- Hier aufgeführt wegen der Idee einer einzigen Befehlspalette für viele Funktionen (ADR 0013).
