# KDE Plasma (Aktivitäten) - APIs und Protokolle

Aktivitäten werden von einem Hintergrunddienst verwaltet (kactivitymanagerd, im KDE-Fehlerverfolgungssystem genannt). Ein Hook, um Benutzerskripte bei einem Wechsel der Aktivität auszuführen, wurde von Entwicklern in einem Fehlerbericht erwähnt. Offen: D-Bus-Schnittstelle, Skripting, Authentifizierung (lokal nicht relevant).
