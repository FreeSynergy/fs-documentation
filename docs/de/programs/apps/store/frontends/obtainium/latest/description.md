# Obtainium – Beschreibung

## Was das Programm tut

Der Nutzer fügt eine App über die Adresse ihrer Release-Seite hinzu. Obtainium liest die Seite, findet das neueste installierbare Paket, zeigt es als verfügbare Aktualisierung an und installiert es auf Wunsch.

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| F-Droid | Ein kuratierter, neu gebauter Katalog; Obtainium hat keinen eigenen Katalog und vertraut den Releases des Herausgebers. |
| Stores im Stil von Play | Kein Konto, keine zentrale Auflistung. |

## Hinweise

- Einige Quellen funktionieren, indem sie Webseiten auslesen, und können brechen, wenn sich eine Seite ändert (laut Projekt).
- Offen: unterstützte Android-Versionen, Details zur Zeitplanung der Update-Prüfung.
