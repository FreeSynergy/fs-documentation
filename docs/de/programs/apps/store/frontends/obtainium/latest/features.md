# Obtainium – Funktionen

## Hauptfunktionen

- Apps aus vielen Quellarten verfolgen (siehe Index); Versionsvergleich mit der installierten App.
- Benachrichtigungen über neue Releases; Installation von Aktualisierungen.
- Von der Community gesammelte App-Konfigurationen für gängige Apps.
- Neuere Einträge im Changelog (v1.7.x) nennen: Installationsart je App, Wahl des Installationsdienstes Shizuku oder Dhizuku, einen Abschnitt "Update Health", der möglicherweise veraltete App-Konfigurationen markiert, eine App deaktivieren ohne sie zu entfernen, Kategorien von der Update-Prüfung ausschließen, einen globalen Filter für Paketdateien, ein Muster zum Kürzen von Versionen, Entwurfs-Releases einbeziehen und F-Droid-Builds nach Gerätearchitektur filtern.
- Ein Prüfwerkzeug ("Verified Apps") ist eingebunden.

## Grenzen

- Nur Android.
- Nur so zuverlässig wie jede einzelne Quellseite.

## Offen

- Import und Export der App-Liste, Intervalle der Hintergrundprüfung: indirekt erwähnt, nicht bestätigt.
