# Flathub

> Kategorie: [store](../../index.md)

## Was es ist

Flathub ist der wichtigste App-Store für Flatpak unter Linux: ein Web-Katalog plus ein Repository, aus dem die Flatpak-Werkzeuge und Software-Center Apps in einer Sandbox installieren.

## Bemerkenswerte Ideen

- **Verifizierte Herausgeber**: Eine verifizierte App zeigt auf ihrer Seite ein Kennzeichen; der Entwickler weist die Kontrolle über die Domain oder das Code-Hosting-Konto hinter der App-ID nach.
- **Teilmengen für Nutzer**: Ein Client lässt sich auf verifizierte Apps, auf freie Software oder auf beides beschränken.
- **Stabile und Beta-Kanäle** als getrennte Remotes.
- Hier wegen der Idee aufgeführt, nachzuweisen, wer eine App veröffentlicht (ADR 0013).
