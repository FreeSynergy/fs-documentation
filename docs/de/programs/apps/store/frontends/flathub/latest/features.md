# Flathub – Funktionen

## Hauptfunktionen

- Katalog von Apps mit einer Seite je App.
- **Kennzeichen "Verifiziert"** auf den App-Seiten.
- Verifizierungsmethoden für Entwickler: eine Token-Datei unter dem well-known-Pfad der Domain aus der App-ID, ein DNS-TXT-Eintrag, oder Anmeldung mit einem Konto eines Code-Hosting-Dienstes für IDs unter GitHub, GitLab, GNOME oder KDE; manuelle Anfrage für offizielle Apps. Für die Dateimethode ist HTTPS nötig.
- Teilmengen für Clients: verifiziert, freie Software (floss), verifiziert und freie Software.
- Eigenes Beta-Remote für Alpha- und Beta-Builds; stabile und Beta-Zweige können nebeneinander bestehen.

## Grenzen

- Neu angelegte IDs unter den alten GitHub- und GitLab-Präfixen werden nicht angenommen.

## Offen

- Anzeige der Berechtigungen auf den App-Seiten, Download-Statistiken, Spendenlinks: nicht bestätigt.
