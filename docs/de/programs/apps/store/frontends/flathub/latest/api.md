# Flathub – APIs und Protokolle

## Repository

Flatpak-Remotes: das stabile Remote und ein Beta-Remote. Die Remote-Option `--subset` nimmt `verified`, `floss` oder `verified_floss`.

## Web-API

Es gibt eine versionierte API mit interaktiver Dokumentation (https://flathub.org/api/v2/docs). Offen: Endpunktliste, Authentifizierung, Rate Limits – die Seite war nicht lesbar.
