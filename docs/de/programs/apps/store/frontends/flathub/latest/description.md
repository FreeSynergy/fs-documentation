## Was das Programm tut

Flathub stellt Flatpak-Apps bereit. Nutzer finden sie auf der Website oder in einem Software-Center; das Kommandozeilenwerkzeug oder das Center installiert sie. Apps laufen in einer Sandbox mit angegebenen Berechtigungen.

## Verifizierung

Verifiziert heißt, dass der Entwickler die Kontrolle über die App-ID nachgewiesen hat. Meist heißt es auch, dass die App vom Entwickler oder von jemandem gepflegt wird, den er dazu berechtigt hat. Fremde Pakete ohne Mitwirkung des Entwicklers können nicht verifiziert werden. Erweiterungen und Laufzeiten können nicht verifiziert werden.
