# Mastodon - Menüpunkte

## Übersicht

Mastodon ist ein Open-Source-Mikroblogging-Netzwerk, das auf dem ActivityPub-Protokoll basiert. Es ist dezentral organisiert und besteht aus vielen unabhängigen Servern (Instanzen), die miteinander kommunizieren können.

## Hauptmenüpunkte

### 1. Menü (Links)
- **Funktion**: Navigation und Hauptfunktionen
- **Details**:
  - Home-Timeline öffnen
  - Local-Timeline öffnen
  - Federated-Timeline öffnen
  - Direktnachrichten öffnen
  - Benachrichtigungen öffnen

### 2. Toot-Menü (Mitte)
- **Funktion**: Toot-Kommunikation
- **Details**:
  - Neuer Toot
  - Toot bearbeiten/löschen
  - Toot zitieren
  - Toot markieren (Lesezeichen)
  - Toot teilen (Boost)
  - Medien hochladen

### 3. Timeline-Menü (Mitte)
- **Funktion**: Timeline-Verwaltung
- **Details**:
  - Home-Timeline
  - Local-Timeline
  - Federated-Timeline
  - Hashtag-Timeline
  - Timeline-Filter anwenden

### 4. Benutzer-Menü (Rechts)
- **Funktion**: Benutzer-Verwaltung
- **Details**:
  - Benutzer profile öffnen
  - Benutzer folgen/entfolgen
  - Benutzer blockieren/ignorieren
  - Benutzer melden

### 5. Benachrichtigungen-Menü (Rechts)
- **Funktion**: Benachrichtigungen verwalten
- **Details**:
  - Folgen-Benachrichtigungen
  - Toot-Benachrichtigungen
  - Erwähnungs-Benachrichtigungen
  - Direktnachrichten-Benachrichtigungen

### 6. Einstellungen
- **Funktion**: Einstellungen verwalten
- **Details**:
  - Allgemeine Einstellungen
  - Medieneinstellungen
  - Sicherheitseinstellungen
  - Theme-Einstellungen
  - Spracheinstellungen

### 7. Hilfefunktionen
- **Funktion**: Hilfefunktionen
- **Details**:
  - Hilfedokumentation
  -Über Mastodon
  - Problemlösung
