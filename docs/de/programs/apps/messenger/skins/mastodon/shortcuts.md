# Mastodon - Tastatur-Shortcuts

## Übersicht

Mastodon bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten.

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `F1` | Hilfe |
| `Ctrl+,` | Einstellungen |
| `Ctrl+Shift+M` | Neue Direktnachricht |
| `Ctrl+Shift+E` | Neue öffentliche Nachricht |

## Toot Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Enter` | Toot senden |
| `Shift+Enter` | Neue Zeile |
| `Ctrl+Enter` | Toot senden (in manchen Konfigurationen) |
| `Ctrl+K` | Toot suchen |
| `Ctrl+Shift+F` | Profil suchen |

## Navigation Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+K` | Toot suchen |
| `Ctrl+Shift+F` | Profil suchen |
| `Ctrl+.` | Nächster Toot |
| `Ctrl+,` | Vorheriger Toot |
| `Ctrl+Shift+N` | Nächster ungelesener Toot |
| `Ctrl+Shift+P` | Vorheriger ungelesener Toot |

## Bearbeiten Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Z` | Rückgängig |
| `Ctrl+Y` | Wiederholen |
| `Ctrl+X` | Ausschneiden |
| `Ctrl+C` | Kopieren |
| `Ctrl+V` | Einfügen |
| `Ctrl+A` | Alles auswählen |

## Markdown Shortcuts (in Toots)

| Shortcut | Funktion |
|----------|----------|
| `**Text**` | Fett |
| `*Text*` | Kursiv |
| `~Text~` | Durchstreichen |
| `` `Text` `` | Code |
| `> Text` | Zitat |

## Web-App Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Home` | Startseite |
| `Local` | Lokale Timeline |
| `Federated` | Verbundene Timeline |
| `Notifications` | Benachrichtigungen |
| `Messages` | Direktnachrichten |
| `Bookmarks` | Lesezeichen |

## Mac Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Cmd+K` | Toot suchen |
| `Cmd+Shift+F` | Profil suchen |
| `Cmd+E` | Einstellungen |
| `Cmd+Enter` | Toot senden |
| `Cmd+Shift+M` | Neue Direktnachricht |

## Tastatur-Navigation

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Nächster Fokus |
| `Shift+Tab` | Vorheriger Fokus |
| `Escape` | Fokus verlassen |
| `Enter` | Aktivieren |
