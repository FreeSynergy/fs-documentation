# Discord - Funktionen

## Übersicht

Discord ist ein proprietary Communication-Plattform und Chat-Client, der ursprünglich für Gaming-Communities entwickelt wurde, mittlerweile aber für alle Arten von Communities verwendet wird.

## Hauptfunktionen

### 1. Server-Management
- **Server erstellen**: Eigene Server erstellen
- **Server betreten**: Vorhandene Server betreten
- **Server-Einstellungen**: Server-Einstellungen konfigurieren
- **Server-Rollen**: Rollen für Mitglieder verwalten
- **Server-Berechtigungen**: Berechtigungen für Rollen konfigurieren

### 2. Channel-Management
- **Text-Kanäle**: Textbasierte Kanäle für Chat
- **Voice-Kanäle**: Voice-Kanäle für Audio-Chats
- **Kategorien**: Kanäle in Kategorien organisieren
- **Kanal-Einstellungen**: Kanal-Einstellungen konfigurieren
- **Kanal-Berechtigungen**: Berechtigungen für Kanäle konfigurieren

### 3. Chat-Kommunikation
- **Textchat**: Textbasierte Kommunikation in Kanälen
- **Direktnachrichten**: Direktnachrichten an einzelne Benutzer
- **Gruppennachrichten**: Gruppennachrichten an mehrere Benutzer
- **E2E-Verschlüsselung**: Keine E2E-Verschlüsselung (nur TLS)
- **Status**:Online/Abwesend/Busy/Offline
- **Lesebestätigungen**: Lesebestätigungen anzeigen

### 4. Voice- und Videoanrufe
- **Voice-Chats**: Audio-Chats in Voice-Kanälen
- **Video-Chats**: Video-Chats mit Kamera
- **Bildschirmfreigabe**: Bildschirmfreigabe für Streaming
- **Anruf-Tools**: Stummschaltung, Lautstärke steuern
- **Anruf-History**: Anrufverlauf anzeigen

### 5. Dateiübertragung
- **Dateianhänge**: Senden von Dateien beliebiger Größe
- **Drag & Drop**: Drag & Drop für Dateiübertragung
- **Dateivorschau**: Vorschau von Bildern, Videos, Dokumenten
- **GIFs**: GIFs in Nachrichten einbinden

### 6. Bots und Integrationen
- **Bots**: Umfangreiches Bot-System für Automatisierung
- **Webhooks**: Webhooks für externe Integrationen
- **OAuth2**: OAuth2-Integration für externe Dienste
- **Zufallsfunktionen**: Zufallsfunktionen für Unterhaltung
- **Integrationen-Manager**: Manager für externe Integrationen

### 7. Moderation
- **Mitglieder verwalten**: Mitglieder kicken, verbannen
- **Rollen verwalten**: Rollen erstellen und verwalten
- **Audit-Log**: Audit-Log für Server-Änderungen
- **Warnsystem**: Warnsystem für Mitglieder
- **Automod**: Automatische Moderation

### 8. Profil
- **Eigenes Profil**: Eigenes Profil verwalten
- **Benachrichtigungen**: Benachrichtigungen verwalten
- **Privacy-Einstellungen**: Privacy-Einstellungen konfigurieren
- **Authentifizierung**: Zwei-Faktor-Authentifizierung

## Was Discord NICHT kann

- Keine Native-Unterstützung für E-Mail (muss mit E-Mail-Client kombiniert werden)
- Keine Native-Unterstützung für IRC
- Keine Native-Unterstützung für Signal/WhatsApp
- Keine Native-Mastodon-Integration (nur über Webhooks)
- Keine Native-End-to-End-Verschlüsselung (nur TLS)

## Discord-Bots

### Beliebte Bots
- **MEE6**: Moderations-Bot und Musik-Bot
- **Dyno**: Moderations-Bot und Automatisierung
- **Music Bot**: Musik in Voice-Kanälen abspielen
- **Carl-bot**: Moderations-Bot und Auto-Moderation
- **Utility Bots**: Verschiedene Utility-Bots

## Discord Nitro (Premium)

### Funktionen von Discord Nitro
- **Höhere Dateigröße**: Dateien bis 100MB senden
- **HD-Videos**: HD-Videos senden
- **GIFs**: Eigene GIFs als Emoji nutzen
- **Server-Logo**: Eigenes Server-Logo
- **Animated Avatar**: Animierter Avatar
- **Streaming**: Höhere Streaming-Qualität
- **Larger Server**: Größere Server (bis zu 1 Million Mitglieder)
