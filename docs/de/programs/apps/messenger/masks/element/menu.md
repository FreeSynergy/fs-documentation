# Element - Menüpunkte

## Übersicht

Element ist ein Open-Source-Messenger für die Matrix-Protokoll-Community. Es ist eine vollständige Client-Implementierung des Matrix-Protokolls, das auf sichere, dezentrale Kommunikation ausgelegt ist.

## Hauptmenüpunkte

### 1. Einstellungen
- **Funktion**: Einstellungen verwalten
- **Details**:
  - Einstellungen öffnen
  - Allgemeine Einstellungen
  - Medieneinstellungen
  - Sicherheitseinstellungen
  - Theme-Einstellungen
  - Spracheinstellungen

### 2. Raum
- **Funktion**: Raum-bezogene Aktionen
- **Details**:
  - Raum betreten/verlassen
  - Raum-Einstellungen
  - Raum-Benachrichtigungen
  - Raum-Abos
  - Raum-Historie löschen

### 3. Mitglieder
- **Funktion**: Raummitglieder verwalten
- **Details**:
  - Mitglieder anzeigen
  - Mitglieder einladen
  - Mitglieder kicken
  - Mitglieder verbannen
  - Mitgliederrechte ändern

### 4. Suche
- **Funktion**: Nachrichten und Räume suchen
- **Details**:
  - Global Suche
  - Raum-Suche
  - Nachrichten-Suche
  - Filter anwenden

### 5. Datei
- **Funktion**: Datei-Operationen
- **Details**:
  - Dateien senden
  - Dateien herunterladen
  - Dateien öffnen
  - Dateien speichern

### 6. Hilfefunktionen
- **Funktion**: Hilfefunktionen
- **Details**:
  - Hilfedokumentation
  -Über Element
  -Über Matrix
  - Problemlösung
