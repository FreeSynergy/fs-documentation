# Discord - Tastatur-Shortcuts

## Übersicht

Discord bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten.

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `F1` | Hilfe |
| `Ctrl+Shift+A` | Anwesenheit ändern |
| `Ctrl+Shift+X` | Tastenkürzel öffnen |
| `Ctrl+Shift+M` | Audio-Anruf |
| `Ctrl+Shift+V` | Video-Anruf |
| `Ctrl+Shift+N` | Neuer Server |
| `Ctrl+Shift+K` | Server suchen |
| `Ctrl+K` | Kanal suchen |

## Chat Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Enter` | Nachricht senden |
| `Shift+Enter` | Neue Zeile |
| `Ctrl+Enter` | Nachricht senden (in manchen Konfigurationen) |
| `Ctrl+U` | Benutzer erwähnen |
| `Ctrl+Shift+U` | Emoji auswählen |
| `Ctrl+P` | Profil öffnen |
| `Ctrl+Shift+P` | Profil öffnen (andere) |

## Navigation Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+K` | Kanal suchen |
| `Ctrl+Shift+K` | Server suchen |
| `Ctrl+.` | Nächster Kanal |
| `Ctrl+,` | Vorheriger Kanal |
| `Ctrl+1` | Ersten Kanal |
| `Ctrl+2` | Zweiten Kanal |
| `Ctrl+3` | Dritten Kanal |
| `Ctrl+Tab` | Nächster Server |
| `Ctrl+Shift+Tab` | Vorheriger Server |

## Voice Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Shift+D` | Bildschirmfreigabe |
| `Ctrl+Shift+S` | Stummschaltung |
| `Ctrl+Shift+M` | Audio-Anruf |
| `Ctrl+Shift+V` | Video-Anruf |
| `Ctrl+Shift+K` | Kanal verlassen |

## Bearbeiten Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Z` | Rückgängig |
| `Ctrl+Y` | Wiederholen |
| `Ctrl+X` | Ausschneiden |
| `Ctrl+C` | Kopieren |
| `Ctrl+V` | Einfügen |
| `Ctrl+A` | Alles auswählen |

## Mac Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Cmd+K` | Kanal suchen |
| `Cmd+Shift+K` | Server suchen |
| `Cmd+E` | Einstellungen |
| `Cmd+Enter` | Nachricht senden |
| `Cmd+Shift+M` | Audio-Anruf |
| `Cmd+Shift+V` | Video-Anruf |

## Tastatur-Navigation

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Nächster Fokus |
| `Shift+Tab` | Vorheriger Fokus |
| `Escape` | Fokus verlassen |
| `Enter` | Aktivieren |
