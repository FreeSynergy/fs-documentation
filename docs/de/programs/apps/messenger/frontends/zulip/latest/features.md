# Zulip — Funktionen

- Kanäle mit Themen; das Thema wird beim Senden gewählt.
- Automatische Antwort in das offene Thema.
- Themen finden: linke Seitenleiste (aktuelle Themen), Posteingang (ungelesene Themen), Aktuelle Unterhaltungen.
- Inhalt in ein anderes Thema verschieben, ein Thema als erledigt markieren, ein Thema stummschalten (im Hilfe-Index genannt).
- Nutzung per E-Mail: einen Kanal per E-Mail anschreiben.
- Integrationen und Bots über die API-Dokumentation.
- Tastenkürzel, zum Beispiel zum nächsten ungelesenen Thema.

## Offen

Direktnachrichten, Suche, Anrufe, Berechtigungen, Aufbewahrung: nicht gelesen.
