# Apple Mail iOS 26 — UI-Zustände

✅ = gesehen · ⚠️ = erschlossen.

| Zustand | Auslöser | Nächste Zustände |
|-------|---------|-------------|
| Gerade aktualisiert / vor n Minuten aktualisiert | Hintergrund- oder manuelles Abrufen ✅ | Aktualisierung läuft ⚠️ |
| Kategorie-Filter aktiv | Chip antippen ✅ | andere Kategorie; alle ⚠️ |
| Zeile nach links geöffnet | nach links wischen ✅ | Aktion ausgeführt; geschlossen |
| Auswahlmodus | „Auswählen“ ✅ | Verschieben-Sheet ✅; Abbrechen |
| Mailbox-Bearbeitungsmodus | „Bearbeiten“ ✅ | Fertig ✅ |
| Mail markiert (Farbe) | Aktionsblatt ✅ | Markierung aufgehoben ✅ |
| Erinnere mich gesetzt | Aktionsblatt ✅ | Mail kehrt zur gewählten Zeit zurück ⚠️; aufgelistet in Mailbox „Erinnere mich“ ✅ |
| Später senden eingereiht | Verfassen mit späterer Zeit ⚠️ | gesendet; aufgelistet in Mailbox „Später senden“ ✅ |
| Nachverfolgen vorgeschlagen | gesendete Mail ohne Antwort ⚠️ | aufgelistet in Mailbox „Nachverfolgen“ ✅ |
| Benachrichtigen bei Thread | Langdruck-Menü ✅ | Benachrichtigungen für Antworten ⚠️; aus |
| Stummgeschalteter Thread | Langdruck-Menü ✅ | nicht mehr stummgeschaltet ⚠️; aufgelistet in „Stummgeschaltete Threads“ ✅ |
| VIP-Absender | Kontaktkarte ✅ | Stern in der Liste ✅; VIP-Mailbox ✅ |
| Suche läuft | in Suchkapsel tippen ✅ | Treffer (Top / weitere) ✅; Bereich gewechselt ✅ |
| Keine Mail ausgewählt (mac) | leere Auswahl ✅ | — (großer grauer Platzhaltertext) ✅ |
| Konto hinzufügen | Dialog mit Adressfeld, „Weiter“ deaktiviert bis zur Eingabe ✅ | Anmeldung beim Anbieter ⚠️ |
| Mailaktivität schützen an/aus | Einstellungen ✅ | — |

Rückgängig: Schütteln zum Rückgängigmachen / Rückgängig nach Löschen ⚠️ (nicht gesehen). Rückgängig für Senden existiert ⚠️ (seit iOS 16 bekannt, nicht gesehen).
