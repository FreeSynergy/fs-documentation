# FreeSynergy Simple 0.1 — Layout

## Lesebildschirm (Startbildschirm)
```
┌──────────────────────────────────────┐
│ ⚙ Einstellungen             ☰ Liste  │  obere Leiste: nur zwei Symbole
│                                      │
│  Absender · Zeit · 🔒 Verschl.-Status│
│  Betreff (Mail) / Raum (Chat)        │
│                                      │
│  Nachrichtentext, Vollbild           │
│  Anhänge eingebettet                 │
│                                      │
└──────────────────────────────────────┘
```

## Verfassen- / Antwortbildschirm
```
┌──────────────────────────────────────┐
│ 👤+ Empfänger hinzufügen  Empfänger… │
│                                      │
│  Text (einfacher Editor)             │
│                                      │
│  ↑ senden · ↓ abbrechen · ← Entwurf · → anhängen (Hinweise, blenden nach Nutzung aus)
└──────────────────────────────────────┘
```

## Listenbildschirm
Einfache Liste der Unterhaltungen (neueste zuerst, ungelesene markiert). Oben rechts: ✎ neue Nachricht (ersetzt
das Listensymbol). Tippen auf einen Eintrag → Lesebildschirm.

## Empfängerauswahl
```
┌──────────────────────────────────────┐
│ 🔍 Name, Nummer, Adresse eingeben …  │
│  ─ gefilterte Kontaktliste ─         │
│  Anna Berg       Matrix · Mail       │
│  …                                   │
└──────────────────────────────────────┘
```
Kein Treffer → Formular „Neuer Kontakt“ öffnet sich (siehe [Funktionen](features.md)).

## Einstellungen
Eine kurze Seite: Konten, Benachrichtigungen, Theme (hell/dunkel), Textgröße. Sonst nichts.
