# Telegram - Tastatur-Shortcuts

## Übersicht

Telegram bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten.

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `F1` | Hilfe |
| `Ctrl+,` | Einstellungen |
| `Ctrl+Shift+N` | Neuer Chat |
| `Ctrl+Shift+F` | Global Suche |

## Chat Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Enter` | Nachricht senden |
| `Shift+Enter` | Neue Zeile |
| `Ctrl+Enter` | Nachricht senden (in manchen Konfigurationen) |
| `Ctrl+K` | Chat suchen |
| `Ctrl+E` | Einstellungen |
| `Ctrl+M` | Audio-Anruf |
| `Ctrl+V` | Video-Anruf |
| `Ctrl+Shift+M` | Audio-Anruf (Alternative) |
| `Ctrl+Shift+V` | Video-Anruf (Alternative) |

## Navigation Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+K` | Chat suchen |
| `Ctrl+Shift+F` | Global Suche |
| `Ctrl+.` | Nächster Chat |
| `Ctrl+,` | Vorheriger Chat |
| `Ctrl+1` | Ersten Chat |
| `Ctrl+2` | Zweiten Chat |
| `Ctrl+3` | Dritten Chat |
| `Ctrl+Tab` | Nächster Chat |
| `Ctrl+Shift+Tab` | Vorheriger Chat |

## Bearbeiten Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Z` | Rückgängig |
| `Ctrl+Y` | Wiederholen |
| `Ctrl+X` | Ausschneiden |
| `Ctrl+C` | Kopieren |
| `Ctrl+V` | Einfügen |
| `Ctrl+A` | Alles auswählen |

## Mac Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Cmd+K` | Chat suchen |
| `Cmd+Shift+F` | Global Suche |
| `Cmd+E` | Einstellungen |
| `Cmd+Enter` | Nachricht senden |
| `Cmd+Shift+M` | Audio-Anruf |
| `Cmd+Shift+V` | Video-Anruf |

## Tastatur-Navigation

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Nächster Fokus |
| `Shift+Tab` | Vorheriger Fokus |
| `Escape` | Fokus verlassen |
| `Enter` | Aktivieren |
