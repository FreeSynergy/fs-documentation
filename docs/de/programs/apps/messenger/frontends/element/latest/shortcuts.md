# Element - Tastatur-Shortcuts

## Übersicht

Element bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten.

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `F1` | Hilfe |
| `Ctrl+,` | Einstellungen |
| `Ctrl+K` | Raum suchen |
| `Ctrl+Shift+F` | Global Suche |
| `Ctrl+E` | Einstellungen |

## Chat Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Enter` | Nachricht senden |
| `Shift+Enter` | Neue Zeile |
| `Ctrl+Enter` | Nachricht senden (in manchen Konfigurationen) |
| `Ctrl+P` | Raumpreferences |
| `Ctrl+U` | Benutzer erwähnen |
| `Ctrl+Shift+U` | Emoji auswählen |
| `Ctrl+Shift+M` | Audio-Anruf |
| `Ctrl+Shift+V` | Video-Anruf |

## Navigation Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+K` | Raum suchen |
| `Ctrl+Shift+F` | Global Suche |
| `Ctrl+Shift+R` | Nächster ungelesener Raum |
| `Ctrl+Shift+P` | Vorheriger ungelesener Raum |
| `Ctrl+.` | Nächster Raum |
| `Ctrl+,` | Vorheriger Raum |
| `Ctrl+1` | Ersten Raum |
| `Ctrl+2` | Zweiten Raum |
| `Ctrl+3` | Dritten Raum |

## Bearbeiten Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Z` | Rückgängig |
| `Ctrl+Y` | Wiederholen |
| `Ctrl+X` | Ausschneiden |
| `Ctrl+C` | Kopieren |
| `Ctrl+V` | Einfügen |
| `Ctrl+A` | Alles auswählen |

## Markdown Shortcuts (in Chat)

| Shortcut | Funktion |
|----------|----------|
| `**Text**` | Fett |
| `*Text*` | Kursiv |
| `~Text~` | Durchstreichen |
| `` `Text` `` | Code |
| `> Text` | Zitat |

## Mac Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Cmd+K` | Raum suchen |
| `Cmd+Shift+F` | Global Suche |
| `Cmd+E` | Einstellungen |
| `Cmd+Enter` | Nachricht senden |
| `Cmd+Shift+M` | Audio-Anruf |
| `Cmd+Shift+V` | Video-Anruf |

## Tastatur-Navigation

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Nächster Fokus |
| `Shift+Tab` | Vorheriger Fokus |
| `Escape` | Fokus verlassen |
| `Enter` | Aktivieren |
