# Element - Funktionen

## Übersicht

Element ist ein Open-Source-Messenger für die Matrix-Protokoll-Community. Es ist eine vollständige Client-Implementierung des Matrix-Protokolls, das auf sichere, dezentrale Kommunikation ausgelegt ist.

## Hauptfunktionen

### 1. Chat-Kommunikation
- **Einzelgespräche**: Direkte Nachrichten an einzelne Benutzer
- **Gruppenräume**: Chat-Räume mit mehreren Teilnehmern
- **E2E-Verschlüsselung**: End-to-End-Verschlüsselung für sichere Kommunikation
- **Status**:Online/Abwesend/Inaktiv
- **Lesebestätigungen**: Lesebestätigungen anzeigen
- **Synchronisation**: Synchronisation aller Geräte

### 2. Audio- und Videoanrufe
- **Einzelanrufe**: Audio- und Videoanrufe mit einem Teilnehmer
- **Gruppenanrufe**: Audio- und Videoanrufe mit mehreren Teilnehmern
- **Bildschirmfreigabe**: Bildschirmfreigabe während Anrufen
- **Anrufhistory**: Anrufverlauf anzeigen
- **Stummschaltung**: Mikrofon und Kamera steuern

### 3. Dateiübertragung
- **Dateianhänge**: Senden von Dateien beliebiger Größe
- **Drag & Drop**: Drag & Drop für Dateiübertragung
- **Dateivorschau**: Vorschau von Bildern, Videos, Dokumenten
- **Datei-Hosting**: Optional eigenes File-Hosting

### 4. Raumfunktionen
- **Raumdescription**: Beschreibung und Topic für Räume
- **Raumbild**: Benutzerdefiniertes Raumbild
- **Raum-Abos**: Räume abonnieren/pin
- **Raum-Benachrichtigungen**: Benachrichtigungen für Räume
- **Raum-Einladungen**: Einladungen an Benutzer senden
- **Raum-Berechtigungen**: Berechtigungen für Räume konfigurieren

### 5. Integrationen
- **Giphys**: GIFs in Nachrichten einbinden
- **Webhooks**: Webhooks für externe Integrationen
- **Bots**: Bot-Unterstützung für Automatisierung
- **Zufallsfunktionen**: Zufallsfunktionen für Unterhaltung
- **Integrationen-Manager**: Manager für externe Integrationen

### 6. Sicherheit
- **E2E-Verschlüsselung**: Standardmäßig aktiviert
- **Geräteverwaltung**: Verwalten aller Geräte
- **Sicherheitshinweise**: Sicherheitshinweise anzeigen
- **Authentifizierung**: Zwei-Faktor-Authentifizierung
- **Passwortschutz**: Passwortschutz für Konten

### 7. Navigation
- **Raum-Historie**: Verlauf in Räumen durchsuchen
- **Suche**: Suche in Räumen und global
- **Schnellauswahl**: Schnellauswahl von Räumen
- **Markierung**: Nachrichten markieren
- **Antworten**: Auf Nachrichten antworten

## Was Element NICHT kann

- Keine Native-Unterstützung für E-Mail (muss mit E-Mail-Client kombiniert werden)
- Keine Native-Unterstützung für IRC
- Keine Native-Unterstützung für Signal/WhatsApp
- Keine Native-Mastodon-Integration (nur über Webhooks)
- Keine Native-Office-Integration (wie Word/Excel)

## Erweiterungen und Bot-Funktionen

### Beliebte Bots
- **Giffy**: GIFs in Nachrichten einbinden
- **Polls**: Umfragen in Räumen erstellen
- **Music-Bots**: Musik in Räumen abspielen
- **Moderations-Bots**: Raummoderation
- **Integration-Bots**: Integration mit externen Diensten

### Beliebte Erweiterungen
- **Theme**: Benutzerdefinierte Themes
- **Emoji**: Erweiterte Emoji-Unterstützung
- **Markdown**: Markdown-Unterstützung für Formatierung
- **Code-Block**: Code-Block-Unterstützung
