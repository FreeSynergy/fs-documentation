# Element - Beschreibung

## Übersicht

Element ist ein Open-Source-Messenger für die Matrix-Protokoll-Community. Es ist eine vollständige Client-Implementierung des Matrix-Protokolls, das auf sichere, dezentrale Kommunikation ausgelegt ist. Element ist die offizielle Referenz-Implementierung des Matrix-Protokolls.

## Was Element macht

Element ist ein vollwertiger Chat- und Kommunikationsclient, der auf dem Matrix-Protokoll basiert. Er ermöglicht sichere, verschlüsselte Kommunikation in Gruppen und Einzelgesprächen, sowohl über öffentliche als auch private Server. Element unterstützt Text, Dateien, Sprach- und Videoanrufe.

## Vorteile

- **Open Source**: Kostenlos und quelloffen unter Apache-2.0-Lizenz
- **Matrix-Protokoll**: Offenes, dezentrales Protokoll
- **End-to-End-Verschlüsselung**: E2E-Verschlüsselung für sichere Kommunikation
- **Dezentralität**: Arbeitet mit beliebigen Matrix-Servern
- **Cross-Platform**: Funktioniert auf Web, Windows, macOS, Linux, iOS, Android
- **Federierung**: Server können miteinander kommunizieren
- **Integrationen**: Viele Integrationen mit externen Diensten
- **Forschungsprojekt**: Weiterentwicklung durch Matrix.org Foundation
- **Zertifiziert**: E2E-Verschlüsselung zertifiziert durch externen Sicherheitsexperten

## Abgrenzung zu anderen Systemen

### Element vs. Discord
- **Element** ist dezentral und Open Source, **Discord** ist zentral und proprietär
- **Element** hat E2E-Verschlüsselung standardmäßig, **Discord** nur in Privatnachrichten
- **Discord** hat native Voice/Video, **Element** hat es via VoIP-Protokoll
- **Element** ist für Privatnutzer und Communities, **Discord** für Community-Server

### Element vs. Telegram
- **Element** ist Open Source und dezentral, **Telegram** ist proprietär und zentral
- **Element** hat standardmäßig E2E-Verschlüsselung, **Telegram** nur in Secret Chats
- **Element** nutzt Matrix-Protokoll, **Telegram** proprietäres Protokoll
- **Telegram** hat mehr Features (Bots, Kanäle), **Element** hat mehr Privatsphäre

### Element vs. Mastodon
- **Element** ist für Chat und Gruppen, **Mastodon** ist für Mikroblogging
- **Element** hat E2E-Verschlüsselung, **Mastodon** hat keine E2E-Verschlüsselung
- **Element** ist dezentral über Server, **Mastodon** ist dezentral über Instanzen

## Technische Details

- **Platform**: Web, Windows, macOS, Linux, iOS, Android
- **Protokoll**: Matrix
- **Backend**: Eigenes Matrix-Protokoll
- **Verschlüsselung**: Olm/Ratchet für E2E-Verschlüsselung
- **Authentication**: OAuth2, OpenID Connect
- **Federierung**: Matrix-Federation-Protokoll
- **Programming Language**: TypeScript, React (Web), Kotlin (Android), Swift (iOS)
- **Hosting**: Eigenes Matrix-Server oder öffentliche Server

## Für wen ist Element geeignet?

- **Privatnutzer**: Für diejenigen, die Datenschutz wertschätzen
- **Communities**: Für diejenigen, die eigene Chat-Gruppen betreiben wollen
- **Unternehmen**: Für diejenigen, die selbst-hosted Kommunikation wollen
- **Open Source-Nutzer**: Für diejenigen, die quelloffene Software bevorzugen
- **Matrix-Nutzer**: Für diejenigen, die das Matrix-Protokoll nutzen wollen
