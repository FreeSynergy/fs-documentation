# Delta Chat — Funktionen

- Kontakte per QR-Code oder Einladungslink hinzufügen; kein öffentliches Verzeichnis.
- Chatmail-Relais (Standard, änderbar); ein klassisches E-Mail-Konto nur, wenn es ausschließlich mit Chatmail-Apps genutzt wird.
- Ende-zu-Ende-Verschlüsselung standardmäßig (OpenPGP-Teilmenge, Autocrypt, Secure-Join), auch für Anhänge; Fingerabdrücke werden unter „Encryption Info“ zum Vergleich angezeigt.
- Push-Benachrichtigungen, die weder Profildaten, IP-Adressen noch Inhalte offenlegen sollen.
- Kanäle: der Betreiber veröffentlicht, Abonnenten empfangen.
- Mehrere Geräte: zweites Gerät per QR-Code im selben Netzwerk, manuelle Sicherung als Ausweichlösung; mehrere Profile pro Gerät.
- webxdc: Apps in einer Sandbox (`.xdc`, Spiele, Umfragen, Zusammenarbeit) ohne Internetzugang.
- Audio- und Videoanrufe zwischen zwei Personen auf dem Desktop, Ubuntu Touch, iOS und Android 8+.
- Unabhängige Sicherheitsprüfungen; die neueste genannte ist rPGP aus 2024.
