# Superhuman Mail — Funktionen

- **Split Inbox**: Standard- und eigene Splits; aus einer ausgewählten Unterhaltung über die Befehlspalette angelegt („New Split Inbox“); Unterhaltungen können einem bestehenden Split hinzugefügt werden; Splits lassen sich aktivieren, deaktivieren und löschen; ein Split kann sich ausblenden, wenn er leer ist, und bleibt über die Befehlspalette erreichbar.
- **Befehlspalette** (Cmd+K, unter Windows Strg+K); Zwei-Finger-Tippen auf dem Mobilgerät.
- Anbieterseite: Automatische Entwürfe, automatische Labels, automatisches Archivieren, Freigabe der Verfügbarkeit.

## Offen

Später senden, Erinnerungen, Textbausteine, Lesestatus, Teamfunktionen: in Texten Dritter genannt, aber in keiner Anbieterquelle geprüft. Hier nicht beschrieben.
