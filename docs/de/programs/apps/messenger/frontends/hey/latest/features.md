# HEY — Funktionen

Aus der Funktionsseite des Anbieters:

- **Der Screener**: entscheidet, ob Absender, die zum ersten Mal schreiben, wieder schreiben dürfen.
- **Imbox**: fokussierter Posteingang für wichtige Post.
- **The Feed**: Newsletter an einem Ort, bereits geöffnet, neueste oben.
- **Paper Trail**: Belege und transaktionale Post, aus dem Weg, aber auffindbar.
- **Set Aside**, **Reply Later**: Stapel zum Nachschlagen und für spätere Antworten.
- **Bubble Up**: eine Mail für eine Weile wegschicken; sie kehrt oben in die Imbox zurück.
- **Clips**: Text wie Telefonnummern, Links oder Bestätigungsnummern speichern.
- **Collections**: mehrere Verläufe auf einer benannten Seite; Teilen mit einer Einladung über „HEY for Domains“.
- @hey.com-Adressen; „Send-as“ für externe Adressen über SMTP.
- Pflicht-Zwei-Faktor-Authentifizierung für zahlende Kunden.
- Die Seite erwähnt außerdem ein Kommandozeilenwerkzeug von HEY und Unterstützung für KI-Agenten.
