# Spark — Funktionen

Von der Anbieterseite:

- **Team Comments**: private, chatähnliche Kommentare an einem E-Mail-Verlauf.
- **Private Comments**: nur für Mitarbeitende sichtbar.
- **Shared Draft**: gemeinsames Schreiben einer Antwort in Echtzeit.
- **Shared Inbox**: Teamrollen unter einer Adresse.
- **Smart Inbox**: wichtige Post getrennt vom Rest.
- **Send Later**: Versand zeitlich planen.
- Plattformen: Windows, Android, Mac, iPhone, iPad, Apple Watch.
