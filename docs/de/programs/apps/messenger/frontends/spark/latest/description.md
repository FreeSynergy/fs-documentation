## Was das Programm macht

Spark zeigt die Post mehrerer Konten an einem Ort, trennt wichtige Post vom Rest und erlaubt einem Team, gemeinsam an Mails zu arbeiten: private Kommentare, gemeinsame Entwürfe, ein geteilter Posteingang mit Teamrollen.

## Abgrenzung

| Verglichen mit | Unterschied |
|----------------|-------------|
| Superhuman | Teamfunktionen rund um eine Mail stehen im Mittelpunkt. |
| Chatwoot, Zammad (Helpdesk) | Spark bleibt ein E-Mail-Client; Helpdesks ergänzen Tickets und Kanäle. |

## Für wen geeignet

Kleine Teams, die Post gemeinsam beantworten, ohne ein Ticketsystem.
