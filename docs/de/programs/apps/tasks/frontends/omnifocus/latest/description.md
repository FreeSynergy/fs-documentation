# OmniFocus – Beschreibung

## Was das Programm tut

OmniFocus hält eine Gliederung aus Ordnern, Projekten und Aktionen mit Tags, Markierungen, Zurückstellungs- und Fälligkeitsdaten. Perspektiven bestimmen, was sichtbar ist; Forecast zeigt datierte Aktionen neben Kalenderereignissen; Review hält Projekte aktuell.

## Für wen es passt

OmniFocus ist ein Aufgabenmanager für Mac, iPhone, iPad, Apple Watch und Vision Pro, dazu OmniFocus im Web, ausgelegt auf langfristige Projekte und die wöchentliche Überprüfung.
