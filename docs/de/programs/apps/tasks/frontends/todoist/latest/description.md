# Todoist – Beschreibung

## Was das Programm tut

Aufgaben liegen in Projekten (mit Unterprojekten und Abschnitten), tragen Labels, eine Priorität p1 bis p4, Daten und Bearbeiter. Ansichten wie Heute, Demnächst und gespeicherte Filter wählen Aufgaben über Projekte hinweg aus.

## Für wen es passt

Todoist ist ein plattformübergreifender Aufgabenmanager mit Projekten, Abschnitten, Labels, Prioritäten und Datumsangaben in natürlicher Sprache.
