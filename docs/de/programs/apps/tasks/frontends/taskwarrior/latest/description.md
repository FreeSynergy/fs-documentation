# Taskwarrior – Beschreibung

## Was das Programm tut

Taskwarrior speichert Aufgaben mit Projekt, Tags, Priorität, Fällig-, Geplant- und Wartedaten, Abhängigkeiten und Anmerkungen. Eine numerische Dringlichkeit verbindet diese und steuert den Standardbericht.

## Für wen es passt

Taskwarrior ist ein To-do-Manager für die Kommandozeile. Aktuelle stabile Version auf der Projektseite: 3.5.0.
