## Hauptfunktionen

- Dringlichkeits-Faktoren: nächster Tag, Fälligkeitsdatum (überfällig zählt mehr), Priorität (hoch/mittel/niedrig), Blockieren anderer Aufgaben, geplant, begonnen, Alter, Anmerkungen, Tags, Projekt; wartend und blockiert verringern sie.
- Standardwerte laut Dokumentation: nächster Tag 15.0, fällig 12.0, Blockieren 8.0, hohe Priorität 6.0, mittlere 3.9, niedrige 1.8, geplant 5.0, aktiv 4.0, Alter 2.0, Anmerkungen 1.0, Tags 1.0, Projekt 1.0, wartend -3.0, blockiert -5.0.
- Jeder Koeffizient ist einstellbar; 0 schaltet einen Faktor ab; einige lassen sich je Projekt setzen.
- Anzahl der Tags und Anmerkungen skaliert ihren Faktor (0,8 für einen, 0,9 für zwei, 1,0 für mehr).
- Abhängigkeiten, Wiederholung, Anmerkungen: in der Dringlichkeitsdokumentation genannt; Details offen.
