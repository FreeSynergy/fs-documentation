# Things 3 – API

In den Quellen wurde keine öffentliche REST-API gefunden. Ein dokumentiertes URL-Schema (add, add-project, show, Suchbefehle, Hinzufügen per JSON) existiert; Integrationen für Kurzbefehle und Siri gibt es. Offen: Authentifizierung und Rate Limits gelten für ein lokales URL-Schema nicht; für Things Cloud ist in den gelesenen Quellen keine öffentliche API dokumentiert.
