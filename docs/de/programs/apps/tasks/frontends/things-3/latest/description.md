# Things 3 – Beschreibung

## Was das Programm tut

Things 3 ordnet Arbeit in Bereiche (langfristige Verantwortungen), Projekte (abgeschlossene Ziele mit Überschriften) und lose Aufgaben. Ein Tag wird geplant, indem Einträge nach Heute, Heute Abend oder Irgendwann verschoben werden; wiederkehrende und datierte Einträge erscheinen unter Demnächst.

## Für wen es passt

Things 3 ist eine persönliche To-do-App für Mac, iPhone, iPad, Apple Watch und Vision Pro, aufgebaut um eine kleine Auswahl fester Listen und einen ruhigen, schnellen Erfassungsablauf.
