## Was das Programm tut

Linear ordnet Issues pro Team nach Workflow-Status, Projekten, Cycles, Labels, eigenen Ansichten und Initiativen, dazu einen Posteingang für Benachrichtigungen und Auswertungen für Analysen.

## Für wen es passt

Linear ist ein Issue-Tracker für Teams, auf Tempo gebaut: per Tastatur bedienbar, mit Cycles (zeitlich begrenzten Iterationen), Projekten, Initiativen und einem Triage-Eingang.
