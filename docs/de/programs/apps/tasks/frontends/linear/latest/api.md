# Linear – API

GraphQL-API, die alle Objekte abdeckt; Änderungen sind in Echtzeit sichtbar. API-Schlüssel (persönlich oder für den Arbeitsbereich, mit Berechtigungen wie read, write, admin, Issues anlegen, Kommentare anlegen, optional auf Teams beschränkt) und OAuth-Anwendungen. Webhooks für Issues, Kommentare, Anhänge, Dokumente, Reaktionen, Projekte, Projekt-Updates, Cycles, Labels, Benutzer und SLAs; die Nutzlast enthält das Objekt und die vorherigen Werte; Admin-Berechtigung nötig. Rate Limits: offen (auf der Seite nicht angegeben).
