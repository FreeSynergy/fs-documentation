# Exist.io latest — API

Entwicklerdokumentation unter developer.exist.io. Die Willkommensseite nennt, dass nur Benutzerkonten auf die API zugreifen können und dass Benutzer Daten in Attribute schreiben können.

| Bereich | Inhalt |
|---------|--------|
| Authentifizierung | Token-Authentifizierung und OAuth2 (eigene Referenzseiten) |
| Lesen | Attribute, Zusammenhänge, Erkenntnisse, Mittelwerte, Benutzer |
| Schreiben | Eigentümerschaft von Attributen, Anlegen von Attributen, Aktualisieren von Werten |

Endpunkt-Pfade, Anfragebeispiele, Rate Limits: offen (Referenzseiten nicht gelesen).
