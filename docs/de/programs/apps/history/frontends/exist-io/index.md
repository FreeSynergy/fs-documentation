# Exist.io

> Kategorie: [history](../../index.md) · Typ: persönliche Auswertung · Anbieter: Hello Code (Melbourne, Australien) · Lizenz: proprietär

## Was es ist
Exist ist ein Dienst zur Selbstbeobachtung, der Daten aus anderen Apps und Geräten sammelt, manuelle Einträge wie Stimmung ergänzt und nach Zusammenhängen zwischen ihnen sucht.

## Bemerkenswerte Ideen
- Zusammenhänge zwischen unabhängigen Quellen (Schlaf, Schritte, Stimmung, Wetter, Arbeit). Warum: ein Verlauf, der auf "warum" antwortet, nicht nur auf "was".
- Eigene Tags mit mehreren Werttypen (Menge, Dauer, Skala 1–9, Prozent, Uhrzeit). Warum: ein kleines Modell für selbst erfasste Daten.
- Wochenzusammenfassung und tägliche Erkenntnisse. Warum: History könnte einen Digest im gleichen Sinn bieten.
- Eine öffentliche API, über die Nutzer auch Attribute schreiben können. Warum: der Dienst ist ein Knotenpunkt für Daten von außen.
