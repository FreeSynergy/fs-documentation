# ActivityWatch latest — Funktionen

## Hauptfunktionen
- Offizielle Watcher: afk, window, web.
- Buckets und Ereignisse; Heartbeats verschmelzen gleiche aufeinanderfolgende Ereignisse innerhalb einer bestimmten Zeitlücke.
- Abfragesprache über Zeiträume.
- Weboberfläche, Tray-Symbol, Pausieren, Filtern.
- Kategorien: anlegen, bearbeiten, Regeln (reguläre Ausdrücke).
- Export und Import.

## Was es NICHT tut
- Fenster-Watcher: keine Wayland-Unterstützung (nur X11, laut Dokumentation).
- Synchronisation zwischen Geräten: nur ein alter Prototyp ist aufgeführt.
- Mobile Apps: offen.
