# Zammad Dokumentation

## Übersicht

Zammad ist ein moderner, quelloffener Helpdesk: Tickets aus E-Mail, Web-Formular, Chat, Telefon und Telegram laufen in einer Oberfläche zusammen, mit SLAs, Textbausteinen, Wissensdatenbank und einer vollwertigen REST-API. Stack: Ruby on Rails + Elasticsearch (Suchindex), Frontend Vue.

## Dateistruktur

- [menu.md](menu.md) - Globale Navigation, Admin-/Manager-Menüs, Ticketaktionen
- [features.md](features.md) - Kanäle, SLA, Wissensdatenbank, Was Zammad NICHT kann
- [description.md](description.md) - Beschreibung und Abgrenzung zu osTicket, GLPI und Request Tracker
- [structure.md](structure.md) - Drei-Spalten-Ticketmaske, Massendialoge, Themes
- [shortcuts.md](shortcuts.md) - dokumentierte Zammad-Kurzbefehle (inkl. `Ctrl+Shift+K` Palette)
- [api.md](api.md) - REST /api/v1, Token/OAuth2, Webhooks, Trigger
