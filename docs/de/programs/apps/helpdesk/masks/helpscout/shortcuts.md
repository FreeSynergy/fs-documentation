# Help Scout - Tastatur-Shortcuts

## Übersicht

Help Scout dokumentiert eine kleine Set an Mail-Curzbefehlen.

> Stand: Help Scout App (2026).

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `/` | Suche fokussieren |
| `J` / `K` | nächste/vorherige Conversation |
| `R` | Antworten |
| `F` | Weiterleiten |
| `N` | interne Notiz |
| `S` | Snooze |
| `E` | als gelöst markieren („Resolve“) |
| `A` | zuweisen |
| `Shift+A` | sich selbst zuweisen |
| `Ctrl/Cmd+Enter` | senden |
| `Esc` | Editor verwerfen |
| `?` | Shortcuts-Overlay |

## Ausdrücklich nicht vorhanden

- Ticketnummern-Sprung, Makro-Tasten

## Mac

`Cmd` statt `Ctrl`, Einzelbuchstaben identisch.
