# Help Scout - Menüpunkte

## Hauptnavigation

| Menü | Inhalt |
|------|--------|
| Conversations | Postfach-Ansicht je Mailbox (Ordner: Needs to respond, Active, Everyone, Closed) |
| Reports | Antwortzeiten, Volume, Agents |
| Docs / Knowledge Base | öffentliche und private Artikel (Help Center + „Guides“) |
| Customers | Personenprofil: Historie, Fields, Tags |
| Settings | Mailboxen, Users/Teams, Auto-signature, Saved Replies, Rules, Beacons, Integrations, API |

## Conversation-Ansicht

- Aktionen: **Reply / Forward / Note**, Status (Active/Pending/Inactive), Assignee, Tags, „Delete spam“
- Rechts: Person-Karte (Custom Fields, vorherige Conversations), Snippets

## Automationen (Settings → Rules)

- Rules pro Mailbox: Case-Handling (Tags, Zuweisung, Auto-reply „Out of office“, Snooze, Assign to first responder)
- Workflows: Chat/Escalations (planabhängig)

## Menüs nach Rolle

| Rolle | Sicht |
|-------|-------|
| Admin | Settings voll |
| Agent (Full) | Conversations + Antworten |
| Restricted/Light | zugewiesene Mailboxes nur lesen/antworten |
| Kunde | nur eigene Beacon-Formulare/Docs |
