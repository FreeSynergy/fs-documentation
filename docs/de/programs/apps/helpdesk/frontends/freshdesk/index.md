# Freshdesk Dokumentation

## Übersicht

Freshdesk (Freshworks) ist ein SaaS-Helpdesk mit Tickets, Knowledge Base, SLAs, Omnichannel-E-Mail/Telefon/Chat und Freddy-KI. API REST (JSON), Webhooks und Marketplace-Apps; Self-Service-Portal inklusive.
