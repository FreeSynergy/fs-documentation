# Chatwoot – Beschreibung

## Was das Programm macht
Support-Teams antworten Kunden aus einem Posteingang, über welchen Kanal der Kunde auch schreibt. Gespräche erhalten Labels, Prioritäten, Zuweisung und Notizen; Kunden haben Profile mit Verlauf.

## Vorteile
- Viele Kanäle an einem Ort, einschließlich eines Website-Widgets.
- Teams, Zuweisungsregeln (Round-Robin und andere), Kapazitätsgrenzen pro Agent, Geschäftszeiten, SLAs.
- Berichte und ein Hilfecenter in mehreren Sprachen.

## Abgrenzung
| System | Unterschied |
|--------|-------------|
| Zammad | Ticketzentriert; Chatwoot ist gesprächszentriert und stellt Live-Chat in den Vordergrund. |
| Help Scout | E-Mail-zentrierter gemeinsamer Posteingang; Chatwoot startet bei Chat und Messengern. |

## Technische Details
Backend Ruby on Rails, Frontend Vue.js (Repository-Themen ✅); Docker-Bereitstellung; MIT-Lizenz (Fußzeile des README). Ein KI-Assistent (Captain) ist guthabenbasiert.
