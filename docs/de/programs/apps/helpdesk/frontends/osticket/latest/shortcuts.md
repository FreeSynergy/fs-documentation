# osTicket - Tastatur-Shortcuts

## Übersicht

osTicket hat **keine dokumentierten Kurzbefehle**. Bedienung über Klicks und Formular-Standards.

> Stand: osTicket 1.17/1.18.

## Was funktioniert

| Shortcut | Funktion |
|----------|----------|
| `Tab` / `Shift+Tab` | Formularfelder |
| `Enter` | Dialoge bestätigen (im Editor: neue Zeile) |
| `Esc` | Dialoge schließen |
| `Strg/Cmd+Enter` | (nicht dokumentiert — Senden bleibt ein Button) |
| `Strg+F` | Browser-Suche auf der Ticketseite |

## Ausdrücklich nicht vorhanden

- keine Palette, keine Ein-Tasten-Aktionen
- keine Shortcuts für Statuswechsel (Aktionenmenü)

## Mac

`Cmd` ersetzt `Strg` bei Browser-Standards.
