# Zammad Dokumentation

> Kategorie: [helpdesk](../../index.md)

## Übersicht

Zammad ist ein moderner, quelloffener Helpdesk: Tickets aus E-Mail, Web-Formular, Chat, Telefon und Telegram laufen in einer Oberfläche zusammen, mit SLAs, Textbausteinen, Wissensdatenbank und einer vollwertigen REST-API. Stack: Ruby on Rails + Elasticsearch (Suchindex), Frontend Vue.

## Bemerkenswerte Ideen

_Zu tun: Was kann dieses Programm, das andere nicht können? Warum ist es hier dokumentiert (ADR 0013)?_
