# Helodesk Dokumentation

> Kategorie: [helpdesk](../../index.md)

## Übersicht

Helodesk ist eine französische SaaS-Kundenservice-Suite (Kontaktcenter): Telefonie/Softphone, E-Mail, Chat, SMS und Callback in einer Oberfläche, dazu Cases (Tickets), Wissensdatenbank, IVR und Reporting. API REST mit Token-Auth und Webhooks. Für FreeSynergy ist Helodesk der Skin-Fall „Callcenter + Tickets aus einer Oberfläche“.

## Bemerkenswerte Ideen

_Zu tun: Was kann dieses Programm, das andere nicht können? Warum ist es hier dokumentiert (ADR 0013)?_
