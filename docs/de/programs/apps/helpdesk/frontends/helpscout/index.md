# Help Scout Dokumentation

> Kategorie: [helpdesk](../../index.md)

## Übersicht

Help Scout ist Support als gemeinsames Postfach: Kunden schreiben an eine E-Mail-Adresse („Conversations“), das Team antwortet wie aus einer persönlichen Mail — ohne Ticketnummern-Gefühl. Dazu Beacon-Widget, Knowledge-Base-Docs, Light-CRM-Felder und REST-API.

## Bemerkenswerte Ideen

_Zu tun: Was kann dieses Programm, das andere nicht können? Warum ist es hier dokumentiert (ADR 0013)?_
