# Zammad - Menüpunkte

## Globale Navigation (linker Rand, Symbole)

| Symbol/Menü | Beschreibung |
|-------------|--------------|
| Dashboard | personalisierte Kacheln (Tickets je Status, SLA-Ticker) |
| Tickets | gefilterte Ticketlisten (eigene, offene, geteilte) |
| Kunden & Organisationen | CRM-artige Kundenprofile, Historie, Verknüpfungen |
| Produkte | (optional) Produkt-/Vertragsverwaltung |
| Kalendare | Servicetermine/Urlaubszeiten für SLA-Berechnung |
| Knowledge Base | Artikel-Editor und -Publikation |
| Reports | vordefinierte und eigene Auswertungen |
| Online Chat | Chat-Transkripte |

## Plus-Menü (oben rechts)

- Neues Ticket, Neue Aufgabe, Neue Kunde, Neuer Chat

## Benutzermenü (Avatar)

Profil, Abwesenheit, Benachrichtigungen, Theme, Language, Admin-Bereich betreten (bei Recht)

## Admin-Menüs (⚙)

| Menü | Inhalt |
|------|--------|
| Kanäle | E-Mail (fetch/push), Web-Formular, Telefon (CTI), Telegram, Chat, Jira/Synchronisationen |
| Tickets | Status, Statusarten, SLA, Texte (Textbausteine), Tags, Artikel-Typen |
| Kalender & Zeiten | Arbeitszeiten, Feiertage, Abwesenheiten |
| Systeme | Rollen, Organisationen, Benutzer, LDAP/SSO (OIDC/SAML), Webhooks, Trigger, Scheduler, Backups, Store-Apps |
| Knowledge Base | Verwaltungs-/Publikationseinstellungen |

## Manager-/Agenten-Ticketmenü (⋮ im Ticket)

Owner setzen, Gruppenwechsel, Priority, State (open/pending…/closed), Tags, Share-Link, Drucken, Löschen, Merge, Follow-up, Splitting

## Menüs nach Rolle

| Rolle | Sichtbar |
|-------|----------|
| Agent | Tickets, Kunden, eigene Dashboards |
| Manager | + Reports, Knowledge-Verwaltung, Teamverwaltung |
| Admin | + kompletter ⚙-Bereich |
| Customer (Portal) | eigenes Kundenportal: eigene Tickets, Knowledge Base (öffentlich) |
