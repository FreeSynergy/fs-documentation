# Snipe-IT – Funktionen

- **Anlagen**: wertvolle Artikel mit eindeutiger Kennzeichnung; Ausgabe an Personen, Orte oder andere Anlagen.
- **Zubehör**: nicht gekennzeichnete, austauschbare Artikel, an Personen oder Anlagen ausgegeben.
- **Komponenten**: Teile, die an Anlagen ausgegeben werden.
- **Verbrauchsgüter**: nur an Personen ausgegeben, nie zurückgenommen.
- **Statusbezeichnungen**: vier Arten, die bestimmen, ob ein Artikel zugewiesen werden kann.
- Optionale Farbmarkierungen und Ein-/Ausblenden von Tabellenspalten.
- Lizenzen, Prüfprotokoll, Berichte: offen (nicht auf der gelesenen Seite).
