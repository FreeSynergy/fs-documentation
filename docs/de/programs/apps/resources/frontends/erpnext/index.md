# ERPNext

> Kategorie: [resources](../../index.md)

## Was es ist

ERPNext ist eine Open-Source-Suite für die Unternehmensverwaltung auf Basis des Frappe-Frameworks. Sie deckt Buchhaltung, Lager, Verkauf, Einkauf, Fertigung und Anlagen ab.

## Bemerkenswerte Ideen

- Jeder Datensatztyp ist ein **DocType**: eine Definition beschreibt die Felder, wie Datensätze benannt werden, und die Datenbanktabelle. Die Listenansicht und die Formularansicht existieren dann ohne weiteren Code. Das ist das Vorbild dafür, unsere eigenen Formulare aus einer Beschreibung des Datentyps zu erzeugen (siehe die Admin-Ansicht in der [Karte](../../../../map.md)).
- Hier wegen dieses Erzeugungsprinzips aufgeführt (ADR 0013); sonst wird nichts übernommen.
