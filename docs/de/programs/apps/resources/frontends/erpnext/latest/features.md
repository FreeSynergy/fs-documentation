# ERPNext – Funktionen

## Hauptfunktionen

- Buchhaltung, Lager, Verkauf, Einkauf, Fertigung, Anlagen (laut Projektseite).
- Ein DocType definiert einen Datensatztyp: Felder, Benennung und Tabelle. Für jeden DocType gibt es eine Listenansicht und eine Formularansicht ohne zusätzlichen Code.
- Datensätze sind über Routen erreichbar, zum Beispiel eine Liste unter einer Adresse und jeder Datensatz unter einer Unteradresse.

## Hier nicht dokumentiert

- Reservierung oder Buchung von Räumen und Zeit: offen.
- Eigene Felder und Skripte für DocTypes: offen.
