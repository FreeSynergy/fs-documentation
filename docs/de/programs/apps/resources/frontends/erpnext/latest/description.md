# ERPNext – Beschreibung

## Was das Programm tut

ERPNext verwaltet die kaufmännische Seite einer Organisation in einem System: Buchhaltung, Lager, Verkauf, Einkauf, Fertigung und Anlagen. Seine Oberflächen werden größtenteils vom Frappe-Framework aus DocType-Definitionen erzeugt, deshalb sehen alle Module gleich aus und verhalten sich gleich.

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| Odoo | Ebenfalls modular; ERPNext ist um das DocType-Modell herum gebaut, das andere Apps erweitern können. |
| Dolibarr, Tryton | Andere offene ERP-Systeme; hier nicht verglichen (offen). |

## Technische Details

- Aufgebaut auf dem Frappe-Framework (Python-Server, Web-Client "Desk"). Details zu Datenbank- und Client-Stack: offen.
- Lizenz: offen (in dieser Sitzung nicht geprüft).

## Für wen es passt

Organisationen, die Lager, Buchhaltung und Verkauf zusammen brauchen. Für FreeSynergy ist es eine Referenz für erzeugte Formulare, nicht für die Buchung von Ressourcen.
