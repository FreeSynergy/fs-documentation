# Grocy – Funktionen

- **Vorrat**: Einkäufe erfassen, Fälligkeitsdaten, Barcode-Scan mit der Kamera im Browser.
- **Einkaufsliste**: Mindestbestände fügen Artikel automatisch hinzu; Produkte nach Abteilung im Laden gruppiert.
- **Rezepte**: zeigt, ob Zutaten vorhanden sind, und setzt fehlende auf die Liste; eine Bewertung reiht Rezepte, die bald ablaufende Bestände verbrauchen.
- **Speiseplan**: tägliche Mahlzeiten aus Rezepten.
- **Haushalt**: Aufgaben, To-do-Liste, Geräte und Handbücher, Verfolgung des Batterieladestands.
- **Anpassung**: eigene Felder, eigene Objekt- und Listentypen, Feature-Flags.
- Version 4.7.1 nennt einen Endpunkt zum Kopieren von Lagerprodukten und einen Kalenderexport (iCal).
