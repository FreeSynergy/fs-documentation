# Grocy – API

- Eine REST-API mit Swagger-UI-Dokumentation (Startseite).
- API-Schlüssel-Authentifizierung wird unterstützt, auch bei Installation in einem Unterverzeichnis (Version 4.7.1).
- Kalenderexport als iCal (Version 4.7.1; ein früherer Fehler `401` wurde behoben).
- Webhooks, Rate Limits: offen.
