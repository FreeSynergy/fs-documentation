# Grocy

> Kategorie: [resources](../../index.md)

## Was es ist

Grocy ist eine selbst gehostete Web-App für Haushaltsvorräte und Haushaltsaufgaben: Bestand, Einkaufsliste, Rezepte, Speiseplan, Aufgaben, Geräte und Batterien.

## Bemerkenswerte Ideen

- **Bestand an Verbrauchsgütern** mit Fälligkeitsdaten, Mindestmengen und Erfassung per Barcode: das Vorbild für Material, das aufgebraucht wird (siehe [Resources](../../index.md)).
- Fehlende Artikel wandern automatisch auf eine Einkaufsliste; Rezepte zeigen, ob der Bestand reicht.
- Feature-Flags blenden Module aus, die ein Haushalt nicht nutzt; es gibt eigene Felder und benutzerdefinierte Objekttypen.
- Hier aufgeführt, weil es Bestand, Aufgaben und Planung für kleine Gruppen verbindet (ADR 0013).
