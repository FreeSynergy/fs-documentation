# Odoo – Beschreibung

## Was das Programm tut

Odoo bietet viele Geschäfts-Apps in einer Installation: Verkauf, Lager, Buchhaltung und weitere, in der Dokumentation nach Bereich geordnet. Welche Apps installiert sind, bestimmt, was die Oberfläche anbietet.

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| ERPNext | Ähnlicher Umfang; Odoo führt Apps als eigene Module mit eigenen Dokumentationskapiteln. |

## Technische Details

Offen: Sprache, Datenbank, Lizenz und Grenzen der Editionen wurden nicht geprüft.

## Für wen es passt

Organisationen, die mit einer App beginnen und später weitere hinzufügen wollen. Für FreeSynergy zeigt es, wie Module verknüpft werden können, ohne Daten zu kopieren.
