# OpenBoard - Menüpunkte

## Vollbild-Werkzeugbögen

OpenBoard hat keine klassische Menüleiste — die Bögen klappen seitlich aus:

| Bogen/Fläche | Inhalt |
|--------------|--------|
| Haupt-Werkzeugleiste (links, senkrecht) | Stift, Marker, Radierer, Auswahl, Text, Formen, Bild, Screenshot-Werkzeug |
| Stift-Untermenü (aufgeklappt) | Farben, Linienstärken, Textmarker-Modus |
| Dokumenten-Werkzeuge | neue Seite/seitige Duplikat, Duplizieren/Löschen von Seiten, Miniaturübersicht |
| Bibliothek (unten, einklappbar) | Bilder, Stacks/Objektsammlungen, Dokumente (.obz), Web-Browser-Werkzeug, Dokumenten-Betrachter |
| Capture | Bildschirm-Aufnahme (Video) + Wiedergabe-Overlay |

## Dokumenten-Menü

- Neu / Öffnen / Speichern / Speichern unter (.obz) / Export PDF / Drucken
- Seitenverwaltung: hinzufügen, duplizieren, löschen, Reihenfolge

## Menüs nach Rolle

Keine Konten/Rollen — Einzelplatzanwendung (geteilte Whiteboards über Rechner-/OS-Profile).
