# Miro Dokumentation

> Kategorie: [whiteboards](../../index.md)

## Übersicht

Miro ist das kommerzielle Online-Whiteboard (SaaS) für Visual Collaboration: Infinite Canvas, Shapes/Sticky Notes, Frames, Vorlagen-Bibliothek (Retros, Workshops, Customer Journeys), Voting/Timer und Board-Apps. REST-API (REST + GraphQL-Beta), keine Selbst-Host-Option.
