# draw.io - Tastatur-Shortcuts

## Übersicht

draw.io führt eine offizielle Shortcut-Liste in der Anwendungshilfe (Hilfe-Menü). draw.io ist ein Zeichenprogramm **ohne Werkzeug-Buchstaben** — Formen kommen aus Bibliotheken, nicht aus einer Tool-Palette. Viele Kürzel stehen in den Menüs selbst; punktuell unterscheiden sich Web- und Desktop-Version (versionsabhängig).

---

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Z` / `Cmd+Z` | Rückgängig |
| `Ctrl+Y` / `Cmd+Y` | Wiederholen |
| `Ctrl+A` / `Cmd+A` | Alles auswählen |
| `Ctrl+C` / `Cmd+C` | Kopieren (Form oder Auswahl) |
| `Ctrl+X` / `Cmd+X` | Ausschneiden |
| `Ctrl+V` / `Cmd+V` | Einfügen |
| `Entf` / `Backspace` | Auswahl löschen |
| `Esc` | Bearbeitung abbrechen, Auswahl aufheben |
| `Enter` | Beschriftung der ausgewählten Zelle bearbeiten |
| `F2` | Daten der ausgewählten Zelle bearbeiten (Bearbeiten-Menü) |
| `Tab` / `Shift+Tab` | Nächste / vorherige Zelle auswählen (versionsabhängig) |

---

## Auswahl und Navigation

| Shortcut | Funktion |
|----------|----------|
| `Shift`+Klick | Zellen zur Auswahl hinzufügen |
| Über freie Fläche ziehen | Kasten-Auswahl (Marquee) |
| `Strg`+Scrollen | Zoomen |
| Doppelklick auf Form | Text bearbeiten |
| Klick auf Seitenreiter | Seite wechseln (unten) |
| Rechtsklick-Ziehen auf freier Fläche | Canvas verschieben (versionsabhängig) |

---

## Bearbeitung

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+D` / `Cmd+D` | Duplizieren (Bearbeiten-Menü) |
| `Ctrl+G` / `Cmd+G` | Gruppieren |
| `Ctrl+Shift+G` / `Cmd+Shift+G` | Gruppierung aufheben |
| `Alt`+Ziehen | Zelle klonen |
| `Shift`+Ziehen an einem Griffs | Proportionale Skalierung |
| `Shift`+Ziehen einer Kante | Winkel der Kante fixieren |
| Punkt einer Kante ziehen | Wegpunkte setzen, `Alt`+Klick entfernt Punkt |

## Ausrichten und Verteilen (Mehrfachauswahl)

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Shift+L` / `Cmd+Shift+L` | Links ausrichten |
| `Ctrl+Shift+C` / `Cmd+Shift+C` | Horizontal mittig |
| `Ctrl+Shift+R` / `Cmd+Shift+R` | Rechts ausrichten |

## Seiten und Zoom

| Shortcut / Bedienung | Funktion |
|----------------------|----------|
| `Strg`+Scrollen | Hinein-/hinauszoomen |
| Zoom-Regler unten | Zoom-Stufe setzen |
| Ansicht > Zoom (Menü) | Herein/Vergrößern, Verkleinern, Maßstab wählen |
| `+`-Schaltfläche neben Seitenreitern | Neue Seite einfügen |
| Rechtsklick auf Seitenreiter | Umbenennen, duplizieren, löschen |

---

## Suche

Formsuche funktioniert über das **Suchfeld links** — ein Shortcut dafür existiert nicht. Die Textsuche des Browsers (`Strg+F`) findet nur Oberflächen-Texte, keine Zellinhalte.

## NICHT vorhanden

| Verbreiteter Wunsch | Status |

| Werkzeug-Buchstaben (`R`, `T`, `A` …) | ❌ Nicht vorhanden — draw.io hat keine Werkzeug-Tasten |
| `Ctrl+S` Speichern | ❌ Web-Version löst den Browser-Speichern-Dialog aus; Speichern läuft über die Leiste (Desktop: versionsabhängig) |
| `Ctrl+F` Suchen in Diagramm | ❌ Nicht als draw.io-Funktion dokumentiert |
| Befehlspalette / `Ctrl+Shift+P` | ❌ Nicht vorhanden |
| Seitenwechsel per Tastenkürzel | ❌ Nicht dokumentiert — Seiten-Reiter nutzen |
| `Ctrl+P` Drucken | ❌ Kein dokumentiertes Kürzel — Menü Datei > Drucken |

## Maus-Gesten (ergänzend)

| Geste | Funktion |
|-------|----------|
| Form kurz berühren (Hover) | Verbindungspunkte erscheinen |
| Kantenmitte ziehen | Kante verbiegen, Wegpunkt entsteht |
| `Alt`+Klick auf Kantensegment | Wegpunkt entfernen |
| Form in Container ziehen | Form wird untergeordnet |
| `Strg`+Scrollen | Zoom |
| Rechter Mausklick | Kontext-Menü der Zelle oder Fläche |

---

## Zusammenfassung

draw.io setzt auf Menü + Maus statt Schnellstart-Kürzel:

- **Klassiker** für Undo/Redo, Zwischenablage, Auswählen, Gruppieren
- **`Ctrl+Shift`+Buchstaben** für Ausrichten und Stil-Übertragung — die markanteste Shortcut-Familie
- **Keine Werkzeug-Tasten, keine Suche, keine Palette** — diese Erwartungen bewusst nicht erfüllt (siehe Tabelle oben)
