# Mural - Beschreibung

## Was das Programm macht

Mural strukturiert Moderation: Neben dem Canvas bringt es „Sequenzen“ — eine Abfolge moderierter Schritte mit Zeitangaben, die Workshop-Leitung und Teilnehmende gemeinsam durchlaufen. Es zielt stärker auf Facilitation als auf freies Kritzel-Whiteboarding.

## Vorteile

- **Moderationsrhythmus** als Produktfeature (Timer, Schritte, Breakouts)
- aufgeräumte UI mit wenig Werkzeug-Ablenkung
- EU-Hosting-Option

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Miro** | größeres App-Ökosystem und API; Mural facettenreicher im Moderationskern |
| **FigJam** | Design-Workflow-nah (Figma), weniger Facilitationstiefe |
| **OpenBoard** | Klassenraum-/Präsentations-Tool, kein Team-SaaS |

## Technische Details

- **Modell**: SaaS (Workspaces; Mural.co), EU-US-Residency; Desktop-App/Clients
- **Auth**: E-Mail/Google/Microsoft/SSO (SAML/SCIM Enterprise)
- **Preise**: Free/Team/Business/Enterprise

## Für wen geeignet

- Workshop-/Beratungsteams, die Abläufe standardisieren wollen
- FreeSynergy-Skin-Kandidat für „geführte Interaktion“ (Sequence-Modell)
