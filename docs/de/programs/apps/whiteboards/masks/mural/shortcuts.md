# Mural - Tastatur-Shortcuts

## Übersicht

Mural listet Shortcuts im Menü („Keyboard shortcuts“). Bestand hier reduziert auf Sicheres; übrige bitte im Client prüfen.

> Stand: 2026.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `V` | Auswahl |
| `H` | Hand/Pan |
| `N` | neue Notiz |
| `T` | Text |
| `Strg/Cmd+Z` / `+Shift+Z` | Rückgängig / Wiederholen |
| `Strg/Cmd+C` / `+V` / `+D` | Kopieren / Einfügen / Duplizieren |
| `Entf` | Auswahl löschen |
| `Strg/Cmd+A` | Alles auswählen |
| `Esc` | Auswahl/Editor verlassen |

## Ausdrücklich ungesichert

- Ein-Buchstaben-Formen (`R`/`O`) je Version unterschiedlich — Menü-Legende nutzen

## Mac

`Cmd` statt `Strg`.
