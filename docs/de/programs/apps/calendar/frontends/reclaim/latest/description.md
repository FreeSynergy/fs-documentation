# Reclaim – Beschreibung

## Was das Programm macht

Liest den Kalender der Nutzer und legt Kalenderereignisse für Gewohnheiten, Aufgaben und Fokuszeit an; diese werden verschoben, wenn Besprechungen kommen und gehen. Kommerziell; es gibt einen kostenlosen Tarif ⚠️ (Drittanbieter-Test).

## Abgrenzung

- Gegenüber Motion: beide platzieren Aufgaben; die gelesenen Quellen erlauben keinen feineren Vergleich. Offen.
- Gegenüber einfachen To-do-Listen: die Aufgabe wird zu einem echten Kalenderereignis.

## Für wen geeignet

Angestellte mit vielen Besprechungen, die geschützte Arbeitszeit wollen.
