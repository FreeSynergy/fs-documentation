# Notion Calendar – Funktionen

| Funktion | Gesehen | Anmerkung |
|----------|---------|-----------|
| Mehrere Zeitzonen mit eigenen Bezeichnungen | ✅ | Suchausschnitt des Hilfecenters; die Seite selbst verlinkt nur dorthin |
| „Reisen“ in eine Zone (vorübergehende Hauptzone) | ✅ | Kürzel Z |
| Terminierungslink, einmalig | ✅ | Zeiten per Ziehen oder Eingabe |
| Terminierungslink, wiederkehrend | ✅ | Mehrere Zeitbereiche pro Tag; nimmt mehrere Buchungen an |
| Buchungsfenster (Minimum, Maximum), Ablauf, Ort, Video- oder Telefondetails, Beschreibung | ✅ | |
| „Konflikte vermeiden“: Verfügbarkeit folgt neuen Konflikten | ✅ | |
| Eingeladene können verschieben oder absagen | ✅ | Nicht für einmalige Links mit nur einer Nutzung |
| Verfügbarkeit anderer Personen berücksichtigen | ❌ | Als nicht unterstützt aufgeführt |
| Verfügbarkeit mobil teilen | Offen | Die Seite nennt nur Desktop und Web |
