# Notion Calendar – Beschreibung

## Was das Programm macht

Ein tastaturorientiertes Kalender-Frontend über vorhandenen Kalenderkonten, mit mehreren gemeinsam angezeigten Zeitzonen und Links, über die anderen freie Slots angeboten werden. Kommerzieller Dienst. ✅

## Abgrenzung

- Gegenüber Cal.com: der Terminierungslink ist eine Funktion eines persönlichen Kalenders, kein eigenständiges Buchungsprodukt.
- Gegenüber Google Calendar: Zeitzonen können benannt und „bereist“ werden; die Hilfe nennt, dass die Zone zunächst vom Google-Konto übernommen wird ✅.

## Für wen geeignet

Menschen, die über Zeitzonen hinweg Termine planen. Welche Konten außer Google unterstützt werden: offen.
