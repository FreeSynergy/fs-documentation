# Cal.com – Funktionen

| Funktion | Gesehen | Anmerkung |
|----------|---------|-----------|
| Termintypen | ✅ | Als API-Bereich benannt |
| Zeitpläne (Verfügbarkeit) | ✅ | API-Bereich |
| Buchungen | ✅ | API-Bereich |
| Verfügbarkeit, Puffer, Mindestvorlauf, Slot-Intervalle pro Termin | ⚠️ | Suchausschnitt |
| Kalender- und Konferenz-Integrationen (Google, Microsoft, Zoom) | ✅ | Für den Fork aufgeführt |
| Terminplanung im Team (Round-Robin, kollektiv) | Open | Quellen widersprechen sich, welche Edition es hat |
| SSO/SAML | Open | Im Fork entfernt; im Original kommerziell |
| Workflows, Insights, Organisationen | ✅ | Als im Fork entfernte Enterprise-Teile genannt |
