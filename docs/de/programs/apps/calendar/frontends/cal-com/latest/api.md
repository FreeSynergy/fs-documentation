# Cal.com – API

| Merkmal | Wert | Gesehen |
|---------|------|---------|
| API | REST, Version 2 | ✅ |
| Authentifizierung | OAuth; API-Schlüssel als Bearer-Token (`cal_` Test, `cal_live_` Live); eine Platform-Methode ist veraltet | ✅ |
| Ratenlimit | standardmäßig 120 Anfragen pro Minute für API-Schlüssel; mehr auf Anfrage | ✅ |
| Tokens für verwaltete Nutzer | Zugriff 60 Minuten, Refresh ein Jahr | ✅ |
| Webhooks | OAuth-Client-Webhooks erwähnt; allgemeine Webhooks Open | ⚠️ |
| Endpunkt-Umfang | Teams und Organisationen erhalten die meisten Endpunkte; Platform-Zusätze | ✅ |

Quelle: https://cal.com/docs (abgerufen 2026-11-10).
