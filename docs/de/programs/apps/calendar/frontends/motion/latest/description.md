# Motion – Beschreibung

## Was das Programm macht

Verbindet einen Kalender, eine Aufgabenliste und Projektmanagement; ein KI-Planer füllt den Kalender mit Aufgaben. Externe Google- oder Outlook-Kalender werden gelesen, damit belegte Zeiten respektiert werden ✅.

## Abgrenzung

- Gegenüber Reclaim: Motion ist ein eigener Arbeitsbereich mit Projekten und Nutzern, nicht nur eine Schicht über einem Kalender. ⚠️
- Gegenüber Planner (GNOME): Planner plant nach Abhängigkeiten, aber von Hand; Motion tut das fortlaufend.

## Für wen geeignet

Einzelpersonen und kleine Teams, die das Werkzeug ihren Tag planen lassen wollen.
