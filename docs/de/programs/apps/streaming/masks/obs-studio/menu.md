# OBS Studio - Menüpunkte

## Dateimenü

| Menüpunkt | Beschreibung |
|-----------|--------------|
| Neue Szenen-/Sammlungsgruppe | Szenen und Ordner anlegen |
| Aktuelle Szenen kopieren | Szenen in andere Profilsammlung übernehmen |
| Einstellungen | Allgemein, Video, Audio, Ausgabe, Aufnahmen, Stream, Erweitert, Hotkeys, Erweiterungen |
| Bildschirmaufnahmen starten/stoppen | schnelle Aufnahme ohne Streaming |
| Alle Bildschirmaufnahmen stoppen | Mehrfachaufnahmen beenden |
| Beenden | inkl. Speichern des Szenenwechsels |

## Ansicht-Menü

Docks ein-/ausblenden (Szenen, Quellen, Mischer, Steuerungen, Übergänge), Vollbild-Studio-Vorschau, Vollbild-Projektion (Preview/Ausgang), Fortgeschrittenes Audio-Dock, Benutzeroberfläche skalieren, Bildschirmauflösungen sperren

## Bearbeiten-Menü

Rückgängig/Wiederherstellen (der letzten Szenenänderung), Kopieren/Einfügen von Quellen, Eigenschaftenzwischenablage

## Szenen- und Quellenkontextmenüs (Rechtsklick)

| Objekt | Aktionen |
|--------|----------|
| Szene | Umbenennen, Duplizieren, Umschalten-Übergang setzen, Transform-Reset |
| Quelle | Umbenennen, Sperren, Sichtbarkeit, Transformieren (Rand/Center), Duplizieren, Filter, Eigenschaften, Skalierung (Quellen-/Ausgangsgröße) |
| Gruppierung | Gruppe auflösen, Gruppenquelle bearbeiten |

## Docker und Steuerungen

| Dock | Inhalt |
|------|--------|
| Szenen | Liste inkl. Ordner, Reihenfolge per Drag |
| Quellen | Quellen der aktiven Szene |
| Audio-Mischer | Kanäle, Stummtaste, Gain, Filter, Monitoring |
| Übergänge | Typ und Dauer, „Schnitt“ |
| Steuerungen | Start Streaming, Aufnahme, Studio-Modus, Rekorde, Einstellungen, Untertitel |
| Fortgeschrittenes Audio | Noise-Gate, Kompressor, Pegelanzeige pro Quelle |

## Rechtsmenüs (Drei-Punkt-Menüs in den Steuerungen)

Rekorde, Untertitel aktivieren, Studio-Modus, Virtuelle Kamera starten, Bildschirmaufnahme, Tools: Enhancer, Shader, Skripting, Erweiterungen verwalten, Websocket-Server-Einstellungen, Streaming-Protokollierung

## Menüs nach Rolle

OBS ist ein Einzelplatzprogramm — Rollen entstehen erst im Team-Betrieb über Profiles/Scenes-Dateien und obs-websocket (Operator, Regie, Moderator).
