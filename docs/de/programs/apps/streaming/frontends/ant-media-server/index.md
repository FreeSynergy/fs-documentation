# Ant Media Server Dokumentation

> Kategorie: [streaming](../../index.md)

## Übersicht

Der Ant Media Server (AMS) ist eine Streaming-Plattform auf Java-Basis: Er nimmt RTMP, RTSP, SRT und WebRTC an, liefert WebRTC, HLS und DASH aus, kann transkodieren (Adaptive Multi-Bitrate) und verwaltet Streams, Aufnahmen und Cluster über ein Web-Panel und eine REST-API. Es gibt eine Community- (MIT) und eine Enterprise-Ausgabe.
