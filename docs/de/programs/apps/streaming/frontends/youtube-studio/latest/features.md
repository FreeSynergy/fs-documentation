# YouTube Studio - Funktionen (Live-Teil)

## Vorhanden
| Funktion | Beleg |
|----------|-------|
| Live-Kontrollraum mit Stream-Zustand (Anzeigen für Bitrate und Verbindung) | Hilfeseite ✅ |
| Echtzeit-Messwerte: gleichzeitige Zuschauende, höchste Zahl gleichzeitiger Zuschauender | Hilfeseite ✅ |
| Auswertungen nach dem Stream, getrennt verarbeitet und nicht sofort | Hilfeseite ✅; Verzögerung von 48–72 Stunden stammt aus einer Quelle eines Dritten ⚠️ |
| Zahlen eines beendeten Streams unter der Inhaltsliste, im Live-Bereich, in den Auswertungen ablesen | Leitfaden eines Dritten ⚠️ |
| Datenexport als CSV | Quelle eines Dritten ⚠️ |

## Offen
Terminplanung, Chat-Moderation, Monetarisierung, Stream-Schlüssel, DVR/Zurückspulen, Weiterleitung, Untertitel, Unterschiede zwischen Streams. Nicht aus einer Primärquelle gelesen.
