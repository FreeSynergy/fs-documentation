## Was es ist
Ecamm Live ist ein Studio für Live-Streaming und Aufnahmen für den Mac. Es vereint Kameras, Bildschirm, Medien und Szenen in einer Anwendung und sendet das Ergebnis an Streaming-Plattformen oder zeichnet es auf.

## Bemerkenswerte Ideen
- **Native Mac-Anwendung** — eine plattformspezifische Entscheidung; sie zeigt, wie ein lokales, integriertes Studio neben einem Browser-Studio aussieht (ADR 0013).
- **Szenen, die im Voraus vorbereitet werden, mit Platzhaltern für Gäste** (Bericht eines Dritten ⚠️) — Szenen können gebaut werden, bevor die Gäste eintreffen.
- **Gästelimit hängt vom Prozessor ab** — ein sichtbares Beispiel für eine Kapazitätsgrenze, die durch die Hardware gesetzt wird, nicht durch den Tarif (Angabe aus dem Handbuch, siehe Funktionen).
