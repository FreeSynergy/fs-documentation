# Ecamm Live - Beschreibung

## Was das Programm macht
Eine einzelne Mac-Anwendung für die Live-Produktion: Kameras und andere Eingänge auswählen, zwischen vorbereiteten Szenen wechseln, Interview-Gäste einbinden und streamen oder aufzeichnen.

## Vorteile
- Integriert: Aufnahme, Szenen und Ausgabe in einer Anwendung.
- Szenen lassen sich vor der Sendung vorbereiten.

## Abgrenzung
| System | Unterschied |
|--------|-------------|
| OBS Studio | Plattformübergreifend und quelloffen; Ecamm Live ist nur für Mac und proprietär. |
| StreamYard | Browser-Studio; Ecamm Live läuft lokal auf dem Mac. |

## Technische Details
Nur Mac; eine Windows-Version ist nicht geplant (Aussage eines Dritten ⚠️). Offen: Pläne, Version, unterstützte Protokolle.
