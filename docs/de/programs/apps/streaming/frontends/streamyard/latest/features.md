## Offen
Layouts, Einblendungen, Kommentare auf dem Bildschirm, Aufnahme, Streaming an mehrere Ziele, Grenzen je Tarif. Nicht aus einer Primärquelle gelesen.

## Bekannte Risiken (Dritte) ⚠️
Strenge Firewalls und schwache WebRTC-Unterstützung im Browser können dazu führen, dass der Link nicht funktioniert.
