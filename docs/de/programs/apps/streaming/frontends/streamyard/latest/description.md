# StreamYard - Beschreibung

## Was das Programm macht
Die Gastgeberin oder der Gastgeber öffnet ein Studio im Browser, lädt Gäste per Link ein, ordnet sie auf dem Bildschirm an und streamt oder zeichnet auf. Gäste brauchen keine Software und standardmäßig kein Konto.

## Vorteile
- Der Zugang für Gäste ist ein Link im Browser.
- Wenig einzuarbeiten im Vergleich zu Encoder-Software.

## Abgrenzung
| System | Unterschied |
|--------|-------------|
| OBS Studio | OBS ist lokale Encoder-Software mit Szenen und Quellen; StreamYard ist ein gehostetes Studio mit Gästen. |
| Ecamm Live | Mac-Anwendung; StreamYard läuft in jedem unterstützten Browser. |

## Technische Details
Nur gehostet. Offen: Codecs, Auflösungsgrenzen, Tarifgrenzen (eine Quelle eines Dritten nennt eine Grenze von sechs Personen im kostenlosen Tarif ⚠️).
