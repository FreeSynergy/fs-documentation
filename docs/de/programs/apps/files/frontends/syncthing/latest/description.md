## Was das Programm macht

Läuft auf jedem Gerät, findet die anderen Geräte und kopiert Änderungen in geteilten Ordnern. Die Nutzer verwalten es über eine Browserseite des lokalen Programms. ✅

## Abgrenzung

- Gegenüber Seafile und Nextcloud: kein Server, keine Konten; nur Geräte.
- Gegenüber rclone: fortlaufende Zwei-Wege-Synchronisation zwischen Gleichberechtigten, kein Werkzeug für Speicherdienste.

## Für wen geeignet

Nutzer, die ihre eigenen Geräte ohne Cloud synchron halten wollen. Konfliktbehandlung, Versionierung, Ignorier-Regeln: offen (nicht auf den gelesenen Seiten).
