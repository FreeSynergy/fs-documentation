## Was das Programm macht

Führt eine Liste aller Datei- und Ordnernamen auf lokalen Datenträgern und filtert sie live. Es öffnet oder verschiebt Dateien nicht selbst; es ist ein Finder. ✅

## Abgrenzung

- Gegenüber der Suche in Dolphin oder im Finder: diese suchen innerhalb des Dateimanagers und können Inhalte durchsuchen; Everything antwortet schneller, aber nur auf Namen.
- Nur Windows (XP bis 11) ✅.

## Für wen geeignet

Menschen mit sehr vielen Dateien, die einen Teil eines Namens kennen. Aktuelle Versionsnummer: offen.
