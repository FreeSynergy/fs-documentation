# Decidim

> Kategorie: [surveys](../../index.md)

## Was es ist

Decidim ist eine Plattform für partizipative Demokratie, gestartet vom Rathaus Barcelona. Eine Organisation richtet eine Website ein, auf der Menschen an Planung, Haushalt, Regelsetzung und Wahlen teilnehmen.

## Bemerkenswerte Ideen

- **Beteiligungsräume** (Prozesse, Versammlungen, Initiativen, Konferenzen) enthalten **Komponenten** (Vorschläge, Debatten, Haushalte, Treffen, Umfragen, Auslosungen, Rechenschaft, Blog, Seiten). Ein Raum ist ein Container; die Komponenten werden je Raum gewählt. Das ist ein Modell dafür, wie ein Entscheidungsthema mehrere Arten von Beteiligung aufnehmen kann.
- Hier aufgeführt, weil es das umfassendste der Gruppe ist (ADR 0013).
