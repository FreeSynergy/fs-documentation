## Was das Programm tut

Decidim ist ein Framework für Websites demokratischer Beteiligung. Städte, Vereine, Hochschulen, Nichtregierungsorganisationen, Stadtteile und Genossenschaften nutzen es für strategische Planung, Bürgerhaushalt, gemeinsame Regelsetzung, öffentliche Räume und Wahlen.

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| Consul | Ebenfalls für öffentliche Beteiligung; Decidim betont konfigurierbare Räume und Komponenten. |
| Loomio | Loomio ist für eine Gruppe, die entscheidet; Decidim für große öffentliche Verfahren. |
