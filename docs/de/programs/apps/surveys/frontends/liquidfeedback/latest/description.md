## Was das Programm tut

Teilnehmende entwickeln Vorschläge gemeinsam und entscheiden darüber in einem Ablauf. Eine abstimmende Person kann ihre Stimme zu Themen, die sie nicht verfolgt, weitergeben (delegieren).

## Aktivität

Die aktuelle Version ist Core 4.2.2 (gelistet am 2021-02-05) mit Frontend 4.0.0 (Datum nicht gefunden), zu verwenden mit WebMCP 2.2.1 und Moonbridge 1.1.3. Es wurde kein neueres Release gefunden. Das ist eine **Stagnation**, keine Einstellung; die Projektseite ist weiterhin online.
