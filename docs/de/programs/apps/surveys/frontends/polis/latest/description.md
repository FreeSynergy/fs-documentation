# Polis – Beschreibung

## Was das Programm tut

Polis erfasst, was eine große Gruppe denkt, ohne Fragebogen. Das Projekt nennt es organischer als Umfragen und weniger aufwendig als Fokusgruppen. Ein Mathematikdienst berechnet die Gruppierung, die die Visualisierung speist.

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| Loomio | Loomio treibt auf eine Entscheidung zu; Polis zeigt, wo Meinungen liegen. |
| Decidim | Decidim ist eine vollständige Plattform; Polis ist ein einzelnes Werkzeug. |

## Technische Details

- Lizenz: AGPL-3.0 mit einer zusätzlichen Erlaubnis nach Abschnitt 7.
- Zu den Diensten gehören ein API-Server und eine Python-Mathematik-Engine.
- Einbettung und API: offen.

## Für wen es passt

Gruppen, die viele Meinungen verstehen müssen, bevor sie entscheiden.
