# Piwigo Dokumentation

> Kategorie: [gallery](../../index.md)

## Übersicht

Piwigo ist eine klassische Webbaukasten-Fotogalerie: Kategorienbaum, Rollen und Rechte pro Ordner, Themes, Erweiterungen und eine vollständige Webservice-API. Stack: PHP/MySQL, eigenes Template-System, Admin- und Publikumsbereich getrennt.

## Bemerkenswerte Ideen

_Zu tun: Was kann dieses Programm, das andere nicht können? Warum ist es hier dokumentiert (ADR 0013)?_
