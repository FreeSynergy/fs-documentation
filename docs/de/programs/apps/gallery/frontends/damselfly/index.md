# Damselfly Dokumentation

## Übersicht

Damselfly ist eine leichte, schnell startende Fotogalerie mit KI-Erkennung (Gesichter, Szenen, Texte/OCR, Ähnlichkeitssuche) auf Basis von PostgreSQL-Vektoren. Stack: C#/.NET 8, React-Frontend, PostgreSQL mit pgvector, Container-orientiert.
