# Lychee - Menüpunkte

## Galerie-Navigation

| Menü | Beschreibung |
|------|--------------|
| Alben | eigene und geteilte Alben, verschachtelte Alben |
| Öffentlich | als öffentlich markierte Alben |
| Suche | Suche nach Titel, Beschreibung, Album |
| Favoriten | mit Stern markierte Aufnahmen |
| Teilen | eigene Freigaben (Links, Benutzer, Passwort) |
| Neu | Upload-Fläche (Dateien, Ordner, URL-Import) |

## Album-Menüs

| Menü | Inhalt |
|------|--------|
| Album-Aktionen (⋮) | Umbenennen, Beschreibung, Cover, Sortierung, Löschen, Herunterladen (ZIP) |
| Teilen-Dialog | öffentlicher Link, Passwort, Ablauf, Berechtigungen (Lesen/Herunterladen) |
| Aufnahmen | Favorit, Drehen, Bearbeiten (Crop), Löschen, Verschieben, Taggen |

## Einstellungen / Administration

| Bereich | Inhalt |
|---------|--------|
| Benutzer | Konten, Rollen (Admin/Benutzer/Gast), Quotas |
| Galerie | Wasserzeichen, Größe der Vorschaubilder, Sortierreihenfolge |
| Sicherheit | 2FA, Session-Lifetime, Registrierung an/aus |
| System | Logs, Diagnostics (`php artisan diagnose`), Update |
| Intelligenz | Smart Album (regelmäßige Suche als Album) |

## Menüs nach Rolle

| Rolle | Sichtbar |
|-------|----------|
| Gast | öffentliche Alben und geteilte Links |
| Benutzer | eigene Alben, Upload, Freigaben |
| Admin | zusätzlich Administration und Diagnose |
