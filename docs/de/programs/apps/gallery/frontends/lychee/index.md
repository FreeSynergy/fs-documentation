# Lychee Dokumentation

## Übersicht

Lychee ist eine schlanke, selbst gehostete Fotogalerie mit Alben, Freigaben per Link und einer sauberen REST-API. Stack: PHP/Laravel, MySQL/MariaDB/PostgreSQL, React-Frontend (Lychee-front), Version 5 mit getrenntem Frontend.
