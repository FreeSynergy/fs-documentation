# Coppermine Dokumentation

> Kategorie: [gallery](../../index.md)

## Übersicht

Coppermine (CPG) ist ein klassischer Webbaukasten für Fotogalerien mit Alben, Kategorien, Kommentaren, Bewertungen und Rollenrechten. Stack: PHP/MySQL, Template-basiert, seit vielen Jahren im Einsatz; aktuelle Zweige pflegen PHP-8-Kompatibilität.

## Bemerkenswerte Ideen

_Zu tun: Was kann dieses Programm, das andere nicht können? Warum ist es hier dokumentiert (ADR 0013)?_
