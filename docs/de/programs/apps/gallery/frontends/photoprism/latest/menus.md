# PhotoPrism - Menüpunkte

## Hauptnavigation (obere Leiste)

| Menü | Beschreibung |
|------|--------------|
| Suchen | Volltext-, Label-, Farb-, Orts- und Gesichtsfilter |
| Alben | eigene Alben, Story-/Album-Ordner, Upload-Alben |
| Ordner | Dateibaum des indexierten Bibliotheksordners |
| Label | Label-Wolke mit Häufigkeit, auch aus KI-Vorschlägen |
| Kalender | Zeitleiste nach Aufnahmedatum |
| Orte | Karte und Ortsliste (Reverse Geocoding) |
| Gesichter | Personen mit Namen und Geburtstag |
| Fotos / Videos / Dateien | Filter nach Mediumtyp |

## Favoriten und Archiv

- Favoriten (Stern), Archiv (aus Suche ausgeblendet), Versteckte Objekte (`private`), Gelöschte (Index-Entfernung)

## Einstellungen (Zahnrad)

| Bereich | Inhalt |
|---------|--------|
| Konto | Passwort, Sprache, Theme, Zwei-Faktor |
| Gallery | Wasserzeichen-Optionen (Plus), Vorschaumaßstäbe, Sortierung, Blurring |
| Index | Sammelordner, Importordner, Update-Intervall, Offline-Modus |
| Gesichts-Erkennung | Modell, Schwelle, Gesichtserkennung an/aus |
| Lab | experimentelle Funktionen, OCR, Vektor-Suche |

## Admin-Menü (nur Admin, `/admin`)

| Menü | Inhalt |
|------|--------|
| Benutzer | Rollen (Admin, Viewer, Contributor), Quotas, Freigaben |
| Medien | Vorschau-/Sidecar-Größen, Transcoding-Optionen |
| Server | Protokoll, Neustart, Lizenz-Status, Originalanzeige |
| Import / Index | „Update“, „Rescan“, „Clear“ für den Index |
| API | API-Client-Verwaltung, Zugriffsschlüssel |

## Kontextmenüs (Mehrfachauswahl)

Label hinzufügen/entfernen, Album zuweisen, Favorit, Veröffentlichen/Verstecken, Bearbeiten (Crop, Rotation, Zeit), Herunterladen, Löschen, Teilen per Link, „Ähnliche suchen“

## Menüs nach Rolle

| Rolle | Sichtbar |
|-------|----------|
| Viewer | Suche, Alben, Betrachter-Funktionen, keine Bearbeitung |
| Contributor | zusätzlich Upload und eigene Alben |
| Admin | alles inkl. Einstellungen und `/admin` |
