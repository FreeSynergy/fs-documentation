# Nextcloud Photos - Menüpunkte

## Photos-App (obere App-Leiste: „Fotos“)

| Bereich | Beschreibung |
|---------|--------------|
| Neueste / Chronologie | alle für die Galerie freigegebenen Ordner, nach Aufnahmedatum |
| Alben | eigene Alben, Systemalben (Urlaube etc. je Version) |
| Ordner | alternative Ansicht nach Ordnerstruktur |
| Geteilt mit mir | von anderen geteilte Alben und Ordner |
| Favoriten | als Favorit markierte Bilder |
| Personen / recognition | Gesichts-Cluster (nur mit aktivierter App) |
| Karten | Ortsansicht (App „Maps“ erforderlich) |

## Ordnerauswahl (Einstellungen → Fotos)

- Festlegen, welche Ordner in der Chronologie erscheinen (Standard: `Fotos`, `Camera`)
- Ausgeschlossene Ordner, Reihenfolge, „Video in Chronologie“

## Alben-Dialog

Album anlegen, bearbeiten, Cover setzen, Bilder hinzufügen/entfernen, als Ordner-Album speichern, Teilen (Benutzer/Gruppen/Link)

## Nextcloud-Plattform-Menüs (relevant für Galerie)

| Menü | Inhalt |
|------|--------|
| Files Sharing | Link-Policies, Ablauf, Passwort, Download-Recht |
| Recognizer / Face Recognition | Modelle, Index-Lauf, Datenschutz-Freischaltung |
| Administration → Einstellungen | Passwort-Links, öffentliche Uploads, Preview-Größen |

## Menüs nach Rolle

| Rolle | Sichtbar |
|-------|----------|
| Gast (Link) | freigegebene Alben/Ordner, Upload je nach Einstellung |
| Benutzer | eigene Galerie, Alben, geteilte Inhalte |
| Group Admin | Gruppenordner-Galerie, Rechte der Gruppe |
| Nextcloud-Admin | globale Einstellungen, Apps, recognition |
