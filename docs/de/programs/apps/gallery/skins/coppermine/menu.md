# Coppermine - Menüpunkte

## Publikumsnavigation

| Menü | Beschreibung |
|------|--------------|
| Startseiten | letzte Uploads, beliebte, top bewertete, Zufallsbilder |
| Alben | Alben und Kategoriebaum, „last uploads“-Alben |
| Suche | nach Dateiendung, Schlüsselwort, Zeitraum, „nur Betiteltes“ |
| Mitgliederbereich | meine Favoriten, Uploads, Benachrichtigungen |
| Gastbuch / Kommentare | Moderation und eigene Beiträge |
| Links/Blöcke | themenabhängige Zusatzblöcke (RSS, Kalender) |

## Benutzer-Menü

Login/Registrierung, Profil, Passwort, Sprache, Benachrichtigungs-Einstellungen, Upload („Mein Album“)

## Admin-Menü (cuPCP)

| Menü | Inhalt |
|------|--------|
| Konfiguration | allgemeine Galerie-, Bild- und Kommentar-Einstellungen |
| Alben & Kategorien | anlegen, verschieben, Rechte je Album |
| Benutzer & Gruppen | Konten, Gruppenbenennungen, Rechte-Matrix |
| Bildverwaltung | Batch bearbeiten, verschieben, rotieren, moderieren |
| Kommentare & Bewertungen | Freigabe, Sperren, Meldungen |
| Themen & Plugins | Theme-Wechsel, Plugin-Verwaltung (`plugin_api`) |
| Wartung | Wasserzeichen-Cron, Thumbnail-Neubau, Prüfberichte |

## Menüs nach Rolle

| Rolle | Sichtbar |
|-------|----------|
| Gast | öffentliche Alben, Kommentare je Recht |
| Eingeloggter Benutzer | eigene Uploads, Favoriten, private Alben |
| Moderator | Alben-Betreuung ohne Systemrechte |
| Admin | volles cuPCP |
