# Lychee - Tastatur-Shortcuts

## Übersicht

Shortcuts betreffen Albenübersicht, Album-Ansicht und Lightbox. In Dialogen wirken nur `Enter` und `Esc`.

> Stand: Lychee v5 (Lychee-front).

## Lightbox

| Shortcut | Funktion |
|----------|----------|
| `←` / `→` | vorheriges / nächstes Bild |
| `Esc` | Lightbox schließen |
| `i` | EXIF-/Info-Overlay |
| `Space` | Diashow starten/pausieren |
| `f` | Favorit umschalten |
| `d` | Download des aktuellen Bildes |
| `Del` | Bild löschen (mit Rückfrage) |

## Galerie und Alben

| Shortcut | Funktion |
|----------|----------|
| `/` | Suche fokussieren |
| `n` | neues Album (angemeldet) |
| `u` | Upload-Dialog |
| `Ctrl/Cmd+A` | alle Aufnahmen des Albums auswählen |
| `Shift + Klick` | Bereichsauswahl |

## Nicht vorhanden (bewusst)

## Mac

`Cmd` statt `Ctrl`, übrige Tasten identisch.
