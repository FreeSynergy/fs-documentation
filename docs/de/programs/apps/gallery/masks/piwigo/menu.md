# Piwigo - Menüpunkte

## Publikumsnavigation

| Menü | Beschreibung |
|------|--------------|
| Startseiten | letzte Besuche, zufällige, meistgesehene, Best bewertete Bilder |
| Alben (Kategorien) | hierarchischer Kategorienbaum, sub-allocations |
| Tags | Schlagwortwolke mit Bildzahlen |
| Kalender | Jahres-/Monats-/Tagesansicht nach Aufnahmedatum |
| Suche | Volltext, Tags, Zeitraum, „wer hat hochgeladen“ |
| Kommentare | letzte Kommentare der Community |
| Meine Alben | private Alben angemeldeter Benutzer |
| Benachrichtigungen | Antwort auf Kommentare, neue Bilder (je Plugin) |

## Benutzer-Menü

Profil bearbeiten, Passwort, Benachrichtigungen, Favoriten, Highres-Download (je Recht), Abmelden

## Admin-Menüs (Administration)

| Menü | Inhalt |
|------|--------|
| Tools → Verwaltung | Bildverwaltung (Batch), Kategorieverwaltung, Sync (Ordner ↔ Datenbank) |
| Tags | Schlagwörter anlegen, zusammenführen, automatisch zuweisen |
| Benutzer | Benutzer, Gruppen, Zugriffsrechte pro Kategorie |
| Einstellungen | Allgemein, Themes, Sprachen, Kommentare, Benachrichtigungen |
| Plugins | installieren, aktualisieren, konfigurieren |
| Statistiken | Besuche, Bildzahlen, Bestbewertung |
| Site-Historik | Änderungsprotokoll |

## Kontextmenüs

| Objekt | Aktionen |
|--------|----------|
| Bild (Admin-Batch) | Rotieren, Bearbeiten (Metadata), Löschen, Kategorie zuweisen, Taggen, Status (veröffentlicht/wartend) |
| Kategorie | Umbenennen, Unteralben, Rechtezuweisung, Cover setzen, Beschreibung |
| Bild (Publikum) | Favorit, Kommentar, Teilen (Social/Link), Download (je Recht) |

## Menüs nach Rolle

| Rolle | Sichtbar |
|-------|----------|
| Gast | öffentliche Kategorien, Kommentare je Einstellung |
| Benutzer | eigene Alben, Favoriten, Upload je Recht |
| Webmaster | Administration ohne Systemebene |
| Admin | volle Administration inkl. Plugins und Config |
