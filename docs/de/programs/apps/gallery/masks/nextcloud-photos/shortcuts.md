# Nextcloud Photos - Tastatur-Shortcuts

## Übersicht

Es gelten die Shortcuts der Nextcloud-Web-Oberfläche (Viewer und Dateiansicht); Photos selbst bringt keine eigenen Kürzel mit.

> Stand: Nextcloud 29/30, Photos-App 6.x.

## Global

| Shortcut | Funktion |
|----------|----------|
| `/` | Suchfeld fokussieren |
| `Esc` | Viewer/Dialog schließen |
| `F1` | Kurzhilfe (Hilfe-App erforderlich) |
| `c` | neues Kommentarfeld (in Dateiansicht) |

## Viewer / Dateiansicht

| Shortcut | Funktion |
|----------|----------|
| `←` / `→` | vorheriges / nächstes Element |
| `Space` | Diashow starten/pausieren |
| `i` | Detailseite der Datei |
| `d` | Download |
| `Ctrl/Cmd+A` | alles in Ansicht auswählen |
| `Shift + Klick` | Bereich auswählen |

## Nicht vorhanden (bewusst)

| Angenommen | Status |
|------------|--------|

## Mac

`Cmd` statt `Ctrl`, übrige Tasten identisch.
