# MediaWiki - Tastatur-Shortcuts

## Übersicht

MediaWiki bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten mit den beiden Haupt-Editoren: dem visuellen VisualEditor und dem Quelltext-Editor (WikiText).

---

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Shift+P` / `Cmd+Shift+P` | Befehlspalette öffnen |
| `Ctrl+,` / `Cmd+,` | Einstellungen öffnen |
| `F1` | Hilfe |
| `Ctrl+K` / `Cmd+K` | Link hinzufügen |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | Global Suche |

## Quelltext-Editor (WikiText) Shortcuts

### Formatierung (Wiki-Syntax)

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+B` / `Cmd+B` | Fett (`'''text'''`) |
| `Ctrl+I` / `Cmd+I` | Kursiv (`''text''`) |
| `Ctrl+Shift+L` / `Cmd+Shift+L` | Aufzählung (`*`) |
| `Ctrl+Shift+N` / `Cmd+Shift+N` | Nummerierte Liste (`#`) |
| `Ctrl+Shift+1` / `Cmd+Shift+1` | H2 (`==`) |
| `Ctrl+Shift+2` / `Cmd+Shift+2` | H3 (`===`) |
| `Ctrl+Shift+3` / `Cmd+Shift+3` | H4 (`====`) |
| `Ctrl+K` / `Cmd+K` | Link (`[[Page|Name]]`) |
| `Ctrl+Shift+M` / `Cmd+Shift+M` | Zitat (`>`) |

### Navigation im Code

| Shortcut | Funktion |
|----------|----------|
| `Enter` | Neue Zeile |
| `Tab` / `Shift+Tab` | Einrücken |
| `Ctrl+Z` / `Cmd+Z` | Rückgängig |
| `Ctrl+Y` / `Cmd+Y` | Wiederholen |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | Syntax-Highlighting umschalten |

### Wiki-Syntax-Schnellzugriff

| Shortcut | Funktion | Beispiel |
|----------|----------|----------|
| `Ctrl+Shift+L` / `Cmd+Shift+L` | Interner Link | `[[Seite|Name]]` |
| `Ctrl+Shift+E` / `Cmd+Shift+E` | Externer Link | `[http://example.com Name]` |
| `Ctrl+Shift+D` / `Cmd+Shift+D` | Bild | `[[Datei:Bild.jpg|Thumb]]` |
| `Ctrl+Shift+V` / `Cmd+Shift+V` | Vorlage | `{{Vorlage}}` |
| `Ctrl+Shift+T` / `Cmd+Shift+T` | Tabelle | `{| ... |}` |

## Zusammenfassung

MediaWiki bietet umfangreiche Shortcuts für:
- **Visueller Editor**: Standard-Formatierungen, Tabellen, Vorlagen
- **Quelltext-Editor**: Wiki-Syntax-Schnellzugriff, Code-Navigation
- **Navigation**: editor-intern und zwischen Komponenten
- **Datei-Operationen**: Speichern, Öffnen, Drucken, Export
- **Suche**: Lokal und global
- **Ansicht**: Vollbild, Sidebar, Vorschau

Mac-Nutzer profitieren von den gleichen Shortcuts mit `Cmd` anstelle von `Ctrl`.
