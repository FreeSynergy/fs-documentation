# Tana - Beschreibung

## Was das Programm macht

Tana verbindet Gliederungsnotizen mit einer typisierten Schicht: Supertags mit Feldern, Vorlagen, Vererbung und Live-Suchen.

## Für wen geeignet

Tana ist ein Gliederungswerkzeug, in dem jede Zeile ein Knoten ist und Knoten in typisierte Objekte mit Feldern verwandelt werden können.
