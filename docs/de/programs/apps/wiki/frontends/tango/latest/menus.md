## Einstiegspunkte

- **Symbol in der Browser-Symbolleiste** (Tango): öffnet die Seitenleiste ([Installation](https://help.tango.ai/en/articles/5971659-how-do-i-install-tango-for-the-first-time), [anheften](https://help.tango.ai/en/articles/5971657-how-do-i-pin-my-chrome-extension)). Hilfeartikel: „How do I install Tango for the first time?“
- **Seitenleiste, lila Schaltfläche** auf der Startseite: startet eine Aufnahme ([Anleitung zur Dokumentation](https://help.tango.ai/en/articles/7966907-how-do-i-use-tango-for-documentation)). Beschriftung laut [Aufnahme starten](https://help.tango.ai/en/articles/5971654-how-do-i-start-capturing-a-workflow) „Start Capture“.
- **Aufnahme-Steuerung:** Abschließen, Pausieren, Neu starten, Verwerfen.
- **Editor:** Bearbeiten; Schritte hinzufügen → Weitere Schritte aufnehmen ([Schrittlimit](https://help.tango.ai/en/articles/6325769-are-there-limits-to-how-many-steps-i-can-capture-in-a-workflow)).
- **Teilen und Exportieren:** Freigabe-Link, E-Mail an Teammitglied, HTML kopieren, Link kopieren, Einbettung; Export als PDF/Markdown/HTML in Pro/Ent ([Anleitung zur Dokumentation](https://help.tango.ai/en/articles/7966907-how-do-i-use-tango-for-documentation)).
- **Sammelleiste der Team-Bibliothek:** Autor bearbeiten (Admins), Verschieben nach, Duplizieren, Freigeben, Löschen (ins Archiv) ([Sammelaktionen](https://help.tango.ai/en/articles/16652169-how-do-i-use-bulk-actions-in-the-team-library)).
- **Einstellungen und Mitglieder → Branding** (Admins) ([Branding](https://help.tango.ai/en/articles/5971709-can-i-add-my-own-branding-to-tango-workflows)).

## Menüs nach Rolle
