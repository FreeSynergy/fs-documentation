## Kann nicht (dokumentiert)

- Keine Aufnahme in Firefox, Safari, Arc. Keine Linux-Desktop-App. Keine mobilen Apps; keine Aufnahme auf Smartphones oder Tablets ([Wo es funktioniert](https://help.tango.ai/en/articles/17359491-where-does-tango-work)).
- Keine öffentliche API und keine Webhooks dokumentiert (siehe [api.md](api.md)).
- Aufnahme von Inhalten aus Google Docs, Sheets, Slides, Figma, Webflow, den Chrome-Einstellungen und dem Chrome Web Store ist eingeschränkt oder ausgeschlossen ([Grenzen](limits.md)).
- Desktop-aufgenommene Anleitungen: kein Guide Me, kein Live Blur, keine Sprachtranskription ([Wo es funktioniert](https://help.tango.ai/en/articles/17359491-where-does-tango-work)).
- Free: 5 geteilte Workflows, bis zu 10 Nutzer je Arbeitsbereich ([Preise](https://www.tango.ai/pricing)).
- Kein Markdown-Schreiben im Editor; Markdown ist nur ein Exportformat (Pro) (abgeleitet aus der Exportliste).
