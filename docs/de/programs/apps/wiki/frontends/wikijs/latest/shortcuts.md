# Wiki.js - Tastatur-Shortcuts

## Übersicht

Wiki.js bietet umfangreiche Tastatur-Shortcuts für schnelles Arbeiten mit beiden Editoren: dem visuellen WYSIWYG-Editor und dem Markdown-Editor.

---

## Allgemeine Shortcuts

| Shortcut | Funktion |
|----------|----------|
| `Ctrl+Shift+P` / `Cmd+Shift+P` | Befehlspalette öffnen |
| `Ctrl+,` / `Cmd+,` | Einstellungen öffnen |
| `F1` | Hilfe |
| `Ctrl+K` / `Cmd+K` | Link hinzufügen |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | Global Suche |

## Zusammenfassung

Wiki.js bietet umfangreiche Shortcuts für:
- **Formatierung**: Alle gängigen Formatierungen (Fett, Kursiv, Überschriften)
- **Navigation**: editor-intern und zwischen Komponenten
- **Datei-Operationen**: Speichern, Öffnen, Drucken
- **Suche**: Lokal und global
- **Ansicht**: Vollbild, Sidebar, Vorschau

Mac-Nutzer profitieren von den gleichen Shortcuts mit `Cmd` anstelle von `Ctrl`.
