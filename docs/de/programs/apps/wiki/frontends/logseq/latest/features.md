# Logseq - Funktionen

## Hauptfunktionen

- Blockverweise (Fenster auf einen anderen Block) gegenüber Blockeinbettungen (Portal, das direkt bearbeitet werden kann) — laut einem Forenbeitrag; die offizielle Seite dazu war nicht lesbar (offen).
- Knoten haben die Abschnitte Verlinkte und Unverlinkte Verweise.
- DB-Graphen: Schlagwörter mit geerbten Eigenschaften und mehreren Eltern; Eigenschaftstypen Text, Zahl, Datum, Datum/Uhrzeit, Kontrollkästchen, URL, Knoten; Seiten sind je Schlagwort eindeutig.
- Aufgaben: Statuseigenschaft (Backlog, Todo, Doing, In Review, Done, Canceled), Statusverlauf je Block, Wiederholungen.
- Abfragen mit dem Schlagwort Query, über den Abfrage-Baukasten oder erweiterte Abfragen; Ansichten Tabelle, Liste, Galerie.
- Importwerkzeug von Datei zu DB für Markdown-Graphen.
- Plattformen: Desktop, Web-App, iOS (DB-Version laut Repository in Alpha), Plugin-API; Anleitung für die Web-App per Docker.
- Stand der DB-Version: ein Testbericht eines Dritten nennt den Beginn der öffentlichen Beta am 2026-07-13 (offen, nicht vom Anbieter bestätigt).
