# Logseq - Beschreibung

## Was das Programm macht

Logseq speichert Notizen als Gliederung aus Blöcken. Der DB-Graphtyp nutzt eine Datenbank (Exporte als SQLite/EDN); der ältere Dateigraph nutzt Markdown- oder Org-Dateien.

## Für wen geeignet

Logseq ist ein quelloffenes Gliederungswerkzeug, in dem jeder Punkt ein Block ist, auf den von anderen Stellen verwiesen werden kann; eine Datenbankversion ersetzt die Version mit Markdown-Dateien.
