# Notion — Layout (2026-11-07)

Quellen: [S12] Seitenleiste, [S15] Seitenmenü, [S13] Datenbanken. Pixelmaße und visuelle Details stehen nicht auf den gelesenen offiziellen Seiten und werden nicht angegeben.

## Bereiche

```
+--------------------------------------------------------------------+
| (page tabs)                                       Inbox  New item  |
+-------------------+------------------------------------------------+
| Sidebar           | Page header: icon, cover, title   ... (page)   |
|                   |----------------------------------------------- |
| Home              | Content: blocks, or database view             |
| Chats with AI     |                                                |
| Meetings          |                                                |
| Library           |                                                |
| Templates         |                                                |
| Trash             |                                                |
| Settings          |                                                |
| (workspace name)  |                                                |
+-------------------+------------------------------------------------+
```

Die Skizze stammt von uns. Sie zeigt die Orte, die in [S12] und [S15] genannt sind, nicht gemessene Positionen.

## Seitenleiste [S12]

- Oberste Reiter mit eigenen Tastenkürzeln und Abschnitten.
- Oben rechts: Inbox (Benachrichtigungen) und das Menü Neues Element.
- Auf der Seite genannte Einträge: Search (cmd/ctrl+K), Home, Chats with Notion AI, Meetings, Inbox, Library, Templates, Trash, Settings. "Library" durchsucht alle Inhalte des Arbeitsbereichs.
- Unten: Der Name des Arbeitsbereichs öffnet den Arbeitsbereichswechsler.
- Abschnitte: Private, Shared, Teamspaces. Favorites erscheint nach dem ersten Favoriten. Ein Klick auf den Abschnittsnamen klappt ihn ein.
- Seiten per Ziehen ordnen oder verschachteln. Eine Seite in den Papierkorb zu ziehen löscht sie samt ihren Unterseiten.
- Rechter Rand: zum Ändern der Breite ziehen. "<<" und ">>" klappen die Seitenleiste ein; cmd/ctrl+\ schaltet sie ebenfalls um [S12].

## Inhaltsbereich

- Seitenkopf: Icon, Titelbild, Titel [S15].
- Seitenmenü (••• oben rechts): Gruppe Appearance & layout mit Font, Small text, Full width, Table of contents [S15].
- Datenbankseite: ein Ansichtswechsler mit den Ansichten Tabelle, Liste, Board, Kalender, Galerie und Diagramm [S13].
- Vollbildmodus für Bilder und Einbettungen: cmd/ctrl+Enter auf einem ausgewählten Block [S11].
