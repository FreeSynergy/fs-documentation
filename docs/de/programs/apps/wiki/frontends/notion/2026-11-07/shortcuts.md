# Notion: Tastenkürzel (2026-11-07)

Quelle: [S11] Seite mit den Tastenkürzeln, sofern nicht anders markiert. Notion schreibt `cmd/ctrl`: cmd unter macOS, ctrl unter Windows und Linux. `option/alt` und `shift` sind so geschrieben, wie sie angegeben sind.

## Am häufigsten verwendet

| Taste | Funktion |
|-----|----------|
| cmd/ctrl + F | In einer Seite suchen |
| cmd/ctrl + P oder cmd/ctrl + K | Suche öffnen oder zu einer zuletzt angesehenen Seite springen |
| cmd/ctrl + L | Seiten-URL kopieren |
| cmd/ctrl + [ / ] | Zurück / vor |
| cmd/ctrl + shift + L | Zwischen dunklem und hellem Modus wechseln |
| cmd/ctrl + N | Neue Seite (Desktop) |
| cmd/ctrl + T | Neuer Tab (Desktop) |

## Schreiben und Formatieren

| Taste | Funktion |
|-----|----------|
| Enter | Neue Zeile / neuer Block |
| shift + Enter | Zeilenumbruch innerhalb eines Blocks |
| cmd/ctrl + B / I / U | Fett / kursiv / unterstrichen (bei markiertem Text) |
| cmd/ctrl + shift + S | Durchgestrichen (bei markiertem Text) |
| cmd/ctrl + E | Code im Text (bei markiertem Text) |
| cmd/ctrl + K | Link hinzufügen (bei markiertem Text) |
| cmd/ctrl + shift + M | Kommentar erstellen |
| `---` + Enter | Trennlinie (als Markdown eingegeben) |
| `**text**`, `*text*`, `` `text` ``, `~text~` | Markdown-Inline-Stile beim Schreiben |
| `* `, `- `, `+ ` | Aufzählungsliste |
| `[] ` | To-do |
| `1. `, `a. `, `i. ` | Nummerierte Liste |
| `# `, `## `, `### ` | Überschrift 1–3 |
| `> ` | Umschaltliste |
| `" ` | Zitatblock |

## Blöcke

| Taste | Funktion |
|-----|----------|
| Tab / shift + Tab | Einrücken / Ausrücken |
| Esc | Aktuellen Block auswählen, oder Auswahl aufheben |
| cmd/ctrl + A | Den Block auswählen, in dem der Cursor steht |
| Pfeiltasten | Einen anderen Block auswählen |
| shift + Pfeil nach oben/unten | Auswahl erweitern |
| shift + Klick | Einen Bereich auswählen |
| cmd/ctrl + shift + Klick (Mac) / alt + shift + Klick (Windows) | Einen Block auswählen oder abwählen |
| cmd/ctrl + D | Ausgewählte Blöcke duplizieren |
| Backspace / Delete | Ausgewählte Blöcke löschen |
| cmd/ctrl + shift + Pfeiltaste | Ausgewählten Block verschieben |
| option/alt + ziehen | Inhalt duplizieren |
| Enter | Text eines ausgewählten Blocks bearbeiten |
| cmd/ctrl + / | Ausgewählte Blöcke bearbeiten oder ändern (auch mehrere Datenbankzeilen) |
| cmd/ctrl + Enter | Aktion auf den aktuellen Block ausführen: Seite öffnen, To-do abhaken, Umschalter, Einbettung oder Bild im Vollbild |
| cmd/ctrl + option/alt + T | Alle Umschalter auf- oder zuklappen |
| cmd/ctrl + option/shift + 0–9 | 0 Text, 1–3 Überschriften, 4 To-do, 5 Aufzählung, 6 nummeriert, 7 Umschalter, 8 Codeblock, 9 neue Seite |
| cmd/ctrl + shift + H | Letzte Text- oder Markierungsfarbe anwenden |
| cmd/ctrl + shift + U | Eine Ebene nach oben in der Seitenhierarchie |
| cmd/ctrl + + / - | Vergrößern / verkleinern |
| Leertaste | Bild im Vollbild öffnen oder schließen |

## Datenbank-Vorschau [S11]

| Taste | Funktion |
|-----|----------|
| ctrl + shift + K (Mac) / ctrl + K (Windows) | Vorherige Datenbankseite |
| ctrl + shift + J (Mac) / ctrl + J (Windows) | Nächste Datenbankseite |

## Schrägstrich-Befehle [S11]

Gib den Befehl ein und drücke Enter, zum Beispiel `/h1` und dann Enter.

| Befehl | Block |
|---------|-------|
| `/text`, `/plain`, `/page`, `/bullet`, `/num`, `/todo`, `/toggle`, `/div`, `/quote`, `/h1`, `/h2`, `/h3`, `/link` | Grundlegende Blöcke |
| `/mention`, `/date`, `/reminder`, `/equation`, `/emoji` | Inline |
| `/image`, `/pdf`, `/book`, `/video`, `/audio`, `/code`, `/file`, `/embed` | Medien |
| `/duplicate`, `/moveto`, `/delete`, `/toc`, `/button`, `/template`, `/bread`, `/math`, `/latex` | Erweitert |
| `/turn`, `/color`, `/default` | Typ und Farbe ändern |

## Entfernt (nicht auf der offiziellen Seite)

Die frühere Seite mit Tastenkürzeln nannte viele Kürzel, die die offizielle Seite nicht dokumentiert, darunter Ctrl+Shift+P Befehlspalette, Ctrl+S speichern, Ctrl+Shift+E exportieren, Ctrl+Shift+F teilen, Ctrl+Shift+A App-Manager, F11 sowie Sprach-Schrägstrich-Befehle wie `/js` und `/python`. Jedes davon ist nicht verifiziert und wurde entfernt. Siehe [changelog.md](../changelog.md).

## Hinweise

- Die offizielle Seite nennt Tasten für Windows und Mac. Linux wird nicht erwähnt; cmd/ctrl bedeutet dort ctrl.
- Manche Kürzel unterscheiden sich je nach Plattform nur im Tastennamen (cmd vs. ctrl). Andere unterscheiden sich in der Taste (option vs. alt).
