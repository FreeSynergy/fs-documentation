# Asana - Menüpunkte

## Sideleiste

| Menü | Inhalt |
|------|--------|
| Suche (oben) | Globale Suche/„Sprung zu“ |
| Mein Arbeitsbereich | **Meine Aufgaben** (heute/alle), Benachrichtigungen, Inbox |
| Projekte | Projekte je Team, Ansichten: Liste, Tafel (Kanban), Timeline, Kalender, Tabelle |
| Portfolios | Sammlungen mit Status/Ampeln (Advanced/Enterprise) |
| Workloads | Kapazitätsauslastung je Person (Advanced+) |
| Ziele (Goals) | OKR-artige Ziele mit Verfolgung |
| Forms | Formulare als Aufgabe-Eingang |

## Aufgabenpanel (Rechtsklick/Klick)

- Bearbeiten: Titel, Beschreibung, Fällig, Zugeordnet, Teilnehmer, Abhängigkeiten, Anhänge, Tags, Custom Fields
- Unteraufgaben-Liste, Kommentare, „Beobachten“

## Admin/Einstellungen

| Bereich | Inhalt |
|---------|--------|
| Workspace-Einstellungen | Mitglieder, Gastfreigaben, Custom Fields verwalten |
| Apps/Integrationen | Marketplace, **REST-API-Token**, Webhooks (App-Konfiguration) |
| Regeln (Advanced) | Automatisierungsregeln je Projekt („if Fälligkeit < heute then …“) |
| Abrechnung/Sicherheit | SSO/SAML, Domain-Capturing (Enterprise) |

## Menüs nach Rolle

Member/Guest differiert kaum (Gäste eingeschränkte Projekte); Admins sehen Abrechnung/API.
