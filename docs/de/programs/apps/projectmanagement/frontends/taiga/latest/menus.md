# Taiga - Menüpunkte

## Kopfnavigation je Projekt (Module)

| Modul | Inhalt |
|-------|--------|
| Backlog | User Stories, Points, Filter, Sprint-Zuweisung (Scrum-Projekte) |
| Kanban | Tafel mit Spalten, WIP-Grenzen (Kanban-Projekte) |
| Issues | klassische Fehler-/Aufgabenliste (alle Projekttypen) |
| Sprints | aktiver Sprint, Burndown, Closure-Check |
| Epics | Epics + Subtasks (mit Epics-Modul) |
| Customer CRM | Kunden-Kontakte + CRM-Notes (optionales Modul) |
| Wiki | Seiten im Projekt |
| Stats | Statistiken/Burndown-Charts |
| Timeline | Meilenstein-/Sprint-Timeline |

## Epic-Tracker (Projektübergreifend)

Epics über mehrere Projekte, Fortschrittsbalken, Statusfelder.

## Admin-Center (⚙)

| Bereich | Inhalt |
|---------|--------|
| Projekte | anlegen, Rollen (Epics Manager/Backlog Admin…), Module aktivieren |
| Benutzer | Mitglieder, Einladungen, Teams (Taiga Cloud) |
| Custom Fields | Status/Prioritäten/Feldauswahlen, eigene Felder |
| Benachrichtigungen/Vorlagen | Mail-Templates, Slack/Telegram-GitHub-Integrationen |
| Import/Export | JSON-Backup, Import aus Asana/Jira/Trello (Version prüfen) |

## Menüs nach Rolle

Rollen (Backlog Admin, User Story Admin, EPIC Admin, Page Admin…) schalten Modulzugriff; anonyme Projects = öffentlich lesbar.
