# Trello - Tastatur-Shortcuts

## Übersicht

Trello hat eine der besten Shortcut-Sets unter den Web-Tools; `?` zeigt die Übersicht.

> Stand: Trello (2026).

## Board

| Shortcut | Funktion |
|----------|----------|
| `N` | neue Liste |
| `C` | neue Karte (in fokussierter Liste) |
| `A` | (Karte offen) Mitglieder zuweisen |
| `L` | (Karte offen) Labels |
| `D` | (Karte offen) Fälligkeit |
| `Leertaste` | (Karte offen) sich selbst zuweisen |
| `E` | (Karte offen) Titel bearbeiten |
| `[` / `]` | (Karte fokussiert) nach links/rechts verschieben |
| `←↑↓→` | Kartenfokus bewegen |
| `F` | Filter |
| `/` | Suche im Board |
| `Strg/Cmd+K` | Board-Schnellwechsler (Workspace) |
| `?` | Shortcuts-Overlay |
| `Esc` | Overlay schließen |

## Ausdrücklich nicht vorhanden

- Kein „Karte archivieren“-Shortcut dokumentiert (Menü „…“ → Archivieren; ältere Builds: `S`)

## Mac

Alle `Strg`-Tasten mit `Cmd`; Einzelbuchstaben identisch.
