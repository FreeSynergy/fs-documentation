# Trello Dokumentation

## Übersicht

Trello (Atlassian) ist das digitale Kanban-Brett: Boards mit Listen und Karten, Fälligkeiten, Labels, Mitglieder, Checklisten und Automatisierung per „Butler“. SaaS mit sehr guter REST-API; Vorlage für praktisch jedes Kanban-Skin.
