# Asana - Tastatur-Shortcuts

## Übersicht

Asana dokumentiert Kurzbefehle (`?` zeigt das Overlay). Der Bestand ist kleiner als bei Trello/Jira — Unsicheres ist markiert.

> Stand: 2026.

## Global

| Shortcut | Funktion |
|----------|----------|
| `/` | Suche fokussieren |
| `Esc` | Panel/Suche schließen |
| `?` | Shortcuts-Overlay |
| `Strg/Cmd+K` | Schnellnavigation (Jump-to) — in aktuellen Versionen, Stand prüfen |

## Aufgabe (Panel offen)

| Shortcut | Funktion |
|----------|----------|
| `Q` | Fälligkeit setzen |
| `A` | zuweisen |
| `C` | Kommentare fokussieren |
| `E` | Titel bearbeiten — Status prüfen |
| `Strg/Cmd+Enter` | Kommentar senden |

## Nicht dokumentiert

- Board-/Portfolio-Ebene: keine Buchstaben-Aktionen

## Mac

`Cmd` statt `Strg`; Buchstabentasten identisch.
