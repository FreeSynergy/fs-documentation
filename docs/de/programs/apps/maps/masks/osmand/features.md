# OsmAnd - Funktionen

## Hauptfunktionen

### Offline-Karten
- Regionen (.obb) herunterladen, mehrere Kartenprofile (Standard/Rad/Wander…), Höhendaten + Konturlinien, Offline-Suche + Routing komplett ohne Netz

### Navigation
- Routingprofile (Auto/LKW/Rad/Fuß), Fahrspur-/Abbiegehinweise, TMC (online), Spurassistent, „Fahren nach GPX“ (Track folgen)
- ÖPNV-Haltestellen/Route teils online (OpenTripPlanner-Integration)

### Eigene Orte (Skin-relevant!)
- **Meine Orte**: Ordner als Ebenen, Punkte mit Notizen, GPX-Import aus uMap/Komoot, Layer-Sichtbarkeit
- Track-Aufzeichnung (Zeiten, Höhe), „Aufzeichnung teilen“

### Kartenansicht
- 3D-Ansicht, Nachtkarten, Maßstabs-/Messwerkzeug, POI-Overlay-Kategorien

## Was OsmAnd NICHT kann

- **kein Server/Synchronisationsdienst** — Datenhaltung lokal/Dateien (Sync via own Cloud)
- **kein Karten-Editor** (OSM-Änderungen nur per OSM-App/Web)
- Live-Stau/Verkehr nur mit Online-Diensten; keine CarPlay/Android-Auto-Tiefintegration (teilweise)
- iOS-Funktionen hinter Android (Plugins später)
