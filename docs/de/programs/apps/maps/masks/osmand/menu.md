# OsmAnd - Menüpunkte

## Hauptnavigation (unten, Leiste)

| Reiter | Inhalt |
|--------|--------|
| Navigation | Zielroutung starten (Adresse/POI/Karte/Meine Orte) |
| Planen (Route) | Route per Punkte-Kette, Zwischenstopps, Höhenprofil, Export GPX/GPX-Freigabe |
| Meine Orte (My Places) | Ordner + Punkte + GPX-Dateien (Ebenen), Import/Export |
| Wiki/Nearby | POI-Kategorien, Suche |
| configure… | Einstellungen/Plugins („Planung & Navigation“-Modul, Live-Updates) |

## Seitenleisten

| Leiste | Inhalt |
|--------|--------|
| Linke Leiste („Hamburger“) | Offline-Karten herunterladen, App-Einstellungen, deaktivierte Funktionen |
| Rechte Leiste („Karte konfigurieren“) | Konturlinien, POI-Ebenen, 3D-Ansicht, Nachtmodus, Messwerkzeug |

## Navigationsmodus

- Abbiege-Kacheln, Spurassistent, TMC-Verkehr (online), „Reise-Statistik“

## Import/Export-Menü

- GPX/KML/KMZ Import, „Meine Orte“ als `.ovf/.gpx` sichern; Sharing per Datei
