# QGIS - Tastatur-Shortcuts

## Übersicht

QGIS hat eine ausführliche, editierbare Shortcuts-Übersicht unter **Einstellungen → Tastatur-Shortcuts**. Basisliste:

> Stand: QGIS 3.x (aktuelle LTS).

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Strg+N` / `Strg+O` / `Strg+S` | neues Projekt / öffnen / speichern |
| `Strg+Z` / `Strg+Shift+Z` | Undo / Redo (Editierungen) |
| `F2` (Layer-Baum) | Layer umbenennen |
| `Entf` (Layer) | Layer entfernen |
| `Esc` | Auswahl/Werkzeug abbrechen |
| `Leertaste`+Ziehen | Pan (Verschieben) |
| `Shift+Drag` | Rechteck-Auswahl (Auswahlwerkzeug) |
| `Strg+Shift+V` | Einfügen als neuer Layer (Copy/Paste Geometrien) — Stand prüfen |

## Anpassen

Shortcuts frei belegbar (Dialog oben).

## Mac

`Cmd`-Variante bei Datei-/Editierbefehlen.
