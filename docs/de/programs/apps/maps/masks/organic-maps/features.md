# Organic Maps - Funktionen

## Hauptfunktionen

- **Offline-Karten + Routing** (Auto/Fahrrad/Zu Fuß), Offline-Suche, Höhenlinien
- **Bookmarks/Sammlungen**: Punkte mit Notizen, Listen, KML/BM2-Import/Export — Gruppen-Ordner per Datei teilbar
- **Track-Planung** (neuere Versionen: Routenpunkte, GPX-Import für Touren)
- Datenschutz: keine Konten-pflicht, kein Tracking; Open-Source (F-Droid)

## Was Organic Maps NICHT kann

- **kein LKW-Profil/Spurassistent-Feintuning** (OsmAnd-Detailtiefe)
- **kein Live-Verkehr/ÖPNV-Routing**
- Bookmarks ohne Verschlagwortung/Beziehungen (flach, Listen)
- kein Karten-Editing; Sync nur über Dateien (kein Dienst)
