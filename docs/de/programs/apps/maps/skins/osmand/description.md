# OsmAnd - Beschreibung

## Was das Programm macht

OsmAnd bringt OSM als vollwertige Navigation aufs Handy: Karten offline, Routing offline, eigene Orte als GPX-Ordner. Es ist die Power-User-Variante der offenen Karten-Apps — Funktionen vor Eleganz.

## Vorteile

- **echtes Offline-Abenteuer** (Karten, Höhen, POI)
- **My Places als verteiltes Adressbuch**: Gruppenpunkte per GPX austauschbar
- quelloffen, Fork-freundlich (Community-Builds)

## Abgrenzung

| System | Unterschied |
|--------|-------------|
| **Organic Maps** | schlanker/schneller; OsmAnd feature-reicher (Plugins, LKW-Profile) |
| **Locus Map** | kommerziell, ähnlicher Funktionsberg |
| **Google Maps** | proprietär/live; OsmAnd offline/datensouverän |

## Technische Details

- **Stack**: C++-Kern (OsmAnd Core), Android/iOS-Oberflächen
- **Daten**: .obb-Kacheln + .ipn-Index (OSM-PBF abgeleitet, ODbL)
- **Authentifizierung**: keine (lokal); Plus-Abo freischaltend
- **Lizenz**: Apache-2.0 (OsmAnd)

## Für wen geeignet

- Wander-/Vereinsgruppen mit Standpunkte-Tausch + Navigationsbedarf ([standpunkte.md](../../standpunkte.md))
