# Organic Maps - Tastatur-Shortcuts

## Übersicht

Touch-App ohne dokumentierte Tastaturkürzel; Steuerung über Gesten und Sheets.

> Stand: Organic Maps 2026.

## Gesten

| Geste | Funktion |
|-------|----------|
| Tippen | POI auswählen/Sheet öffnen |
| Doppeltipp | Zoom |
| Zwei Finger | Zoom/Rotieren/Kippen |
| Wischen am Sheet | Detailtiefe wechseln |
| langes Tippen | Punkt-Marker (Kontext) |

## Ausdrücklich nicht vorhanden
