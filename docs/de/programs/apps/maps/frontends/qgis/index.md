# QGIS Dokumentation

> Kategorie: [maps](../../index.md)

## Übersicht

QGIS (GPL) ist das professionelle Desktop-GIS: Layer (Shapefile/GeoPackage/PostGIS/WMS), Analyse-Werkzeuge (Puffer, Überlagerungen, Geoprocessing), Druck-Layouts, **QGIS Server** (OGC-Dienste) und Python (PyQGIS). De-facto-Standard im offenen Geowesen.

## Bemerkenswerte Ideen

_Zu tun: Was kann dieses Programm, das andere nicht können? Warum ist es hier dokumentiert (ADR 0013)?_
