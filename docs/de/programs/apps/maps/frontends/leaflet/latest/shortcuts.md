# Leaflet - Tastatur-Shortcuts

## Übersicht

Die **Karte** (nicht die Bibliothek) hat eine Tastaturnavigation — aktivierbar über `keyboard: true` (Standard).

> Stand: Leaflet 1.9.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Pfeiltasten` | Karte verschieben |
| `+` / `-` | Zoom hinein/hinaus |
| `Esc` | Popup/Tooltip schließen |
| `Tab` | Controls/Marker (DOM-Fokus der App) |

## Ausdrücklich nicht vorhanden

- globale Kurzbefehle (App-seitig selbst zu bauen)
