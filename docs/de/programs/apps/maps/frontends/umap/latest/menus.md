# uMap - Menüpunkte

## Werkzeugleiste (links auf der Karte)

| Werkzeug | Inhalt |
|----------|--------|
| Marker/Set setzen | Punkt, Linie, Fläche, Kreis, Rechteck (Icons/Symbole wählbar) |
| Ebenen verwalten | Ebenen anlegen/umschalten (sichtbar/auswählbar), „Basisdaten“ vs. eigene Ebenen |
| Filter/Sortierung | Suchfeld für Marker-Attribute |

## Ebenen-Panel (links)

- Ebenenliste mit Zähler, „Diese Ebene bearbeiten“ (Farbe, Symbol, Cluster-Optionen, POP-Ups)
- Daten pro Ebene: Tabelle-ähnliche Auflistung der Objekte

## Karte bearbeiten (Zahnrad oben)

| Menü | Inhalt |
|------|--------|
| Karten-Einstellungen | Name/Beschreibung, Basislayer, Zoom/Bounds, „Karte als Startseite“ |
| Formate | Icon-Sätze, Popup-Größe, Datumsformat |
| Teilen | Links (bearbeitbar/anschaubar), Einbettung (iframe), QR |
| Import/Export | GeoJSON/GPX/KML/KCSV importieren/exportieren |
| Berechtigungen | anonym bearbeiten?, „edit token“ Link, Passwortschutz eingeschränkt |

## Menüs nach Rolle

- **Jeder** (bei privatem Modus: keiner) · **Redakteure per Token-Link** · **Eigentümer** (Einstellungen)
