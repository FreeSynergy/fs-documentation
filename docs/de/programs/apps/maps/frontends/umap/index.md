# uMap Dokumentation

> Kategorie: [maps](../../index.md)

## Übersicht

uMap (uMap Project, free software) ist **kollaborative Karten-Diagrammung**: eigene Ebenen mit Markern/Polylinien/Flächen, Popup-Inhalte (HTML), Sharing per Link, Mehrbenutzer-Edit. Baut auf OSM-Kacheln; self-hostbar (Django/PostgreSQL) oder öffentliche Instanzen (uMap.org).

## Bemerkenswerte Ideen

_Zu tun: Was kann dieses Programm, das andere nicht können? Warum ist es hier dokumentiert (ADR 0013)?_
