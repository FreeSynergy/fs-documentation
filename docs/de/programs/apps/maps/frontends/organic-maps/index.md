# Organic Maps Dokumentation

## Übersicht

Organic Maps (GPL, Abo-freie Nonprofit-App) ist die schlanke Offline-Karten-/Navigations-App (Android/iOS/Desktop): schnell, datensparsam (keine Tracking-Werbelogik), OSM-basiert, mit eigenen Orten (Bookmarks) und Offline-Routing.
