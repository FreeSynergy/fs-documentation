# Google Earth latest — Layout

Das detaillierte Layout wurde nicht aus einer primären Quelle gelesen; nur das Folgende ist bekannt oder vernünftig angenommen.

- Hauptbereich: der Globus, der das Fenster füllt.
- Seitenpanel für Suchergebnisse, Projekte und Touren: offen (Platzierung nicht geprüft).
- Kartensteuerung: Kippen, Zoom, ein Pegman-Symbol für Street View.
- Responsiv/mobil: eigene mobile Apps existieren; Verhalten: offen.
- Barrierefreiheit: offen.
