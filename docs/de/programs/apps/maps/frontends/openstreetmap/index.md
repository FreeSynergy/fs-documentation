# OpenStreetMap Dokumentation

> Kategorie: [maps](../../index.md)

## Übersicht

OpenStreetMap (OSM) ist die weltweite kollaborative Kartenplattform: Jeder editiert die Geodaten („Wiki der Karten“). Ökosystem: iD/JOSM-Editoren, Overpass-API (Datenabfragen), OSM-API (Knoten/Ways/Relations), Nominatim (Suche), Kachel-/Vektor-Dienste Dritter. ODbL-Lizenz (Namensnennung!).

## Bemerkenswerte Ideen

_Zu tun: Was kann dieses Programm, das andere nicht können? Warum ist es hier dokumentiert (ADR 0013)?_
