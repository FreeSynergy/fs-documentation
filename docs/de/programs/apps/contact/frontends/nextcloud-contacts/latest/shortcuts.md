# Nextcloud Contacts - Tastatur-Shortcuts

## Übersicht

Die Contacts-App definiert **keine eigenen Shortcuts**; es gelten die Nextcloud-Global-Tasten und Browser-Standards. Fehlende werden markiert.

> Stand: Contacts 5.x/6.x auf Nextcloud 28+.

## Nextcloud-Global

| Shortcut | Funktion |
|----------|----------|
| `/` | Suchfeld fokussieren (Nextcloud-Kopfzeile) |
| `Strg/Cmd+K` | Universal-Search / Befehlspalette |
| `Esc` | Detailpanel/Suche schließen |
| `Enter` | ersten Suchtreffer öffnen; Feldbearbeitung bestätigen |

## Liste und Detail

| Shortcut | Funktion |
|----------|----------|
| `Tab` | Felder im Formular durchlaufen |
| `Shift+Tab` | zurück |
| `Entf` | (nicht dokumentiert — Löschen nur per Button) |
| `N` neuer Kontakt | ❌ nicht vorhanden — Button „Neuer Kontakt“ |

## Mac

`Cmd` statt `Strg`.

## Ausdrücklich nicht vorhanden

- keine Ein-Buchstaben-Navigation wie in Mail-Clients
- kein Shortcut zum Anlegen von Adressbüchern
