# KAddressBook - Tastatur-Shortcuts

## Übersicht

KAddressBook folgt den KDE-Standardkurzbefehlen; die wichtigsten sind in den Menüs sichtbar („Configure Shortcuts“ frei remappbar).

> Stand: KDE Gear 23.x/24.x.

## Datei und Kontaktanlage

| Shortcut | Funktion |
|----------|----------|
| `Strg+N` | Neuer Kontakt |
| `Strg+Shift+V` | Neue Verteilerliste (in vielen Versionen; sonst Menü) |
| `Strg+I` | Import-Assistent |
| `Strg+E` | Export-Assistent |
| `Strg+P` | Drucken (Adressen/Visitenkarten) |
| `Strg+W` / `Strg+Q` | Fenster / Anwendung schließen |

## Bearbeiten

| Shortcut | Funktion |
|----------|----------|
| `Enter` / `Return` | markierten Kontakt bearbeiten |
| `Entf` | Kontakt löschen |
| `Strg+C` / `Strg+V` | Kontakt kopieren / in anderes Adressbuch einfügen |
| `Strg+Z` | Rückgängig (innerhalb der Sitzung) |

## Navigation und Suche

| Shortcut | Funktion |
|----------|----------|
| `Strg+F` | Suchfeld fokussieren |
| `Pfeiltasten` / `Bild auf/ab` | Liste bewegen |
| `Pos1` / `Ende` | Listenanfang/-ende |
| `F5` | Akonadi-Ressourcen aktualisieren |

## Mac-Varianten

KAddressBook hat keinen offiziellen Mac-Build; Qt-Ersatz `Cmd`↔`Strg`, falls gebaut.

## Ausdrücklich nicht vorhanden

- Kein Ein-Buchstaben-Filter wie in Evolution
- Kein globaler Hotkey zum Öffnen (über Plasma-Tastatur selbst zuweisen)
