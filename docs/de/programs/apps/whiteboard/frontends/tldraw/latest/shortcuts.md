# tldraw - Tastatur-Shortcuts

## Übersicht

tldraw ist extrem shortcut-getrieben; die Kurzbefehle sind offiziell dokumentiert und in der App über `?` (Hilfe-Dialog) abrufbar.

> Stand: tldraw 2.x/3.x (App und SDK identische Belegung).

## Werkzeuge

| Shortcut | Werkzeug |
|----------|----------|
| `V` | Auswählen |
| `H` | Hand (Pan) |
| `S` | Laser-Pointer |
| `D` | Stift (Draw) |
| `E` | Radierer |
| `A` | Pfeil |
| `R` | Rechteck |
| `O` | Ellipse |
| `L` | Linie |
| `T` | Text |
| `N` | Notiz |
| `F` | Frame |
| `I` | Bild |
| `B` | Bookmark |

## Bearbeiten

| Shortcut | Funktion |
|----------|----------|
| `Strg/Cmd+C` / `+V` / `+X` | Kopieren / Einfügen / Ausschneiden |
| `Strg/Cmd+D` | Duplizieren |
| `Strg/Cmd+A` | Alles auswählen |
| `Entf` / `Backspace` | Auswahl löschen |
| `Strg/Cmd+Z` / `+Shift+Z` | Rückgängig / Wiederholen |
| `Strg/Cmd+G` / `+Shift+G` | Gruppieren / Auflösen |
| `Strg/Cmd+]` / `+[` | nach vorne / nach hinten |
| `Strg/Cmd+L` | Sperren/Entsperren |
| `Pfeiltasten` | Auswahl 1 px bewegen (`Shift` = 10 px) |

## Ansicht

| Shortcut | Funktion |
|----------|----------|
| `Strg/Cmd+=` / `+-` | Zoom rein/raus |
| `Strg/Cmd+0` | Zoom zurücksetzen |
| `Strg/Cmd+1` | Zoom auf Auswahl |
| `Strg/Cmd+Shift+1` | Zoom auf alles |
| `Leertaste` + Ziehen | Canvas bewegen |
| `Strg/Cmd+Rad` | Zoomen |

## Dateien

| Shortcut | Funktion |
|----------|----------|
| `Strg/Cmd+S` | Speichern (lokal-first, ohnehin autosave) |
| `Strg/Cmd+P` | Drucken |

## Mac

Alle `Strg`-Kombinationen mit `Cmd`; die Buchstaben-Tool-Tasten sind identisch.

## Ausdrücklich nicht vorhanden

- Kein Vim-Modus
- Kein „Heute"- oder Ordner-Navigator — Dateien werden über das App-Startbild (bzw. eigene Implementierung im SDK) geöffnet
