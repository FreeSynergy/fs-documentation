# Mural - Struktur und UI/UX

## Seitenstruktur

```
┌───────────────────────────────────────────────────────────────────┐
│ ◀ Workspace   „Retro Q4“   ⋯ Share   👥 (7)                      │
│ ┌Sequenz: Schritt 2/5 · Retro-Sammlung · 10:00 ⏱┐                │
│ ├────────────────────────────────────────────────┤                │
│ │      (Canvas mit Areas/Notizen)                │                │
│ │   🟦🟦🟦   🟨🟨   🟩🟩🟩                        │                │
│ └────────────────────────────────────────────────┘                │
│        [V N T R …]  (Werkzeugleiste unten)      Zoom 43%          │
└───────────────────────────────────────────────────────────────────┘
```

- Sequenz-Balken oben zeigt Moderationsschritte + Timer; Werkzeugleiste unten mittig

## UI/UX

- reduzierte, dunkle Chrome-Elemente, helles Canvas; Areas als strukturierte Zonen
- Notizen mit Autor:innen-Farbe

## Interaktionen

- Multiplayer-Cursor, „Follow the facilitator“, Notizen gruppierbar
- Drag & Drop, Shift+Drag = Auswahlrechtwinkel

## Responsive Design

- Web + Desktop-App; Mobil für Viewing/Kurzbearbeitung

## Accessibility

- Tastatur für Notiz-/Formwerkzeuge; Sequenzsteuerung per Klick/Tastatur
- Mural publiziert Accessibility-Erklärungen (Enterprise-Bereich)
