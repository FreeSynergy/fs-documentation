# FigJam - Layout

Drei Bereiche sind dokumentiert: das Board (Zeichenfläche), eine Dateileiste oben und eine Werkzeugleiste für Werkzeuge und Objekte unten.

| Bereich | Inhalt |
|---------|--------|
| Linkes Panel | Seiten der Datei |
| Rechte Seitenleiste | Vorlagen |
| Untere Werkzeugleiste | Werkzeuge, zum Beispiel Abschnitte |
| Obere Werkzeugleiste | Dateimenü und Dateiaktionen |
| Panel für Timer, Abstimmung und Musik | Öffnet sich über ein Symbol; hat einen Ergebnis-Reiter; der Timer lässt sich ausblenden und läuft in der Werkzeugleiste weiter |

Offen: genaue Positionen der Zoom-Steuerung, der Schaltfläche „Teilen“ und der Mitgliederliste; Verhalten auf kleinen Bildschirmen und Tablets.
