# FigJam - Funktionen

## Vorhanden
| Bereich | Funktion | Beleg |
|---------|----------|-------|
| Notizen | Haftnotizen; der Name des Autors wird standardmäßig angezeigt und lässt sich abschalten | Hilfeseite ✅ |
| Zeichnen | Text, Marker, Textmarker, Washi-Tape, Formen | Liste der Tastenkürzel ✅ |
| Struktur | Abschnitte gruppieren und verschieben Objekte gemeinsam; Verbindungslinien (gerade, abgewinkelt) zwischen Objekten | ✅ |
| Reaktionen | Sticker (kuratierte Aufkleber) auf dem Board oder auf Objekten; Emotes als vorübergehende Schübe | ✅ |
| Moderation | Timer; Abstimmung mit Stimmzahl je Teilnehmendem; Ergebnisse bis zum Ende der Sitzung verborgen; Ergebnis-Reiter je Sitzung | ✅ (Details zur Abstimmung ⚠️) |
| Anwesenheit | Cursor-Chat (eine Nachricht am eigenen Zeiger) | ✅ |
| Erweiterung | Widgets (eigene Objekte, externe Daten) | ✅ |
| Import | Import aus CSV | ✅ |
| Vorlagen | Vorlagen-Seitenleiste | ✅ |

## Nicht vorhanden oder offen
| Funktion | Status |
|----------|--------|
| Selbsthosting | nicht angeboten (angenommen; keine Aussage gefunden) offen |
| Kommentare an einer Stelle verankert | Kommentarwerkzeug existiert (`C`) ✅; Details offen |
| Exportformate | offen |
| Offline-Nutzung | offen |
