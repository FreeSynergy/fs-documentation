# FigJam - Tastenkürzel

Werkzeugtasten aus der Hilfeseite (macOS-Bezeichnungen):

| Taste | Funktion |
|-------|----------|
| `S` | Haftnotiz |
| `T` | Text |
| `M` | Marker |
| `Shift+M` | Textmarker |
| `W` | Washi-Tape |
| `C` | Kommentar |
| `E` | Sticker |
| `L` | Gerade Verbindungslinie |
| `X` oder `Shift+L` | Abgewinkelte Verbindungslinie |
| `Shift+S` | Abschnitt |
| `/` | Cursor-Chat |
| `Esc` | Aktuelles Werkzeug verlassen |

Offen: Kürzel für Zoom, Ausrichten, Gruppieren sowie die Tastennamen für Windows/Linux.
