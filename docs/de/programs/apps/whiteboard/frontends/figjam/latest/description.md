# FigJam - Beschreibung

## Was das Programm macht
FigJam ist ein gemeinsames Board für Brainstorming, Retrospektiven und Diagramme. Menschen fügen Haftnotizen, Text, Formen, Verbindungen und Zeichnungen hinzu, gruppieren sie in Abschnitten und reagieren aufeinander mit Stickern. Moderationswerkzeuge (Timer, Abstimmung) unterstützen geführte Sitzungen.

## Vorteile
- Sehr niedrige Einstiegshürde: eine Notiz, ein Sticker und eine Stimme sind je ein Klick.
- Soziale Präsenz: benannte Notizen, Cursor-Chat, Emotes.
- Widgets binden externe Daten ein (zum Beispiel Einträge eines Aufgabenverwaltungswerkzeugs).

## Abgrenzung
| System | Unterschied |
|--------|-------------|
| Miro, Mural | Größere Vorlagen- und Moderationskataloge; FigJam ist leichter und steht neben dem Design-Werkzeug desselben Anbieters. |
| tldraw, Excalidraw | Offen, auf die Zeichenfläche ausgerichtet; keine eingebaute Abstimmung oder Timer. |

## Technische Details
- Nur als gehosteter Dienst; kein Selbsthosting. Offen: Dateiformat, Client-Technologie.
- Zugang: Figma-Konto; API mit Zugriffstoken oder OAuth2.
