# Mautic - Menüpunkte

## Hauptmenü

| Menü | Inhalt |
|------|--------|
| Dashboard | Widgets (Kampagnenstatistik) |
| Kontakte | Liste, Segmente, import (CSV), Custom Fields, activity-Feed je Kontakt |
| Kampagnen | Baum-Builder: Trigger → Bedingungen/Actions (E-Mail, Tag, Wait, Point-Change) |
| E-Mails | Segmente (Newsletter), Vorlagen, A/B, Sender-Profile |
| Formulare/Landingpages | Baukasten + Einbettung (JS-Embed), Double-Opt-in |
| Berichte | Kampagnen-/E-Mail-Öffnung/Klick-Reports |
| Assets/Punkte | Downloads, Point-Leading-Regelkatalog |

## Konfiguration (⚙)

| Bereich | Inhalt |
|---------|--------|
| E-Mail-Einstellungen | SMTP/Transport, Tracking-Domain (CNAME!) |
| Webhooks | Ereignisse → Ziel-URLs (Kontakt erstellt/geändert…) |
| API-Zugänge | OAuth2-Clients, Basic-Auth-Schalter |
| Punkte/Felder | Custom Fields (Skin-Mapping!), Punktregeln |
| Sicherheit/DSGVO | Double-Opt-in-Pflicht, Lösch-Workflows (GDPR-Tools) |

## Menüs nach Rolle

Berechtigungs-Vektoren (view/create/edit/delete/full) pro Objekttyp; Admin global.
