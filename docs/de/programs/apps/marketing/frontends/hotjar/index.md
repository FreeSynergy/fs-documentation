# Hotjar Dokumentation

> Kategorie: [marketing](../../index.md)

## Übersicht

Hotjar (kommerziell) ergänzt Web-Analytik um das **Wie**: Heatmaps (Klicks/Scrolls/Moves), Session-Replays, Umfragen (Onsite-Surveys), Feedback-/Rage-Click-Erkennung und Funnel-Kopplung. Skript-basiert, EU-Datenhaltungsoption.

## Bemerkenswerte Ideen

_Zu tun: Was kann dieses Programm, das andere nicht können? Warum ist es hier dokumentiert (ADR 0013)?_
