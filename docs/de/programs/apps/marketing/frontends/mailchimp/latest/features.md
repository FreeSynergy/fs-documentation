# Mailchimp - Funktionen

## Hauptfunktionen

- **Kontaktverwaltung** mit Tags, Custom Fields, Segmenten, Profilen (E-Commerce-Historie)
- **Kampagnen-Editor** (Drag-Blöcke, Templates, A/B-Tests, Send-Optimierung)
- **Customer Journeys**: Trigger-Ereignisse (Signup, Kauf, Cart-Abbruch) → automatisierte Sequenzen
- Landingpages/Formulare/Popups, Social-Posts, einfache Websites
- **Reports**: Opens/Clicks/Maps, Conversions; Add-ons: Heatmaps, Retargeting-Ads

## Was Mailchimp NICHT kann

- **DSGVO-Schwierigkeiten** (US-Cloud; Auftragsverarbeitung möglich, aber Daten-flows kritisch prüfen — EU-Alternative Mautic/Brevo)
- Preise steigen mit Kontaktzahl (Kontingente, kein „unbegrenzt“)
- **keine Self-Hosting-Option**
- CRM-Tiefe begrenzt (Deals nur light; Pipeline-Features rudimentär)
- Transaktions-E-Mails (SMTP-API) nur in höheren Plänen
