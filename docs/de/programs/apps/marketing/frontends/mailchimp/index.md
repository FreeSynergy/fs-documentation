# Mailchimp Dokumentation

## Übersicht

Mailchimp (Intuit, kommerziell) ist die Newsletter-/Marketing-Automation-Plattform: Listen + Segmente, Kampagnen-Editor, E-Mail-Automatisierungen (Journeys), Landingpages, CRM-lite und Analytics. API v3 mit OAuth2.
