# Matomo Dokumentation

## Übersicht

Matomo (GPL, ehem. Piwik) ist die führende **self-hostbare Web-Analytics-Plattform** (PHP/MySQL): Besucherauswertung cookieless-fähig, Cookies mit Consent-Integration, Heatmaps/Session-Replay (Paid), Rollen, Rohdaten in der eigenen Datenbank. Cloud optional.
