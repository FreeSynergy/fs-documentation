# Hotjar Dokumentation

## Übersicht

Hotjar (kommerziell) ergänzt Web-Analytik um das **Wie**: Heatmaps (Klicks/Scrolls/Moves), Session-Replays, Umfragen (Onsite-Surveys), Feedback-/Rage-Click-Erkennung und Funnel-Kopplung. Skript-basiert, EU-Datenhaltungsoption.

## Dateistruktur

- [menu.md](menu.md) - Heatmaps/Replays/Surveys, Aufnahme-Regeln
- [features.md](features.md) - Heatmap-Typen, Umfragen, Was Hotjar NICHT kann
- [description.md](description.md) - Abgrenzung zu Matomo-Plugins, FullStory, Microsoft Clarity
- [structure.md](structure.md) - Heatmap-Overlay, Replay-Player, Umfrage-Editoren
- [shortcuts.md](shortcuts.md) - keine
- [api.md](api.md) - REST (Recordings/Surveys), Identify-API, keine offene Heatmap-Export-API
