# Plausible - Tastatur-Shortcuts

## Übersicht

Plausible hat **keine dokumentierten Kurzbefehle**; Dashboard ist klickbasiert.

> Stand: 2026.

## Vorhanden

| Shortcut | Funktion |
|----------|----------|
| `Tab`/`Enter` | Zeitraum-/Filterpicker |
| `Esc` | Dropdowns schließen |
| `Strg/Cmd+F` | Browser-Suche |
